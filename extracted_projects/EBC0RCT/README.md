# MatterJS Physics Sandbox

UI for customizing and visualizing physics scenarios with adjustable gravity, friction, and shapes using Matter.js and Tailwind CSS.

## Project Details
- **Slug:** `EBC0RCT`
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# INK — Real-time fluid, rendered live

A high-performance WebGL2 landing page template featuring real-time, living fluid physics and interactive GPU-rendered motion.

## Project Details
- **Slug:** `ink-landing-page-69`
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

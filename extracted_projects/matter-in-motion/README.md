# Matter in Motion — Immersive Exhibition

A cinematic and immersive landing page template for art exhibitions and galleries featuring smooth scroll interactions and reactive light visual effects.

## Project Details
- **Slug:** `matter-in-motion`
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

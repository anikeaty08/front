# neon-lab

A reusable landing page template designed to help teams build, launch, and grow products faster with AI-powered design, automation, collaboration, and analytics.

## Project Details
- **Slug:** `neon-lab`
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

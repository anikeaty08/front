# Neon Oiran — Cyber Geisha Action RPG

A high-impact gaming landing page template featuring immersive scroll animations, interactive character rosters, and tiered pricing sections for action-RPGs.

## Project Details
- **Slug:** `neon-oiran`
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

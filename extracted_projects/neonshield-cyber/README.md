# NeonShield – Cyber Defense Infrastructure

This reusable landing page template is designed for cybersecurity platforms, showcasing infrastructure security features, integrations, developer tools, and live monitoring.

## Project Details
- **Slug:** `neonshield-cyber`
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

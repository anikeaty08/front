# NEXUS — The Idea Arcade

A high-energy, retro-arcade inspired SaaS template for creative concept management and design systems.

## Project Details
- **Slug:** `nexus-arcade`
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

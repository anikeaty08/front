# Interactive Weather App Interface

Responsive weather UI with animated icons, 3D transforms, particle effects, and dynamic temperature display using Tailwind CSS and JS.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Interactive Scheduling Dashboard

Responsive scheduling UI with video background, calendar navigation, quick date ranges, and call-to-action buttons using Tailwind CSS.

## Project Details
- **Slug:** `1WKSHEN`
- **Views:** 303
- **Tags:** Scheduler, Calendar, Responsive UI, Tailwind CSS, Video Background, Navigation, Date Picker
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

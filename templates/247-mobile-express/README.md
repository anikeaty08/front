# Mobile Car Detailing Landing Page Template

A reusable landing page template for mobile car detailing businesses to showcase services, build trust, and capture bookings online.

## Project Details
- **Slug:** `247-mobile-express`
- **Views:** 20
- **Tags:** Landing Page, Services, Clean, Minimal, Dark, Automotive, Car Detailing, Booking, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

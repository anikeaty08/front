# Animated Horizontal Logo Band

Displays a horizontal band of animated colorful star logos moving continuously with 3D perspective and random hues.

## Project Details
- **Slug:** `2NDVZ6C`
- **Views:** 107
- **Tags:** Logo Animation, SVG, CSS Animation, 3D Perspective, Tailwind CSS, JavaScript
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Account Sign-In Interface

Responsive sign-in form with animated inputs, password toggle, custom checkbox, and alternative Google login button.

- **Slug:** `2VXCZP1`
- **Views:** 1440
- **Tags:** Sign-In, Form, Animation, TailwindCSS, Password Toggle, Custom Checkbox, Responsive

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

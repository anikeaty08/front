# Pixel Matrix Generation Interface

UI for generating and customizing pixel matrix patterns with algorithm, pattern, and render settings using animated Tailwind CSS styles.

## Project Details
- **Slug:** `2XGSOZT`
- **Views:** 298
- **Tags:** Pixel Matrix, Algorithm Settings, Pattern Types, Render Options, Tailwind CSS, Animation, UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

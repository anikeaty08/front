# 2 Hamilton Court Listing Template

Modern real estate property listing template for showcasing single-family homes with photos, key stats, school info, and agent contact in a clean layout.

## Project Details
- **Slug:** `2hamiltoncourt`
- **Views:** 17
- **Tags:** Real Estate, Landing Page, Business, Clean, Minimal, Grid, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

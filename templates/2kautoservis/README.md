# Auto Service Landing Page Template

A modern Autoservis Praha 4 website template for car repair shops with multiple locations, perfect as a reusable landing page for local auto services.

## Project Details
- **Slug:** `2kautoservis`
- **Views:** 16
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Technology, Automotive, Local Business, Car Repair
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

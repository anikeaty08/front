# Interactive 3D Globe Visualization

Creates a rotating 3D globe with animated connection points and pulsing halos using Three.js and Tailwind CSS.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

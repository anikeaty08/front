# 3D Artist Portfolio Landing Page Template

A reusable landing page template designed for 3D artists and CGI specialists to showcase portfolios, services, process, and contact options effectively.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

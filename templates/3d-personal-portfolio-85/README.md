# 3D Portfolio Website Template

A reusable 3D portfolio template for personal branding, showcasing bio, skills, goals, and contact details in a modern dark layout.

## Project Details
- **Slug:** `3d-personal-portfolio-85`
- **Views:** 45
- **Tags:** Portfolio, Landing Page, Personal Brand, Technology, 3D, Dark, Gradient, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

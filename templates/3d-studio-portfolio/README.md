# 3D Studio Portfolio Landing Page Template

A dark, cinematic 3D studio portfolio landing page template for showcasing Blender, Unreal Engine 5, and Adobe compositing projects and pipelines.

## Project Details
- **Slug:** `3d-studio-portfolio`
- **Views:** 55
- **Tags:** Landing Page, Portfolio, Art & Design, Technology, 3D, Dark, Minimal, Large Type, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

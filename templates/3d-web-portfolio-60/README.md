# Gregory Dearham Portfolio

A cinematic, gold-lit portfolio template designed for showcasing WordPress projects, 3D modelling, and code repositories with an immersive atmosphere.

## Project Details
- **Slug:** `3d-web-portfolio-60`
- **Views:** 39
- **Tags:** Portfolio, Technology, Art & Design, Dark, 3D, Animated, Clean, Services

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

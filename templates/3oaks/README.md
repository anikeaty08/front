# Furniture & Facility Services Landing Page Template

A modern, brand-forward landing page template for furniture and facility solution providers to showcase services, focus areas, and partners.

## Project Details
- **Slug:** `3oaks`
- **Views:** 16
- **Tags:** Landing Page, Services, Business, Brand, Clean, Minimal, Large Type, Technology, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

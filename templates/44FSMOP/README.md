# User Account Settings Interface

Responsive user account settings UI with profile, preferences, and dark mode toggle using Tailwind CSS and glassmorphism.

## Project Details
- **Slug:** `44FSMOP`
- **Views:** 162
- **Tags:** Settings, Profile, Preferences, Dark Mode, Tailwind CSS, Glassmorphism
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

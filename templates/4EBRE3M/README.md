# Customer Stories Showcase UI

Displays customer testimonials with animated fade-in cards over a 3D background and includes navigation and call-to-action buttons.

## Project Details
- **Slug:** `4EBRE3M`
- **Views:** 600
- **Tags:** Testimonials, Animation, Tailwind CSS, 3D Background, Navigation, Call-to-Action
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

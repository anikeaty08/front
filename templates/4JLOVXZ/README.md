# 3D Device Model Viewer UI

Interactive 3D model viewer with color options, auto-rotate toggle, preset views, and model info panel using Tailwind CSS.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

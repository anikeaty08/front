# Interactive 3D Flippable Credit Card

3D flip card UI with animated shader background on front, showing card details and back with magnetic stripe and CVV info.

## Project Details
- **Slug:** `53WSORI`
- **Views:** 217
- **Tags:** 3D Card Flip, Canvas Shader, WebGL, TailwindCSS, Animation, Credit Card UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mobile Music Player Interface

Responsive music player UI with album art, playback controls, progress bar, and upcoming tracks list using Tailwind CSS.

- **Slug:** `5esSey9`
- **Views:** 113

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

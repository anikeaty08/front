# Interactive Floating Heart Animation

Creates floating, pulsing hearts with click-triggered heartbeat animations using SVG and CSS in a fullscreen container.

- **Slug:** `664v2H`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Classic Desktop Interface Layout

HTML and Tailwind CSS recreate a vintage desktop UI with menu bar, icons, and draggable windows.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

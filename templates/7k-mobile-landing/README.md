# DeFi Mobile Landing Page Template

A sleek DeFi mobile landing page template for promoting a non-custodial Sui-based exchange, capturing waitlist signups, and showcasing core product features.

## Project Details
- **Slug:** `7k-mobile-landing`
- **Views:** 789
- **Tags:** Landing Page, Technology, Brand, Clean, Gradient, Minimal, Large Type, Futuristic, DeFi, SaaS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

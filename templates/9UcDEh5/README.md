# Weather Information Dashboard

Responsive weather UI displaying current conditions, hourly and 7-day forecasts with icons and metrics using Tailwind CSS.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Interactive Floating Sidebar UI

Creates a dark-themed full-screen layout with dynamic backgrounds, animated floating particles, and a left vertical navigation dock with icon buttons.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

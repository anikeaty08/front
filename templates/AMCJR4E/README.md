# AI Workflow Terminal Interface

Interactive terminal UI with matrix-style background, animated hero section, and console screen to deploy and manage AI models.

## Project Details
- **Slug:** `AMCJR4E`
- **Views:** 157
- **Tags:** Terminal, Hero, Animation, Console, Matrix Background, TailwindCSS, UI

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

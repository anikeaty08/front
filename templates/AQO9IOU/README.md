# Mobile More Options Screen UI

Responsive mobile UI with quick actions, settings list, status bar, and bottom navigation using Tailwind CSS and Font Awesome icons.

## Project Details
- **Slug:** `AQO9IOU`
- **Views:** 99
- **Tags:** More Screen, Tailwind CSS, Mobile UI, Quick Actions, Navigation Bar, Font Awesome, Responsive Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mobile Analytics Dashboard UI

Responsive mobile dashboard showing revenue, user stats, performance radar, revenue bar chart, and recent activities with Tailwind and Chart.js.

## Project Details
- **Slug:** `BQRKYH1`
- **Views:** 509
- **Tags:** Dashboard, Analytics, Mobile UI, Chart.js, Tailwind CSS, Data Visualization, Performance Metrics
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

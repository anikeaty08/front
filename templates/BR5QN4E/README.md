# Desktop Weather Forecast UI

Responsive desktop weather app UI with location sidebar, current conditions, and temperature unit toggle using Tailwind CSS.

## Project Details
- **Slug:** `BR5QN4E`
- **Views:** 315
- **Tags:** Weather, Sidebar, Tailwind CSS, Responsive, Temperature Toggle, UI Component

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

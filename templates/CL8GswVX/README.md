# Network Sign Up Form with Animation

Responsive sign-up form featuring animated network background, input fields, terms checkbox, and network status indicator.

## Project Details
- **Slug:** `CL8GswVX`
- **Views:** 360
- **Tags:** Sign Up, Animated Background, Vanta.js, Tailwind CSS, Form, Network Status
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

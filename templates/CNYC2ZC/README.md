# Music Player Interface with Controls

Dark-themed music player UI with playback controls, progress bar, volume slider, and scrollable playlist using Tailwind CSS.

## Project Details
- **Slug:** `CNYC2ZC`
- **Views:** 165
- **Tags:** Music Player, Dark Mode, Playback Controls, Progress Bar, Volume Control, Playlist, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

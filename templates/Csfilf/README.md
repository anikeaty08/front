# Code Editor Styled User Testimonials

Displays user testimonials formatted as code in a styled code editor interface using Tailwind CSS.

## Project Details
- **Slug:** `Csfilf`
- **Views:** 140
- **Tags:** HTML, Tailwind CSS, Code Editor, Testimonials, UI Design, Syntax Highlighting
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

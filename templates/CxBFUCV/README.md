# Mobile Onboarding Interface

Responsive mobile onboarding UI with progress bar, feature highlights, and a horizontal carousel of popular templates.

## Project Details
- **Slug:** `CxBFUCV`
- **Views:** 240
- **Tags:** Onboarding, Mobile UI, Progress Bar, Feature Cards, Carousel, Glassmorphism, Animations

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Gaming Console HUD Interface

Displays a futuristic HUD with animated scan lines, data flows, status indicators, and a side navigation panel using Tailwind CSS.

## Project Details
- **Slug:** `D5W2U5B`
- **Views:** 128
- **Tags:** HUD, Tailwind CSS, Animation, Navigation Panel, Status Indicators, Glitch Effect
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

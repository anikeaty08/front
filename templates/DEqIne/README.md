# Payment Card UI with Details

Responsive payment card interface showing card type, masked number, holder info, expiry, CVV, and a pay button using Tailwind CSS.

## Project Details
- **Slug:** `DEqIne`
- **Views:** 132
- **Tags:** Payment Card, Tailwind CSS, Responsive, UI, Form, Masked Input
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

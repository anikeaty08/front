# User Onboarding Form Interface

Interactive onboarding form with user name input and selectable options enabling a continue button upon valid input.

## Project Details
- **Slug:** `DItYRG`
- **Views:** 538
- **Tags:** Onboarding, Form, User Input, Tailwind CSS, Responsive Design, Interactive UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

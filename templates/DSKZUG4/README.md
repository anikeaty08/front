# Neon Glow Flower Builder UI

Interactive UI to customize and preview glowing flower visuals with adjustable petals, speed, frequency, color gradients, and flower count.

## Project Details
- **Slug:** `DSKZUG4`
- **Views:** 87
- **Tags:** Glow, Shader, Interactive Controls, Canvas, Tailwind CSS, Color Picker, Range Sliders
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

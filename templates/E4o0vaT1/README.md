# Weather Information Card UI

Responsive weather card displaying current conditions, stats, and a 5-day forecast using Tailwind CSS and SVG icons.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

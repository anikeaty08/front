# Network Status Card with Meteor Animation

Displays a translucent status card with uptime and node metrics over an animated meteor shower background.

## Project Details
- **Slug:** `EGC3oN`
- **Views:** 89
- **Tags:** Status Card, Animation, Tailwind CSS, Meteor Shower, Progress Bar, UI Component
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Interactive AI Engineer Profile UI

Displays a personal profile with animated glass cards, gradient text, and a physics-based falling letters background using Matter.js.

## Project Details
- **Slug:** `EGEGW2H`
- **Views:** 458
- **Tags:** Profile, Hero Section, Animation, Glassmorphism, Matter.js, Tailwind CSS, SVG, Gradient Text
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# iOS Music App Landing Page Template

This is a reusable iOS music app landing page template designed to showcase music search, now playing, and library features in a sleek mobile UI mockup.

## Project Details
- **Slug:** `EKP6WDI`
- **Views:** 890
- **Tags:** Landing Page, Music App, iOS, Mobile UI, Search, Now Playing, Library, Playlists, Controls
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

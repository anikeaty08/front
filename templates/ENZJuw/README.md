# Multi-Tab World Clock Interface

Responsive UI showing local time, multiple world clocks, and navigation for alarm, timer, and stopwatch features.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

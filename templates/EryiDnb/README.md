# Multi-step Onboarding Interface

Dark-themed multi-step onboarding UI with progress indicators, user profile form, and navigation buttons using Tailwind CSS.

## Project Details
- **Slug:** `EryiDnb`
- **Views:** 247
- **Tags:** Onboarding, Multi-step Form, Tailwind CSS, Dark Mode, Progress Bar, User Profile
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

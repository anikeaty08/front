# Interactive Pricing with Animated Shader

Displays a pricing toggle with dynamic yearly/monthly prices and an interactive iridescent shader background reacting to mouse movements.

## Project Details
- **Slug:** `FSKT3J2`
- **Views:** 136
- **Tags:** Pricing Toggle, Iridescent Shader, WebGL, GLSL, Animation, Tailwind CSS, Interactive UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

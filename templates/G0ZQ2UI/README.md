# Interactive Camera Viewfinder UI

Renders a dynamic camera viewfinder with shader effects, grid overlay, focus animation, and interactive shutter button using WebGL and Tailwind CSS.

## Project Details
- **Slug:** `G0ZQ2UI`
- **Views:** 571
- **Tags:** Camera, WebGL Shader, Viewfinder, Focus Animation, Tailwind CSS, UI Overlay, Interactive Button
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

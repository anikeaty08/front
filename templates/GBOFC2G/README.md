# Customer Testimonials Grid UI

Displays a responsive grid of customer testimonials with glowing, animated cards using Tailwind CSS and custom radial gradient effects.

## Project Details
- **Slug:** `GBOFC2G`
- **Views:** 138
- **Tags:** Testimonials, Glow Effect, Animation, Tailwind CSS, Responsive Grid, Radial Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

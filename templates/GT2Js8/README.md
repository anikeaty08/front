# Code Editor with Terminal UI

A JavaScript code editor UI featuring syntax highlighting, line numbers, status bar, and an integrated terminal simulation.

## Project Details
- **Slug:** `GT2Js8`
- **Views:** 49
- **Tags:** Code Editor, Syntax Highlighting, Terminal, JavaScript, Tailwind CSS, UI Component

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

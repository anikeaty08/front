# User Profile and Settings UI

Responsive user profile interface with account details, saved locations, and weather preference toggles using Tailwind CSS.

## Project Details
- **Slug:** `GT8PeA`
- **Views:** 90
- **Tags:** Profile, Settings, Tailwind CSS, Responsive, User Interface, Toggle Switches
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Interactive Product Selection Card

Responsive product card with color and size selectors, image zoom on hover, and add-to-cart button using Tailwind CSS.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

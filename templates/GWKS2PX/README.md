# Multi-Layer Waveform Canvas Visualizer

Animated multi-layer sine wave visualizer on canvas with dynamic colors and smooth transitions using JavaScript and Tailwind CSS.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

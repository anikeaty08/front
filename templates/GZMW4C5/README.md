# Hiking Trail Map and Stats UI

Displays a hiking trail map with start/end markers, stats, and action buttons for starting or sharing the trail.

- **Slug:** `GZMW4C5`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

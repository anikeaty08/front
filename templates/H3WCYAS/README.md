# macOS Style Schema Manager UI

Responsive macOS-themed dashboard UI with sidebar navigation and animated aurora background canvas using Tailwind CSS and Three.js.

## Project Details
- **Slug:** `H3WCYAS`
- **Views:** 330
- **Tags:** Dashboard, Sidebar Navigation, macOS UI, Tailwind CSS, Three.js, Animation, Canvas Background
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Beauty Product iOS Style Landing Page Template

This reusable landing page template features a sleek iOS style design for showcasing and selling beauty products, including search, categories, product details, and cart.

- **Slug:** `HFBULPY`
- **Views:** 901
- **Tags:** Landing Page, Beauty Products, iOS Style, Search, Categories, Product Detail, Shopping Cart, Responsive, TailwindCSS, E-commerce

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

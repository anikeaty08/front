# Usage Progress Counter Panel

Displays a usage progress bar with current stats, reset timer, and an upgrade button in a glowing card UI.

- **Slug:** `HFNrHnF`
- **Views:** 380

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

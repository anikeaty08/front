# Personal Finance Overview UI

Mobile finance dashboard showing balance, cards, recent transactions with interactive buttons using Tailwind CSS.

## Project Details
- **Slug:** `HKtbmC`
- **Views:** 270
- **Tags:** Finance Dashboard, Transactions, Cards, Tailwind CSS, Mobile UI, Interactive Elements
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

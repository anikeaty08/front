# Interactive Pricing Card Layout

Displays animated 3D pricing cards with hover effects, feature lists, and call-to-action buttons using Tailwind CSS.

## Project Details
- **Slug:** `HYTRTIO`
- **Views:** 200
- **Tags:** Pricing Cards, 3D Animation, Tailwind CSS, Hover Effects, Responsive Design, UI Components
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

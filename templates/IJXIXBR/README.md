# Aura Energy Portal Interface

Responsive UI with animated header, navigation, and interactive energy-themed cards using Tailwind CSS and custom fade-slide effects.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Pricing Plan Cards with Aurora BG

Interactive pricing cards with monthly/annual toggle over a dynamic WebGL aurora background in dark mode.

- **Slug:** `INW2MDR`
- **Views:** 431

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

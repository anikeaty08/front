# Interactive AI Terminal Interface

Creates a futuristic AI-themed terminal UI with matrix animation, typewriter text, neon buttons, and responsive navigation using Tailwind CSS.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

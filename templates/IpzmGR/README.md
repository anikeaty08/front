# Interactive Plant Growing Interface

UI for a plant-growing game with animated plant cards, day cycle, money tracking, and harvest management using Tailwind CSS.

## Project Details
- **Slug:** `IpzmGR`
- **Views:** 46
- **Tags:** HTML, CSS, Tailwind CSS, Animation, Interactive UI, Game Interface

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Gaming Profile and Stats Dashboard

Displays a gaming profile card with avatar, tabs, champion stats, and a bottom navigation using Tailwind CSS and animations.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

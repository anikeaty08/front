# StatsApp Mobile Analytics Dashboard Template

A reusable mobile analytics dashboard template designed to visualize cashflow, expenses, user metrics, and content revenue for app and content creators.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

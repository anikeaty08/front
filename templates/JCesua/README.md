# Flight Booking Interface

Responsive flight search UI with trip type, location, date, class, and traveler selection using modern styling.

## Project Details
- **Slug:** `JCesua`
- **Views:** 110
- **Tags:** HTML, CSS, Tailwind CSS, Responsive Design, UI, Flight Search
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

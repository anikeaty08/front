# Thermostat Control Interface

Mobile UI simulating thermostat controls with toggle switches, circular dial, and temperature history chart inside a phone frame.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# macOS Style App Window UI

Creates a macOS-like app window with title bar, traffic light buttons, loading screen, and search overlay using Tailwind CSS.

## Project Details
- **Slug:** `JYWOJSK`
- **Views:** 368
- **Tags:** macOS Window, Tailwind CSS, Loading Screen, Search Overlay, UI Components, Animation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

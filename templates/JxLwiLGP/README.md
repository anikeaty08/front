# Precipitation Forecast Dashboard

Displays current, hourly, and 7-day precipitation chances with progress bars and interactive UI using Tailwind CSS.

## Project Details
- **Slug:** `JxLwiLGP`
- **Views:** 103
- **Tags:** Precipitation, Weather, Forecast, Tailwind CSS, Progress Bars, Responsive UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

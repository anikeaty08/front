# Payment Processing Dashboard UI

Responsive payment dashboard with sidebar navigation, secure card payment form, and order summary using Tailwind CSS and Font Awesome icons.

- **Slug:** `K55E0OW`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

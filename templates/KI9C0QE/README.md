# Interactive Digital Portal UI

Creates an animated digital portal with glowing grid overlay, floating particles, and sequentially appearing text using Tailwind CSS and SVG.

- **Slug:** `KI9C0QE`
- **Views:** 2107
- **Tags:** Digital Portal, Animation, Tailwind CSS, SVG Grid, Floating Particles, Text Animation

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

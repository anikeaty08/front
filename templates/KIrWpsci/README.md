# Digital Banking Dashboard UI

Responsive digital banking interface showing balance, quick actions, cards, and recent transactions with dark theme styling.

## Project Details
- **Slug:** `KIrWpsci`
- **Views:** 303
- **Tags:** Dashboard, Banking, Tailwind CSS, Cards, Transactions, Dark Mode, Responsive

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Nebula Portfolio Landing Page Template

A reusable landing page template designed for UI/UX designers to showcase portfolios, services, and design packages with modern, dark-themed aesthetics.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

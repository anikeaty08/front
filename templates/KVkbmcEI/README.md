# Interactive 3D Dot Shape Viewer

Displays a customizable 3D shape of dots with controls for shape, color, size, rotation, and animation effects.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

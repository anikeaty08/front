# Mobile Music Player Interface

HTML and Tailwind CSS code creating a mobile music player UI with playback controls, currently playing info, and animated equalizer bars.

## Project Details
- **Slug:** `KpySm8`
- **Views:** 144
- **Tags:** Music Player, Mobile UI, Tailwind CSS, Equalizer Animation, Responsive Design, Glassmorphism
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

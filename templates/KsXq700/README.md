# User Sign In Interface

Responsive sign-in form with social login buttons, password toggle, input focus effects, and staggered animations using Tailwind CSS.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

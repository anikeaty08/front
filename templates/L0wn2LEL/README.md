# Mobile Statistics Dashboard UI

Responsive mobile dashboard displaying stats with bar and pie charts, period selectors, and summary cards using Tailwind CSS.

## Project Details
- **Slug:** `L0wn2LEL`
- **Views:** 213
- **Tags:** Statistics, Dashboard, Tailwind CSS, Bar Chart, Pie Chart, Mobile UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Interactive Flappy Bug Game UI

Responsive game interface with animated backgrounds, score display, sound toggle, and start/game over overlays using Tailwind CSS.

## Project Details
- **Slug:** `LH0OVFX`
- **Views:** 304
- **Tags:** Game UI, Animated Background, Tailwind CSS, Canvas, Interactive Controls, Responsive Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

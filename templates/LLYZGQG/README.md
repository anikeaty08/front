# Financial Dashboard Interface

Responsive UI displaying wallet and card info with animated header, hero section, and 3D background using Tailwind and Chart.js.

## Project Details
- **Slug:** `LLYZGQG`
- **Views:** 383
- **Tags:** Dashboard, Financial, Wallets, Cards, Animation, Tailwind CSS, 3D Background
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

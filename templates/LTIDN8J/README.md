# Team Member Profile Cards UI

Displays horizontally scrolling, animated team member cards with photos, roles, and detailed bios on a dark themed background.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Realtime Analytics Dashboard UI

HTML layout for a responsive realtime analytics dashboard with data cards, charts, and a header using Tailwind CSS and Chart.js.

## Project Details
- **Slug:** `MLWJGVU`
- **Views:** 808
- **Tags:** Dashboard, Analytics, Tailwind CSS, Chart.js, Responsive, UI, Data Visualization

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Sunrise and Sunset Time Viewer

Displays sunrise, sunset, golden hour, and solar noon times with sun position and weekly daylight info using Tailwind CSS.

## Project Details
- **Slug:** `Mr2KEN3`
- **Views:** 26
- **Tags:** Sunrise, Sunset, Sun Position, Tailwind CSS, Responsive UI, Time Visualization, Weather
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

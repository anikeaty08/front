# Order Tracking and Timeline UI

Displays order details, items, payment summary, tab navigation, and a timeline of order events with user info.

- **Slug:** `N2ICT7O`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Weather Forecast Interface

Displays current weather, stats, and a 5-day forecast with temperature and conditions using Tailwind CSS.

## Project Details
- **Slug:** `NGLXOFF`
- **Views:** 148
- **Tags:** Weather, Forecast, Tailwind CSS, Responsive, UI, SVG Icons
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

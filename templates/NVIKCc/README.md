# Interactive 3D Globe Visualization

Renders a customizable 3D globe made of lines with adjustable parameters and animated breathing and rotation effects.

## Project Details
- **Slug:** `NVIKCc`
- **Views:** 310
- **Tags:** 3D Globe, Interactive UI, Animation, JavaScript, TailwindCSS, Sliders, Visualization
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

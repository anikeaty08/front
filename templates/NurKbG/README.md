# Hiking Weather and Trail Dashboard

Responsive UI displaying current weather, recommended hiking trails, quick stats, and a start hiking button with fade animations.

## Project Details
- **Slug:** `NurKbG`
- **Views:** 214
- **Tags:** HTML, Tailwind CSS, Weather UI, Hiking Trails, Responsive Design, Animation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

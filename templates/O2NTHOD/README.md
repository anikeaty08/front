# Smartphone Lock Screen UI Layout

HTML and Tailwind CSS code creating a glass-effect smartphone lock screen with time, date, status bar, and translucent notifications.

## Project Details
- **Slug:** `O2NTHOD`
- **Views:** 278
- **Tags:** Glassmorphism, Lock Screen, Notifications, Tailwind CSS, Responsive UI, Time Display
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

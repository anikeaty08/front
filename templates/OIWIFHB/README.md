# Animated Shape Loading Screen

Displays an animated loading screen with bouncing, rotating shapes and a progress bar using Tailwind CSS and custom CSS animations.

- **Slug:** `OIWIFHB`
- **Views:** 231

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# 3D Black Hole Visualization UI

Interactive 3D black hole model with adjustable accretion disk, spin, temperature, and camera controls using WebGL and shaders.

## Project Details
- **Slug:** `OUCJLQA`
- **Views:** 262
- **Tags:** 3D Visualization, WebGL, Three.js, Shader, Interactive Controls, Astronomy, Simulation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

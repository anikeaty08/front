# Revenue Dashboard with Metrics

Interactive revenue dashboard displaying key metrics, charts, time range filters, and recent transactions with Tailwind CSS styling.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

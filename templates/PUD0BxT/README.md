# Interactive Monthly Calendar Picker

Renders a monthly calendar UI with navigation and date selection, highlighting today and showing the selected date.

## Project Details
- **Slug:** `PUD0BxT`
- **Views:** 106
- **Tags:** Calendar, Date Picker, JavaScript, Tailwind CSS, Interactive UI, Responsive
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

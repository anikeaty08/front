# Shader-Based Digital Clock UI

Renders a dynamic 12-hour digital clock using WebGL shaders and Three.js on a full-screen canvas.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

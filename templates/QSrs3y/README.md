# Weather App Settings Interface

Responsive weather app settings UI with customizable theme, language, notifications, privacy, and unit preferences using Tailwind CSS.

## Project Details
- **Slug:** `QSrs3y`
- **Views:** 72
- **Tags:** Settings, Units, Tailwind CSS, Responsive UI, Icons, Customization

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

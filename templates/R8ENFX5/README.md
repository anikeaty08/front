# Mobile Weather Preview Interface

Displays an animated mobile weather preview with live data, particles effect, and interactive UI using Tailwind CSS and Font Awesome icons.

## Project Details
- **Slug:** `R8ENFX5`
- **Views:** 365
- **Tags:** Weather Preview, Mobile UI, Tailwind CSS, Particles Animation, Responsive Design, Animated Icons, CSS Animations
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

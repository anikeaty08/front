# Course Progress Chart Interface

Displays animated course progress with bar and line charts, performance stats, and a gradient action button using Tailwind CSS.

## Project Details
- **Slug:** `RPEw01`
- **Views:** 181
- **Tags:** Animation, Tailwind CSS, SVG, CSS Keyframes, Data Visualization, UI Design

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

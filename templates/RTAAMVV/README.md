# Flight and Hotel Booking UI

Responsive travel booking interface with navigation, animated header, and 3D background using Tailwind CSS and embedded Spline design.

## Project Details
- **Slug:** `RTAAMVV`
- **Views:** 441
- **Tags:** Travel Booking, Navigation, Animation, 3D Background, Tailwind CSS, Responsive Design

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

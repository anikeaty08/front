# Step Count and Activity Stats UI

Displays step count, calories, distance, and active minutes with a clean, responsive fitness stats card using Tailwind CSS.

## Project Details
- **Slug:** `RkmtfyNg`
- **Views:** 37
- **Tags:** HTML, Tailwind CSS, Responsive Design, Fitness UI, Dashboard, SVG Icon
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

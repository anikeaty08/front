# Package Tracking Dashboard UI

Responsive package tracking dashboard with sidebar navigation, animated transitions, and mobile header using Tailwind CSS and SVG icons.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

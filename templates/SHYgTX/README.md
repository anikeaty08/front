# Scrolling Customer Testimonials Section

Displays continuously scrolling customer testimonials with profile images and quotes using Tailwind CSS and marquee animation.

## Project Details
- **Slug:** `SHYgTX`
- **Views:** 176
- **Tags:** Testimonials, Marquee, Tailwind CSS, Animation, UI Section, Scrolling
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Pixel Art Grid Drawing Tool

Interactive 32x32 pixel grid for drawing with draw, erase, bucket fill, undo, redo, and color picker controls.

## Project Details
- **Slug:** `SRGNGBN`
- **Views:** 73
- **Tags:** Pixel Drawing, Grid, Canvas, Undo Redo, Flood Fill, Color Picker, JavaScript
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

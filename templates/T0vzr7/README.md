# Mobile Settings Screen UI

Responsive mobile settings interface with profile, toggles, navigation bar, and dynamic time display using Tailwind CSS and Font Awesome.

## Project Details
- **Slug:** `T0vzr7`
- **Views:** 117
- **Tags:** Settings, Mobile UI, Tailwind CSS, Toggle Switches, Navigation Bar, Profile, Responsive Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

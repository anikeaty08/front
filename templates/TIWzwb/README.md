# Interactive Bouncing Character UI

UI with a bouncing character whose eyes follow the cursor, tracks happiness, and responds to bounce, feed, and pet actions.

## Project Details
- **Slug:** `TIWzwb`
- **Views:** 34
- **Tags:** Interactive Character, Eye Tracking, Animation, UI Components, Happiness Meter, Tailwind CSS, JavaScript
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

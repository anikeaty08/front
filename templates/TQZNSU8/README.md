# Clock Interface with Analog and Digital

Displays a real-time analog clock with rotating hands alongside a digital time readout using Tailwind CSS styling.

## Project Details
- **Slug:** `TQZNSU8`
- **Views:** 47
- **Tags:** Analog Clock, Digital Clock, Tailwind CSS, JavaScript, Time Display, UI Component
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

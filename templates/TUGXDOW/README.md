# Travel Itinerary Timeline UI

Responsive travel itinerary UI with day tabs, timeline events, icons, and smooth scrolling using Tailwind CSS and SVG icons.

## Project Details
- **Slug:** `TUGXDOW`
- **Views:** 915
- **Tags:** Timeline, Itinerary, Tailwind CSS, Responsive, SVG Icons, Travel UI, Tabs
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Snow Weather Forecast Card

Interactive weather card displaying current snow conditions, stats, and a 5-day forecast with animated icons and particle background.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

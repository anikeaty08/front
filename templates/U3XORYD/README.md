# Interactive 3D Background Website UI

Webpage with fixed 3D spline background, gradient blur blobs, glassmorphism header, and smooth scrolling using Tailwind CSS.

## Project Details
- **Slug:** `U3XORYD`
- **Views:** 523
- **Tags:** 3D Background, Glassmorphism, Tailwind CSS, Gradient Blobs, Smooth Scroll, Responsive Nav
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

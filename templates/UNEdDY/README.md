# User Account Profile Interface

Responsive dark-themed user account page with profile card, personal info, and editable account options using Tailwind CSS.

## Project Details
- **Slug:** `UNEdDY`
- **Views:** 103
- **Tags:** Account, Profile, Tailwind CSS, Dark Mode, Responsive, UI, Editable
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

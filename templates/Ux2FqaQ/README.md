# Credit Card Overview Interface

Displays credit card carousel, credit limit bar, spending analytics chart, and recent transactions with Tailwind CSS styling.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

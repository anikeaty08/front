# Scholarship Testimonials Interface

Displays animated scholar testimonials with a vintage theme, sidebar navigation, and ambient ink spot animations using Tailwind CSS.

## Project Details
- **Slug:** `VGNAS4Z`
- **Views:** 113
- **Tags:** Testimonials, Sidebar Navigation, Tailwind CSS, Animations, Typography, Responsive Grid
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Service Pricing Plans UI

Responsive pricing page with billing toggle, multiple plan cards, and animated shader background using Tailwind and Three.js.

## Project Details
- **Slug:** `VKAXSEC`
- **Views:** 365
- **Tags:** Pricing, Billing Toggle, Pricing Cards, Shader Background, Tailwind CSS, Three.js, Responsive Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Interactive 3D Bass Guitar Model

3D bass guitar with realistic textures and lighting; click strings to play notes using WebGL and audio synthesis.

## Project Details
- **Slug:** `VWhIWld`
- **Views:** 53
- **Tags:** 3D Model, WebGL, Three.js, Interactive UI, Audio Synthesis, Instrument Simulation, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

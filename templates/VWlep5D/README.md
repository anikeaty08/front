# 3D Interactive Piano Explorer

Renders a 3D piano with interactive keys playable via mouse; includes WASD movement and mouse look controls in a WebGL scene.

## Project Details
- **Slug:** `VWlep5D`
- **Views:** 104
- **Tags:** 3D Piano, WebGL, Three.js, Interactive, Audio, Movement Controls, Mouse Look
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

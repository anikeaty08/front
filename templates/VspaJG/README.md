# Mobile Weather Interface Layout

Responsive mobile weather UI with current conditions, hourly forecast, animated elements, and dynamic island style header.

## Project Details
- **Slug:** `VspaJG`
- **Views:** 90
- **Tags:** HTML, Tailwind CSS, Animation, Responsive Design, Weather UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

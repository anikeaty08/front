# Saved Recipes Interface

Mobile UI displaying saved recipes with filter tabs, collections, and recipe cards using Tailwind and FontAwesome icons.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Space Exploration Website Interface

Responsive space-themed website UI with fixed background, navigation menu, and blur effects using Tailwind CSS and Google Fonts.

## Project Details
- **Slug:** `WQQVCD4`
- **Views:** 2445
- **Tags:** Navigation, Background, Responsive, Tailwind CSS, Blur Effect, Google Fonts

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Credit Card Stack Interface

Displays overlapping credit card stacks with gradients, status bar, pagination dots, and a hexagonal navigation button using Tailwind CSS.

## Project Details
- **Slug:** `Wvf6LV`
- **Views:** 86
- **Tags:** Card Stack, Tailwind CSS, Gradient, Navigation Button, UI Design, Overlapping Cards
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# 3D Block World Builder UI

Interactive 3D block placement UI with real-time FPS, block selector, controls, and crosshair overlay using Three.js and Tailwind CSS.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

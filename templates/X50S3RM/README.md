# Interactive Features Grid UI

Displays animated glow effect feature cards with icons and descriptions in a responsive grid layout using Tailwind CSS.

## Project Details
- **Slug:** `X50S3RM`
- **Views:** 350
- **Tags:** Features, Glow Effect, Animation, Tailwind CSS, Responsive Grid, UI Cards
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

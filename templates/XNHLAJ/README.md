# Mobile App Financial Dashboard UI

Responsive mobile UI displaying balance, card details, and recent financial transactions with a phone frame design.

## Project Details
- **Slug:** `XNHLAJ`
- **Views:** 160
- **Tags:** Mobile UI, Financial Dashboard, Tailwind CSS, Responsive Design, Transactions, Card Details
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# 3D Interactive Device Carousel

Creates a 3D rotating carousel of device images with next/previous controls using Tailwind and GSAP animations.

- **Views:** 327

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

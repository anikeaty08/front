# Interactive Weather Map UI

Displays a weather map with temperature, precipitation, and wind layers plus interactive controls and weather icons.

## Project Details
- **Slug:** `YBpy2Cs`
- **Views:** 42
- **Tags:** Weather Map, Interactive Map, Tailwind CSS, Weather Icons, Map Controls, Responsive UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Vehicle Dashboard Interface

HTML and Tailwind CSS code for a smooth, animated vehicle dashboard UI with disabled animations and 3D rendering during loading.

- **Slug:** `YFO9NUA`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

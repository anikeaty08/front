# Weather Forecast Desktop Interface

Responsive desktop weather app UI with location sidebar, current conditions, and temperature unit toggle using Tailwind CSS.

## Project Details
- **Slug:** `YHHA9GV`
- **Views:** 211
- **Tags:** Weather, Sidebar, Tailwind CSS, Responsive UI, Temperature Toggle, Desktop App

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Layer Management Panel UI

UI for managing, searching, and toggling visibility of nested layers in a design editor using icons and Tailwind CSS.

## Project Details
- **Slug:** `YVI4SUG`
- **Views:** 286
- **Tags:** Layers, Nested List, Search, Tailwind CSS, SVG Icons, Dark Mode
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

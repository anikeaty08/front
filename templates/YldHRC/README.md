# Face Feature Customization UI

Interactive face creator allowing selection and randomization of eyes, noses, and mouths with SVG graphics.

## Project Details
- **Slug:** `YldHRC`
- **Views:** 22
- **Tags:** SVG, Tailwind CSS, Face Generator, UI, JavaScript, Interactive Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

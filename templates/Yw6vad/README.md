# Mobile Chat Interface Layout

Responsive mobile chat UI with search, quick actions, recent chats, and a custom status bar using Tailwind CSS.

## Project Details
- **Slug:** `Yw6vad`
- **Views:** 350
- **Tags:** Mobile UI, Chat Interface, Tailwind CSS, Search Bar, Quick Actions, Recent Chats
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

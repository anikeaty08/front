# Linear Course Progress Tracker

Displays a linear progress bar with steps, lesson details, statistics, and a continue button using Tailwind CSS and custom styles.

## Project Details
- **Slug:** `Z4woCOh`
- **Views:** 128
- **Tags:** HTML, Tailwind CSS, CSS Animation, Progress Bar, UI Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

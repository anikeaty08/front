# Trading Analytics Dashboard UI

Responsive trading dashboard UI with navigation, animated 3D background, and data visualization using Chart.js and Tailwind CSS.

## Project Details
- **Slug:** `ZFLLUYH`
- **Views:** 560
- **Tags:** Dashboard, Trading, Data Visualization, Tailwind CSS, Chart.js, 3D Background, Responsive Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

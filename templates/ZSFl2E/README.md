# User Profile Interface

Responsive user profile UI with light/dark theme toggle, account management, and editable profile details using Tailwind CSS.

## Project Details
- **Slug:** `ZSFl2E`
- **Views:** 50
- **Tags:** User Profile, Dark Mode, Tailwind CSS, Responsive Design, Theme Toggle, Account Management
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

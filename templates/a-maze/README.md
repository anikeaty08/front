# A-MAZE

A modern template for experiential and live events agencies to showcase services, case studies, team, and contact, ready to customize for your brand.

## Project Details
- **Slug:** `a-maze`
- **Views:** 14
- **Tags:** Landing Page, Services, Brand, Art & Design, Portfolio, Clean, Gradient, Large Type, Minimal, Futuristic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

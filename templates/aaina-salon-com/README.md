# Salon Landing Page Template

A reusable salon landing page template for beauty, grooming, spa, and appointment-booking businesses seeking a polished online presence.

## Project Details
- **Slug:** `aaina-salon-com`
- **Views:** 74
- **Tags:** Landing Page, Services, Health, Fashion, Wedding, Clean, Minimal, Dark, booking, salon
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

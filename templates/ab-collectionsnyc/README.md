# Collections CRM Dashboard Template

A reusable Collections CRM dashboard template designed for managing clients, collections, and feedback effectively in real estate or brokerage workflows.

## Project Details
- **Slug:** `ab-collectionsnyc`
- **Views:** 30
- **Tags:** Landing Page, Dashboard, CRM, Clients, Collections, Feedback, Modal Form, Search, Navigation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

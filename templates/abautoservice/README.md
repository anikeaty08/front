# Auto Repair Landing Page Template

A reusable auto repair landing page template for mechanics and service shops to showcase services, reviews, location details, and booking CTAs.

## Project Details
- **Slug:** `abautoservice`
- **Views:** 75
- **Tags:** Landing Page, Services, Business, Clean, Dark, Technology, automotive, auto repair, mechanic, local business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mobile Store Landing Page Template

A reusable landing page template for premium mobile phone stores to showcase inventory, drive WhatsApp sales, and promote trade-ins and showroom visits.

## Project Details
- **Slug:** `abdul-store-012`
- **Views:** 31
- **Tags:** E-commerce, Landing Page, Technology, Dark, Gradient, Clean, Animated, mobile store, electronics retail
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

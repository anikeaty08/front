# Consulting & Brand Architecture Landing Page Template

A dark, minimalist consulting landing page template for solution architecture, brand strategy, and diagnostics-based services websites.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

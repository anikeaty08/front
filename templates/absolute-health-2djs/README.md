# Health Consultation Landing Page Template

A reusable landing page template for functional medicine clinics to promote root-cause care, build trust with testimonials, and drive consultation bookings.

## Project Details
- **Slug:** `absolute-health-2djs`
- **Views:** 39
- **Tags:** Health, Landing Page, Services, Clean, Minimal, testimonials, medical, functional medicine, consultation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Academic Health Portal Dashboard Template

A reusable academic health portal template for schools, offering student, teacher, and principal dashboards to track performance, attendance, and risk alerts.

## Project Details
- **Slug:** `academic-health-10`
- **Views:** 13
- **Tags:** Landing Page, Education, Health, Technology, Brand, Clean, Minimal, Grid, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

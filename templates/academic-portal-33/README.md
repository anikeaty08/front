# BCA Student Portal Landing Page Template

A modern BCA student portal template for academic notes sharing, subject management, uploads, and contact workflows, ready to adapt for your institution.

## Project Details
- **Slug:** `academic-portal-33`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

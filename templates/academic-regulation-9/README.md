# Academic Policy Documentation Template

A reusable academic regulations template for universities to present grading rules, attendance policies, FAQs, and an interactive score calculator.

## Project Details
- **Slug:** `academic-regulation-9`
- **Views:** 69
- **Tags:** Documentation, Education, Landing Page, Clean, Minimal, Services, academic regulations, student portal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

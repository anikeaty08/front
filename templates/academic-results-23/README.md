# Academic Performance Result Generator Template

A clean, dark-mode calculator template designed for students and educators to compute grade percentages and academic passing status instantly.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

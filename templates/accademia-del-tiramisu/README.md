# Accademia del Tiramisù di Treviso

A refined landing page template for a tiramisù academy or food brand, showcasing original recipes, certified venues, courses, shop, and membership in one elegant layout.

## Project Details
- **Slug:** `accademia-del-tiramisu`
- **Views:** 14
- **Tags:** Food, Landing Page, Brand, Clean, Minimal, Large Type, E-commerce, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

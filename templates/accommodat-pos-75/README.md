# Accommodation POS Interface Template

A reusable Accommodation POS interface template for hotels and guesthouses, featuring room charges, minibar items, and streamlined cash/card/check payments.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

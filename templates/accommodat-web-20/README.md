# Accommodation Booking Landing Page Template

A clean, conversion-focused landing page template for accommodation providers to promote direct bookings and reduce third‑party commission costs.

## Project Details
- **Slug:** `accommodat-web-20`
- **Views:** 14
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Technology, Travel, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

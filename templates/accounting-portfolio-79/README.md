# Accounting Portfolio Template

A reusable portfolio template for accounting, tax, and finance professionals to showcase experience, education, skills, and achievements with a polished resume-style layout.

## Project Details
- **Slug:** `accounting-portfolio-79`
- **Views:** 42
- **Tags:** Portfolio, Resume, Services, Clean, Minimal, Personal branding, Accounting, Finance, Tax, Professional
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Accounting Services Landing Page Template

A reusable landing page template for accounting and bookkeeping firms to showcase services, process, testimonials, and capture consultations and newsletter leads.

## Project Details
- **Slug:** `accounting-services-60`
- **Views:** 14
- **Tags:** Landing Page, Services, Business, Accounting, Clean, Minimal, Brand, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

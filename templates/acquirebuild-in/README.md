# Website Marketplace Landing

A dark, premium marketplace UI template for buying and selling websites and SaaS projects, including listing details, dashboard, admin, checkout, and docs views.

## Project Details
- **Slug:** `acquirebuild-in`
- **Views:** 55
- **Tags:** Landing Page, Business, Technology, Brand, Dark, Clean, Minimal, Large Type, Marketplace, SaaS

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

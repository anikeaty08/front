# Health Coaching Dashboard UI Template

A clean mobile health coaching dashboard UI template for tracking sessions, daily goals, and check-ins, ready to reuse in wellness and fitness apps.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Service Business Landing Page Template

A dark, modern AI automation landing page template for service businesses, showcasing features, pricing, and testimonials to convert visitors into booked audits.

## Project Details
- **Slug:** `adapt-from-ai-16`
- **Views:** 54
- **Tags:** Landing Page, Services, Technology, Dark, Clean, Gradient, Brand, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

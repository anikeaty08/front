# WhatsApp Bot Builder Landing Page Template

A clean, conversion-focused landing page template for showcasing a no-code WhatsApp bot automation platform, complete with features, integrations, and CTAs.

## Project Details
- **Slug:** `adapt-from-ai-26`
- **Views:** 14
- **Tags:** Landing Page, Technology, Business, Brand, Clean, Gradient, Large Type, Minimal

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

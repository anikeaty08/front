# Recruitment Landing Page Template

A reusable recruitment landing page template for hiring firms and talent networks to showcase roles, explain the process, and attract skilled candidates.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

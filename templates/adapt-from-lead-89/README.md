# B2B Hair Wholesale

A premium B2B hair wholesale landing page template for salons and distributors to showcase collections, pricing tiers, and applications with a modern, clean design.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

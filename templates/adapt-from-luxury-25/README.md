# Nido de Almas

A dark, minimalist luxury retreat landing page template for boutique eco-resorts to showcase sanctuaries, experiences, and drive premium bookings.

## Project Details
- **Slug:** `adapt-from-luxury-25`
- **Views:** 30
- **Tags:** Landing Page, Travel, Brand, Minimal, Dark, Large Type, Gradient, Luxury retreat, Boutique hotel
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

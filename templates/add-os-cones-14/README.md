# Minimal Contact Card Template

A clean, reusable contact card template for personal branding that showcases name, role, phone, email, website, and social links in a compact layout.

## Project Details
- **Slug:** `add-os-cones-14`
- **Views:** 20
- **Tags:** Landing Page, Brand, Clean, Minimal, Portfolio, Resume, Technology, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

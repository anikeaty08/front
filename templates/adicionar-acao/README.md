# Environmental Action Submission Form Template

Reusable template for municipalities and organizations to submit, document, and budget environmental glass recycling actions in a clear, guided form layout.

## Project Details
- **Slug:** `adicionar-acao`
- **Views:** 33
- **Tags:** Landing Page, Environmental, Services, Clean, Minimal, Grid, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

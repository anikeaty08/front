# Stationery E-commerce App UI Template

A modern mobile e-commerce UI template for stationery shops and wholesale suppliers, ready to reuse for building your own stationery shopping app experience.

## Project Details
- **Slug:** `adinath-stationery-23`
- **Views:** 12
- **Tags:** E-commerce, Services, Brand, Clean, Minimal, Gradient, Large Type, Technology, Landing Page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

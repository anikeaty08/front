# Stationery E-commerce Landing Page Template

A clean, ready-to-use stationery shop template for photocopy and office supply stores, featuring product filters, cart drawer, and simple order checkout flow.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

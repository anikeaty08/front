# Polymer Manufacturing Landing Page Template

A modern landing page template for polymer and plastic packaging manufacturers to showcase capabilities, product categories, and capture B2B quote requests.

## Project Details
- **Slug:** `aditya-polymer`
- **Views:** 35
- **Tags:** Landing Page, Business, Services, Technology, Brand, Clean, Minimal, Large Type, Industrial, Manufacturing
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

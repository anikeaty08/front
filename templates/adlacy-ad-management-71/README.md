# Adlacy Smart Ad Management Landing Page Template

A reusable landing page template for Adlacy-style smart ad management platforms, showcasing instant top-up, ad credit control, and multi-account ad spend management.

## Project Details
- **Slug:** `adlacy-ad-management-71`
- **Views:** 8
- **Tags:** Landing Page, Technology, Services, Brand, Dark, Gradient, Clean, Minimal, Large Type, Advertising
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

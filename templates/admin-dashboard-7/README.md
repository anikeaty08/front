# Admin Dashboard Template

A reusable admin dashboard template for managing store billing cycles, contracts, reservations, and operations in multi-store hospitality or retail systems.

## Project Details
- **Slug:** `admin-dashboard-7`
- **Views:** 45
- **Tags:** Technology, Services, Dashboard, Admin, Dark, Clean, Minimal, Landing Page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

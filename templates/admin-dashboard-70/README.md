# Finance Analytics Dashboard Template

A reusable admin dashboard template for tracking net margin, order profitability, costs, and business performance with clean finance analytics UI.

## Project Details
- **Slug:** `admin-dashboard-70`
- **Views:** 64
- **Tags:** Technology, Services, Landing Page, Clean, Minimal, Dashboard, Admin, Analytics, Finance
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

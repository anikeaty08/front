# Admin Dashboard Modal Template

A reusable admin UI template for editing roles, subscriptions, and permission settings with tabbed controls, toggles, and configuration management.

- **Slug:** `admin-role-management-40`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Admin Dashboard Template

A reusable admin dashboard template for service businesses to manage sign-in, quote requests, media galleries, and client reviews in one workspace.

## Project Details
- **Slug:** `admin-workspace-42`
- **Views:** 48
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Dashboard, Admin, CMS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

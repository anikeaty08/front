# Elegant Wedding Landing Page Template

A refined wedding landing page template featuring love story, event details, dress code, hotel, gifts, and RSVP to share your big day online.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

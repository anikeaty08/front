# Advanced Dentistry Clinic Landing Page Template

A modern dental clinic landing page template for prosthodontists and implant specialists to showcase services, doctors, testimonials, and patient contact details.

## Project Details
- **Slug:** `advanced-dentistry-54`
- **Views:** 18
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Technology, dental clinic, medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

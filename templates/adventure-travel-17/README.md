# Adventure Trekking Website Template

A reusable adventure trekking website template for tour operators and outdoor brands to showcase treks, guides, galleries, testimonials, and booking inquiries.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

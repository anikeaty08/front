# Political Campaign Landing Page Template

A reusable political campaign template for advocacy groups and movements to showcase policy platforms, candidates, campaign media, and public opinion polls.

## Project Details
- **Slug:** `advocacy-and-political-2`
- **Views:** 34
- **Tags:** Landing Page, Political, Social, Health, Clean, Minimal, Brand, campaign, advocacy
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

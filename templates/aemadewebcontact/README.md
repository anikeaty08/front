# AEMadeWeb - Contact for any infortmation

A modern one-page contact card template for freelance web developers to showcase services and let clients quickly start a project via email or phone.

## Project Details
- **Slug:** `aemadewebcontact`
- **Views:** 21
- **Tags:** Landing Page, Services, Technology, Dark, Minimal, Clean, Portfolio, Large Type, Contact Card, Freelancer
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

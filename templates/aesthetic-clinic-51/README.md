# Aesthetic Clinic Landing Page Template

A premium landing page template for modern aesthetic and dermatology clinics to showcase treatments, results, and bookings with a luxurious, spatial design.

## Project Details
- **Slug:** `aesthetic-clinic-51`
- **Views:** 90
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

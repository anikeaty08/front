# Aesthetic Cosmetology Landing Page Template

Elegant, ready-to-use landing page template for premium hardware cosmetology and beauty studios to showcase services, results, and client reviews in a modern layout.

- **Slug:** `aesthetic-cosmetolog-55`
- **Views:** 14

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

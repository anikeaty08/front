# Aether Agency Landing Page Template

Aether is a dark, futuristic agency landing page template for digital studios and tech services, featuring 3D visuals, portfolio, services, contact, and admin dashboard sections.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

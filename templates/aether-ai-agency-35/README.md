# AI Agency Landing Page Template

A dark, futuristic AI agency landing page template for promoting intelligent ML services, showcasing capabilities, workflow, and a waitlist-style CTA.

## Project Details
- **Slug:** `aether-ai-agency-35`
- **Views:** 30
- **Tags:** Landing Page, Technology, Brand, Dark, Futuristic, Gradient, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

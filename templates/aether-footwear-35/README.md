# Aether Footwear E-commerce Landing Page Template

A modern footwear E-commerce landing page template for showcasing premium shoe collections, product details, and specs with a sleek, minimalist shopping experience.

## Project Details
- **Slug:** `aether-footwear-35`
- **Views:** 11
- **Tags:** E-commerce, Landing Page, Brand, Clean, Minimal, Gradient, Large Type, Fashion

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

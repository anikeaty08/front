# Aether UI/UX Designer Portfolio Template

Aether is a modern UI/UX designer portfolio template showcasing projects, capabilities, and contact CTA for digital creatives ready to present their work.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

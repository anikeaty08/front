# Creative Tech Agency Landing Page Template

A reusable landing page template for creative technology agencies to showcase services, portfolio, pricing, and client testimonials with a modern design.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

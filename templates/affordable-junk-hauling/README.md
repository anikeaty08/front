# Junk Removal Services Landing Page Template

A reusable landing page template for junk removal and hauling businesses to showcase services, build trust, and capture free estimate requests.

## Project Details
- **Slug:** `affordable-junk-hauling`
- **Views:** 39
- **Tags:** Landing Page, Services, Clean, Minimal, Brand, local services, junk removal, hauling, home services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# All star pros

A reusable plumbing services landing page template for local contractors to showcase emergency repairs, capture estimate leads, and build trust fast.

## Project Details
- **Slug:** `affordable-plumbing-com`
- **Views:** 20
- **Tags:** Landing Page, Services, Clean, Gradient, Blog, Brand, plumbing, home services, lead generation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Agency Collaboration Dashboard UI Template

A dark, modern dashboard UI template for agency and product teams to manage channels, messages, and project collaboration in a Slack-style interface.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

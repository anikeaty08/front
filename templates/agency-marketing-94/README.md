# Agency Marketing Landing Page Template

A dark, futuristic agency landing page template for marketing teams to showcase services, case studies, and lead-generation diagnostics sessions.

## Project Details
- **Slug:** `agency-marketing-94`
- **Views:** 45

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

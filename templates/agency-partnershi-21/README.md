# Agency Partnership Proposal Landing Page Template

A dark, modern landing page template for agencies to present strategic partnership proposals, showcase capabilities, and invite prospects to start a conversation.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Alestra Agency Website Template

Alestra is a dark, modern multi-page agency website template for showcasing digital work, pricing, and insights for service-based brands.

## Project Details
- **Slug:** `agency-portfolio-76`
- **Views:** 29
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Gradient, Large Type, Portfolio, Blog
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Agency Portfolio Landing Page Template

A dark, modern agency portfolio landing page template for showcasing software, SaaS, and web development case studies with metrics-driven storytelling.

## Project Details
- **Slug:** `agency-portfolio-80`
- **Views:** 16
- **Tags:** Landing Page, Portfolio, Services, Technology, Brand, Dark, Gradient, Clean, Large Type, Minimal

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

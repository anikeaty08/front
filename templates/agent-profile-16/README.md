# Delivery Agent Dashboard Template

A reusable mobile dashboard template for showcasing delivery agent profiles, achievements, performance metrics, and account settings in one polished UI.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

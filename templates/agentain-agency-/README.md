# Social Media Marketing Agency Landing Page Template

A reusable landing page template for social media marketing agencies to showcase services, capture leads, and manage inquiries with an admin-style dashboard.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

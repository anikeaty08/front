# AI Automation Platform Landing Page Template

A premium dark-mode SaaS landing page template for AI automation platforms to showcase workflows, features, pricing, and testimonials with a product-led story.

## Project Details
- **Slug:** `agenticflow`
- **Views:** 13
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Futuristic, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Political Information Dashboard Template

A reusable political platform template for publishing civic news, tracking parties, petitions, elected officials, and media transparency in one clean interface.

## Project Details
- **Slug:** `agora-social-beta-version`
- **Views:** 39
- **Tags:** Landing Page, Political, Social, Technology, Dashboard, Clean, Minimal, Data Visualization
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

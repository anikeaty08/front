# Agriculture Export Landing Page Template

A reusable B2B landing page template for vegetable oil exporters to showcase products, certifications, logistics, and generate quote requests.

## Project Details
- **Slug:** `agricultur-export-29`
- **Views:** 45
- **Tags:** Landing Page, Services, Business, Clean, Dark, Brand, Technology, export, agriculture, B2B
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

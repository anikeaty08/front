# Agricultural Investment Landing Page Template

A terminal-style landing page template for TerraYield-like agricultural investment platforms to showcase land yield consoles, protocols, and allocation tiers.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Agricultural Maintenance Landing Page Template

A reusable landing page template for agricultural maintenance and parts businesses to showcase services, catalogs, trust signals, and lead capture.

- **Slug:** `agricultur-maintenanc-4`
- **Views:** 27

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Agriculture Marketplace Landing Page Template

Reusable landing page template for an agriculture supplies marketplace and distributor, featuring product listings, filters, and contact CTAs for agro businesses.

## Project Details
- **Slug:** `agro-products-64`
- **Views:** 28
- **Tags:** Landing Page, E-commerce, Services, Brand, Clean, Colorful, Gradient, Large Type, Agriculture, Marketplace

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Agrotourism Restaurant & Apartments Website Template

A refined agrotourism website template for promoting a countryside estate with restaurant, apartments, winery, and contact inquiries in one elegant layout.

## Project Details
- **Slug:** `agrotouris-restaurant-98`
- **Views:** 61
- **Tags:** Travel, Services, Brand, Clean, Minimal, Large Type, Landing Page, Restaurant, Hotel, Winery
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Agriculture Brand Landing Page Template

A modern agriculture landing page template for potato producers and agri-brands to showcase heritage, sustainable technology, products, and partner inquiries.

## Project Details
- **Slug:** `agrotrade-farming-68`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Food E-commerce Mobile App Template

Reusable template for a mobile-style food and grocery e-commerce app, featuring product catalog, cart, QR/COD payment, user login, and admin dashboard.

## Project Details
- **Slug:** `aharer-swad-mart`
- **Views:** 17
- **Tags:** E-commerce, Food, Services, Technology, Mobile App, Clean, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

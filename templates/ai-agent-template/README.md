# AI Automation Landing Page Template

A reusable landing page template for AI workflow automation platforms, built to showcase integrations, no-code flows, product features, and conversion-focused CTAs.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

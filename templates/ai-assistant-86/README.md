# AI Assistant Dashboard Template

A reusable AI assistant dashboard template for hotel operations teams to manage tasks, guest knowledge, staffing, and reports in one interface.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Automation Agency Landing Page Template

A dark, modern AI automation agency landing page template for showcasing services, use cases, pricing, and lead-gen contact forms for enterprise clients.

## Project Details
- **Slug:** `ai-automation-12`
- **Views:** 13
- **Tags:** Landing Page, Technology, Services, Brand, Dark, Clean, Gradient, Large Type, Minimal, Grid
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

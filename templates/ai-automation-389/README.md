# AI Automation Agency Landing Page Template

A reusable landing page template for AI automation consultancies and service firms to showcase offerings, case studies, trust signals, and lead generation.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

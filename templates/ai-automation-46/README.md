# AI Automation Agency Landing Page Template

Reusable dark-mode landing page template for an AI automation agency offering chatbots, workflow automation, and data-driven services to modern businesses.

## Project Details
- **Slug:** `ai-automation-46`
- **Views:** 70
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Minimal, Gradient, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

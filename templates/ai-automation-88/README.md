# AI Automation Agency Landing Page Template

A reusable landing page template for AI automation and voice agent agencies to showcase services, process, insights, and drive strategy call bookings.

## Project Details
- **Slug:** `ai-automation-88`
- **Views:** 780
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Gradient, Minimal, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

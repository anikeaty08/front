# AI Bootcamp Landing Page Template

A reusable landing page template for promoting live AI bootcamps, training programs, and cohort-based courses with curriculum, instructors, pricing, FAQs, and enrollment CTAs.

## Project Details
- **Slug:** `ai-bootcamp-landing-34`
- **Views:** 128
- **Tags:** Landing Page, Education, Technology, Clean, Dark, Gradient, Bootcamp, AI, Course
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

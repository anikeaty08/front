# AI Chat Dashboard Template

A reusable AI dashboard template for embedding chat assistants with a polished glassmorphism layout, sidebar navigation, and a modern app-like interface.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Chat Interface UI Template

A reusable AI chat interface UI template that replicates a modern assistant layout with sidebar history, chat thread, and input composer for web apps.

- **Views:** 284

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Services Landing Page Template

A reusable landing page template for AI service providers to showcase local business AI assistants, case studies, and consultations that convert visitors into leads.

## Project Details
- **Slug:** `ai-coaching-services-79`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

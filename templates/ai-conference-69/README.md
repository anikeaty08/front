# AI Conference Landing Page Template

A reusable conference landing page template for promoting AI events with speakers, program schedules, ticketing, community highlights, and registration CTAs.

## Project Details
- **Slug:** `ai-conference-69`
- **Views:** 81
- **Tags:** Landing Page, Conference, Technology, Dark, Minimal, Clean, Event, AI, Ticketing
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

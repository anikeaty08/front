# AI Corporate Training Landing Page Template

A reusable dark-style landing page template for an AI-powered corporate training platform that turns static manuals into interactive, secure active learning.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Customer Support Landing Page Template

A reusable landing page template for promoting AI support agents that automate customer service across WhatsApp, Instagram, email, and web chat.

## Project Details
- **Slug:** `ai-customer-support-41`
- **Views:** 43
- **Tags:** Landing Page, Technology, Services, Clean, Minimal, SaaS, AI, Automation, Customer Support, Chatbot
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

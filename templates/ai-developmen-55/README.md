# AI Development Platform Landing Page Template

A reusable landing page template for AI-powered development platforms, showcasing visual app building, code export, edge deployment, and product-led CTAs.

## Project Details
- **Slug:** `ai-developmen-55`
- **Views:** 45
- **Tags:** Landing Page, Technology, SaaS, AI, Dark, Futuristic, Gradient, Clean, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Ecosystem Landing Page Template

A modern, dark-mode AI ecosystem landing page template for showcasing products, consulting, academy, and R&D lab with multi-language support.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

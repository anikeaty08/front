# EntertainAI Social Discovery Web App Template

A dark, AI-powered entertainment discovery web app UI template to help users find movies and shows with social group recommendations and smart filters.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

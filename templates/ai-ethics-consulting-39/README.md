# AI Ethics Consulting Landing Page Template

A reusable landing page template for AI ethics consultancies, researchers, and advocacy-led brands to present services, credibility, and contact CTAs.

## Project Details
- **Slug:** `ai-ethics-consulting-39`
- **Views:** 365
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Editorial, Minimal, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

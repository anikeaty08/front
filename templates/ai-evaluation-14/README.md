# AI Evaluation Platform Landing Page Template

A dark, futuristic landing page template for AI evaluation and alignment platforms, showcasing telemetry, safety metrics, and model evaluation workflows.

## Project Details
- **Slug:** `ai-evaluation-14`
- **Views:** 11
- **Tags:** Landing Page, Technology, Brand, Dark, Futuristic, Clean, Gradient, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Event Assistant Landing Page Template

A reusable landing page template for showcasing an AI-powered event assistant app with chat, maps, schedules, and attendee support features.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

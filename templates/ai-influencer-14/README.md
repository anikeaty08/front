# AI Influencer Marketing Landing Page Template

A clean, modern landing page template for AI-driven influencer marketing apps to showcase features, social proof, and conversion-focused CTAs.

## Project Details
- **Slug:** `ai-influencer-14`
- **Views:** 9
- **Tags:** Landing Page, Technology, Brand, Clean, Colorful, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

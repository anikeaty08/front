# AI Lead Generation Landing Page Template

A reusable dark-mode landing page template for AI lead generation and done-for-you outbound services, built to convert B2B prospects into booked conversations.

## Project Details
- **Slug:** `ai-lead-generation-6`
- **Views:** 60

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

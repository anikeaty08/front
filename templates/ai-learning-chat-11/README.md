# AI Learning Chat Landing Page Template

A reusable landing page template for AI-powered language learning chat apps, featuring voice input, quick replies, and a polished mobile-first interface.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

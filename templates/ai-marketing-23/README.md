# AI Marketing Agency Landing Page Template

A reusable landing page template for AI-powered marketing agencies to showcase SEO, paid media, automation services, insights, and lead capture.

## Project Details
- **Slug:** `ai-marketing-23`
- **Views:** 40
- **Tags:** Landing Page, Services, Technology, Dark, Gradient, Clean, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

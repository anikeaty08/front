# AI Masterclass Course Landing Page Template

A reusable AI masterclass landing page template for promoting non-technical AI courses, showcasing modules, benefits, testimonials, and a clear purchase CTA.

- **Slug:** `ai-masterclas-8`
- **Views:** 1
- **Tags:** Landing Page, Education, Services, Brand, Clean, Minimal, Large Type, Technology, AI course, Masterclass
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

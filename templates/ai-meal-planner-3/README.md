# AI Meal Planner Web App Template

A modern AI meal planner web app template with onboarding, dashboard, calendar schedule, and meal detail views to jumpstart nutrition and diet products.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

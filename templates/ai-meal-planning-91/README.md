# AI Meal Planning Mobile App Template

Reusable mobile app template that lets users scan their fridge, set goals, and generate a 7-day AI-powered meal plan with optimized grocery list and checkout flow.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

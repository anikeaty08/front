# AI Media Enhancer Web App Template

A reusable template for an AI-powered image and video enhancement web app with upscale controls, real-time preview, and processing modal UI.

- **Slug:** `ai-media-enhancer-60`
- **Views:** 10

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

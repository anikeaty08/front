# AI Operations Landing Page Template

A reusable landing page template for AI operations platforms to showcase monitoring, anomaly detection, security workflows, and enterprise integrations.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

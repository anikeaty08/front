# Predictive Intelligence Engine SaaS Template

A reusable SaaS landing page template for showcasing a predictive intelligence engine like YUNA, with hero UI, feature flows, pricing, testimonials, and CTAs.

## Project Details
- **Slug:** `ai-predictive`
- **Views:** 2401
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Gradient, Large Type, SaaS, AI, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Restaurant AI SaaS Landing Page Template

A modern SaaS landing page template for an AI phone receptionist service for restaurants, showcasing features, pricing, and demos ready to customize.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

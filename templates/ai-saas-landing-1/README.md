# AstraLaunch SaaS Landing Page Template

AstraLaunch is a dark, futuristic SaaS landing page template for AI tools and startups, designed to be reused and customized for high-converting product launches.

- **Slug:** `ai-saas-landing-1`
- **Views:** 70

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

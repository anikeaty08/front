# AI Sales Analytics Landing Page Template

A reusable landing page template for AI-powered sales analytics and revenue forecasting platforms, built to showcase features, pricing, testimonials, and demos.

## Project Details
- **Slug:** `ai-sales-analytics`
- **Views:** 1975
- **Tags:** Technology, Landing Page, SaaS, AI, Analytics, Clean, Animated, Gradient, Dashboard

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

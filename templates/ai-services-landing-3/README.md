# AI Services Landing Page Template

A dark, futuristic landing page template for AI consultancies to showcase data services, model development, and ML infrastructure offerings from pilot to production.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Smart Tutor Web App Template

A reusable AI tutor dashboard template for education platforms, featuring text chat, voice tutoring, diagrams, quizzes, and student profiles.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Shopping Assistant Widget Template

Reusable AI shopping assistant chat widget template for ecommerce sites, showcasing a glassmorphism UI and floating launcher you can embed and customize.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

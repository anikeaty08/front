# AI Staffing Service Landing Page Template

A reusable landing page template for promoting AI staffing services that help small businesses deploy AI “team members” for support, sales, and operations.

## Project Details
- **Slug:** `ai-staffing-service-2`
- **Views:** 2
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Gradient, Minimal, Large Type, AI staffing, Small business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

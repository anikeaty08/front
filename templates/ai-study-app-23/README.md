# AI Study Landing Page Template

A reusable landing page template for AI study apps that turn notes and class materials into summaries, flashcards, quizzes, and guided learning.

## Project Details
- **Slug:** `ai-study-app-23`
- **Views:** 57
- **Tags:** Landing Page, Education, Technology, Clean, Minimal, AI, SaaS, Study App, Flashcards, Productivity
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

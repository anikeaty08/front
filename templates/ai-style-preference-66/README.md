# AI Preference Test UI Template

Dark, futuristic comparison UI template for quick “Which is better?” preference tests to train AI style memory or collect user choice data.

- **Slug:** `ai-style-preference-66`

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Telemetry Platform Landing Page Template

A reusable landing page template for AI observability and telemetry platforms, built to showcase monitoring, anomaly detection, pricing, testimonials, and enterprise-scale infrastructure.

## Project Details
- **Slug:** `ai-telemetry`
- **Views:** 1974
- **Tags:** Landing Page, Technology, Dark, Futuristic, Animated, Clean, SaaS, AI, Observability, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

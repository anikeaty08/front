# AI Tool Directory Landing Page Template

A modern AI tool directory landing page template for listing, searching, and promoting AI apps, experts, and courses in a clean, conversion-focused layout.

## Project Details
- **Slug:** `ai-tool-directory-22`
- **Views:** 70
- **Tags:** Landing Page, Technology, Services, Brand, Clean, Minimal, Gradient, Large Type, AI directory, SaaS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

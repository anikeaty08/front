# AI Tool Directory Website Template

A reusable dark-mode website template for showcasing curated AI, design, and development tools with searchable categories and clean directory layouts.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

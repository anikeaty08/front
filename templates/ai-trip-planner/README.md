# Travel Itinerary Landing Page Template

A reusable travel itinerary template for showcasing destination overviews, maps, weather, budgets, and trip planning details in an immersive UI.

## Project Details
- **Slug:** `ai-trip-planner`
- **Views:** 72
- **Tags:** Landing Page, Travel, Technology, Dark, Clean, Minimal, itinerary, trip planner, map UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

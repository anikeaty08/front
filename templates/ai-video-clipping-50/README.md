# AI Video Clipping Landing Page Template

A reusable landing page template for AI video clipping tools that turn long-form content into viral short clips with captions, scoring, and editing.

## Project Details
- **Slug:** `ai-video-clipping-50`
- **Views:** 80
- **Tags:** Landing Page, Technology, Dark, Gradient, Futuristic, Animated, AI video, SaaS, video editor
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

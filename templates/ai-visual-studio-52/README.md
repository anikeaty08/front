# AI Creative Studio Landing Page Template

A dark, cinematic landing page template for AI-powered visual production studios to showcase generative visuals, services, tools, clients, and contact inquiries.

- **Slug:** `ai-visual-studio-52`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Website Builder Dashboard Template

A modern AI website builder dashboard template for managing, editing, and publishing web projects with integrated AI design assistance.

## Project Details
- **Slug:** `ai-website-builder`
- **Views:** 8
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Dashboard, AI, Website Builder, Editor, No-code
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

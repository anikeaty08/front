# AI WhatsApp Agency Dashboard Template

A reusable template for showcasing and planning an AI WhatsApp chatbot business, including product strategy, technical setup, pricing, and growth playbooks.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

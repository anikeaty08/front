# AI Assistant Landing Page Template

A clean, modern landing page template for promoting an intelligent messaging-based AI assistant like ShareClaw across WhatsApp and other chat platforms.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

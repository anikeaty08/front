# AI Masterclass Presentation Template

A reusable dark presentation template for AI workshops, masterclasses, and educational landing experiences about neural networks, tools, and creative workflows.

## Project Details
- **Slug:** `ai-workshop-presentati-82`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

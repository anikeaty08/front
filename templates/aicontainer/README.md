# AI Container Landing Page Template

A conversion-focused landing page template for an AI-powered container turnover logistics SaaS platform connecting shippers and container owners between Russia and China.

- **Slug:** `aicontainer`
- **Views:** 28

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Consulting Landing Page Template

Aikara-inspired AI consulting landing page template for showcasing enterprise AI services, industries, and strategy call CTAs with a modern, trust-focused design.

## Project Details
- **Slug:** `aikara-consulting`
- **Views:** 128

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Aim Trainer Game Interface Template

A reusable aim trainer game interface template for creating browser-based reaction and accuracy training experiences with a sleek dark UI.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

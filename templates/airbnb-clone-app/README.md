# Vacation Rental Marketplace Template

A reusable vacation rental listing template for showcasing homes, condos, and booking details with immersive browsing and reservation-ready UI.

## Project Details
- **Slug:** `airbnb-clone-app`
- **Views:** 22
- **Tags:** Real Estate, Travel, Landing Page, E-commerce, Clean, Minimal, Marketplace, Booking, Directory
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

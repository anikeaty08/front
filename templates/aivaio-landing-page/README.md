# AI Startup Coming Soon Landing Page Template

A dark, modern coming soon landing page template for AI startups to capture emails, highlight product value, and build an exclusive early-access waitlist.

## Project Details
- **Slug:** `aivaio-landing-page`
- **Views:** 71
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Large Type, Gradient, Clean, AI, Coming Soon
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Employee Management Dashboard UI Template

A reusable Employee Growth Portal UI template for visualizing career paths, skills, and progression insights inside HR or people development tools.

## Project Details
- **Slug:** `ak-lts-hrm-portal`
- **Views:** 8
- **Tags:** Landing Page, Technology, Brand, Dark, Clean, Minimal, Dashboard, HR, Employee Growth, Career Development
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

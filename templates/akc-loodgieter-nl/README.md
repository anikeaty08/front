# Plumbing Services Landing Page Template

A reusable landing page template for plumbers and emergency repair businesses to promote local services, showcase trust signals, and drive calls fast.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

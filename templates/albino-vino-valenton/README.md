# Albino Vino

A minimalist wine e-commerce landing page template for socially conscious brands to showcase a hero bottle, manifesto, impact metrics, and donation-focused purchase CTA.

## Project Details
- **Slug:** `albino-vino-valenton`
- **Views:** 32
- **Tags:** Landing Page, E-commerce, Food, Brand, Clean, Minimal, Large Type, Gradient, Social impact, Wine
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

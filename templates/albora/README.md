# Social Innovation Studio Landing

A reusable landing page template for social innovation studios, consultancies, and impact organizations to present services, methodology, initiatives, and collaboration flows.

## Project Details
- **Slug:** `albora`
- **Views:** 16
- **Tags:** Landing Page, Services, Social, Non-profit, Brand, Minimal, Clean, Large Type, Dark
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Digital Drawing Diary App UI Template

A reusable Digital Drawing Diary App UI Template for sketching, journaling, and sticker-based note-taking with pages, tools, and light/dark themes.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Check-in OS SaaS Dashboard Template

A reusable dark SaaS dashboard template for an aligned performance check-in OS, featuring client login, admin console, and calendar-based check-in workflows.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Video Downloader Landing Page Template

A modern dark-mode template for a universal video downloader landing page, perfect for apps or SaaS tools that let users download HD/4K content from major platforms.

## Project Details
- **Slug:** `all-in-one-video`
- **Views:** 149
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Gradient, Large Type, Video Downloader, SaaS, Product
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# All purpose carpet & tile cleaning

A reusable landing page template for carpet, tile, and upholstery cleaning businesses to showcase services, results, testimonials, and capture quote requests.

## Project Details
- **Slug:** `all-purpose-carpet-tile`
- **Views:** 78
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, home services, cleaning business, quote form, testimonials
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

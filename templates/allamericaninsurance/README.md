# Insurance Agency Landing Page

A reusable landing page template for independent insurance agencies to showcase personal and commercial coverage, build trust, and drive quote requests.

## Project Details
- **Slug:** `allamericaninsurance`
- **Views:** 43
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Brand, insurance, local agency, quote form

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

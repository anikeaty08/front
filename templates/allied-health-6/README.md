# Alpaca Health Clinic Landing Page Template

A clean, clinical landing page template for home-based allied health, physiotherapy, and rehabilitation clinics to showcase services and capture bookings.

## Project Details
- **Slug:** `allied-health-6`
- **Views:** 15
- **Tags:** Health, Landing Page, Services, Brand, Clean, Minimal, Gradient, Large Type, Technology, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

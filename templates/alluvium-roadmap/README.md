# Alluvium Roadmap Landing Page Template

Interactive roadmap landing page template that visualizes NOW/NEXT/LATER initiatives with a flowing river UI, ideal for product roadmaps and strategy updates.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

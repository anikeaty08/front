# Eco City Government Portal Landing Page Template

A modern eco-city portal landing page template for government or municipal teams to showcase air quality data, LEZ maps, EV benefits, and citizen reporting tools.

## Project Details
- **Slug:** `almaty-eco-city-34`
- **Views:** 18
- **Tags:** Landing Page, Services, Environmental, Clean, Dark, Gradient, Large Type, Technology, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

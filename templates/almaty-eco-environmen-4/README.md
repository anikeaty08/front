# Eco City Portal Landing Page Template

A modern eco-portal landing page template for city environmental services with news, complaints, benefits, calculator, FAQ, and contact sections.

## Project Details
- **Slug:** `almaty-eco-environmen-4`
- **Views:** 32
- **Tags:** Landing Page, Services, Environmental, Clean, Minimal, Grid, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

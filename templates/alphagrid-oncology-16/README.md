# Oncology Startup Landing Page Template

A clean, research-forward landing page template for an oncology or healthtech startup to present a computational cancer platform, narrative, and clinical pilots.

## Project Details
- **Slug:** `alphagrid-oncology-16`
- **Views:** 33
- **Tags:** Landing Page, Health, Technology, Clean, Minimal, Brand, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

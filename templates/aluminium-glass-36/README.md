# Aluminium & Glass Services Landing Page Template

A reusable landing page template for local aluminium and glass service businesses to showcase doors, windows, partitions, projects, and contact options.

## Project Details
- **Slug:** `aluminium-glass-36`
- **Views:** 28
- **Tags:** Landing Page, Services, Business, Brand, Clean, Minimal, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

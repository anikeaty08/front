# Alumni Association Landing Page Template

A modern, Italian-language landing page template for professional alumni associations to showcase events, news, mission, and membership calls-to-action.

## Project Details
- **Slug:** `alumni-associatio-76`
- **Views:** 18

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

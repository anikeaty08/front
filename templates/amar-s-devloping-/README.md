# Mac App Feature List Template

A dark, minimal Mac app feature list template for showcasing product capabilities in a native-feel UI, ready to reuse for your own app marketing.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

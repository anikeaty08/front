# Amaranth Product Landing Page Template

A reusable landing page template for amaranth seed and health product brands, featuring hero storytelling, product highlights, science sections, news, and rich footer navigation.

## Project Details
- **Slug:** `amaranth-product-69`
- **Views:** 16
- **Tags:** Landing Page, Health, Food, Brand, Clean, Gradient, Large Type, Minimal, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

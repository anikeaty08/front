# Amateur Football Management Landing Page Template

A dark, gamified landing page template for apps that manage amateur football matches, payments, stats, and organizers’ branding.

## Project Details
- **Slug:** `amateur-football-41`
- **Views:** 12
- **Tags:** Landing Page, Services, Technology, Dark, Gradient, Brand, Clean, Large Type, Sports, SaaS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

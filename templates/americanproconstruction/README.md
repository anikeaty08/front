# American Pro Construction 

A reusable construction company landing page template for contractors and remodelers to showcase services, projects, testimonials, and capture estimate requests.

## Project Details
- **Slug:** `americanproconstruction`
- **Views:** 24
- **Tags:** Landing Page, Services, Business, Clean, Dark, Grid, Construction, Remodeling, Contractors
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

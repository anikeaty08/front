# Analytics Dashboard Cards UI Template

A reusable analytics dashboard cards UI template for visualizing sales, breakdowns, and cancellations in modern web apps using Tailwind CSS.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

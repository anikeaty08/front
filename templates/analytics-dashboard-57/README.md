# Analytics Dashboard Template

A reusable dark analytics dashboard template for SaaS teams to track revenue, users, growth charts, and recent activity in a clean UI.

## Project Details
- **Slug:** `analytics-dashboard-57`
- **Views:** 73

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

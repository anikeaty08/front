# An Atomic Party

A stylish interactive template for wedding or celebration announcements that reveals event details on hover with immersive imagery and elegant typography.

## Project Details
- **Slug:** `anatomicparty`
- **Views:** 174
- **Tags:** Landing Page, Wedding, Animated, Dark, Minimal, Brand, event invitation, hover reveal, celebration
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

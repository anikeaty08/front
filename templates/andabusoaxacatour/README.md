# City Tour Oaxaca Landing Page Template

Reusable landing page template for promoting a hop-on hop-off Oaxaca city tour, featuring route highlights, pricing, WhatsApp booking, FAQs, and testimonials.

## Project Details
- **Slug:** `andabusoaxacatour`
- **Views:** 42
- **Tags:** Landing Page, Travel, Services, Brand, Colorful, Large Type, Clean, City Tour, WhatsApp Booking, Oaxaca
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

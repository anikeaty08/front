# AndaPack B2B Logistics Landing Page Template

Reusable landing page template for B2B logistics and shipping services focused on CDMX–Puebla–Puerto Escondido routes, optimized for lead capture and quotes.

## Project Details
- **Slug:** `andapack-b2b-logistics-5`
- **Views:** 25
- **Tags:** Landing Page, Services, Business, Logistics, B2B, Clean, Gradient, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

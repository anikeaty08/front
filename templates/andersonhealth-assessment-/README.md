# Health Assessment Landing Page Template

A reusable landing page template for longevity clinics and health brands to promote a free assessment, build trust, and drive patient lead conversions.

## Project Details
- **Slug:** `andersonhealth-assessment-`
- **Views:** 17
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Brand, medical assessment, longevity clinic, lead generation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

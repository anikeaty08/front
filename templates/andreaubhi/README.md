# Andrea Ubhi Cosmetic Dentistry Team Page Template

A reusable template for cosmetic dentistry clinics to showcase their award-winning team, practice details, and consultation inquiries on a polished about-us page.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

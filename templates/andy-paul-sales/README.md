# Sales Coaching by Andy

A reusable landing page template for sales coaches, consultants, and thought leaders to promote buyer engagement services and book strategy calls.

## Project Details
- **Slug:** `andy-paul-sales`
- **Views:** 42

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

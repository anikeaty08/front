# Abstract Background Landing Page Template

A reusable dark background template for landing pages and brand sites, ideal for adding immersive animated visuals with minimal setup.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

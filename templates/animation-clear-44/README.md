# Student UX/UI Portfolio Website Template

A modern student UX/UI portfolio template for showcasing projects, skills, and contact details, ready to customize for design students and junior designers.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Anime Streaming Dashboard Template

ANISTREAM is a dark anime TV & movie dashboard template that connects to the MyAnimeList API for browsing titles and plugging in your own streaming embeds.

## Project Details
- **Slug:** `anime-streaming-65`
- **Views:** 87

- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Anita's Sweet Home Kitchen

A reusable landing page template for home-based Indian sweets and festive food businesses to showcase menus, pre-orders, testimonials, and WhatsApp ordering.

## Project Details
- **Slug:** `anitas-sweethome-kitchen`
- **Views:** 38
- **Tags:** Landing Page, Food, Services, Brand, Warm, Traditional, Minimal, Colorful, Festival, WhatsApp
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

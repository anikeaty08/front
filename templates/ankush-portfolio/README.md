# Ankush Web Developer Portfolio Template

A high-performance dark-themed portfolio template designed for developers and freelancers to showcase services and capture leads via WhatsApp.

## Project Details
- **Slug:** `ankush-portfolio`
- **Views:** 52
- **Tags:** Portfolio, Technology, Services, Dark, Clean, Minimal, Landing Page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# whispr Anonymous Chat App UI Template

A reusable mobile-style anonymous chat app UI template for building privacy-first messaging experiences with onboarding, rooms, profiles, and safety tools.

## Project Details
- **Slug:** `anonymous-chat-10`
- **Views:** 73
- **Tags:** Landing Page, Technology, Brand, Dark, Gradient, Minimal, Large Type, Chat App, Mobile UI, Messaging
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

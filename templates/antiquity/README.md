# AI QA Landing Page Template

A reusable landing page template for AI-powered QA, automated testing, debugging, and developer tooling products with a polished modern hero and clear CTAs.

## Project Details
- **Slug:** `antiquity`
- **Views:** 40
- **Tags:** Landing Page, Technology, SaaS, AI, Clean, Gradient, Animated, Futuristic, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

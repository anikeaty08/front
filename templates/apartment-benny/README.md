# Seaside Apartment Rental Landing Page Template

A modern Costa Adeje apartment rental landing page template with booking widget, gallery, surroundings guide, and admin pricing dashboard for property hosts.

## Project Details
- **Slug:** `apartment-benny`
- **Views:** 43
- **Tags:** Landing Page, Real Estate, Travel, Clean, Minimal, Brand, Marketing, Vacation Rental, Apartment, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# ApaSakit

A modern ApaSakit telehealth landing page template for Malaysian online healthcare apps, optimized for SaaS-style plans, mobile app promotion, and trial signups.

## Project Details
- **Slug:** `apasakit`
- **Views:** 46
- **Tags:** Landing Page, Health, Services, Technology, Brand, Clean, Gradient, Large Type, Minimal, Telehealth
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

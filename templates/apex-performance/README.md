# Apex Performance Auto Service Landing Page Template

A dark, high-octane landing page template for performance auto tuning and service shops to showcase services, builds, pricing, and capture service requests.

## Project Details
- **Slug:** `apex-performance`
- **Views:** 13
- **Tags:** Landing Page, Services, Brand, Dark, Large Type, Minimal, Automotive, Car Tuning, Workshop
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# HVAC Heat Pump Services Landing Page Template

A reusable landing page template for HVAC and heat pump service businesses, featuring contact forms, rebate calculator, AI helper, and detailed service sections.

## Project Details
- **Slug:** `apexheatpumps-live`
- **Views:** 161
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

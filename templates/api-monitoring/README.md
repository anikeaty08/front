# API Monitoring Landing Page Template

A reusable dark-mode template for showcasing an API monitoring platform with dashboards, observability features, pricing, FAQs, and strong conversion CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

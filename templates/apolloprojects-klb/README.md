# Engineering Student Projects Landing Page Template

A reusable landing page template for engineering project services, ideal for showcasing Arduino, IoT, and robotics solutions to attract final-year students.

## Project Details
- **Slug:** `apolloprojects-klb`
- **Views:** 32
- **Tags:** Landing Page, Services, Education, Technology, Clean, Minimal, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

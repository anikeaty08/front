# App Store Button Link Template

Minimal App Store button link template for landing pages, letting you quickly add a sleek, reusable download CTA for your app or product.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

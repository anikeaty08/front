# Apple Pay Modal UI Template

A reusable Apple Pay-style payment flow template for summarizing charges, entering passcodes, and handling limit errors in dark, modern web apps.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

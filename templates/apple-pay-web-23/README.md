# Apple Pay Web Modal UI Template

A reusable Apple Pay–style web payment modal template that simulates passcode entry, limits, and transaction details for modern checkout flows.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Appliance Repair Service Landing Page Template

A clean, conversion-focused template for local appliance repair businesses to showcase services, hours, reviews, and drive appointment bookings.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

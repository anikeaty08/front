# Eventi & Formazione Artisti Landing Page Template

Elegante landing page template per associazioni e realtà di eventi e formazione dedicati ad artisti, performer e professionisti dello spettacolo.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

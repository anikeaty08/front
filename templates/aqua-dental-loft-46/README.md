# Dental Clinic Landing Page Template

A modern dental practice landing page template for cosmetic, general, and emergency dentistry clinics to showcase services, team, and online booking.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Arabic Digital Store Landing Page Template

Modern Arabic RTL landing page template for a professional digital products store, ideal for showcasing and selling templates, ebooks, and design bundles.

## Project Details
- **Slug:** `arabic-digital-15`
- **Views:** 28

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

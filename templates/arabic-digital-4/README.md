# Arabic Digital Licenses Store Landing Page Template

A modern Arabic RTL landing page template for a digital licenses and software subscriptions store, ready to customize for your own e-commerce brand.

## Project Details
- **Slug:** `arabic-digital-4`
- **Views:** 100
- **Tags:** E-commerce, Technology, Landing Page, Brand, Gradient, Clean, Dark, Colorful, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Arabic Guessing Game Landing Page Template

A reusable Arabic game template for hosting quick guessing rounds with categories, timers, and simple controls for parties, classrooms, or social play.

## Project Details
- **Slug:** `arabic-guessing-62`
- **Views:** 57
- **Tags:** Landing Page, Entertainment, Clean, Minimal, Game, Arabic, RTL, Interactive
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

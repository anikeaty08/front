# Arabic HR Dashboard UI Template

A modern Arabic HR dashboard UI template for managing jobs, applications, employees, and payroll analytics, ready to customize for HR web apps.

## Project Details
- **Slug:** `arabic-hr-dashboard-23`
- **Views:** 26
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Dashboard, HR, Arabic, Web App UI, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Arabic Legal Encyclopedia Page Template

A reusable Arabic legal encyclopedia page template for displaying civil law articles with a clean RTL layout, sticky TOC, and structured legal content.

## Project Details
- **Slug:** `arabic-legal-48`
- **Views:** 28
- **Tags:** Landing Page, Documentation, Brand, Clean, Minimal, Large Type, Technology, Arabic, Legal, RTL
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Arabic Legal Platform Login Page Template

A reusable Arabic RTL login page template for legal or professional platforms, featuring a modern dark hero, secure form design, and clear CTAs.

## Project Details
- **Slug:** `arabic-legal-80`
- **Views:** 21
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

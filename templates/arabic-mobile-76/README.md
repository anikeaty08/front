# Arabic Social App Mobile UI Template

A reusable Arabic RTL mobile app UI template for a social availability app with home feed, contacts, and profile screens.

## Project Details
- **Slug:** `arabic-mobile-76`
- **Views:** 15
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Mobile App, Arabic, RTL, Social
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Arabic Receipt UI Template

Reusable Arabic receipt UI template for digital remittance and payment confirmations, ready to adapt to your finance or services platform.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

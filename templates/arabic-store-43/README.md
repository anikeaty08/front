# Mobile E-commerce App Builder Template

A comprehensive drag-and-drop template for building customized mobile store applications with Zid platform integration.

## Project Details
- **Slug:** `arabic-store-43`
- **Views:** 45
- **Tags:** Landing Page, Technology, Clean, E-commerce, Services, Flat, Minimal

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

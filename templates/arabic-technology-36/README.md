# Arabic Technology Services Landing Page Template

A modern Arabic RTL landing page template for technology and digital solutions companies to showcase services, process, and contact details in a sleek, reusable layout.

## Project Details
- **Slug:** `arabic-technology-36`
- **Views:** 15
- **Tags:** Landing Page, Services, Technology, Brand, Gradient, Dark, Clean, Large Type, Minimal, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

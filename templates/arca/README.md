# Fintech Banking Landing Page Template

A modern fintech banking landing page template for promoting digital banking apps, cards, and financial services with pricing, features, and advisor network sections.

## Project Details
- **Slug:** `arca`
- **Views:** 39
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Gradient, Clean, Futuristic, Large Type, Financial

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Arcade Game Landing Page Template

A reusable landing page template for showcasing a browser-based arcade game with interactive gameplay, score tracking, and a bold dark UI.

## Project Details
- **Slug:** `arcade-game-landing-70`
- **Views:** 188

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

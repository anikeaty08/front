# Arcadia - Gaming Marketplace

A dark, futuristic gaming launcher UI template for showcasing game stores, libraries, and social activity feeds—ready to customize for your own platform.

- **Slug:** `arcadia-of-games`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

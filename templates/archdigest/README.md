# Modern Architecture Landing Page Template

This reusable landing page template is designed for architecture studios showcasing modern, brutalist projects with portfolio, awards, and newsletter features.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

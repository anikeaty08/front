# ARCHITEKFUTURA

A dark, brutalist architecture studio landing page template for showcasing premium residential and commercial projects with a minimalist, gallery-style layout.

## Project Details
- **Slug:** `archi-futur`
- **Views:** 15
- **Tags:** Landing Page, Brand, Art & Design, Portfolio, Brutal, Dark, Minimal, Large Type, Architecture, Studio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

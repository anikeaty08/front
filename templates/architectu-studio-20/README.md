# Architecture Studio Landing Page Template

A reusable landing page template for architecture studios and design firms to showcase projects, expertise, careers, blog content, and lead capture.

## Project Details
- **Slug:** `architectu-studio-20`
- **Views:** 20
- **Tags:** Landing Page, Services, Brand, Blog, Minimal, Clean, Grid, Architecture, Studio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

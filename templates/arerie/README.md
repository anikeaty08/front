# AERIE

A dark, futuristic Web3 SaaS landing page template for showcasing a unified multi-chain operations console, ideal for NFT, wallet, and credential platforms.

- **Views:** 36

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

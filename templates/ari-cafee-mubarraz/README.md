# Cafe Landing Page Template

A bilingual cafe landing page template for showcasing menus, brand story, reviews, and fast WhatsApp ordering in a polished modern format.

## Project Details
- **Slug:** `ari-cafee-mubarraz`
- **Views:** 247

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Hospitality Arrival Experience Landing Page Template

A reusable landing page template for hotel and hospitality tech brands promoting digital check-in, mobile key access, and zero-queue guest arrival experiences.

## Project Details
- **Slug:** `arrival`
- **Views:** 56
- **Tags:** Landing Page, Technology, Services, Clean, Minimal, Futuristic, Hospitality, Hotel, Mobile Access, SaaS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Art Collection Mobile UI Template

A sleek mobile app UI template for showcasing, organizing, and sharing modern art collections and gallery favorites, ready to customize for your brand.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

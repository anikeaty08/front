# Art Gallery CMS Landing Page Template

A reusable landing page template for promoting a headless CMS built for modern art galleries, with API-first features, exhibition management, and shop workflows.

## Project Details
- **Slug:** `art-gallery-cms-76`
- **Views:** 56
- **Tags:** Landing Page, Technology, Art & Design, Dark, Minimal, Clean, CMS, Headless API, Gallery
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

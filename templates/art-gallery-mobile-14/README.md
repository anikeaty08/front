# bSide Mobile Art Gallery App UI Template

A sleek mobile app UI template for showcasing, capturing, and browsing contemporary artworks and gallery recommendations, ready to customize for your art brand.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

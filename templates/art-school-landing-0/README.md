# Art School Landing Page Template

A reusable landing page template for art and music schools to showcase courses, galleries, and contacts with a modern, conversion-focused layout.

## Project Details
- **Slug:** `art-school-landing-0`
- **Views:** 30
- **Tags:** Landing Page, Education, Art & Design, Portfolio, Clean, Colorful, Brand, Services, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

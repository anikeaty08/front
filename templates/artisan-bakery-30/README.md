# Artisan Cake E-commerce Template

A reusable e-commerce template for artisan cake shops, featuring product catalogs, custom orders, blog content, cart flow, and contact forms.

## Project Details
- **Slug:** `artisan-bakery-30`
- **Views:** 35
- **Tags:** E-commerce, Food, Landing Page, Blog, Dark, Gradient, Clean, custom cakes, bakery, cart
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Artisan Bakery E-commerce Landing Page Template

A clean, modern artisan bakery e-commerce landing page template with shoppable menu, cart sidebar, and storefront details ready for local bakery brands.

## Project Details
- **Slug:** `artisan-bakery-52`
- **Views:** 32

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

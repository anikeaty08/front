# Ideal Bakery Restaurant Landing Page Template

A refined bakery and restaurant landing page template for showcasing menus, specialties, locations, and online ordering for local food businesses.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Artisan Bakery E-commerce Template

A reusable e-commerce template for artisan bakeries and cake shops to showcase collections, custom orders, and a smooth cart-to-checkout experience.

## Project Details
- **Slug:** `artisan-bakery-97`
- **Views:** 46
- **Tags:** E-commerce, Food, Landing Page, Clean, Minimal, Brand, bakery, cakes, custom orders
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

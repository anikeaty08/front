# Artisan Burger Restaurant Landing Page Template

A high-energy, bold restaurant landing page template designed for smashed burger brands and artisanal food services.

## Project Details
- **Slug:** `artisan-burger-23`
- **Views:** 5
- **Tags:** Food, Landing Page, Services, Colorful, Large Type, Animated, Clean

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

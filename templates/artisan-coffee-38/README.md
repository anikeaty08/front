# Artisan Coffee Shop Landing Page Template

A modern artisan coffee shop landing page template for showcasing your cafe, menu, location, and online orders with a stylish lifestyle aesthetic.

- **Slug:** `artisan-coffee-38`
- **Views:** 28

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

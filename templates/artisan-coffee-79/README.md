# Artisan Coffee E-commerce Template

A reusable e-commerce template for artisan coffee brands to showcase roasts, subscriptions, reviews, and direct-to-consumer shopping.

## Project Details
- **Slug:** `artisan-coffee-79`
- **Views:** 35
- **Tags:** E-commerce, Food, Landing Page, Brand, Clean, Minimal, coffee, subscription, roastery
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

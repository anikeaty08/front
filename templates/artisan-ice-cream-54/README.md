# Artisan Ice Cream Landing Page Template

A reusable artisan ice cream shop landing page template to showcase flavors, share your story, and guide visitors to nearby scoop shop locations.

## Project Details
- **Slug:** `artisan-ice-cream-54`
- **Views:** 419
- **Tags:** Landing Page, Food, Brand, Clean, Colorful, Gradient, Large Type, Minimal, E-commerce

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

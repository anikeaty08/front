# Artisanal Bakery Landing Page Template

A refined bakery website template for showcasing artisan breads, pastries, brand story, and pre-orders with an elegant, minimal storefront experience.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

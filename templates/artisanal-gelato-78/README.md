# Monello Gelato Shop Landing Page Template

A modern Monello Gelato-inspired landing page template for artisanal dessert shops to showcase flavors, story, and locations with a built-in contact form.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Artisanal Pizzeria Landing Page Template

A modern artisanal pizzeria landing page template for showcasing your menu, story, and online ordering with a clean, premium restaurant brand feel.

## Project Details
- **Slug:** `artisanal-pizzeria-60`
- **Views:** 28
- **Tags:** Landing Page, Food, Brand, Clean, Minimal, Gradient, Large Type, Restaurant, Pizzeria, Tailwind
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

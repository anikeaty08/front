# Artist E-commerce Landing Page Template

A refined e-commerce landing page template for artists and studios to showcase collections, sell artwork, and grow a collector email list.

## Project Details
- **Slug:** `artist-e-commerce-20`
- **Views:** 31
- **Tags:** E-commerce, Art & Design, Artist, Portfolio, Brand, Clean, Minimal, Large Type, Gradient

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

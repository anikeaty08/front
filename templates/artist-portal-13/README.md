# Artist Portal Template

A dark, modern template for artists and music brands to showcase tracks, streaming stats, and licensed beat bundles with clear purchase CTAs.

## Project Details
- **Slug:** `artist-portal-13`
- **Views:** 36

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

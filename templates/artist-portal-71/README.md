# Artist Portal Template

A dark, modern template for musicians and producers to showcase music catalogs, stream stats, and exclusive beat licensing offers in one portal.

## Project Details
- **Slug:** `artist-portal-71`
- **Views:** 34

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

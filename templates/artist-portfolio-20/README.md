# Visual Artist Portfolio Website Template

A refined portfolio website template for visual artists to showcase sculptures, paintings, photography, exhibitions, and contact details in a clean, gallery-style layout.

## Project Details
- **Slug:** `artist-portfolio-20`
- **Views:** 328
- **Tags:** Art & Design, Artist, Portfolio, Landing Page, Brand, Clean, Minimal, Large Type, Grid
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Artist & Venue Booking Landing Page Template

A reusable landing page template for music booking platforms that helps artists get discovered and venues find, evaluate, and book the right talent faster.

## Project Details
- **Slug:** `artist-venue-31`
- **Views:** 22
- **Tags:** Landing Page, Entertainment, Services, Clean, Minimal, Music, Booking, Artists, Venues
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Artist & Venue Exchange Landing Page Template

A reusable landing page template for artist-and-venue marketplaces, built to promote gigs, hosting, community trust, and global creative exchange.

## Project Details
- **Slug:** `artist-venue-79`
- **Views:** 21
- **Tags:** Landing Page, Entertainment, Travel, Social, Clean, Gradient, Minimal, community marketplace, music platform

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

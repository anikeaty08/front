# ARUN PRAJAPATI

A minimalist fashion e-commerce template for showcasing apparel, footwear, and seasonal collections with polished product grids and conversion-focused shopping CTAs.

## Project Details
- **Slug:** `arun-prajapati-fashion`
- **Views:** 20
- **Tags:** E-commerce, Fashion, Landing Page, Minimal, Clean, Brand, Style, apparel, storefront
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Asian Restaurant Landing Page Template

A polished restaurant website template for Asian eateries to showcase menus, signature dishes, hours, location, and dine-in or takeaway calls to action.

## Project Details
- **Slug:** `asian-restaurant-2`
- **Views:** 346
- **Tags:** Food, Landing Page, Services, Clean, Gradient, Large Type, Restaurant, Menu, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

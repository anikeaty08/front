# Aspire Chiropractic Clinic Landing Page Template

A modern chiropractic clinic landing page template for promoting local health services, pricing, FAQs, and bookings in a clean, trust-building layout.

- **Slug:** `aspirechiro`
- **Views:** 46

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

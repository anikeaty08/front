# Asrama Haji Jakarta

A reusable landing page template for official facility booking portals, designed for managing room, hall, and religious training reservations online.

## Project Details
- **Slug:** `asramahajijakarta`
- **Views:** 27
- **Tags:** Landing Page, Services, Clean, Minimal, Brand, Religious, Government, Booking, Portal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

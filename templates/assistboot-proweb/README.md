# AI E-commerce Landing Page Template

Template de landing page para Assistboot, una solución de chatbots IA para e-commerce, ideal para presentar servicios, testimonios y captar leads con formulario RGPD.

## Project Details
- **Slug:** `assistboot-proweb`
- **Views:** 229
- **Tags:** Landing Page, E-commerce, Technology, Brand, Dark, Clean, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

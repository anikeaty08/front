# Spiritual Association Landing Page Template

A reusable landing page template for spiritual associations, membership communities, and mission-led organizations promoting events, teachings, and member access.

## Project Details
- **Slug:** `association-incandescence`
- **Views:** 169
- **Tags:** Landing Page, Membership, Religious, Conference, Education, Brand, Dark, Minimal, Clean

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

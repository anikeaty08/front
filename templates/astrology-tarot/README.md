# Astrology & Tarot Landing Page Template

A celestial, dark-themed landing page template for astrologers and tarot readers to showcase services, testimonials, and pricing and attract new clients.

## Project Details
- **Slug:** `astrology-tarot`
- **Views:** 569
- **Tags:** Landing Page, Services, Brand, Dark, Gradient, Large Type, Minimal, Astrology, Tarot

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Minimal Furniture E-commerce Landing Page Template

A high-end, minimal e-commerce landing page template for showcasing modern furniture, interior objects, and atelier-style collections with a gallery-driven layout.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

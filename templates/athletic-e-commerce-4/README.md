# Athletic E-commerce Landing Page Template

A bold, colorful e-commerce landing page template for athletic footwear and apparel brands to showcase collections, highlight drops, and drive online sales.

## Project Details
- **Slug:** `athletic-e-commerce-4`
- **Views:** 18
- **Tags:** E-commerce, Landing Page, Fashion, Brand, Style, Colorful, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

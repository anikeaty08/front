# Atlantech Global Technology Landing Page Template

A dark, premium B2B technology landing page template for AI, cloud, and engineering consultancies to showcase services, tools, leadership, and consultation CTAs.

- **Slug:** `atlantech-global-22`
- **Views:** 21
- **Tags:** Technology, Landing Page, Business, Services, Brand, Dark, Clean, Gradient, Large Type, Futuristic

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Family Dental Clinic Landing Page Template

A modern, brandable template for family and cosmetic dental practices to showcase services, locations, and let patients request appointments online.

## Project Details
- **Slug:** `atlanticsmilesnj`
- **Views:** 39

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

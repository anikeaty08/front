# Personal Life OS Landing Page Template

A modular personal life OS landing page template for promoting a minimalist ecosystem of finance, pantry, health, and planning tools with integrated modules.

## Project Details
- **Slug:** `atlas-modular-80`
- **Views:** 26

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

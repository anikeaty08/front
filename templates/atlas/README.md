# Internal Knowledge Search UI Template

A reusable template for an internal knowledge and CRM search interface that lets teams query engagements, clients, documents, and contacts with synthesized insights.

## Project Details
- **Slug:** `atlas`
- **Views:** 49
- **Tags:** Technology, Landing Page, Brand, Clean, Minimal, Large Type, Dashboard, Internal Tool, Search UI, Knowledge Base
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

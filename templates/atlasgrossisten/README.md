# Atlas Grossisten E-commerce Website Template

A reusable e-commerce template for Atlas-style B2B supplement wholesalers, featuring dark athletic branding, product grids, deals, and newsletter capture.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

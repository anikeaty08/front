# Weather App Landing Page Template

A reusable landing page template for hyper-local weather apps and forecasting platforms, showcasing live radar, alerts, telemetry dashboards, and premium features.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

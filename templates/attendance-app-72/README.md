# Mobile Attendance App UI Template

A reusable mobile attendance app UI template for tracking check-ins, shifts, and logs with a dark, modern dashboard layout.

## Project Details
- **Slug:** `attendance-app-72`
- **Views:** 220
- **Tags:** Technology, Landing Page, Brand, Dark, Minimal, Futuristic, Mobile UI, Dashboard, Attendance, Workforce
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

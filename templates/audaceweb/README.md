# Local Services AI Agency Landing Page Template

A high-converting landing page template for local service and automation agencies showcasing CRM, AI, and web development services for regional businesses.

## Project Details

- **Views:** 32

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

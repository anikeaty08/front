# Pastor Sermon Prep Landing Page Template

A reusable landing page template for a voice-first sermon prep and ministry note-taking app, tailored to pastors and church leaders in private beta.

## Project Details
- **Slug:** `audinote-voiceapp`
- **Views:** 34
- **Tags:** Landing Page, Brand, Clean, Gradient, Large Type, Technology, Services, Religious, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

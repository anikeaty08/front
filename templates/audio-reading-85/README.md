# Audio App MVP Mobile UI Template

A sleek mobile audio library and player UI template for text-to-speech apps, perfect for quickly prototyping and launching your audio MVP.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

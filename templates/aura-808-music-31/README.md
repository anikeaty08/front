# Music Artist Landing Page Template

A dark, minimalist music artist landing page template to showcase a new single, link out to Spotify, YouTube, TikTok and promote your digital music project.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

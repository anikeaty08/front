# AURA — AI Personal Assistant Landing Page Template

A premium landing page template for AI personal assistants, productivity tools, workflow automation apps, and modern SaaS products.

AURA is designed around a clean skeuomorphic interface, soft blue gradients, floating UI cards, privacy-focused messaging, pricing, FAQ, and conversion-ready CTA sections. Perfect for products that help users capture ideas, summarize context, organize priorities, manage follow-ups, and move through their day with more clarity.

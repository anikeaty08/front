# Health & Wellness VSL Landing Page Template

A high-converting functional medicine landing page template featuring a video-sales-letter (VSL) hero section, trust indicators, and social proof for clinics.

## Project Details
- **Slug:** `aura-build-landing-14`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

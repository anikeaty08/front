# Health Consultation Landing Page Template

A reusable landing page template for functional health clinics and specialists to promote consultations, build trust, and convert patients seeking answers.

## Project Details
- **Slug:** `aura-build-landing-44`
- **Views:** 24
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Brand, testimonials, medical, consultation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

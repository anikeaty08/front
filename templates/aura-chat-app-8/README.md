# Aura Messaging App Landing Page Template

A polished, glassmorphism landing page template for a modern chat or messaging app, ready to customize for showcasing product features and downloads.

## Project Details
- **Slug:** `aura-chat-app-8`
- **Views:** 26
- **Tags:** Landing Page, Technology, Brand, Gradient, Clean, Minimal, Large Type, Colorful, App

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

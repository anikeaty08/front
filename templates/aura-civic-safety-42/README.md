# Civic Traffic Violation Reporting Portal Template

A reusable template for a civic online portal that lets citizens submit, track, and administer road traffic violation reports with secure workflows.

## Project Details
- **Slug:** `aura-civic-safety-42`
- **Views:** 4
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Minimal, Large Type, Traffic, Government Portal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

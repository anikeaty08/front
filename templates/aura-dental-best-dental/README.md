# Dental Clinic Landing Page Template

A modern dental clinic landing page template for showcasing services, treatments, and contact details, ideal for dentists and implant centers.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

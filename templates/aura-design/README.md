# Aura AI-Powered Site Builder Landing Page Template

Reusable landing page template for Aura, an AI-powered website builder that converts screenshots to code and offers visual Tailwind editing and premium templates.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Digital Reality Studio Landing Page Template

A dark, futuristic landing page template for digital reality studios offering UX/UI, 3D, gaming, and Web3 services to showcase work and capture project inquiries.

## Project Details
- **Slug:** `aura-digital-43`
- **Views:** 4
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Futuristic, Minimal, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

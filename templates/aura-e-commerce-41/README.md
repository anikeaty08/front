# Aura E-Commerce Landing Page Template

A reusable e-commerce landing page template designed for fashion and apparel stores to showcase products, promotions, and drive sales.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

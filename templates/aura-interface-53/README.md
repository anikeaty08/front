# Aura UI App Landing Page Template

A dark, futuristic landing page template for apps and SaaS products showcasing fluid generative backgrounds and interface integration.

## Project Details
- **Slug:** `aura-interface-53`
- **Views:** 6
- **Tags:** Landing Page, Technology, Brand, Dark, Futuristic, Minimal, Gradient, App, Dashboard

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

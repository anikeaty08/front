# AURA Sportsbook Mobile UI Template

A modern mobile sportsbook UI template for betting apps, featuring live odds, match cards, and bottom navigation ready to customize for your sports betting product.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

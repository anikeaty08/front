# AURA OS Admin Dashboard Template

AURA OS Admin Dashboard Template is a reusable dark UI template for creative studios to manage projects, CRM, and AI content workflows in one place.

## Project Details
- **Slug:** `aura-os-dark-98`
- **Views:** 14
- **Tags:** Landing Page, Brand, Technology, Dark, Minimal, Dashboard, Admin, AI, Portfolio, CRM
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

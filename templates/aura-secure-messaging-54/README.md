# aurachat

A dark, modern landing page template for promoting a secure messaging and calling app with features, testimonials, FAQ, and strong download-focused CTAs.

## Project Details
- **Slug:** `aura-secure-messaging-54`
- **Views:** 24
- **Tags:** Landing Page, Brand, Technology, Dark, Gradient, Minimal, Large Type, App Landing, Messaging, Secure Communication
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

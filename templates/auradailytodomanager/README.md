# Aura Daily To-Do Manager

A reusable Repeat task PWA UI template for creating a clean, mobile-first recurring task and reminders dashboard for productivity web apps.

## Project Details
- **Slug:** `auradailytodomanager`
- **Views:** 16
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Large Type, Gradient, Productivity, Task Management, PWA
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

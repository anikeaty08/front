# Freelance Pricing Engine Dashboard Template

A dark-mode dashboard template for a services-based pricing engine, ideal for freelancers and agencies to configure quotes, rates, and project estimates.

## Project Details
- **Slug:** `auraengine-pricing-6`
- **Views:** 35
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Gradient, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

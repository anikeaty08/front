# Aura Therapy Clinic Landing Page Template

A clean, modern landing page template for integrated therapy and wellness clinics to showcase services, build trust, and drive consultation bookings.

## Project Details
- **Slug:** `auratherapycentre`
- **Views:** 37
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Gradient, Large Type, Clinic, Wellness

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

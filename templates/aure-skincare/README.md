# Auré Natural Skincare Landing Page Template

This is a reusable landing page template designed for natural skincare brands to showcase products, collections, and engage customers with a clean, botanical aesthetic.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

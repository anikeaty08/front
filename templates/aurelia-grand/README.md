# Aurelia Grand Luxury Hotel Landing Page Template

A polished luxury hotel landing page template for showcasing premium rooms, spa, dining, and packages with integrated booking and contact sections.

## Project Details
- **Slug:** `aurelia-grand`
- **Views:** 33
- **Tags:** Landing Page, Travel, Services, Brand, Clean, Dark, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Aurora Mobile Experience Landing Page Template

A reusable mobile landing page template designed for art galleries and digital exhibitions to showcase collections, featured pieces, and membership benefits.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

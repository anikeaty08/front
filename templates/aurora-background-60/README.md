# Aurora Background Animation Template

A reusable WebGL background template for creating immersive aurora-style animated backdrops on landing pages, portfolios, and modern digital experiences.

- **Slug:** `aurora-background-60`
- **Views:** 63

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

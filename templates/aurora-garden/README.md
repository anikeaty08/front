# Smart Garden Control Dashboard Template

This template provides a modern, reusable dashboard UI for smart garden irrigation control, featuring automation, weather integration, and scheduling.

## Project Details
- **Slug:** `aurora-garden`
- **Views:** 1915
- **Tags:** Dashboard, Smart Garden, Irrigation, Automation, Weather Forecast, Scheduling, Water Usage, Controls, Analytics, Responsive
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

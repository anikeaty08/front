# Model Portfolio Landing Page Template

A reusable landing page template designed for international fashion models and brand ambassadors to showcase portfolios, campaigns, and contact information.

## Project Details
- **Slug:** `aurora`
- **Views:** 3113
- **Tags:** Landing Page, Portfolio, Fashion, Editorial, Runway, Brand Ambassador, Testimonials, Campaigns, Contact Form, Parallax

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Austin Solar Pros

A reusable landing page template for local solar installers and lead-gen brands to explain savings, incentives, and capture free estimate requests.

## Project Details
- **Slug:** `austin-solor-pros`
- **Views:** 70

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

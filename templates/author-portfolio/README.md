# Literary Author Portfolio and Book Store Template

A sophisticated and minimalist landing page template designed for authors to showcase their bibliography, sell signed copies, and engage their readers.

## Project Details
- **Slug:** `author-portfolio`
- **Views:** 329
- **Tags:** Portfolio, Landing Page, Clean, Minimal, Services, Brand, Animated, Dark

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

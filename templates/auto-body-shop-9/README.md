# Auto Body Shop Landing Page Template

A modern Auto Body & Paint Shop landing page template for showcasing services, gallery, testimonials, and contact details to convert visitors into workshop bookings.

## Project Details
- **Slug:** `auto-body-shop-9`
- **Views:** 7
- **Tags:** Landing Page, Services, Brand, Clean, Gradient, Large Type, Minimal, Automotive, Auto Repair
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

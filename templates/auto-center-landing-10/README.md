# Auto Center Landing Page Template

A modern Auto Center landing page template for automotive service shops to showcase services, build trust, and drive online appointment bookings.

## Project Details
- **Slug:** `auto-center-landing-10`
- **Views:** 14
- **Tags:** Landing Page, Services, Brand, Dark, Clean, Minimal, Automotive, Auto Center, Mechanic, Workshop
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

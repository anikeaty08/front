# Mobile Auto Detailing Landing Page Template

A premium landing page template for mobile auto detailing and ceramic coating businesses to showcase services, build trust, and drive bookings.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

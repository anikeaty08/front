# AUTO Driving App Landing Page Template

Modern landing page template for apps connecting driving students and independent instructors, optimized for waitlists, benefits, legal info, and FAQs.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

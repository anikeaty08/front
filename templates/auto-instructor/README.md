# AUTO Driving Lesson Landing Page Template

Modern landing page template for apps that connect driving students with independent instructors, featuring waitlist signup, benefits, FAQ, and legal info sections.

## Project Details
- **Slug:** `auto-instructor`
- **Views:** 30
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Large Type, Education, Driving App, Waitlist
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

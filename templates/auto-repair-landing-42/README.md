# Auto Repair Landing Page Template

A reusable landing page template for auto repair shops and car service businesses to showcase services, build trust, and drive appointment bookings.

## Project Details
- **Slug:** `auto-repair-landing-42`
- **Views:** 64
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Grid, automotive, auto repair, mechanic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

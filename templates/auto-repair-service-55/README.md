# Auto Repair Service Center Landing Page Template

A modern landing page template for an import and European auto repair service center, featuring services, reviews, FAQ, and a booking form for local shops.

## Project Details
- **Slug:** `auto-repair-service-55`
- **Views:** 56
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Minimal, Automotive, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Auto Repair Services Landing Page Template

A reusable landing page template for local auto repair shops to showcase service packages, NCT prep, reviews, pricing, and fast booking via WhatsApp.

## Project Details
- **Slug:** `auto-repair-services-14`
- **Views:** 49
- **Tags:** Landing Page, Services, Technology, Dark, Clean, Minimal, Automotive, Pricing, Local Business, WhatsApp
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

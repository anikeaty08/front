# Auto Repair Service Landing Page Template

A reusable landing page template for auto repair shops and mechanics to showcase services, build trust, and drive online booking requests.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

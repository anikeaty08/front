# Auto Repair Service Landing Page Template

Responsive one-page template for independent auto repair garages and mechanics to showcase services, testimonials, and contact bookings.

## Project Details
- **Slug:** `auto-repair-workshop-22`
- **Views:** 15
- **Tags:** Landing Page, Services, Business, Automotive, Clean, Minimal, Gradient, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

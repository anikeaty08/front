# Auto Service Booking Landing Page Template

A reusable landing page template for tire shops and auto services to promote online reservations, showcase services, and reduce phone-based booking friction.

## Project Details
- **Slug:** `auto-service-51`
- **Views:** 87
- **Tags:** Landing Page, Services, Technology, Clean, Dark, Minimal, Automotive, Booking, Reservation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

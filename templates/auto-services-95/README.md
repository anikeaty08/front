# Auto Service Landing Page Template

A reusable landing page template for local auto repair and car service businesses, featuring services, pricing, testimonials, and contact sections.

## Project Details
- **Slug:** `auto-services-95`
- **Views:** 134
- **Tags:** Landing Page, Services, Business, Clean, Dark, Gradient, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

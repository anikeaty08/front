# Auto servis 2

Dark, high-impact autoservis website template for professional car repair garages to showcase services, pricing, team, and bookings in a modern landing page layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

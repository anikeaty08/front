# Auto Tire & Wheel Landing Page Template

A modern BlueRidge-branded landing page template for tire shops and auto care centers to showcase premium tires, custom wheels, services, and seasonal offers.

- **Slug:** `auto-tire-shop-56`
- **Views:** 16
- **Tags:** Landing Page, Services, Business, Brand, Clean, Minimal, Gradient, Automotive, Tire Shop, Local Service

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

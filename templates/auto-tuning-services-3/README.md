# Auto Tuning Services Landing Page Template

A modern landing page template for car tuning and auto service businesses, ready to customize for bookings, diagnostics, and workshop contact inquiries.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

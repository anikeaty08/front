# Auto Wrap Services Landing Page Template

A reusable landing page template for premium auto wrap, PPF, window tinting, and detailing studios to showcase services, projects, and capture quote requests.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

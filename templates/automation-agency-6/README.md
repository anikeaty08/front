# Automation Agency Landing Page Template

A reusable dark-mode landing page template for automation and systems agencies to showcase capabilities, process, outcomes, and convert leads.

## Project Details
- **Slug:** `automation-agency-6`
- **Views:** 12
- **Tags:** Landing Page, Services, Technology, Dark, Minimal, Brand, Large Type, Gradient, Portfolio

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

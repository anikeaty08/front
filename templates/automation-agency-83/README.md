# Automation Services Landing Page Template

A dark, modern automation services landing page template for showcasing workflow, AI bot, and CRM integration offerings to service-based businesses.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

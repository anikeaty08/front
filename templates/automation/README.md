# Perfume E-commerce Landing Page Template

Bold, scent-driven e-commerce landing page template for fragrance decant shops to showcase collections, reviews, and CTAs that drive perfume sales.

- **Slug:** `automation`
- **Views:** 62

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

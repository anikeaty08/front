# Autoservis Business Landing Page Template

Clean autoservis landing page template for car repair businesses, ideal for showcasing services, contact details, and location in a modern, trustworthy layout.

## Project Details
- **Slug:** `automleziva`
- **Views:** 20
- **Tags:** Landing Page, Services, Business, Brand, Clean, Minimal, Large Type, Automotive, Local Service, Contact Focused
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

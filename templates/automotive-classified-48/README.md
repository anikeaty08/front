# Automotive Classifieds Listing Template

A modern eClassify-style template for automotive and vehicle classifieds, letting you quickly launch a responsive listings page with filters, grid/list views, and app promotion.

## Project Details
- **Slug:** `automotive-classified-48`
- **Views:** 55
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Large Type, E-commerce, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

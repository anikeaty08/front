# Automotive E-commerce Website Template

A reusable e-commerce template for automotive electronics brands selling plug-and-play vehicle upgrade kits, security modules, and accessories.

## Project Details
- **Slug:** `automotive-electronic-1`
- **Views:** 73

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

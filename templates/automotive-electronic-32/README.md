# Automotive Electronics E-commerce Template

A reusable e-commerce template for automotive electronics brands selling plug-and-play systems, harnesses, and installation support for enthusiast vehicles.

## Project Details
- **Slug:** `automotive-electronic-32`
- **Views:** 24
- **Tags:** E-commerce, Technology, Landing Page, Dark, Clean, Minimal, automotive, electronics, aftermarket, catalog
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

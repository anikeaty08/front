# GaragePro Auto Marketplace Landing Page Template

A modern GaragePro-style landing page template for an automotive B2B marketplace to list, browse, and manage professional garage ads and equipment.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

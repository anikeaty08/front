# Automotive E-commerce Landing Page Template

A reusable automotive technology template for selling plug-and-play vehicle upgrade kits with compatibility search, product showcases, reviews, and support.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

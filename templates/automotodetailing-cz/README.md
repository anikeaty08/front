# Automotodetailing Demo Web

A premium auto detailing landing page template for car care studios to showcase services, portfolio, trust signals, and booking CTAs.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Auto Repair Service Landing Page Template

Clean, modern autoservis landing page template for local car repair shops to showcase services, testimonials and contact details in Czech or any language.

## Project Details
- **Slug:** `autoservis-vzor`
- **Views:** 24
- **Tags:** Landing Page, Services, Business, Auto Repair, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

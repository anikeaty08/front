# autoservis3

A bold automotive service template for garages and repair shops to showcase services, pricing, team expertise, and booking details.

## Project Details
- **Slug:** `autoservis3`
- **Views:** 63
- **Tags:** Landing Page, Services, Technology, Dark, Minimal, Large Type, Automotive, Garage, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

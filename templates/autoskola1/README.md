# Driving School Landing Page Template

A modern Czech driving school website template for promoting courses, pricing, vehicles, and contact details, ready to customize for any autoškola.

## Project Details
- **Slug:** `autoskola1`
- **Views:** 28
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Technology, Education

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Auto Service Business Website Template

Modern multi-page template for local auto parts and car service businesses, ready to customize for branches, offers, and contact — built as a reusable website template.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

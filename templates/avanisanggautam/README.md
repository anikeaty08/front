# Indian Wedding Invitation Landing Page Template

Elegant Indian wedding invitation landing page template with Hindi typography, event timeline, and countdown timer for sharing ceremony details online.

## Project Details
- **Slug:** `avanisanggautam`
- **Views:** 19
- **Tags:** Wedding, Landing Page, Brand, Clean, Illustrative, Colorful, Large Type, Minimal, Event, Invitation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Medical & Dental Clinic Landing Page Template

A modern Medical & Dental Clinic landing page template for health practices to showcase services, doctors, and enable online appointment bookings.

## Project Details
- **Slug:** `avishka-healthcare`
- **Views:** 24
- **Tags:** Health, Landing Page, Services, Brand, Clean, Colorful, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

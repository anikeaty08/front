# Law Firm Landing Page Template

A reusable landing page template for criminal defense law firms and legal studios, designed to showcase expertise, trust, media presence, and private consultations.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

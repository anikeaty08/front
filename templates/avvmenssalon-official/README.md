# AVV Men's Salon Official Website

A premium dark-style men's salon landing page template for showcasing grooming services, pricing, and contact details for barbershops and salons.

## Project Details
- **Slug:** `avvmenssalon-official`
- **Views:** 560
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Minimal, Large Type, Barber, Salon, Grooming
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Car Wash & Cafe Landing Page Template

A modern Awash-themed landing page template for premium car wash, detailing services, and in-store cafe experiences, ready to customize for your business.

## Project Details
- **Slug:** `awashcarservice`
- **Views:** 9
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Gradient, Large Type, Car Wash, Cafe, Detailing
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

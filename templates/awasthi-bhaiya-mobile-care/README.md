# Mobile Repair Services Template

A reusable landing page template for phone repair shops and mobile accessory businesses, featuring booking, pricing tools, product listings, and service trust builders.

## Project Details
- **Slug:** `awasthi-bhaiya-mobile-care`
- **Views:** 28
- **Tags:** Landing Page, Services, Technology, E-commerce, Dark, Minimal, Clean, mobile repair, accessories
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

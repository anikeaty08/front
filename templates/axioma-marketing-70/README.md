# Axioma Marketing Landing Page Template

Axioma is a dark, futuristic marketing landing page template designed to help bold brands launch campaigns faster with immersive visuals and clear CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

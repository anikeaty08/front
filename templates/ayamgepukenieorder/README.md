# Food Ordering Web App Template

A sleek Nasi Ayam Gepuk food ordering web app template with customer flow and admin dashboard, ready to customize for your restaurant.

## Project Details
- **Slug:** `ayamgepukenieorder`
- **Views:** 34
- **Tags:** Food, E-commerce, Landing Page, Brand, Clean, Colorful, Minimal, Large Type, Restaurant, Ordering
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

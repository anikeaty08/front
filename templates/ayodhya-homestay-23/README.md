# Ayodhya Homestay Landing Page Template

A reusable landing page template for devotional homestays in Ayodhya, featuring rooms, amenities, gallery, reviews, and WhatsApp-based booking.

## Project Details
- **Slug:** `ayodhya-homestay-23`
- **Views:** 20
- **Tags:** Landing Page, Travel, Services, Brand, Clean, Minimal, Colorful, Homestay, Ayodhya, WhatsApp Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

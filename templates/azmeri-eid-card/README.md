# Eid Greeting Card Template

A reusable interactive greeting card template for sharing Eid wishes with a playful envelope reveal, cute animations, and heartfelt personal messages.

## Project Details
- **Slug:** `azmeri-eid-card`
- **Views:** 44
- **Tags:** Landing Page, Religious, Animated, Colorful, Illustrative, Minimal, greeting card, Eid, interactive card

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# B2B Lead Generation Landing Page Template

A reusable landing page template for B2B outbound agencies and SaaS teams to showcase cold email services, results, process, and discovery call CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

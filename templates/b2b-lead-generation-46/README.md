# B2B Lead Generation Landing Page Template

A reusable landing page template for B2B lead generation agencies and service businesses to promote cold email systems and book more qualified strategy calls.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# User Account Management Panel

Responsive account UI with profile card, personal info, payment settings, and navigation options using Tailwind CSS.

## Project Details
- **Slug:** `bSkBvcpm`
- **Views:** 121
- **Tags:** Account, Profile Card, Settings, Tailwind CSS, Responsive UI, Navigation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

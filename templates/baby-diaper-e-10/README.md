# Baby Care E-commerce Website Template

A clean, modern baby care e-commerce website template featuring product listings, detailed PDPs, cart, checkout, and account pages for online diaper brands.

- **Slug:** `baby-diaper-e-10`
- **Views:** 13

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

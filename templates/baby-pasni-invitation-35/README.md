# Pasni Ceremony Invitation Card Template

A sweet, baby-themed Pasni ceremony invitation card template you can customize to share your rice-feeding celebration details with loved ones.

## Project Details
- **Slug:** `baby-pasni-invitation-35`
- **Views:** 8
- **Tags:** Wedding, Social, Brand, Clean, Colorful, Minimal, Large Type, Illustrative
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

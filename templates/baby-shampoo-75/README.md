# Baby Shampoo Product Landing Page Template

A clean, modern product landing page template for promoting gentle baby shampoo or skincare products, ready to customize for your own brand and offer.

## Project Details
- **Slug:** `baby-shampoo-75`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

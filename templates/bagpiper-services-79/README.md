# Bagpiper Services Landing Page Template

A dark, elegant landing page template for professional bagpipers to showcase services, biography, and enquiries for weddings, funerals, and events.

## Project Details
- **Slug:** `bagpiper-services-79`
- **Views:** 9
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Minimal, Large Type, Musician, Wedding
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Bakery WhatsApp Ordering Landing Page Template

A conversion-focused landing page template for local bakeries to showcase custom cakes, reviews, and WhatsApp ordering with same-day delivery.

## Project Details
- **Slug:** `bakery-landing-31`
- **Views:** 27
- **Tags:** Landing Page, Food, Services, Brand, Clean, Colorful, Minimal, E-commerce, Bakery, WhatsApp Ordering

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

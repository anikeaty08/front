# Balkan Restaurant & Grill Landing Page Template

A premium culinary website template for restaurants and bars featuring an integrated menu filter, reservation booking system, and elegant dark theme.

## Project Details
- **Slug:** `balkan-cuisine-80`
- **Views:** 281

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

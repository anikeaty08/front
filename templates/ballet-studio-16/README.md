# For Ballet Studio

A reusable landing page template for ballet and dance studios to promote classes, locations, pricing, and bookings in a modern, conversion-focused layout.

## Project Details
- **Slug:** `ballet-studio-16`
- **Views:** 54
- **Tags:** Landing Page, Services, Brand, Clean, Colorful, Gradient, Large Type, Minimal, Art & Design, Entertainment
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

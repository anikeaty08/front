# Band Official Website Template

A reusable dark music website template for bands and artists to showcase media, tour dates, visuals, and booking inquiries in one bold page.

## Project Details
- **Slug:** `band-official-7`
- **Views:** 73
- **Tags:** Landing Page, Entertainment, Artist, Dark, Minimal, Large Type, Music, Band, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Bangermon 

A reusable landing page template for crypto trading campaigns that gamify engagement with ticket rewards, prize vaults, winner tracking, and wallet-based claims.

## Project Details
- **Slug:** `bangermon`
- **Views:** 59
- **Tags:** Landing Page, Technology, Dark, Clean, Gradient, Brand, crypto, trading, rewards, gaming
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

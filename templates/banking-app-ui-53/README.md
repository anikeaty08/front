# Mobile Banking App UI Template

A reusable mobile banking app template for showcasing account balances, transactions, and payment actions in a clean fintech dashboard interface.

## Project Details
- **Slug:** `banking-app-ui-53`
- **Views:** 84
- **Tags:** Technology, Landing Page, Clean, Minimal, Mobile App, Fintech, Banking, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

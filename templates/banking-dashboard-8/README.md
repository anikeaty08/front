# Modern Banking Dashboard UI Template

A clean, modern banking dashboard UI template for showcasing account overviews, cards, transfers, and transactions in financial or fintech web apps.

## Project Details
- **Slug:** `banking-dashboard-8`
- **Views:** 270
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Dashboard, Fintech, Banking UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

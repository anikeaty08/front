# Banking Operations Dashboard Template

A reusable banking dashboard template for trade finance teams to review customer profiles, extract document data, and manage verification workflows.

## Project Details
- **Slug:** `banking-operations-36`
- **Views:** 32
- **Tags:** Technology, Services, Documentation, Dashboard, Clean, Minimal, Banking, Fintech, Admin
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Barber Shop Landing Page Template

A modern dark-style barber shop landing page template for grooming studios to showcase services, reviews, and bookings with a premium Tel Aviv-inspired aesthetic.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

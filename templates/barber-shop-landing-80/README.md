# Barber Shop Landing Page Template

A modern dark-themed barber shop landing page template for showcasing services, reviews, and location details with clear calls to book appointments.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

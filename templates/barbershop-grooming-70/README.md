# Barbershop Grooming Landing Page Template

A premium dark-mode barbershop landing page template for grooming lounges to showcase services, atmosphere, and online booking in a stylish modern layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

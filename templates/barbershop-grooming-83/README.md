# Barbershop Landing Page Template

A modern dark-theme barbershop landing page template for premium grooming brands, featuring services, lookbook, and an effortless booking widget.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

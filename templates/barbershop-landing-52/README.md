# Barbershop Landing Page Template

A premium barbershop landing page template for grooming studios to showcase services, hours, location, and online booking in a modern, clean layout.

- **Views:** 504

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

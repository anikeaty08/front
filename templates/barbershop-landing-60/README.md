# Barbershop Landing Page Template

A modern dark-style barbershop landing page template featuring appointment booking, services, and portfolio sections for grooming brands.

- **Slug:** `barbershop-landing-60`
- **Views:** 16

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

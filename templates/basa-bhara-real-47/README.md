# Basa Bhara Real Estate Marketplace Template

A comprehensive Bengali-language real estate rental template for listing apartments, office spaces, and bachelor messes with full search functionality.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

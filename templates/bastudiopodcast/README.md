# Podcast Studio & Digital Design Landing Page Template

A premium dark-mode landing page template for podcast studios and digital design studios to showcase services, portfolio work, process, and contact CTAs.

## Project Details
- **Slug:** `bastudiopodcast`
- **Views:** 56
- **Tags:** Landing Page, Services, Technology, Brand, Art & Design, Portfolio, Dark, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

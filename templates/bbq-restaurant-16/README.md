# BBQ Restaurant Landing Page Template

A reusable landing page template for barbecue restaurants and smokehouses to showcase their story, menu, catering services, and contact details.

## Project Details
- **Slug:** `bbq-restaurant-16`
- **Views:** 36
- **Tags:** Landing Page, Food, Services, Dark, Clean, Minimal, Restaurant, BBQ, Smokehouse
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

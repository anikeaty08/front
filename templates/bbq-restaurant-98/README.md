# Home Time BBQ Restaurant Landing Page Template

A modern dark-style restaurant landing page template for barbecue and bakery venues to showcase menus, hours, location, and online ordering.

## Project Details
- **Slug:** `bbq-restaurant-98`
- **Views:** 24
- **Tags:** Food, Landing Page, Brand, Dark, Clean, Minimal, Restaurant, BBQ, Bakery, Cafe
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Bootcamp Challenge Accélération

A reusable landing page template for bootcamps, cohorts, and communities to organize team challenges, scoring systems, rules, rewards, and kickoff guidance.

## Project Details
- **Slug:** `bc-tribuinde-challenge`
- **Views:** 75
- **Tags:** Landing Page, Education, Membership, Services, Clean, Minimal, Community, Bootcamp, Challenge

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

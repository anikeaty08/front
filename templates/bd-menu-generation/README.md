# AI Restaurant Menu Landing Page Template

A reusable landing page template for AI-powered restaurant menu builders that showcases digital menu creation, QR publishing, and mobile-first previews.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

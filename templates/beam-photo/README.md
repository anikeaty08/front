# Photo Sharing Landing Page Template

This reusable landing page template is designed for photo sharing apps, highlighting privacy, original quality, live albums, and effortless sharing.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Beam Dental

A modern Beam Dental-inspired landing page template for dental clinics to showcase treatments, team, reviews, and online appointment booking.

## Project Details
- **Slug:** `beamdental`
- **Views:** 34
- **Tags:** Health, Landing Page, Services, Brand, Clean, Minimal, Large Type, Gradient, Chatbot
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

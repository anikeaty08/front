# Coffee Storytelling Landing Page Template

A dark, editorial-style landing page template for specialty coffee brands to share articles, gear picks, and newsletter-driven coffee culture content.

## Project Details
- **Slug:** `bean-water-boys`
- **Views:** 56
- **Tags:** Landing Page, Brand, Entertainment, Dark, Minimal, Coffee, Editorial, Blog Layout, Newsletter, Storytelling
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

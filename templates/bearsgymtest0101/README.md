# Gym & Fitness Landing Page Template

A modern, dark-themed gym landing page template for promoting local fitness centers, memberships, and contact details in a single high-converting layout.

- **Slug:** `bearsgymtest0101`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

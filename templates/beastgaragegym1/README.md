# Gym & Rehabilitation Landing Page Template

A reusable landing page template for gyms, fitness studios, and rehabilitation centers to showcase services, memberships, facilities, and client results.

## Project Details
- **Slug:** `beastgaragegym1`
- **Views:** 46
- **Tags:** Landing Page, Health, Services, Dark, Clean, Minimal, Fitness, Gym, Rehabilitation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

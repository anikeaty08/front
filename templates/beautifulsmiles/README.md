# Dental Clinic Landing Page Template

A modern, conversion-focused dental clinic landing page template for cosmetic, implant, and family dentistry practices ready to attract new patients.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

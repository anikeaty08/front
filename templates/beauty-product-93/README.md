# Beauty Product Feedback Form Template

A reusable survey template for beauty and haircare brands to collect structured post-purchase product feedback on texture, packaging, scent, and results.

## Project Details
- **Slug:** `beauty-product-93`
- **Views:** 55
- **Tags:** Landing Page, Brand, Services, Clean, Minimal, Fashion, feedback form, survey, beauty, haircare
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

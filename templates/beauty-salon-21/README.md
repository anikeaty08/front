# Beauty Salon Landing Page Template

A reusable beauty salon template for showcasing services, pricing, portfolio, testimonials, and online appointment booking in a luxury brand style.

## Project Details
- **Slug:** `beauty-salon-21`
- **Views:** 308
- **Tags:** Landing Page, Services, Fashion, Wedding, Minimal, Clean, Brand, luxury salon, beauty booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Beauty Salon Landing Page Template

A sleek, reusable template for beauty salons and unisex studios to showcase services, highlight expertise, and drive online appointment bookings.

## Project Details
- **Slug:** `beauty-salon-52`
- **Views:** 72
- **Tags:** Landing Page, Services, Fashion, Dark, Clean, Gradient, Minimal, booking, salon, beauty
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

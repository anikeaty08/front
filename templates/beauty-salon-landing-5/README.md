# Beauty Salon Landing Page Template

A reusable landing page template for beauty parlours and salons to showcase services, gallery, testimonials, and appointment booking.

## Project Details
- **Slug:** `beauty-salon-landing-5`
- **Views:** 42
- **Tags:** Landing Page, Services, Health, Clean, Elegant, Beauty Salon, Bridal Makeup, Appointment Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

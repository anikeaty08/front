# Beauty Studio Landing Page Template

A modern one-page beauty studio website template for salons offering manicure, cosmetics, epilation and massage services, ready to customize and reuse.

## Project Details
- **Slug:** `beauty-studio-38`
- **Views:** 6
- **Tags:** Landing Page, Services, Brand, Clean, Gradient, Minimal, Large Type, Beauty salon, Wellness studio, One-page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

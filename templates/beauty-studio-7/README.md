# Beauty Studio Landing Page Template

A refined landing page template for makeup studios and bridal beauty services to showcase offerings, portfolio, location, and booking details.

## Project Details
- **Slug:** `beauty-studio-7`
- **Views:** 23

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

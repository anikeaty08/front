# Ina Beauty Studio Plovdiv

A reusable landing page template for beauty studios, salons, and solo estheticians to showcase services, pricing, gallery highlights, and booking details.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

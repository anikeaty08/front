# Beauty Salon Dashboard UI Template

A reusable BeautyBoard dashboard template for salons and beauty studios to track daily bookings, schedules, and revenue in a clean, modern interface.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

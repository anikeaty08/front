# Bed & Breakfast Booking Inquiry Landing Page Template

A dark, elegant Bed & Breakfast booking inquiry landing page template with contact info, email form, and newsletter signup for boutique hotels and guesthouses.

## Project Details
- **Slug:** `bed-breakfast-19`
- **Views:** 6
- **Tags:** Landing Page, Travel, Services, Brand, Dark, Clean, Minimal, Large Type, Booking, Bed and Breakfast
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

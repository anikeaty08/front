# Cleaning Service Reviews Section Template

A reusable template for showcasing Google reviews and testimonials for cleaning service websites using embedded review widgets.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

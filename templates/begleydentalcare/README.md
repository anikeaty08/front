# Begley Dental

A clean, modern dental clinic landing page template for local practices to showcase services, team, and contact details with clear calls to book or call.

## Project Details
- **Slug:** `begleydentalcare`
- **Views:** 19
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, Large Type, Clinic, dentist, medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Artist Portfolio Website Template

A reusable website template for musicians and performance artists to showcase releases, tour dates, videos, and brand story in a cinematic format.

## Project Details
- **Slug:** `belle-sisoski-website`
- **Views:** 591
- **Tags:** Portfolio, Entertainment, Landing Page, Dark, Minimal, Animated, Artist, Music, Video, Personal Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

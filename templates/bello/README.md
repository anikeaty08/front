# AI Parenting Planner Landing Page Template

This reusable landing page template is designed for AI-powered family management apps to showcase features, pricing, testimonials, and encourage trial signups.

- **Slug:** `bello`
- **Views:** 1918
- **Tags:** Landing Page, AI, Family Planner, Features, Pricing, Testimonials, Dashboard, Scheduling, Collaboration, Reminders

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

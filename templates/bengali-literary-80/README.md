# Bengali Literary Magazine Website Template

A refined Bengali literary magazine website template for showcasing stories, poems, essays, and authors with reader and admin views.

## Project Details
- **Slug:** `bengali-literary-80`
- **Views:** 48
- **Tags:** Landing Page, Brand, Art & Design, Minimal, Clean, Bengali magazine, Literary, Stories, Poetry, Essays
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

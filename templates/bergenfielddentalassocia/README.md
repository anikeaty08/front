# Dental Clinic Landing Page Template

A modern, conversion-focused dental clinic landing page template for showcasing services, reviews, and online appointment requests for local practices.

## Project Details
- **Slug:** `bergenfielddentalassocia`
- **Views:** 30
- **Tags:** Landing Page, Health, Services, Brand, Clean, Colorful, Minimal, Large Type, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

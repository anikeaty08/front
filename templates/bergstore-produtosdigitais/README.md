# Digital Product Store Landing Page Template

A reusable e-commerce template for selling digital products with featured offers, pricing cards, instant-delivery messaging, and WhatsApp-based purchase CTAs.

## Project Details
- **Slug:** `bergstore-produtosdigitais`
- **Views:** 51
- **Tags:** E-commerce, Landing Page, Technology, Dark, Gradient, Clean, Minimal, digital products, WhatsApp sales
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

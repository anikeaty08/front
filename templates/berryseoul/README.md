# The Sweetest Way to Gift Korea

A reusable template for premium food and souvenir brands to showcase products, gift editions, travel-friendly benefits, and drive online orders.

## Project Details
- **Slug:** `berryseoul`
- **Views:** 896
- **Tags:** Food, E-commerce, Landing Page, Brand, Clean, Minimal, Gradient, Travel, gift shop, souvenir
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# berryseoul Landing Page Template

A reusable landing page template for Korean dessert brands and souvenir gift products, designed to showcase travel-friendly editions, brand story, and pop-up CTAs.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Artisanal Ice Cream Shop Landing Page Template

A charming landing page template for artisanal ice cream shops to showcase flavors, story, location, and drive visits or online orders.

## Project Details
- **Slug:** `besame-icecream`
- **Views:** 52
- **Tags:** Food, Landing Page, Brand, Clean, Colorful, Minimal, local business, restaurant, ice cream
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

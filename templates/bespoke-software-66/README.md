# Bespoke Software Studio Landing Page Template

A clean, conversion-focused landing page template for bespoke software studios and small agencies to showcase services, process, proof, and contact CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

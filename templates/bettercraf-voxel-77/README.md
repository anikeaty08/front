# BetterCraft Voxel Sandbox Template

A high-performance 3D voxel sandbox template built with Three.js and Tailwind CSS, featuring world generation, inventory systems, and crafting mechanics.

## Project Details
- **Slug:** `bettercraf-voxel-77`
- **Views:** 4
- **Tags:** Technology, Landing Page, Clean, Animated, Futuristic, 3D, Entertainment
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

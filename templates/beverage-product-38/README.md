# Beverage Brand Landing Page Template

A high-impact, refreshing beverage landing page template featuring crisp visuals, bento-style feature grids, and a modern dark aesthetic for drinks and consumer goods.

## Project Details
- **Slug:** `beverage-product-38`
- **Views:** 67
- **Tags:** Landing Page, Food, Dark, Animated, Clean, Technology

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

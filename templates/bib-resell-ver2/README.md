# Race Bib Marketplace Landing Page Template

A reusable landing page template for secure race bib marketplaces, helping athletes buy or sell entries with trust, verification, and clear onboarding.

## Project Details
- **Slug:** `bib-resell-ver2`
- **Views:** 32
- **Tags:** Landing Page, Sports, Marketplace, Technology, Services, Dark, Clean, Gradient, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

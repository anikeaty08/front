# Home Services and Plumbing Landing Page Template

A professional service-oriented landing page template designed for plumbing, electrical, and home maintenance businesses to drive emergency and service inquiries.

## Project Details
- **Slug:** `biggs-plumbers-65`
- **Views:** 16
- **Tags:** Services, Technology, Clean, Colorful, Minimal, Grid

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

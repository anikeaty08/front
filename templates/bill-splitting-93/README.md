# Bill Splitting Mobile App Template

A reusable mobile app template for splitting restaurant bills by item or evenly, helping groups track payments and confirm each person's share.

## Project Details
- **Slug:** `bill-splitting-93`
- **Views:** 74
- **Tags:** Landing Page, Technology, Food, Minimal, Clean, Mobile App, Finance, UI Kit
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Bill Tracking Dashboard Template

A reusable dark-mode dashboard template for tracking recurring bills, monitoring payment status, and managing reminders, reports, and exports.

## Project Details
- **Slug:** `bill-tracker-72`
- **Views:** 72
- **Tags:** Technology, Services, Dashboard, Landing Page, Dark, Clean, Minimal, Finance, Admin
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

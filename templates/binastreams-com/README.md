# Streaming Movies & Series Landing Page Template

A dark, cinematic streaming UI template for showcasing movies and series with hero banner, carousels, and Tailwind-based layout, ready to adapt for your platform.

## Project Details
- **Slug:** `binastreams-com`
- **Views:** 27
- **Tags:** Landing Page, Entertainment, Brand, Dark, Clean, Gradient, Large Type, Technology, Streaming, Movies
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

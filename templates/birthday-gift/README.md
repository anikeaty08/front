# Birthday Gift Landing Page

A reusable birthday celebration template for collecting wishes and digital gifts with a QR code, polished hero section, and festive interactive effects.

## Project Details
- **Slug:** `birthday-gift`
- **Views:** 44
- **Tags:** Landing Page, Social, Dark, Gradient, Minimal, Animated, Clean, celebration, birthday, QR code
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Birthday Greeting Landing Page Template

A reusable, elegant birthday landing page template for creating personalized online celebrations with heartfelt wishes and modern glassmorphism styling.

## Project Details
- **Slug:** `birthday-greeting-68`
- **Views:** 10
- **Tags:** Landing Page, Brand, Clean, Gradient, Minimal, Large Type, Birthday, Celebration, Personal Greeting
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

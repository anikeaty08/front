# Birthday Surprise Landing Page Template

A reusable birthday surprise template for creating an emotional, animated celebration page with photos, heartfelt messages, and optional music.

## Project Details
- **Slug:** `birthday-tribute-6`
- **Views:** 68
- **Tags:** Landing Page, Social, Animated, Dark, Gradient, Colorful, Clean, celebration, birthday, photo gallery
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

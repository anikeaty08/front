# Bistro Menu Restaurant Website Template

A modern bistro menu website template for restaurants and bars, showcasing dinner, brunch, late night dishes and drinks in a bold editorial layout.

## Project Details
- **Slug:** `bistro-menu-landing-11`
- **Views:** 15
- **Tags:** Food, Landing Page, Brand, Clean, Minimal, Large Type, Restaurant menu, Bistro, Editorial layout, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Construction & Demolition Services Landing Page Template

A modern, brand-ready landing page template for construction, demolition, and land hauling service companies to showcase capabilities and capture quote requests.

## Project Details
- **Slug:** `bits-dev-vertex`
- **Views:** 320
- **Tags:** Landing Page, Services, Business, Construction, Demolition, Clean, Minimal, Gradient, Large Type, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

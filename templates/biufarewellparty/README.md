# Event Farewell Celebration Template

An elegant and animated event invitation template featuring a glassmorphism countdown and cinematic motion graphics for farewell parties.

## Project Details
- **Slug:** `biufarewellparty`
- **Views:** 54
- **Tags:** Social, Wedding, Event, Animated, Clean, Colorful, Gradient, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

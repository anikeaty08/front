# B2B Enterprise CRM Dashboard Template

A clean and professional administrative dashboard template for managing company profiles, industrial sites, and commercial contracts.

## Project Details
- **Slug:** `bkw-dashboard`
- **Views:** 32
- **Tags:** Services, Technology, Clean, Dark, Minimal, Dashboard, CRM, Management
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Premium Leather Goods E-commerce Template

A reusable e-commerce template for premium leather goods brands to showcase products, arrivals, blog content, and a stylish shopping experience.

## Project Details
- **Slug:** `black-card-connections`
- **Views:** 42
- **Tags:** E-commerce, Fashion, Blog, Dark, Clean, Minimal, Brand, Landing Page, luxury retail, leather goods
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

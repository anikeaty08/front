# Natural Hair Salon Landing Page Template

A refined natural hair & beauty salon landing page template for showcasing services, testimonials, and bookings for salons in Accra or similar locations.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

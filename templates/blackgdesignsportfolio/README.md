# Creative Agency Portfolio Template

A reusable portfolio template for UI/UX agencies and creative studios to showcase services, experience, selected work, and a high-end digital brand presence.

## Project Details
- **Slug:** `blackgdesignsportfolio`
- **Views:** 11
- **Tags:** Portfolio, Landing Page, Services, Technology, Brand, Dark, Futuristic, Minimal, Animated, 3D
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

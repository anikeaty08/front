# Logistics Services Landing Page Template

A dark, modern logistics and courier services landing page template featuring services, quote form, news, and contact sections for freight brands.

## Project Details
- **Slug:** `blackhawkexpress`
- **Views:** 9
- **Tags:** Landing Page, Services, Brand, Dark, Clean, Futuristic, Large Type, Logistics, Courier, Freight
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

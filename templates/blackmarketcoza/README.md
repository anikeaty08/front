# Creator Market Landing Page Template

A dark, futuristic creator market landing page template showcasing digital product cards, cart checkout, and admin stats for selling creator kits.

## Project Details
- **Slug:** `blackmarketcoza`
- **Views:** 70
- **Tags:** Landing Page, Technology, Brand, Dark, Gradient, Minimal, Large Type, E-commerce, Portfolio

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Luxury Restaurant Landing Page Template

A dark, cinematic restaurant landing page template for high-end dining brands, featuring hero, curated menu, sustainability, reservations, and newsletter sections.

## Project Details
- **Slug:** `blackstone-restaurant`
- **Views:** 576
- **Tags:** Landing Page, Food, Brand, Dark, Minimal, Large Type, Gradient, Clean, 3D, Restaurant
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

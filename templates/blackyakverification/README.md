# Supplement Product Authentication Landing Page Template

A dark, secure product authentication landing page template with customer verification flow and admin dashboard for managing and validating serial codes.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Blind Spot Creative Studio

A premium landing page template for creative studios, photographers, and video teams to showcase services, process, portfolio work, and book audits.

## Project Details
- **Slug:** `blindspot-studio`
- **Views:** 80
- **Tags:** Landing Page, Services, Brand, Portfolio, Dark, Minimal, Clean, Photography, Video Production
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Concrete Product Landing Page Template

A reusable landing page template for showcasing and selling industrial concrete block products with product grids, benefits, and WhatsApp quote CTAs.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

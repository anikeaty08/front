# Industrial Manufacturing Blog Template

A clean and corporate blog news template designed for industrial manufacturing and supply chain management brands to showcase materials and innovations.

## Project Details
- **Slug:** `blog-news-29`
- **Views:** 15
- **Tags:** Technology, Services, Blog, Clean, Minimal, Corporate, Material Science
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

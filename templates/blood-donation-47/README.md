# Blood Donation Landing Page Template

A reusable landing page template for blood donation and emergency donor-matching platforms, designed to promote fast requests, donor signup, and hospital trust.

## Project Details
- **Slug:** `blood-donation-47`
- **Views:** 15
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, donation, emergency response, donor matching
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

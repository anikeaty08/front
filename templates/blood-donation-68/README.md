# Blood Donor Landing Page Template

A reusable landing page template for blood donor and emergency blood request platforms, designed to connect recipients with nearby donors fast.

- **Slug:** `blood-donation-68`
- **Views:** 28

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

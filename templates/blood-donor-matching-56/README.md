# Blood Donor Landing Page Template

A reusable landing page template for blood donation platforms that helps hospitals, nonprofits, and communities connect urgent blood requests with nearby donors fast.

## Project Details
- **Slug:** `blood-donor-matching-56`
- **Views:** 47
- **Tags:** Landing Page, Health, Non-profit, Services, Clean, Minimal, Technology, emergency response, blood donation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

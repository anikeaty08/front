# Flower Delivery App Template

A reusable flower delivery app template designed for browsing, customizing, and ordering fresh bouquets with same-day delivery.

## Project Details
- **Slug:** `bloom`
- **Views:** 957
- **Tags:** Landing Page, Mobile UI, Flower Delivery, Ecommerce, Orders, Bouquets, Tracking, Onboarding, Pricing, Testimonials
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Blooms Academy School Landing Page Template

A reusable school landing page template for modern academies, showcasing admissions, academic tiers, facilities, values, and testimonials in a clean, conversion-focused layout.

## Project Details
- **Slug:** `bloomsacademysuncity`
- **Views:** 28
- **Tags:** Landing Page, Education, Brand, Clean, Minimal, Large Type, Technology, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

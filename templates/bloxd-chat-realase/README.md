# BLOXD Chat App UI Template

A reusable BLOXD Chat UI template for real-time global and private messaging with owner controls, ideal for gaming or community chat web apps.

- **Slug:** `bloxd-chat-realase`
- **Views:** 17

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

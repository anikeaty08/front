# BMI Calculator App Template

A reusable BMI calculator template for health and wellness apps, featuring sleek result cards, intuitive sliders, and mobile-first tracking UI.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

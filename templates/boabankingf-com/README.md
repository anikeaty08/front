# Boa banking

A reusable banking dashboard template for online finance platforms, featuring account overviews, transaction history, transfers, and rewards UI.

## Project Details
- **Slug:** `boabankingf-com`
- **Views:** 35
- **Tags:** Technology, Services, Landing Page, Clean, Minimal, Dashboard, Banking, Finance
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

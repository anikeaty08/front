# Boat Finance Landing Page Template

A professional marine finance template designed to help buyers explore credit options for yachts, motorboats, and RIBs through a structured enquiry process.

## Project Details
- **Slug:** `boat-finance-80`
- **Views:** 16
- **Tags:** Services, Technology, Landing Page, Clean, Minimal, Dark, Corporate
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

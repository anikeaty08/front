# Boat Marketplace & Marina Parking Landing Page Template

A modern Boat Mania-inspired template for marketplaces that combine boat sales, marina berths, and parking services into one seamless landing page experience.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

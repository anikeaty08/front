# Athletic E-commerce Landing Page Template

Reusable e-commerce template for athletic and performance wear brands, featuring hero promo, best sellers grid, lifestyle video, and newsletter capture.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

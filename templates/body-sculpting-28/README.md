# Body Sculpting Spa Landing Page Template

A reusable landing page template for body sculpting and wellness spas to showcase non-invasive services, highlight benefits, and convert visitors into booked sessions.

## Project Details
- **Slug:** `body-sculpting-28`
- **Views:** 22
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Spa, Wellness, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

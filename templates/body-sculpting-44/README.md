# Body Sculpting Clinic About Page Template

A reusable About Us page template for non-surgical body sculpting and wellness clinics, featuring mission, services, locations, and conversion-focused CTAs.

## Project Details
- **Slug:** `body-sculpting-44`
- **Views:** 12
- **Tags:** Landing Page, Services, Health, Brand, Clean, Gradient, Large Type, Minimal, Clinic, Wellness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Bollywood Movie Directory Landing Page Template

A dark, cinematic landing page template for a Bollywood movie directory, perfect for showcasing folders, posters, and media details in a modern grid layout.

## Project Details
- **Slug:** `bollywood-movie-49`
- **Views:** 28
- **Tags:** Landing Page, Entertainment, Brand, Dark, Gradient, Grid, Minimal, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

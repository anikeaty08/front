# BookFlow Local Service Agency Template

A high-converting landing page template designed for local service businesses to automate bookings and follow-ups with a bold, neo-brutalism aesthetic.

## Project Details
- **Slug:** `bookflow-local-75`
- **Views:** 28
- **Tags:** Landing Page, Services, Technology, Clean, Colorful, Grid, Animated
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

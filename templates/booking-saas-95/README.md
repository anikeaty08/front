# Booking SaaS Landing Page Template

A reusable landing page template for online booking and reservation software, designed to help service businesses showcase features, pricing, and demos.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

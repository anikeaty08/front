# Bookstore E-commerce Dashboard Template

A reusable bookstore template for showcasing books, managing cart checkout, and running inventory, orders, and customer admin in one clean interface.

## Project Details
- **Slug:** `bookstore-e-commerce-36`
- **Views:** 29
- **Tags:** E-commerce, Landing Page, Technology, Clean, Minimal, Dashboard, Bookstore, Admin, Checkout
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

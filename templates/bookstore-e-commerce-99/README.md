# Bookstore E-commerce Website Template

A clean bookstore template for selling books online, showcasing catalogs, search, product cards, and contact features for modern reading brands.

## Project Details
- **Slug:** `bookstore-e-commerce-99`
- **Views:** 13
- **Tags:** E-commerce, Landing Page, Brand, Clean, Minimal, Grid, Bookstore, Books, Catalog, Retail
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Boondy Studio Landing Page Template

A sleek Boondy-inspired landing page template for brand and product design studios to showcase services, portfolio work, and capture new client inquiries.

## Project Details
- **Slug:** `boondy-brand-studio`
- **Views:** 12
- **Tags:** Landing Page, Brand, Services, Art & Design, Portfolio, Dark, Gradient, Minimal, Large Type, Futuristic

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# BornesLib Electric Charging Landing Page Template

Reusable landing page template for BornesLib-style electric vehicle charging apps, showcasing features, badge offer, and EV charging network benefits.

## Project Details
- **Slug:** `borneslib-electric`
- **Views:** 24
- **Tags:** Landing Page, Technology, Services, Clean, Minimal, Gradient, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Hotel Offers & Rooms Landing Page Template

A reusable landing page template for boutique hotels and B&Bs to showcase rooms, seasonal offers, and packages with a dark, modern glassmorphism design.

## Project Details
- **Slug:** `boutique-hotel-81`
- **Views:** 2
- **Tags:** Landing Page, Travel, Services, Brand, Dark, Clean, Gradient, Large Type, Minimal, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

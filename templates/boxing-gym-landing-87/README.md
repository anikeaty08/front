# Boxing Gym Landing Page Template

A bold, dark-theme boxing gym landing page template for promoting training programs, culture, and membership signups for local fitness or boxing centers.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Packaging Manufacturing Landing Page Template

A modern Boxmeninc-style landing page template for industrial packaging manufacturers to showcase capabilities, technology, sustainability, and contact CTAs.

## Project Details
- **Slug:** `boxmenincbengaluru`
- **Views:** 30
- **Tags:** Landing Page, Business, Services, Technology, Brand, Clean, Minimal, Grid, Large Type, Industrial Packaging
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

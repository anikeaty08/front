# Brain Battle Quiz App Template

Mobile-first Brain Battle quiz app template for multilingual student learning, featuring class and subject selection, timed questions, and gamified scoring.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

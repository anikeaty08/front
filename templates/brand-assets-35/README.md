# Brand Assets Logo System Template

A reusable template for showcasing animated primary logos, app icons, and navigation brand lockups for digital products and creative brands.

## Project Details
- **Slug:** `brand-assets-35`
- **Views:** 39
- **Tags:** Brand, Brand Guidelines, Landing Page, Technology, Art & Design, Clean, Dark, Minimal, Animated

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

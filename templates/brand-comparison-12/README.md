# Brand Comparison Landing Page Template

A reusable landing page template for visualizing brand positioning and competitive advantages with a polished Venn-style comparison layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

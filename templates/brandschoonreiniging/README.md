# Cleaning Services Landing Page Template

A clean, conversion-focused template for local cleaning and maintenance businesses to showcase services, testimonials, and capture quote requests.

## Project Details
- **Slug:** `brandschoonreiniging`
- **Views:** 64
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Brand, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

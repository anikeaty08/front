# Brasbeer3

A reusable landing page template for traditional African beer brands, featuring age-gate, heritage storytelling, packaging sustainability, media gallery, and contact form.

## Project Details
- **Slug:** `brasbeer3`
- **Views:** 60
- **Tags:** Landing Page, Brand, Food, Clean, Colorful, Large Type, Minimal, E-commerce, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

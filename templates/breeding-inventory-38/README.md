# Pigeon Breeding Dashboard UI Template

A clean, modern dashboard template for pigeon breeders to manage breeding, inventory, and lineage records in a reusable web app layout.

## Project Details
- **Slug:** `breeding-inventory-38`
- **Views:** 80
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Dashboard, Management, Admin, Inventory, Breeding
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

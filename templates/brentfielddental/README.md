# Brentfield Dental

A modern, patient-focused dental clinic landing page template for promoting services, reviews, and appointments for local practices.

## Project Details
- **Slug:** `brentfielddental`
- **Views:** 16
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Gradient, Dental, Clinic

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

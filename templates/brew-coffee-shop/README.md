# Futuristic Coffee Shop Landing Page Template

A reusable landing page template for coffee shops and cafes, featuring a cyberpunk menu, product highlights, and bold ordering CTAs.

## Project Details
- **Slug:** `brew-coffee-shop`
- **Views:** 574
- **Tags:** Landing Page, Food, E-commerce, Futuristic, Dark, Animated, Gradient, Technology, Menu
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

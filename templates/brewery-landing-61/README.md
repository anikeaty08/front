# Brewery Brand Landing Page Template

A reusable brewery website template for showcasing heritage, signature beers, hospitality venues, tours, and local retail offers with warm brand storytelling.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Bridal Boutique Landing Page Template

A customizable landing page template for women-owned bridal gown shops to showcase custom wedding collections, reviews, and appointments.

## Project Details
- **Slug:** `bridal-shop-landing-31`
- **Views:** 29

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

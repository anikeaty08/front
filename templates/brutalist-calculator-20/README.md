# Brutalist Calculator UI Template

A reusable brutalist calculator UI template with keyboard support and 8-bit SFX, perfect for embedding in web apps, landing pages, or product demos.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Brutalist Designer Portfolio Template

A dark, brutalist portfolio template for digital product designers to showcase selected work, skills, and contact details in a bold, system-like layout.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

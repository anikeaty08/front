# Mobile Art Gallery App UI Template

A dark, minimal mobile app UI template for showcasing, curating, and sharing contemporary artworks and photo collections on a sleek gallery-style interface.

- **Slug:** `bside-art-tasfia-7`
- **Views:** 67

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Motion Lettering Studio Web App Template

A customizable template for a motion lettering studio-style web app UI, letting users design animated text and render MP4 exports for creative projects.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

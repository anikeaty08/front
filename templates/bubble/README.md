# Childcare Center Landing Page Template

This reusable template is designed for childcare centers to showcase trusted care, programs, and parent engagement with warm, play-based learning experiences.

## Project Details
- **Slug:** `bubble`
- **Views:** 1456
- **Tags:** Landing Page, Hero, Features, Programs, Testimonials, Contact, CTA, Responsive, Childcare, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

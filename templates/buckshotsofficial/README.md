# Restaurant Roadhouse Landing Page Template

A modern dark-theme restaurant landing page template for roadhouses and grills, featuring menu highlights, reviews, and contact details to attract diners.

## Project Details
- **Slug:** `buckshotsofficial`
- **Views:** 34
- **Tags:** Landing Page, Food, Brand, Dark, Clean, Minimal, Large Type, Restaurant, BBQ, Roadhouse
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

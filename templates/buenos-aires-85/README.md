# Buenos Aires Tour Guide Landing Page Template

A modern landing page template for private Buenos Aires tour guides to showcase excursions, story-driven routes, and capture booking inquiries.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mobile Banking Transfer Flow Template

A reusable mobile banking app template for sending money, verifying recipients, entering a PIN, and handling transfer states in a clean financial UI.

## Project Details
- **Slug:** `build-a-realistic-97`
- **Views:** 42
- **Tags:** Technology, Landing Page, Clean, Minimal, Services, mobile banking, fintech, payment flow
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Eco‑Village Community Landing Page Template

A dark, nature-forward landing page template for eco‑villages and intentional communities to showcase territory, values, and waitlist applications.

## Project Details
- **Slug:** `build-a-single-15`
- **Views:** 26
- **Tags:** Landing Page, Brand, Environmental, Clean, Dark, Large Type, Minimal, Travel, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Building Management Education Landing Page Template

A modern template for building management and cleaning education providers to showcase training paths, exams, and resources with a professional, multilingual layout.

## Project Details
- **Slug:** `building-management-57`
- **Views:** 45
- **Tags:** Landing Page, Education, Services, Brand, Clean, Minimal, Gradient, Large Type, Technology

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Buildshop Weekend Bootcamp Landing Page Template

A dark, minimalist Buildshop landing page template for coding bootcamps or cohort-based courses to promote curriculum, classes, testimonials, and applications.

## Project Details
- **Slug:** `buildshop`
- **Views:** 382
- **Tags:** Landing Page, Education, Brand, Clean, Dark, Minimal, Technology, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

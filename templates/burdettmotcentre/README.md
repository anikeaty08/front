# Local MOT Garage Landing Page Template

A clean, ready-to-edit landing page template for local MOT garages and auto service centres to showcase services, reviews, and contact details.

## Project Details
- **Slug:** `burdettmotcentre`
- **Views:** 37
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Automotive, Local Business, MOT Centre, Garage
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

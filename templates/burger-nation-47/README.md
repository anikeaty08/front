# Burger Nation Food & Restaurant Template

A high-performance restaurant landing page template featuring multi-location management, dynamic menu sections, and WhatsApp ordering integration for local businesses.

## Project Details
- **Slug:** `burger-nation-47`
- **Views:** 24
- **Tags:** Food, Landing Page, Services, Clean, Dark, Animated, Responsive
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Media Buyer Business Card Template

A sleek business card template for media buyers, marketers, and personal brands to present contact details with a premium, modern look.

## Project Details
- **Slug:** `business-card-1`
- **Views:** 14
- **Tags:** Brand, Services, Portfolio, Dark, Minimal, Clean, Business card, Personal branding, Professional
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

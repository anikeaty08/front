# Business SaaS Landing Page Template

A reusable landing page template for AI-powered business management platforms, featuring CRM, payments, analytics, pricing, and multi-audience product sections.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Video Content Dashboard UI Template

A reusable dashboard UI template for video-led business teams to manage workflows, repurpose content, and track multi-channel distribution outcomes.

## Project Details
- **Slug:** `business-video-6`
- **Views:** 3

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

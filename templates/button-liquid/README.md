# Liquid Glass UI Button Template

A reusable template showcasing liquid glass, camera-reactive buttons you can plug into modern interfaces for interactive, futuristic CTAs.

## Project Details
- **Slug:** `button-liquid`
- **Views:** 22
- **Tags:** Landing Page, Technology, Art & Design, Futuristic, Gradient, Animated, Minimal, Large Type, UI Component, Glassmorphism
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Interactive Button Component Gallery Template

A reusable template showcasing interactive, animated CTA button components you can copy, customize, and drop into any modern landing page or website.

## Project Details
- **Slug:** `buttons`
- **Views:** 33
- **Tags:** Landing Page, Technology, Art & Design, Gradient, Animated, Clean, Dark, Large Type, UI components, Buttons
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

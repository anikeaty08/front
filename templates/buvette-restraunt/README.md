# Buvette restraunt

A minimalist coffee shop landing page template for intimate cafés, featuring menu highlights, gallery, FAQs, and a contact form to attract local guests.

## Project Details
- **Slug:** `buvette-restraunt`
- **Views:** 86
- **Tags:** Landing Page, Food, Brand, Clean, Minimal, Large Type, Café, Restaurant
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

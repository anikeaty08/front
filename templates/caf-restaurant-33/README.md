# Café & Restaurant Landing Page Template

A modern café and restaurant landing page template for showcasing menus, reviews, gallery, and contact details for local dining businesses.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

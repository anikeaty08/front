# Café Botanica

A refined Café Botanica-inspired coffee shop landing page template for showcasing menus, storytelling, and online orders with a warm, artisanal brand feel.

## Project Details
- **Slug:** `cafe-botanica`
- **Views:** 16
- **Tags:** Landing Page, Food, Brand, Clean, Minimal, Large Type, Gradient, Coffee shop, cafe
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

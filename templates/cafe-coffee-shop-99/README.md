# Café Landing Page Template

A refined café landing page template for specialty coffee shops to showcase menu, story, gallery, and location details with an elegant, modern aesthetic.

## Project Details
- **Slug:** `cafe-coffee-shop-99`
- **Views:** 31
- **Tags:** Landing Page, Food, Brand, Clean, Minimal, Gradient, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

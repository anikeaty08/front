# Restaurant QR Menu Platform Template

A reusable template for a QR-powered restaurant menu and admin platform, featuring digital menu management, QR code generation, and WhatsApp ordering.

## Project Details
- **Slug:** `cafe-digital-52`
- **Views:** 135

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dark Cafe & Dining Landing Page Template

A sleek dark-mode cafe and dining landing page template with interactive menu, cart, and WhatsApp ordering for modern restaurants and coffee shops.

## Project Details
- **Slug:** `cafe-dining-landing-36`
- **Views:** 61
- **Tags:** Food, Landing Page, Brand, Dark, Clean, Gradient, Large Type, Restaurant, Cafe, WhatsApp Ordering, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

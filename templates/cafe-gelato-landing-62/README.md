# Monello Gelato Café Landing Page Template

A cozy winter café website template for Monello-style gelato & coffee shops, perfect as a reusable landing page to showcase menu, story, and contact details.

## Project Details
- **Slug:** `cafe-gelato-landing-62`
- **Views:** 19
- **Tags:** Landing Page, Food, Brand, Clean, Minimal, Colorful, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Cafe Hott Coffee Shop Landing Page Template

A modern cafe and coffee shop landing page template showcasing menu, custom drink builder, and locations for coffee brands and local cafes.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

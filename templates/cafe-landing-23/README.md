# Cafe Restaurant Landing Page Template

A reusable cafe and restaurant landing page template for showcasing menus, ambiance, reviews, and table reservations with a modern premium feel.

## Project Details
- **Slug:** `cafe-landing-23`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Cafe Landing Page Template

A reusable cafe landing page template for coffee shops and roasteries to showcase menus, ambiance, testimonials, and table reservations.

## Project Details
- **Slug:** `cafe-landing-24`
- **Views:** 508
- **Tags:** Landing Page, Food, Services, Dark, Elegant, Minimal, Restaurant, Cafe, Reservation, Menu
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

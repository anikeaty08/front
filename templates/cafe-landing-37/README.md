# Cafe 

A reusable cafe landing page template for coffee shops and local eateries to showcase menus, ambiance, reviews, location, and online ordering.

## Project Details
- **Slug:** `cafe-landing-37`
- **Views:** 34
- **Tags:** Landing Page, Food, Services, Clean, Minimal, Brand, cafe, coffee shop, restaurant, local business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

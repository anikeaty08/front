# Cafe Restaurant Landing Page Template

A modern cafe and restaurant landing page template for showcasing menu, reviews, and location details with a warm, minimal coffee-inspired design.

## Project Details
- **Slug:** `cafe-landing-52`
- **Views:** 690
- **Tags:** Landing Page, Food, Services, Brand, Clean, Minimal, Gradient, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

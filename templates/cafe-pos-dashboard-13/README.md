# Cafe POS UI Dashboard Template

A modern cafe point-of-sale UI template for managing orders, menus, and checkout in coffee shops and bakeries.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Cafe Price Heatmap Web App Template

A reusable template for a cafe price tracker web app with list and map heatmap views, ideal for visualizing coffee prices across cities or regions.

## Project Details
- **Slug:** `cafe-price-heatmap-12`
- **Views:** 12
- **Tags:** Landing Page, Services, Food, Clean, Minimal, Gradient, Large Type, Technology, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

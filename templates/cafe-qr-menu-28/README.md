# Cafe QR Menu SaaS Dashboard Template

A modern SaaS dashboard template for cafe and restaurant owners to manage QR menus, track orders, and run promotions with upgradeable free vs premium states.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

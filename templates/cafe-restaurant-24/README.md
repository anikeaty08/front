# Café Restaurant Landing Page Template

A modern café and restaurant landing page template for showcasing menus, galleries, reviews, and online ordering for local dining brands.

## Project Details
- **Slug:** `cafe-restaurant-24`
- **Views:** 39
- **Tags:** Food, Landing Page, Brand, Clean, Colorful, Minimal, Restaurant, Café, Tailwind CSS, Responsive
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Cafe Restaurant Landing Page Template

A warm, editorial-style template for cafés and small restaurants to showcase weekly specials, menus, opening hours, and brand story.

## Project Details
- **Slug:** `cafe-restaurant-4`
- **Views:** 23
- **Tags:** Food, Landing Page, Services, Clean, Minimal, Editorial, Restaurant, Cafe, Menu

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

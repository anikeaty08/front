# Cafe & Restaurant Landing Page Template

A warm, heritage-inspired cafe & restaurant landing page template for showcasing menus, live events, hours, and bookings in a single elegant layout.

## Project Details
- **Slug:** `cafe-restaurant-65`
- **Views:** 14
- **Tags:** Landing Page, Food, Brand, Clean, Minimal, Large Type, Restaurant, Cafe, Events, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Cafe & Restaurant Landing Page Template

A modern Prakren Cafe-inspired landing page template for cozy cafes and restaurants, featuring menu highlights, online ordering, reservations, reviews, and contact.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

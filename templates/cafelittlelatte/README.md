# Little Latte Cafe Landing Page Template

A clean, editorial-style coffee shop landing page template designed for cafes, roasteries, and small-batch food service businesses.

## Project Details
- **Slug:** `cafelittlelatte`
- **Views:** 208
- **Tags:** Food, Services, Landing Page, Clean, Large Type, Minimal, Grid
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

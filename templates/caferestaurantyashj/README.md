# Cafe Landing Page Template

A warm, modern template for cafés and coffee shops to showcase menus, bestsellers, gallery highlights, reviews, and online ordering.

## Project Details
- **Slug:** `caferestaurantyashj`
- **Views:** 520
- **Tags:** Landing Page, Food, Services, Brand, Clean, Minimal, Warm tones, Cafe, Restaurant
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Aesthetic Clinic Landing Page Template

A refined landing page template for consultant-led aesthetic clinics and regenerative medicine practices to showcase treatments, technology, and bookings.

## Project Details
- **Slug:** `cahome3`
- **Views:** 98
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Luxury, Medical, Aesthetics

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

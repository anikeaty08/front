# Fashion Landing Page Template

A dark, editorial landing page template for avant-garde, genderless fashion or resortwear brands to showcase collections and attract investment partners.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

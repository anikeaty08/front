# Cakeria Dessert & Bar Landing Page Template

A pastel, dessert-focused landing page template for cafes and bakeries to showcase organic cakes, locations, and social profiles with a modern, cozy feel.

## Project Details
- **Slug:** `cakeria-dessert-29`
- **Views:** 25
- **Tags:** Landing Page, E-commerce, Food, Brand, Clean, Colorful, Illustrative, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Aesthetic Clinic SaaS Landing Page Template

A reusable landing page template for aesthetic clinics and estheticians to promote budget, pricing, and PDF quote software with free-trial conversion.

## Project Details
- **Slug:** `calculadoraestetica`
- **Views:** 73
- **Tags:** Landing Page, Technology, Health, Services, Clean, Minimal, SaaS, Pricing, Beauty Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

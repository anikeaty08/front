# HealthOS BMI Dashboard UI Template

A modern HealthOS BMI dashboard template for health and wellness apps, featuring an interactive BMI calculator layout you can reuse and customize.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

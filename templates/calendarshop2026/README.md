# Calendar E-commerce Landing Page Template

A modern e-commerce landing page template for showcasing and selling South African-themed calendars, greeting cards, and stationery products online.

## Project Details
- **Slug:** `calendarshop2026`
- **Views:** 23
- **Tags:** E-commerce, Landing Page, Brand, Clean, Minimal, Large Type, Technology, Travel
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

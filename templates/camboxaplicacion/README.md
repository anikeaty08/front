# GymFlow Admin Dashboard Template

Dark-mode GymFlow admin dashboard template for managing gym member access, attendance check-ins, and evaluation emails across multiple branches.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

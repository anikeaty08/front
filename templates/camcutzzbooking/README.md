# Cam Cutz Booking System

A reusable landing page template for barbers and grooming professionals to showcase services, build trust, and accept appointment bookings online.

## Project Details
- **Slug:** `camcutzzbooking`
- **Views:** 29
- **Tags:** Landing Page, Services, Brand, Dark, Clean, Minimal, Booking, Barbershop, Grooming
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

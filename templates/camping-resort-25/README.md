# Camping Resort Landing Page Template

A modern Scandinavian-style camping resort landing page template for promoting campgrounds, glamping, and nature stays with booking and contact flows.

## Project Details
- **Slug:** `camping-resort-25`
- **Views:** 60
- **Tags:** Landing Page, Travel, Services, Brand, Clean, Minimal, Large Type, Gradient, Camping, Nature
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

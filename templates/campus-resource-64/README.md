# Campus Resource Manager Dashboard Template

A modern Campus Resource Manager dashboard template for universities and colleges to manage bookings, equipment, and facilities in one clean interface.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

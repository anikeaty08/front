# Camzy App

A modern app landing page template for Camzy-style dual-camera recording apps, showcasing features, how it works, FAQ, and strong App Store download CTAs.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

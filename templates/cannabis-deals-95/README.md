# Cannabis Deals Landing Page Template

A reusable landing page template for cannabis deal directories and dispensary marketplaces to showcase local offers, categories, and alert signups.

- **Slug:** `cannabis-deals-95`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

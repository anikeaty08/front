# Canny-Style SaaS Feedback Landing Page Template

A dark, modern SaaS landing page template inspired by Canny/Linear for showcasing product feedback boards, roadmaps, changelogs, and integrations.

## Project Details
- **Slug:** `canny-style-product-2`
- **Views:** 25
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Grid, Minimal, Large Type, SaaS, Product Feedback
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Canvas Design System Landing Page Template

A reusable landing page template for showcasing a comprehensive design system including icons, data visualization, micro-interactions, decorative elements, and UI components.

## Project Details
- **Slug:** `canvas-design-42`
- **Views:** 64
- **Tags:** Landing Page, Design System, Icons, Data Visualization, Micro-interactions, UI Components, Decorative Elements, Dark Mode, Tailwind CSS, Accessibility
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Canvas Web Builder Landing Page Template

A modern Canvas web builder landing page template for showcasing visual editing, templates, pricing, and FAQs to convert designers into users.

## Project Details
- **Slug:** `canvas-website-30`
- **Views:** 58
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Gradient, Large Type, Portfolio, SaaS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

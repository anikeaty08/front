# Video Caption Tool Landing Page Template

A reusable landing page template for promoting an Adobe-based caption animation tool with feature highlights, pricing plans, and conversion-focused CTAs.

## Project Details
- **Slug:** `caption-tool-10`
- **Views:** 16
- **Tags:** Landing Page, Technology, Dark, Animated, Gradient, Clean, SaaS, Video Editing, Captions
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Car Dashboard UI Template

A sleek, dark-mode car dashboard UI template for in-vehicle infotainment screens, ready to customize for navigation, music, calls, and maintenance controls.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

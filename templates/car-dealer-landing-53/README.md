# Car Dealer Landing Page Template

A clean, modern car dealer landing page template for showcasing used cars, import services, and financing options for local automotive dealerships.

## Project Details
- **Slug:** `car-dealer-landing-53`
- **Views:** 17
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Large Type, Technology, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Auto Detailing Services Landing Page Template

A reusable landing page template for premium car cleaning and auto detailing businesses to showcase services, reviews, pricing, and booking.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

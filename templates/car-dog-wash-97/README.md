# Car & Dog Wash Landing Page Template

A modern single-location car and dog wash landing page template for promoting self-service bays, hours, services, and driving directions.

## Project Details
- **Slug:** `car-dog-wash-97`
- **Views:** 24
- **Tags:** Landing Page, Services, Business, Local, Clean, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

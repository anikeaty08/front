# Car Garage Dashboard Template

A reusable dark UI template for racing games and automotive apps, featuring a 3D-style garage dashboard, tuning controls, telemetry panels, and action CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

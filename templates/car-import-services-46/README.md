# Car Import Landing Page Template

A modern dark-themed landing page template for European car import and sales businesses, featuring services, featured cars, process steps, testimonials, and contact form.

## Project Details
- **Slug:** `car-import-services-46`
- **Views:** 11
- **Tags:** Landing Page, Services, Brand, Dark, Clean, Gradient, Minimal, Real Estate, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

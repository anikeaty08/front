# Car Service Booking App UI Template

Mobile-first template for a car service booking app flow, showcasing entry, package selection, scheduling, and confirmation screens ready for reuse.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

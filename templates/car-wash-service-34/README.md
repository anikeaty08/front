# Car Wash Service Landing Page Template

A modern Vietnamese car wash & detailing landing page template for promoting services, pricing, and online booking for local auto care shops.

## Project Details
- **Slug:** `car-wash-service-34`
- **Views:** 43
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Gradient, Large Type, Car wash, Auto detailing

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

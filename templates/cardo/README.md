# Logistics Landing Page Template

Bold, dark logistics landing page template for cargo and freight services, featuring routes, process steps, benefits, and a conversion-focused quote request form.

## Project Details
- **Slug:** `cardo`
- **Views:** 20
- **Tags:** Landing Page, Services, Brand, Dark, Gradient, Grid, Large Type, Minimal, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Trading Card Marketplace Landing Page Template

A high-converting landing page template for TCG trading card marketplaces, designed to showcase features for buyers and sellers and drive beta signups.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

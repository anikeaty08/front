# Healthcare Recruitment Landing Page Template

A reusable landing page template for promoting guidebook downloads and consultations for care facilities hiring foreign staff under skilled worker visa programs.

## Project Details
- **Slug:** `care-recruitmen-69`
- **Views:** 56
- **Tags:** Landing Page, Services, Health, Clean, Minimal, Lead Generation, Healthcare, Recruitment, Download
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

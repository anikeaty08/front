# Careerookie

A reusable education template for student orientation platforms, showcasing guided pathways, dashboards, quizzes, and school-matching journeys from high school to application.

## Project Details
- **Slug:** `careerookie-edu`
- **Views:** 81
- **Tags:** Education, Landing Page, Technology, Clean, Minimal, Dashboard, Student Portal, Orientation, Career Guidance
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

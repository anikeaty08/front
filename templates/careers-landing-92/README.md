# Careers Landing Page Template

A reusable careers landing page template for industrial and B2B employers to showcase culture, teams, benefits, vacancies, and hiring process.

## Project Details
- **Slug:** `careers-landing-92`
- **Views:** 55
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Corporate careers, Recruitment, HR, Jobs
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

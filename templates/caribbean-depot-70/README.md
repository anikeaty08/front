# Caribbean Food Wholesale Landing Page Template

A reusable landing page template for Caribbean food wholesalers and retailers to showcase products, location, and contact details with a fresh, clean design.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

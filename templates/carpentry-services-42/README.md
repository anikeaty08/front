# Artigianal Carpentry Landing Page Template

Elegant Italian carpentry website template for showcasing artisanal woodwork services, heritage story, and contact details for traditional workshops and makers.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Carpintería Alumihogar Landing Page Template

Plantilla de landing page para carpintería de aluminio, PVC y madera, ideal como base reutilizable para talleres y servicios de reformas del hogar.

## Project Details
- **Slug:** `carpinter-a-alumihogar-1`
- **Views:** 19
- **Tags:** Landing Page, Services, Business, Brand, Clean, Minimal, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

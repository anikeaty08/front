# Carpintero Servicios Landing Page Template

Plantilla de landing page para carpinteros y servicios de carpintería locales, lista para reutilizar y adaptar a negocios de montaje, cocinas y suelos en tu ciudad.

## Project Details
- **Slug:** `carpintero-servicios-2`
- **Views:** 7
- **Tags:** Landing Page, Services, Business, Brand, Clean, Minimal, Large Type, Local Service, Carpintería, Profesionales
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# WhatsApp E-commerce Landing Page Template

A modern Cartivo-style WhatsApp E-commerce landing page template for showcasing fashion, beauty, and gadget products with simple chat-based ordering.

- **Views:** 242

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

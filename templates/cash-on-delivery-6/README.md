# Cash On Delivery E-commerce Landing Page Template

A dark, conversion-focused landing page template for Markium-style cash-on-delivery e-commerce platforms targeting Algerian and COD-based sellers.

## Project Details
- **Slug:** `cash-on-delivery-6`
- **Views:** 175
- **Tags:** E-commerce, Landing Page, Technology, Brand, Dark, Clean, Gradient, Large Type, Minimal

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

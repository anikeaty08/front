# Castan couverture 

A reusable landing page template for roofers, carpenters, and local home service businesses to showcase services, build trust, and capture quote requests.

## Project Details
- **Slug:** `castan-couverture`
- **Views:** 25
- **Tags:** Landing Page, Services, Clean, Minimal, Brand, Portfolio, local services, roofing, contractor
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

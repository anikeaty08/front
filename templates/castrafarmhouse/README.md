# Nature Retreat Landing Page Template

A reusable landing page template for glamping retreats, eco stays, and wilderness getaways, designed to showcase experiences, reviews, and direct booking CTAs.

## Project Details
- **Slug:** `castrafarmhouse`
- **Views:** 345
- **Tags:** Landing Page, Travel, Services, Dark, Animated, Nature retreat, Glamping, Eco stay, Booking

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

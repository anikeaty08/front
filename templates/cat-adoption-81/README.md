# Pet Adoption Landing Page Template

A dark, modern pet adoption landing page template for showcasing individual cats or pets with rich profiles, pricing, and breeder details.

## Project Details
- **Slug:** `cat-adoption-81`
- **Views:** 15
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Minimal, Large Type, Pet Adoption, Animal Rescue, Breeder
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Vietnamese Catering Landing Page Template

A reusable restaurant template for showcasing Vietnamese catering, menus, social proof, and enquiry forms to drive bookings and online orders.

## Project Details
- **Slug:** `catering-page-70`
- **Views:** 44
- **Tags:** Food, Landing Page, Services, Clean, Colorful, Minimal, Restaurant, Catering, Menu

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

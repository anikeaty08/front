# CAV Maquette

A refined, ready-to-use landing page template for wine shops, cavistes, and spirits boutiques to showcase collections, occasions, and store location.

## Project Details
- **Slug:** `cavmaquette`
- **Views:** 11
- **Tags:** Landing Page, E-commerce, Food, Brand, Clean, Minimal, Large Type, Gradient, Wine Shop, Spirits
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

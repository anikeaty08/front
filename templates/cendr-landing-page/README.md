# Logistics Infrastructure Landing Page Template

A reusable landing page template for urban logistics, courier infrastructure, and delivery platforms that need to showcase reliability, routing, APIs, and scale.

## Project Details
- **Slug:** `cendr-landing-page`
- **Views:** 25
- **Tags:** Landing Page, Technology, Services, Dark, Futuristic, Grid, Clean, API, Logistics
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

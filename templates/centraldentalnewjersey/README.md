# Dental Clinic Landing Page Template

A modern dental practice landing page template for local clinics, featuring services, doctor bio, FAQs, and an integrated appointment request form.

## Project Details
- **Slug:** `centraldentalnewjersey`
- **Views:** 22
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, Large Type, Gradient, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

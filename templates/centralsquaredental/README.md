# Dental Clinic Landing Page Template

A modern, brandable dental clinic landing page template for promoting services, showcasing dentists, and driving online appointment bookings.

## Project Details
- **Slug:** `centralsquaredental`
- **Views:** 45
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

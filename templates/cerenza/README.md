# CERENZA Modern Atelier Landing Page Template

A reusable landing page template for a modern atelier showcasing refined fashion, jewelry, timepieces, and beauty collections with elegant visuals and curated selections.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

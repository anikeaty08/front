# Chabaw Restaurant Landing Page Template

A clean and modern restaurant landing page template featuring business hours, location details, and integrated ordering buttons.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

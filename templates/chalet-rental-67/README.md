# Chalet Rental Landing Page Template

A reusable chalet rental landing page template for showcasing alpine stays, amenities, activities, testimonials, and booking inquiries.

## Project Details
- **Slug:** `chalet-rental-67`
- **Views:** 40
- **Tags:** Landing Page, Travel, Real Estate, Services, Clean, Minimal, Luxury chalet, Vacation rental, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

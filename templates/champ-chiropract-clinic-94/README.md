# Healthcare Clinic Landing Page Template

A reusable healthcare landing page template for chiropractic, back pain, and wellness clinics to promote treatments, build trust, and drive consultation bookings.

## Project Details
- **Slug:** `champ-chiropract-clinic-94`
- **Views:** 46

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

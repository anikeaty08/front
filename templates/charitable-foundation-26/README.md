# Charitable Foundation Landing Page Template

A modern, non-profit landing page template for charitable healthcare foundations to showcase missions, programs, news, and drive donations and volunteer signups.

## Project Details
- **Slug:** `charitable-foundation-26`
- **Views:** 456
- **Tags:** Landing Page, Non-profit, Health, Education, Brand, Clean, Minimal, Large Type, Gradient

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

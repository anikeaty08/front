# Charity Concert Landing Page Template

A reusable landing page template for promoting charity concerts and benefit events with artist highlights, venue details, ticket tiers, and donation-driven messaging.

## Project Details
- **Slug:** `charity-concert-29`
- **Views:** 22
- **Tags:** Landing Page, Non-profit, Conference, Entertainment, Clean, Minimal, Brand, event tickets, charity concert

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

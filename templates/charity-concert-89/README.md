# Charity Concert Landing Page Template

A reusable charity concert landing page template for promoting benefit events, showcasing artists, sharing venue details, and driving ticket sales.

- **Slug:** `charity-concert-89`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Vietnamese Restaurant Landing Page Template

A reusable restaurant website template for Vietnamese food brands to showcase menus, locations, catering, social proof, and online ordering.

## Project Details
- **Slug:** `chat-17`
- **Views:** 40
- **Tags:** Food, Landing Page, Brand, Clean, Colorful, Minimal, Restaurant, Vietnamese, Catering
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

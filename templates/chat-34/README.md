# Restaurant Landing Page Template

A reusable restaurant landing page template for food brands to showcase their story, menu, hours, locations, catering, and online ordering.

## Project Details
- **Slug:** `chat-34`
- **Views:** 30
- **Tags:** Food, Landing Page, Brand, Services, Clean, Colorful, Minimal, restaurant, catering, contact form
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Vietnamese Restaurant Landing Page Template

A clean, vibrant landing page template designed for authentic Asian cuisine restaurants, featuring menu highlights, ordering systems, and feedback forms.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

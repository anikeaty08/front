# Contact Form Landing Page Template

A clean, reusable contact form template for collecting leads, inquiries, and customer details with a polished, mobile-friendly UI.

## Project Details
- **Slug:** `chat-60`
- **Views:** 64
- **Tags:** Landing Page, Services, Technology, Minimal, Clean, Form, Contact, Lead Generation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Messaging App UI Template

A reusable dark messaging interface template for chat apps, inbox dashboards, or communication product demos with realistic conversation and sidebar layouts.

## Project Details
- **Slug:** `chat-app-interface-15`
- **Views:** 55
- **Tags:** Technology, Landing Page, Dark, Clean, Minimal, Messaging, Chat UI, Dashboard, Mobile App
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

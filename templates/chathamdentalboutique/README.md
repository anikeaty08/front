# Dental Clinic Landing Page Template

A modern, patient-focused dental clinic landing page template for promoting family, cosmetic, and pediatric dentistry and driving online appointment requests.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

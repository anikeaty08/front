# Hospitality Digital Check-In Landing Page Template

A reusable landing page template for hospitality platforms promoting digital guest check-in, kiosk workflows, PMS integrations, and demo-driven conversion.

- **Slug:** `checkin`
- **Views:** 37

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

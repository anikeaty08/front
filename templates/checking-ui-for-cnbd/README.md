# CNBD E-commerce Fashion Landing Page Template

A modern CNBD-themed fashion e-commerce landing page template featuring denim collections, category switcher, and product grid for online clothing stores.

- **Views:** 8

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

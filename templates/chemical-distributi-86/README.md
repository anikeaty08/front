# Chemical Distribution Landing Page Template

A reusable landing page template for chemical distributors and industrial suppliers to showcase industries, compliance, infrastructure, and sales contact options.

## Project Details
- **Slug:** `chemical-distributi-86`
- **Views:** 35

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

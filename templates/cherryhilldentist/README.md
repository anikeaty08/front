# Dental Practice Landing Page Template

A modern dental practice landing page template for clinics to showcase services, team, hours, and appointment requests with a clean, patient-focused design.

## Project Details
- **Slug:** `cherryhilldentist`
- **Views:** 10
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

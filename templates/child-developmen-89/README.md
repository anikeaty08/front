# Child Therapy Center Landing Page Template

A reusable landing page template for child development and therapy centers to showcase services, build trust, and drive consultation bookings.

## Project Details
- **Slug:** `child-developmen-89`
- **Views:** 16

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Restaurant Landing page by Gajanan

A dark, modern restaurant landing page template for showcasing menus, reviews, and location details for local eateries and food businesses.

## Project Details
- **Slug:** `chinese-corner-udgir`
- **Views:** 18
- **Tags:** Landing Page, Food, Services, Brand, Dark, Clean, Minimal, Large Type, Restaurant, Menu
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

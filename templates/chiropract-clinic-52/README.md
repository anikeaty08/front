# Chiropractic Clinic Landing Page Template

A reusable landing page template for chiropractic and functional medicine clinics to promote consultations, build trust, and convert patients.

## Project Details
- **Slug:** `chiropract-clinic-52`
- **Views:** 32
- **Tags:** Health, Landing Page, Services, Clean, Dark, Minimal, testimonials, medical clinic, chiropractic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Chiropractic Clinic Landing Page Template

A high-converting landing page template for chiropractic, rehab, and wellness clinics to promote consultations, build trust, and attract local patients.

## Project Details
- **Slug:** `chiropract-clinic-79`
- **Views:** 14
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Local business, Chiropractic, Rehab, Wellness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

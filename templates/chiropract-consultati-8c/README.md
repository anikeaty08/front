# Chiropractic Landing Page Template

A conversion-focused template for chiropractic clinics to promote consultations, showcase testimonials, explain treatment methods, and drive appointment bookings.

## Project Details
- **Slug:** `chiropract-consultati-8c`
- **Views:** 17
- **Tags:** Health, Landing Page, Services, Clean, Minimal, testimonials, video sales letter, medical practice, local clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

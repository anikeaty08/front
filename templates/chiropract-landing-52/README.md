# Chiropractic Landing Page Template

A conversion-focused template for chiropractic clinics to promote consultations, showcase patient testimonials, and turn local traffic into booked appointments.

## Project Details
- **Slug:** `chiropract-landing-52`
- **Views:** 31
- **Tags:** Health, Landing Page, Services, Clean, Minimal, testimonials, local business, lead generation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Chiropractic Practice Landing Page Template

A reusable landing page template for chiropractors and wellness clinics to promote free consultations, build trust with testimonials, and drive bookings.

## Project Details
- **Slug:** `chiropract-practice-32`
- **Views:** 28
- **Tags:** Landing Page, Health, Services, Clean, Minimal, testimonials, chiropractor, wellness clinic, video testimonials
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Chiropractic Landing Page Template

A healthcare landing page template for chiropractors and wellness clinics to promote treatments, build trust with reviews, and drive consultation bookings.

## Project Details
- **Slug:** `chiropract-wellness-84`
- **Views:** 23
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Wellness, Chiropractic, Reviews, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

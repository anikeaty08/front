# Chiropractic Clinic Landing Page Template

A modern chiropractic clinic landing page template to showcase services, patient testimonials, and online appointment booking for health practices.

## Project Details
- **Slug:** `chiroprakt-praxis-17`
- **Views:** 13
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Gradient, Clinic, Chiropractor
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

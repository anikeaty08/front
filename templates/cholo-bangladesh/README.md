# Cholo

A modern travel booking landing page template for listing stays, flights, and rentals with search, offers, trending destinations, and property highlights.

## Project Details
- **Slug:** `cholo-bangladesh`
- **Views:** 32
- **Tags:** Landing Page, Travel, Services, Brand, Clean, Minimal, Large Type, Colorful
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

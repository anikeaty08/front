# Chris Ritson

A reusable landing page template for cold calling coaches, sales trainers, and outbound consultants to showcase training, frameworks, proof, and booking CTA.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Christian School Landing Page Template

A reusable landing page template for private Christian schools to showcase faith-based academics, build trust with families, and drive tour requests.

## Project Details
- **Slug:** `christian-school-p1`
- **Views:** 28
- **Tags:** Landing Page, Education, Religious, Services, Clean, Minimal, Brand, private school, Christian academy
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

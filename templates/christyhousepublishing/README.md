# Christy House Publishing Preorder Landing Page Template

A reusable landing page template for boutique publishing houses to showcase curated books and facilitate preorders of upcoming releases.

## Project Details
- **Slug:** `christyhousepublishing`
- **Views:** 46
- **Tags:** Landing Page, Books, Publishing, Preorder, Featured Editions, About, Contact, Form, Modal, Typography

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Chronicle Modern Blog Interface Template

A dark, modern blog interface template for publishing product, design, and engineering articles with a featured grid layout and newsletter capture.

## Project Details
- **Slug:** `chronicle-modern-57`
- **Views:** 21
- **Tags:** Blog, Landing Page, Brand, Technology, Dark, Gradient, Minimal, Large Type, Art & Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

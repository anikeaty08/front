# Church & Community Landing Page Template

A dark, modern, and spiritually focused landing page template designed for religious organizations and community groups to manage membership and outreach.

## Project Details
- **Slug:** `church-community-4`
- **Views:** 32
- **Tags:** Membership, Non-profit, Social, Dark, Minimal, Clean, Religious
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

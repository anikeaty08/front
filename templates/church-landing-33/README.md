# Church Landing Page Template

A warm, faith-centered template for churches and online ministries to welcome members, share sermons, collect emails, and encourage giving.

## Project Details
- **Slug:** `church-landing-33`
- **Views:** 184
- **Tags:** Landing Page, Religious, Community, Services, Clean, Warm, Ministry, Church, Sermons, Donation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Church Landing Page Template

A reusable church website template for welcoming visitors, sharing service times, sermons, ministries, events, and online giving.

## Project Details
- **Slug:** `church-landing-39`
- **Views:** 44
- **Tags:** Landing Page, Religious, Services, Clean, Minimal, Blog, Community, church, sermons, ministries
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

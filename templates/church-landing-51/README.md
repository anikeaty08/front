# Church Landing Page Template

A warm, community-focused church landing page template for ministries sharing sermons, livestreams, giving, and diaspora outreach online.

## Project Details
- **Slug:** `church-landing-51`
- **Views:** 40
- **Tags:** Landing Page, Religious, Community, Services, Clean, Minimal, Brand, church, ministry, livestream
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Church Landing Page Template

A warm, faith-centered church website template for ministries to share sermons, welcome members, collect emails, and encourage online giving.

## Project Details
- **Slug:** `church-landing-60`
- **Views:** 20
- **Tags:** Landing Page, Religious, Services, Brand, Clean, Elegant, Community, Sermons, Church
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Cikka Financial App UI Template

Mobile-first UI template for a financial super app with shopping mall, cart, rewards, profile, and notifications screens, ready to reuse in your next product.

## Project Details
- **Slug:** `cikka-financial-64`
- **Views:** 13
- **Tags:** Technology, E-commerce, Brand, Clean, Dark, Minimal, Large Type, Financial app, Mobile UI, Rewards
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Cinematographer Portfolio Template

A reusable portfolio template for filmmakers, photographers, and visual storytellers to showcase work, services, biography, and contact details.

## Project Details
- **Slug:** `cinematic-portfolio-81`
- **Views:** 180
- **Tags:** Portfolio, Artist, Photography, Services, Dark, Minimal, Clean, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# CineQuote Movie Quotes App Template

A reusable template for a cinematic movie quotes app experience, featuring quote discovery, search, collections, and a dark glassmorphism UI.

## Project Details
- **Slug:** `cinequote-movie-59`
- **Views:** 21
- **Tags:** Entertainment, Art & Design, Landing Page, Brand, Dark, Clean, Gradient, Minimal, Large Type, Movie quotes
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Kids Circus School Landing Page Template

A playful landing page template for children's circus schools, classes, and youth programs to showcase schedules, safety, instructors, and trial bookings.

## Project Details
- **Slug:** `circus-school`
- **Views:** 26
- **Tags:** Landing Page, Education, Services, Colorful, Gradient, Animated, Clean, kids classes, circus school
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# City Diner Restaurant Landing Page Template

A modern City Diner landing page template for restaurants and cafes to showcase menus, hours, location, and online ordering in a cozy, nostalgic style.

## Project Details
- **Slug:** `city-diner-restaurant-4`
- **Views:** 34
- **Tags:** Landing Page, Food, Services, Brand, Clean, Colorful, Minimal, Restaurant, Cafe, Diner
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Eco City Government Portal Landing Page Template

Reusable landing page template for a city ecology portal with complaints, eco-calculator, benefits, news and FAQ sections, ideal for municipal environmental services.

## Project Details
- **Slug:** `city-ecology-76`
- **Views:** 7
- **Tags:** Landing Page, Services, Environmental, Brand, Clean, Colorful, Minimal, Technology, Large Type, Documentation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

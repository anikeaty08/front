# Eco City Environment Portal Landing Page Template

A modern template for eco-city environment portals featuring air quality news, complaint reporting, citizen benefits, and vehicle eco-class tools.

## Project Details
- **Slug:** `city-environmen-93`
- **Views:** 8
- **Tags:** Landing Page, Environmental, Clean, Minimal, Brand, Technology, Large Type, Services

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

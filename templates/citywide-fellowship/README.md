# Citywide Fellowship Church Groups Landing Page Template

A church small-groups landing page template for helping visitors find or lead community groups, featuring search results, leader benefits, and an application form.

## Project Details
- **Slug:** `citywide-fellowship`
- **Views:** 30
- **Tags:** Landing Page, Religious, Community, Clean, Minimal, Brand, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

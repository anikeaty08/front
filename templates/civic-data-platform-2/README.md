# About Us Page Example

A reusable landing page template for civic data platforms, nonprofits, and public-interest initiatives to present mission, partners, services, and contact options.

- **Slug:** `civic-data-platform-2`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

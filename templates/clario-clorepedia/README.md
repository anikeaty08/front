# Gaming Hub Landing Page Template

A reusable gaming hub template for embedding and launching browser-based game sites with a polished loader, fullscreen iframe, and cookie consent UI.

## Project Details
- **Slug:** `clario-clorepedia`
- **Views:** 44
- **Tags:** Landing Page, Technology, Entertainment, Dark, Minimal, Clean, gaming, browser games, iframe, cookie banner
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Marketplace Blog Template

A reusable blog template for classifieds and marketplace brands to publish articles, category guides, and seller tips with search, sidebar widgets, and CTAs.

## Project Details
- **Slug:** `classified-blog-94`
- **Views:** 24
- **Tags:** Blog, E-commerce, Real Estate, Technology, Clean, Minimal, Brand, marketplace, classifieds
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

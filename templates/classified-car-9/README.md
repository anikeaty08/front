# Classified Car Listing Page Template

A modern classified car listing page template for eClassify-style marketplaces, ready to reuse for vehicle ads with gallery, specs, seller info, and CTAs.

## Project Details
- **Slug:** `classified-car-9`
- **Views:** 45
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Large Type, Gradient, Automotive, Marketplace
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Neo Pop Marketplace Landing Page Template

A bold Neo Pop marketplace landing page template inspired by classifieds sites, perfect for showcasing listings, categories, and call-to-sell CTAs.

## Project Details
- **Slug:** `classified-marketplac-92`
- **Views:** 10
- **Tags:** Landing Page, E-commerce, Brand, Clean, Colorful, Brutal, Large Type, Gradient, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Cleaning Services Landing Page Template

A reusable landing page template for window washing and facility cleaning businesses to showcase services, pricing, and capture online service requests.

## Project Details
- **Slug:** `cleaning-services-21`
- **Views:** 23
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Brand, pricing, contact form, cleaning company
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

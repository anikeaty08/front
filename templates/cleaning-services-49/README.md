# Cleaning Services Landing Page Template

A reusable landing page template for commercial and apartment cleaning businesses to showcase services, build trust, and capture quote requests.

## Project Details
- **Slug:** `cleaning-services-49`
- **Views:** 32
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Brand, commercial cleaning, apartment cleaning, quote form

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

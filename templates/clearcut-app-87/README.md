# ClearCut App Landing Page Template

A dark, modern landing page template for a macOS offline background remover app, perfect for promoting privacy-first desktop software products.

## Project Details
- **Slug:** `clearcut-app-87`
- **Views:** 52

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

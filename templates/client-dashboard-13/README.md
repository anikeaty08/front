# Client Dashboard UI Template

A reusable client dashboard UI template for agencies and service providers to showcase billing, hours, SEO, and system health in a clean, modern layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

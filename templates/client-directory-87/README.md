# Client Directory Dashboard Template

A reusable admin dashboard template for managing client profiles, wallet balances, orders, logistics, billing, and customer messaging in one workspace.

## Project Details
- **Slug:** `client-directory-87`
- **Views:** 21
- **Tags:** Technology, Services, Dashboard, Admin, CRM, E-commerce, Clean, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

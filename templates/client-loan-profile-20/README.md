# Client Loan Profile Dashboard Template

A reusable client loan profile dashboard template for legal and finance teams to track case details, loan history, and payments in a clean UI.

## Project Details
- **Slug:** `client-loan-profile-20`
- **Views:** 10
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Dashboard, Legal, Finance, Client Management, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Client Portal Dashboard Template

A dark, modern client portal dashboard template for verification and authorization services, featuring login, status tracking, and payment summary UI.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

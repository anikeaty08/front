# Client Portal Dashboard Template

A reusable client portal template for agencies and service teams to share project updates, deliverables, invoices, approvals, and communication in one place.

## Project Details
- **Slug:** `client-portal-90`
- **Views:** 92
- **Tags:** Landing Page, Services, Brand, Dark, Clean, Minimal, Dashboard, Client Portal, Agency
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Client Portal Dashboard Page Template

A modern client portal dashboard template for web agencies, letting clients track project progress, upload files, and view billing status in one place.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

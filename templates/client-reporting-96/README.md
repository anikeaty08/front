# Aurix Media Client Portal Template

A reusable template for a minimalist media client portal with admin onboarding, weekly performance dashboards, and exportable campaign reports.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

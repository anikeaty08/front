# Physiotherapy Clinic Landing Page Template

A reusable landing page template for physiotherapy and osteopathy clinics to showcase treatments, build trust, and drive appointment bookings.

## Project Details
- **Slug:** `clinicaaguirrefisio`
- **Views:** 67

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

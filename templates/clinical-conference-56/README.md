# Clinical Conference Landing Page Template

A modern, multi-section landing page template for medical or academic conferences, featuring event details, speakers, pricing, and registration flow.

## Project Details
- **Slug:** `clinical-conference-56`
- **Views:** 5
- **Tags:** Landing Page, Conference, Education, Health, Brand, Clean, Gradient, Large Type, Minimal, Technology

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Psychologist Landing Page Template

A gentle, modern psychologist landing page template for promoting clinical therapy services, showcasing formats, FAQ, and contact booking online.

## Project Details
- **Slug:** `clinical-psychologi-15`
- **Views:** 140
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Psychology, Therapist, Personal Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

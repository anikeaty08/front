# Medical Clinic Landing Page Template

A reusable medical clinic landing page template for promoting specialties, doctors, facilities, and appointment booking with a polished, trust-focused design.

## Project Details
- **Slug:** `clinicapiqueras`
- **Views:** 23
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Brand, medical clinic, doctor, appointment booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

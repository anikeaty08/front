# Veterinary Clinic Landing Page Template

A reusable landing page template for veterinary clinics and pet care centers to showcase services, team, locations, and appointment booking.

## Project Details
- **Slug:** `clinicaveterinariamalasana`
- **Views:** 70
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, veterinary, pet care, appointment booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# ClipCut Short-Form Video Offer Landing Page Template

A dark, conversion-focused landing page template for ClipCut-style short-form video services, built to book discovery calls and validate a winning content format.

- **Slug:** `clipcut-winning-33`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

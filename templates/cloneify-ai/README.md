# Cloneify AI Web Design Template

A sophisticated SaaS landing page template for AI-driven design tools, allowing users to convert links, photos, or videos into clean, responsive code.

## Project Details
- **Slug:** `cloneify-ai`
- **Views:** 7
- **Tags:** Technology, Landing Page, Clean, Dark, Futuristic, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Fashion Design Landing Page Template

A modern landing page template for AI-powered fashion design and production platforms, perfect for showcasing workflows, features, and pricing to apparel brands.

## Project Details
- **Slug:** `cloth-ra-ai-fashion`
- **Views:** 30
- **Tags:** Landing Page, Technology, Fashion, Brand, Clean, Gradient, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Cloud Consulting Landing Page Template

A modern MeetCloud-style landing page template for cloud and Google Workspace consulting firms to showcase services, team, testimonials, and capture leads.

## Project Details
- **Slug:** `cloud-consulting-45`
- **Views:** 29
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Large Type, Gradient, Cloud Consulting

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

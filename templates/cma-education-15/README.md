# CMA Education Chat Assistant Dashboard Template

A modern template for institutes to deploy a CMA-focused AI inquiry chat assistant, streamlining course, fees, and admission queries for students.

## Project Details
- **Slug:** `cma-education-15`
- **Views:** 17
- **Tags:** Education, Services, Technology, Landing Page, Brand, Clean, Minimal, Dashboard, Chatbot, CMA
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

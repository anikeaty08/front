# Lumina CMS Dashboard UI Template

A modern CMS dashboard template for managing posts, pages, analytics, and system health, ready to reuse in your content management applications.

## Project Details
- **Slug:** `cms-dashboard-35`
- **Views:** 105
- **Tags:** Technology, Services, Brand, Clean, Minimal, Dashboard, CMS, Admin, Analytics

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

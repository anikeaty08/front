# CMS Automation SaaS Landing Page Template

A modern SaaS landing page template for CMSFlow-style platforms that automate AI-powered, SEO-optimized content publishing to WordPress, Wix, and Squarespace.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Housing Society Services Landing Page Template

A reusable landing page template for co-op housing society management firms to showcase accounting, compliance, auditing, and resident support services.

## Project Details
- **Slug:** `co-op-housing-69`
- **Views:** 57
- **Tags:** Landing Page, Services, Business, Real Estate, Clean, Minimal, Professional, Accounting, Compliance
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Markium COD E-commerce Landing Page Template

A high-converting landing page template for Markium, a COD-first e-commerce platform tailored to Algerian sellers, featuring dashboard, features, and CTA sections.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

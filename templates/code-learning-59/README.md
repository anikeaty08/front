# Coding Education Dashboard Template

A reusable dark-mode template for coding education platforms, interview prep apps, and developer dashboards with IDE, lessons, and analytics.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

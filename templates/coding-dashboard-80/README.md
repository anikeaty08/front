# Coding Learning Dashboard Template

A dark, modern coding learning dashboard template for developer education platforms, featuring course progress, challenges, and skill tracking UI.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

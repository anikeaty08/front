# CoffBae Café Landing Page Template

A cozy café landing page template for showcasing artisan coffee, pastries, ambience, reviews, and location details for local coffee shops.

## Project Details
- **Slug:** `coffbae-testwebsite`
- **Views:** 43
- **Tags:** Landing Page, Food, Services, Brand, Clean, Minimal, Colorful, Large Type, Café, Coffee Shop
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

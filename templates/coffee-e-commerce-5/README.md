# Coffee E-commerce Template

A reusable coffee e-commerce template for selling beans, gear, and subscriptions online with a clean storefront and conversion-focused shopping flow.

## Project Details
- **Slug:** `coffee-e-commerce-5`
- **Views:** 30
- **Tags:** E-commerce, Food, Landing Page, Clean, Minimal, Brand, coffee, online store, subscription
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

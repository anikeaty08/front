# Coffee E-commerce Website Template

A reusable e-commerce template for specialty coffee brands to showcase products, subscriptions, sourcing values, and drive online sales.

## Project Details
- **Slug:** `coffee-e-commerce-68`
- **Views:** 55
- **Tags:** E-commerce, Food, Brand, Clean, Minimal, Landing Page, subscriptions, specialty coffee, product grid
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Coffee Ordering App Template

A reusable mobile app template for coffee shops to showcase drink ordering, customization, and fast reorders with a clean premium interface.

## Project Details
- **Slug:** `coffee-ordering-13`
- **Views:** 21
- **Tags:** Food, E-commerce, Landing Page, Minimal, Clean, Mobile App, Coffee Shop, Ordering UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

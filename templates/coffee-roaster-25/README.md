# Coffee E-commerce Landing Page Template

A refined Alpine Grind-inspired coffee e-commerce landing page template for showcasing roasts, subscriptions, and brand storytelling for specialty coffee shops.

## Project Details
- **Slug:** `coffee-roaster-25`
- **Views:** 22
- **Tags:** E-commerce, Food, Landing Page, Brand, Clean, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

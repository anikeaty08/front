# Coffee Shop Landing Page Template

A modern coffee shop landing page template for cafés to showcase menu, reviews, and location with online ordering and visitor-focused details.

## Project Details
- **Slug:** `coffee-shop-landing-12`
- **Views:** 16
- **Tags:** Landing Page, Food, Services, Brand, Clean, Minimal, Large Type, Coffee shop, Café, Local business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

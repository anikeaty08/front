# Coffee Shop Landing Page 

A modern coffee shop landing page template for showcasing your café story, menu, location, and table reservations in a clean, inviting layout.

- **Slug:** `coffee-shop-landing-20`
- **Views:** 318

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

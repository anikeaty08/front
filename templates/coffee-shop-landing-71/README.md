# Coffee Shop Landing Page Template

A modern coffee shop landing page template for specialty cafés, showcasing menu, reviews, products, Instagram feed, and visit details.

## Project Details
- **Slug:** `coffee-shop-landing-71`
- **Views:** 36
- **Tags:** Landing Page, Food, Brand, Clean, Minimal, Gradient, Large Type, E-commerce, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

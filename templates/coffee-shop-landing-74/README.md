# Coffee Shop Landing Page Template

A modern one-page coffee shop website template for independent cafés, featuring menu highlights, roasters, reviews, hours, and visit info.

## Project Details
- **Slug:** `coffee-shop-landing-74`
- **Views:** 12
- **Tags:** Landing Page, Food, Brand, Clean, Dark, Minimal, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

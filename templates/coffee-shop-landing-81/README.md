# Coffee Shop Landing Page Template

A reusable coffee shop landing page template for cafes and roasteries to showcase their story, menu, location, and email signups with a warm editorial feel.

## Project Details
- **Slug:** `coffee-shop-landing-81`
- **Views:** 53
- **Tags:** Food, Landing Page, Brand, Clean, Minimal, Editorial, Cafe, Coffee Shop, Menu
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

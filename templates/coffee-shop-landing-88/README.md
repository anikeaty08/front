# Coffee Shop Landing Page Template

A refined coffee shop landing page template for cafes and roasteries to showcase their story, group brands, menu, and location in a warm, minimal aesthetic.

## Project Details
- **Slug:** `coffee-shop-landing-88`
- **Views:** 396
- **Tags:** Landing Page, Food, Brand, Clean, Minimal, Large Type, Gradient, Coffee Shop, Café, Restaurant
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

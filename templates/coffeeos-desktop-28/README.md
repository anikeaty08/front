# CoffeeOS Desktop Experience Template

A high-performance, Arch-inspired web desktop template featuring a window manager, terminal, and productivity widgets in the Catppuccin Mocha aesthetic.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Coffee Shop Landing Page Template

A dark, minimalist coffee shop landing page template for specialty cafés to showcase their menu, shop products, and location in a premium, brand-forward layout.

## Project Details
- **Slug:** `coffeeshopsixty`
- **Views:** 550
- **Tags:** Landing Page, Food, Brand, Clean, Dark, Minimal, Large Type, Gradient, Coffee shop, café
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

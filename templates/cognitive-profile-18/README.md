# Cognitive Profile Assessment Web App Template

A reusable template for an interactive cognitive profile assessment web app with participant flow, analytics dashboard, and chart-based results visualization.

- **Slug:** `cognitive-profile-18`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

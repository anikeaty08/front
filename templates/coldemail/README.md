# Cold Email Marketing SOP Landing Page Template

A conversion-focused landing page template for selling a cold email marketing SOP PDF, optimized to showcase benefits, social proof, and clear purchase CTAs.

- **Slug:** `coldemail`
- **Views:** 18

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

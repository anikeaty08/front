# College Landing Page Template

A reusable college landing page template for universities and institutes to showcase programs, campus life, admissions, and student outcomes.

## Project Details
- **Slug:** `college-admissions-24`
- **Views:** 16
- **Tags:** Landing Page, Education, Services, Clean, Minimal, Brand, college, university, admissions
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# College Search Education Template

A reusable education directory template for helping students discover colleges, courses, exams, and career paths with guided search and comparison tools.

## Project Details
- **Slug:** `college-search-37`
- **Views:** 21
- **Tags:** Education, Landing Page, Services, Clean, Minimal, Directory, College Search, Career Guidance
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

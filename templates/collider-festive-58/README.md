# Collider Festive Beverage Landing Page Template

A reusable landing page template designed for promoting festive non-alcoholic craft beer products with features like countdown, bundles, science-backed benefits, and social proof.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

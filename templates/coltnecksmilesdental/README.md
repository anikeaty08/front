# Dental Clinic Landing Page Template

A modern dental clinic landing page template for practices to showcase services, introduce the doctor, and capture new patient appointment requests.

## Project Details
- **Slug:** `coltnecksmilesdental`
- **Views:** 11
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Gradient, Large Type, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

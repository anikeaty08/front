# Comedian Personal Branding Landing Page Template

This reusable template showcases a comedian and speaker's personal brand with sections for bio, services, videos, shows, testimonials, and contact booking.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

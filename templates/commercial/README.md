# Commercial Insurance Landing Page Template

A reusable landing page template designed for commercial insurance brokers to showcase risk management services and drive risk audit bookings.

## Project Details
- **Slug:** `commercial`
- **Views:** 50
- **Tags:** Landing Page, Insurance, Risk Management, Audit, Brokerage, Testimonials, FAQ, Features, Comparison, CTA
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Community Care Directory Web App Template

A reusable template for a community emergency directory web app, enabling quick search of members, blood donors, hospitals, ambulances, and police by area.

## Project Details
- **Slug:** `community-care-29`
- **Views:** 20
- **Tags:** Health, Services, Landing Page, Dark, Minimal, Clean, Grid, Large Type, Emergency directory, Community care
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

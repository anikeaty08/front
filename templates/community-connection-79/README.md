# Anonymous Community Landing Page Template

A clean, minimal landing page template for anonymous support communities like Zumlo, showcasing shared connection, safety, and a single primary CTA.

## Project Details
- **Slug:** `community-connection-79`
- **Views:** 18
- **Tags:** Landing Page, Brand, Minimal, Clean, Gradient, Large Type, Social, Community, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

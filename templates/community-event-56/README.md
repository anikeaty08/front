# Community Event Portal Website Template

A modern community event portal website template for local associations, showcasing news, agendas, boards and contact forms in one clean hub.

## Project Details
- **Slug:** `community-event-56`
- **Views:** 40
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Social, Community, Event Portal, Local Association
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Community Events Landing Page Template

A reusable landing page template for community event brands, curated experiences, and social clubs to showcase stories, upcoming events, and custom bookings.

## Project Details
- **Slug:** `community-events-70`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

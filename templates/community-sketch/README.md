# Creative Arts Community Landing Page Template

A clean, minimalist community landing page template designed for art clubs, social meetups, and creative workshop organizers to manage sessions and members.

## Project Details
- **Slug:** `community-sketch`
- **Views:** 20
- **Tags:** Community, Art & Design, Social, Membership, Portfolio, Clean, Minimal, Grid
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

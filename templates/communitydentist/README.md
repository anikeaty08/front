# Dental Clinic Landing Page Template

A modern dental practice landing page template for clinics to showcase services, insurance info, and online appointment requests with a clean, patient-friendly design.

## Project Details
- **Slug:** `communitydentist`
- **Views:** 98
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, dental clinic template, medical practice
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

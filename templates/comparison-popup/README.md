# comparison-popup

A reusable modal comparison template for sleep tracking products that showcases feature tables, mobile cards, and clear CTAs for product selection.

- **Slug:** `comparison-popup`
- **Views:** 40

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

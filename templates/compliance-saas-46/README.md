# Compliance SaaS Landing Page Template

A modern compliance SaaS landing page template for showcasing license tracking, alerts, and waitlist signup for construction, technical, and medical firms.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Compulsory Insurance Center Landing Page Template

This reusable landing page template is designed for compulsory car insurance services, providing a clear platform to buy policies, check coverage, and access agent portals.

## Project Details
- **Slug:** `compulsory-insurance-85`
- **Views:** 27
- **Tags:** Landing Page, Insurance, Car Insurance, FAQ, Features, Agent Portal, Contact, Pricing, Policies, Support
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

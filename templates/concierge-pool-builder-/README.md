# Concierge Pool Builder 

A reusable landing page template for luxury pool builders and outdoor living firms to showcase services, portfolio work, and consultation-driven lead capture.

## Project Details
- **Slug:** `concierge-pool-builder-`
- **Views:** 14
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Dark, Luxury, Construction, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

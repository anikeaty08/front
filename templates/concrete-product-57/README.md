# Concrete Product Catalog Landing Page Template

A modern template for concrete suppliers to showcase ready-mix product catalogs and detailed single product specs with built-in quote and enquiry CTAs.

## Project Details
- **Slug:** `concrete-product-57`
- **Views:** 29
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Grid, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Security Services Landing Page Template

A reusable landing page template for condominium security providers to promote remote concierge services, cost savings, and lead generation.

- **Slug:** `condominiu-security-70`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

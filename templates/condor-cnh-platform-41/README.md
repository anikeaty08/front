# Driving Lessons Platform Landing Page Template

Modern landing page template for a CNH/driver’s license platform connecting students, independent instructors, and CFC hubs under Brazil’s new CNH law.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

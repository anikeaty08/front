# Condor Landing Page Template

Modern CONDOR-inspired landing page template for CNH platforms connecting driving students, instructors and CFC hubs under Brazil's new CNH law.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# International Conference Landing Page Template

A reusable conference landing page template for promoting global events, sharing schedules and highlights, and driving media or attendee invite requests.

## Project Details
- **Slug:** `conference-landing-16`
- **Views:** 50
- **Tags:** Landing Page, Conference, Dark, Clean, Minimal, Brand, event promotion, media invitation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

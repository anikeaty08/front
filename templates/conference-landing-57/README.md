# Academic Conference Landing Page Template

A reusable template for academic and professional conference landing pages, featuring sections for themes, speakers, call for papers, fees, and registration.

## Project Details
- **Slug:** `conference-landing-57`
- **Views:** 33
- **Tags:** Conference, Education, Landing Page, Brand, Clean, Minimal, Large Type, Technology, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

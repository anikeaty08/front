# Medical Conference Landing Page Template

A reusable event landing page template for medical seminars and academic conferences, designed to showcase details, categories, and drive registrations.

## Project Details
- **Slug:** `conference-landing-82`
- **Views:** 42
- **Tags:** Landing Page, Conference, Health, Education, Clean, Minimal, Brand, event registration, medical seminar
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Conference Networking App UI Template

A mobile-first conference networking app UI template for showcasing attendee cards, event details, and bottom navigation in a modern gradient design.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

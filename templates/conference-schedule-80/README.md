# Conference Schedule Landing Page Template

A reusable conference schedule template for showcasing multi-day event agendas, speakers, venues, and registration with a refined, high-impact design.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

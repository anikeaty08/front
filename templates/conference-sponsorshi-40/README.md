# Conference Sponsorship Landing Page Template

A reusable conference sponsorship landing page template for showcasing audience demographics, partner value, and tiered packages to attract event sponsors.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

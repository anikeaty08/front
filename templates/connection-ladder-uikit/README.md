# Moodboard Inspired UI Kit Template

A reusable moodboard-inspired UI kit template featuring pastel color system, typography samples, buttons, forms, and cards for modern product interfaces.

- **Slug:** `connection-ladder-uikit`
- **Views:** 44

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Construction Job Matching Mobile App Template

A reusable mobile onboarding template for construction hiring platforms to collect worker profiles, skills, availability, and job preferences fast.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Industrial Construction Supplier Landing Page Template

Spanish-language landing page template for an industrial construction materials supplier, ideal for B2B companies selling block, mortars, and concrete by volume.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

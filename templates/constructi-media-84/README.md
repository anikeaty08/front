# Construction Industry Media Website Template

A reusable website template for construction news, B2B directories, jobs, and commercial real estate platforms targeting industry professionals.

## Project Details
- **Slug:** `constructi-media-84`
- **Views:** 40
- **Tags:** Technology, Services, Real Estate, Blog, Brand, Clean, Minimal, Editorial, B2B, News

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Construction Operations Dashboard Template

A reusable admin dashboard template for construction and property service teams to manage work requests, client details, quotes, scheduling, and vendor assignments.

## Project Details
- **Slug:** `constructi-operations-84`
- **Views:** 42
- **Tags:** Services, Technology, Landing Page, Clean, Minimal, Dashboard, Admin, Construction, CRM

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

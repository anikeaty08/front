# Industrial Product Landing Page Template

Reusable landing page template for industrial and construction products, ideal to showcase features, specs, and WhatsApp quote CTAs for B2B brands.

## Project Details
- **Slug:** `constructi-product-4`
- **Views:** 4
- **Tags:** Landing Page, Business, Services, Brand, Clean, Minimal, Large Type, Technology, Gradient, Industrial
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

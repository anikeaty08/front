# Construction Services Landing Page Template

A clean, modern landing page template for local construction and renovation companies to showcase services, projects, and capture quote enquiries.

## Project Details
- **Slug:** `constructi-services-39`
- **Views:** 32
- **Tags:** Landing Page, Services, Business, Construction, Clean, Minimal, Large Type, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

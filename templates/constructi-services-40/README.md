# Construction Services Landing Page Template

A reusable landing page template for paving, aggregates, transport, and equipment rental businesses to showcase services, projects, and free quote forms.

## Project Details
- **Slug:** `constructi-services-40`
- **Views:** 32
- **Tags:** Landing Page, Services, Business Category, Clean, Dark, Minimal, Construction, Paving, Equipment Rental
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Construction Training Landing Page Template

A reusable landing page template for selling construction management training programs to site managers, with sections for benefits, curriculum, pricing, and urgency.

## Project Details
- **Slug:** `constructi-training-17`
- **Views:** 23
- **Tags:** Landing Page, Services, Education, Clean, Minimal, Business training, Construction, Coaching

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Construction Services Landing Page Template

A polished IronGrid Build Co. landing page template for construction firms to showcase services, projects, safety, and testimonials and convert visitors via bid requests.

## Project Details
- **Slug:** `construction-services`
- **Views:** 31
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Grid, Large Type, Construction, Contractor, Responsive
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

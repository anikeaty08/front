# Consultant Portfolio Template

A reusable dark portfolio template for consultants, writers, and thought leaders to showcase expertise, essays, credentials, and personal brand.

## Project Details
- **Slug:** `consultant-portfolio-77`
- **Views:** 40
- **Tags:** Portfolio, Services, Brand, Technology, Dark, Gradient, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Consultoría Corporativa Landing Page Template

Plantilla de landing page para firmas de consultoría corporativa que ofrece pilares de servicios, metodología, métricas de confianza y formulario de contacto listo para usar.

## Project Details
- **Slug:** `consultor-a-corporativ-36`
- **Views:** 8
- **Tags:** Landing Page, Services, Business, Consulting, Corporate, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Public Sector Consulting Landing Page Template

Reusable landing page template for public sector consulting firms to showcase services, methodology, and lead-generation CTAs in a clean, modern layout.

## Project Details
- **Slug:** `consultor-a-sector-10`
- **Views:** 6
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Technology, Grid
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

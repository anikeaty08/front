# Contabilidade Consultoria Landing Page Template

Landing page template for consultative accounting and BPO finance services, ideal to present a modern tax and financial advisory brand to digital businesses.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

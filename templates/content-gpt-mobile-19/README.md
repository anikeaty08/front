# Content GPT Mobile App UI Template

A dark, mobile-style Content GPT app UI template for AI-powered scripts, captions, blogs, and rewrites—ready to reuse for your next content tool.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Technology Dashboard Template

A reusable dark dashboard template for managing contracts, tracking KPIs, visualizing retention and churn, and automating reports via WhatsApp.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

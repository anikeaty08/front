# ccg

Reusable ISO 27001 compliance dashboard template for tracking controls, evidence, and Annex A readiness across organizational, people, physical, and technological controls.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

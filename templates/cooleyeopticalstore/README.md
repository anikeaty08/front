# CoolEye Optical

A clean, modern optical shop landing page template with services, reviews, AI assistant chat, and location details for local eye-care businesses.

## Project Details
- **Slug:** `cooleyeopticalstore`
- **Views:** 15
- **Tags:** Landing Page, Services, Health, Brand, Clean, Minimal, Gradient, Large Type, Optical, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Coppice View Dental Demo

A modern dental practice landing page template for clinics to showcase treatments, contact details, and online enquiries with a clean, patient-friendly design.

## Project Details
- **Slug:** `coppiceviewdental`
- **Views:** 29
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# CortexCRM SaaS Landing Page Template

A modern dark SaaS landing page template for promoting a CortexCRM-style AI-powered CRM platform, with hero, features, pricing, FAQ, and RTL support.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

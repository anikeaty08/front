# Real Estate Property Search Template

A clean and functional real estate listing template designed for property management firms to showcase rental communities with integrated search filters and map views.

## Project Details
- **Slug:** `corp-maps`
- **Views:** 21
- **Tags:** Real Estate, Services, Landing Page, Clean, Grid, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Corporate Academy Cohort Landing Page Template

A reusable landing page template for corporate academy and professional readiness programs to showcase cohort-based curriculum, founders, and institutional partnerships.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Corporate Bond Listing Template

A reusable mobile-first template for showcasing corporate bond tranches, ISIN details, yields, maturity terms, and investment availability.

## Project Details

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Corporate Consulting Landing Page Template

A reusable consulting template for strategy firms and advisory brands to showcase expertise, case studies, client proof, insights, and session booking.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

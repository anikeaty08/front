# Mental Health BGM Landing Page Template

A reusable landing page template for pragmatic corporate mental health (BGM) services focused on 15‑minute sessions for mid-sized companies.

## Project Details
- **Slug:** `corporate-mental-45`
- **Views:** 6
- **Tags:** Landing Page, Services, Health, Brand, Clean, Minimal, Large Type, Gradient, Corporate, HR
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Cosmic Watch NEO Dashboard Template

A dark, futuristic web app template for monitoring near-Earth objects with dashboards, alerts, watchlists, and 3D orbital visualizations.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

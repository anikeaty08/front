# FocusTimer

A reusable Focus Timer app UI template for creating elegant, minimal productivity timers with presets, circular progress, and light/dark themes.

- **Slug:** `countdown-zenixy`
- **Views:** 11

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Geography Learning App UI Template

A reusable UI template for a warm, modern geography learning app with dashboard, flashcards, quizzes, country detail views, and progress analytics screens.

## Project Details
- **Slug:** `country-coach-49`
- **Views:** 26

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Course Session Manager Dashboard Template

A dark, minimal course session manager template for educators to run live modules with timers, notes, quizzes, and resources in one streamlined workspace.

## Project Details
- **Slug:** `course-session-17`
- **Views:** 16
- **Tags:** Landing Page, Education, Technology, Brand, Dark, Minimal, Dashboard, Course Manager, Learning, Clean
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

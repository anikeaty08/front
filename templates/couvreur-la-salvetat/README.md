# Couvreur La Salvetat-sur-Agout

A reusable landing page template for local roofing and home repair businesses to showcase services, reviews, coverage areas, and capture quote requests.

## Project Details
- **Slug:** `couvreur-la-salvetat`
- **Views:** 35
- **Tags:** Landing Page, Services, Business, Clean, Dark, Minimal, Local Services, Home Repair, Roofing
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Craft Lifestyle Blog Template

A reusable blog template for craft, home decor, sewing, and DIY brands to publish editorial content, buying guides, and product reviews with a refined magazine feel.

## Project Details
- **Slug:** `craft-home-editorial-16`
- **Views:** 79
- **Tags:** Blog, Lifestyle, Brand, Services, Clean, Minimal, Editorial, Home Decor, Sewing, DIY
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

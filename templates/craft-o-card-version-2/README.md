# Business Card Printing Landing Page Template

Modern landing page template for an AI-assisted business card and print design service, ideal for showcasing products, pricing, and CTAs to convert visitors.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

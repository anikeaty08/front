# Fresh Produce Business Landing Page Template

A clean, modern landing page template for fresh produce and farm-to-market vegetable businesses to showcase products and drive phone orders.

## Project Details
- **Slug:** `creat-a-webside-35`
- **Views:** 17
- **Tags:** Landing Page, E-commerce, Food, Brand, Clean, Minimal, Gradient, Large Type, Fresh Produce, Farm to Table
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Private Equity Investment Landing Page Template

A modern dark-mode landing page template for private equity or investment firms to showcase philosophy, sectors, Vision 2030 alignment, and investor contact.

## Project Details
- **Slug:** `create-a-landing-40`
- **Views:** 20
- **Tags:** Landing Page, Business, Brand, Clean, Dark, Minimal, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Medical Equipment Inventory Email Template

A reusable HTML email template for showcasing premium refurbished medical laser equipment inventory, featured deals, and contact details for clinics.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

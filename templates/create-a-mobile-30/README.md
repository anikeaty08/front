# Identity Verification Portal UI Template

A reusable mobile-style verification portal UI template for identity and asset clearance flows, including multi-step review, camera scan, and success states.

## Project Details
- **Slug:** `create-a-mobile-30`
- **Views:** 8
- **Tags:** Technology, Landing Page, Brand, Clean, Dark, Minimal, Large Type, Verification, Identity, Security
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

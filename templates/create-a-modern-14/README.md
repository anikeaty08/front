# SteelVent Commercial Kitchen Landing Page Template

A clean, industrial SteelVent-inspired landing page template for commercial kitchen fabrication, ventilation services, and product catalog experiences.

## Project Details
- **Slug:** `create-a-modern-14`
- **Views:** 14
- **Tags:** Landing Page, Business, Services, Technology, Clean, Minimal, Grid, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

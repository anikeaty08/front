# 3D Dental Clinic Landing Page Template

A modern 3D-inspired dental clinic landing page template with online appointment booking, service highlights, testimonials, and an admin-style dashboard view.

## Project Details
- **Slug:** `create-a-modern-28`
- **Views:** 64
- **Tags:** Landing Page, Health, Services, 3D, Clean, Gradient, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

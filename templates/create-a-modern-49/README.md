# Marketplace Rental Landing Page Template

A clean and modern marketplace template designed for space rentals, featuring advanced filtering, listing grids, and a responsive booking layout.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Bank Transfer App Template

A reusable mobile banking app template for simulating money transfers, recipient verification, PIN confirmation, and transaction status flows.

## Project Details
- **Slug:** `create-a-responsive-37`
- **Views:** 61

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Artist Portal Template

A reusable dark-themed template for music artists to showcase tracks, streaming stats, balances, and reserved beat licensing offers.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

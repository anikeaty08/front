# Immersive Web App Landing Page Template

A dark, futuristic landing page template for immersive WebGL and 3D-powered web apps, ready to customize for next-gen product launches.

## Project Details
- **Slug:** `create-exact-21`
- **Views:** 12
- **Tags:** Landing Page, Technology, Brand, Futuristic, Dark, Gradient, Large Type, Minimal, 3D
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

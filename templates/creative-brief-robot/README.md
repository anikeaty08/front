# Quick Links: CREATIVE BRIEF

A reusable quick-links template for photographers and photo booth brands to showcase galleries, bookings, social profiles, guides, and contact info in one polished hub.

## Project Details
- **Slug:** `creative-brief-robot`
- **Views:** 26
- **Tags:** Landing Page, Portfolio, Services, Artist, Wedding, Minimal, Clean, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

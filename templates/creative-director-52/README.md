# Artistic Portfolio & Composer Template

A sophisticated, dark-themed template designed for composers, creative directors, and artists to showcase high-end musical and generative media projects.

## Project Details
- **Slug:** `creative-director-52`
- **Views:** 200
- **Tags:** Portfolio, Artist, Dark, Clean, Minimal, Music, Creative, Animated
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mubashir Creative Designer

A reusable portfolio template for UI/UX designers, graphic designers, and freelancers to showcase services, work, experience, and contact details.

## Project Details
- **Slug:** `creative-portfolio-60`
- **Views:** 22
- **Tags:** Portfolio, Services, Landing Page, Art & Design, Graphic Design, Clean, Minimal, Animated, Personal Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Creative Studio Portfolio Landing Page Template

A modern dark-mode portfolio landing page template for brand and web designers to showcase services, selected work, testimonials, and a contact form.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

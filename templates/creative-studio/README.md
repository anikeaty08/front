# MAZERA Fashion Landing Page Template

A reusable landing page template designed for contemporary fashion studios to showcase collections, best sellers, and brand philosophy with elegant visuals and interactive modals.

## Project Details
- **Slug:** `creative-studio`
- **Views:** 1302
- **Tags:** Landing Page, Fashion, Collections, Best Sellers, Product Modal, Gallery, Responsive, Interactive, Branding, E-commerce
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

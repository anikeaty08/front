# Creative Workshops Landing Page Template

A refined landing page template for premium art, pottery, and culinary workshop studios to showcase curricula, schedules, and bookings in an elegant layout.

## Project Details
- **Slug:** `creative-workshops-20`
- **Views:** 8
- **Tags:** Landing Page, Services, Art & Design, Portfolio, Clean, Minimal, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

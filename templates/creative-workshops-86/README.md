# Creative Workshops Landing Page Template

A warm, minimalist landing page template for creative art, ceramics, and baking workshops to showcase classes, tell your brand story, and capture bookings.

## Project Details
- **Slug:** `creative-workshops-86`
- **Views:** 4
- **Tags:** Landing Page, Services, Art & Design, Portfolio, Minimal, Clean, Gradient, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Creator Portfolio Landing Page Template

A dark, cinematic personal portfolio template for creators and designers to showcase videos, products, and contact links in a sleek single-page layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

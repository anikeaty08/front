# Creator Services Landing Page Template

A dark, premium landing page template for freelance creators offering video editing, photo editing, and content services with direct phone and email contact.

## Project Details
- **Slug:** `creator-services-24`
- **Views:** 20
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Gradient, Large Type, Portfolio, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

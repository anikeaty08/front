# Creator Application Form UI Template

A modern creator campaign application form template for UGC and influencer programs, ready to reuse in creator portals and marketing dashboards.

## Project Details
- **Slug:** `creators-sideapp`
- **Views:** 73

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

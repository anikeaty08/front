# Credit Rewards Landing Page Template

This is a reusable landing page template designed for credit card rewards programs, featuring early access signup and user-focused financial stats.

- **Slug:** `credit-rewards-25`
- **Views:** 10

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

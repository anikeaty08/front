# Dental Clinic Landing Page Template

A reusable dental clinic landing page template for private practices to showcase services, memberships, testimonials, and appointment booking.

## Project Details
- **Slug:** `crescent-dental`
- **Views:** 36
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, dental clinic, private practice, appointment booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

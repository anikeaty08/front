# Crescent Dental Harrogate

A modern dental clinic landing page template for private practices to showcase services, memberships, and contact options with a clean, patient-focused design.

## Project Details
- **Slug:** `crescentdentalharrogate`
- **Views:** 210
- **Tags:** Health, Landing Page, Services, Brand, Clean, Minimal, Large Type, Gradient, Medical, Dental
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

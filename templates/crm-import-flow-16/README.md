# CRM Import Flow UI Template

A clean CRM import flow UI template for uploading Excel files, mapping fields, and reviewing import summaries to embed in your web app.

## Project Details
- **Slug:** `crm-import-flow-16`
- **Views:** 30
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Dashboard, CRM, Import Flow, Admin UI, Web App
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# CRO Confidence Calculator Tool Template

A reusable CRO calculator template for landing pages that lets teams input A/B test data and instantly visualize confidence, uplift, and significance results.

## Project Details
- **Slug:** `cro-confidence-62`
- **Views:** 18
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Tool, AB Testing, Conversion Optimization, Calculator
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# CrossFit Gym Landing Page Template

A bold fitness club template for CrossFit gyms and training studios to showcase programs, memberships, facilities, and drive trial signups.

## Project Details
- **Slug:** `crossfit-gym-70`
- **Views:** 500
- **Tags:** Landing Page, Health, Services, Dark, Minimal, Large Type, Brand, fitness, CrossFit, gym
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Crown Bank

A modern, conversion-focused dental clinic landing page template for promoting implants, Invisalign, cosmetic treatments, and online bookings.

## Project Details
- **Slug:** `crownbankdental`
- **Views:** 16
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Gradient, Large Type, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

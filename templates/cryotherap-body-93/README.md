# Cryobody Aesthetic Clinic Landing Page Template

A clean, modern landing page template for non-surgical cryobody sculpting clinics to showcase services, pricing, results, and drive consultations.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

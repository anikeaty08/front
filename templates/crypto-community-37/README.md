# Crypto Community Landing Page Template

A reusable landing page template for Web3 communities, meme coins, and ecosystem brands to showcase mission, culture, and membership-driven growth.

## Project Details
- **Slug:** `crypto-community-37`
- **Views:** 21
- **Tags:** Landing Page, Technology, Social, Brand, Gradient, Clean, Community, Web3, Crypto
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

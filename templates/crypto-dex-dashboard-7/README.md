# Crypto DEX Metrics Landing Page Template

A dark, futuristic landing page template for showcasing decentralized exchange (DEX) performance metrics like finality, throughput, security, and scalability.

## Project Details
- **Slug:** `crypto-dex-dashboard-7`
- **Views:** 40
- **Tags:** Landing Page, Technology, Brand, Futuristic, Dark, Minimal, Large Type, Gradient

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

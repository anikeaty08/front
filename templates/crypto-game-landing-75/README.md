# Crypto Game Landing Page Template

A reusable landing page template for a Christmas-themed, provably fair crypto coin-flip game with wallet connect, live history, and animated UI.

## Project Details
- **Slug:** `crypto-game-landing-75`
- **Views:** 21
- **Tags:** Landing Page, Technology, Entertainment, Brand, Dark, Gradient, Animated, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

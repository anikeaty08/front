# Crypto Loans Mobile UI Template

A reusable mobile UI template for secure crypto lending, asset management, and loan applications with instant liquidity and no credit checks.

## Project Details
- **Slug:** `crypto-loans`
- **Views:** 947
- **Tags:** Landing Page, Mobile UI, Crypto Lending, Dashboard, Loans, Collateral, Financial, Charts, Assets, Responsive
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Crypto Merchandise & Legal Website Template

A reusable dark-mode template for crypto brands to sell merchandise, showcase community value, and publish legal policies in one polished site.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Crypto Rewards Dashboard UI Template

A dark, terminal-style template for a crypto rewards dashboard that you can reuse to display points, boost vectors, and system logs in a gamified interface.

- **Slug:** `crypto-rewards-73`
- **Views:** 132

- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

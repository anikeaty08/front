# Crypto Faucet Landing Page Template

A reusable POChain-style crypto faucet landing page template for testnet token distribution with wallet input, captcha check, and modern dark UI.

## Project Details
- **Slug:** `crypto-testnet-59`
- **Views:** 71
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Clean, Crypto, Web3
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Crypto Wallet Landing Page Template

A bold, privacy-focused crypto wallet landing page template for promoting secure Web3 apps, cold-storage support, and debit card benefits.

- **Views:** 17

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Crypto Wallet Overview UI Template

A reusable crypto wallet overview UI template for showcasing multi-asset balances, Solana network details, and core actions like send, swap, and deposit.

## Project Details
- **Slug:** `crypto-wallet-19`
- **Views:** 12
- **Tags:** Technology, Landing Page, Brand, Dark, Minimal, Gradient, Crypto wallet, Fintech UI, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# SiamWallet Crypto Landing Page Template

A reusable landing page template designed for a crypto wallet focused on the Thai market, featuring digital baht support, instant swaps, and local bank integration.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

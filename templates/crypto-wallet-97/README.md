# Crypto Wallet Landing Page Template

A sleek, dark-mode landing page template for promoting a non-custodial Solana crypto wallet app with features, security, testimonials, and download CTAs.

- **Slug:** `crypto-wallet-97`
- **Views:** 107

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Crypto Vault | Wealth Management

A reusable crypto wealth management template for showcasing investment plans, asset swaps, lending markets, and account onboarding in one polished landing page.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Crystal Gift E-commerce Landing Page Template

Elegant e-commerce template for showcasing personalized 3D crystal engraving gifts and business trophies, ready to customize for your own online store.

## Project Details
- **Slug:** `crystal-gift-85`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

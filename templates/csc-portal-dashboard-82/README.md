# CSC Customer Services Portal Dashboard Template

A modern CSC customer services portal dashboard template for searching customers, tracking applications, and managing government service transactions.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

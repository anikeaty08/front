# Cube Solver App Interface Template

A sleek interactive cube solver UI template for visualizing states, validating color layouts, and displaying solution steps for Rubik’s-style puzzles.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Culinary Restaurant Landing Page Template

A premium restaurant landing page template for showcasing menus, story, and location while driving table bookings and WhatsApp orders.

## Project Details
- **Slug:** `culinary-restaurant-2`
- **Views:** 12
- **Tags:** Food, E-commerce, Landing Page, Brand, Clean, Dark, Minimal, Restaurant, Menu, WhatsApp Ordering
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

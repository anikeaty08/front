# Cultural Presentation Landing Page Template

A reusable dark presentation template for showcasing cultural exchange stories, global influences, and educational content in an immersive slide-based format.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

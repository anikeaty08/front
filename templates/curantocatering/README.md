# Curanto - catering de fuegos

A premium landing page template for fire-based catering and event services, ideal for showcasing live cooking, values, shop, and booking in Spanish.

## Project Details
- **Slug:** `curantocatering`
- **Views:** 90
- **Tags:** Landing Page, Food, Services, Brand, Clean, Minimal, Gradient, Large Type, Catering, Event
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

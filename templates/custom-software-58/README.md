# Custom Software Agency Landing Page Template

A reusable landing page template for custom software agencies to showcase web and mobile app development, integrations, branding, and IT services.

## Project Details
- **Slug:** `custom-software-58`
- **Views:** 124
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Minimal, Large Type, Gradient, Agency, Software Development
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# SaaS Customer Health Dashboard Template

A dark, modern SaaS customer health dashboard template for managing users, revenue, automations, and activity in a CRM-style interface.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

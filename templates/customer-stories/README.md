# Customer Stories Carousel Section Template

A reusable dark-mode customer stories carousel section template for showcasing testimonial quotes and avatars on modern product or SaaS landing pages.

## Project Details
- **Slug:** `customer-stories`
- **Views:** 87
- **Tags:** Landing Page, Brand, Clean, Dark, Minimal, Gradient, testimonial carousel, customer stories, UI component, SaaS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

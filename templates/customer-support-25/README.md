# Customer Support Mobile App Template

A reusable mobile CRM and live chat dashboard template for teams managing conversations, contacts, broadcasts, and support workflows.

## Project Details
- **Slug:** `customer-support-25`
- **Views:** 97

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

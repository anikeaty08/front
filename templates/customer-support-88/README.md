# Customer Support Inbox UI Template

A modern customer support inbox UI template for prototyping multi-channel conversations, tickets, and reply workflows in helpdesk or SaaS tools.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

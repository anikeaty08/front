# Custos | Guardians of the ones you love

A reusable landing page template for privacy-first elder care and family safety products, showcasing smart home monitoring, pricing, impact, and trust-building CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

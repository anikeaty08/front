# Laser Cutting Services Landing Page Template

A modern dark-mode landing page template for laser cutting and engraving studios to showcase capabilities, pricing, and quotes-ready CTAs.

## Project Details
- **Slug:** `cut-laser-workshop`
- **Views:** 38
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Gradient, Large Type, Portfolio

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

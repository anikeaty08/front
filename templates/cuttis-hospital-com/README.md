# Plastic Surgery Hospital Landing Page Template

A premium landing page template for plastic surgery clinics and cosmetic hospitals to showcase treatments, results, trust signals, and appointment booking.

## Project Details
- **Slug:** `cuttis-hospital-com`
- **Views:** 380
- **Tags:** Health, Services, Landing Page, Clean, Dark, Minimal, hospital, plastic surgery, cosmetic clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

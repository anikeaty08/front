# CyberWise Landing Page

A clean education landing page template for online safety programs, helping schools, parents, and youth organizations present curriculum and build trust.

## Project Details
- **Slug:** `cyber-wise-dot-org`
- **Views:** 15
- **Tags:** Landing Page, Education, Technology, Clean, Minimal, Blog, Services, youth safety, digital literacy
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

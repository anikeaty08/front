# Money Frontier Conference Landing Page Template

A bilingual cyberpunk-style conference landing page template for finance and technology events, featuring agenda, speakers, tickets, and sponsor sections.

## Project Details
- **Slug:** `cyberpunk-fintech-38`
- **Views:** 54
- **Tags:** Landing Page, Brand, Technology, Conference, Dark, Gradient, Large Type, Minimal, Clean

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

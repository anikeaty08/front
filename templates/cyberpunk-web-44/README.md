# Cyberpunk Web Course Landing Page Template

A cyberpunk-styled landing page template for promoting an AI & web development course with sections for benefits, curriculum, testimonials, and pricing.

## Project Details
- **Slug:** `cyberpunk-web-44`
- **Views:** 10
- **Tags:** Landing Page, Education, Technology, Brand, Dark, Futuristic, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Cybersecurity Resume Landing Page Template

A clean, modern resume landing page template for cybersecurity students and interns to showcase skills, projects, and education in a printable, web-ready format.

## Project Details
- **Slug:** `cybersecur-resume-13`
- **Views:** 10
- **Tags:** Landing Page, Portfolio, Clean, Minimal, Technology, Brand, Resume, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

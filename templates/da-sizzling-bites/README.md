# Pizza Restaurant Landing Page Template

A modern pizza restaurant landing page template for local cloud kitchens and dine-in pizzerias to showcase menus, reviews, and location details.

## Project Details
- **Slug:** `da-sizzling-bites`
- **Views:** 510
- **Tags:** Food, Landing Page, Brand, Clean, Colorful, Minimal, Restaurant, Pizza, Local Business, Cloud Kitchen
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

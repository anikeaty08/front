# DailyFee

A clean mobile app UI template for displaying live currency exchange rates in card-based grids, ideal for fintech and finance apps.

## Project Details
- **Slug:** `dailyfeeandroidapp`
- **Views:** 45
- **Tags:** Technology, Landing Page, Brand, Clean, Minimal, Gradient, Mobile app, Fintech, Currency, UI kit
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

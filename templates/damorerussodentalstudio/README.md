# Dental Practice Landing Page Template

A modern dental practice landing page template for showcasing services, doctors, and appointment requests for local dentistry offices.

- **Slug:** `damorerussodentalstudio`
- **Views:** 27

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

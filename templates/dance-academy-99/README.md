# Dance Academy Landing Page Template

A modern dark-gradient landing page template for dance academies to showcase styles, schedules, pricing, and community while driving class registrations.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

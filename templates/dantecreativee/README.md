# Dante Creative Web Design

A dark, high-impact agency landing page template for premium web design studios to showcase services, portfolio, pricing, and capture new project inquiries.

## Project Details
- **Slug:** `dantecreativee`
- **Views:** 50
- **Tags:** Landing Page, Services, Brand, Art & Design, Portfolio, Dark, Gradient, Minimal, Large Type, Technology

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

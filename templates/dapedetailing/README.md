# dape-detailing

A premium car detailing service landing page template for studios and garages to showcase services, pricing, results, and bookings in a dark, modern style.

## Project Details
- **Slug:** `dapedetailing`
- **Views:** 66
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Gradient, Large Type, Minimal, Portfolio, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

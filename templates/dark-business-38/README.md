# Business Services Presentation Slide Template

A reusable presentation slide template for agencies and service businesses to showcase solutions, lead generation, and conversion-focused offers.

## Project Details
- **Slug:** `dark-business-38`

- **Tags:** Landing Page, Services, Technology, Dark, Minimal, Clean, Presentation, Agency, Lead Generation

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

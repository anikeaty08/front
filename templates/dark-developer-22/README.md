# Software Engineer Portfolio Website Template

A dark, minimal Software Engineer portfolio website template showcasing projects, experience, and contact CTAs, ready to customize for developers.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

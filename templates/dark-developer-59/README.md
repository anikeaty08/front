# Dark Portfolio Website Template

A reusable portfolio template for students, developers, and aspiring data or AI professionals to showcase skills, experience, projects, and contact details.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

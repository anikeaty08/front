# Documentation Community Landing Page Template

A reusable dark-mode template for documentation and certificate discussion platforms, designed to showcase posts, filters, contact info, and support resources.

## Project Details
- **Slug:** `dark-documentat-91`
- **Views:** 30
- **Tags:** Documentation, Landing Page, Education, Community, Technology, Dark, Clean, Minimal, forum, certificates
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

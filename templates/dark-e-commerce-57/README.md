# Futuristic Tech E-commerce Landing Page Template

A dark, Apple-inspired e-commerce landing page template for showcasing premium tech accessories, cases, and pricing options in a sleek, modern layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dark E-commerce Collection Landing Page Template

A dark, minimalist e-commerce landing page template for showcasing monochrome apparel collections with product grid, filters, and newsletter signups.

## Project Details
- **Slug:** `dark-fashion-78`
- **Views:** 12
- **Tags:** E-commerce, Fashion, Landing Page, Brand, Dark, Minimal, Grid, Large Type, Clean
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Gift Card Rate Calculator UI Template

A reusable dark-mode rate calculator UI template for real-time gift card exchange previews with multi-currency support and searchable dropdowns.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Roofing Services Landing Page Template

A reusable roofing services landing page template for contractors to showcase repairs, renovations, maintenance, and drive quote requests.

## Project Details
- **Slug:** `dark-landing-99`
- **Views:** 38
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Home Services, Roofing, Construction
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Ayushman-Mukherjee

A modern dark-mode portfolio template for engineers and founders to showcase projects, experience, awards, and vouches in a clean, resume-style layout.

## Project Details
- **Slug:** `dark-minimal-48`
- **Views:** 23
- **Tags:** Portfolio, Resume, Landing Page, Technology, Brand, Dark, Minimal, Large Type, Grid, Clean
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Sales Pitch Deck Template

A dark presentation template for agencies and sales teams to showcase client pain points, frame problems clearly, and guide prospects through a pitch.

## Project Details
- **Slug:** `dark-pitch-deck-37`
- **Views:** 35
- **Tags:** Landing Page, Technology, Dark, Minimal, Clean, Presentation, Pitch Deck, Sales, Agency

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

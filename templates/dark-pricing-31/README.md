# Pricing Card Template

A reusable dark pricing card template for SaaS or technology landing pages, designed to showcase premium plans, features, and a strong conversion CTA.

## Project Details
- **Slug:** `dark-pricing-31`
- **Views:** 63
- **Tags:** Landing Page, Technology, Dark, Clean, Minimal, Pricing, SaaS, Card UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

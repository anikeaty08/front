# Dark Super App Mobile UI Template

A premium dark mobile UI template for a ride, food, and delivery super app home screen, ready to customize for your own multi-service platform.

## Project Details
- **Slug:** `dark-ride-delivery-20`
- **Views:** 25
- **Tags:** Landing Page, Technology, Brand, Dark, Clean, Minimal, Mobile UI, Super App, Ride Hailing, Food Delivery
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

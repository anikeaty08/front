# Dark SaaS Landing Page Template

A reusable dark-mode SaaS landing page template with hero, metrics, features, and CTA sections for modern software product launches.

## Project Details
- **Slug:** `dark-saas-landing-10`
- **Views:** 25
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

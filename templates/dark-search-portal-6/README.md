# Minimal Search Portal Landing Page Template

A reusable dark-mode template for secure search portals, browser start pages, or gateway apps with quick links and a focused search-first interface.

## Project Details
- **Slug:** `dark-search-portal-6`
- **Views:** 75
- **Tags:** Landing Page, Technology, Dark, Minimal, Clean, portal, search, dashboard, browser start page

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

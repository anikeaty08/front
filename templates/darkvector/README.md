# Dark Vector Landing Page 0.2

A modern dark SaaS landing page template for developer-focused automation platforms, featuring hero, benefits, architecture, pricing, and CTA sections.

## Project Details
- **Slug:** `darkvector`
- **Views:** 10
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Gradient, Large Type, Minimal, SaaS, Developer Tools
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dash Ops Revenue Systems Landing Page Template

A dark, glassmorphism landing page template for Dash Ops-style revenue infrastructure services, tailored to home service businesses and scalable marketing systems.

## Project Details
- **Slug:** `dash-ops-revenue-32`
- **Views:** 10
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Gradient, Minimal, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

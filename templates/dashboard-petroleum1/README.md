# EV Charging Dashboard UI Template

A reusable dark-mode dashboard UI template for monitoring EV charging stations, connectors, and network status in real time.

## Project Details
- **Slug:** `dashboard-petroleum1`
- **Views:** 70
- **Tags:** Technology, Landing Page, Brand, Dark, Dashboard, EV charging, Admin panel, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Performance Marketing Agency Landing Page Template

A reusable landing page template for data-driven performance marketing agencies to showcase systems, process, and results while converting visitors into strategy calls.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

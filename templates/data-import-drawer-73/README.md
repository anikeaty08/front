# Data Import Drawer UI Template

A modern, reusable Data Import Drawer UI template for inspecting uploaded files, reviewing row-level data, and managing processing states in web apps.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

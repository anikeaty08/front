# SuperFlowSQL Data Orchestration Landing Page Template

A reusable landing page template for promoting a modern data orchestration platform integrating Airflow, PostgreSQL, PgAdmin, and Superset.

## Project Details
- **Slug:** `data-orchestrat-97`
- **Views:** 5
- **Tags:** Landing Page, Technology, Brand, Clean, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

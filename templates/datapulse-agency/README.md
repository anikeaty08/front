# Analytics & Marketing Services Landing Page Template

A clean, data-driven landing page template for analytics, GA4, and marketing implementation agencies to showcase services, case studies, and blog content.

## Project Details
- **Slug:** `datapulse-agency`
- **Views:** 16
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Gradient, Large Type, Analytics, Agency
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

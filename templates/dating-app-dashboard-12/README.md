# Dating App Discovery Interface Template

A reusable dating app template for showcasing nearby profiles, filtering matches, and driving engagement through likes, chat, and discovery flows.

## Project Details
- **Slug:** `dating-app-dashboard-12`
- **Views:** 24
- **Tags:** Landing Page, Social, Technology, Dark, Clean, Minimal, mobile app, dating, discovery, dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

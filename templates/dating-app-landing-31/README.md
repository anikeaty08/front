# Dating App Mobile UI Template

A sleek reusable mobile app template for proximity-based dating and social discovery, featuring nearby matches, profile signals, and chat-focused interactions.

## Project Details
- **Slug:** `dating-app-landing-31`
- **Views:** 50
- **Tags:** Landing Page, Technology, Clean, Minimal, Dark, Mobile App, Dating, Social
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

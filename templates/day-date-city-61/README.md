# Japan Trip Itinerary Planner Template

A reusable Japan trip itinerary planner template for visualizing multi-city, multi-day travel plans with times, logistics, hotels, and map links in a sleek dark UI.

## Project Details
- **Slug:** `day-date-city-61`
- **Views:** 13
- **Tags:** Travel, Landing Page, Brand, Clean, Dark, Minimal, Grid, Itinerary, Planner, Japan
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# DayStarr

Bold streetwear e-commerce landing page template for skate and apparel brands to showcase collections, highlight drops, and drive Buy Now conversions.

## Project Details
- **Slug:** `daystarrforever`
- **Views:** 34
- **Tags:** E-commerce, Fashion, Landing Page, Brand, Minimal, Large Type, Clean, Style, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

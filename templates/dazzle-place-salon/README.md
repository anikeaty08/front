# Beauty Salon Landing Page Template

A premium beauty salon landing page template for showcasing hair, lash, brow, and nail services with bookings, testimonials, and gallery in an elegant style.

## Project Details
- **Slug:** `dazzle-place-salon`
- **Views:** 42
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Portfolio, Beauty Salon, Booking, Testimonials
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Creative Communications Agency Landing Page Template

A minimalist creative communications agency landing page template with draggable cards and fixed header/footer layout, ready to customize for modern studios.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

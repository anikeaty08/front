# Deals Directory Landing Page Template

A dark, modern deals directory template for showcasing verified offers, coupons, and discounts with filters, search, and card-based layouts.

## Project Details
- **Slug:** `deals-explorer-63`
- **Views:** 40
- **Tags:** Landing Page, E-commerce, Technology, Brand, Dark, Clean, Gradient, Large Type, Minimal, Grid
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Health Podcast Landing Page Template

A reusable landing page template for health and healthcare podcasts to showcase episodes, hosts, frameworks, and grow subscriber lists.

- **Slug:** `deciding-health-v2`
- **Views:** 774

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

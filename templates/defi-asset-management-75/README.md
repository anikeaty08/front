# Crypto Asset Management Landing Page Template

A dark, institutional-grade crypto asset management landing page template for DeFi funds and DaaS providers to showcase on-chain strategies and services.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# DeFi Mobile App Landing Page Template

A modern DeFi mobile app landing page template for promoting non-custodial, high-speed crypto trading and wallet experiences on Sui or similar networks.

## Project Details
- **Slug:** `defi-mobile-app-80`
- **Views:** 120
- **Tags:** Landing Page, Technology, Brand, Clean, Gradient, Dark, Minimal, DeFi, Mobile App, Crypto
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

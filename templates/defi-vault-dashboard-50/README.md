# Crypto Vaults Dashboard Template

A dark, hacker-style crypto vaults dashboard template for tracking protocol and user vault performance, TVL, and APR in DeFi apps.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Delivery Success Mobile App Template

A reusable mobile app template for delivery, logistics, and agent handover confirmation screens with rewards, progress tracking, and clear post-delivery actions.

## Project Details
- **Slug:** `delivery-success-68`
- **Views:** 13

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

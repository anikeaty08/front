# Стомотология Астана

A reusable landing page template for modern dental clinics to showcase services, before-and-after cases, team expertise, reviews, and appointment booking.

## Project Details
- **Slug:** `deltastomclinic-test`
- **Views:** 24
- **Tags:** Дельта Стом, Стомотологий Астана, Детские стомотологий Астана, Delta Stom
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

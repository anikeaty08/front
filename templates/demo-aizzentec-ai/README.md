# AI MVP Studio Landing Page Template

A sleek, dark-mode landing page template for AI MVP studios and product agencies to showcase a 20-day build process, features, pricing, and lead capture.

## Project Details
- **Slug:** `demo-aizzentec-ai`
- **Views:** 70
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Minimal, Large Type, AI MVP, Agency
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Packaging Manufacturer Landing Page Template

Reusable landing page template for corrugated cardboard packaging manufacturers to showcase products, quality certifications, and flexible production services.

## Project Details
- **Slug:** `demo-cajas-san-luis`
- **Views:** 11
- **Tags:** Landing Page, Business, Services, Brand, Clean, Minimal, Large Type, Technology, E-commerce, Industrial

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

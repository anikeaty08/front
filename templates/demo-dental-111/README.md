# Dental Clinic Landing Page Template

A modern, calming dental clinic landing page template with live-style appointment widget, services, interiors, team, testimonials, and contact layout.

## Project Details
- **Slug:** `demo-dental-111`
- **Views:** 22
- **Tags:** Health, Services, Landing Page, Brand, Clean, Gradient, Minimal, Large Type, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

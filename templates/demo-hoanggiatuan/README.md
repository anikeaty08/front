# Human Resources Services Landing Page Template

A professional Vietnamese HR services landing page template for staffing, outsourcing, and workforce management providers to showcase services and capture leads.

## Project Details
- **Slug:** `demo-hoanggiatuan`
- **Views:** 30
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Healthcare Software Agency Landing Page Template

A conversion-focused template for healthcare software agencies to showcase compliant development services, case studies, and book discovery calls.

## Project Details
- **Slug:** `demo-latenthqwebsite`
- **Views:** 90
- **Tags:** Landing Page, Health, Services, Technology, Brand, Dark, Clean, Gradient, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

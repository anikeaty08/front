# Pastry Mania Bakery Template

A high-end artisanal bakery and cake boutique landing page template featuring WhatsApp ordering integration and a premium signature menu.

## Project Details
- **Slug:** `demobakerywebsite`
- **Views:** 23
- **Tags:** Food, Services, Landing Page, Brand, Clean, Minimal, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

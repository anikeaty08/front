# Premium Travel Booking Landing Page Template

A reusable landing page template for premium cab, tour, and intercity travel services with instant booking, fare estimation, and WhatsApp conversion flows.

## Project Details
- **Slug:** `demov3travels-1`
- **Views:** 28
- **Tags:** Landing Page, Travel, Services, Dark, Minimal, Futuristic, Technology, booking, transportation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

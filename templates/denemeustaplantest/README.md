# Auto Service Management App Template

A reusable mobile app template for auto repair shops to manage appointments, customers, inventory, revenue, and marketing in one streamlined interface.

## Project Details
- **Slug:** `denemeustaplantest`
- **Views:** 39
- **Tags:** Technology, Services, Landing Page, Clean, Minimal, Mobile App, Dashboard, Scheduling, Auto Service
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

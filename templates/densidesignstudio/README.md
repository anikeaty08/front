# Freelance Graphic Designer Portfolio Template

A clean, elegant portfolio template for freelance graphic designers to showcase services, projects, process, and capture client inquiries.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

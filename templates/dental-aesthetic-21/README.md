# Dental & Aesthetic Clinic Landing Page Template

A premium clinic landing page template for dental, skin, and aesthetic practices to showcase treatments, patient stories, and streamline appointment bookings.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

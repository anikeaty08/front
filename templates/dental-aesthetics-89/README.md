# Dental Aesthetic Landing Page Template

A reusable landing page template for dentists and facial aesthetics clinics to showcase treatments, philosophy, and drive appointment bookings.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

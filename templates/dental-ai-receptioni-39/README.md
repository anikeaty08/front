# Dental AI Receptionist Dashboard Template

A reusable dashboard template for dental clinics to manage AI receptionist chats, urgent triage, scheduling, and human takeover workflows.

## Project Details
- **Slug:** `dental-ai-receptioni-39`
- **Views:** 73

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Services Landing Page Template

A reusable landing page template for dental and community health centers to showcase services, providers, locations, and telehealth options.

## Project Details
- **Slug:** `dental-care-landing-76`
- **Views:** 24
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Technology, Dental, Medical

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

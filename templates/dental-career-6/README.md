# Dental Career Landing Page Template

A modern recruiting landing page template for dental clinics and practices to attract dentists and specialists with benefits, culture, FAQs, and an application form.

## Project Details
- **Slug:** `dental-career-6`
- **Views:** 8
- **Tags:** Landing Page, Services, Health, Brand, Clean, Gradient, Large Type, Minimal, Recruiting, Dental
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

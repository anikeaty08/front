# Dental Clinic Landing Page Template

A reusable dental clinic landing page template for promoting services, showcasing staff, and capturing appointment requests for local practices.

## Project Details
- **Slug:** `dental-clinic-16`
- **Views:** 38
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Grid, medical, dental clinic, appointment form
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

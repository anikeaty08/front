# Dental Clinic Landing Page Template

A modern dental clinic landing page template for restorative and cosmetic practices to showcase services, build trust, and drive appointment bookings.

## Project Details
- **Slug:** `dental-clinic-22`
- **Views:** 2
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Technology, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

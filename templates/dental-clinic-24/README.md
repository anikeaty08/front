# Dental Practice Landing Page Template

A modern dental practice website template for clinics to showcase services, patient stories, and appointment CTAs with a calm, trust-building design.

## Project Details
- **Slug:** `dental-clinic-24`
- **Views:** 24
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Clinic Landing Page Template

A reusable dental clinic landing page template for promoting services, showcasing location and hours, and driving patient appointment bookings.

## Project Details
- **Slug:** `dental-clinic-29`
- **Views:** 45
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Grid, Dental, Clinic, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

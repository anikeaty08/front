# Dental Clinic Landing Page Template

Modern VT Dental-inspired landing page template for dental clinics to showcase treatments, team, technology, and appointment booking in a clean, patient-focused layout.

## Project Details
- **Slug:** `dental-clinic-3`
- **Views:** 39
- **Tags:** Landing Page, Health, Services, Brand, Clean, Gradient, Minimal, Large Type, Technology, Dental
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

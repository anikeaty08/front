# Dental Clinic Landing Page Template

Modern Italian-language dental clinic landing page template for promoting services, showcasing team expertise, and driving online appointment bookings.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

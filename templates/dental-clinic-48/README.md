# Dental Clinic Landing Page Template

A polished dental practice template for clinics to showcase services, build trust with reviews, and drive appointment bookings online.

## Project Details
- **Slug:** `dental-clinic-48`
- **Views:** 30
- **Tags:** Health, Services, Landing Page, Clean, Gradient, Minimal, dental, clinic, appointment booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

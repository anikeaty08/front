# Dental Clinic Landing Page Template

A modern dental clinic landing page template for showcasing services, specialists, testimonials, and appointment CTAs for local healthcare practices.

## Project Details
- **Slug:** `dental-clinic-50`
- **Views:** 502
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Clinic, Medical, Healthcare
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

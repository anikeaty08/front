# Dental Clinic Landing Page Template

A reusable dental clinic landing page template for promoting services, new patient offers, emergency care, testimonials, and online appointment bookings.

## Project Details
- **Slug:** `dental-clinic-51`
- **Views:** 25
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Luxury, Medical, Dental, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

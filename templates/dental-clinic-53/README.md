# Dental Clinic Landing Page Template

A modern, conversion-focused dental clinic landing page template for family, cosmetic, and emergency dentistry practices to showcase services and book patients online.

## Project Details
- **Slug:** `dental-clinic-53`
- **Views:** 19
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Gradient, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

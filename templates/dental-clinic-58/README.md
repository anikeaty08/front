# Dental Clinic Landing Page Template

A modern dental clinic landing page template for promoting premium dental services, showcasing testimonials, and capturing appointment bookings online.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

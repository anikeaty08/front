# Dental Clinic Landing Page Template

A modern, family-focused dental clinic landing page template for showcasing services, team, and contact details for local dentistry practices.

## Project Details
- **Slug:** `dental-clinic-6`
- **Views:** 37
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

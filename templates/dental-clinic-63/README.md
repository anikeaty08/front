# Dental Clinic Landing Page Template

A modern Sil-Dom Dentistry-inspired landing page template for family and cosmetic dental clinics to showcase services, offers, and online booking.

## Project Details
- **Slug:** `dental-clinic-63`
- **Views:** 14

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

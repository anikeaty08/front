# Dental Clinic Landing Page Template

A modern, family dental clinic landing page template designed for local practices to showcase services, providers, reviews, and booking options.

## Project Details
- **Slug:** `dental-clinic-63test`
- **Views:** 7
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, Technology, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

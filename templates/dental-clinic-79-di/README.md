# Dental Clinic Landing Page Template

A reusable landing page template for modern dental clinics to showcase services, team, FAQs, and online appointment bookings.

## Project Details
- **Slug:** `dental-clinic-79-di`
- **Views:** 24

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

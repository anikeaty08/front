# Dental Clinic Landing Page Template

A clean, modern dental clinic landing page template for promoting advanced dental care services, showcasing treatments, testimonials, and online appointment booking.

## Project Details
- **Slug:** `dental-clinic-82`
- **Views:** 25

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

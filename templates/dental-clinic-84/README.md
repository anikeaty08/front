# Dental Clinic Landing Page Template

A modern DentaCare-style dental clinic landing page template for showcasing services, team, pricing, and contact options to book patient appointments.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Campaign Landing Page Template

A modern landing page template for dental clinics running coffee-partner prevention campaigns, ready to customize for your own promotion and bookings.

## Project Details
- **Slug:** `dental-clinic-87`
- **Views:** 38
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

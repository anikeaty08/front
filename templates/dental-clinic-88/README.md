# Dental Clinic Landing Page Template

A modern Dental Clinic Landing Page Template for aesthetic dentistry practices to showcase services, smile transformations, and book patient appointments.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Clinic Landing Page Template

A clean dental clinic landing page template designed to showcase treatments, build trust with reviews, and drive appointment bookings for local practices.

## Project Details
- **Slug:** `dental-clinic-9`
- **Views:** 70
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, local clinic, appointment booking, medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

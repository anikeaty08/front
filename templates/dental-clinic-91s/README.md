# Dental Clinic Landing Page Template

A modern Singh Dental-inspired landing page template for dental clinics to showcase treatments, reviews, and online appointment booking with a clean, professional layout.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

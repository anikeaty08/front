# Dental Clinic Landing Page Template

A modern dental clinic landing page template for showcasing services, team, and online appointment bookings for local dentistry practices.

## Project Details
- **Slug:** `dental-clinic-93`
- **Views:** 21
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Gradient, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Clinic Landing Page Template

A reusable dental clinic landing page template for family and cosmetic dentists to showcase services, social proof, and appointments in a clean, modern layout.

## Project Details
- **Slug:** `dental-clinic-96`
- **Views:** 30
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Technology, Portfolio, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Clinic Landing Page Template

A reusable dental clinic landing page template for dentists and specialty practices to showcase services, build trust, and drive appointment bookings.

## Project Details
- **Slug:** `dental-clinic-cli1`
- **Views:** 20
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Brand, dental clinic, appointment booking, medical practice
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

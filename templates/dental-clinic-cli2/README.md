# Dental Clinic Landing Page Template

A modern dental clinic template for showcasing services, building trust, and driving appointment bookings for local practices and surgeons.

## Project Details
- **Slug:** `dental-clinic-cli2`
- **Views:** 28
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Local business, Medical, Clinic, Appointment booking

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

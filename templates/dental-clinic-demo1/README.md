# Dental Clinic Landing Page Template

A reusable landing page template for dentists and dental clinics to showcase treatments, build trust, and drive appointment bookings with a premium feel.

## Project Details
- **Slug:** `dental-clinic-demo1`
- **Views:** 33
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Luxury, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

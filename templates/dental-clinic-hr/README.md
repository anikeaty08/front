# Dental Clinic Landing Page Template

A clean, modern dental clinic landing page template for showcasing services, pricing, technology, and contact booking for local practices.

## Project Details
- **Slug:** `dental-clinic-hr`
- **Views:** 31
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Gradient, Large Type, Technology, Dental
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

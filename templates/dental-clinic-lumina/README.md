# Lumina Dental Clinic Landing Page Template

A modern Lumina Dental clinic landing page template for dentists and dental practices to showcase services, build trust, and drive online appointments.

## Project Details
- **Slug:** `dental-clinic-lumina`
- **Views:** 21
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

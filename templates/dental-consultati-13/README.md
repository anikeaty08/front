# Dental Consultation Landing Page Template

A reusable dental landing page template for clinics promoting smile makeovers, insurance-friendly treatment, patient testimonials, and free consultation bookings.

## Project Details
- **Slug:** `dental-consultati-13`
- **Views:** 71
- **Tags:** Landing Page, Health, Services, Clean, Minimal, 3D, testimonials, dental, insurance, local clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

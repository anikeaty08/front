# Dental Consultation Landing Page Template

A reusable dental consultation landing page template designed to help implant clinics build trust, showcase expertise, and drive appointment bookings.

## Project Details
- **Slug:** `dental-consultati-17`
- **Views:** 21
- **Tags:** Landing Page, Health, Services, Clean, Dark, Minimal, testimonials, dental, consultation, medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

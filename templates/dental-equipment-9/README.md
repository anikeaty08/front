# Dental Equipment Product Landing Page Template

A clean, structured landing page template for showcasing a dental unit or medical equipment, with sections for advantages, specs, media, and documentation.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

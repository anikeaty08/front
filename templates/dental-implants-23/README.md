# Dental Implant Landing Page Template

A reusable landing page template for oral surgery and dental implant practices to promote full-arch smile restoration, build trust, and drive consultations.

## Project Details
- **Slug:** `dental-implants-23`
- **Views:** 40
- **Tags:** Landing Page, Health, Services, Clean, Minimal, testimonials, dental implants, oral surgery, medical marketing

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental IT Services Landing Page Template

A reusable landing page template for dental IT and data infrastructure firms to showcase backups, recovery, CRM solutions, pricing, and consultations.

## Project Details
- **Slug:** `dental-it-services-16`
- **Views:** 16
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Futuristic, healthcare IT, dental, SaaS, consulting
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

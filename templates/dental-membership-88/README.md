# Dental Membership Landing Page Template

A reusable landing page template for dental membership platforms promoting education, EMC credits, webinars, and smarter procurement tools for dentists.

- **Slug:** `dental-membership-88`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

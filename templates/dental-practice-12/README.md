# Dental Practice Landing Page Template

A reusable dental clinic website template for cosmetic and general practices to showcase providers, services, office tours, and drive online bookings.

## Project Details
- **Slug:** `dental-practice-12`
- **Views:** 46
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, dental, cosmetic dentistry, medical, booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Practice Landing Page Template

Clean, patient-focused dental practice landing page template for local clinics to showcase services, hours, and contact details with clear CTAs.

## Project Details
- **Slug:** `dental-practice-22`
- **Views:** 40
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

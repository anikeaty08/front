# Dental Practice Landing Page Template

A modern dental practice landing page template for family and cosmetic dentists to showcase services, reviews, and schedule appointments online.

## Project Details
- **Slug:** `dental-practice-37`
- **Views:** 26
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

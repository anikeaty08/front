# Dental Clinic Landing Page Template

Modern dental practice landing page template for showcasing services, emergency info, team, and contact details for local dentists and clinics.

## Project Details
- **Slug:** `dental-practice-62`
- **Views:** 16
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

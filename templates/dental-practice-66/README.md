# Dental Clinic Landing Page Template

Customizable landing page template for modern dental clinics to showcase services like whitening, implants, and family dentistry and drive new patient appointments.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

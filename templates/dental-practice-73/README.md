# Dental Clinic Landing Page Template

A modern dental clinic landing page template for NHS and private practices to showcase treatments, pricing options, and location details with clear booking CTAs.

## Project Details
- **Slug:** `dental-practice-73`
- **Views:** 11
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Dental, Clinic, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Practice Landing Page Template

A refined dental practice landing page template for modern clinics to showcase services, office tour, and appointments with a calm, welcoming brand experience.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Practice Landing Page Template

A clean, modern dental practice website template for showcasing NHS and private treatments, team bios, and contact options for local patients.

## Project Details
- **Slug:** `dental-practice-91`
- **Views:** 16
- **Tags:** Health, Landing Page, Services, Brand, Clean, Gradient, Minimal, Large Type, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

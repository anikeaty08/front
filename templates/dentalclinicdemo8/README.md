# Dental Clinic 0

A reusable dental clinic landing page template for private practices promoting services, memberships, testimonials, and appointment bookings.

## Project Details
- **Slug:** `dentalclinicdemo8`
- **Views:** 8
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Brand, dental clinic, medical, appointment booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

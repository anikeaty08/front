# Dental Clinic Landing Page Template

A modern, patient-first dental clinic landing page template designed for sedation and family dentistry practices to showcase services and capture appointments.

## Project Details
- **Slug:** `dentalclinichelptest`
- **Views:** 32
- **Tags:** Landing Page, Services, Health, Brand, Clean, Gradient, Large Type, Minimal, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

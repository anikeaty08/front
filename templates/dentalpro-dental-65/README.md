# DentalPro Clinic Dashboard UI Template

A clean DentalPro dashboard UI template for dental clinics to manage appointments, patients, billing, and revenue at a glance, ready for reuse in your app.

## Project Details
- **Slug:** `dentalpro-dental-65`
- **Views:** 99
- **Tags:** Landing Page, Health, Technology, Dashboard, Clean, Minimal, Gradient, Large Type, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

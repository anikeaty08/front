# Dental Clinic Landing Page Template

A modern dental clinic landing page template for showcasing services, specialists, locations, and online appointment booking.

## Project Details
- **Slug:** `dentistree-oral-care`
- **Views:** 9
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Healthcare, Dental Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Career Landing Page Template

A premium dental practice career landing page template for showcasing culture, benefits, and open positions while driving applications from dental staff.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

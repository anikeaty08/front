# Depth Swimming Training Programs

A reusable Depth Swimming login page template with modern glassmorphism styling, social sign-in, and email/password access for web applications.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

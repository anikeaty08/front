# Dermatology Clinic Landing Page Template

A modern dermatology clinic website template for promoting medical, cosmetic, and surgical skin services with locations, insurance, and appointment booking.

## Project Details
- **Slug:** `dermatolog-clinic-38`
- **Views:** 125
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Medical, Clinic, Dermatology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

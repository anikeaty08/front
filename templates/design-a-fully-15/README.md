# Tech Conference Landing Page Template

A reusable dark-themed TEC Expo landing page template for tech conferences and events, featuring halls overview, schedule timeline, sponsors, and registration CTAs.

## Project Details
- **Slug:** `design-a-fully-15`
- **Views:** 32
- **Tags:** Landing Page, Conference, Education, Technology, Brand, Dark, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

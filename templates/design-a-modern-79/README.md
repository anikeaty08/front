# Local Services Marketplace Landing Page Template

A reusable landing page template for promoting a local services marketplace that helps users find, book, and manage trusted professionals nearby.

## Project Details
- **Slug:** `design-a-modern-79`
- **Views:** 57
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Dark, marketplace, local services, booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

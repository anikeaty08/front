# Design Conference Landing Page Template

A reusable landing page template for design summits and creative conferences, featuring speaker highlights, agenda sections, venue details, sponsors, and registration CTA.

## Project Details
- **Slug:** `design-conference-6`
- **Views:** 240
- **Tags:** Landing Page, Conference, Education, Technology, Dark, Futuristic, Gradient, Large Type, Animated
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

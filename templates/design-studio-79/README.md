# Design Studio Landing Page Template

A dark, gradient-rich landing page template for digital design studios to showcase UX/UI, branding, and web development services with a bold portfolio.

- **Slug:** `design-studio-79`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

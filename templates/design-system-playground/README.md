# UI Style Variant Generator

A modular Design Mutation System template for experimenting with 36 SaaS and creative landing page styles, ready to adapt into your own product or marketing site.

## Project Details
- **Slug:** `design-system-playground`
- **Views:** 2682

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

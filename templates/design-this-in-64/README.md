# Fitness Tracker Mobile UI Template

A sleek dark-mode fitness tracker mobile UI template for showcasing workout splits, streaks, and calendar-based progress in modern health apps.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

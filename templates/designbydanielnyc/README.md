# Product Designer Portfolio Website Template

A dark, minimal product designer portfolio website template to showcase selected work, experience, and contact details with a modern, grid-based layout.

## Project Details
- **Slug:** `designbydanielnyc`
- **Views:** 20
- **Tags:** Portfolio, Landing Page, Art & Design, Minimal, Dark, Clean, Grid, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

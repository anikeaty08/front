# Architecture & Interior Design Landing Page Template

A clean, modern landing page template for architecture and interior design studios to showcase services, projects, testimonials, and consultations.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dessert Takeaway Landing Page Template

A reusable dessert shop landing page template for takeaway or delivery brands, featuring bold hero imagery, menu highlights, and multiple Order Now CTAs.

- **Slug:** `dessert-shop-15`
- **Views:** 40
- **Tags:** Landing Page, Food, E-commerce, Brand, Colorful, Large Type, Clean, Gradient, Dessert, Takeaway

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

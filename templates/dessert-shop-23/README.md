# Dessert Shop Landing Page Template

A reusable dessert shop landing page template for promoting signature treats, featured menu items, bundles, and online ordering with a premium brand feel.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

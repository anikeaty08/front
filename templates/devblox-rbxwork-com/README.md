# Game Developer Marketplace Landing Page Template

A reusable landing page template for showcasing and hiring game developers, with talent search, profiles, pricing, and creator onboarding sections.

## Project Details
- **Slug:** `devblox-rbxwork-com`
- **Views:** 33
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Portfolio, Marketplace, Hiring, Freelance

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

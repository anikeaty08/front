# Developer E-commerce Storefront Template

A dark, minimal e-commerce template for showcasing and selling modern developer apparel, accessories, and objects with filters, grid, and cart UI.

## Project Details
- **Slug:** `developer-e-commerce-31`
- **Views:** 21
- **Tags:** E-commerce, Landing Page, Technology, Brand, Dark, Minimal, Grid, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

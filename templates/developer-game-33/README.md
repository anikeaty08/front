# Developer Game Landing Page Template

A dark, glitchy developer game UI landing page template that lets you showcase a playful ‘ship’ simulator experience for coders and tech audiences.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

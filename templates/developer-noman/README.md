# Developer Portfolio Website Template

A reusable dark-mode portfolio template for freelance developers and designers to showcase skills, projects, workflow, and contact details with polished motion.

## Project Details
- **Slug:** `developer-noman`
- **Views:** 99
- **Tags:** Portfolio, Landing Page, Technology, Dark, Gradient, Clean, Minimal, Animated, Developer, Freelancer
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

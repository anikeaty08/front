# Developer Playground Dashboard Template

A reusable developer playground dashboard template for showcasing live React previews, code editing, and system logs in a modern dark UI.

## Project Details
- **Slug:** `developer-playground-18`
- **Views:** 65
- **Tags:** Landing Page, Technology, Brand, Dark, Clean, Minimal, Developer dashboard, React playground, Code editor
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

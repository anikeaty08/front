# Developer Portfolio Website Template

A clean, Mac-style developer portfolio template for showcasing projects, tech stack, and experience with featured cards, stats, and a contact CTA.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Developer Portfolio Template

A reusable dark portfolio template for full stack developers to showcase experience, skills, projects, education, and contact details with a polished personal brand.

## Project Details
- **Slug:** `developer-portfolio-15`
- **Views:** 45
- **Tags:** Portfolio, Resume, Landing Page, Technology, Dark, Minimal, Clean, Personal Brand, Developer
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

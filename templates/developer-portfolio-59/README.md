# ManasDev Minecraft and Developer Portfolio 

A reusable dark portfolio template for full-stack developers to showcase projects, experience, skills, and contact calls-to-action.

## Project Details
- **Slug:** `developer-portfolio-59`
- **Views:** 98

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

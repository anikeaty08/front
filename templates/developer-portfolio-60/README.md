# Developer Portfolio Website Template

A modern dark-mode developer portfolio website template for CSE students and junior developers to showcase skills, projects, achievements, and a blog.

## Project Details
- **Slug:** `developer-portfolio-60`
- **Views:** 16
- **Tags:** Portfolio, Landing Page, Technology, Brand, Minimal, Dark, Large Type, Grid, Developer Portfolio, Student
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

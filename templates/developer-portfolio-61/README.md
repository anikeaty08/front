# Personal Portfolio Landing Page Template

A modern personal portfolio landing page template for young developers and creators to showcase vision, skills, projects, and a future app in a clean layout.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

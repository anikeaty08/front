# NexFind Admin Dashboard UI Template

A modern NexFind Admin Dashboard UI template for agencies and SaaS teams to manage clients, requests, analytics, and reports in a sleek dark interface.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Minimal Chat App Landing Page Template

A clean, Apple-inspired chat app landing page template for WordPress or SaaS products, showcasing features, philosophy, and download CTAs.

## Project Details
- **Slug:** `devhushdemolandingpage`
- **Views:** 29
- **Tags:** Landing Page, Technology, Brand, Minimal, Clean, Gradient, Large Type, Portfolio, Dark
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

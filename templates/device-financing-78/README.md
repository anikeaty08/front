# Installment Purchase Mobile Landing Page Template

A modern RTL mobile-first landing page template for showcasing smartphone installment purchase plans with a built-in financing calculator.

## Project Details
- **Slug:** `device-financing-78`
- **Views:** 7
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Gradient, Large Type, RTL, Mobile-first
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

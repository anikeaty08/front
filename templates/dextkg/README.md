# Software Agency Landing Page Template

A modern dark/light bilingual software agency landing page template for development studios to showcase services, stack, methodology, pricing, and contact details.

## Project Details
- **Slug:** `dextkg`
- **Views:** 15
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Dark, Gradient, Large Type, Portfolio, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

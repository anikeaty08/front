# Dental Clinic Landing Page Template

A reusable dental clinic landing page template for dentists and family practices to showcase services, build trust, and drive appointment bookings.

## Project Details
- **Slug:** `dharmadentalhospital`
- **Views:** 28
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Brand, medical, dental clinic, dentist, family care
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

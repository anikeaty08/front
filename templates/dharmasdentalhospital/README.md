# Dental Hospital Landing Page Template

A clean healthcare template for dental hospitals and clinics to showcase services, doctor credibility, location, and appointment calls.

## Project Details
- **Slug:** `dharmasdentalhospital`
- **Views:** 27
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Medical, Dental Clinic, Hospital, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Minecraft Server Landing Page Template

A dark, modern Minecraft server landing page template for showcasing features, server IP, and Discord, ready to customize for any gaming community.

## Project Details
- **Slug:** `diablo-server-009`
- **Views:** 41
- **Tags:** Landing Page, Technology, Gaming, Dark, Gradient, Large Type, Minimal, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

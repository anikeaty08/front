# Digi Verse 

A bold, dark-style landing page template for digital marketing agencies offering Shopify, ads, and influencer services to manage and scale online businesses.

- **Slug:** `digii-verse-360`
- **Views:** 594

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

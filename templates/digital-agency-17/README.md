# Digital Agency Landing Page Template

A modern digital agency landing page template for showcasing web design, SEO services, pricing, and testimonials to win new web projects.

## Project Details
- **Slug:** `digital-agency-17`
- **Views:** 20
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Gradient, Minimal, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

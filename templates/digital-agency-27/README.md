# Digital Agency Landing Page Template

A reusable dark-mode template for digital agencies and brand studios to showcase services, portfolio work, founder credibility, and startup-focused design expertise.

## Project Details
- **Slug:** `digital-agency-27`
- **Views:** 50
- **Tags:** Landing Page, Services, Brand, Portfolio, Technology, Dark, Clean, Minimal, Animated

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

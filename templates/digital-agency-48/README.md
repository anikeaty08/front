# Digital Agency Landing Page Template

Modern NexDigital-inspired landing page template with blog and admin panel for digital marketing and SEO agencies to showcase services and publish content.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

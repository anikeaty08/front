# Digital Agency Landing Page Template

A modern dark-mode digital agency landing page template for showcasing services, industries, and technologies while driving project proposals and sales inquiries.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

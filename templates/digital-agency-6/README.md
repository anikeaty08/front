# Digital Agency Landing Page Template

A modern brutalist digital agency landing page template for showcasing web development, SEO, and branding services, ready to customize for your studio.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

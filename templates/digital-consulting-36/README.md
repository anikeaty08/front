# Digital Consulting Landing Page Template

A reusable landing page template for digital consulting firms to showcase transformation services, pillars, and contact CTAs with a polished modern design.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

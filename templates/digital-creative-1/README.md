# Digital Creative Portfolio Website Template

A modern, minimal portfolio website template for digital creatives and web designers to showcase work, services, experience, awards, and testimonials with a strong personal brand.

- **Slug:** `digital-creative-1`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

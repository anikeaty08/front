# Digital Designer Portfolio Template

A reusable portfolio template for digital designers and developers to showcase services, featured projects, and contact options with a polished personal brand.

## Project Details
- **Slug:** `digital-designer-11`
- **Views:** 32
- **Tags:** Portfolio, Services, Brand, Graphic Design, Dark, Minimal, Clean, Grid, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

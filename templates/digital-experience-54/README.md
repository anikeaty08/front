# Digital Agency Landing Page Template

A dark, futuristic digital agency landing page template for showcasing services, process, and lead-gen contact forms for creative and tech studios.

## Project Details
- **Slug:** `digital-experience-54`
- **Views:** 24
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Gradient, Minimal, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

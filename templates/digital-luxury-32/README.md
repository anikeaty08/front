# High-End Digital Experience Landing Page Template

A high-end digital experience landing page template for luxury SaaS and tech brands to showcase product vision, roadmap, journal content, and client testimonials.

- **Slug:** `digital-luxury-32`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

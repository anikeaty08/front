# Digital Repair Service Landing Page Template

Modern one-page template for a digital repair service, ideal for showcasing device repair offerings, benefits, and lead-capture forms as a reusable landing page.

## Project Details
- **Slug:** `digital-repair-38`
- **Views:** 11
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Gradient, Large Type, Minimal

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

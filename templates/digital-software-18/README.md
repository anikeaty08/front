# Digital Software Marketplace Template

A modern digital software marketplace template for showcasing products, managing carts, and handling user accounts with customer and admin dashboards.

- **Slug:** `digital-software-18`
- **Views:** 10

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

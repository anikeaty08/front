# .ntdesign Creative Studio Landing Page Template

A dark, minimal .ntdesign landing page template for creative studios to showcase digital product design, development services, and portfolio case studies.

## Project Details
- **Slug:** `digital-studio-8`
- **Views:** 3
- **Tags:** Landing Page, Brand, Art & Design, Portfolio, Minimal, Dark, Gradient, Large Type, Technology, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

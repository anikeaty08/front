# Digital Obscura Visual Archive Template

A cinematic, high-concept portfolio and digital exhibition template designed for photographers and artists looking to document memories with a technical, archival aesthetic.

## Project Details
- **Slug:** `digitalobscura`
- **Views:** 256
- **Tags:** Portfolio, Art & Design, Dark, Minimal, Clean, Animated, Futuristic, Gallery, Creative
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

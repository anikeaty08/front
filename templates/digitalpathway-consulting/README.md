# Digital Pathway Marketing Landing Page Template

A conversion-focused landing page template for marketing agencies and revenue operations teams to showcase done-for-you client acquisition systems and book strategy calls.

## Project Details
- **Slug:** `digitalpathway-consulting`
- **Views:** 11
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

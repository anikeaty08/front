# Accounting Services Landing Page Template

Modern one-page template for local accounting and bookkeeping firms, ready to customize for your own brand, services, and contact inquiries.

## Project Details
- **Slug:** `din-redovisning`
- **Views:** 8
- **Tags:** Landing Page, Services, Business, Accounting, Bookkeeping, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

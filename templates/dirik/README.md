# Dirigeable

A cozy anticafe landing page template for showcasing time-based pricing, services, gallery, and contact details for a modern social space or coworking cafe.

## Project Details
- **Slug:** `dirik`
- **Views:** 109
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Entertainment, Cafe, Anticafe, Coworking, Events
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Discord Lightning Bot Landing Page Template

A reusable landing page template for showcasing a Discord Lightning Network bot with NWC integration, setup guides, and command documentation.

## Project Details
- **Slug:** `discord-lightning-79`
- **Views:** 40
- **Tags:** Technology, Landing Page, Brand, Dark, Gradient, Grid, Minimal, Large Type, Documentation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

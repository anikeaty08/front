# Discord Security Landing Page Template

A dark, futuristic landing page template for promoting a Discord member backup, recovery, and anti-nuke protection tool to community owners and server admins.

## Project Details
- **Slug:** `discord-security-19`
- **Views:** 539
- **Tags:** Landing Page, Technology, Brand, Dark, Gradient, Minimal, Large Type, Animated

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

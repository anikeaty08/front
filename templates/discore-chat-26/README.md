# Discore Chat App UI Template

A reusable Discore chat application template with login, registration, servers, channels, and dark-mode messaging UI for real-time community platforms.

## Project Details
- **Slug:** `discore-chat-26`
- **Views:** 7
- **Tags:** Technology, Landing Page, Brand, Dark, Minimal, Gradient, Large Type, Social, Chat, Web App

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Discount Voucher Landing Page Template

Reusable landing page template designed to showcase discount vouchers and promo codes for e-commerce platforms, enabling quick deal discovery.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

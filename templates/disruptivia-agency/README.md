# AI Marketing Agency Landing Page Template

A dark, futuristic landing page template for AI-powered marketing agencies to showcase services, clones, agents, portfolio, pricing, and capture high-intent leads.

## Project Details
- **Slug:** `disruptivia-agency`
- **Views:** 60
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Gradient, Large Type, Minimal, Futuristic, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Technical Web Agency Landing Page Template

A dark, high-end technical agency landing page template for showcasing Laravel, PrestaShop, and performance web services to enterprise clients.

## Project Details
- **Slug:** `divioseo-webdevelopement`
- **Views:** 35
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Gradient, Grid, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# DJ Alex Booking Landing Page Template

A dark, modern DJ booking landing page template for showcasing a club & event DJ, highlighting experience, playlists, and a conversion-focused booking form.

## Project Details
- **Slug:** `dj-alex`
- **Views:** 315
- **Tags:** Landing Page, Entertainment, Services, Brand, Dark, Gradient, Large Type, Clean, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

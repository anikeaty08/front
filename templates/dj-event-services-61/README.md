# DJ Event Services Landing Page Template

A modern DJ & event entertainment landing page template for promoting wedding, birthday and private party services with testimonials, FAQs, and contact form.

## Project Details
- **Slug:** `dj-event-services-61`
- **Views:** 260
- **Tags:** Landing Page, Services, Entertainment, Brand, Clean, Dark, Gradient, Large Type, Portfolio

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

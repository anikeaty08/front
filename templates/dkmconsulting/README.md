# Healthcare Consulting Landing Page Template

A dark, modern landing page template for healthcare and AI consulting firms to showcase services, expertise, and drive strategy call bookings.

## Project Details
- **Slug:** `dkmconsulting`
- **Views:** 23
- **Tags:** Landing Page, Services, Health, Technology, Brand, Dark, Clean, Minimal, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Docalo Premium Coffee Dripper Landing Page Template

This reusable landing page template is designed to showcase premium coffee dripper products with features, specs, testimonials, and a CMS for easy content management.

## Project Details
- **Slug:** `docalo-coffee-15`
- **Views:** 48
- **Tags:** Landing Page, Hero, Features, Product, Specifications, Testimonials, CMS, Coffee, E-commerce, Responsive
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

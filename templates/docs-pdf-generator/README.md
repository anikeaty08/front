# PDF Generator Documentation Landing Page Template

A modern documentation landing page template for explaining a Google Sheets and Docs-based PDF Generator workflow, ready to reuse for your own tools.

## Project Details
- **Slug:** `docs-pdf-generator`
- **Views:** 27
- **Tags:** Documentation, Landing Page, Technology, Brand, Clean, Minimal, Gradient, Large Type, Dark, Animated
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Physical Therapist Portfolio Website Template

A modern, clean portfolio website template for doctors of physical therapy to showcase experience, research, skills, and consultations.

## Project Details
- **Slug:** `doctor-of-physical-40`
- **Views:** 75
- **Tags:** Health, Portfolio, Services, Brand, Clean, Minimal, Large Type, Landing Page, Medical, Personal Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

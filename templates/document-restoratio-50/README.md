# Document Restoration Landing Page Template

A reusable landing page template for document conservation, restoration, and archival education projects that want to share expertise and attract inquiries.

## Project Details
- **Slug:** `document-restoratio-50`
- **Views:** 26
- **Tags:** Landing Page, Documentation, Education, Services, Clean, Minimal, Brand, archival, restoration
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

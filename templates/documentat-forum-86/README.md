# Dark Forum Landing Page Template

A reusable dark landing page template for online forum-style directories, public posting boards, and document request communities.

- **Slug:** `documentat-forum-86`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

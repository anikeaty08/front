# Premium Catering Landing Page Template

A reusable landing page template for premium buffet, catering, and event gastronomy brands to showcase menus, social proof, and drive quote requests.

## Project Details
- **Slug:** `docura-validacao`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dog Experience Event Landing Page Template

A premium, brand-forward landing page template for immersive dog experience events, showcasing zones, passes, FAQs, and app features to drive pass requests.

## Project Details
- **Slug:** `dog-event-landing-37`
- **Views:** 36
- **Tags:** Landing Page, Brand, Clean, Dark, Gradient, Large Type, Event, Dog Experience, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

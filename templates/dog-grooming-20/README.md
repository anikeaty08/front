# Tälje Hundtrim Södertälje

A modern dog grooming salon website template for showcasing services, building trust, and driving booking calls for local pet care businesses.

## Project Details
- **Slug:** `dog-grooming-20`
- **Views:** 370
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Pet grooming, Local business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

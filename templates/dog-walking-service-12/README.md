# Pet Walking Service Landing Page Template

A modern WoofWalk-inspired landing page template for premium dog walking and pet sitter services, featuring booking, pricing, login, and secure checkout flows.

## Project Details
- **Slug:** `dog-walking-service-12`
- **Views:** 32
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Pet care, dog walking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

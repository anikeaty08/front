# Luxury Holiday Rental Landing Page Template

A luxury holiday rental landing page template for showcasing a premium 12-bed property, its amenities, location and bookings in a refined, bilingual layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Student Portfolio Resume Template

A clean, one-page student portfolio and resume template designed for showcasing STEM projects, education, athletics, and skills with modern Tailwind styling.

## Project Details
- **Slug:** `dominics-portfolio`
- **Views:** 57
- **Tags:** Landing Page, Portfolio, Education, Clean, Minimal, Technology, Resume, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

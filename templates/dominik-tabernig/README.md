# Earth Observation ePortfolio Website Template

A modern dark-mode ePortfolio website template for students and professionals in Earth observation and geospatial science to showcase studies, skills, and projects.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

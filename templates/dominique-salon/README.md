# Beauty Salon Landing Page Template

Elegant one-page beauty salon website template for hair, nails, and cosmetics studios to showcase services, pricing, and contact details in a modern layout.

## Project Details
- **Slug:** `dominique-salon`
- **Views:** 13
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Beauty salon, Hairdresser
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

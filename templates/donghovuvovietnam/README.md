# Community App Mobile UI Template

A modern mobile community app UI template for Vietnamese family and clan networks, ready to customize for your own private social community.

## Project Details
- **Slug:** `donghovuvovietnam`
- **Views:** 48
- **Tags:** Landing Page, Community, Brand, Clean, Minimal, Large Type, Mobile App, Social, Vietnamese
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

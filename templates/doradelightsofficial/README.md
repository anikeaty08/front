# Dessert Landing Page Template

A reusable landing page template for premium dessert brands to showcase menu items, highlight quality, and drive fast WhatsApp orders.

## Project Details
- **Slug:** `doradelightsofficial`
- **Views:** 85
- **Tags:** Landing Page, Food, E-commerce, Clean, Minimal, Brand, dessert, restaurant, WhatsApp ordering
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

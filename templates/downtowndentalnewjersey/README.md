# Dental Clinic Landing Page Template

A modern dental clinic landing page template for practices offering implants, prosthodontics, and cosmetic dentistry, optimized for local patients and bookings.

## Project Details
- **Slug:** `downtowndentalnewjersey`
- **Views:** 42
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Gradient, Large Type, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# dpi-group

Premium B2B landing page template for food ingredient suppliers to showcase products, partnerships, careers, and contacts in a clean, trust-focused layout.

## Project Details
- **Slug:** `dpi-group-russian`
- **Views:** 12
- **Tags:** Landing Page, Business, Food, Brand, Clean, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

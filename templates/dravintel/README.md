# Design Studio Landing Page Template

A reusable landing page template for modern design studios to showcase UX, product, and AI services with a dark, glassmorphic aesthetic.

- **Views:** 9

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

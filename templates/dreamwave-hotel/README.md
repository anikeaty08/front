# Dreamwave Hotel Landing Page Template

A vibrant hotel landing page template for island resorts, showcasing rooms, amenities, gallery, and inquiry booking to boost direct bookings.

## Project Details
- **Slug:** `dreamwave-hotel`
- **Views:** 54
- **Tags:** Landing Page, Travel, Services, Brand, Colorful, Clean, Gradient, Large Type, Hotel, Resort
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

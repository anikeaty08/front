# Drift Auto Workshop Landing Page Template

A dark, premium auto workshop website template for car service, paint, and restoration businesses, ready to customize for your local garage.

- **Slug:** `drift`
- **Views:** 20

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

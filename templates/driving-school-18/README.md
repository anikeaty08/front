# Driving School Landing Page Template

Reusable landing page template for a modern driving school, showcasing courses, pricing, testimonials, and contact details to convert visitors into enrolled students.

- **Slug:** `driving-school-18`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

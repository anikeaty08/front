# Drone Reality Capture Landing Page Template

A dark, futuristic landing page template for drone and robotics reality capture platforms to showcase AI-powered site monitoring, features, and demos.

## Project Details
- **Slug:** `drone-reality-7`
- **Views:** 6
- **Tags:** Landing Page, Technology, Brand, Dark, Gradient, Minimal, Futuristic, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

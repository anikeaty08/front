# Dental Clinic Landing Page Template

A modern, bilingual dental clinic landing page template designed for health services brands to showcase treatments, build trust, and capture appointments.

## Project Details
- **Slug:** `dummy-doctortonydental`
- **Views:** 34
- **Tags:** Health, Landing Page, Services, Brand, Clean, Colorful, Gradient, Large Type, Minimal, Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

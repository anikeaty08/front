# Speak Dutch at B2 level in 3 months

A modern cohort-based Dutch course landing page template for promoting intensive 90-day B2 fluency programs and driving applications online.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

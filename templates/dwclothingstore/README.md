# Fashion Brand Landing Page Template

A clean, reusable landing page template for clothing brands and local fashion stores to showcase products, store highlights, reviews, and social CTA.

## Project Details
- **Slug:** `dwclothingstore`
- **Views:** 37
- **Tags:** Landing Page, Fashion, Brand, Services, Clean, Minimal, Style, local retail, clothing store
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

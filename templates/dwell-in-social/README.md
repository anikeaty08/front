# Dwell-In Social Care Website Template

A modern, compassionate social care website template for providers to showcase services, quality standards, careers, news, and contact information.

## Project Details
- **Slug:** `dwell-in-social`
- **Views:** 29
- **Tags:** Health, Services, Landing Page, Brand, Clean, Dark, Gradient, Large Type, Social Care, Non-profit
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

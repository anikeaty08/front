# Responsive Website Footer Layout

Creates a responsive footer with glassmorphism style, navigation links, social icons, and glowing background effects.

## Project Details
- **Slug:** `dy2QZNh`
- **Views:** 360
- **Tags:** Footer, Glassmorphism, Tailwind CSS, Responsive Design, Navigation, Social Icons

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# E-commerce Cart Popup Template

A reusable e-commerce popup template for confirming added items, previewing product details, and guiding shoppers to cart or continued browsing.

## Project Details
- **Slug:** `e-commerce-cart-91`
- **Views:** 30
- **Tags:** E-commerce, Landing Page, Clean, Minimal, Services, popup, cart modal, product confirmation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# E-commerce Checkout Page Template

Reusable e-commerce checkout template for Russian online stores selling parts or equipment, featuring cart summary, delivery options, and newsletter signup.

## Project Details
- **Slug:** `e-commerce-checkout-83`
- **Views:** 36
- **Tags:** E-commerce, Landing Page, Services, Brand, Clean, Minimal, Large Type, Grid
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

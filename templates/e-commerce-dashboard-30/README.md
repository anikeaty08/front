# E-commerce Operations Dashboard Template

A reusable dashboard template for managing orders, purchases, shipments, and customer carts in modern e-commerce operations teams.

## Project Details
- **Slug:** `e-commerce-dashboard-30`
- **Views:** 58
- **Tags:** E-commerce, Technology, Services, Clean, Minimal, Dashboard, Admin, Order Management, Logistics

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

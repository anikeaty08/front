# E-commerce Finance Dashboard UI Template

A reusable e-commerce finance dashboard UI template for planning product costs, tracking income and expenses, and visualizing profit in a clean, modern layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

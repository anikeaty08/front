# E-commerce Cart Mobile App Template

A reusable mobile shopping cart template for e-commerce apps, built to showcase basket management, delivery selection, order totals, and checkout actions.

## Project Details
- **Slug:** `e-commerce-mobile-28`
- **Views:** 27
- **Tags:** E-commerce, Landing Page, Technology, Clean, Minimal, Gradient, Mobile UI, Checkout, Shopping Cart
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

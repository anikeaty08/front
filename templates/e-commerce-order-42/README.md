# E-commerce Order Details App Template

A reusable mobile UI template for e-commerce apps to display group order details, item breakdowns, totals, and downloadable invoices.

## Project Details
- **Slug:** `e-commerce-order-42`
- **Views:** 30
- **Tags:** E-commerce, Landing Page, Technology, Clean, Minimal, Fashion, Mobile UI, Order Tracking, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

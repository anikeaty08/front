# E-commerce Product & Payment Card UI Template

Modern e-commerce template recreating an Amazon-style product page with buy box, checkout CTAs, and premium payment card UI for product detail layouts.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

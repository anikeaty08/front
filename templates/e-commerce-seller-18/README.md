# E-commerce Seller Dashboard UI Template

A reusable E-commerce seller dashboard UI template for tracking sales, orders, inventory, and live order feeds in a modern analytics-style interface.

## Project Details
- **Slug:** `e-commerce-seller-18`
- **Views:** 20
- **Tags:** E-commerce, Technology, Landing Page, Brand, Clean, Minimal, Dashboard, Seller Portal, Analytics, Admin
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

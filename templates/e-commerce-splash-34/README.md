# E-commerce Splash Screen Template

A reusable e-commerce splash screen template for cross-border shopping and grouped shipping services, designed to introduce your brand while users load in.

## Project Details
- **Slug:** `e-commerce-splash-34`
- **Views:** 39
- **Tags:** E-commerce, Landing Page, Brand, Clean, Minimal, Animated, Splash Screen, Logistics, Shipping
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

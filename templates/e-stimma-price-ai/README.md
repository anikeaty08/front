# E-commerce Price Analytics Dashboard Template

A reusable dashboard template for e-commerce price intelligence, helping retail and fashion teams monitor competitors, track price index, and optimize pricing.

## Project Details
- **Slug:** `e-stimma-price-ai`
- **Views:** 30
- **Tags:** E-commerce, Technology, Dashboard, Analytics, Dark, Minimal, Grid, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

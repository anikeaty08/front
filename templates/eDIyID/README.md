# Interactive Canvas with Bouncing Balls

Canvas animation of colorful bouncing balls with adjustable speed, size, trail, fade, and rainbow color mode controls.

## Project Details
- **Slug:** `eDIyID`
- **Views:** 203
- **Tags:** JavaScript, Canvas, Animation, Tailwind CSS, Interactive UI, Slider Controls
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

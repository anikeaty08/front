# Early Childhood Education Landing Page Template

A reusable landing page template for early childhood learning spaces like ludotecas and Reggio Emilia-inspired centers to present their story, pedagogy, and programs.

## Project Details
- **Slug:** `early-childhood-74`
- **Views:** 32
- **Tags:** Landing Page, Education, Services, Brand, Clean, Colorful, Large Type, Minimal, Portfolio

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Easycube TAG

A reusable landing page template for smart parcel location products, built to showcase instant package finding, workflow benefits, and trial signup.

## Project Details
- **Slug:** `easycube-parcelstation-tag`
- **Views:** 94
- **Tags:** Landing Page, Technology, Services, Clean, Minimal, Animated, IoT, logistics, parcel tracking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Ebook Sales Landing Page Template

High-converting dark-style landing page template for selling a ChatGPT/AI ebook or digital guide, ready to reuse for your own info products.

## Project Details
- **Slug:** `ebookrendaextra`
- **Views:** 25
- **Tags:** Landing Page, Technology, Business, Brand, Dark, Gradient, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Echoes of the Grid

A cinematic, cyberpunk-style landing page template for immersive ARG, live event, or citywide puzzle experiences to recruit players and share the mission.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Echogram Landing Page Template

Reusable landing page template for showcasing a tool that mirrors X (Twitter) feeds to Telegram quickly without API keys or developer accounts.

## Project Details
- **Slug:** `echogram-x-to-59`
- **Views:** 38
- **Tags:** Landing Page, Hero, Features, Pricing Comparison, CTA, Social Proof, Responsive, Form, Modern UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

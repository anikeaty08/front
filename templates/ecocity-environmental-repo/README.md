# EcoCity Environmental Report Form Template

A reusable EcoCity-style template for reporting city pollution incidents with step-by-step form, map location, and media upload for municipal portals and civic apps.

## Project Details
- **Slug:** `ecocity-environmental-repo`
- **Views:** 31
- **Tags:** Landing Page, Services, Environmental, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Ecommerce Inventory SaaS Landing Page Template

A reusable landing page template for Linnworks-style ecommerce inventory and order management SaaS, featuring demo booking form, features, integrations, and testimonials.

## Project Details
- **Slug:** `ecommerce-saas-39`
- **Views:** 13

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Pro Straps E-commerce Landing Page Template

A modern e-commerce landing page template for premium smartwatch straps and accessories, perfect for showcasing hero products, collections, and reviews.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

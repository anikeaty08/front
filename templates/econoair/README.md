# Econo Air

A reusable landing page template for HVAC, air conditioning, and heating companies to promote services, build trust, and capture service requests.

## Project Details
- **Slug:** `econoair`
- **Views:** 44
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Dark, HVAC, Air Conditioning, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

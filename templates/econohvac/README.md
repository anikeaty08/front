# Econo Air

A reusable landing page template for local HVAC and air conditioning businesses to showcase services, build trust, and drive service requests.

## Project Details
- **Slug:** `econohvac`
- **Views:** 21
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Local business, HVAC, Home services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

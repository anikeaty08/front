# Edge & Flow

A reusable landing page template for custom wood and resin art studios to showcase products, personalization options, and quote-based ordering.

- **Views:** 71

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

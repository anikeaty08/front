# Dental Practice Landing Page Template

A modern dental practice landing page template for clinics to showcase services, dentist profiles, hours, and appointment requests with a clean, trust-building design.

## Project Details
- **Slug:** `edgemontdentalnewjersey`
- **Views:** 23
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

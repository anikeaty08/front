# ZioBratClub E-commerce Landing Page Template

Bold E-commerce landing page template for a satirical, resistance-style merch brand with hero, shop grid, lore section, quiz teaser, and email capture.

## Project Details
- **Slug:** `edgy-e-commerce-45`
- **Views:** 15
- **Tags:** E-commerce, Landing Page, Brand, Entertainment, Art & Design, Colorful, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

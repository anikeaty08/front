# EDI Integration Dashboard UI Template

A reusable EDI Integration Dashboard template for monitoring real-time B2B transactions, partner health, and document status in a clean web UI.

## Project Details
- **Slug:** `edi`
- **Views:** 39
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Dashboard, B2B, EDI, Admin Panel, Integration
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

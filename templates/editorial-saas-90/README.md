# Editorial SaaS Hero Layout Template

A reusable hero layout template for editorial and SaaS landing pages, combining serif elegance with Inter for modern, conversion-focused hero sections.

## Project Details
- **Slug:** `editorial-saas-90`
- **Views:** 15
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

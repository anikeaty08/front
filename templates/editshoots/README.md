# Cinematic Portfolio 

A dark, cinematic portfolio landing page template for directors, cinematographers, and visual artists to showcase motion work and attract high-end clients.

- **Slug:** `editshoots`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

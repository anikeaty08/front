# Educational App Interface Flow Template

A 16-screen educational app interface template for kids, parents, and tutors, ideal for designing learning, games, chat, and community experiences.

## Project Details
- **Slug:** `education-app-5`
- **Views:** 5
- **Tags:** Technology, Education, Landing Page, Brand, Clean, Colorful, Minimal, Large Type, Mobile UI, App Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

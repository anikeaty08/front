# Education Community Landing Page Template

A reusable landing page template for first-generation and low-income student groups to showcase programs, events, mentorship, and campus community support.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

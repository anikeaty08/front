# SMS

A reusable school management dashboard template for academies and campuses to handle logins, student admissions, schedules, staff, grades, and reports.

## Project Details
- **Slug:** `education-dashboard-50`
- **Views:** 37
- **Tags:** Education, Technology, Services, Landing Page, Clean, Minimal, Dashboard, Admin
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Education Dashboard Template

A reusable education dashboard template for managing course catalogs, filtering programs, tracking analysis status, and reviewing course health metrics.

## Project Details
- **Slug:** `education-dashboard-77`
- **Views:** 70
- **Tags:** Education, Technology, Services, Dashboard, Admin, Data Table, Clean, Minimal, Landing Page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

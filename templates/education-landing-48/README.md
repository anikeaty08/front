# Education Landing Page Template

A reusable education landing page template for coaching academies and tutors to showcase mentorship, subjects, results, testimonials, and enrollment CTAs.

## Project Details
- **Slug:** `education-landing-48`
- **Views:** 22
- **Tags:** Education, Landing Page, Services, Technology, Clean, Minimal, Animated, tutoring, coaching academy

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

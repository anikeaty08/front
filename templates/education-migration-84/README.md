# Education & Migration Landing Page Template

A reusable landing page template for education and migration agencies to promote study abroad, visa support, and consultation-based services.

## Project Details
- **Slug:** `education-migration-84`
- **Views:** 70
- **Tags:** Landing Page, Education, Services, Technology, Clean, Dark, Minimal, Gradient, study abroad, migration

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

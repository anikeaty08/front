# Education Open Day Landing Page Template

A reusable landing page template for promoting school open days, capturing registrations, and showcasing programs, schedules, campus details, and event benefits.

## Project Details
- **Slug:** `education-open-24`
- **Views:** 30
- **Tags:** Landing Page, Education, Conference, Services, Clean, Minimal, Brand, event registration, open day
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

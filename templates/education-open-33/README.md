# Education Open Day Landing Page Template

A reusable landing page template for education open day events, designed to promote campus visits, showcase programs, and drive student registrations.

## Project Details
- **Slug:** `education-open-33`
- **Views:** 40
- **Tags:** Landing Page, Education, Conference, Clean, Minimal, Grid, Event, Open Day, Enrollment
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

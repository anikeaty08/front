# Education Platform Landing Page Template

A modern landing page template for online tutoring and education platforms, designed to showcase tutor matching, scheduling, progress tracking, and trust-building features.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Education Portal Landing Page Template

A reusable education portal template for helping students discover colleges, courses, exams, scholarships, and career guidance in one place.

## Project Details
- **Slug:** `education-portal-87`
- **Views:** 41
- **Tags:** Education, Landing Page, Services, Technology, Clean, Minimal, portal, college search, career guidance
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Education Resources Landing Page Template

A dark, modern landing page template for exam resource libraries showcasing papers, answer keys, AI tools, and roadmaps for student preparation.

## Project Details
- **Slug:** `education-resources-59`
- **Views:** 41
- **Tags:** Landing Page, Education, Technology, Brand, Dark, Clean, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

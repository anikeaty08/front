# Education Tutoring Landing Page Template

A reusable landing page template for online tutoring services that helps education brands promote 1:1 classes, subjects, pricing, and free trial bookings.

## Project Details
- **Slug:** `education-tutoring-81`
- **Views:** 25
- **Tags:** Landing Page, Education, Services, Technology, Clean, Minimal, tutoring, online learning, pricing, testimonials
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Educational Academy Landing Page Template

A modern, bilingual educational academy landing page template for showcasing programs, values, and admissions with WhatsApp and phone enquiries.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

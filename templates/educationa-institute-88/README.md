# Education Institute About Page Template

A reusable About page template for faith-driven education institutes to showcase leadership, vision, programs, and accreditation details with a modern design.

## Project Details
- **Slug:** `educationa-institute-88`
- **Views:** 7
- **Tags:** Landing Page, Education, Brand, Clean, Minimal, Large Type, Services, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

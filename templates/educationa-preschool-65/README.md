# Education & Preschool Landing Page Template

A warm and professional landing page template designed for preschools, kindergartens, and educational centers to showcase programs and manage enrollments.

## Project Details
- **Slug:** `educationa-preschool-65`
- **Views:** 4
- **Tags:** Education, Social, Colorful, Clean, Services, Landing Page

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

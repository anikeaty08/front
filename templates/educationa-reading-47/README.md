# Educational Reading Platform Landing Page Template

A clean, modern landing page template for an educational reading platform with plans, recommended books, and resources for teachers and schools.

## Project Details
- **Slug:** `educationa-reading-47`
- **Views:** 12
- **Tags:** Landing Page, Education, Brand, Clean, Colorful, Minimal, Blog, Services, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

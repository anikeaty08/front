# Educator Dashboard UI Template

A modern educator dashboard template for enterprise training platforms, ideal for managing bookings, students, and trainings in a reusable UI layout.

## Project Details
- **Slug:** `educator-dashboard-77`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Egbert Dental & Massage Booking Landing Page Template

A reusable dark-style template for Egbert-style dental and massage appointment booking, featuring a guided agenda, service list, pricing, and contact sections.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Eigarlabs.ai

A sleek, dark AI consulting landing page template for agencies and boutique firms to showcase services, team, and book strategy calls.

## Project Details
- **Slug:** `eigerlabs2`
- **Views:** 120
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Minimal, Large Type, AI consulting, Agency

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Barbershop Landing Page Template

A refined landing page template for barbershops and grooming studios to showcase services, team, style galleries, and appointment booking.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

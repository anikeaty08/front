# Elastoplaz Symposium 

A modern event landing page template for technical symposiums and university conferences, fully customizable for registrations, passes, workshops, and galleries.

## Project Details
- **Slug:** `elastoplaz-26-sympo`
- **Views:** 42

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

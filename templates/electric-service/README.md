# Everett Electric Service Landing Page Template

A reusable landing page template designed for local electrical service providers to showcase services, customer reviews, and enable easy booking.

## Project Details
- **Slug:** `electric-service`
- **Views:** 1036
- **Tags:** Landing Page, Electrical Services, Booking, Testimonials, Blog, Local Business, Contact Form, Residential, EV Chargers, Code Compliance
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

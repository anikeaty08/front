# Electrical & Plumbing Store Landing Page Template

A clean, modern landing page template for electrical and plumbing stores to showcase location, services, availability checks, and customer actions.

## Project Details
- **Slug:** `electrical-plumbing-26`
- **Views:** 54
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

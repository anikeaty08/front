# Electrical Services Landing Page Template

A modern, dark-mode electrical services landing page template for showcasing residential and commercial offerings, trust signals, and booking requests.

## Project Details
- **Slug:** `electrical-services-24`
- **Views:** 11

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

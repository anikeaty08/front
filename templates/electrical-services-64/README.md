# Elektrotechnische Diensten Landing Page Template

Een herbruikbare landing page template voor elektrotechnische dienstverleners om installatietechniek, infra en energietechniek professioneel te presenteren.

## Project Details
- **Slug:** `electrical-services-64`
- **Views:** 12
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Gradient, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

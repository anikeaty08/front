# Electrical Services Landing Page Template

A reusable landing page template for electrical, air conditioning, and solar service businesses to showcase services, build trust, and generate quote requests.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

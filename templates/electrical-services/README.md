# Electria Electrical Services Landing Page Template

A modern Electria-branded landing page template for electricians and electrical service companies to showcase services, testimonials, FAQs, and drive quote requests.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Electrical Store Landing Page Template

A modern Ukrainian-language landing page template for an electrical goods and lighting store, perfect for showcasing products, services, and contact details.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

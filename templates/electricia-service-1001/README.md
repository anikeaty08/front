# Electrical Services Landing Page Template

A modern electrical services landing page template for local tradies to showcase services, build trust, and capture quote and callout enquiries.

## Project Details
- **Slug:** `electricia-service-1001`
- **Views:** 67
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Brand, Large Type, Technology, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Electronic Music Producer Portfolio Template

A modern electronic music producer portfolio template to showcase releases, videos, stats, and contact links for DJs, artists, and music creators.

## Project Details
- **Slug:** `electronic-music-37`
- **Views:** 37

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

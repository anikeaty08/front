# Elegant Wedding Celebration Template

A sophisticated, interactive wedding event template designed for couples to share their story, itinerary, and RSVP details with guests.

## Project Details
- **Slug:** `elegant-wedding-25`
- **Views:** 25
- **Tags:** Wedding, Social, Clean, Minimal, Animated, Elegant
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

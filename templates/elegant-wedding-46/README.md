# Elegant Wedding Landing Page Template

A refined wedding website template for couples to share their story, event timeline, gallery, gift registry, and RSVP details in a romantic format.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

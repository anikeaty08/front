# Elegant Wedding Invitation Page Template

A refined wedding invitation page template with ceremonies, venue, and couple details, perfect for sharing modern Hindu wedding information online.

## Project Details
- **Slug:** `elegant-wedding-79`
- **Views:** 41
- **Tags:** Wedding, Landing Page, Brand, Clean, Minimal, Colorful, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

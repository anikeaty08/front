# Electrician Services Landing Page Template

A reusable landing page template for electricians and electrical service companies to showcase services, build trust, and drive phone inquiries.

## Project Details
- **Slug:** `elektrikar-vzor`
- **Views:** 55
- **Tags:** Landing Page, Services, Business, Clean, Dark, Minimal, local services, electrician, home services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

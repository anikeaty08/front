# Elite Event BR

A sleek, dark-themed landing page template for multilingual event service providers to showcase cleaning, organizing, guest support, and bartending offerings.

## Project Details
- **Slug:** `eliteeventbr`
- **Views:** 44

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

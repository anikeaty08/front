# Creative Design Portfolio Template

A modern portfolio template for creative technologists and developers to showcase projects, expertise, and testimonials with a clean 3D-enhanced layout.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

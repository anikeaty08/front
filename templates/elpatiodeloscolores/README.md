# Art Therapy Studio Landing Page Template

A reusable landing page template for art therapy studios and creative wellness workshops to showcase services, methodology, testimonials, and contact forms.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Aesthetic Medicine Landing Page Template

A dark, science-led landing page template for aesthetic injectable and hair complex brands to showcase products, clinical results, and physician-focused benefits.

## Project Details
- **Slug:** `elyara-aesthetics02`
- **Views:** 70
- **Tags:** Landing Page, Health, Brand, Clean, Dark, Large Type, Minimal, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

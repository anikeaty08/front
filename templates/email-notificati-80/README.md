# Product Update Email Template

A reusable email template for announcing product releases, platform updates, and changelogs in a polished mobile inbox-style layout.

## Project Details
- **Slug:** `email-notificati-80`
- **Views:** 45
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Dark, email template, newsletter, product update
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

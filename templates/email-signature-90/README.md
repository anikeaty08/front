# Email Signature Template

A modern email signature template for branding, tech, and business professionals who want a polished, reusable contact block for daily communication.

## Project Details
- **Slug:** `email-signature-90`
- **Views:** 40
- **Tags:** Brand, Services, Technology, Minimal, Dark, Clean, Email Signature, Personal Branding
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

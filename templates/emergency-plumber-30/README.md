# Emergency Plumber Service Landing Page Template

High-converting 24/7 emergency plumber landing page template for local service businesses to showcase urgent plumbing help, reviews, and contact CTAs.

## Project Details
- **Slug:** `emergency-plumber-30`
- **Views:** 80
- **Tags:** Landing Page, Services, Business, Local Service, Clean, Minimal, Large Type, Emergency, Plumber, Home Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

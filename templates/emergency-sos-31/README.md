# Emergency SOS Mobile App UI Template

A dark, mobile-first Emergency SOS app UI template for showcasing safety alerts, GPS location, emergency contacts, and settings in a modern prototype.

## Project Details
- **Slug:** `emergency-sos-31`
- **Views:** 90
- **Tags:** Health, Technology, Landing Page, Brand, Dark, Minimal, Gradient, Large Type, Mobile App, Emergency SOS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

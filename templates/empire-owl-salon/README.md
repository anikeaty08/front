# Beauty Salon & Stylist Landing Page Template

A sophisticated and warm landing page template designed for independent salons, stylists, and beauty professionals to showcase services and manage bookings.

## Project Details

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Employee Bus Booking Template

A reusable employee bus booking template for internal transport teams to manage seat selection, passenger details, and schedule-based reservations.

## Project Details
- **Slug:** `employee-bus-61`
- **Views:** 22
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Dashboard, Booking, Transport, Internal Tool

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

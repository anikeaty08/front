# Fitness EMS Studio Landing Page Template

A modern EMS gym landing page template for fitness studios and personal trainers to showcase 20-minute electrostimulation workouts and capture new client leads.

- **Views:** 9

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

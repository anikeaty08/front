# Endodontic Clinic Landing Page Template

A modern dental endodontics landing page template for showcasing root canal specialists, procedures, and appointment requests for local practices.

## Project Details
- **Slug:** `endodontic-practice-36`
- **Views:** 6
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Medical, Dental, Clinic

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Energy Contractor Landing Page Template

A modern Ampera-branded landing page template for energy contractors and utility service providers to showcase services, certifications, and capture project inquiries.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

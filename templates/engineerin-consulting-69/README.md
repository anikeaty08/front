# Student Consulting Club Landing Page Template

A dark, modern landing page template for engineering and business student consulting clubs to showcase services, team, applications, and corporate partnerships.

- **Slug:** `engineerin-consulting-69`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

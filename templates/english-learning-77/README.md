# English Learning Dashboard Template

A reusable education dashboard template for English learning platforms, featuring lessons, quizzes, vocabulary tools, progress tracking, and learner settings.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

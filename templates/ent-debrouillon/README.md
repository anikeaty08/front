# ENT.DEBROUILLON

A reusable landing page template for local roofing and home service businesses to showcase services, build trust, and capture quote requests.

## Project Details
- **Slug:** `ent-debrouillon`
- **Views:** 35
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, local services, roofing, contractor, quote form
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

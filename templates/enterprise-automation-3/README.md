# Enterprise AI Automation Agency Landing Page Template

A dark, modern landing page template for enterprise AI automation and workflow agencies to showcase services, process, pricing, and lead-gen CTAs.

## Project Details
- **Slug:** `enterprise-automation-3`
- **Views:** 9
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Large Type, Services, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

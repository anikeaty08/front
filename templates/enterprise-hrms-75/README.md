# Enterprise HRMS Dashboard UI Template

A reusable enterprise HRMS dashboard UI template for managing employees, attendance, leave, payroll, and analytics in a modern web application.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Onyx Systems Enterprise UI Template

A reusable enterprise-grade UI template featuring an icon system, data visualization library, interaction components, decorative assets, and full control dashboard for SaaS applications.

## Project Details
- **Slug:** `enterprise-ui-0`
- **Views:** 1264
- **Tags:** Landing Page, Icon System, Data Visualization, Interaction Library, Decorative Assets, UI Components, Dashboard, Dark Mode, SVG, SaaS Template
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

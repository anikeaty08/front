# Entreggo Farmacia

A reusable landing page template for pharmacy delivery and logistics software, built to showcase route optimization, proof of delivery, and demo booking.

## Project Details
- **Slug:** `entreggo-farmacia`
- **Views:** 72
- **Tags:** Landing Page, Technology, Services, Clean, Minimal, Brand, logistics, pharmacy, delivery, SaaS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Environmental Non-profit Landing Page Template

A modern Vietnamese non-profit landing page template for environmental organizations to showcase missions, campaigns, news, and recruit volunteers online.

- **Slug:** `environmen-non-96`
- **Views:** 21

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

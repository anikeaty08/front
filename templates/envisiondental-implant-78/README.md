# Dental Quiz Landing Page Template

A reusable landing page template for dental implant clinics to qualify full-arch restoration leads with a quick quiz, testimonials, and trust-building CTAs.

## Project Details
- **Slug:** `envisiondental-implant-78`
- **Views:** 24
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Video Testimonials, Lead Generation, Quiz Funnel

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# LA MATRICE ESCAPE GAME

A dark, cyberpunk escape game landing page template for promoting immersive hacker-themed rooms, pricing, and testimonials with glitch animations.

## Project Details
- **Slug:** `escape-la-matrice`
- **Views:** 13
- **Tags:** Landing Page, Entertainment, Art & Design, Dark, Futuristic, Gradient, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Escriturando Certo Landing Page Template

Landing page template para vender Vade Mecum e materiais de estudo para concursos de cartórios (ENAC), pronta para personalizar e reutilizar em projetos similares.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

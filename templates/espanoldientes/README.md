# Dental & Cosmetic Clinic Landing Page Template

A high-converting, professional landing page template designed for dental clinics and cosmetic services, featuring an interactive before/after slider and trust-building sections.

## Project Details
- **Slug:** `espanoldientes`
- **Views:** 45
- **Tags:** Health, Services, Technology, Clean, Minimal, Animated, Landing Page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

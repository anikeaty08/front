# Gaming Tournament Landing Page Template

A reusable landing page template for Free Fire-style esports communities to showcase tournaments, leaderboards, player dashboards, and registration flows.

## Project Details
- **Slug:** `esports-tournament-38`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

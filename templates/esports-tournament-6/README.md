# Esports Tournament Dashboard Web App Template

A dark, gaming-style web app template for esports tournaments with player auth, wallet, referrals, leaderboard, and admin match management features.

## Project Details
- **Slug:** `esports-tournament-6`
- **Views:** 15
- **Tags:** Landing Page, Technology, Brand, Dark, Futuristic, Gradient, Gaming, Esports, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

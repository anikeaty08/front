# Coffee Cafe

A reusable landing page template for coffee shops and cafes featuring hero, menu highlights, gallery, reviews, and location sections for quick launch.

## Project Details
- **Slug:** `espressotipusultan`
- **Views:** 24
- **Tags:** Landing Page, Food, Brand, Clean, Minimal, Large Type, Cafe, Restaurant, Coffee Shop
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

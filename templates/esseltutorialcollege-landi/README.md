# Education Landing Page Template for Tutorial College

A modern education landing page template for tutorial colleges to showcase programs, locations, and drive student enrollment inquiries.

## Project Details
- **Slug:** `esseltutorialcollege-landi`
- **Views:** 24
- **Tags:** Landing Page, Education, Services, Brand, Clean, Colorful, Large Type, Minimal, Technology

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

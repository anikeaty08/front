# Fine Dining Restaurant Landing Page Template

A refined restaurant website template for showcasing menus, events, private dining, galleries, and reservations with a premium hospitality feel.

## Project Details
- **Slug:** `estebanrestaurant`
- **Views:** 360
- **Tags:** Landing Page, Food, Services, Dark, Elegant, Minimal, Restaurant, Fine Dining, Hospitality
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

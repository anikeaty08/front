# Estética Clínica Landing Page Template

Landing page template para clínicas de estética que desejam apresentar tratamentos, estrutura da clínica e formulário de agendamento de forma elegante.

## Project Details
- **Slug:** `estetica-landingpage`
- **Views:** 36
- **Tags:** Landing Page, Services, Health, Brand, Clean, Minimal, Large Type, Gradient, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

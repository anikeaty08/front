# Beauty Studio Landing Page Template

Elegant Spanish-language beauty studio landing page template for salons offering waxing, brows, lashes, and skin care with online booking.

## Project Details
- **Slug:** `estetica-lili`
- **Views:** 27
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Beauty, Salon, Waxing, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

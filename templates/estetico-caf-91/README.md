# Estetico Café Restaurant Landing Page Template

A modern café and restaurant landing page template for showcasing your menu, ambience, hours, and reservations with a warm, upscale aesthetic.

## Project Details
- **Slug:** `estetico-caf-91`
- **Views:** 67
- **Tags:** Landing Page, Food, Brand, Clean, Minimal, Gradient, Large Type, 3D
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

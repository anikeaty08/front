# EV Charging Map Mobile UI Template

Dark, glassmorphism EV charging map mobile UI template for showcasing nearby stations, connector status, and quick navigation inside your app.

## Project Details
- **Slug:** `ev-charging-map-33`
- **Views:** 29
- **Tags:** Landing Page, Technology, Brand, Dark, Clean, Futuristic, Mobile UI, EV charging, Map interface, Glassmorphism
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# EV Command Dashboard UI Template

A dark, data-rich EV charging network dashboard UI template for visualizing live station maps, revenue, alerts, and energy consumption analytics.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

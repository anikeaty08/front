# EVAS.os Enterprise Software Landing Page Template

A dark-mode enterprise software website template for showcasing B2B cloud and healthcare solutions, services, team, and contact in a polished layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

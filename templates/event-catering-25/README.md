# Event Catering Landing Page Template

A reusable landing page template for event caterers and food service brands to showcase menus, services, testimonials, and capture quote requests.

## Project Details
- **Slug:** `event-catering-25`
- **Views:** 26
- **Tags:** Landing Page, Food, Services, Wedding, Clean, Minimal, Brand, event catering, quote form
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

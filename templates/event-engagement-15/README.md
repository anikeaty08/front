# Event Engagement Landing Page Template

A reusable landing page template for promoting interactive event and gamification platforms with live insights, scoreboards, and audience engagement features.

## Project Details
- **Slug:** `event-engagement-15`
- **Views:** 50
- **Tags:** Landing Page, Technology, Conference, Clean, Gradient, Minimal, Dashboard, Gamification, Events

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

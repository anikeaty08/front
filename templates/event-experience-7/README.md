# Event Experience Landing Page Template

A playful, reusable landing page template for event planners and pop-up experience brands to showcase services, atmosphere, and booking CTAs.

## Project Details
- **Slug:** `event-experience-7`
- **Views:** 23
- **Tags:** Landing Page, Services, Social, Wedding, Colorful, Illustrative, Large Type, Brand, event planning, pop-up experiences
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Event Feedback Form Template

A reusable dark-themed template for post-event thank-you and feedback collection, designed to gather attendee insights, ratings, and follow-up interest.

- **Slug:** `event-feedback-52`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Event Management Landing Page Template

A reusable event management template for showcasing services, galleries, videos, testimonials, and booking inquiries for weddings, parties, and corporate events.

## Project Details
- **Slug:** `event-management-48`
- **Views:** 41
- **Tags:** Landing Page, Services, Wedding, Conference, Clean, Minimal, Brand, event management, booking form
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Event Management SaaS Landing Page Template

A reusable landing page template for event management SaaS products that promote live polls, Q&As, quizzes, and audience engagement tools.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

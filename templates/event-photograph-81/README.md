# Event Photography Landing Page Template

A reusable landing page template for event photographers and corporate photography studios to showcase services, portfolio, process, and quote inquiries.

## Project Details
- **Slug:** `event-photograph-81`
- **Views:** 33
- **Tags:** Landing Page, Services, Portfolio, Brand, Clean, Minimal, Photography, Events, Corporate
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

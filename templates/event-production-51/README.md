# Event Production Studio Landing Page Template

A dark, cinematic landing page template for event production studios to showcase technical services, immersive lighting, sound, and portfolio projects.

## Project Details
- **Slug:** `event-production-51`
- **Views:** 13
- **Tags:** Landing Page, Services, Brand, Portfolio, Dark, Gradient, Grid, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Event Tickets Mobile UI Template

A modern mobile event tickets screen template for apps, featuring active and past tickets, QR codes, and bottom navigation for seamless reuse.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Event Marketplace Landing Page Template

A reusable landing page template for event vendor marketplaces that helps organizers discover, compare, and book vendors while vendors attract leads.

## Project Details
- **Slug:** `event-vendor-41`
- **Views:** 66
- **Tags:** Landing Page, Services, Technology, Clean, Gradient, Marketplace, Event Planning, Vendor Directory
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

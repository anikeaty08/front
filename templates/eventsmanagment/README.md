# Premium Event Management Landing Page Template

A reusable landing page template for event planners, wedding coordinators, and luxury event agencies to showcase services, packages, galleries, and inquiries.

## Project Details
- **Slug:** `eventsmanagment`
- **Views:** 68
- **Tags:** Landing Page, Services, Wedding, Conference, Portfolio, Dark, Clean, Minimal, Luxury, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

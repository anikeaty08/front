# Event Venue Landing Page Template

Elegant, conversion-focused landing page template for showcasing a premium event venue with availability calendar, galleries, and event details.

## Project Details
- **Slug:** `eventspace`
- **Views:** 36
- **Tags:** Landing Page, Services, Wedding, Clean, Minimal, Large Type, Brand, Event Venue, Calendar Booking, Responsive
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

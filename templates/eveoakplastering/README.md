# Plastering Services Landing Page Template

A reusable landing page template for plasterers and local trade businesses to showcase services, build trust, display work, and capture quote requests.

## Project Details
- **Slug:** `eveoakplastering`
- **Views:** 24
- **Tags:** Landing Page, Services, Portfolio, Clean, Dark, Minimal, local trades, home improvement, quote form
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Exam Prep Platform Landing Page Template

A modern Exam Prep Platform landing page template for showcasing MCQs, smart tests, progress tracking, and exam tools for Pakistani competitive exam takers.

## Project Details
- **Slug:** `exam-prep-platform-24`
- **Views:** 20
- **Tags:** Landing Page, Education, Technology, Brand, Clean, Gradient, Minimal, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

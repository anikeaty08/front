# Exotic Rally Event Landing Page Template

A cinematic, dark-mode landing page template for high-end exotic rally or motorsport events, showcasing routes, daily stages, and premium experiences.

## Project Details
- **Slug:** `exotic-rally-69`
- **Views:** 404
- **Tags:** Landing Page, Travel, Brand, Dark, Minimal, Large Type, Gradient, Clean, Entertainment
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

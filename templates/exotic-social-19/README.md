# Exotic Social Media Web App Template

A full-featured social media web app UI template with feeds, messaging, stories, servers, AI assistant, and in-browser database, ready for customization.

## Project Details
- **Slug:** `exotic-social-19`
- **Views:** 10
- **Tags:** Technology, Landing Page, Brand, Clean, Minimal, Large Type, Social media, Web app, Tailwind CSS, Dark mode
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

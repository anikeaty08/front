# Experimental Music Platform Landing Page Template

A dark brutalist landing page template for experimental music platforms to showcase live sessions, archives, and artist-driven broadcasts.

## Project Details
- **Slug:** `experiment-music-71`
- **Views:** 18
- **Tags:** Landing Page, Entertainment, Art & Design, Brutal, Dark, Minimal, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

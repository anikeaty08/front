# Astrology Explore Menu UI Template

A reusable Explore Menu UI template for astrology and spiritual services, featuring scrollable image tiles for quick navigation to offerings like matchmaking, tarot, and horoscope.

## Project Details
- **Slug:** `explore-menu-ui-0`
- **Views:** 32
- **Tags:** Landing Page, Services, Clean, Minimal, Brand, Gradient, Astrology, Spiritual, Menu UI, Component
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

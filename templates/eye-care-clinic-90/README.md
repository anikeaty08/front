# Eye Care Clinic Website Template

A premium medical website template for ophthalmology clinics and eye care centers to showcase treatments, doctors, locations, and appointment booking.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

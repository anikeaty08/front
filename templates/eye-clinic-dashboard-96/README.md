# Eye Care Dashboard Template

A reusable healthcare dashboard template for ophthalmology clinics to manage patients, appointments, prescriptions, surgeries, and billing in one clean interface.

## Project Details
- **Slug:** `eye-clinic-dashboard-96`
- **Views:** 55
- **Tags:** Health, Services, Dashboard, Clean, Minimal, Landing Page, Medical, Admin, Patient Management
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

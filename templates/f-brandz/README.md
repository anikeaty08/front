# F-Brandz 3PL

A dark, conversion-focused landing page template for 3PL and Amazon FBA logistics providers to showcase services, pricing, and lead-gen contact forms.

## Project Details
- **Slug:** `f-brandz`
- **Views:** 1115
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Gradient, Large Type, Minimal, Logistics
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

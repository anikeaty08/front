# Facade Cleaning Services Landing Page Template

A reusable landing page template for facade cleaning and property maintenance businesses to showcase services, build trust, and capture local leads.

## Project Details
- **Slug:** `facade-cleaning-41`
- **Views:** 14
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Local Services, Lead Generation, Home Maintenance

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

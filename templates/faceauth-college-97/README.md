# FaceAuth College Attendance Dashboard Template

A reusable template for a FaceAuth-style college attendance dashboard with live facial scanning, real-time logs, and student directory management UI.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

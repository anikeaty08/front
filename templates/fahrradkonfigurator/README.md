# Dein Fahrrad-Konfigurator

Ein modernes Landing Page Template für einen Fahrrad-Konfigurator, mit dem du markenunabhängige Bike-Konfigurationen und Features wie Echtzeit-Preis & Gewicht präsentieren kannst.

## Project Details
- **Slug:** `fahrradkonfigurator`
- **Views:** 85
- **Tags:** Landing Page, Technology, Brand, Dark, Gradient, Minimal, Large Type, Clean, Bicycle configurator
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Notification Dashboard Web App Template

A dark, real-time notification dashboard template for web apps, showcasing OS push permissions, activity feeds, and mock traffic testing.

## Project Details
- **Slug:** `fakenotificationweb`
- **Views:** 17
- **Tags:** Technology, Landing Page, Brand, Dark, Minimal, Dashboard, Notifications, Web App UI, Real-time, Admin Panel

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

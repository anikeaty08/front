# Family Restaurant Menu Landing Page Template

A clean, mobile-friendly template for family restaurants to showcase their full menu, specials, and table bookings in a modern landing page layout.

## Project Details
- **Slug:** `family-restaurant-58`
- **Views:** 38
- **Tags:** Food, Landing Page, Brand, Clean, Minimal, Restaurant, Menu, Responsive, Tailwind CSS, Modern
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

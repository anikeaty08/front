# Family Shopping List App Template

Reusable family shopping list app template for organizing multi-user grocery items by store with German/Kurdish support and a clean mobile-first UI.

## Project Details
- **Slug:** `family-shopping-9`
- **Views:** 21
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Brand, Shopping list, Family app, Mobile UI, Multilingual
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

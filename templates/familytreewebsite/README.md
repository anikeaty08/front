# Family Tree Dashboard Template

A modern, interactive family history dashboard template for visualizing lineage, profiles, and life events—ready to adapt for genealogy or ancestry apps.

## Project Details
- **Slug:** `familytreewebsite`
- **Views:** 50
- **Tags:** Landing Page, Brand, Clean, Minimal, Technology, Dashboard, Genealogy, Family Tree

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# MMORPG Game Landing Page Template

A vibrant Celestia Luna Online-inspired landing page template for fantasy MMORPGs, featuring hero CTA, navigation, member login, promos, and footer links.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

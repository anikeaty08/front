# Fantasy Trading Dashboard Template

A reusable dark dashboard template for fantasy sports player trading platforms, featuring market overviews, portfolio-style widgets, and buy/sell actions.

## Project Details
- **Slug:** `fantasy-sports-67`
- **Views:** 18
- **Tags:** Technology, Landing Page, Dark, Clean, Minimal, Dashboard, Finance, Sports
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

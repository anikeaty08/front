# Farag Dentistry Website

A modern dental clinic website template for showcasing services, team profiles, location details, and appointment requests for local dentistry practices.

## Project Details
- **Slug:** `faragdentistryhoboken`
- **Views:** 24
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Brand, Large Type, Technology, Dental, Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

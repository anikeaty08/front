# Fashion Brand Landing Page Template

A reusable landing page template for sustainable fashion brands to showcase craftsmanship, benefits, reviews, and brand values with a refined editorial style.

## Project Details
- **Slug:** `fashion-brand-46`
- **Views:** 35
- **Tags:** Landing Page, E-commerce, Fashion, Brand, Clean, Minimal, Editorial, Sustainability, Reviews
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

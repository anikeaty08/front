# Fashion Catalog Flipbook Landing Page Template

This reusable template showcases a stylish interactive flipbook catalog designed for fashion brands to present collections and products elegantly.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

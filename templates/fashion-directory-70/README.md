# Fashion Brand Directory Template

A high-impact, neo-brutalist brand directory template designed to showcase local style, curated fashion labels, and creative portfolios.

## Project Details
- **Slug:** `fashion-directory-70`
- **Views:** 32
- **Tags:** Fashion, Landing Page, Grid, Colorful, Brutal, Style, Portfolio, Clean
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

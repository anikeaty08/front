# Fashion E-commerce Landing Page Template

A modern fashion e-commerce landing page template for clothing boutiques to showcase collections, store locations, and contact options.

- **Slug:** `fashion-e-commerce-13`
- **Views:** 27
- **Tags:** E-commerce, Fashion, Landing Page, Brand, Clean, Minimal, Large Type, Gradient, Clothing Store, Boutique

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

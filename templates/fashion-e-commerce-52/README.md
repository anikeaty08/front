# Fashion E-commerce Landing Page Template

Modern fashion e-commerce template for boutiques like MABIR, featuring product catalog, regional delivery zones, admin dashboard, and product detail flows.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

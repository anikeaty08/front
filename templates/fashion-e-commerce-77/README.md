# Accessories E-commerce Website Template

A reusable e-commerce website template for premium accessories brands, featuring shopping, product pages, editorial content, contact flows, and app-focused CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

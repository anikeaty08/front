# Fashion Model Portfolio Website Template

A dark, editorial-style model portfolio website template to showcase fashion, runway, and commercial work with biography, experience timeline, and contact CTA.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Fashion Model Agency Landing Page Template

A sleek dark-mode landing page template for modern fashion model agencies to showcase talent, campaigns, and capture new model applications.

## Project Details
- **Slug:** `fashion-modeling-51`
- **Views:** 140

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

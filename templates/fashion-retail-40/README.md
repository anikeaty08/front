# Fashion Retail Landing Page Template

A modern, store-focused landing page template for fashion retailers and boutiques to showcase collections, location, and contact details.

## Project Details
- **Slug:** `fashion-retail-40`
- **Views:** 27
- **Tags:** Landing Page, E-commerce, Fashion, Brand, Clean, Colorful, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

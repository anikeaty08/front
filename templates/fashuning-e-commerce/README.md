# Fashion E-commerce Landing Page Template

A modern dark-mode fashion e-commerce template with hero, product grid, cart, and checkout flows, perfect for online stores and affiliate marketers.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

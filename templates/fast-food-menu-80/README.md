# Fast Food Menu Landing Page Template

A modern fast food restaurant menu landing page template for showcasing categories, best sellers, and recommended dishes with online ordering CTAs.

## Project Details
- **Slug:** `fast-food-menu-80`
- **Views:** 44
- **Tags:** Landing Page, E-commerce, Food, Brand, Clean, Colorful, Grid, Large Type, Restaurant, Online Ordering
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Fast Food Rewards Landing Page Template

Reusable fast food rewards landing page template with a spin-to-win wheel to boost customer loyalty signups and promote free menu item offers.

## Project Details
- **Slug:** `fast-food-rewards-89`
- **Views:** 10
- **Tags:** Landing Page, Food, Services, Brand, Clean, Colorful, Minimal, Marketing, Spin the wheel, Loyalty
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Veterinary Clinic Landing Page Template

A modern veterinary clinic landing page template for showcasing services, team, hours, and contact details to help pet owners book appointments with ease.

## Project Details
- **Slug:** `fawavetandsurgery`
- **Views:** 25

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

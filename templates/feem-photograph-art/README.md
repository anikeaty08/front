# Wedding Photographer Landing Page Template

A modern, luxury wedding photographer website template for showcasing galleries, testimonials, and contact inquiries to book your photography services.

## Project Details
- **Slug:** `feem-photograph-art`
- **Views:** 424
- **Tags:** Landing Page, Services, Wedding, Photography, Portfolio, Clean, Dark, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Femtech Health Landing Page Template

A reusable landing page template for femtech, wearable health, and menopause-tracking products, designed to showcase hardware, AI insights, research, and pre-orders.

## Project Details
- **Slug:** `femtech-health-52`
- **Views:** 50
- **Tags:** Health, Technology, Landing Page, Brand, Dark, Futuristic, Gradient, Clean, 3D
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

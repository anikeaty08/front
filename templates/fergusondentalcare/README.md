# Dental Practice Landing Page Template

A clean, modern dental practice landing page template for showcasing family, cosmetic, and pediatric services and driving online appointment requests.

## Project Details
- **Slug:** `fergusondentalcare`
- **Views:** 21
- **Tags:** Health, Landing Page, Services, Brand, Clean, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

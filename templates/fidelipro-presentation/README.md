# FideliPro

A modern SaaS landing page template for automated marketing and customer loyalty platforms, ready to customize for your own assistant marketing product.

## Project Details
- **Slug:** `fidelipro-presentation`
- **Views:** 21
- **Tags:** Landing Page, Technology, Business, Brand, Clean, Minimal, Gradient, Large Type, SaaS, Marketing Automation

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

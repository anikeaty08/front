# Dental Practice Landing Page Template

A modern dental practice landing page template for clinics to showcase services, team, location, and appointment requests with a clean, patient-friendly design.

## Project Details
- **Slug:** `fietandjonasdental`
- **Views:** 25
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Technology, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

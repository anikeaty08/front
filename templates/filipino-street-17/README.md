# Filipino Street Food Landing Page Template

A dark, bold restaurant landing page template for Filipino charcoal chicken and street food brands to showcase menus, locations, story, and catering inquiries.

## Project Details
- **Slug:** `filipino-street-17`
- **Views:** 30
- **Tags:** Landing Page, Food, Brand, Clean, Dark, Large Type, Restaurant, Street Food, Charcoal Chicken, Catering
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

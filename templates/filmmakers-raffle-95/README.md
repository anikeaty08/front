# Filmmakers Raffle Picker App Template

A sleek, dark-mode raffle picker template for meetups and events, letting you paste names, seed the draw, and visually reveal winners with repeatable fairness.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

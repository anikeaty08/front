# Finance App Landing Page Template

This reusable landing page template is designed for finance apps to showcase features, dashboards, and mobile capabilities with a sleek iPhone frame design.

## Project Details
- **Slug:** `finance-app-mobile`
- **Views:** 2161
- **Tags:** Landing Page, Finance, Features, Dashboard, Mobile App, iPhone Frame, CTA, Analytics, Real-time Data, Automation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

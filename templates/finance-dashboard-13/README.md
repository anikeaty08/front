# CashFlow Finance Dashboard UI Template

A reusable dark-mode finance dashboard UI template for visualizing cash flow, KPIs, and recent transactions in modern web apps.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

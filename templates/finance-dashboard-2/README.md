# Financial Dashboard UI Template

A reusable financial dashboard UI template for modern web apps, featuring dark glassmorphism, cards, charts, and transaction views for fintech products.

- **Slug:** `finance-dashboard-2`
- **Views:** 437

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Finance Dashboard Template

A reusable finance dashboard template for tracking balances, cash flow, expenses, accounts, and recent transactions in a clean analytics UI.

## Project Details
- **Slug:** `finance-dashboard-37`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

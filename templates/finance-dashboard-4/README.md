# Finance Dashboard UI Template

Modern FinDash-inspired finance dashboard UI template for managing cash flow, payables, receivables, suppliers, and clients in a web app.

## Project Details
- **Slug:** `finance-dashboard-4`
- **Views:** 30
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Dashboard, Finance, SaaS, Admin Panel, Web App
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

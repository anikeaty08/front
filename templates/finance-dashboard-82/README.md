# Finance Dashboard Template

This reusable Finance Dashboard Template provides a comprehensive layout for managing payments, accounts, sales, inventory, and reports with user-friendly forms and navigation.

## Project Details
- **Slug:** `finance-dashboard-82`
- **Views:** 32
- **Tags:** Finance, Dashboard, Payments, ERP, CRM, Inventory, Reports, User Management, Form, TailwindCSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

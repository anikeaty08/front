# Mobile App Frames Landing Page Template

This template provides a sleek, reusable landing page showcasing mobile app UI frames for finance, analytics, and approval workflows.

## Project Details
- **Slug:** `finance-dashboard-mobile`
- **Views:** 1335
- **Tags:** Landing Page, Mobile App, Finance, Analytics, Approvals, UI Frames, Dashboard, Transactions, Metrics, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# FinEase Personal Loan Landing Page Template

A modern FinEase-style landing page template for instant personal and business loan services in India, featuring benefits, eligibility, reviews, FAQ, and enquiry form.

1. Open folder in VS Code / terminal.
2. Run `npm install`.

# Financial Mobile App Landing Page Template

This is a reusable landing page template designed for financial mobile apps, showcasing banking features and user interface elements for iPhone frames.

## Project Details
- **Slug:** `financial-app-mobile`
- **Views:** 2079
- **Tags:** Landing Page, Mobile App, Finance, Banking, iPhone Frames, Features, UI, Call to Action, Testimonials, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Financial Asset Card UI Template

A clean, modern financial asset card UI template for displaying stock prices and returns, ready to plug into dashboards, fintech apps, or landing pages.

- **Slug:** `financial-asset-65`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Financial Dashboard UI Template

A dark, glassmorphism financial dashboard UI template for fund analytics, risk scoring, ESG insights, and investment reporting interfaces.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

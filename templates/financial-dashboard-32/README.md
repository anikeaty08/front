# Financial Dashboard Template

A reusable financial dashboard template for fintech products, internal ops teams, and business analytics interfaces with cards, charts, and activity tracking.

## Project Details
- **Slug:** `financial-dashboard-32`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

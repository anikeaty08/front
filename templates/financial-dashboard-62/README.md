# Financial Dashboard Template

A reusable financial dashboard template for tracking balances, income, expenses, and transactions with filters, exports, and dark mode.

## Project Details
- **Slug:** `financial-dashboard-62`
- **Views:** 18
- **Tags:** Technology, Services, Dashboard, Admin, Clean, Minimal, Dark, Landing Page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

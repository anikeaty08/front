# Finance Dashboard UI Template

A reusable finance dashboard UI template for visualizing company expenses with interactive charts, category filters, and a modern sidebar layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Financial Services Brand Landing Page Template

A reusable landing page template for financial services groups to present their brand story, ecosystem, governance, and offices with a clean, modern layout.

## Project Details
- **Slug:** `financial-group-79`
- **Views:** 14
- **Tags:** Landing Page, Services, Business, Brand, Brand Guidelines, Clean, Minimal, Large Type, Gradient, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

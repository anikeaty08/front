# Financial Intelligence Landing Page Template

This reusable landing page template is designed to showcase a financial intelligence platform for modern enterprises, highlighting banking, treasury, and cash flow forecasting features.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

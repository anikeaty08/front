# Personal Finance Mobile UI Template

A modern personal finance app UI template for tracking assets, budgets, accounts, and transactions in a clean mobile dashboard layout.

- **Slug:** `finchi-personal-49`
- **Views:** 21

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

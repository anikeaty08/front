# Prediction Markets Trading Platform Template

A reusable dark-mode template for launching a prediction markets or event trading platform with dashboard UI, liquidity sections, and conversion-focused CTAs.

## Project Details
- **Slug:** `finomenn-markets`
- **Views:** 71
- **Tags:** Landing Page, Technology, Dark, Futuristic, Gradient, Animated, Trading, Dashboard, Finance
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Fintech Accounts Dashboard UI Template

A modern fintech accounts dashboard template for tracking balances, payouts, and transaction activity, ready to adapt into your finance or banking web app.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

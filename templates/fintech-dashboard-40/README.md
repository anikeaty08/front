# FinTech Payout Management Template

A professional financial services dashboard template designed for prop trading firms to manage payouts, withdrawals, and payment method verification.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

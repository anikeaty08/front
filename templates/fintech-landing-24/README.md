# Fintech App Landing Page Template

A reusable fintech landing page template for showcasing budgeting apps that help gig workers manage cash flow, spending limits, and financial survival.

## Project Details
- **Slug:** `fintech-landing-24`
- **Views:** 40
- **Tags:** Landing Page, Technology, Dark, Gradient, Futuristic, Clean, Finance, Fintech, Mobile App, SaaS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

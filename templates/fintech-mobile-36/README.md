# Fintech App Interface UI Template

Modern fintech app interface template showcasing multi-screen balance, cards, and transfers layouts for designing and prototyping finance mobile apps.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

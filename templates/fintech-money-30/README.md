# AfriSend Money Transfer Landing Page Template

A dark, modern landing page template for secure international money transfer and forex apps, ready to reuse for remittance or fintech brands.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# DiamondChain FinTech Payment Portal Template

A clean, professional financial portal template for secure transaction confirmations and cross-bank transfer flows with integrated identity verification.

- **Slug:** `fintech-payment-29`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

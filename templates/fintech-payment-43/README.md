# Global Payments Landing Page Template

A reusable landing page template for fintech and payment infrastructure platforms showcasing global payments, payouts, treasury, FX, and compliance.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

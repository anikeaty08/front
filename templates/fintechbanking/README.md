# Neobank Finance Landing Page Template

A modern dark-mode neobank landing page template for showcasing digital banking apps, debit cards, and account signups with bold, glassmorphism visuals.

## Project Details
- **Slug:** `fintechbanking`
- **Views:** 68
- **Tags:** Landing Page, Technology, Brand, Dark, Gradient, Minimal, Large Type, Finance, Neobank, App
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

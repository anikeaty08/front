# Fitness Coach AI Assistant Landing Page Template

A dark, modern landing page template for promoting an AI assistant Telegram bot that automates bookings, client support, and payments for fitness trainers.

## Project Details
- **Slug:** `fitness-ai-assistant-1`
- **Views:** 16
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Futuristic, Large Type, Gradient, Fitness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

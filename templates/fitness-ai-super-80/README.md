# FitRecover+ Health & Fitness App UI Template

A dark, glassmorphism mobile app UI template for an AI-powered health, recovery, and fitness coaching experience from onboarding to rehab and nutrition.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

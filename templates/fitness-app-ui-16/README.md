# Fitness App UI Screens Template

A reusable mobile fitness app UI template featuring sign up, settings, notifications, and comments screens for health and workout tracking products.

## Project Details
- **Slug:** `fitness-app-ui-16`
- **Views:** 152
- **Tags:** Health, Technology, Landing Page, Brand, Dark, Gradient, Minimal, Futuristic, Mobile UI, Fitness App
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

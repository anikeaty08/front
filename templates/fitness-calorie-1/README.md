# Health Calorie Calculator App Template

A reusable calorie calculator template for health and fitness sites, using the Harris-Benedict formula to show cut, maintain, and bulk calorie targets.

## Project Details
- **Slug:** `fitness-calorie-1`
- **Views:** 30
- **Tags:** Health, Landing Page, Services, Technology, Dark, Clean, Minimal, Large Type, Calorie Calculator, Fitness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

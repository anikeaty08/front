# Fitness Center Landing Page Template

A modern fitness center landing page template for gyms and wellness studios to showcase classes, trainers, schedules, and membership plans.

## Project Details
- **Slug:** `fitness-center-88`
- **Views:** 20
- **Tags:** Landing Page, Health, Services, Dark, Clean, Gradient, Minimal, fitness, gym, membership
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

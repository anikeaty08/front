# Fitness Gym Landing Page Template

A reusable fitness club landing page template for gyms and wellness studios to promote classes, trainers, memberships, schedules, and app downloads.

## Project Details
- **Slug:** `fitness-club-12`
- **Views:** 57
- **Tags:** Landing Page, Health, Services, Brand, Dark, Clean, Large Type, Minimal, Fitness, Gym
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

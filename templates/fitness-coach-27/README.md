# Fitness Coach Landing Page Template

A bold, reusable landing page template for online fitness coaches to promote programs, showcase results, answer FAQs, and drive coaching sign-ups.

## Project Details
- **Slug:** `fitness-coach-27`
- **Views:** 155
- **Tags:** Landing Page, Health, Services, Dark, Clean, Large Type, fitness coach, personal training, testimonials
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

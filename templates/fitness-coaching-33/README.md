# Fitness Coaching Landing Page Template

A reusable landing page template for online and in-person fitness coaching brands to showcase programs, transformations, testimonials, and conversion-focused CTAs.

## Project Details
- **Slug:** `fitness-coaching-33`
- **Views:** 62
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Dark, Fitness, Coaching, Personal Training

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

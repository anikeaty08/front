# Fitness Coaching Landing Page Template

A reusable landing page template for online fitness coaches to attract busy professionals, showcase packages, build trust, and drive consultation bookings.

## Project Details
- **Slug:** `fitness-coaching-5`
- **Views:** 84
- **Tags:** Landing Page, Health, Services, Brand, Dark, Clean, Minimal, Fitness, Coaching

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

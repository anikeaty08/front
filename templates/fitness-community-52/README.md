# Fitness Community App UI Template

A modern fitness community app UI template for showcasing athletes, daily challenges, and trending workouts in a sleek dark mobile-style layout.

## Project Details
- **Slug:** `fitness-community-52`
- **Views:** 34
- **Tags:** Health, Community, Brand, Clean, Dark, Minimal, Large Type, Gradient, Mobile App, Fitness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

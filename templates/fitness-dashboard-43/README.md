# Fitness Dashboard Template

A reusable fitness dashboard template for tracking workouts, habits, sleep, and activity metrics with a sleek dark analytics UI.

## Project Details
- **Slug:** `fitness-dashboard-43`
- **Views:** 39
- **Tags:** Health, Technology, Dashboard, Landing Page, Dark, Clean, Minimal, Analytics, Fitness

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

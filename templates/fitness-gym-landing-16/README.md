# Fitness Gym Landing Page Template

A sleek fitness studio template for gyms and training centers to showcase facilities, memberships, classes, and drive new member signups.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

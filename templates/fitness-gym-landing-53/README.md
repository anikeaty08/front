# Fitness Gym Landing Page Template

A bold fitness landing page template for gyms and personal training studios to showcase programs, class schedules, trainers, and memberships.

- **Slug:** `fitness-gym-landing-53`
- **Views:** 425

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Fitness Match AI Mobile UI Template

A dark, futuristic Fitness Match AI mobile UI template for visualizing compatibility scores, breakdowns, and detailed stats in fitness or wellness apps.

## Project Details
- **Slug:** `fitness-match-83`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

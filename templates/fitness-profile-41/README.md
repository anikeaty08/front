# Fitness Profile UI Landing Page Template

A dark, futuristic fitness profile UI template for workout tracking apps, ideal as a reusable landing page and in-app profile screen design.

## Project Details
- **Slug:** `fitness-profile-41`
- **Views:** 11
- **Tags:** Landing Page, Health, Technology, Brand, Dark, Futuristic, Minimal, Large Type, Fitness app, Mobile UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

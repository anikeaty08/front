# Fitness Player Dashboard Template

A reusable dark fitness dashboard template for tracking workouts, nutrition goals, weekly training splits, and progression with a gamified system UI.

## Project Details
- **Slug:** `fitness-progress-66`
- **Views:** 21
- **Tags:** Health, Technology, Dashboard, Landing Page, Dark, Futuristic, Clean, Minimal, Fitness, Gamified
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

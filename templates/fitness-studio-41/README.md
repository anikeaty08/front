# Fitness Studio Landing Page Template

A modern fitness studio landing page template for showcasing facilities, classes, trainers, and memberships with a built-in free trial signup flow.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Fitness Training App Template

A dark mobile fitness app template for building workout libraries, training logs, interval timers, video references, and nutrition tracking flows.

## Project Details
- **Slug:** `fitness-training-28`
- **Views:** 42
- **Tags:** Health, Technology, Landing Page, Dark, Clean, Minimal, Mobile App, Fitness, Workout Tracker
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

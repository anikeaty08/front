# Fitonomics web page 

A dark, modern landing page template for promoting a Telegram-based mental wellness bot and content channel, ready to customize for your own service.

- **Slug:** `fitonomicsrobot`
- **Views:** 23

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# All Device Repairing

A reusable landing page template for local computer and laptop repair services, featuring service grids, contact details, enquiry form, and map integration.

## Project Details
- **Slug:** `fixplusconzapollo`
- **Views:** 48
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

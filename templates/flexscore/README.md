# Sports Fantasy Scores Landing Page Template

A reusable landing page template designed for sports fantasy leagues and live scores, featuring match previews, fantasy contests, and real-time score updates.

## Project Details
- **Slug:** `flexscore`
- **Views:** 1898
- **Tags:** Landing Page, Fantasy Sports, Live Scores, Match Preview, Filters, Interactive UI, Dark Theme, Sports News, Mobile Navigation, User Profile
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Flight Booking UI Template

A modern flight booking UI template showcasing multi-city trips, space flights, and mobile boarding passes for travel and airline app interfaces.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

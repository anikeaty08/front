# Dental Clinic Landing Page Template

A reusable dental clinic template for implant, restoration, and consultation websites with service highlights, testimonials, and appointment booking.

## Project Details
- **Slug:** `florida-dental-implant`
- **Views:** 68
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Technology, medical, dental clinic, appointment form
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

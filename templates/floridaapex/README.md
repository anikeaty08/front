# Florida Apex

A reusable landing page template for landscaping, remodeling, flooring, and property improvement businesses to showcase services, projects, reviews, and quote requests.

## Project Details
- **Slug:** `floridaapex`
- **Views:** 14
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Portfolio, Home services, Landscaping, Remodeling, Construction
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

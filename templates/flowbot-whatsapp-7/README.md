# FlowBot WhatsApp Automation Landing Page Template

A reusable landing page template for showcasing WhatsApp automation tools aimed at African businesses, featuring AI chatbots and no-code workflow building.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

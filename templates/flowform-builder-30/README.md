# FlowForm Builder App Template

A dark, modern FlowForm Builder UI template for creating, previewing, and publishing logic-based forms with JSON export and draft saving.

## Project Details
- **Slug:** `flowform-builder-30`
- **Views:** 29
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Form builder, Web app UI, Logic flows, Interactive preview, JSON export

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

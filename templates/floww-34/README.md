# Floww WhatsApp Marketing Landing Page Template

A high-converting Floww WhatsApp Marketing API landing page template for SaaS and service businesses to showcase features, pricing, and AI chatbot benefits.

1. Open folder in VS Code / terminal.
2. Run `npm install`.

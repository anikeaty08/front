# Fluxer AI Website Generator Landing Page Template

A dark, AI-powered website builder landing page template for showcasing features, editor UI, and pricing plans for modern SaaS products.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

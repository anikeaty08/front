# CS Matchmaking Dashboard UI Template

A dark, competitive CS-style matchmaking dashboard UI template for gaming platforms, featuring lobby, ELO stats, skins hub, leaderboard, and global chat.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

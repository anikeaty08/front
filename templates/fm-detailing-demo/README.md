# FM DETAILING Demo Web

A high-impact template for car detailing studios to showcase services, portfolio, trust signals, and drive bookings for premium vehicle care.

## Project Details
- **Slug:** `fm-detailing-demo`
- **Views:** 39
- **Tags:** Landing Page, Services, Portfolio, Dark, Gradient, Clean, Minimal, automotive, detailing
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# FMCG Brand Group Landing Page Template

A modern FMCG group landing page template for showcasing multi-brand portfolios, sectors, and products with investor and partner contact built in.

## Project Details
- **Slug:** `fmcg-brand-group-76`
- **Views:** 40
- **Tags:** Landing Page, Brand, E-commerce, Clean, Minimal, Large Type, Technology, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

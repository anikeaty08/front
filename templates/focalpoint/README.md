# Focal Point Landing Page

A high-converting dark-mode landing page template for Klaviyo and Shopify email agencies to showcase services, results, FAQs, and drive call bookings.

## Project Details
- **Slug:** `focalpoint`
- **Views:** 60
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Gradient, Large Type, Minimal, Email Marketing, Shopify
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

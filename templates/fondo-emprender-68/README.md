# Fondo Emprender Project Management Landing Page Template

Landing page template inspired by Fondo Emprender SENA to manage entrepreneurship projects, showcase active funding calls, and guide users through the application process.

## Project Details
- **Slug:** `fondo-emprender-68`
- **Views:** 27
- **Tags:** Landing Page, Business, Services, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

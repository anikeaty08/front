# Plumbing Services Landing Page Template

A reusable landing page template for plumbing, heating, and gas service businesses to showcase services, credentials, gallery work, and quote requests.

## Project Details
- **Slug:** `fontaneriacalefaccion`
- **Views:** 22
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Dark, Local business, Home services, Plumbing, Heating
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

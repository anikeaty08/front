# Food Delivery Landing Page Template

A reusable food delivery and quick commerce template for showcasing restaurants, grocery options, campaigns, and fast local ordering.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

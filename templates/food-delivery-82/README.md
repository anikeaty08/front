# Food Delivery Landing Page Template

A modern food delivery landing page template for showcasing restaurants, menus, and an interactive cart experience for online food ordering platforms.

## Project Details
- **Slug:** `food-delivery-82`
- **Views:** 6
- **Tags:** Food, E-commerce, Landing Page, Brand, Clean, Colorful, Minimal, Large Type, Technology

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

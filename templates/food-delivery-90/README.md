# Food Delivery App Template

A reusable food delivery template for showcasing restaurants, menus, cart flows, and checkout in a modern mobile-friendly ordering experience.

## Project Details
- **Slug:** `food-delivery-90`
- **Views:** 62
- **Tags:** Food, E-commerce, Landing Page, Clean, Minimal, Services, app UI, restaurant ordering, checkout flow
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

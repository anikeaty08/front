# Food Landing Page Template

A polished e-commerce template for premium food and gift brands to showcase products, editions, FAQs, and purchase journeys with a travel-friendly story.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

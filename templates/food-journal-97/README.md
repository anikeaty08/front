# Food Journal App Landing Page Template

A dark, modern landing page template for a mobile food journal app to log meals, ratings, and locations, ready to customize for your own product.

## Project Details
- **Slug:** `food-journal-97`
- **Views:** 24
- **Tags:** Landing Page, Food, Technology, Brand, Dark, Gradient, Minimal, Large Type, Mobile App, Product
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Gochujang Bros_en

A reusable landing page template for launching and promoting a bold snack or food product with waitlist CTAs, feature sections, pricing, and FAQs.

## Project Details
- **Slug:** `food-product-47`
- **Views:** 40
- **Tags:** Food, Landing Page, Brand, Clean, Minimal, Gradient, Product Launch, Snack, Waitlist
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

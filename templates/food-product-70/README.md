# Gochujang Bros

A bold, reusable landing page template for promoting snack or food products with storytelling, features, pricing, testimonials, FAQ, and pre-order CTAs.

## Project Details
- **Slug:** `food-product-70`
- **Views:** 36
- **Tags:** Food, Landing Page, Brand, Clean, Bold, Minimal, Product Launch, Pre-order, Korean Snack
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Food Rarity Scanner App UI Template

Mobile app UI template for a gamified food rarity scanner that analyzes dishes, shows health stats, and reveals detailed ingredient insights.

## Project Details
- **Slug:** `food-rarity-scanner-8`
- **Views:** 9
- **Tags:** Food, Health, Technology, Landing Page, Dark, Gradient, Minimal, Large Type, Mobile App, Scanner
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

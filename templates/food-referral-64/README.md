# Customer Profile & Referral Dashboard Template

Reusable customer profile and referrals dashboard template for food or e-commerce brands to manage accounts, rewards, and support in one clean UI.

## Project Details
- **Slug:** `food-referral-64`
- **Views:** 20
- **Tags:** Landing Page, E-commerce, Food, Brand, Clean, Gradient, Minimal, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Food Social App UI Template

A colorful BiteBuddies mobile app UI template for food-sharing, recipes, and cooking challenges, ready to customize for your own social food platform.

- **Slug:** `food-social-app-43`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Food Tracking Card UI Template

A reusable template for showcasing food log and calorie tracking cards with clean, modern layouts for nutrition, health, or meal-planning apps.

## Project Details
- **Slug:** `food-tracking-34`
- **Views:** 38

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Football Club Landing Page Template

A modern football club landing page template for teams to showcase matches, news, tickets, and shop in a bold, brand-forward layout.

## Project Details
- **Slug:** `football-club-38`
- **Views:** 100
- **Tags:** Landing Page, Brand, Sports, Club, Clean, Dark, Gradient, Large Type, Minimal, Entertainment
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Football Club Landing Page Template

Modern single-page website template for local football clubs, featuring fixtures, squad, membership, sponsors, and contact sections, ready to customize for your team.

## Project Details
- **Slug:** `football-club-67`
- **Views:** 37
- **Tags:** Landing Page, Brand, Clean, Minimal, Sports, Football Club, Community, Membership
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

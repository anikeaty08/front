# Football News Portal Landing Page Template

A modern football news portal landing page template with live scores, betting odds widgets, and article layouts ready for sports media sites.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

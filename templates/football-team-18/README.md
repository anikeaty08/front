# Football Team Management Dashboard Template

Modern FutManager-style web app template for managing amateur football team schedules, payments, squad and media in a single dashboard interface.

## Project Details
- **Slug:** `football-team-18`
- **Views:** 28
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Minimal, Large Type, Dashboard, Sports
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

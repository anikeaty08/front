# Footwear E-commerce Store Template

A modern Shoe Box-inspired e-commerce template for selling footwear online, featuring product grids, filters, WhatsApp checkout, and an integrated admin dashboard.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

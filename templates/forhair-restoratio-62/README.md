# Hair Restoration Quiz Landing Page Template

A reusable landing page template for hair restoration clinics to qualify leads with a quick quiz, build trust with testimonials, and drive free consultations.

## Project Details
- **Slug:** `forhair-restoratio-62`
- **Views:** 13
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, quiz funnel, testimonials, medical lead generation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Accounting Firm Landing Page Template

A modern Swedish accounting firm landing page template for showcasing bookkeeping, payroll, and advisory services with local, trust-focused messaging.

## Project Details
- **Slug:** `forsredovisning`
- **Views:** 538
- **Tags:** Landing Page, Services, Business, Accounting, Clean, Dark, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

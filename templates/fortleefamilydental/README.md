# Dental Clinic Landing Page Template

A modern dental practice landing page template for family and cosmetic dentists to showcase services, team, location, and online appointment requests.

## Project Details
- **Slug:** `fortleefamilydental`
- **Views:** 18
- **Tags:** Landing Page, Services, Health, Brand, Clean, Minimal, Large Type, Gradient, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

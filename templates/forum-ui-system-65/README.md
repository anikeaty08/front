# Forum UI System Landing Page Template

A reusable forum and community app UI template featuring feeds, threads, profiles, chat, subscriptions, and error states for modern product interfaces.

## Project Details
- **Slug:** `forum-ui-system-65`
- **Views:** 10
- **Tags:** Landing Page, Brand, Technology, Dark, Minimal, Clean, Large Type, Community, UI Kit, Forum
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

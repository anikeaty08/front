# Non-profit Donation Landing Page Template

A modern Hope Foundation-inspired non-profit landing page template for charities to showcase causes, programs, and drive donations and volunteer signups.

## Project Details
- **Slug:** `foundationforhope`
- **Views:** 78
- **Tags:** Landing Page, Non-profit, Social, Clean, Gradient, Large Type, Brand, Services, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

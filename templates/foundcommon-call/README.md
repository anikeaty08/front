# Call Confirmation Landing Page Template

A high-converting call confirmation landing page template to prep leads with a pre-call video, FAQ, calculator, and proof before your sales call.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

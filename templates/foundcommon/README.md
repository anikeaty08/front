# Home Service Appointment Funnel Landing Page Template

Conversion-focused landing page template for home service contractors to sell pay-per-appointment booking services with pricing, calculators, and step-by-step process.

## Project Details
- **Slug:** `foundcommon`
- **Views:** 18
- **Tags:** Landing Page, Business, Services, Technology, Clean, Minimal, Large Type, Appointment booking, Home services, Lead generation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

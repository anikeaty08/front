# Executive Dashboard Template

A reusable executive dashboard template for tracking revenue, clients, labor allocation, service logs, and data exports in a sleek operations UI.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

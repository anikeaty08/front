# Framer Commerce Landing Page Template

A modern Framer commerce landing page template for brands selling products with Stripe integration, customizable checkout, and animated product UI.

## Project Details
- **Slug:** `framer-commerce-35`
- **Views:** 16
- **Tags:** Landing Page, E-commerce, Technology, Brand, Clean, Gradient, Large Type, Minimal, Animated
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

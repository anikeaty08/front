# Fitness Franchise Landing Page Template

High-impact landing page template for fitness and kickboxing franchises to showcase their business model, highlight benefits, and capture qualified leads.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

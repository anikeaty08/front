# Travel CMS Admin Dashboard Template

A modern Travel CMS admin dashboard template for managing tour offers, bookings, clients, and SEO content in one streamlined interface.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

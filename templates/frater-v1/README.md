# Catholic Travel Agency Landing Page Template

Elegant Catholic travel agency landing page template for pilgrimage, cultural tours, and faith-based travel brands to showcase offers and capture inquiries.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

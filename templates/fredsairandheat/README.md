# Fred's Air Conditioning and Heating

A reusable landing page template for HVAC companies to promote repair, installation, maintenance, and lead generation in local service markets.

## Project Details
- **Slug:** `fredsairandheat`
- **Views:** 46

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

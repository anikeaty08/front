# Fred's Air Conditioning and Heating

A reusable landing page template for HVAC, AC repair, and heating businesses to promote services, build trust, and drive service requests.

## Project Details
- **Slug:** `fredshvac`
- **Views:** 69
- **Tags:** Landing Page, Services, Business, Technology, Clean, Minimal, Grid, Local Services, HVAC, Home Services

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

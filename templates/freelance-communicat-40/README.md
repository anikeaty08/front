# Freelance Communication Portfolio Website Template

A modern dark-mode portfolio website template for freelance communication and copywriting professionals to showcase services, projects, testimonials, and capture client leads.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

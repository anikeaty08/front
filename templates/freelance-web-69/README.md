# Web Designer

A reusable plumbing services landing page template for local tradies, featuring hero quote form, service highlights, FAQs, and blog-style tips to convert visitors.

## Project Details
- **Slug:** `freelance-web-69`
- **Views:** 21
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Technology, Plumbing, Local Business, Home Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

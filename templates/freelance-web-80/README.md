# Freelance Web Architect Landing Page Template

A dark, minimal freelance web architect landing page template for showcasing services, portfolio, pricing, FAQs, and contact to win high-value clients.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

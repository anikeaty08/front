# Dental Practice Landing Page Template

A premium dental clinic website template for cosmetic, general, and emergency dentistry practices to showcase services, build trust, and book appointments.

## Project Details
- **Slug:** `freemansbaydentalclinic`
- **Views:** 47
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, booking, dental, medical, luxury

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# IA Var | L’IA simple à intégrer en 3 étapes, sans compromis

A modern template for promoting a sovereign AI SaaS and training offer for French TPE/PME, combining on-site formation and application in a reusable landing page layout.

1. Open folder in VS Code / terminal.

# French Restaurant Landing Page Template

Elegant French restaurant landing page template for showcasing chef, menu, hours, and reservations for bistros and upscale dining venues.

## Project Details
- **Slug:** `french-bistro-48`
- **Views:** 21

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

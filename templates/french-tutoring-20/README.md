# French Tutoring Landing Page Template

A clean landing page template for private French tutors and language coaches to book free assessments, showcase trust signals, and drive student inquiries.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

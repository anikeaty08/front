# Frendz Partners Partner Dashboard UI Template

A modern partner dashboard UI template for bars and local venues to manage events, boosts, benefits, and KPIs in a clean, responsive interface.

## Project Details
- **Slug:** `frendz-partners`
- **Views:** 11
- **Tags:** Landing Page, Brand, Technology, Clean, Colorful, Gradient, Minimal, Dashboard, Events, Bars
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

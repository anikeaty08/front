# JuiceOS Delivery Landing Page Template

A dark, futuristic JuiceOS landing page template for fresh juice and fruit delivery brands to showcase features, offers, and fast ordering experiences.

## Project Details
- **Slug:** `fresh-juice-delivery-76`
- **Views:** 11
- **Tags:** Landing Page, Food, Brand, Dark, 3D, Gradient, Minimal, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

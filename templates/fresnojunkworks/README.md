# Junk Removal Services Landing Page Template

A reusable landing page template for junk removal and hauling businesses to showcase services, build trust, and drive quote requests fast.

## Project Details
- **Slug:** `fresnojunkworks`
- **Views:** 38
- **Tags:** Landing Page, Services, Brand, Dark, Gradient, Clean, Animated, local business, junk removal, hauling
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

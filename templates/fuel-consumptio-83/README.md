# Fuel Record Pro Mobile App UI Template

A modern mobile app UI template for Fuel Record Pro, designed to track fuel expenses, mileage, and consumption with clean dashboards and intuitive record forms.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# FuelTunnel Bulk Fuel Landing Page Template

A dark, technology-focused landing page template for bulk diesel and fuel logistics providers to showcase services, pricing, monitoring tech, and contact capture.

## Project Details
- **Slug:** `fueltunnel-bulk-57`
- **Views:** 36
- **Tags:** Landing Page, Business, Services, Technology, Brand, Dark, Gradient, Clean, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

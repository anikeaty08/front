# Functional Health Coaching Landing Page Template

A reusable landing page template for functional health coaches to attract high-performing clients, showcase results, explain offers, and book discovery calls.

## Project Details
- **Slug:** `functional-health-5`
- **Views:** 83
- **Tags:** Health, Landing Page, Services, Dark, Clean, Minimal, coaching, testimonials, booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

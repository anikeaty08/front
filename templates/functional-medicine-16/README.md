# Functional Medicine Landing Page Template

A high-converting healthcare template for functional medicine clinics to showcase root-cause care, patient trust, testimonials, and consultation booking.

## Project Details
- **Slug:** `functional-medicine-16`
- **Views:** 48
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Video testimonials, Medical, Consultation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

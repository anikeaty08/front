# Functional Medicine and Health Services Template

A clean, high-conversion healthcare template designed for functional medicine practitioners and clinics looking to turn patient inquiries into consultations.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

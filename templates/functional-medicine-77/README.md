# Functional Medicine Landing Page Template

A reusable healthcare landing page template for functional medicine clinics to promote consultations, showcase testimonials, and drive patient bookings.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

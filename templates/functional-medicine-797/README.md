# Health Services Landing Page Template

A reusable landing page template for chiropractic, functional medicine, and wellness clinics to showcase outcomes, build trust, and drive evaluation bookings.

## Project Details
- **Slug:** `functional-medicine-797`
- **Views:** 24
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Video Testimonials, Wellness, Chiropractic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

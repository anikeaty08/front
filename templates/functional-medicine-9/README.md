# Functional Medicine Consultation Landing Page Template

A reusable healthcare landing page template for chiropractors and functional medicine clinics to promote consultations, build trust, and convert patients.

## Project Details
- **Slug:** `functional-medicine-9`
- **Views:** 58
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Testimonials, Medical, Wellness, Consultation

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

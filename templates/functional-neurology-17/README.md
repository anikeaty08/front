# Functional Neurology Landing Page Template

A reusable healthcare landing page template for functional neurology clinics to showcase services, build trust, and drive consultation bookings.

## Project Details
- **Slug:** `functional-neurology-17`
- **Views:** 33
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Brand, medical, neurology, clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

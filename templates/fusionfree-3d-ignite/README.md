# Mobile UX Portfolio Landing Page Template

A dark, Swiss-inspired mobile UX portfolio landing page template showcasing hero, features, pricing, and testimonials for designers and creatives.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

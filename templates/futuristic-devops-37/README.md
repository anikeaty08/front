# Futuristic SaaS Landing Page Template

A sleek, futuristic landing page template for developer-first infrastructure or SaaS platforms, featuring glassmorphism, workflow, features, and testimonial sections.

1. Open folder in VS Code / terminal.
2. Run `npm install`.

# Futuristic Restaurant Landing Page Template

A bold, cyberpunk restaurant landing page template for edgy food brands to showcase menus, locations, and newsletter drops with animated 3D visuals.

- **Slug:** `futuristic-food-25`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

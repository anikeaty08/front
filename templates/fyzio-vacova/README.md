# Physiotherapy Clinic Landing Page Template

A clean, modern physiotherapy clinic landing page template for promoting private practices, showcasing services, pricing, and contact details.

## Project Details
- **Slug:** `fyzio-vacova`
- **Views:** 10
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

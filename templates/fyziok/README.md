# Physiotherapy Clinic Landing Page Template

A modern physiotherapy clinic landing page template for independent therapists and studios to showcase services, pricing, and contact details in a clean, trust-building layout.

## Project Details
- **Slug:** `fyziok`
- **Views:** 101
- **Tags:** Health, Landing Page, Services, Brand, Clean, Minimal, Large Type, Gradient, Physiotherapy, Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

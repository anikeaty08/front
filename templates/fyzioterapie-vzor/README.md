# Physiotherapy Landing Page Template

A reusable physiotherapy landing page template for clinics and solo practitioners to promote services, build trust, and drive appointment bookings.

## Project Details
- **Slug:** `fyzioterapie-vzor`
- **Views:** 17
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, local clinic, physiotherapy, rehabilitation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

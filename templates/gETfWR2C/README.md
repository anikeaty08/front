# Code Editor Interface with Terminal

Displays a web-based code editor UI featuring syntax-highlighted code, line numbers, terminal output, and status info using Tailwind CSS.

## Project Details
- **Slug:** `gETfWR2C`
- **Views:** 105
- **Tags:** Code Editor, Syntax Highlighting, Terminal, Tailwind CSS, UI Component, Line Numbers, Status Bar
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

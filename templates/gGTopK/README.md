# Glassmorphic Music Player UI

Responsive music player UI with glassmorphism, animated equalizer, progress bar, and playback controls using Tailwind CSS.

## Project Details
- **Slug:** `gGTopK`
- **Views:** 69
- **Tags:** Music Player, Glassmorphism, Tailwind CSS, Animated Equalizer, Progress Bar, Responsive UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Gamified Learning Dashboard UI Template

A dark, gamified learning dashboard UI template for quiz-based education apps, featuring streaks, badges, leaderboards, and multiple practice modes.

## Project Details
- **Slug:** `gabits-gamified-8`
- **Views:** 24
- **Tags:** Education, Landing Page, Technology, Brand, Dark, Gradient, Clean, Minimal, Dashboard, Gamification
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

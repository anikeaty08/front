# Digital Services Portfolio Website Template

A modern dark-theme portfolio website template for freelancers offering automation, SEO, design, and web development services to showcase work and book clients.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

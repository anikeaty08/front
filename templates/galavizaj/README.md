# AJ Galaviz

A reusable portfolio landing page template for graphic designers and visual creatives to showcase work, process, and contact details in a polished dark UI.

- **Slug:** `galavizaj`
- **Views:** 272

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Galaxy  SaaS Landing Page Template

A futuristic Galaxy Goals-inspired landing page template for goal-tracking or productivity SaaS products, ready to customize for your own brand.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

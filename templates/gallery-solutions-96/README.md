# Web Development Services Landing Page Template

A modern, dark-mode landing page template for web development agencies to showcase services, packages, and lead-capture forms with a premium aesthetic.

- **Slug:** `gallery-solutions-96`
- **Views:** 20

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

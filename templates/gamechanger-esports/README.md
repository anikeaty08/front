# Game Changer Esports Landing Page Template

A reusable landing page template designed for esports leagues to showcase tournaments, teams, live events, and community engagement.

## Project Details
- **Slug:** `gamechanger-esports`
- **Views:** 46
- **Tags:** Landing Page, Esports, Tournaments, Teams, Live Events, Gallery, Registration, Stats, Filters
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

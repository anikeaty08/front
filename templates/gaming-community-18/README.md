# Gaming Community Portal Landing Page Template

A reusable gaming community portal landing page template featuring news feed, video highlights, admin post editor, and comments for eSports and streamer hubs.

## Project Details
- **Slug:** `gaming-community-18`
- **Views:** 26
- **Tags:** Landing Page, Services, Brand, Dark, Clean, Gradient, Large Type, Technology, Entertainment, Gaming
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

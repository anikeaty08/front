# Gaming Event Agency Landing Page Template

A dark, modern landing page template for gaming and e-sport event agencies to showcase services, packages, and contact options in a polished, ready-to-use layout.

## Project Details
- **Slug:** `gaming-event-80`
- **Views:** 44
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

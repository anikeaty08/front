# Gaming Landing Page Template

A reusable gaming landing page template for browser-based multiplayer strategy games, featuring hero messaging, server lists, faction selection, and gameplay highlights.

## Project Details
- **Slug:** `gaming-landing-31`
- **Views:** 47
- **Tags:** Landing Page, Technology, Dark, Futuristic, Clean, Gaming, Multiplayer, Strategy

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Gaming Landing Page Template

A reusable betting and casino app landing page template for promoting game categories, app downloads, and fast login or registration on mobile.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

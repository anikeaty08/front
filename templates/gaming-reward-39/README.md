# Reward App Screen Template

A reusable mobile app template for gamified reward screens, showcasing challenges, prizes, progress tracking, and a bold call-to-action.

- **Slug:** `gaming-reward-39`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Gaming Server Landing Page Template

A dark, modern landing page template for Lineage 2 or private MMORPG servers to showcase features, live stats, and drive player registration.

## Project Details
- **Slug:** `gaming-server-31`
- **Views:** 100
- **Tags:** Landing Page, Entertainment, Brand, Dark, Gradient, Large Type, Minimal, Technology, Gaming, MMO
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

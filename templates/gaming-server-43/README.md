# Gaming Server Loading Screen Template

A reusable template for GTA roleplay or multiplayer server loading screens with animated progress UI, keybinds, rules, staff panels, and store modals.

- **Slug:** `gaming-server-43`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

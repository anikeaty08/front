# Gaming Server Landing Page Template

A dark, pixel-styled landing page template for showcasing a Minecraft/GTA-inspired roleplay gaming server and driving players to join your community.

## Project Details
- **Slug:** `gaming-server-7`
- **Views:** 34
- **Tags:** Landing Page, Entertainment, Gaming, Dark, Gradient, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

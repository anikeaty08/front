# Gaming Recruitment Landing Page Template

A dark, modern application landing page template for gaming and FiveM roleplay servers to recruit police, EMS, mechanics, and staff roles.

## Project Details
- **Slug:** `gaming-staff-73`
- **Views:** 9
- **Tags:** Landing Page, Brand, Clean, Dark, Gradient, Large Type, Gaming, FiveM, Recruitment, Application Form
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Gaming Dashboard Template

A reusable dark gaming dashboard template for virtual wallets, mini games, rewards, transactions, and admin request management.

## Project Details
- **Slug:** `gaming-wallet-64`
- **Views:** 88
- **Tags:** Landing Page, Technology, Dark, Clean, Minimal, Animated, dashboard, gaming, wallet

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

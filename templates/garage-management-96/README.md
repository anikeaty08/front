# Garage Management System Dashboard Template

A modern Garage Management System dashboard template for managing jobs, customers, inventory, finance, and staff in automotive workshops.

- **Slug:** `garage-management-96`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

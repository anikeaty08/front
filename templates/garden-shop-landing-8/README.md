# Garden Shop Landing Page Template

A clean, ready-to-use landing page template for a local garden shop or garden services business, perfect for showcasing offers, location, and contact details.

## Project Details
- **Slug:** `garden-shop-landing-8`
- **Views:** 22
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Garden, Local Business, Contact
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

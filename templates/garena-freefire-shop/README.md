# Gaming E-commerce Landing Page Template

A reusable dark-mode gaming e-commerce landing page template for selling digital game accounts and products with a bold, mobile-first layout.

- **Slug:** `garena-freefire-shop`
- **Views:** 54

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

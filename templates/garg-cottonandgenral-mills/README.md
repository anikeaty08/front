# Cotton Manufacturing Landing Page Template

A reusable landing page template for cotton mills, exporters, and agricultural manufacturers to showcase products, quality standards, sustainability, and inquiries.

## Project Details
- **Slug:** `garg-cottonandgenral-mills`
- **Views:** 51
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Environmental, manufacturing, cotton, export, agriculture
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

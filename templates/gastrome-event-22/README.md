# GASTROME Catering Landing Page Template

Elegant French catering landing page template for showcasing high-end event services, menus, and lead-gen contact forms for weddings and corporate events.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

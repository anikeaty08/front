# Gazebo E-commerce Landing Page Template

A modern e-commerce landing page template for selling premium pop-up gazebos and outdoor accessories, ready to customize for your own brand.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

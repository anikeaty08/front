# Vehicle Marketplace Landing Page Template

A modern UK-focused vehicle marketplace landing page template for listing cars, vans, parts, and services, ready to reuse for automotive trading platforms.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

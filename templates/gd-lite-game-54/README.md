# Arcade Game Landing Page Template

A dark, minimal arcade game landing page template showcasing a rhythm-based browser game with level select, customizer UI, and game over states.

## Project Details
- **Slug:** `gd-lite-game-54`
- **Views:** 25
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Entertainment, Game UI, Arcade, Interactive, Canvas
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

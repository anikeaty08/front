# Gen Z Mobile Dashboard UI Template

A Gen Z-inspired mobile dashboard UI template with glassmorphism cards, analytics, music player, and bottom navigation for modern apps.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

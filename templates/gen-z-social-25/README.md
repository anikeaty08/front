# Gen Z Social App UI Template

A reusable mobile-first Gen Z social app UI template for showcasing feeds, stories, and discovery screens in dark, claymorphism style.

## Project Details
- **Slug:** `gen-z-social-25`
- **Views:** 31
- **Tags:** Landing Page, Brand, Art & Design, Entertainment, Dark, Colorful, Gradient, Futuristic, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

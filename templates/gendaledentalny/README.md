# Dental Clinic Landing Page Template

A modern, conversion-focused dental clinic landing page template for promoting individualized care, locations, and appointment requests for local practices.

## Project Details
- **Slug:** `gendaledentalny`
- **Views:** 21
- **Tags:** Health, Landing Page, Services, Brand, Clean, Minimal, Large Type, Gradient, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# General des vetements

A reusable e-commerce shop template for showcasing products, managing carts, and handling simple checkout flows for modern online stores.

## Project Details
- **Slug:** `general-des-vetements`
- **Views:** 37

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Genika Café Artisan Landing Page Template

A warm and elegant cafe landing page template designed for coffee shops and restaurants to showcase their story and menu.

## Project Details
- **Slug:** `genika-cafe-tanjil`
- **Views:** 57
- **Tags:** Food, Services, Landing Page, Clean, Minimal, Dark, Typography
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Practice Landing Page Template

A modern Dental Practice Landing Page Template for showcasing services, savings plans, testimonials, and appointment requests for local dentists and clinics.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Hippocampus

A polished SaaS landing page template for an AI-powered company memory platform, ideal for showcasing product features, pricing, and enterprise-ready context tools.

## Project Details
- **Slug:** `get-hippocampus`
- **Views:** 27
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Gradient, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

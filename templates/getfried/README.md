# Gourmet Fries Food Truck Menu Template

A clean, ready-to-edit template for showcasing a gourmet fries food truck menu, including signature items, refreshments, and ingredient breakdowns.

## Project Details
- **Slug:** `getfried`
- **Views:** 21

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

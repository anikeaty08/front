# Luxury Reseller Landing Page Template

A minimalist luxury reseller landing page template for showcasing high-end fashion items and driving Telegram consultation-based sales.

- **Slug:** `gglux-number-one`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

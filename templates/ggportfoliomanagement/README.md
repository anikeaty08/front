# GG Portfolio Dashboard UI Template

A modern Folio portfolio management dashboard UI template for tracking investments, visualizing performance, and managing assets across stocks and crypto.

## Project Details
- **Slug:** `ggportfoliomanagement`
- **Views:** 16
- **Tags:** Landing Page, Technology, Brand, Gradient, Dark, Animated, Dashboard, Finance, Portfolio, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

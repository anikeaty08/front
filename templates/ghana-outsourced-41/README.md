# Outsourced Operations Landing Page Template

A dark, modern landing page template for outsourced customer support and back office teams, ideal for showcasing Ghana-based operations and lead capture.

- **Slug:** `ghana-outsourced-41`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Cybersecurity Tool Landing Page Template

A dark landing page template for showcasing cybersecurity, OSINT, recon, or research tools with a terminal-style hero and bold launch CTA.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

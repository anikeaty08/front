# Gift Card Redemption UI Template

A sleek, Apple-inspired gift card redemption UI template for entering or scanning card codes with loading states and error handling.

- **Slug:** `gift-card-redemption-25`
- **Views:** 15

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Gift Service Landing Page Template

A reusable landing page template for promoting gift ordering services, showcasing package options, payment details, and WhatsApp-based ordering.

## Project Details
- **Slug:** `gift-service-19`
- **Views:** 27
- **Tags:** Landing Page, Services, E-commerce, Clean, Minimal, Brand, gift shop, WhatsApp order, school campaign
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Artisan Gift Shop Landing Page Template

A reusable landing page template for artisan gift shops and local boutiques to showcase handcrafted collections, community roots, and in-store visits.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

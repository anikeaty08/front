# GIMENEZ MULTI SERVICES 32

A reusable landing page template for roofers and local home service businesses to showcase services, build trust, and generate free quote requests.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

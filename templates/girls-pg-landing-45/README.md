# Girls PG Landing Page Template

A reusable landing page template for girls PG, hostel, and managed accommodation brands to showcase rooms, amenities, pricing, safety, and booking CTAs.

## Project Details
- **Slug:** `girls-pg-landing-45`
- **Views:** 76
- **Tags:** Landing Page, Real Estate, Services, Clean, Minimal, accommodation, hostel, pg, coliving
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Glasshouse Café Landing Page Template

A reusable landing page template for stylish glasshouse cafés and coffee shops to showcase menus, galleries, reviews, and location details.

## Project Details
- **Slug:** `glasshouse-caf-44`
- **Views:** 49
- **Tags:** Landing Page, Food, Brand, Clean, Gradient, Large Type, Minimal, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

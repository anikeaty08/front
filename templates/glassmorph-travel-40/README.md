# Glassmorphism Travel Booking Mobile UI Template

A premium glassmorphism mobile UI template for travel and stay booking apps, featuring search, listings, calendar, and payment flows ready for customization.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

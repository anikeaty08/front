# Glassmorphism Mobile UI Template

A glassmorphism mobile UI template showcasing travel booking flows with settings, search, listing, and calendar screens for modern app prototypes.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

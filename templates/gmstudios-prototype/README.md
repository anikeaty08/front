# Community Collective Landing Page Template

A dark, futuristic landing page template for community-driven tech collectives and studios to showcase their philosophy, network, and high-trust circles.

## Project Details
- **Slug:** `gmstudios-prototype`
- **Views:** 36

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

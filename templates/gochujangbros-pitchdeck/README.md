# Food Pitch Deck Template

A reusable pitch deck template for food startups launching bold snack brands, with sections for problem, solution, validation, category vision, and team.

## Project Details
- **Slug:** `gochujangbros-pitchdeck`
- **Views:** 54
- **Tags:** Food, Landing Page, Brand, Clean, Minimal, Pitch Deck, Startup, Snack Brand, Korean Food
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

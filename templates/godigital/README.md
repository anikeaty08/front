# GoDigital Pay Homepage

A reusable landing page template for fintech infrastructure platforms, designed to showcase payment APIs, workflow automation, and developer-focused services.

## Project Details
- **Slug:** `godigital`
- **Views:** 72
- **Tags:** Landing Page, Technology, Services, Clean, Minimal, Brand, fintech, API, payments, SaaS

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

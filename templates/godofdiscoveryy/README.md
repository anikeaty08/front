# Creator Commerce App UI Template

A mobile-first Creator Studio app UI template for monetizing properties, music, cars, movies, tickets, and services in a sleek glassmorphism feed.

## Project Details
- **Slug:** `godofdiscoveryy`
- **Views:** 26
- **Tags:** Technology, Landing Page, Brand, Dark, Gradient, Minimal, Large Type, Clean, E-commerce, App UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

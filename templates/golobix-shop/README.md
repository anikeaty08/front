# Global E-Commerce Marketplace Template

A clean and functional e-commerce template designed for global marketplaces, featuring cross-border logistics tools and localized shopping experiences.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Local Business Booking Landing Page Template

A clean, conversion-focused landing page template for promoting a simple online booking system for local businesses with WhatsApp and Google Calendar sync.

## Project Details
- **Slug:** `googlesheets-booksimple`
- **Views:** 43
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Brand, Gradient, Large Type, Booking, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

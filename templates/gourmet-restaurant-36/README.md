# Gourmet Restaurant Landing Page Template

A clean and modern street-food restaurant landing page template designed to showcase culinary specialties, digital menus, and online ordering.

## Project Details
- **Slug:** `gourmet-restaurant-36`
- **Views:** 36
- **Tags:** Food, Services, Clean, Minimal, Blue, Landing Page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

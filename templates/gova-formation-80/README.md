# Gova Formation Dashboard Template

A dark, modern dashboard template for a French-language achat‑revente (buy‑resell) training platform, ready to customize for your own online course program.

## Project Details
- **Slug:** `gova-formation-80`
- **Views:** 9
- **Tags:** Landing Page, Education, Services, Brand, Dark, Clean, Minimal, Dashboard, Course Platform, E-learning
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

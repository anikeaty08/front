# Government Case Management Portal Template

A reusable government portal template for labor dispute and case management systems, featuring secure login, dashboards, workflows, reporting, and role-based access.

- **Slug:** `government-case-6`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

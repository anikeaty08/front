# Government e-Service Portal Landing Page Template

A modern government e-service portal landing page template for municipalities to showcase online payments, parking compounds, facility bookings, and citizen services.

## Project Details
- **Slug:** `government-e-35`
- **Views:** 53
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Large Type, Gradient, Government portal template, Citizen services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

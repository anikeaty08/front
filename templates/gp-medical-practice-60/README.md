# GP Medical Centre Website Template

A clean, NHS-style GP medical centre website template to showcase services, news, and patient resources with online appointments and prescriptions.

## Project Details
- **Slug:** `gp-medical-practice-60`
- **Views:** 27
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Technology, Medical, Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Gradient UI Buttons Component Template

A reusable gradient button UI template featuring modern pill-shaped call-to-action buttons you can drop into any landing page or app interface.

- **Slug:** `gradient-ui-buttons-65`
- **Views:** 17

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

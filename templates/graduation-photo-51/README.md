# AI Graduation Photo Landing Page Template

A reusable Arabic landing page template for universities and event teams to help graduates find, preview, and purchase ceremony photos with AI face search.

## Project Details
- **Slug:** `graduation-photo-51`
- **Views:** 106
- **Tags:** Landing Page, Education, Technology, Clean, Gradient, Minimal, AI, Photo Gallery, Arabic, Face Recognition
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

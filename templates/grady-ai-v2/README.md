# AI Grading SaaS Landing Page Template

A modern, professor-focused SaaS landing page template for an AI grading assistant, ideal for showcasing rubric-based workflows, analytics, security, and demos.

## Project Details
- **Slug:** `grady-ai-v2`
- **Views:** 16
- **Tags:** Landing Page, Education, Technology, Brand, Clean, Minimal, Large Type, Gradient

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

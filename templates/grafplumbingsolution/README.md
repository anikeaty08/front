# Plumbing Services Landing Page Template

A modern dark-themed plumbing services landing page template for local residential and commercial plumbers, featuring emergency callouts and service request forms.

## Project Details
- **Slug:** `grafplumbingsolution`
- **Views:** 50
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Minimal, Large Type, Technology, Plumbing, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

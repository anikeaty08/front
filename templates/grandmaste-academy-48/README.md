# Chess Academy Landing Page Template

A reusable landing page template designed for chess academies featuring programs, achievements, testimonials, and demo booking to attract parents and students.

- **Views:** 22

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Grange Road Dental

A modern dental practice website template for clinics to showcase treatments, plans, and online booking, ready to customize for your own practice.

## Project Details
- **Slug:** `grangeroad`
- **Views:** 21
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

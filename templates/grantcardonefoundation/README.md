# Non-profit Financial Education Landing Page Template

A reusable landing page template for non-profit financial education programs, ideal for foundations reaching underserved youth, schools, and community partners.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

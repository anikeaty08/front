# Graphic Design Studio Landing Page Template

A reusable landing page template for graphic design studios and branding services, built to showcase portfolios, services, testimonials, and contact CTAs.

## Project Details
- **Slug:** `graphic-design-31`
- **Views:** 17
- **Tags:** Landing Page, Services, Brand, Graphic Design, Portfolio, Dark, Gradient, Futuristic, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

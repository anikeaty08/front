# Serverless Infrastructure Features Page Template

A dark, futuristic features page template for a serverless infrastructure or edge compute platform, ready to customize for your own technology brand.

## Project Details
- **Slug:** `graviton`
- **Views:** 16
- **Tags:** Landing Page, Technology, Brand, Futuristic, Dark, Clean, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

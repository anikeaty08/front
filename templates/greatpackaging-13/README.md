# Packaging Corporation Landing Page Template

A modern, corporate packaging company landing page template for showcasing divisions, services, certifications, and global offices to attract B2B brand partners.

- **Slug:** `greatpackaging-13`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

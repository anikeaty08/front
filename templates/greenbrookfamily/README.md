# Dental Clinic Landing Page Template

A modern dental clinic landing page template for family and sedation practices, featuring services, hours, contact info, and an appointment request form.

## Project Details
- **Slug:** `greenbrookfamily`
- **Views:** 473
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Gradient, Large Type, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

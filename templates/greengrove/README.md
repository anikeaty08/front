# GreenGrove Garden Store Landing Page Template

Reusable landing page template for garden stores offering plants, tools, expert advice, and same-day delivery to help users grow their dream garden.

## Project Details
- **Slug:** `greengrove`
- **Views:** 974

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

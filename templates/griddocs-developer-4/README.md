# GridDocs Software Documentation Template

A clean, minimalist documentation template featuring a 3D-animated sidebar, responsive layouts, and data table configurations for technical products.

## Project Details
- **Slug:** `griddocs-developer-4`
- **Views:** 20
- **Tags:** Documentation, Technology, Clean, Minimal, Animated, Grid
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

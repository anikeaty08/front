# Futuristic Hero Landing Page Template

A dark, holographic hero section template for bold, futuristic landing pages that you can reuse to showcase brands, events, or digital experiences.

## Project Details
- **Slug:** `griddy`
- **Views:** 13
- **Tags:** Landing Page, Brand, Technology, Futuristic, Dark, Gradient, Large Type, Minimal, Animated, Art & Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

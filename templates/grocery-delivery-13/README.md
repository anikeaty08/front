# Modern Bakery Ordering Landing Page Template

A clean, modern bakery ordering UI template for showcasing menus, promos, and online orders for cafes and bakeries.

## Project Details
- **Slug:** `grocery-delivery-13`
- **Views:** 4
- **Tags:** Landing Page, Food, E-commerce, Brand, Clean, Minimal, Colorful, Large Type, Bakery, Cafe
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

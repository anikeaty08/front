# Grocery E-commerce Landing Page Template

A reusable grocery delivery template for online food stores, featuring product discovery, special offers, testimonials, app promo, and newsletter capture.

## Project Details
- **Slug:** `grocery-delivery-52`
- **Views:** 38

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

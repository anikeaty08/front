# Grocery E-commerce Landing Page Template

A modern grocery e-commerce landing page template for showcasing fresh food categories, filters, and products with a clean, conversion-focused layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

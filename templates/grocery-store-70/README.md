# Grocery Store E-commerce UI Template

A reusable grocery store e-commerce UI template featuring promotions, product grids, loyalty banners, store locator, and article sections for modern food retailers.

## Project Details
- **Slug:** `grocery-store-70`
- **Views:** 37
- **Tags:** E-commerce, Food, Landing Page, Brand, Clean, Colorful, Grid, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

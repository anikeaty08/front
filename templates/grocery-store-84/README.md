# Grocery Store Landing Page Template

A clean, modern grocery store landing page template for showcasing local supermarket hours, location, reviews, and contact details.

## Project Details
- **Slug:** `grocery-store-84`
- **Views:** 92
- **Tags:** Landing Page, Business, Services, Clean, Minimal, Brand, E-commerce, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

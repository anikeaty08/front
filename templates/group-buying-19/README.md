# Group Buy Onboarding App Template

A mobile onboarding template for group buying apps that helps users understand how to split shipping costs, save money, and join shared purchases.

## Project Details
- **Slug:** `group-buying-19`
- **Views:** 33
- **Tags:** Landing Page, Technology, Clean, Gradient, Minimal, 3D, Mobile App, Onboarding, E-commerce
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

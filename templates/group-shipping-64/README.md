# Logistics Mobile App Template

A reusable mobile app template for creating group shipping flows, helping communities organize routes, set cargo goals, and invite members easily.

## Project Details
- **Slug:** `group-shipping-64`
- **Views:** 34
- **Tags:** Landing Page, Technology, Services, Clean, Gradient, Minimal, Mobile App, Logistics, Shipping
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Group Shopping Mobile App Template

A reusable mobile-first template for social group checkout, inviting friends, tracking shipping goals, and collecting individual payments with a polished UI.

## Project Details
- **Slug:** `group-shopping-66`
- **Views:** 22
- **Tags:** E-commerce, Landing Page, Technology, 3D, Gradient, Clean, Mobile UI, Social Commerce, Checkout
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Group Shopping Mobile Checkout Template

A reusable mobile e-commerce template for group buying, shared carts, and split-payment checkout flows that help shoppers unlock shipping discounts together.

## Project Details
- **Slug:** `group-shopping-70`
- **Views:** 26
- **Tags:** E-commerce, Landing Page, Technology, Clean, Gradient, Minimal, mobile app, group buying, checkout
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

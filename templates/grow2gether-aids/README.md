# DSA Group Tracker Web App Template

A reusable dark-mode DSA group tracker web app template with dashboard, roadmap, and group chat views to manage study progress collaboratively.

## Project Details
- **Slug:** `grow2gether-aids`
- **Views:** 17
- **Tags:** Landing Page, Technology, Brand, Dark, Clean, Minimal, Dashboard, Web App, Study Group
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

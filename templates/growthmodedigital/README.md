# B2B Cold Email 

A high-converting performance-based cold email landing page template designed for B2B agencies and service providers who want to showcase qualified call booking results.

## Project Details
- **Slug:** `growthmodedigital`
- **Views:** 128
- **Tags:** Landing Page, Technology, Services, Dark, Clean, Animated
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

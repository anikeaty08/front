# Music Studio Landing Page Template

A dark, modern landing page template for music studios and training academies to promote lessons, studio services, pricing, and special offers.

- **Views:** 48

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

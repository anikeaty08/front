# Gardening Services Landing Page Template

A reusable landing page template for local gardening and landscaping services, designed to showcase offerings, service areas, testimonials, and quote requests.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

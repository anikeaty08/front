# Brand Assets Display Card Template

Minimal brand assets display card template for showcasing logo, isotype, wordmark, and SVG download in a clean identity presentation layout.

## Project Details
- **Slug:** `guardalobonitov10`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

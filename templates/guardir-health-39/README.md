# GuardIR Health App Landing Page Template

A sleek, dark-mode landing page template for GuardIR-style metabolic health apps, ideal for promoting waitlists, features, and guardian systems.

## Project Details
- **Slug:** `guardir-health-39`
- **Views:** 14
- **Tags:** Landing Page, Health, Technology, Brand, Dark, Gradient, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

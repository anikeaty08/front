# Guesthouse Landing Page Template

A reusable guesthouse landing page template for showcasing rooms, amenities, location, reviews, and contact details for small hotels and family-run pensions.

## Project Details
- **Slug:** `guesthouse-landing-67`
- **Views:** 38
- **Tags:** Landing Page, Travel, Services, Brand, Clean, Minimal, Large Type, Gradient, Guesthouse, Hotel
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

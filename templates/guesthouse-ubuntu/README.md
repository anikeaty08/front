# Ubuntu Guesthouse Landing Page Template

A refined guesthouse landing page template for boutique stays, crafted to showcase rooms, experiences, and bookings for hospitality brands.

## Project Details
- **Slug:** `guesthouse-ubuntu`
- **Views:** 343
- **Tags:** Landing Page, Travel, Services, Brand, Clean, Minimal, Large Type, Colorful, Boutique Hotel, Guesthouse

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

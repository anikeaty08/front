# Guitar Teacher Landing Page Template

A warm, conversion-focused landing page template for independent guitar teachers to promote lessons, pricing, testimonials and contact bookings.

## Project Details
- **Slug:** `guitar-teacher-52`
- **Views:** 70
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Education, guitar teacher, course booking, local business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Gym Maintenance Dashboard Template

A reusable dashboard template for gyms and fitness facilities to manage maintenance schedules, daily checklists, team attendance, and reporting.

## Project Details
- **Slug:** `gym-maintenanc-50`
- **Views:** 30
- **Tags:** Landing Page, Services, Health, Clean, Minimal, Dashboard, Admin, Calendar, Checklist
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

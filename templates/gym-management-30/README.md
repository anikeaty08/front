# Gym Management Dashboard Template

A reusable gym management dashboard template for tracking members, attendance, renewals, revenue, and day-to-day fitness club operations.

## Project Details
- **Slug:** `gym-management-30`
- **Views:** 48
- **Tags:** Health, Technology, Dashboard, Services, Dark, Clean, Minimal, Admin, Analytics
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

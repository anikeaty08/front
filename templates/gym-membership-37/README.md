# Gym Membership Landing Page Template

A modern gym membership landing page template for fitness clubs to showcase pricing, memberships, and class offers with a bold hero and conversion-focused form.

## Project Details
- **Slug:** `gym-membership-37`
- **Views:** 4
- **Tags:** Landing Page, Health, Services, Brand, Clean, Gradient, Large Type, Minimal, Gym, Fitness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

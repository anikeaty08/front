# Gym & Rehabilitation Landing Page Template

A premium landing page template for gyms, physiotherapy clinics, and fitness centers to showcase services, memberships, facilities, and booking options.

- **Slug:** `gym-rehabilita-27`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Fitness App Landing Page Template

A dark, modern landing page template for a social fitness app that helps users find gym partners and showcase app features and calls-to-action.

## Project Details
- **Slug:** `gymbro-fitness-40`
- **Views:** 7
- **Tags:** Landing Page, Health, Technology, Brand, Dark, Gradient, Large Type, Minimal, App, Fitness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

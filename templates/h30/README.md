# Merchant Banking Landing Page Template

A dark, modern merchant banking landing page template for boutique advisory and private equity firms to showcase services, team, and market insights.

## Project Details
- **Slug:** `h30`
- **Views:** 8
- **Tags:** Landing Page, Business, Services, Brand, Dark, Minimal, Large Type, Clean, Technology, Financial
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

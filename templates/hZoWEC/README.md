# Smart Home Control Interface

Responsive UI displaying home status, energy usage, and quick controls for lights, thermostat, and security system.

## Project Details
- **Slug:** `hZoWEC`
- **Views:** 403
- **Tags:** HTML, Tailwind CSS, Animation, Smart Home, UI Design, Responsive
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

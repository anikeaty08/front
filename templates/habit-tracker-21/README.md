# Habit Tracker Dashboard UI Template

A reusable dark-mode habit tracker dashboard UI template for productivity and health apps, featuring stats, streaks, calendar heatmap, and daily insights.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

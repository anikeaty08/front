# Habit Tracking Mobile UI Template

A dark, glassmorphism mobile app UI template for habit tracking, goal setting, and social challenges—ready to reuse for your fitness and productivity app.

## Project Details
- **Slug:** `habit-tracking-20`
- **Views:** 4
- **Tags:** Technology, Brand, Clean, Dark, Gradient, Minimal, Large Type, Mobile App, Habit Tracker, Glassmorphism
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

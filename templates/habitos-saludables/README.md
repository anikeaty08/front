# Health Podcast Landing Page Template

A modern, editorial-style health podcast landing page template for showcasing episodes, hosts, and email newsletter signups with bold, sketchy visuals.

## Project Details
- **Slug:** `habitos-saludables`
- **Views:** 54
- **Tags:** Landing Page, Health, Brand, Entertainment, Art & Design, Clean, Colorful, Illustrative, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

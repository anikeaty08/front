# Hair Restoration Clinic Website Template

A reusable clinic website template for hair restoration and scalp treatment brands, designed to showcase services, programs, expertise, and consultation booking.

## Project Details
- **Slug:** `hair-restoratio-39`
- **Views:** 95

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

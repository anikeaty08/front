# Hair Salon Booking Landing Page Template

A reusable landing page template for hair salons and barbershops to showcase services, build trust, and accept online appointment requests.

## Project Details
- **Slug:** `hair-salon-booking-38`
- **Views:** 131
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Fashion, booking form, hair salon, appointment
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

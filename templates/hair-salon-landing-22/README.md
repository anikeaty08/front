# Hair Studio Landing Page Template

A modern, salon-ready landing page template for hair studios and stylists to showcase services, portfolio, reviews, and online booking in a refined layout.

## Project Details
- **Slug:** `hair-salon-landing-22`
- **Views:** 56
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Beauty, Hair Salon, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Hair Salon Landing Page Template

A reusable hair salon landing page template for promoting services, showcasing inspiration, displaying reviews, and driving online bookings.

## Project Details
- **Slug:** `hair-salon-landing-23`
- **Views:** 60
- **Tags:** Landing Page, Services, Fashion, Clean, Minimal, Brand, salon, hairdresser, beauty, booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

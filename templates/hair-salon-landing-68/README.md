# Hair Salon Landing Page Template

Elegant hair salon website template for showcasing services, team, promos, and contact details for local ateliers and beauty studios.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

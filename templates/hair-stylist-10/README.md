# Hair Stylist Hero Landing Page Template

A modern hair styling hero section template for salons and stylists, ready to customize for event and occasion bookings as a reusable website layout.

## Project Details
- **Slug:** `hair-stylist-10`
- **Views:** 38
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Hair styling, Beauty salon
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

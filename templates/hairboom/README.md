# Hair & Nail Salon Landing Page Template

Elegant landing page template for hair and nail salons to showcase services, pricing, team, testimonials, and contact details in a refined, boutique style.

## Project Details
- **Slug:** `hairboom`
- **Views:** 38
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Portfolio, Beauty Salon, Hair Studio, Nail Studio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

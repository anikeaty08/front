# Hair Salon Landing Page Template

Elegant hair salon website template for showcasing services, team profiles, and online booking, ready to customize for any beauty studio or local salon.

## Project Details
- **Slug:** `hairbymartina`
- **Views:** 10
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Beauty, Hair Salon
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Modern Salon

A modern salon & wellness landing page template for hair, beauty, and spa studios to showcase services, specialists, and drive online bookings.

## Project Details
- **Slug:** `haircaresalon777`
- **Views:** 23
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Beauty, Salon, Wellness

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

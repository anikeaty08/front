# Halal Dairy E-commerce Landing Page Template

A modern Aura Dairy-inspired landing page template for halal milk and beverage distributors to showcase products, testimonials, and drive WhatsApp orders online.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

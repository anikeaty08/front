# Halal Funeral Insurance Landing Page Template

A modern landing page template for halal, in‑kind Islamic funeral insurance providers to capture signups, explain principles, and build trust online.

## Project Details
- **Slug:** `halal-funeral-5`
- **Views:** 6
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Technology, Gradient, Social
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

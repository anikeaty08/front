# Halal Marketplace Platform Website Template

A modern halal lifestyle marketplace website template for listing Muslim-owned businesses, exclusive deals, community classifieds, and a merchant dashboard.

## Project Details
- **Slug:** `halal-marketplac-38`
- **Views:** 12
- **Tags:** E-commerce, Services, Community, Brand, Dark, Clean, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

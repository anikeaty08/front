# Halal Meat E-commerce Landing Page Template

A modern HalalCuts-style e-commerce landing page template for selling premium halal meat online with product grid, cart slide-over, and newsletter signup.

## Project Details
- **Slug:** `halal-meat-e-33`
- **Views:** 90

- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

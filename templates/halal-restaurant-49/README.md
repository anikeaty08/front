# Halal Restaurant Finder App UI Template

Mobile-first UI template for a halal restaurant and shop finder app, ideal for building location-based halal food discovery and ordering experiences.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

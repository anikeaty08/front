# Dental Practice Landing Page Template

A modern dental practice landing page template for cosmetic and general dentists, ready to customize for local clinics and appointment requests.

- **Slug:** `halperdentistry`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

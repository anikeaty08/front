# Handyman Services Landing Page Template

A reusable landing page template for local handyman and home repair businesses to showcase services, build trust, and capture quote requests.

## Project Details
- **Slug:** `handyman-services-46`
- **Views:** 45
- **Tags:** Landing Page, Services, Technology, Dark, Clean, Minimal, Local business, Handyman, Home repair
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

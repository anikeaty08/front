# Filosofía de Vida Landing Page Template

Minimalist Spanish landing page template to present a 7-step happiness framework, ideal for personal development, mindset, or wellness philosophy content.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

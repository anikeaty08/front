# Sweet 21

A beautiful, sentimental storytelling template designed for birthdays, anniversaries, and personal milestones with timeline and audio features.

## Project Details

- **Views:** 36

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

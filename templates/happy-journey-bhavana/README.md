# Dubai Farewell Journey Landing Page Template

A pastel, interactive farewell journey landing page template with map animation, playful reveals, and personalized wishes for travelers heading to Dubai.

## Project Details
- **Slug:** `happy-journey-bhavana`
- **Views:** 31
- **Tags:** Landing Page, Travel, Brand, Clean, Colorful, Gradient, Animated, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

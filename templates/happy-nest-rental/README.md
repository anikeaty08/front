# Plush Rental Landing Page Template

A reusable landing page template for plush toy rental businesses, featuring location-based catalogs, booking flows, FAQs, and an admin dashboard.

## Project Details
- **Slug:** `happy-nest-rental`
- **Views:** 13
- **Tags:** Landing Page, Services, Brand, Colorful, Clean, Minimal, Large Type, Technology, E-commerce
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

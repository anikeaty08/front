# Hardware Distributor E-commerce Template

A reusable e-commerce template for hardware distributors and B2B suppliers to showcase products, pricing, categories, and wholesale ordering workflows.

## Project Details
- **Slug:** `hardware-distributo-42`
- **Views:** 26
- **Tags:** E-commerce, Services, Business, Landing Page, Clean, Minimal, Dark, B2B, wholesale, hardware
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

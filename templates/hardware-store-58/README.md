# Metal Hardware Store Landing Page Template

A modern dark-themed landing page template for a local metal hardware store offering screws, fasteners, tools, and contact details for quick orders.

## Project Details
- **Slug:** `hardware-store-58`
- **Views:** 28
- **Tags:** Landing Page, Services, Brand, Dark, Clean, Grid, Large Type, Portfolio, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

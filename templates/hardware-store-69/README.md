# Metal Hardware Store Landing Page Template

A modern, dark-themed landing page template for local metal and fastening stores to showcase assortment, location, reviews, and contact details.

## Project Details
- **Slug:** `hardware-store-69`
- **Views:** 64
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Gradient, Large Type, Technology, Local Business, Hardware Store
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

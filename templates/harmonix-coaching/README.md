# Personal Coaching Brand Landing Page Template

A modern personal coaching brand landing page template for coaches to showcase services, books, testimonials, and capture calls, leads, and newsletter signups.

## Project Details
- **Slug:** `harmonix-coaching`
- **Views:** 37
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Health, Coaching, Personal Brand, Newsletter
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

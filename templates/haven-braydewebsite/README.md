# Real Estate Investor Dashboard Template

A refined real estate investor dashboard template for tracking portfolio value, properties, tasks, and activity in a clean, modern web app layout.

## Project Details
- **Slug:** `haven-braydewebsite`
- **Views:** 45

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

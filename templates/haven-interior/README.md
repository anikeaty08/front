# Haven Interior Design Studio Template

A sophisticated, high-end interior design and architectural studio template featuring smooth GSAP animations and immersive horizontal scrolling.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

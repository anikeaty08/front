# Mehendi Artist Landing Page Template

Elegant single-page template for premium mehendi and henna artist services, perfect for showcasing portfolios, services, and bookings for weddings and events.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# HealNet Medical Landing Page Template

A modern HealNet medical landing page template for digital healthcare platforms to showcase online consultations, services, doctors, and patient testimonials.

## Project Details
- **Slug:** `healnet-medical-10`
- **Views:** 11
- **Tags:** Health, Landing Page, Services, Technology, Brand, Clean, Gradient, Minimal, Medical, Telehealth
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

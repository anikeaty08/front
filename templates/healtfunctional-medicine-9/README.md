# Functional Medicine Quiz Landing Page Template

A reusable landing page template for functional medicine clinics to promote a free health quiz, build trust, and convert symptom-aware patients into leads.

## Project Details
- **Slug:** `healtfunctional-medicine-9`
- **Views:** 65
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, quiz funnel, testimonials, medical lead generation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Health Assessment Cards UI Template

Reusable UI template for a health assessment landing page with interactive wellness test cards to help users track and understand their well-being.

## Project Details
- **Slug:** `health-assessment-24`
- **Views:** 27
- **Tags:** Health, Landing Page, Brand, Clean, Gradient, Minimal, Large Type, Wellness, Questionnaire

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

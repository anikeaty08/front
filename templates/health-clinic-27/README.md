# Chiropractic Clinic Website Template

A modern, drug-free pain relief clinic website template for chiropractors and multidisciplinary health practices to showcase treatments, conditions, and bookings.

## Project Details
- **Slug:** `health-clinic-27`
- **Views:** 20
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Clinic, Medical, Chiropractic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

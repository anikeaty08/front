# Health Clinic Landing Page Template

A reusable landing page template for functional medicine clinics and wellness practices to showcase expertise, patient results, and book discovery calls.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

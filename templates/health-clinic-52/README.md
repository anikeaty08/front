# Health Clinic Landing Page Template

A conversion-focused template for health clinics, chiropractic practices, and functional medicine providers to promote consultations and build trust.

## Project Details
- **Slug:** `health-clinic-52`
- **Views:** 24
- **Tags:** Landing Page, Health, Services, Dark, Clean, testimonials, chiropractic, functional medicine, medical clinic

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

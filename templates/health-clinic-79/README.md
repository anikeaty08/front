# Health Clinic Landing Page Template

A clean, modern landing page template for pain relief or chiropractic clinics to showcase treatments, patient stories, and online appointment bookings.

## Project Details
- **Slug:** `health-clinic-79`
- **Views:** 15
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Brand, Large Type, Medical, Chiropractic, Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Health Consultation Landing Page Template

A reusable health and wellness landing page template for chiropractors, functional medicine clinics, and nutrition practices to drive consultation bookings.

- **Slug:** `health-consultati-27`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

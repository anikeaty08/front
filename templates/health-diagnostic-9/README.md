# Health Diagnostic Dashboard Template

A reusable healthcare dashboard template for diagnostic labs and patient portals to book tests, track orders, manage reports, and explore packages.

## Project Details
- **Slug:** `health-diagnostic-9`
- **Views:** 46

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

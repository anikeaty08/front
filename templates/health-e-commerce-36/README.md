# Health E-commerce Landing Page Template

Premium Brazilian supplements e-commerce template showcasing best-sellers, kits, promos, and newsletter signup for health and beauty brands.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

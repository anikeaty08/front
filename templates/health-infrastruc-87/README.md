# Health Technology Landing Page Template

A reusable landing page template for health technology platforms that need to showcase secure data vaults, wallet access, QR sharing, and patient coordination.

## Project Details
- **Slug:** `health-infrastruc-87`
- **Views:** 48
- **Tags:** Health, Technology, Landing Page, Clean, Minimal, Brand, wallet integration, QR sharing, patient data, secure vault
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

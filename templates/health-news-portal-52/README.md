# Health News Portal Landing Page Template

A reusable landing page template for a Malayalam-first health news portal with sponsored stories, category navigation, and ad placements.

## Project Details
- **Slug:** `health-news-portal-52`
- **Views:** 27
- **Tags:** Health, Landing Page, Brand, Dark, Clean, Large Type, News Portal, Malayalam
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

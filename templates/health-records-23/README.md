# Health Records Mobile App UI Template

A clean, mobile-first HealthNest app UI template for managing health records, medicines, visits, and emergency info in one secure interface.

## Project Details
- **Slug:** `health-records-23`
- **Views:** 28
- **Tags:** Health, Technology, Landing Page, Brand, Clean, Minimal, Mobile app, Medical records, Patient portal, Emergency info
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# B2B Recovery Services Landing Page Template

A reusable landing page template for on-site B2B recovery and workplace wellness services, designed to capture callback requests and explain interventions clearly.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

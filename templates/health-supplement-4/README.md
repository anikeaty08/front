# Health Supplement Landing Page Template

A premium landing page template for wellness and supplement brands to showcase metabolic support products, ingredients, reviews, and subscription pricing.

- **Slug:** `health-supplement-4`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

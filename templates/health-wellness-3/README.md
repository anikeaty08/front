# Health & Wellness Clinic Landing Page Template

A clean, modern landing page template for health, wellness, and acupuncture clinics to showcase treatments, services, and pricing.

## Project Details
- **Slug:** `health-wellness-3`
- **Views:** 9
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, Clinic, Wellness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

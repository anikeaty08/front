# PHHW Health & Wellness Footer Template

A reusable footer template for health and wellness websites featuring contact info, certifications, social links, app badges, and legal navigation.

## Project Details
- **Slug:** `health-wellness-90`
- **Views:** 29
- **Tags:** Health, Landing Page, Brand, Clean, Dark, Minimal, Services, Footer, Wellness, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

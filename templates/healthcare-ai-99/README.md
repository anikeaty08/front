# Healthcare AI SaaS Landing Page Template

A reusable landing page template designed to showcase an AI WhatsApp assistant for medical clinics, featuring modern dark UI, features, testimonials, and CTAs.

## Project Details
- **Slug:** `healthcare-ai-99`
- **Views:** 19
- **Tags:** Landing Page, Health, Services, Technology, Brand, Clean, Dark, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Healthcare App Landing Page Template

A reusable healthcare app landing page template for digital pharmacies, e-prescriptions, medication delivery, and patient-provider platform launches.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

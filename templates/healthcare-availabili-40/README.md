# Hospital Doctor Availability Dashboard Template

A reusable DocStatus-inspired template for real-time hospital doctor availability, with patient view, doctor panel, and reception admin dashboard in one layout.

## Project Details
- **Slug:** `healthcare-availabili-40`
- **Views:** 13
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Brand, Dashboard, Hospital, Medical, Real-time
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

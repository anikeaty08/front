# Healthcare BPO Landing Page Template

A reusable landing page template for healthcare outsourcing firms to showcase compliance, services, security, and consultation-driven lead generation.

## Project Details
- **Slug:** `healthcare-bpo-99`
- **Views:** 14
- **Tags:** Health, Services, Landing Page, Technology, Dark, Clean, Grid, Minimal, BPO, Healthcare

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Healthcare Care Coordination Landing Page Template

A reusable landing page template for patient-first healthcare care coordination services, designed to explain support, build trust, and guide patients and providers.

## Project Details
- **Slug:** `healthcare-care-48`
- **Views:** 14

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

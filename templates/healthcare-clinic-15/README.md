# Medical Center Landing Page Template

A modern, patient-focused medical center landing page template for healthcare clinics and hospitals to showcase services, doctors, and online appointment booking.

## Project Details
- **Slug:** `healthcare-clinic-15`
- **Views:** 29
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, Medical, Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

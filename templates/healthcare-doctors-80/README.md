# Healthcare Landing Page Template

A modern healthcare website template for clinics, hospitals, and digital health platforms to showcase services, patient portals, telehealth, and appointment booking.

## Project Details
- **Slug:** `healthcare-doctors-80`
- **Views:** 67

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

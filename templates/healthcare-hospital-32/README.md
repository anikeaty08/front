# Hospital Landing Page Template

A modern JDGH Samdari-inspired hospital landing page template for clinics and healthcare centers to showcase services, specialties, and 24x7 emergency care.

## Project Details
- **Slug:** `healthcare-hospital-32`
- **Views:** 26
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Gradient, Large Type, Hospital, Clinic

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Modern Healthcare Landing Page Template

A modern healthcare landing page template for clinics and wellness brands to showcase services, specialists, and consultations with a clean, premium design.

## Project Details
- **Slug:** `healthcare-landing-32`
- **Views:** 25
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Gradient, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Healthcare Landing Page Template

A reusable healthcare landing page template for clinics and medical practices to showcase services, telehealth, patient care, and appointment booking.

## Project Details
- **Slug:** `healthcare-landing-42`
- **Views:** 943
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Dark, Medical, Clinic, Telehealth
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

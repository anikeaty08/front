# Healthcare Landing Page Template

A reusable healthcare landing page template for concierge, functional, or membership-based clinics to showcase trust, care benefits, and drive quiz-based leads.

- **Slug:** `healthcare-longlife-29`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

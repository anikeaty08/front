# Healthcare Patient Registration Form Template

A reusable healthcare form template for collecting patient registration, contact, and emergency details in clinics, hospitals, and medical systems.

## Project Details
- **Slug:** `healthcare-patient-2`
- **Views:** 35
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Dashboard, Form, Patient Intake, Medical Admin
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Healthcare Podcast Landing Page Template

A reusable landing page template for a healthcare podcast, featuring episodes, host story, and newsletter to grow an audience around global medical tourism.

## Project Details
- **Slug:** `healthcare-podcast-46`
- **Views:** 31
- **Tags:** Landing Page, Health, Brand, Clean, Minimal, Large Type, Podcast, Medical Tourism, Newsletter
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

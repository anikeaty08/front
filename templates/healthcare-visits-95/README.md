# Healthcare Visits Kanban Dashboard Template

A clean, Tailwind-based Kanban dashboard template for managing healthcare visits, bookings, and waitlists that you can customize for your own app.

## Project Details
- **Slug:** `healthcare-visits-95`
- **Views:** 12
- **Tags:** Health, Technology, Landing Page, Brand, Clean, Minimal, Large Type, Dashboard, Kanban, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

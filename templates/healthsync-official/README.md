# HealthSync Healthcare Web App Template

A modern HealthSync healthcare web app template with landing page, patient dashboard, doctor search, profiles, and appointments for digital health platforms.

## Project Details
- **Slug:** `healthsync-official`
- **Views:** 21
- **Tags:** Health, Landing Page, Technology, Brand, Clean, Minimal, Gradient, Large Type, Dashboard, Healthcare
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Healthy Snack Landing Page Template

A reusable landing page template for promoting low-sugar, health-focused snack products with brand storytelling, benefits, packages, testimonials, and preorder CTAs.

## Project Details
- **Slug:** `healthy-snack-4`
- **Views:** 49
- **Tags:** Landing Page, Food, Health, Brand, Clean, Minimal, Product Launch, Preorder, Wellness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

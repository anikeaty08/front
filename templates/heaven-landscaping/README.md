# Landscaping Heaven

A reusable landing page template for landscaping companies to showcase services, process, testimonials, and drive quote requests from homeowners.

## Project Details
- **Slug:** `heaven-landscaping`
- **Views:** 38
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Nature, Landscaping, Home Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

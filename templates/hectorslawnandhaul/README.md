# Hector's Lawn & Haul

A ready-made landing page template for local lawn care and junk removal services, featuring bold branding, service highlights, testimonials, and lead capture.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Developer Interface Landing Page Template

A minimal developer-focused interface landing page template for showcasing a platform status, features, and deployment-ready environment.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

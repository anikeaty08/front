# HEMA Club Portal Template

A reusable dark-themed template for HEMA clubs and martial arts communities to share events, documents, training videos, gear resources, and member content.

- **Slug:** `hema-club-portal-93`
- **Views:** 74

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

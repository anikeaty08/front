# Her Alpha Podcast Landing Page Template

A dark, minimal podcast landing page template for Her Alpha-style shows focused on investing, technology, AI tools, and female empowerment.

## Project Details
- **Slug:** `her-alpha-podcast-5`
- **Views:** 18
- **Tags:** Landing Page, Brand, Clean, Dark, Minimal, Technology, Podcast, Investing, AI, Community
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

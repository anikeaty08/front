# Nova Medical Health Clinic Template

A high-converting VSL landing page template designed for medical clinics, plastic surgeons, and specialized health services featuring video sections and social proof.

## Project Details
- **Slug:** `here-are-your-43`
- **Views:** 18
- **Tags:** Health, Landing Page, Dark, Clean, Services, Animated
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

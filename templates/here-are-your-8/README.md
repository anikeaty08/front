# Medical VSL Landing Page Template

A high-converting medical and health-services landing page template featuring a video sales letter (VSL) layout and social proof sections.

## Project Details
- **Slug:** `here-are-your-8`
- **Views:** 21
- **Tags:** Health, Services, Dark, Clean, Minimal, Landing Page, Animated
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

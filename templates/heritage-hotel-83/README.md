# Heritage Hotel Landing Page Template

A refined heritage hotel landing page template for boutique properties to showcase rooms, amenities, offers, and direct booking in a single elegant layout.

## Project Details
- **Slug:** `heritage-hotel-83`
- **Views:** 48
- **Tags:** Landing Page, Travel, Services, Brand, Clean, Minimal, Large Type, Gradient, Hotel, Hospitality
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Heritage Hotel Landing Page Template

A refined heritage hotel website template for boutique stays, featuring rooms, amenities, offers, reviews, booking form, and guest dashboard UI.

## Project Details
- **Slug:** `heritage-hotel-88`
- **Views:** 25
- **Tags:** Landing Page, Travel, Services, Brand, Minimal, Clean, Large Type, Gradient, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

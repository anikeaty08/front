# Day Trading Mentor Landing Page Template

A dark, modern landing page template for trading mentors to promote courses, mentorship, and a free Discord-style community for serious intraday traders.

## Project Details
- **Slug:** `hermantradesbtc`
- **Views:** 33
- **Tags:** Landing Page, Services, Technology, Dark, Clean, Minimal, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Women’s Wellness Community App Template

A reusable mobile app and dashboard template for women’s wellness communities, featuring social feed, cycle tracking, meditation, subscriptions, and admin analytics.

## Project Details
- **Slug:** `herspacesocialmedia`
- **Views:** 40
- **Tags:** Health, Social, Membership, Technology, Landing Page, Clean, Minimal, Dashboard, Wellness, Mobile App
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

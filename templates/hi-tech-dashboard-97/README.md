# Hi-Tech Dashboard Interface Template

A reusable hi-tech dashboard interface template for selecting, configuring, and previewing SaaS, landing page, mobile app, and gallery UI layouts.

- **Views:** 63

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

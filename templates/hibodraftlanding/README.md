# Hibo Energy Drink Landing Page Template

High-converting landing page template for an energy drink or wellness beverage brand, featuring newsletter signup, product highlight, and promotional offers.

- **Slug:** `hibodraftlanding`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

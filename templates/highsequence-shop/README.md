# HIGH SEQUENCE - THE BALACLAVAS

A bold reusable landing page template for custom balaclava, streetwear, or made-to-order fashion brands to showcase products and capture orders.

## Project Details
- **Slug:** `highsequence-shop`
- **Views:** 49
- **Tags:** Landing Page, Fashion, Brand, Dark, Brutal, Large Type, Minimal, Streetwear, Custom Order
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

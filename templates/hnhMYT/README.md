# Sidebar Navigation Menu UI

Responsive sidebar navigation with full and minimized views, menu items, status indicators, and user profile section using Tailwind CSS.

- **Slug:** `hnhMYT`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

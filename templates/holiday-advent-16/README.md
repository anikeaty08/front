# Holiday Advent Calendar App UI Template

A festive mobile advent calendar app UI template for beauty, retail, or holiday campaigns, ready to customize daily surprises, offers, and rewards.

## Project Details
- **Slug:** `holiday-advent-16`
- **Views:** 30

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Somatic Therapy Landing Page Template

A minimalist somatic therapy landing page template for bodywork practitioners to showcase their philosophy, services, and 1:1 sessions with a clear booking CTA.

- **Slug:** `holistic-bodywork-98`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

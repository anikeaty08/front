# Holistic Health & Wellness VSL Template

A professional medical landing page template designed for functional medicine clinics and wellness groups to convert patients through video sales letters.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

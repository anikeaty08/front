# Holistic Massage Practitioner Landing Page Template

A warm, minimal landing page template for holistic massage practitioners and In Touch-style bodywork workshops to showcase services and drive bookings.

## Project Details
- **Slug:** `holistic-massage-17`
- **Views:** 4
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Gradient, Large Type, Portfolio

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

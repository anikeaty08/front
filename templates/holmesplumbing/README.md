# Plumbing Services Landing Page Template

A clean local-services template for plumbing businesses to showcase repairs, reviews, FAQs, location, and drive phone-call bookings fast.

## Project Details
- **Slug:** `holmesplumbing`
- **Views:** 47
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Local Business, Plumbing, Home Services, Reviews
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

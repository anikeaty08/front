# Holter Delivery App Landing Page Template

A modern Holter delivery app landing page template for local food delivery services, ready to customize for your own city-focused delivery startup.

## Project Details
- **Slug:** `holter-delivery`
- **Views:** 36
- **Tags:** Landing Page, Food, Services, Brand, Clean, Colorful, Minimal, Large Type, Delivery App, Mobile

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Home Exterior Services Landing Page Template

A reusable landing page template for exterior remodeling companies to showcase doors, windows, siding, roofing, service areas, projects, and FAQs.

## Project Details
- **Slug:** `home-exterior-68`
- **Views:** 54
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Portfolio, Local SEO, Home Improvement, Remodeling
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

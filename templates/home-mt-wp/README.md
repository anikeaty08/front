# Compliance Training Landing Page Template

A reusable landing page template for safety, compliance, and workforce training providers to showcase courses, expertise, testimonials, and contact options.

## Project Details
- **Slug:** `home-mt-wp`
- **Views:** 82
- **Tags:** Landing Page, Services, Education, Technology, Clean, Dark, Minimal, Brand, compliance training, workforce training
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Home Services 

A modern, conversion-focused home services landing page template for handyman, plumbing, electrical, and smart home businesses to showcase and book services.

## Project Details
- **Slug:** `home-services-2`
- **Views:** 30
- **Tags:** Landing Page, Services, Business, Clean, Gradient, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Home Services App Landing Page Template

A clean, mobile-first landing page template for promoting a home services booking app, optimized to showcase features, pros, and app download CTAs.

## Project Details
- **Slug:** `home-services-26`
- **Views:** 40
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Colorful, Minimal, Large Type, Home services, Mobile app

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Foreclosure Defense Landing Page Template

A high-converting foreclosure defense landing page template for legal service providers and document assistants helping homeowners stop foreclosure and keep their homes.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

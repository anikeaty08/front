# Frozen Food Ordering Landing Page Template

A reusable landing page template for homemade frozen food brands to showcase menus, collect orders, share payment details, and drive WhatsApp inquiries.

## Project Details
- **Slug:** `homemadefrozenfood`
- **Views:** 44
- **Tags:** Food, E-commerce, Landing Page, Clean, Minimal, Services, WhatsApp ordering, menu showcase
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

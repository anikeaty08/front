# Social Skills Gamification Dashboard Template

This reusable landing page template provides a sleek, gamified dashboard for tracking social skills progress and engagement.

## Project Details
- **Slug:** `homepageforthis`
- **Views:** 10
- **Tags:** Landing Page, Gamification, Dashboard, Metrics, User Profile, Progress Tracking, Interactive, Mobile UI, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Homestay Booking Lookup Landing Page Template

A modern homestay booking lookup landing page template for hotels and rentals to let guests securely check reservations by phone number online.

## Project Details
- **Slug:** `homestay-booking-34`
- **Views:** 26
- **Tags:** Landing Page, Services, Travel, Brand, Clean, Minimal, Large Type, Technology, Booking, Homestay

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

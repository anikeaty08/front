# Plumbing and Heating Services Landing Page Template

A professional and responsive landing page template for plumbers and home service contractors, designed to drive 24/7 service inquiries.

## Project Details
- **Slug:** `horas-plumber-draft`
- **Views:** 90
- **Tags:** Services, Technology, Dark, Clean, Minimal, Landing Page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Horizon Dashboard UI Template Modern

A modern e-commerce analytics dashboard UI template for tracking revenue, orders, customers, and traffic sources, ready to customize for your web app.

## Project Details
- **Slug:** `horizondashboard`
- **Views:** 35
- **Tags:** Technology, Landing Page, Brand, Clean, Gradient, Minimal, Dashboard, E-commerce analytics, SaaS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Hospital Healthcare Landing Page Template

A reusable hospital and healthcare landing page template for Spanish medical groups, featuring online appointments, specialties, centers map, and blog layout.

## Project Details
- **Slug:** `hospital-healthcare-26`
- **Views:** 21
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Technology, Hospital, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Hospital Landing Page Template

A reusable hospital website template for healthcare providers to showcase specialties, build trust, and drive appointment bookings online.

## Project Details
- **Slug:** `hospital-landing-41`
- **Views:** 42

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Hospital Landing Page Template

A modern hospital landing page template for multispeciality clinics and healthcare providers to showcase doctors, treatments, facilities, and online appointment booking.

## Project Details
- **Slug:** `hospital-landing-76`
- **Views:** 38
- **Tags:** Health, Landing Page, Services, Clean, Modern, Medical, Hospital, Appointment Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

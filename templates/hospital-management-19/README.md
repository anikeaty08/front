# Hospital Management Dashboard Template

A reusable hospital management dashboard template for monitoring patients, appointments, records, pharmacy, alerts, and care operations in one interface.

## Project Details
- **Slug:** `hospital-management-19`
- **Views:** 50
- **Tags:** Health, Technology, Dashboard, Admin, Clean, Minimal, Landing Page, Analytics
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

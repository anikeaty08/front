# Hospitality Gift Voucher Landing Page Template

A clean, modern landing page template for platforms that let hotels, restaurants, and wellness brands sell digital gift vouchers and offers online.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

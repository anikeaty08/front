# Hotel Booking Landing Page Template

A modern Sunrise-themed hotel booking landing page template for showcasing stays, facilities, and membership tiers with seamless search and booking flows.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

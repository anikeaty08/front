# Hotel Kunan Wasi Landing Page Template

Moderno template de landing page para hotel o alojamiento en Nasca, ideal para mostrar habitaciones, servicios, galería y contacto con reservas directas.

## Project Details
- **Slug:** `hotel-booking-26`
- **Views:** 37
- **Tags:** Landing Page, Travel, Business, Brand, Clean, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

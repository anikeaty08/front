# Boutique Hotel Landing Page Template

A reusable boutique hotel website template for showcasing rooms, dining, amenities, and direct booking with an elegant hospitality-focused design.

## Project Details
- **Slug:** `hotel-lafayette`
- **Views:** 60
- **Tags:** Landing Page, Travel, Services, Clean, Elegant, Hotel, Hospitality, Booking, Restaurant
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

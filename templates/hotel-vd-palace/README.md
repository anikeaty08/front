# Hotel Landing Page Template

Clean, modern hotel landing page template for promoting budget stays, showcasing rooms, amenities, and location with clear calls to book or inquire.

## Project Details
- **Slug:** `hotel-vd-palace`
- **Views:** 40
- **Tags:** Landing Page, Travel, Business, Services, Clean, Minimal, Brand, Large Type, Hotel, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

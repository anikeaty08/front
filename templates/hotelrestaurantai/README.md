# HotelAI Concierge SaaS Landing Page Template

A high-converting landing page template for AI concierge and reservation SaaS, crafted for hotels and restaurants to showcase features, pricing, ROI, and demo signup.

## Project Details
- **Slug:** `hotelrestaurantai`
- **Views:** 26
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

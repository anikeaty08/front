# Ad Campaign Builder Interface Template

A reusable UI template for creating, managing, and uploading media for multi-step digital ad campaigns with an integrated template library.

- **Slug:** `hotspotnow-ad-90`
- **Views:** 21
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Large Type, Gradient, Advertising, Campaign Builder

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Freelance Pricing Tool Landing Page Template

A reusable landing page template for freelancers to calculate hourly rates, build service packages, and share polished pricing links with clients.

## Project Details
- **Slug:** `hourly-rate-and-27`
- **Views:** 89
- **Tags:** Landing Page, Services, Technology, Dark, Clean, Minimal, calculator, freelance, pricing, packages
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

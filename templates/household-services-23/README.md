# Household Services Booking Landing Page Template

A modern, reusable landing page template for on-demand household services platforms to showcase bookings, pricing, and vetted home service pros with a clean UI.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

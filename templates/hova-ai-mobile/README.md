# Hova AI Development Platform Template

A versatile landing page template designed for AI-powered development platforms to showcase features, pricing, integrations, and testimonials.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

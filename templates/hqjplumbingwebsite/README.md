# Plumbing Supplies Landing Page Template

A modern plumbing supplies landing page template for wholesalers and distributors, ready to customize for service, catalog download, and quote requests.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

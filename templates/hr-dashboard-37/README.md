# HR Management Dashboard Template

A reusable HR dashboard template for managing employees, attendance, leave requests, payroll visibility, and onboarding workflows in one clean admin UI.

## Project Details
- **Slug:** `hr-dashboard-37`
- **Views:** 83
- **Tags:** Technology, Services, Dashboard, Landing Page, Clean, Minimal, Admin, HR, SaaS

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

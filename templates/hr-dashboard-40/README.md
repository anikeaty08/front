# Arabic HR Dashboard UI Template

Modern Arabic RTL HR dashboard UI template for tracking employees, jobs, and applications, ready to reuse in HR systems and admin panels.

- **Slug:** `hr-dashboard-40`
- **Views:** 27

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

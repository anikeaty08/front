# HR Dashboard Admin Template

A reusable HR management dashboard template for tracking employees, attendance, leave, contracts, performance, and admin workflows across branches.

## Project Details
- **Slug:** `hr-management-89`
- **Views:** 48
- **Tags:** Landing Page, Services, Technology, Dashboard, Admin, SaaS, Clean, Minimal

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

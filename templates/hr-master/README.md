# HR Consulting Landing Page Template

A modern HR consulting landing page template for showcasing HRD services, leadership development, and talent strategy to enterprise clients.

## Project Details
- **Slug:** `hr-master`
- **Views:** 14
- **Tags:** Landing Page, Services, Business, Consulting, Clean, Minimal, Gradient, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# HR Consulting & Recruitment Landing Page Template

A reusable HR consulting and recruitment landing page template for agencies and talent partners to showcase services, case studies, and book discovery calls.

## Project Details
- **Slug:** `hr-recruitmen-18`
- **Views:** 17
- **Tags:** Landing Page, Services, Business, HR, Recruitment, Consulting, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# E-commerce Product Recommendations UI Template

A reusable e-commerce UI template for “Customers Also Bought” and “Recently Viewed” product carousels, optimized to boost on-site discovery and cart adds.

## Project Details
- **Slug:** `hsc-related-products`
- **Views:** 5
- **Tags:** E-commerce, Landing Page, Services, Clean, Minimal, Grid, Large Type, Technology, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

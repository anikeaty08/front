# Jewellery E-commerce Website Template

A modern jewellery e-commerce website template for showcasing gold and silver collections with product listing, detail pages, and brand story sections.

## Project Details
- **Slug:** `hsm-jewellery-aura`
- **Views:** 35
- **Tags:** E-commerce, Landing Page, Brand, Clean, Minimal, Large Type, Grid, Art & Design, Fashion, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Outbound Agency Landing Page Template

High-converting landing page template for AI-powered, done-for-you outbound agencies to showcase services, results, and book strategy calls with B2B SaaS clients.

## Project Details
- **Slug:** `http-www-jetgrowth-co`
- **Views:** 5
- **Tags:** Landing Page, Business, Services, Technology, Clean, Gradient, Minimal, Brand, B2B SaaS, outbound sales
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

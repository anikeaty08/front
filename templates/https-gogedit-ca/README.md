# Plumbing Services Landing Page Template

A modern plumbing services landing page template for trades and home service brands, optimized for bookings, emergencies, and clear service overviews.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Education Landing Page Template

A reusable landing page template for certification academies, universities, and corporate training providers to showcase tech programs and drive inquiries.

## Project Details
- **Slug:** `https-knowpro-co-in-`
- **Views:** 20
- **Tags:** Landing Page, Education, Technology, Services, Clean, Minimal, Blog, training, certifications
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Humanitarian Institute Landing Page Template

A reusable landing page template for humanitarian training institutes to showcase mission, objectives, and IHL resources with a modern bilingual design.

## Project Details
- **Slug:** `humanitari-training-36`
- **Views:** 9
- **Tags:** Landing Page, Education, Non-profit, Brand, Clean, Gradient, Minimal, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

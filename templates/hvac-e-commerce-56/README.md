# HVAC E-commerce Landing Page Template

A modern HVAC services and product shop landing page template for showcasing cooling/heating solutions, testimonials, and an online catalog.

## Project Details
- **Slug:** `hvac-e-commerce-56`
- **Views:** 10
- **Tags:** Landing Page, E-commerce, Services, Technology, Brand, Clean, Gradient, Large Type, Minimal

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

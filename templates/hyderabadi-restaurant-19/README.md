# Restaurant Landing Page Template

A modern restaurant landing page template for showcasing Indian cuisine, menus, and reservations with bold visuals and clear calls to book a table.

## Project Details
- **Slug:** `hyderabadi-restaurant-19`
- **Views:** 30
- **Tags:** Landing Page, Food, Brand, Clean, Dark, Large Type, Gradient, Restaurant, Indian cuisine, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

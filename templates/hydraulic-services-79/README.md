# Hydraulic Services Landing Page Template

A modern, mobile-ready landing page template for local plumbing and hydraulic service businesses to showcase offers, reviews and drive call-based leads.

## Project Details
- **Slug:** `hydraulic-services-79`
- **Views:** 5
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

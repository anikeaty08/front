# Hypertension Monitoring Dashboard UI Template

A modern dashboard UI template for hypertension and cardiac monitoring apps, ideal for clinicians and health platforms to track vitals, meds, and visits.

## Project Details
- **Slug:** `hypertensi-monitor-85`
- **Views:** 22
- **Tags:** Health, Technology, Landing Page, Brand, Dark, Clean, Gradient, Dashboard, Medical, UI

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

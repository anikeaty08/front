# Pickleball Facility Landing Page Template

A modern pickleball facility landing page template for showcasing locations, courts, pricing, and contact details to drive court bookings.

## Project Details
- **Slug:** `hyprgroundpickleball`
- **Views:** 30
- **Tags:** Landing Page, Services, Sports, Clean, Dark, Gradient, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

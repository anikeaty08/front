# Electrical Services Landing Page Template

A reusable landing page template for electrical and low-voltage design and consultation services, featuring hero, services, process, and contact sections.

## Project Details
- **Slug:** `i-am-going-to-0`
- **Views:** 20
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Large Type, Gradient, Electrical, Consulting
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# LOGTEC Brand Guidelines Landing Page Template

A dark, minimalist brand guidelines template for logistics and technology companies to present logo, typography, color, and UI components consistently.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

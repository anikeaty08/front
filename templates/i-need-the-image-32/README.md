# Indian FMCG B2B Landing Page Template

A modern landing page template for Indian FMCG B2B distributors and marketplaces, featuring catalog highlights, logistics value props, and retailer registration flow.

## Project Details
- **Slug:** `i-need-the-image-32`
- **Views:** 12
- **Tags:** Landing Page, Business, Services, Clean, Minimal, Brand, Large Type, Food, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

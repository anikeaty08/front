# Dental Clinic Landing Page Template

A modern dental clinic landing page template for promoting oral care services, showcasing treatments, and driving online appointment bookings.

- **Slug:** `i-will-send-u-28`
- **Views:** 30
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Dental Clinic, Medical, Appointment Booking

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

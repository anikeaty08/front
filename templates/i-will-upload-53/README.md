# Dating App Store Preview Template

A reusable dating app store preview template showcasing chat, matches, quizzes, and profile screens for modern relationship apps.

- **Slug:** `i-will-upload-53`
- **Views:** 10

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

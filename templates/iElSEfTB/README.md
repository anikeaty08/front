# Vehicle Dashboard Interface

Responsive vehicle dashboard showing battery, speed, trip info, driving conditions, tire pressure, and speedometer gauge.

## Project Details
- **Slug:** `iElSEfTB`
- **Views:** 173
- **Tags:** Dashboard, Vehicle, Battery Status, Speedometer, Trip Info, Tire Pressure, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Interactive Music Player UI

Custom music player with animated background, playback controls, progress bar, and dynamic track info using Tailwind and Font Awesome.

## Project Details
- **Slug:** `iIgafT`
- **Views:** 204
- **Tags:** Music Player, Playback Controls, Progress Bar, Animated Background, Tailwind CSS, JavaScript
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

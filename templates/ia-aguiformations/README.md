# IA AGUI Course

Modern landing page template for an AI-powered marketing training platform with course catalogue, method demo, pricing, and login flows ready to customize.

## Project Details
- **Slug:** `ia-aguiformations`
- **Views:** 25
- **Tags:** Landing Page, Education, Technology, Brand, Clean, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Safety Certification Academy Landing Page Template

A modern template for safety training academies to present ASP/CSP certification courses, upcoming sessions, and certificate verification in a single-page layout.

## Project Details
- **Slug:** `iassnewdemothree`
- **Views:** 78
- **Tags:** Landing Page, Education, Services, Clean, Minimal, Large Type, Brand, Technology, safety training, certification
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

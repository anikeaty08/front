# Ice Delivery Landing Page Template

A modern Docteur Glaçons-style landing page template for on-demand ice delivery services, perfect for showcasing products, pricing, and express ordering.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Chiropractic Clinic Landing Page Template

A reusable landing page template for chiropractic, wellness, and functional medicine clinics to build trust, showcase care, and drive consultation bookings.

## Project Details
- **Slug:** `ideal-motion-chiro1`
- **Views:** 31
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Brand, wellness, chiropractic, testimonials
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Identity Verification Portal UI Template

A secure, multi-step identity verification portal UI template for camera-based ID scanning, profile review, and authorization status display.

- **Slug:** `identity-verificati-25`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

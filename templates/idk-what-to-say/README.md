# Romantic Date Proposal Landing Page Template

A romantic, interactive proposal landing page template for asking someone on a date with animations, timeline memories, and a playful Yes/No interaction.

## Project Details
- **Slug:** `idk-what-to-say`
- **Views:** 21
- **Tags:** Landing Page, Wedding, Social, Art & Design, Clean, Colorful, Animated, Romantic, Proposal, Valentines
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

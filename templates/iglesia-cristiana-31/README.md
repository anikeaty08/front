# Religious Church Landing Page Template

Modern church website template for evangelical congregations, featuring services, congregations map, and contact form to adapt for your ministry.

## Project Details
- **Slug:** `iglesia-cristiana-31`
- **Views:** 123
- **Tags:** Religious, Landing Page, Brand, Clean, Minimal, Large Type, Colorful, Church, Evangelical, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

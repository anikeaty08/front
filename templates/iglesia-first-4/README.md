# Interactive Church Experience Landing Page Template

A modern interactive church experience landing page template for faith communities to guide visitors through beliefs, location, and invitation flow.

- **Slug:** `iglesia-first-4`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

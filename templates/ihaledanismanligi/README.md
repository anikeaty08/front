# İhale Danışmanlığı

A modern landing page template for international tender consulting services, ideal for showcasing global bid management, pricing packages, and FAQs.

## Project Details
- **Slug:** `ihaledanismanligi`
- **Views:** 16
- **Tags:** Landing Page, Services, Business, Consulting, Clean, Gradient, Dark, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

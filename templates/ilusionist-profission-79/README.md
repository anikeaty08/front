# Ilusionista Profissional Event Landing Page Template

Landing page template for professional illusionists and magicians to showcase services, portfolio, testimonials, and capture event booking inquiries.

## Project Details
- **Slug:** `ilusionist-profission-79`
- **Views:** 5
- **Tags:** Landing Page, Services, Entertainment, Brand, Portfolio, Dark, Clean, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

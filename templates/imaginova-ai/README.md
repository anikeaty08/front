# Imaginova Gallery Landing Page Template

A reusable landing page template designed for showcasing AI-generated artwork galleries with interactive filters and a sleek, modern UI.

- **Slug:** `imaginova-ai`
- **Views:** 2295
- **Tags:** Landing Page, Gallery, Filters, AI Art, Interactive, Responsive, Grid Layout, Hero, Navigation, Footer

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

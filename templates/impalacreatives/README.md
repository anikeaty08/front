# Creative Agency Landing Page Template

A bold, dark-mode creative agency landing page template for full-service marketing studios to showcase services, vision, and drive client inquiries.

## Project Details
- **Slug:** `impalacreatives`
- **Views:** 60

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Kebab Restaurant Ordering Landing Page Template

A dark, modern kebab restaurant landing page template with online ordering, cart sidebar, login, and checkout flow ready for local food businesses.

## Project Details
- **Slug:** `imperiumkebab`
- **Views:** 45
- **Tags:** Food, E-commerce, Landing Page, Brand, Dark, Clean, Colorful, Restaurant, Online Ordering, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

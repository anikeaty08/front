# Football Scouting Platform Landing Page Template

A reusable landing page template for AI-powered football scouting platforms, built to showcase prospect discovery, analytics, and pricing for clubs and agencies.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

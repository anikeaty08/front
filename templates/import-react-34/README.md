# Local Tabac Presse Landing Page Template

A modern one-page template for French tabac, presse, loto & PMU shops to showcase services, hours, location and contact details in style.

## Project Details
- **Slug:** `import-react-34`
- **Views:** 364
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Technology, Local Business, French, Tabac
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Importism SaaS Landing Page Template

A retro-styled SaaS landing page template for a lightweight BI tool that automates data imports into Google Sheets, ready to customize for your product.

## Project Details
- **Slug:** `importism-saas-01`
- **Views:** 501
- **Tags:** Landing Page, Technology, Business, Brand, Brutal, Clean, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

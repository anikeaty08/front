# Fitness Landing Page Template

A reusable dark fitness landing page template for gyms, strength clubs, and personal training brands to promote classes, memberships, and core offerings.

## Project Details
- **Slug:** `impulzfitnessgym`
- **Views:** 36
- **Tags:** Landing Page, Health, Services, Dark, Minimal, Clean, fitness, gym, strength training
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

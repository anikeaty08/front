# Aero In-Flight Dashboard Template

A sophisticated, dark-mode aviation dashboard template for in-flight entertainment and cabin control systems featuring glassmorphism and real-time telemetry visuals.

## Project Details
- **Slug:** `in-flight-dashboard-45`
- **Views:** 10
- **Tags:** Technology, Futuristic, Dark, Clean, Animated, Dashboard, UI Kit
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# In-Home Care Landing Page Template

A reusable landing page template for in-home care agencies and caregivers to showcase services, build trust, and drive consultation requests.

## Project Details
- **Slug:** `in-home-care-50`
- **Views:** 31
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Dark, caregiver, senior care, home care
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

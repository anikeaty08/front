# India News Portal Landing Page Template

A modern news portal landing page template for India-focused publishers, featuring breaking news, categories, videos, and newsletter subscriptions.

## Project Details
- **Slug:** `india-news-portal-16`
- **Views:** 18
- **Tags:** Landing Page, Brand, Clean, Colorful, Grid, Large Type, News portal, Media, Publishing, Editorial
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Indian Restaurant Menu Landing Page Template

A reusable restaurant landing page template for showcasing North Indian cuisine, menu categories, pricing, contact details, and quick ordering actions.

## Project Details
- **Slug:** `indian-restaurant-97`
- **Views:** 65
- **Tags:** Landing Page, Food, Dark, Clean, Gradient, Animated, Restaurant, Menu, Glassmorphism
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

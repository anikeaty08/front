# Indian Spices Export Landing Page Template

A conversion-focused landing page template for Indian spices exporters to showcase controlled export processes, quality compliance, and drive sample & pricing requests.

## Project Details
- **Slug:** `indian-spices-20`
- **Views:** 101
- **Tags:** Landing Page, Business, Services, Clean, Minimal, Brand, Large Type, Food, Technology, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

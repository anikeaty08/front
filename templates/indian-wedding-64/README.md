# Elegant Indian Wedding Invitation Page Template

A refined, animated Indian wedding invitation page template showcasing couple details, events, venue, countdown, and RSVP for modern celebrations.

## Project Details
- **Slug:** `indian-wedding-64`
- **Views:** 21
- **Tags:** Wedding, Landing Page, Brand, Clean, Gradient, Large Type, Animated, Event, Invitation, RSVP
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

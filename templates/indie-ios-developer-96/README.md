# Indie iOS Developer Portfolio Template

A clean, privacy-focused indie iOS developer portfolio template for showcasing on-device apps, services, and contact in a calm, minimal layout.

## Project Details
- **Slug:** `indie-ios-developer-96`
- **Views:** 114

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

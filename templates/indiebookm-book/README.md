# IndieBookMarket Marketplace Website Template

A warm, book-focused IndieBookMarket website template for showcasing indie titles, author profiles, and publishing workflows for online book marketplaces.

## Project Details
- **Slug:** `indiebookm-book`
- **Views:** 17
- **Tags:** E-commerce, Landing Page, Brand, Clean, Minimal, Large Type, Technology, Entertainment, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Industrial Battery Supplier Landing Page Template

Dark, industrial-style landing page template for B2B EV battery and energy storage suppliers to showcase products, logistics, and capture wholesale inquiries.

## Project Details
- **Slug:** `industrial-battery-9`
- **Views:** 14
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Grid, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

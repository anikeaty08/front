# Industrial Concrete Block Landing Page Template

Reusable landing page template for promoting industrial concrete block (I-BLOCK) products to construction companies with specs, catalog, and WhatsApp quotes.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

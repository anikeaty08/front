# Industrial Product Landing Page Template

High-conversion landing page template for industrial construction products, ideal to reuse for showcasing a hero product, specs, benefits, and lead-gen forms.

## Project Details
- **Slug:** `industrial-constructi-9`
- **Views:** 20

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

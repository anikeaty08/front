# Industrial Metal Galvanization Landing Page Template

A modern dark-themed template for metal galvanization and coating service businesses, perfect as a reusable landing page to showcase services, capacity, and contact.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Industrial Manufacturing Landing Page Template

A reusable landing page template for precision manufacturing and OEM component suppliers to showcase capabilities, certifications, and case study projects.

## Project Details
- **Slug:** `industrial-manufacturer`
- **Views:** 335
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Large Type, Gradient, Portfolio, Industrial

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

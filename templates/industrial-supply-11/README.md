# Industrial Supply Landing Page Template

A reusable landing page template for industrial tool suppliers and B2B equipment distributors to generate quote requests, showcase expertise, and build buyer trust.

- **Slug:** `industrial-supply-11`
- **Views:** 33

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

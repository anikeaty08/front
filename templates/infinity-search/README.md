# AI Search Interface UI Template

A modern dark-mode AI search interface template for chat-style queries, ideal for building GPT-like assistants and intelligent search experiences.

## Project Details
- **Slug:** `infinity-search`
- **Views:** 5

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

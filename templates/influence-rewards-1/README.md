# Free Business Card Landing Page Template

A high-converting free business card promotion template that lets print and e-commerce brands showcase loyalty coins, workflows, and testimonials to drive signups and orders.

## Project Details
- **Slug:** `influence-rewards-1`
- **Views:** 88
- **Tags:** Landing Page, E-commerce, Business, Brand, Clean, Colorful, Gradient, Large Type, Marketing, Print
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

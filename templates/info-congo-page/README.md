# Environmental Journalism About Page Template

A reusable about-page template for environmental journalism platforms like InfoCongo, featuring mission, impact stats, focus areas, maps, and team presentation.

## Project Details
- **Slug:** `info-congo-page`
- **Views:** 11
- **Tags:** Landing Page, Brand, Environmental, Clean, Dark, Large Type, Gradient, Technology, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

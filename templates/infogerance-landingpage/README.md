# IT Infogérance Landing Page Template

Template de landing page pour prestataires d’infogérance IT, idéal pour promouvoir une offre managée PME avec audit flash interactif et génération de leads.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Infrastructure & Automation Agency Landing Page Template

A dark, modern landing page template for infrastructure, automation, and systems consulting agencies to showcase process, capabilities, and drive evaluation requests.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

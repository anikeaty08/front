# Digital Classroom marketplace

A reusable course marketplace template for showcasing and filtering business courses with ratings, duration, topic clusters, and clean catalog cards.

## Project Details
- **Slug:** `infuse-homework`
- **Views:** 33
- **Tags:** Education, Landing Page, Business, Clean, Minimal, Technology, course marketplace, course catalog, filters
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

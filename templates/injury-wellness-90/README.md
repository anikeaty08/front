# Health Clinic Landing Page Template

A modern Health landing page template for injury and wellness clinics to showcase multidisciplinary care, community mission, and patient-focused services.

## Project Details
- **Slug:** `injury-wellness-90`
- **Views:** 8
- **Tags:** Health, Landing Page, Services, Brand, Clean, Minimal, Large Type, Gradient, Clinic, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Music Social Network Landing Page Template

A dark, brutal-style landing page template for a music social network or audio startup beta waitlist, ready to customize for your own product launch.

## Project Details
- **Slug:** `inpulze-beta-test`
- **Views:** 5
- **Tags:** Landing Page, Technology, Entertainment, Brand, Brutal, Dark, Gradient, Large Type, Animated, Music
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

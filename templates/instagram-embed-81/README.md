# Instagram Embed Widget Template

A reusable Instagram embed widget template with switchable aesthetics (minimal, dark, glass, retro) for showcasing Instagram profiles responsively.

## Project Details
- **Slug:** `instagram-embed-81`
- **Views:** 1
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Colorful, Dark, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

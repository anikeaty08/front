# Institutional Finance Dashboard UI Template

A reusable institutional finance dashboard UI template for monitoring reserves, risk, and performance with a clean, data-rich layout.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

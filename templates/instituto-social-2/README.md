# Non-profit Impact Landing Page Template

A reusable landing page template for institutes, NGOs, and OSCIPs to showcase social, environmental, and economic regeneration projects and attract partners.

## Project Details
- **Slug:** `instituto-social-2`
- **Views:** 20
- **Tags:** Landing Page, Non-profit, Services, Brand, Clean, Gradient, Large Type, Minimal, Technology, Environmental
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

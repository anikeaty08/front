# Insurance Agency Landing Page Template

Reusable landing page template for local insurance agencies to present services, build trust, and capture consultation inquiries online.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

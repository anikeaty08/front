# Health Coverage Finance App UI Template

A dark, mobile-first health coverage finance app UI template for displaying verified insurance benefits, fertility programs, and cost status in a sleek dashboard.

## Project Details
- **Slug:** `insurance-big-40`
- **Views:** 25
- **Tags:** Health, Technology, Landing Page, Brand, Dark, Clean, Minimal, Gradient, Large Type, Mobile UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Health Finance Journey Estimator App Template

A mobile-first health finance estimator app template for visualizing insurance coverage, fertility treatment costs, and out-of-pocket spend in an elegant UI.

## Project Details

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Insurance Mobile App Template

A reusable insurance app template for showcasing policies, claims, payments, and account settings in a polished mobile dashboard UI.

## Project Details
- **Slug:** `insurance-mobile-40`
- **Views:** 21
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Mobile App, Insurance, Dashboard, Fintech
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Integrated Health Landing Page Template

A reusable landing page template for integrated health clinics to showcase services, patient testimonials, and drive consultation bookings.

## Project Details
- **Slug:** `integrated-health-18`
- **Views:** 39
- **Tags:** Health, Services, Landing Page, Clean, Minimal, testimonials, video, medical, wellness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

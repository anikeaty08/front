# Integrative Medicine Landing Page Template

A reusable landing page template for integrative and functional medicine clinics to promote root-cause care, build trust, and drive discovery call bookings.

## Project Details
- **Slug:** `integrativ-medicine-23`
- **Views:** 35
- **Tags:** Health, Landing Page, Services, Clean, Minimal, testimonials, medical, wellness, functional medicine
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

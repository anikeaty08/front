# IntelliSend SMS Gateway Landing Page Template

A reusable dark-mode IntelliSend landing page template for marketing an AI-powered SMS failover gateway, pricing plans, and developer-focused API integration.

1. Open folder in VS Code / terminal.
2. Run `npm install`.

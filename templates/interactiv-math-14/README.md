# Interactive Math Learning App UI Template

Mobile-style interactive math learning app UI template for showcasing problem-solving, streaks, and recent concepts in a modern, student-friendly design.

- **Slug:** `interactiv-math-14`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

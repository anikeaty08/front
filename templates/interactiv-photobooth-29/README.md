# Interactive Photobooth Web App Template

A modern interactive photobooth web app template for events or studios, featuring live webcam capture, filters, photo strips, and downloadable layouts.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

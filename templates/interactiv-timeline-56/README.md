# Timeline Slider Story Section Template

A reusable landing page timeline slider template for showcasing a personal or brand journey with interactive 3D flip cards and horizontal scroll.

## Project Details
- **Slug:** `interactiv-timeline-56`
- **Views:** 14
- **Tags:** Landing Page, Brand, Art & Design, Clean, Minimal, Timeline slider, Personal story, 3D cards, Interactive UI, Horizontal scroll
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

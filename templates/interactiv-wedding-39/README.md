# Romantic Proposal Landing Page Template

A playful, animated romantic proposal landing page template designed to ask “Will you marry me?” with an interactive yes/no experience.

## Project Details
- **Slug:** `interactiv-wedding-39`
- **Views:** 14
- **Tags:** Landing Page, Wedding, Social, Entertainment, Brand, Dark, Gradient, Animated, Minimal

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

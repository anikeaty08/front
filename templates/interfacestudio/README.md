# Interface Studio IFS

A clean, minimal landing page template for contemporary art studios or curatorial associations to present their identity, manifesto, and contact details.

## Project Details
- **Slug:** `interfacestudio`
- **Views:** 48
- **Tags:** Landing Page, Art & Design, Portfolio, Brand, Clean, Minimal, Large Type, Dark, Gradient, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

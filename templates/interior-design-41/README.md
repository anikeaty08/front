# Luxury Interior Design Studio Landing Page Template

A reusable landing page template for luxury interior design studios to showcase services, projects, testimonials, and consultations in a refined, modern layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# International School Landing Page Template

A reusable landing page template for international and kindergarten schools to showcase programs, admissions, and parent testimonials with a modern, family-friendly design.

## Project Details
- **Slug:** `internatio-school-12`
- **Views:** 24
- **Tags:** Landing Page, Education, Services, Brand, Clean, Colorful, Large Type, Minimal, School, Kindergarten
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

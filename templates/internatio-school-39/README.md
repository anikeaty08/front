# International School Landing Page Template

A reusable landing page template for international and kindergarten schools to showcase programs, admissions, and parent trust with a modern, child-friendly design.

## Project Details
- **Slug:** `internatio-school-39`
- **Views:** 50
- **Tags:** Landing Page, Education, Brand, Clean, Colorful, Minimal, Large Type, Services, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Intimacy Tracker Landing Page Template

A dark, modern landing page template for an intimacy and habit tracking app, featuring a hero demo card, email waitlist form, and social proof layout.

- **Slug:** `intimacy-tracker-65`
- **Views:** 15

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

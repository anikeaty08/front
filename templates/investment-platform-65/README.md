# Basket Investment Platform Landing Page Template

A dark-themed reusable landing page template designed for investment platforms to showcase portfolio baskets, performance charts, and transaction histories.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

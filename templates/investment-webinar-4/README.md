# Investment Webinar Landing Page Template

A reusable landing page template for promoting a live investing webinar, capturing email signups, and converting beginner investors into attendees.

## Project Details
- **Slug:** `investment-webinar-4`
- **Views:** 17

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Investment Firm Website Template

A reusable landing page template for private investment and asset management firms to showcase philosophy, portfolio, and sustainability with a refined, disciplined brand.

## Project Details
- **Slug:** `investmentfirm`
- **Views:** 325
- **Tags:** Landing Page, Business, Brand, Clean, Minimal, Large Type, Gradient, Technology, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

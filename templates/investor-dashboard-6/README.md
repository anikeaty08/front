# Investor Dashboard Web App Template

Reusable investor dashboard template for funding platforms to manage lender-ready presentations, guides, tools, and support in one clean interface.

## Project Details
- **Slug:** `investor-dashboard-6`
- **Views:** 11
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Large Type, Dashboard, Investor Portal, Funding
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Invoice & Quote Generator Web App Template

A clean, interactive web app template for generating professional invoices and quotes with multiple styles, live preview, and PDF export.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# iOS Interface Simulation Landing Page Template

An interactive iOS-style interface simulation template for showcasing mobile UI concepts, app demos, and motion design in a browser-based mock phone frame.

## Project Details
- **Slug:** `ios-mobile-ui-6`
- **Views:** 1
- **Tags:** Landing Page, Technology, Brand, Gradient, Dark, Minimal, Large Type, Interactive, Mobile UI, Prototype
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

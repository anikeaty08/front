# Mobile iOS Simulator Landing Page Template

A reusable landing page template simulating an iOS mobile interface for showcasing app UIs and interactions in a sleek phone frame.

## Project Details
- **Slug:** `ios-simulator-16`
- **Views:** 240
- **Tags:** Landing Page, Mobile Simulator, App Demo, UI Showcase, Interactive, Phone Frame, Lock Screen, Home Screen, App Icons, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

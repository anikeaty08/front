# Fitness for champs 

A bold fitness center template for gyms and training studios to showcase services, memberships, trainers, testimonials, and lead-generation CTAs.

## Project Details
- **Slug:** `ironcore-center`
- **Views:** 45
- **Tags:** Landing Page, Health, Services, Dark, Clean, Large Type, Fitness, Gym, Membership, Pricing
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

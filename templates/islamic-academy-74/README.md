# Islamic Academy Landing Page Template

A modern Islamic academy website template for promoting courses, charity campaigns, and contact details, ready to customize for your educational institution.

## Project Details
- **Slug:** `islamic-academy-74`
- **Views:** 6
- **Tags:** Landing Page, Education, Religious, Brand, Clean, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

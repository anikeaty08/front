# Islamic Chat Assistant UI Template

A modern Islamic chat assistant interface template for Quran and Hadith Q&A apps, ready to customize and reuse for faith-based learning experiences.

## Project Details
- **Slug:** `islamic-assistant`
- **Views:** 22
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Dark, Chat UI, Islamic, Religious Assistant, Quran Hadith
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

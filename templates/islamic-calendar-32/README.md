# Islamic Prayer Dashboard UI Template

A reusable Islamic calendar and prayer times dashboard UI template for showcasing Ramadan schedules, upcoming festivals, and Adhan alarm settings.

## Project Details
- **Slug:** `islamic-calendar-32`
- **Views:** 13
- **Tags:** Landing Page, Brand, Clean, Dark, Minimal, Technology, Dashboard, Islamic, Ramadan, Prayer Times
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

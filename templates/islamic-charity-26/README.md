# Humanitarian Charity Landing Page Template

A modern Hassanaty-inspired humanitarian landing page template for Islamic charitable foundations to showcase projects and drive online donations.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Islamic School Landing Page Template

Reusable Islamic school landing page template for foundations and madrasas to showcase programs, teachers, facilities, and drive admissions online.

## Project Details
- **Slug:** `islamic-education-0`
- **Views:** 28
- **Tags:** Landing Page, Education, Religious, Clean, Colorful, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Islamic Education Landing Page Template

A reusable landing page template for Islamic schools, madrasas, and educational institutes to showcase programs, e-learning, news, and donation campaigns.

## Project Details
- **Slug:** `islamic-education-36`
- **Views:** 29
- **Tags:** Landing Page, Education, Religious, Non-profit, Clean, Minimal, Services, donation, e-learning, institute
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

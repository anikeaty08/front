# Islamic Education Landing Page Template

A reusable landing page template for Quran academies and Islamic education institutes to showcase programs, build trust, and drive enrollments online.

## Project Details
- **Slug:** `islamic-education-88`
- **Views:** 74
- **Tags:** Landing Page, Education, Religious, Services, Clean, Dark, Gradient, Minimal, Islamic, Academy

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

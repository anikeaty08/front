# Islamic Boarding School Landing Page Template

A clean and modern Islamic school website template designed for SMP Salsabila Al-Tapaq to showcase educational programs, vision, and student registration.

## Project Details
- **Slug:** `islamic-modern-0`
- **Views:** 52
- **Tags:** Education, Services, Community, Clean, Minimal, Social, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Religious Registration Landing Page Template

A reusable landing page template for Islamic retreat and mosque event registration portals, featuring RTL Persian layout, login, notices, and step tracking.

## Project Details
- **Slug:** `islamic-retreat-27`
- **Views:** 23
- **Tags:** Landing Page, Religious, Clean, Minimal, Brand, Large Type, Technology, Membership, Conference, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

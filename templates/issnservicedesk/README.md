# ISSN Service Desk SImulator

A reusable dark-mode template for creating gamified IT support and cybersecurity training interfaces with terminal tasks, chat flows, and server monitoring.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

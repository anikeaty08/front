# IT Training Course Landing Page Template

A modern AFRINE-style IT training landing page template for promoting networking, cloud, and Python courses with cohorts, features, and testimonials.

## Project Details
- **Slug:** `it-cloud-training-8`
- **Views:** 12
- **Tags:** Landing Page, Education, Technology, Brand, Clean, Minimal, Gradient, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# IT Infrastructure Rental Landing Page Template

A modern landing page template for enterprise IT infrastructure rental services, ideal for promoting server, networking, firewall, and CCTV rental solutions.

## Project Details
- **Slug:** `it-infrastruc-37`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# IT Reseller SaaS Landing Page Template

A modern SaaS landing page template for an IT reseller license management platform, ready to customize for software, MSP, and B2B distribution products.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

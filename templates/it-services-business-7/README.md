# IT Services Landing Page Template

A dark, Hebrew right-to-left IT services landing page template for managed IT, cloud, backup, and cyber security providers serving business clients.

## Project Details
- **Slug:** `it-services-business-7`
- **Views:** 14
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

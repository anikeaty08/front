# IT Services Landing Page Template

A reusable landing page template for IT consulting and enterprise workflow automation services, built to showcase expertise, case studies, and lead-generation CTAs.

## Project Details
- **Slug:** `it-services-landing-24`
- **Views:** 45

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

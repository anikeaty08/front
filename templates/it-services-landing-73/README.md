# IT Services Landing Page Template

A reusable landing page template for IT consultancies and cloud solution providers showcasing services, solutions, case studies, and lead-gen CTAs.

## Project Details
- **Slug:** `it-services-landing-73`
- **Views:** 25
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Business IT, Cloud Services, SaaS, Consulting

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

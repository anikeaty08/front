# Techy Site

A reusable landing page template for local IT shops and computer hardware retailers to showcase products, repairs, store info, and drive in-store visits.

## Project Details
- **Slug:** `it-shop-demo123`
- **Views:** 19
- **Tags:** Landing Page, Technology, Services, E-commerce, Clean, Minimal, Dark, retail, computer hardware, repair services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# RFID Automation SaaS Landing Page Template

A high-converting landing page template for RFID automation and logistics SaaS solutions, showcasing hardware, software, use cases, FAQs, and powerful case studies.

## Project Details
- **Slug:** `itag-op7`
- **Views:** 30
- **Tags:** Landing Page, Technology, Business, Brand, Clean, Dark, Gradient, Large Type, Portfolio

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

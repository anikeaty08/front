# Italian Fast Food Restaurant Landing Page Template

A dark, modern Italian fast food restaurant landing page template with menu sections, drinks, and bold delivery CTAs, ready for dine-in or takeaway brands.

## Project Details
- **Slug:** `italian-fast-75`
- **Views:** 24
- **Tags:** Landing Page, Food, Brand, Clean, Dark, Gradient, Large Type, Restaurant, Menu, Delivery
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

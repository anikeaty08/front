# Italian Restaurant Landing Page Template

A dark, atmospheric Italian restaurant landing page template for showcasing menus, ambience, and reservations for modern dining brands.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Italian Restaurant Landing Page Template

A refined Italian restaurant landing page template for showcasing menu, atmosphere, chef, reviews, and reservations with a dark, rustic aesthetic.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

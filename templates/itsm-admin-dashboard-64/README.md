# ITSM Admin Dashboard UI Template

A modern ITSM admin dashboard template for tracking tickets, assets, and agents with real-time analytics, ready to reuse in your support or ops web app.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

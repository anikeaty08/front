# Construction Careers Landing Page Template

A modern careers landing page template for construction companies to showcase benefits, open positions, and simple CV contact options.

## Project Details
- **Slug:** `ivps`
- **Views:** 16
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Technology, Construction, Careers, Recruitment

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

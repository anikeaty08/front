# Corporate Internet Banking Dashboard UI Template

A modern corporate internet banking dashboard UI template for teams to manage accounts, transfers, and bulk uploads in a clean, responsive layout.

## Project Details
- **Slug:** `jamuna-corp-ib`
- **Views:** 38
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Brand, Dashboard, Banking, Finance, UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Jan Pustina

A modern, mobile-friendly landing page template for local plumbing, heating, gas, and HVAC service businesses to showcase services and drive calls and inquiries.

- **Slug:** `jan-pustina`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

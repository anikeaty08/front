# Japanese Restaurant Landing Page Template

A refined landing page template for high-end Japanese or kaiseki restaurants, ready to customize with your brand, menu, events, and reservations.

## Project Details
- **Slug:** `japanese-restaurant-85`
- **Views:** 19
- **Tags:** Landing Page, Food, Brand, Clean, Minimal, Dark, Large Type, Gradient, Restaurant, Event

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

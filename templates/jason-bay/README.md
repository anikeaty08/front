# jason bay training

A reusable landing page template for sales trainers, consultants, and outbound teams to promote messaging coaching, workshops, and call booking.

## Project Details
- **Slug:** `jason-bay`
- **Views:** 58
- **Tags:** Landing Page, Services, Business, Technology, Dark, Clean, Minimal, Gradient, sales outreach, coaching

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

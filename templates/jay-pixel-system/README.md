# Design System Documentation Template

A Nexus-inspired design system documentation template showcasing tokens, components, and usage guidelines for modern React, TypeScript, and Tailwind UI libraries.

## Project Details
- **Slug:** `jay-pixel-system`
- **Views:** 95
- **Tags:** Documentation, Technology, Brand, Clean, Minimal, Large Type, UI kit, Design system
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

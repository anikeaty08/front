# Sales by Jeb Blount

A reusable landing page template for sales coaches, trainers, and teams promoting prospecting systems, pipeline growth, and call-booking services.

## Project Details
- **Slug:** `jeb-blount-sales`
- **Views:** 37
- **Tags:** Landing Page, Services, Technology, Dark, Gradient, Animated, sales coaching, prospecting, pipeline generation

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# VORTEX JEE Prep Landing Page Template

A dark, futuristic landing page template for the VORTEX JEE exam preparation app, showcasing practice features, analytics, and mobile download CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.

# Jewelry WhatsApp Order Landing Page Template

A modern Jaipur Jewelry landing page template for showcasing oxidised and anti-tarnish collections with WhatsApp ordering and store details.

## Project Details
- **Slug:** `jewelry-whatsapp-91`
- **Views:** 17
- **Tags:** E-commerce, Landing Page, Brand, Clean, Minimal, Gradient, Large Type, Jewelry, WhatsApp Order, Indian Boutique
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

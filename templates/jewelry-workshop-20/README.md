# Jewelry Workshop Landing Page Template

Minimal jewelry workshop landing page template for promoting local handcrafted courses, private sessions, and gift vouchers in a modern, boutique style.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

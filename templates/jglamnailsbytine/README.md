# J Glam Nails 

A reusable nail salon landing page template for showcasing services, pricing, reviews, and booking policies for modern beauty studios.

## Project Details
- **Slug:** `jglamnailsbytine`
- **Views:** 465
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Beauty, Nail Salon, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

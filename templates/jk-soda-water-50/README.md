# Soda Shop 

A modern dark-themed landing page template for soda shops or beverage brands to showcase signature drinks, tell their story, and drive in-store visits.

## Project Details
- **Slug:** `jk-soda-water-50`
- **Views:** 19
- **Tags:** Food, Landing Page, Brand, Clean, Dark, Minimal, Large Type, Beverage, Restaurant
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

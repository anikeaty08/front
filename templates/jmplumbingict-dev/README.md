# Plumbing Services Landing Page Template

A modern plumbing services landing page template for local, family-owned contractors to showcase offerings, reviews, and drive calls and quote requests.

## Project Details
- **Slug:** `jmplumbingict-dev`
- **Views:** 30
- **Tags:** Landing Page, Services, Business, Clean, Gradient, Brand, Large Type, Minimal, Local Service, Plumbing
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

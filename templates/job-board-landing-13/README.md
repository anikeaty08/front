# Job Board Landing Page Template

A modern job board landing page template to showcase vacancies, employers, and candidates with clean UI, stats, categories, and calls-to-action.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Job Board Landing Page Template

A reusable job board template for showcasing openings, filtering roles, and helping candidates discover remote, local, and hybrid opportunities.

## Project Details
- **Slug:** `job-board-landing-39`
- **Views:** 16
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Job Board, Recruitment, Careers
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

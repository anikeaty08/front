# Job Listing Landing Page Template

A clean job listing landing page template for showcasing a single role, company details, and application flow on recruitment or career sites.

- **Slug:** `job-board-vacancy-38`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

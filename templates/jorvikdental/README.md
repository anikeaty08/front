# Jorvik Dental Practice Landing Page Template

A modern, conversion-focused dental practice landing page template for private dentists and clinics to showcase treatments, team, offers, and online bookings.

## Project Details
- **Slug:** `jorvikdental`
- **Views:** 13
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Gradient, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

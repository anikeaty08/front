# Sales Coaching By Josh Braun

A reusable landing page template for sales coaches and consultants to promote empathetic outreach training, build trust, and drive strategy call bookings.

## Project Details
- **Slug:** `josh-braun-selling`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Agrifood E-commerce Landing Page Template

A reusable landing page template for an agrifood and wellness brand to showcase farm produce, natural products, kennels, and drive direct orders from customers.

## Project Details
- **Slug:** `jostems-agro-services`
- **Views:** 82
- **Tags:** E-commerce, Food, Health, Services, Brand, Clean, Colorful, Minimal, Landing Page, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

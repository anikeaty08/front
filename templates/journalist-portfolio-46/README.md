# Journalist Portfolio Website Template

A clean, minimal portfolio template for journalists and content creators to showcase articles, video work, and professional credits in a sortable archive layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

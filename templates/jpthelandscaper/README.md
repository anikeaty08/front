# Gardening & Tree Services Landing Page Template

A modern, responsive landing page template for local gardening, landscaping, and tree services businesses to showcase services, hours, and capture estimate requests.

## Project Details
- **Slug:** `jpthelandscaper`
- **Views:** 13
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Technology, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Junk Removal Landing Page Template

A modern junk removal landing page template for local service businesses, optimized for calls, quotes, and transparent pricing sections.

## Project Details
- **Slug:** `junk-removal-75`
- **Views:** 110
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Gradient, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

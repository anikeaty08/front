# Junk n Tow

A modern cash-for-cars and auto wrecking landing page template for local towing businesses to showcase services, highlight service areas, and drive quote requests.

## Project Details
- **Slug:** `junkntow`
- **Views:** 32
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Towing, Cash for cars, Auto wrecking, Local business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

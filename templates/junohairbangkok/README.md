# Luxury Hair Salon Landing Page Template

A cinematic, dark-mode landing page template for premium hair and beauty salons to showcase services, portfolio, pricing, team, and online bookings.

## Project Details
- **Slug:** `junohairbangkok`
- **Views:** 133
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Gradient, Large Type, Portfolio, Beauty Salon, Hairdresser
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

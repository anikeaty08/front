# JVSZ AI és Automatizáció szakmai fórum

Modern landing page template for AI and automation business forums or associations to showcase programs, research, and contact options.

## Project Details
- **Slug:** `jvsz-ai-forum`
- **Views:** 39
- **Tags:** Landing Page, Business, Technology, Clean, Minimal, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mobile Music Player Interface

Responsive music app UI with animated equalizer, glassmorphism cards, and floating particle background inside a phone frame.

## Project Details
- **Slug:** `kYBZRIV`
- **Views:** 133
- **Tags:** Music Player, Glassmorphism, Equalizer Animation, Particle Background, Mobile UI, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

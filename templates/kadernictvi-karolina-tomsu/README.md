# Hair Salon Landing Page Template

A clean, elegant hair salon landing page template for showcasing services, pricing, location, and contact details for local beauty studios.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Hair Salon Landing Page Template

Elegant hair salon website template for showcasing services, pricing, hours, and location—perfect as a reusable landing page for local salons.

## Project Details
- **Slug:** `kadernictvi-linea`
- **Views:** 32
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

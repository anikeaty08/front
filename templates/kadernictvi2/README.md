# Kadeřnictví 2

Elegant one-page hair salon website template for showcasing services, pricing, portfolio and contact details, ready to customize for any hairstylist or beauty studio.

## Project Details
- **Slug:** `kadernictvi2`
- **Views:** 16
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Beauty, Hair Salon
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

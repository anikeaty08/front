# Interstate Bus Booking Landing Page Template

A modern Kaduna Line-inspired landing page template for interstate bus and transport operators to showcase routes, schedules, and online booking.

## Project Details
- **Slug:** `kadunalineticket`
- **Views:** 43
- **Tags:** Landing Page, Services, Travel, Brand, Clean, Minimal, Gradient, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

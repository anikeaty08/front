# Kaffee.co Coffee Shop Landing Page Template

A modern coffee shop landing page template for artisan cafés to showcase their story, menu, and location while driving online orders and reservations.

## Project Details
- **Slug:** `kaffe`
- **Views:** 63
- **Tags:** Landing Page, Food, Brand, Clean, Dark, Large Type, Minimal, Coffee Shop, Restaurant, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

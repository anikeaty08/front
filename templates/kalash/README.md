# Restaurant Order Selection Landing Page Template

A reusable template for restaurant websites to let customers choose collection or delivery, highlight allergy information, and drive online orders.

## Project Details
- **Slug:** `kalash`
- **Views:** 76
- **Tags:** Food, E-commerce, Landing Page, Brand, Dark, Clean, Gradient, Large Type, Restaurant, Online Ordering
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

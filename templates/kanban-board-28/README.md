# Kanban Board App Template

A reusable kanban board template for managing projects, tasks, and team workflows with drag-and-drop columns, task details, and a clean productivity UI.

## Project Details
- **Slug:** `kanban-board-28`
- **Views:** 26
- **Tags:** Technology, Services, Landing Page, Clean, Minimal, Dashboard, Kanban, Task Management

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

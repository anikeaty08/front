# Consorcio Kar & Ma : Corporate WebPage

Premium landing page template for industrial and consumer sea salt brands, perfect for showcasing products, certifications, and quote-driven B2B sales.

## Project Details
- **Slug:** `kar-ma`
- **Views:** 64
- **Tags:** Landing Page, Brand, Services, Clean, Minimal, Large Type, Food, Technology, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

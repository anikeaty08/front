# CA Firm Landing Page Template

A modern dark-themed landing page template for Indian CA, tax, and compliance firms to showcase services, content, and capture consultation leads.

## Project Details
- **Slug:** `karveda-ca-firm`
- **Views:** 127
- **Tags:** Landing Page, Services, Business, Brand, Dark, Clean, Gradient, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

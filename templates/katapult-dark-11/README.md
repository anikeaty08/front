# Katapult Dark Mode Agency Landing Page Template

A dark, futuristic agency landing page template for design studios and creative teams to showcase services, portfolio work, and drive project inquiries.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

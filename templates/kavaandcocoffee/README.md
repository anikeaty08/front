# KÁVA Coffee Shop Landing Page Template

A premium, dark-themed cafe and restaurant template designed for modern coffee shops, bakeries, and local eateries looking for a stylish web presence.

## Project Details
- **Slug:** `kavaandcocoffee`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

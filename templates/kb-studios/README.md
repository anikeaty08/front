# Luxury Digital Studio Landing Page Template

A high-end landing page template for digital studios and agencies, showcasing premium services, portfolio, pricing, and contact in an electric 3D-driven experience.

## Project Details
- **Slug:** `kb-studios`
- **Views:** 15
- **Tags:** Landing Page, Brand, Services, Technology, Dark, Futuristic, 3D, Large Type, Portfolio, Clean
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

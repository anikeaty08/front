# Luxury Car Concierge Landing Page Template

A premium landing page template for exotic and luxury car rental concierge brands, built to showcase fleet inventory, trust signals, and booking CTAs.

## Project Details
- **Slug:** `keeping-in-touch`
- **Views:** 60
- **Tags:** Landing Page, Services, Travel, Technology, Dark, Clean, Luxury, Automotive, Concierge
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

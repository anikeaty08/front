# My Sales Coach

A reusable landing page template for sales coaches, consultants, and leadership advisors to showcase services, build trust, and drive strategy call bookings.

## Project Details
- **Slug:** `kevin-beales`
- **Views:** 20

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

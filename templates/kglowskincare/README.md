# KGlow Skincare E-commerce Template

A reusable KGlow beauty template for estheticians, spas, and skincare brands to showcase services, packages, products, testimonials, and bookings.

## Project Details
- **Slug:** `kglowskincare`
- **Views:** 768
- **Tags:** E-commerce, Health, Services, Landing Page, Brand, Clean, Minimal, Dark, wellness, skincare
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Khatta Singh Pani Puri 

A modern landing page template for gourmet pani puri and street food stalls to showcase menu, story, location, and bulk order details with a premium vibe.

## Project Details
- **Slug:** `khattasingh-kanpur`
- **Views:** 113
- **Tags:** Landing Page, Food, Brand, Clean, Colorful, Minimal, Large Type, Street food, Restaurant, Single page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Children's Content Membership Landing Page Template

A reusable landing page template for children's video libraries, memberships, books, and toys designed to help families create calmer evening routines.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

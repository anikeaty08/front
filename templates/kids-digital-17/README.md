# Urdu Kids Library Landing Page Template

A playful Urdu kids library landing page template for showcasing children's stories with an in-page reader, admin story editor, and warm, family-friendly design.

## Project Details
- **Slug:** `kids-digital-17`
- **Views:** 7
- **Tags:** Landing Page, Education, Entertainment, Brand, Colorful, Clean, Minimal, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

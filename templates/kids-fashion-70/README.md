# Kids Fashion E-commerce Website Template

A modern kids and girls fashion e-commerce website template with product grid, cart, checkout, tracking, and admin dashboard ready to customize.

## Project Details
- **Slug:** `kids-fashion-70`
- **Views:** 11
- **Tags:** E-commerce, Fashion, Landing Page, Brand, Clean, Minimal, Large Type, Technology, Services

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

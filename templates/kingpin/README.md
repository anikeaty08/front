# Tattoo Studio Landing Page Template

Dark, minimal tattoo studio landing page template for showcasing artists, styles, and Instagram feed with clear booking contact details.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

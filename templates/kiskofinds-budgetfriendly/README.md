# KISKO Cafe Restaurant Landing Page Template

A modern dark-mode cafe and restaurant landing page template for showcasing menus, ambience, reviews, and reservations for pizza, burger, and mojito spots.

## Project Details
- **Slug:** `kiskofinds-budgetfriendly`
- **Views:** 26
- **Tags:** Landing Page, Food, Business, Brand, Clean, Dark, Gradient, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

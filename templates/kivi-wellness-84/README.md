# Kivi Wellness Health Clinic Landing Page Template

A modern Kivi Wellness clinic landing page template for health and wellness providers to showcase services, plans, locations, and capture bookings.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Admin Portal Dashboard Template

A reusable dark admin portal template with dashboards, inspection workflow, and master logs for managing sales, agents, and payouts.

## Project Details
- **Slug:** `kiwi-admin-portal`
- **Views:** 29
- **Tags:** Landing Page, Technology, Brand, Dark, Clean, Dashboard, Admin, Analytics, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

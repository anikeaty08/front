# Sales Portal Dashboard Template

A modern sales portal template for logging deals, tracking profit, and managing agent activity, ready to reuse and customize for your sales team workflows.

## Project Details
- **Slug:** `kiwisalesportal`
- **Views:** 52

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Automotive Detailing Landing Page Template

A premium automotive detailing landing page template for showcasing services, pricing estimates, and bookings for high-end car care studios.

- **Slug:** `knightsdetailing`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

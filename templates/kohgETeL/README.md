# Animated Gradient Credit Card UI

Displays a stylized credit card with animated mesh gradients, chip SVG, card number, and cardholder details using Tailwind CSS.

## Project Details
- **Slug:** `kohgETeL`
- **Views:** 51
- **Tags:** Credit Card, Animation, Mesh Gradient, Tailwind CSS, SVG, Responsive Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

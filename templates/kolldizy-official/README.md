# Dark Artist Landing Page Template

A cinematic dark-mode artist landing page template for musicians to showcase music, merch, and platforms with immersive audio and glow effects.

## Project Details
- **Slug:** `kolldizy-official`
- **Views:** 86

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

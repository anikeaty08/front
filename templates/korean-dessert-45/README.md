# Food E-commerce Landing Page Template

A reusable landing page template for premium Korean dessert gifting brands, designed to showcase products, editions, travel-friendly benefits, and online orders.

## Project Details
- **Slug:** `korean-dessert-45`
- **Views:** 31
- **Tags:** Landing Page, E-commerce, Food, Brand, Clean, Minimal, Travel, gift products, dessert
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Kratom Product Quiz Landing Page Template

A reusable mobile-first template for kratom brands to guide shoppers through a short quiz and recommend the right product, format, and purchase path.

## Project Details
- **Slug:** `kratom-product-48`
- **Views:** 32
- **Tags:** Landing Page, E-commerce, Health, Clean, Minimal, Dark, Quiz, Mobile, Product Recommendation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

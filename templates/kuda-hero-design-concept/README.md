# Fintech App Landing Page Template

A dark, modern fintech landing page template designed to showcase a digital banking or finance app with hero video, logo cloud, and clear app download CTA.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

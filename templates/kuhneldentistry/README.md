# Kuhnel Dentistry's Modernized Website 

A modern dental practice landing page template for showcasing services, locations, reviews, and online appointment requests for local dentists.

## Project Details
- **Slug:** `kuhneldentistry`
- **Views:** 40
- **Tags:** Landing Page, Services, Health, Brand, Clean, Minimal, Large Type, Gradient, Dental, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

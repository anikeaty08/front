# Financial Advisor Personal Website Template

A modern, dark-mode personal brand template for independent financial advisors, featuring services, process, blog, testimonials, and contact pages ready to customize.

## Project Details
- **Slug:** `kurdiovsky`
- **Views:** 50
- **Tags:** Landing Page, Services, Brand, Portfolio, Dark, Clean, Gradient, Large Type, Minimal, Technology

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Financial Advisor Landing Page Template

A modern dark-mode landing page template for independent financial advisors to showcase services, process, testimonials, blog, and consultation booking.

## Project Details
- **Slug:** `kurdiovskyfinance`
- **Views:** 10
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Gradient, Large Type, Technology, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

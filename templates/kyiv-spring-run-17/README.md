# Running Event Landing Page Template

A dark, energetic landing page template for promoting city running events or marathons, featuring distances, schedule, partners, and registration CTAs.

## Project Details
- **Slug:** `kyiv-spring-run-17`
- **Views:** 281
- **Tags:** Landing Page, Events, Sports, Clean, Dark, Gradient, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

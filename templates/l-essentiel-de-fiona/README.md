# L'essentiel de Fiona - Institut de beauté - Saint-Paul-Cap-de-Joux

Elegant single-page template for beauty institutes and spas to present services, showcase testimonials, and drive online appointment bookings.

## Project Details
- **Slug:** `l-essentiel-de-fiona`
- **Views:** 24

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

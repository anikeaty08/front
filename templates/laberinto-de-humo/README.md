# Mexican Restaurant Landing Page Template

A bold restaurant landing page template for showcasing authentic Mexican cuisine, hours, menu access, and location details in a modern hero-focused layout.

## Project Details
- **Slug:** `laberinto-de-humo`
- **Views:** 65
- **Tags:** Landing Page, Food, Brand, Dark, Clean, Large Type, restaurant, mexican cuisine, hero section
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Lachowski

A reusable landing page template for interior finishing and renovation companies to showcase services, projects, trust signals, and free quote CTAs.

## Project Details
- **Slug:** `lachowskiremonty`
- **Views:** 310
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Minimal, Portfolio, Local Business, Renovation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

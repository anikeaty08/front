# Restaurant Landing Page Template

A bold Latin fusion restaurant landing page template for showcasing menus, brand story, reservations, and email signups with cinematic food imagery.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Minecraft Server Landing Page Template

A reusable landing page template for promoting a Minecraft server, showcasing game modes, community features, server status, and Discord onboarding.

## Project Details
- **Slug:** `landblock-pl111`
- **Views:** 86
- **Tags:** Landing Page, Technology, Entertainment, Dark, Futuristic, Gradient, Gaming, Community, Discord
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

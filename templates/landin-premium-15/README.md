# Landin Creative Agency Landing Page Template

A high-end dark mode template for creative studios and agencies to showcase portfolios, services, and subscription-based pricing models.

## Project Details
- **Slug:** `landin-premium-15`
- **Views:** 32
- **Tags:** Landing Page, Technology, Portfolio, Services, Dark, Clean, Minimal, Animated
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Arabic Landing Page Template

A reusable Arabic landing page template for promoting low-cost landing page services with WhatsApp ordering, Google Sheets lead capture, and mobile-first design.

## Project Details
- **Slug:** `landing-page-51`
- **Views:** 114
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Gradient, Arabic, WhatsApp, Lead Generation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

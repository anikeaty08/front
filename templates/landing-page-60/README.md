# Анонимная Наркологическая Помощь Landing Page Template

Готовый лендинг‑template для частной анонимной наркологической помощи с услугами, ценами, отзывами и заявкой в 1 клик для региональных клиник.

- **Views:** 29

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

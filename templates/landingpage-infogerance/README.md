# Infogérance PME Landing Page Template

Landing page template for MSPs and IT providers offering managed services and IT audits to SMEs, fully customizable for French-speaking infogérance campaigns.

## Project Details
- **Slug:** `landingpage-infogerance`
- **Views:** 20

- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

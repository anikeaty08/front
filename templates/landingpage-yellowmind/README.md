# WhatsApp AI Assistant Landing Page Template

A modern dark-theme landing page template for promoting an AI assistant that automates personal and business workflows directly inside WhatsApp.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

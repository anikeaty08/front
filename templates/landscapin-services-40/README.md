# Landscaping Services Landing Page Template

A modern landscaping services landing page template for lawn care, hardscaping, and outdoor design businesses to showcase services and capture leads.

## Project Details
- **Slug:** `landscapin-services-40`
- **Views:** 14
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Brand, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

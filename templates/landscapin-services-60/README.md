# Landscaping Services Landing Page Template

A clean, conversion-focused landscaping services landing page template for lawn care businesses to showcase services, trust, and capture quote requests.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Landscaping Services

A modern landscaping services landing page template designed to help local lawn care and outdoor living businesses showcase projects, services, and capture consultations.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

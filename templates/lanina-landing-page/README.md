# Lanina Spa & Wellness

A refined spa and wellness landing page template for beauty salons and skin detox spas to showcase services, testimonials, and bookings.

## Project Details
- **Slug:** `lanina-landing-page`
- **Views:** 8
- **Tags:** Landing Page, Services, Health, Brand, Clean, Minimal, Large Type, Spa, Beauty, Wellness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

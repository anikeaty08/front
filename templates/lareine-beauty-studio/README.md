# Lareine

A reusable luxury beauty studio website template for showcasing lash, nail, and academy services with editorial styling and appointment-focused sections.

## Project Details
- **Slug:** `lareine-beauty-studio`
- **Views:** 12
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Beauty studio, Lash extensions, Nail salon, Course
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

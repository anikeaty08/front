# Lash Extensions Landing Page Template

A reusable beauty business template for lash artists and studios to showcase services, gallery work, testimonials, and online booking.

## Project Details
- **Slug:** `lash-extensions-84`
- **Views:** 27
- **Tags:** Landing Page, Services, Brand, Fashion, Clean, Minimal, Elegant, Beauty, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

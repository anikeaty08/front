# Local Laundry Service Landing Page Template

A modern landing page template for local laundry and dry-clean businesses, featuring WhatsApp booking, transparent pricing, and pickup/delivery details.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

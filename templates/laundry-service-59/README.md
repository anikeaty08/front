# Laundry Service Landing Page Template

A reusable landing page template for laundry and dry cleaning businesses to showcase services, collect pickup bookings, and build trust with testimonials.

## Project Details
- **Slug:** `laundry-service-59`
- **Views:** 17
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Gradient, Technology, booking form, laundry, dry cleaning
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

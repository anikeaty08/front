# Laundromat Services Landing Page Template

A modern laundromat website template for showcasing commercial and personal wash & fold services with reviews, stories, and strong dual B2B/B2C calls-to-action.

## Project Details
- **Slug:** `laundry-services-72`
- **Views:** 13
- **Tags:** Landing Page, Services, Business, Brand, Clean, Dark, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

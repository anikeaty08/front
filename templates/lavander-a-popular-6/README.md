# Lavandería Popular Service Landing Page Template

Landing page template for lavanderías and laundry services, featuring Spanish copy, pricing tables, contact form, and pickup booking tailored for service businesses.

## Project Details
- **Slug:** `lavander-a-popular-6`
- **Views:** 13
- **Tags:** Landing Page, Services, Business, Laundry, Clean, Colorful, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Lawn Care Services Landing Page Template

A clean, local-service landing page template for lawn mowing, gardening, and property clean-up businesses to showcase services and capture quote requests.

## Project Details
- **Slug:** `lawn-care-services-28`
- **Views:** 33
- **Tags:** Landing Page, Services, Business, Brand, Clean, Colorful, Minimal, Large Type, Local Service, lawn care
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

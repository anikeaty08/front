# Sarkari Job Portal Landing Page Template

A reusable Sarkari job and news portal landing page template for listing government jobs, results, admit cards, answer keys, and community updates.

## Project Details
- **Slug:** `layout-must-look-4`
- **Views:** 111
- **Tags:** Landing Page, Services, Education, Brand, Clean, Colorful, Grid, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Weather Forecast and Details UI

Responsive weather interface showing current conditions, 5-day forecast, and detailed daily weather metrics with dark theme styling.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

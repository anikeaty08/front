# ldl10

A dark, desktop-style launcher template that lets you showcase and organize apps, folders, and media galleries in a grid or list layout for your own web workspace.

## Project Details
- **Slug:** `ldl10`
- **Views:** 20
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Grid, Large Type, Web App, Dashboard, Productivity
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

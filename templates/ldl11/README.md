# ldl11

A dark, iOS-style launcher web app template for organizing, launching, and syncing your favorite tools, folders, and media galleries across devices.

## Project Details
- **Slug:** `ldl11`
- **Views:** 58
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Minimal, Grid, Large Type, Web App, Dashboard

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

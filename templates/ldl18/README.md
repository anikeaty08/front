# ldl18 exp

A dark, futuristic web app template that replicates an OS-style desktop launcher with grid/list views, folders, galleries, and modals—ready to customize for your own workspace.

## Project Details
- **Slug:** `ldl18`
- **Views:** 18
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Minimal, Gradient, Large Type, Web App, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

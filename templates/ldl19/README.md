# ldl19

A dark, iOS-inspired web launcher template for organizing apps, folders, and media galleries with drag-and-drop, notes, and Firebase sync.

## Project Details
- **Slug:** `ldl19`
- **Views:** 65
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Grid, Large Type, Web App Launcher, Dashboard, Productivity
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Ldl23

A dark, futuristic desktop OS-style web app template for creating customizable app launchers, windowed web views, and multi-page workspaces.

## Project Details
- **Slug:** `ldl23`
- **Views:** 36
- **Tags:** Landing Page, Technology, Brand, Dark, Futuristic, Minimal, Web App, OS UI, Dashboard

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# ldl25

A reusable dark, desktop-style productivity dashboard template that mimics an OS launcher with draggable windows, app grid, and Firebase-powered sync.

## Project Details
- **Slug:** `ldl25`
- **Views:** 42
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Grid, Futuristic, Web App, Dashboard, Productivity
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

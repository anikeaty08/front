# Aura Launcher Web App Dashboard Template

Customizable Aura Launcher template that lets you build a minimalist web app dashboard-style homepage with reorderable icons and persistent cloud sync.

## Project Details
- **Slug:** `ldl2a`
- **Views:** 9
- **Tags:** Technology, Landing Page, Brand, Dark, Minimal, Grid, Dashboard, Web App, Productivity, Launcher
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

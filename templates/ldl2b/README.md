# Aura App Launcher Dashboard Template

A dark, minimal app launcher dashboard template for organizing, customizing, and syncing your favorite web apps in one sleek, Firebase-powered interface.

- **Slug:** `ldl2b`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

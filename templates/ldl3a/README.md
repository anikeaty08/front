# Launcher Workspace Web App Template

A reusable Launcher workspace web app template featuring a synced login screen and drag-and-drop app grid for organizing and launching your favorite tools.

## Project Details
- **Slug:** `ldl3a`
- **Views:** 29
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Grid, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

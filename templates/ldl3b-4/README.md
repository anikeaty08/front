# ldl3b-4

A dark, iOS-style desktop app launcher template for organizing, syncing, and opening web apps in a grid or list layout with Firebase-powered auth.

## Project Details
- **Slug:** `ldl3b-4`
- **Views:** 46
- **Tags:** Technology, Landing Page, Brand, Dark, Minimal, Grid, App launcher, Firebase, Dashboard UI, Productivity
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

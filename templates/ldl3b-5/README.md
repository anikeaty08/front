# ldl3b-5

A dark, iOS‑style launcher template for organizing web apps, galleries, and tools into sortable pages—perfect as a reusable productivity dashboard UI.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

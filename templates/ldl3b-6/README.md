# ldl3b-6

A dark, iOS-style web app template for building a customizable live desk launcher with draggable app icons, folders, galleries, and Firebase sync.

- **Views:** 157

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

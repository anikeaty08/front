# ldl3b-8

A dark, futuristic web app template that recreates an iOS-style desktop launcher with draggable apps, folders, galleries, and Firebase sync, ready to customize and reuse.

- **Slug:** `ldl3b-8`
- **Views:** 15

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

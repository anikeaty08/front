# Ldl3b

A dark, minimal web app launcher template for creating a cloud‑synced, Firebase-powered workspace grid with Google and email authentication.

## Project Details
- **Slug:** `ldl3b`
- **Views:** 181
- **Tags:** Technology, Landing Page, Brand, Dark, Minimal, Gradient, Large Type, Clean, Workspace, Firebase
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

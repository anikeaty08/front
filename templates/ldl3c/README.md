# LiveDesk OS Web App Launcher Template

A customizable LiveDesk OS-style web app launcher template that lets users sign in, manage shortcuts, and open favorite tools in a sleek desktop-like interface.

## Project Details
- **Slug:** `ldl3c`
- **Views:** 48
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Gradient, Dashboard, Web App Launcher, Productivity, OS UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

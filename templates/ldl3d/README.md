# Ldl3d

A dark, OS-style desktop launcher template for creating a customizable web app dashboard with draggable windows, app grid, and Google login.

## Project Details
- **Slug:** `ldl3d`
- **Views:** 40
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Desktop OS, Web App Dashboard, Productivity Launcher, Glassmorphism UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

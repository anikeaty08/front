# Interactive UI Elements Playground Template

A reusable template showcasing interactive buttons, toggles, sliders, and animations to prototype and refine modern UI micro-interactions.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

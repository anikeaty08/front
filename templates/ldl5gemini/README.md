# 2.5D Live Desk Launcher UI Template

A dark 2.5D desktop-style launcher UI template for creating customizable, block-based web workspaces with drag-and-drop and cloud sync.

## Project Details
- **Slug:** `ldl5gemini`
- **Views:** 39
- **Tags:** Landing Page, Technology, Brand, Dark, 3D, Grid, Minimal, Workspace, Dashboard, UI Kit
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Isometric Workspace Launcher Web App Template

A customizable isometric workspace launcher template for organizing and launching web apps with grid/list views, pages, and persistent user data.

## Project Details
- **Slug:** `ldl5grok`
- **Views:** 21
- **Tags:** Technology, Landing Page, Brand, 3D, Dark, Minimal, Futuristic, Web App, Dashboard, Workspace
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

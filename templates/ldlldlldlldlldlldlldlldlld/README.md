# Dark iOS-Style App Launcher Template

A dark, experimental iOS-style desktop launcher template for organizing web apps, folders, galleries, and internal tools with Firebase sync and Alpine.js.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Crypto Login Screen Template

A secure crypto account login screen template with dark glassmorphism styling, ideal for wallet or fintech apps to quickly implement a polished auth UI.

## Project Details
- **Slug:** `ledger-live-apps`
- **Views:** 45
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Gradient, Large Type, Clean, Crypto, Authentication
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

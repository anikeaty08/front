# Window Cleaning Services Landing Page Template

A clean, modern landing page template for local window cleaning and exterior home services businesses to showcase services, reviews, and drive quote requests.

## Project Details
- **Slug:** `leeswindowcleaning`
- **Views:** 64
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Brand, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

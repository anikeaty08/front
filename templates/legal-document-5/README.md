# Legal Document Request Dashboard Template

A reusable legal services dashboard template for securely browsing, filtering, and requesting court, compliance, and case-related documents.

## Project Details
- **Slug:** `legal-document-5`
- **Views:** 42
- **Tags:** Landing Page, Services, Technology, Dark, Clean, Minimal, dashboard, legal, admin, judiciary
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

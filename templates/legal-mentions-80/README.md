# Previbiz

Reusable legal, privacy policy, and terms of use page template for SaaS and business websites, ready to adapt to your brand and compliance needs.

## Project Details
- **Slug:** `legal-mentions-80`
- **Views:** 27
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Brand, Legal, SaaS, Privacy Policy, Terms and Conditions

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

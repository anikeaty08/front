# Chiropractic Clinic Landing Page Template

A clean, professional template for chiropractic clinics to showcase services, conditions treated, reviews, and online appointment booking.

## Project Details
- **Slug:** `legaultchiropractic`
- **Views:** 433
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Chiropractic, Medical Practice, Local Business

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# locallead.io

A reusable landing page template for local marketing agencies, consultants, and service businesses to showcase automated lead generation systems and book calls.

## Project Details
- **Slug:** `leon-landing-page`
- **Views:** 560
- **Tags:** Landing Page, Services, Technology, Dark, Gradient, Clean, Minimal, lead generation, local SEO, marketing agency
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

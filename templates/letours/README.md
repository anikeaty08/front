# Youth Travel Landing Page Template

Colorful landing page template for youth travel, kids camps, school trips, and bus rental providers to showcase offers, capture inquiries, and attract counselors.

## Project Details
- **Slug:** `letours`
- **Views:** 34
- **Tags:** Landing Page, Travel, Services, Brand, Colorful, Large Type, Clean, Gradient, Youth travel, Kids camps

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

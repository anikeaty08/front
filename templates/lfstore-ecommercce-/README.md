# LF Store

A modern Professional Market e-commerce landing page template for showcasing tech products with filters, cart, login, and order modals ready for customization.

## Project Details
- **Slug:** `lfstore-ecommercce-`
- **Views:** 8
- **Tags:** E-commerce, Landing Page, Technology, Brand, Clean, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

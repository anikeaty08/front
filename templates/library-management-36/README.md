# Library Management Landing Page Template

A reusable library management template for showcasing digital catalogs, search, borrowing flows, and donation forms for schools and community libraries.

## Project Details
- **Slug:** `library-management-36`
- **Views:** 18
- **Tags:** Landing Page, Education, Technology, Services, Clean, Minimal, Catalog, Library, Donation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

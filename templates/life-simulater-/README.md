# AI Automation Landing Page Template

A reusable landing page template for AI automation platforms to showcase workflows, integrations, pricing, and conversion-focused CTAs.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

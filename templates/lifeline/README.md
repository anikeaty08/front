# Discipline Coaching Landing Page Template

A dark, futuristic landing page template for mindset, coaching, or discipline-building programs to inspire visitors to commit and begin their journey.

## Project Details
- **Slug:** `lifeline`
- **Views:** 18

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

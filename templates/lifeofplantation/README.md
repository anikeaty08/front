# Dental Clinic Landing Page Template

A modern, patient-focused dental clinic landing page template for showcasing services, team, location, and online appointment booking.

## Project Details
- **Slug:** `lifeofplantation`
- **Views:** 12
- **Tags:** Landing Page, Health, Services, Brand, Clean, Gradient, Large Type, Minimal, dentist, dental clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Lifestyle Medicine Landing Page Template

A modern lifestyle medicine landing page template for health clinics and wellness programs to promote integrative care, outcomes, and consultation signups.

## Project Details
- **Slug:** `lifestyle-medicine-95`
- **Views:** 47

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Beauty Salon Landing Page Template

A reusable beauty salon landing page template for spas and women-focused wellness brands to showcase services, galleries, reviews, and booking details.

## Project Details
- **Slug:** `lillies-spa-beauty-salon`
- **Views:** 355
- **Tags:** Landing Page, Services, Health, Fashion, Clean, Minimal, Dark, Brand, beauty salon, spa
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

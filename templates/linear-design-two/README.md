# Design System Style Guide Template

A reusable design system template for documenting colors, typography, components, pricing blocks, and motion guidelines in a modern product UI style guide.

## Project Details
- **Slug:** `linear-design-two`
- **Views:** 59
- **Tags:** Documentation, Brand, Brand Guidelines, Technology, Clean, Dark, Minimal, Large Type, Gradient, UI Kit
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

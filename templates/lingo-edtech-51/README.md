# Lingo EdTech SaaS Landing Page Template

A professional SaaS landing page template designed for language teachers to manage scheduling, payments, and student progress in one place.

## Project Details
- **Slug:** `lingo-edtech-51`
- **Views:** 66
- **Tags:** Landing Page, Technology, Education, Services, Clean, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

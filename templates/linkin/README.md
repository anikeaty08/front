# Chris Linx Personal Bio Link Template

A clean and minimal Link Tree style template for creators and entrepreneurs to showcase social links, portfolio items, and integrated newsletters.

## Project Details
- **Slug:** `linkin`
- **Views:** 9
- **Tags:** Landing Page, Portfolio, Minimal, Clean, Technology, Graphic Design, Style, Blog
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# linxm  Portfolio Website Template

A dark, minimal portfolio website template for multidisciplinary designers to showcase UI/UX projects, presentation decks, and generative AI art.

## Project Details
- **Slug:** `linxmportfolio10`
- **Views:** 7
- **Tags:** Portfolio, Landing Page, Art & Design, Minimal, Dark, Clean, Technology, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

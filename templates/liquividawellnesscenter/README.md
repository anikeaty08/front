# Medical Spa Wellness Landing Page Template

A modern Liquivida-style medical spa and IV wellness center landing page template for clinics to showcase services, locations, FAQs, and appointment requests.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

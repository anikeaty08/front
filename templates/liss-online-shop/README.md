# Party Favor Product Page Template

A reusable e-commerce product page template for selling party favor kits, gift bundles, and festive merchandise with gallery, reviews, and purchase CTAs.

## Project Details
- **Slug:** `liss-online-shop`
- **Views:** 37
- **Tags:** E-commerce, Landing Page, Colorful, Clean, Brand, product page, party favors, gift set, retail
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

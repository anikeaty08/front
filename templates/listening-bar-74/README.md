# Listening Bar Restaurant Landing Page Template

A dark, atmospheric landing page template for listening bars, wine bars, and restaurants to showcase menus, music collections, gallery, and DJ schedule.

## Project Details
- **Slug:** `listening-bar-74`
- **Views:** 31
- **Tags:** Landing Page, Food, Brand, Dark, Minimal, Large Type, Entertainment, Restaurant, Bar, Music
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

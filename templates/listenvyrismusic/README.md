# LEGACY Music Artist Website Template

A dark, high-impact music artist website template for promoting albums, tours, videos, and merch with a built-in shop and newsletter capture.

## Project Details
- **Slug:** `listenvyrismusic`
- **Views:** 24
- **Tags:** Landing Page, E-commerce, Entertainment, Brand, Dark, Clean, Large Type, Gradient, Music, Artist
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

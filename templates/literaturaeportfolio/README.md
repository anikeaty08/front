# Literatura e Portfolio

A reusable template for writers, journalists, and creative freelancers to showcase essays, chronicles, visual work, and collaboration services.

## Project Details
- **Slug:** `literaturaeportfolio`
- **Views:** 165
- **Tags:** Portfolio, Blog, Brand, Services, Minimal, Clean, Editorial, Writer, Photography
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

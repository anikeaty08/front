# Live Auction Overlay UI Template

A reusable live auction overlay template for streaming vehicle auctions with real-time bids, timers, and next-lot previews, ready to plug into your platform.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

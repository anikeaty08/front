# Live Music Venue and Event Calendar Template

A high-impact, brutalist-style template designed for concert halls and music venues to showcase event schedules and ticket sales.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

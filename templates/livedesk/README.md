# livedesk

An experimental template for building an iOS-style web app launcher with draggable grids, folders, galleries, and internal windows, ready to customize for your projects.

## Project Details
- **Slug:** `livedesk`
- **Views:** 123
- **Tags:** Technology, Landing Page, Brand, Dark, Futuristic, Grid, Minimal, Large Type, Web App, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# livedesk2

A dark, futuristic desktop OS-style web app template with draggable windows, app grid, and Firebase auth—ready to reuse and customize for your own projects.

## Project Details
- **Slug:** `livedesk2`
- **Views:** 38
- **Tags:** Landing Page, Technology, Brand, Dark, Futuristic, Grid, Minimal, Web App, Desktop UI, OS Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

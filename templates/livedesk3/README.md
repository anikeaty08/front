# livedesk3

A dark, futuristic OS-style web app template that lets users organize apps, widgets, and pages in draggable windows and grids—perfect as a customizable UI shell.

## Project Details
- **Slug:** `livedesk3`
- **Views:** 22
- **Tags:** Technology, Landing Page, Brand, Dark, Futuristic, Grid, Large Type, Web App, OS UI, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# livedesk4

A dark, futuristic OS-style web app template that lets users create, organize, and launch app shortcuts in draggable windows—ready to customize for your own product.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# livedesk6

A dark, futuristic OS-style landing page template that lets you showcase an interactive desktop, app grid, windows, and auth-driven workspace experience.

## Project Details
- **Slug:** `livedesk6`
- **Views:** 5
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Futuristic, Large Type, Interactive, Web App
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

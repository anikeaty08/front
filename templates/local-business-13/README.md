# Local Business Web Design Landing Page Template

A reusable landing page template for web design agencies serving local businesses like cafes, restaurants, and clinics with SEO-focused conversion sections.

## Project Details
- **Slug:** `local-business-13`
- **Views:** 37

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

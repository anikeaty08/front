# Social Enterprise Marketing Landing Page Template

A reusable landing page template for social enterprise marketing services that helps local businesses showcase AI-powered packages, trust signals, and consultation CTAs.

## Project Details
- **Slug:** `local-business-15`
- **Views:** 41
- **Tags:** Landing Page, Services, Technology, Social, Clean, Minimal, Brand, pricing, local business

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Local Business SaaS Landing Page Template

A clean, conversion-focused landing page template for local business and home service SaaS platforms to capture leads, promote features, and drive free trials.

## Project Details
- **Slug:** `local-business-27`
- **Views:** 17
- **Tags:** Landing Page, Business, Services, Technology, Brand, Clean, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

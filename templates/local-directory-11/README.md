# Local Marketplace Landing Page Template

A reusable landing page template for promoting a local business directory, marketplace, and professional network platform for communities and merchants.

## Project Details
- **Slug:** `local-directory-11`
- **Views:** 13
- **Tags:** Landing Page, E-commerce, Services, Technology, Clean, Minimal, Marketplace, Local Directory, Community
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

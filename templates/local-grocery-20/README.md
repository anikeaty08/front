# Local Grocery Landing Page Template

A clean, multi-section landing page template for neighborhood groceries and mini-markets to showcase products, promotions, and contact details online.

## Project Details
- **Slug:** `local-grocery-20`
- **Views:** 20
- **Tags:** Landing Page, Food, Business, Brand, Clean, Colorful, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Local Home Services Landing Page Template

A clean, trust-focused landing page template for local home repair and home services businesses to showcase plumbing, electrical, and HVAC offerings with reviews and quotes.

## Project Details
- **Slug:** `local-home-services-32`
- **Views:** 14
- **Tags:** Landing Page, Services, Business, Brand, Clean, Minimal, Large Type, Technology, Home Services, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# LocalStalls Event Management Dashboard Template

A modern LocalStalls dashboard template for managing markets, stall applications, bookings, payments, and reports, ready to customize for your events platform.

## Project Details
- **Slug:** `local-market-90`
- **Views:** 11

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

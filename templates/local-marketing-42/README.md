# Local Marketing Service Landing Page Template

A high-converting landing page template for the Local Takeover Method, designed to sell a 30-day local marketing system install to established local businesses.

## Project Details
- **Slug:** `local-marketing-42`
- **Views:** 101
- **Tags:** Landing Page, Services, Business, Brand, Clean, Dark, Gradient, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Local Marketplace Website Template

A reusable local marketplace template for listing, browsing, and posting ads across categories like real estate, vehicles, electronics, and services.

## Project Details
- **Slug:** `local-marketplac-61`
- **Views:** 65
- **Tags:** Marketplace, E-commerce, Services, Real Estate, Fashion, Landing Page, Dark, Clean, Minimal, Grid
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

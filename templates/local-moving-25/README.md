# Local Moving Services Landing Page Template

A clean, modern landing page template for local moving and cargo companies to showcase services, routes, reviews, and quotes in one high-converting layout.

## Project Details
- **Slug:** `local-moving-25`
- **Views:** 44
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Technology, Moving, Local Business, Cargo
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

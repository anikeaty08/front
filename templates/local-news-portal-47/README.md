# Local News Portal Template

A reusable local news portal template for regional publishers, featuring breaking alerts, article feeds, video content, community widgets, and reader tip submissions.

## Project Details
- **Slug:** `local-news-portal-47`
- **Views:** 29
- **Tags:** Landing Page, Blog, News, Media, Technology, Clean, Minimal, Dark, Grid
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

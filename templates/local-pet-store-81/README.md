# Local Pet Store Website Template

A reusable template for a local pet store website featuring supplies, grooming, live animals, and pet care guidance for neighborhood pet owners.

## Project Details
- **Slug:** `local-pet-store-81`
- **Views:** 42
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Pet Store, Grooming, Local Business, Small Business, Animal Care
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

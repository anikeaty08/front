# live oak pharmacy

A clean, modern local pharmacy landing page template for independent drugstores to showcase services, mobile app, delivery, and contact details.

## Project Details
- **Slug:** `local-pharmacy-27`
- **Views:** 49
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, Large Type, Technology, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

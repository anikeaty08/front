# Local Plumbing Services Landing Page Template

A clean, mobile-ready landing page template for local plumbing and gas fitting businesses to showcase services, service area, and contact details.

## Project Details
- **Slug:** `local-plumbing-59`
- **Views:** 117
- **Tags:** Landing Page, Services, Business, Brand, Clean, Minimal, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Local Services Marketplace Landing Page Template

A reusable landing page template for local services marketplaces that helps connect trusted experts with clients through clear CTAs, trust cues, and waitlist signup.

## Project Details
- **Slug:** `local-services-10`
- **Views:** 85
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Gradient, marketplace, local services, waitlist
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Typography Tool Landing Page Template

A modern dark-mode landing page template for promoting a font fallback tuning tool or typography SaaS, ready to customize for your own product.

- **Slug:** `localize-type-for-design`
- **Views:** 392

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

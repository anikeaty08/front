# LocalStalls Mobile App Landing Page Template

A reusable LocalStalls-style mobile app landing page template for discovering local markets, fairs, and festivals with search, filters, and event listings.

## Project Details
- **Slug:** `localstall-mobile-93`
- **Views:** 35
- **Tags:** Landing Page, Services, Travel, Clean, Minimal, Mobile app, Events, Markets, Festivals, Local discovery
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

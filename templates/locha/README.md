# Professional Resume Landing Page Template

A clean, modern resume landing page template for showcasing professional experience, education, skills, and contact details in a single personal profile site.

## Project Details
- **Slug:** `locha`
- **Views:** 16
- **Tags:** Landing Page, Portfolio, Clean, Minimal, Large Type, Brand, Resume, Art & Design, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Blockchain Login Landing Page Template

A reusable landing page template for secure blockchain login and crypto wallet access experiences, featuring dark crypto styling and verification UI.

## Project Details
- **Slug:** `login-blockchain`
- **Views:** 99
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Gradient, Crypto, Security, Web3
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

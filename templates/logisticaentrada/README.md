# Logistics Data Capture Form Template

A modern template for logistics teams to register drivers, vehicles, and cargo details, ready to reuse as a transport data collection and record-keeping UI.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Logistics Admin Dashboard Template

A modern logistics admin dashboard template for managing Vietnamese transport orders, shipments, and status tracking across road and sea operations.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Design Education Landing Page Template

A reusable landing page template for online design education, mentorship, and learning platforms promoting courses, features, pricing, FAQs, and conversion CTAs.

## Project Details
- **Slug:** `logistics-automation-44`
- **Views:** 42
- **Tags:** Landing Page, Education, Technology, Clean, Minimal, Brand, course platform, mentorship, pricing, FAQ

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

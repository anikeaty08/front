# Logistics Control Dashboard Template

A reusable logistics dashboard template for managing shipments, warehouse transfers, package assignments, and QR/PDF manifests from one control center.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

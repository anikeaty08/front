# Logistics Corporate Presentation Template

A sleek horizontal-slide template for logistics and transport companies to present their 2025 corporate profile, services, fleet, offices, and strategic clients.

## Project Details
- **Slug:** `logistics-corporate-22`
- **Views:** 15
- **Tags:** Business, Brand, Landing Page, Services, Technology, Clean, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

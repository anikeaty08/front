# Logistics Company Presentation Template

A modern corporate presentation template for logistics and transport companies to showcase services, coverage, fleet, and certifications.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

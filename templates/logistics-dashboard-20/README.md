# Logistics Dashboard Template

A reusable logistics dashboard template for tracking cargos, assigning packages, managing weight-based pricing, and coordinating client pickup workflows.

## Project Details
- **Slug:** `logistics-dashboard-20`
- **Views:** 55
- **Tags:** Technology, Services, Dashboard, Clean, Minimal, Logistics, Admin, Operations
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Logistics Dashboard Template

A reusable dashboard template for parcel hubs and logistics teams to track inventory, withdrawals, overdue stock, and agent access in one clean interface.

## Project Details
- **Slug:** `logistics-dashboard-75`
- **Views:** 26
- **Tags:** Technology, Services, Dashboard, Landing Page, Clean, Minimal, Business, Logistics

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

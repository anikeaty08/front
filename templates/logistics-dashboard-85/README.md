# Logistics Dashboard Template

A reusable logistics dashboard template for managing cargo lots, package assignment, weight reconciliation, client wallet actions, and dispatch workflows.

- **Slug:** `logistics-dashboard-85`
- **Views:** 45

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Logistics Dashboard Template

A reusable logistics operations dashboard template for managing cargo lots, shipment assignments, warehouse status, and exception handling in one clean UI.

## Project Details
- **Slug:** `logistics-dashboard-98`
- **Views:** 26
- **Tags:** Technology, Services, Dashboard, Admin, Logistics, Clean, Minimal, Landing Page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

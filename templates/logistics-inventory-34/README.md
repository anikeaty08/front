# Inventory Management App Template

A reusable mobile app template for tracking cargo inventory, shipment status, and warehouse actions with a clean logistics-focused dashboard UI.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

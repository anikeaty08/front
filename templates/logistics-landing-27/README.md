# Logistics Service Landing Page Template

A modern logistics landing page template for Japan-to-Thailand shipping services, featuring multi-section SPA navigation, pricing tables, and a cost calculator UI.

- **Slug:** `logistics-landing-27`
- **Views:** 30

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

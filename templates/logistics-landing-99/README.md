# Logistics Landing Page Template

A reusable landing page template for freight and trucking companies to showcase transport services, build trust, and capture shipping quote requests.

## Project Details
- **Slug:** `logistics-landing-99`
- **Views:** 133
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Grid, Technology, logistics, trucking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Logistics & Transport Landing Page Template

Modern Spanish-language logistics and transport landing page template for Chilean freight, last-mile, and moving services with national coverage and quote form.

## Project Details
- **Slug:** `logistics-transport-28`
- **Views:** 4
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Large Type, Transportation, Logistics
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

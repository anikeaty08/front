# Logotherapy Institute Landing Page Template

A reusable landing page template for logotherapy institutes, counseling centers, and psychology education programs to present philosophy, courses, and services.

## Project Details
- **Slug:** `logotherap-institute-56`
- **Views:** 84
- **Tags:** Landing Page, Health, Education, Services, Clean, Minimal, Brand, counseling, psychology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

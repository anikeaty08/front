# Health Quiz Landing Page Template

A reusable landing page template for functional medicine clinics to promote a symptom quiz, build trust, and convert visitors into assessment calls.

## Project Details
- **Slug:** `longefunctional-medicine-5`
- **Views:** 25
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Brand, quiz funnel, testimonials, functional medicine
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

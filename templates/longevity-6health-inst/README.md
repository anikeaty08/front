# Health Consultation Landing Page Template

A reusable healthcare landing page template for functional medicine clinics to showcase services, patient testimonials, membership tiers, and consultation booking.

## Project Details
- **Slug:** `longevity-6health-inst`
- **Views:** 41
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Testimonials, Medical, Functional Medicine
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

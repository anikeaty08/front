# AI Automation Platform Landing Page Template

A high-converting, dark-mode template for AI workflow and automation platforms to showcase features, pricing, and customer stories with an app-style UI.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

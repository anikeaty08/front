# Unisex Salon 

A modern unisex salon website template with 3D hero, online booking, offers, gallery, and admin dashboard for managing services and appointments.

## Project Details
- **Slug:** `lorealprofessionalsalon`
- **Views:** 4
- **Tags:** Landing Page, Services, Brand, 3D, Dark, Gradient, Animated, Minimal, Beauty Salon, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

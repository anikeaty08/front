# LoveMeter Compatibility Landing Page Template

A playful LoveMeter compatibility calculator template for romantic or entertainment apps, letting users analyze love matches with animated results, history, and proposal mode.

## Project Details
- **Slug:** `love-compatibil-22`
- **Views:** 12

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

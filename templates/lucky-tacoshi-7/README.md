# Fusion Restaurant Landing Page Template

A bold, neon-styled restaurant landing page template for Japanese–Mexican fusion or modern street food brands, featuring menu highlights, reviews, and online ordering.

## Project Details
- **Slug:** `lucky-tacoshi-7`
- **Views:** 9
- **Tags:** Landing Page, Food, Brand, Colorful, Dark, Minimal, Large Type, Restaurant, Street Food, Fusion
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

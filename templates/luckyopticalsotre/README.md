# Lucky Optical

A modern, mobile-friendly landing page template for local optical stores to showcase eye exams, spectacles, testimonials, and contact details.

## Project Details
- **Slug:** `luckyopticalsotre`
- **Views:** 22
- **Tags:** Landing Page, Services, Health, Brand, Clean, Minimal, Gradient, Large Type, Optical, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

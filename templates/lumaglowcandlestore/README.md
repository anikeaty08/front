# LumaGlow Candle E-commerce Landing Page Template

A refined, sustainable candle shop landing page template for showcasing hand-poured products, storytelling, and email capture for modern DTC brands.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Lumière Restaurant Reservation Landing Page Template

A dark, modern restaurant landing page template with a built-in reservation and booking management system for upscale dining experiences.

- **Slug:** `lumi-re-restaurant-87`
- **Views:** 14

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

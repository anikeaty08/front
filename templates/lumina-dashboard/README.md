# Lumina Real Estate Dashboard Template

A reusable dashboard template designed for real estate professionals to track property listings, sales statistics, and client messages effectively.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

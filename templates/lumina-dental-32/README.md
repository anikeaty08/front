# Lumina Dental Clinic Landing Page Template

A modern Lumina Dental landing page template for dentistry practices to showcase services, patient reviews, and book appointments with a clean, trust-building design.

## Project Details
- **Slug:** `lumina-dental-32`
- **Views:** 11
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# MERN E-commerce Storefront Template

A modern MERN E-commerce UI template featuring product listing, cart, auth, and admin inventory views, ready to adapt for your online store.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Lusine After Christmas Sale E-commerce Template

A premium e-commerce landing page template for furniture brands running seasonal After Christmas Sale campaigns, ready to customize and reuse.

- **Slug:** `lusine-cozyhome`
- **Views:** 36
- **Tags:** E-commerce, Landing Page, Brand, Clean, Minimal, Large Type, Interior Design, Furniture, Seasonal Sale, Home Decor

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

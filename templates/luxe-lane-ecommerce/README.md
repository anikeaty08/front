# AURA Minimalist E-commerce Template

A clean, minimalist e-commerce landing page template designed for lifestyle brands, fashion retailers, and high-end essential goods.

## Project Details
- **Slug:** `luxe-lane-ecommerce`
- **Views:** 29
- **Tags:** E-commerce, Fashion, Clean, Minimal, Landing Page, Lifestyle, Grid, Style

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Luxury Bakery Landing Page Template

A refined landing page template for artisan bakeries and pâtisseries to showcase signature products, craftsmanship, location, and in-store experience.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

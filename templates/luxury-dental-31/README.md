# Luxury Dental Clinic Landing Page Template

A premium landing page template for boutique dental and orthodontic clinics to showcase services, team, transformations, and capture appointment requests in style.

## Project Details
- **Slug:** `luxury-dental-31`
- **Views:** 35
- **Tags:** Landing Page, Health, Services, Brand, Dark, Gradient, Clean, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

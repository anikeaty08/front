# Luxury Event Planner Landing Page Template

A polished, dark-mode landing page template for bespoke event planning agencies to showcase services, portfolio, process, and capture high-intent inquiries.

## Project Details
- **Slug:** `luxury-event-18`
- **Views:** 16

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

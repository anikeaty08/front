# Luxury Hotel Landing Page Template

A premium Chaika Club Hotel landing page template for boutique hotels and resorts, featuring booking, rooms, spa, restaurant, FAQ, and contact sections.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

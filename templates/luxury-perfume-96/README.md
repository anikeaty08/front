# Luxury Perfume Landing Page Template

A dark, luxurious perfume product landing page template for showcasing a single hero fragrance collection with elegant visuals and clear purchase CTAs.

## Project Details
- **Slug:** `luxury-perfume-96`
- **Views:** 23
- **Tags:** E-commerce, Landing Page, Brand, Clean, Dark, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

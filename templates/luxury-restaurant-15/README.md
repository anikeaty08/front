# Bahadur Restaurant Landing Page Template

A luxury fast food restaurant landing page template featuring hero, story, menu, gallery, and contact sections for premium dining brands.

## Project Details
- **Slug:** `luxury-restaurant-15`
- **Views:** 41
- **Tags:** Landing Page, Food, Services, Brand, Dark, Clean, Large Type, Gradient, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Luxury Restaurant Landing Page Template

A reusable luxury restaurant landing page template for showcasing fine dining menus, ambiance galleries, and table reservations with premium styling.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

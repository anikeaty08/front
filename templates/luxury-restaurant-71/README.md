# Luxury Restaurant Landing Page Template

A reusable luxury restaurant template for premium dining venues to showcase menus, chef stories, galleries, reviews, and table reservations.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Luxury Restaurant Landing Page Template

A dark, luxury restaurant landing page template for fine dining brands featuring hero, menu, offers, gallery, reviews, online ordering, and reservations.

## Project Details
- **Slug:** `luxury-restaurant-78`
- **Views:** 27
- **Tags:** Landing Page, Food, Brand, Clean, Dark, Large Type, Gradient, Minimal, E-commerce, Restaurant
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

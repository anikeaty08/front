# Luxury Travel SaaS Landing Page Template

A dark, luxury-styled SaaS landing page template for promoting holiday packages, private jets, and travel discounts through a modern booking portal.

## Project Details
- **Slug:** `luxury-travel-4`
- **Views:** 10
- **Tags:** Landing Page, Travel, Technology, Brand, Dark, Gradient, Clean, Large Type, Holiday, Private Jet
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Masonry Services Landing Page Template

A modern masonry and brick restoration landing page template for local contractors to showcase services, expertise, and capture free quote requests.

## Project Details
- **Slug:** `ma-onnerie-services-3`
- **Views:** 24
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Wellness Promotional Email Template

A reusable email template for wellness and lifestyle brands to promote seasonal offers, featured products, and sitewide discount campaigns.

## Project Details
- **Slug:** `mabel-celebrate-spring-2`
- **Views:** 25
- **Tags:** E-commerce, Health, Landing Page, Brand, Clean, Minimal, Fashion, promotional email, wellness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

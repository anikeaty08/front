# Wellness Promotional Email Template

A reusable email template for wellness and lifestyle brands to promote seasonal discounts, featured products, and sitewide offers with an editorial look.

## Project Details
- **Slug:** `mabel-celebrate-spring`
- **Views:** 41
- **Tags:** E-commerce, Health, Brand, Clean, Minimal, Fashion, Landing Page, email marketing, promotional campaign
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

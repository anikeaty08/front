# Italian Restaurant Landing Page Template

A refined Italian restaurant landing page template designed for osterias and eateries to showcase menus, reservations, reviews, and location in one elegant layout.

## Project Details
- **Slug:** `maccheroni-republic`
- **Views:** 614
- **Tags:** Landing Page, Food, Restaurant, Clean, Minimal, Brand, Large Type, Gradient, Portfolio, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

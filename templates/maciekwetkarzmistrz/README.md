# Fishing Tournament Landing Page Template

A modern, dark-themed landing page template for promoting fishing or sports tournaments, complete with hero, gallery, rules, and registration form sections.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

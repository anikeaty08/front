# macOS Desktop UI Landing Page Template

A macOS desktop-style landing page template that recreates the Finder menu bar, desktop icons, and animated dock for product demos, portfolios, or apps.

- **Slug:** `macos-style-developer-39`
- **Views:** 677

- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

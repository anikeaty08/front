# macOS Portfolio Template

A reusable portfolio template styled like a macOS desktop, built to showcase a designer or frontend specialist’s bio, projects, stack, and contact CTA.

## Project Details
- **Slug:** `macos-style-portfolio-58`
- **Views:** 75

- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

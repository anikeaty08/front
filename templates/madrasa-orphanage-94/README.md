# Islamic Education Landing Page Template

A reusable landing page template for madrasas, orphan care institutions, and Islamic schools with admissions, donations, and parent portal sections.

## Project Details
- **Slug:** `madrasa-orphanage-94`
- **Views:** 34
- **Tags:** Landing Page, Education, Religious, Non-profit, Services, Clean, Minimal, Technology, donation, parent portal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

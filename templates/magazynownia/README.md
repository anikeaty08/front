# Self Storage Landing Page Template

Modern self storage landing page template for promoting secure 24/7 container warehouses, complete with pricing grid, calculator, FAQs, and contact form.

## Project Details
- **Slug:** `magazynownia`
- **Views:** 15
- **Tags:** Landing Page, Services, Business, Brand, Clean, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# MAGIC PATH

A reusable dark E-commerce admin dashboard template for managing products, orders, customers, and store settings with modern analytics and customization tools.

## Project Details
- **Slug:** `magicpathstores`
- **Views:** 9
- **Tags:** E-commerce, Technology, Landing Page, Brand, Dark, Clean, Grid, Large Type, Minimal, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Optical Store Landing Page Template

A modern optical store landing page template for showcasing eyewear collections, lens services, and contact details for local eye-care businesses.

## Project Details
- **Slug:** `mahavir-optics1`
- **Views:** 25
- **Tags:** Landing Page, E-commerce, Services, Brand, Clean, Minimal, Large Type, Optical Store, Eyewear, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Clinic Landing Page Template

A clean, modern dental clinic landing page template for showcasing services, team, FAQs, and online appointment requests for local practices.

## Project Details
- **Slug:** `mahwahprimedental`
- **Views:** 20
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, Large Type, Technology, Medical, Dentist
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

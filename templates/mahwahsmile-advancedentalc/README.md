# Mahwah Smile Website

A modern dental clinic landing page template for promoting general, cosmetic, and specialty dentistry services with booking and testimonials sections.

## Project Details
- **Slug:** `mahwahsmile-advancedentalc`
- **Views:** 31
- **Tags:** Landing Page, Services, Health, Brand, Clean, Minimal, Large Type, Technology, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

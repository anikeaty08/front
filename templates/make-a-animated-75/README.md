# Audio Reactive Visualizer Template

A cinematic audio-reactive visualizer UI template for microphone-based or simulated sound analysis experiences in futuristic landing pages and apps.

## Project Details
- **Slug:** `make-a-animated-75`
- **Views:** 430
- **Tags:** Landing Page, Technology, Brand, Futuristic, Dark, Animated, Minimal, Large Type, 3D

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

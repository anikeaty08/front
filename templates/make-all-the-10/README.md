# Alumni Network Landing Page Template

A modern Alumni Connect landing page template for universities to showcase directories, careers, events, mentorship, and giving in one unified hub.

## Project Details
- **Slug:** `make-all-the-10`
- **Views:** 55
- **Tags:** Landing Page, Education, Community, Brand, Clean, Dark, Gradient, Large Type, Technology, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Clinic Landing Page Template

Elegant Spanish-language dental clinic landing page template for showcasing services, team, testimonials, and contact to book appointments online.

## Project Details
- **Slug:** `make-it-more-28`
- **Views:** 21
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Gradient, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

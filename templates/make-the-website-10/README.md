# Electric Vehicle Brand Landing Page Template

A premium electric vehicle brand landing page template inspired by modern automotive sites, ideal for showcasing EV models, energy products, and sustainability stories.

## Project Details
- **Slug:** `make-the-website-10`
- **Views:** 10
- **Tags:** Landing Page, Brand, Technology, Clean, Minimal, Gradient, Large Type, Automotive, Electric Vehicles, Futuristic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

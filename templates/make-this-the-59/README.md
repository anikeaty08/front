# Trading Analytics Landing Page Template

A high-converting dark-mode landing page template for a trading analytics and journaling SaaS like MyTradeLog, built to showcase features, pricing, and CTAs.

## Project Details
- **Slug:** `make-this-the-59`
- **Views:** 144

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

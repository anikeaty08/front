# Preschool AI Material Landing Page Template

A modern, multilingual landing page template for showcasing an AI generator that creates preschool lunch menus, timetables, announcements, and educational materials.

## Project Details
- **Slug:** `mamchoila-mateiral`
- **Views:** 16
- **Tags:** Landing Page, Education, Technology, Clean, Colorful, Minimal, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

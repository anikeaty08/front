# 3D Streetwear E-commerce Landing Page Template

A dark, 3D-styled streetwear e-commerce landing page template for showcasing premium collections with product grid, filters, and modern CTAs.

## Project Details
- **Slug:** `manfashionforworld`
- **Views:** 20
- **Tags:** E-commerce, Fashion, Landing Page, Brand, 3D, Dark, Minimal, Large Type, Gradient, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

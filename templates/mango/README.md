# Streaming Channel Dashboard UI Template

A dark, modern streaming channel dashboard UI template for video creators to showcase content, manage subscribers, and preview a YouTube-style profile layout.

## Project Details
- **Slug:** `mango`
- **Views:** 2140
- **Tags:** Landing Page, Technology, Brand, Dark, Clean, Colorful, Large Type, Gradient, Dashboard, Streaming
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

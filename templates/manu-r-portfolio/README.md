# Manu R 

A clean, data-driven personal portfolio template for digital marketing analysts to showcase SEO skills, projects, and experience with built-in contact form.

## Project Details
- **Slug:** `manu-r-portfolio`
- **Views:** 40
- **Tags:** Landing Page, Portfolio, Business, Brand, Clean, Minimal, Large Type, Technology, Resume
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

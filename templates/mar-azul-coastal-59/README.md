# Mar Azul Glamping and Resort Template

A high-end hospitality and travel website template designed for camping mar azul in costa rica, mal Pais. The only images that should be shown are that found on google from reviews of camping mar azul via reviews on images, or high quality images of mal pais


## Project Details
- **Slug:** `mar-azul-coastal-59`
- **Views:** 34
- **Tags:** Travel, Landing Page, Services, Clean, Minimal, Dark
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

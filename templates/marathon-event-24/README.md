# Mountain Marathon Event Landing Page Template

A modern, event-focused landing page template for mountain marathons with registration, countdown, eco mission, FAQ, sponsors, and payment flow.

## Project Details
- **Slug:** `marathon-event-24`
- **Views:** 24
- **Tags:** Landing Page, Event, Sports, Marathon, Clean, Dark, Gradient, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

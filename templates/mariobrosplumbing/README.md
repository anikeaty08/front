# Mario Bros Plumbing

A professional plumbing services template for local contractors to showcase repairs, installations, testimonials, and drive calls and estimate requests.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

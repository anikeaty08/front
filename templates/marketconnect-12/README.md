# Local Grocery E-commerce Landing Page Template

A modern e-commerce landing page template for selling fresh local food online with product grid, filters, cart drawer, and checkout experience.

## Project Details
- **Slug:** `marketconnect-12`
- **Views:** 32
- **Tags:** E-commerce, Food, Landing Page, Brand, Clean, Minimal, Grid, Large Type, Checkout, Grocery
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

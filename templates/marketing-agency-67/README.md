# Marketing Agency Collective Landing Page Template

A reusable landing page template for marketing collectives, agencies, and growth consultancies showcasing data, automation, SEO, and CRM services.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Agency Blog Website Template

A reusable blog website template for creative agencies to publish marketing, technology, and branding content while growing leads through newsletter signups.

## Project Details
- **Slug:** `marketing-agency-71`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Agency Project Feedback Form Template

A clean, modern template for agencies to collect project evaluations, service feedback, and client insights with an NPS-style rating form.

## Project Details
- **Slug:** `marketing-agency-feedback`
- **Views:** 14
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Agency, Feedback Form, Client Survey, NPS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

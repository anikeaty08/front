# Marketing & Retail Portfolio Template

A modern Spanish-language portfolio template for marketing, retail and visual merchandising professionals to showcase experience, skills and contact details.

## Project Details
- **Slug:** `marketing-retail-12`
- **Views:** 257
- **Tags:** Portfolio, Resume, Art & Design, Clean, Minimal, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

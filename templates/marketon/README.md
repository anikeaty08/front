# Marketing School Course Landing Page Template

A modern marketing course landing page template for online schools to showcase curriculum, benefits, pricing, and lead-capture forms in a clean layout.

## Project Details
- **Slug:** `marketon`
- **Views:** 26
- **Tags:** Landing Page, Education, Services, Brand, Clean, Minimal, Large Type, Technology, Marketing Course, Online School
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Marketplace Exit E-commerce Landing Page Template

Conversion-focused landing page template for Russian e-commerce brands to pitch moving sales from marketplaces to an owned site and booking a profit audit.

## Project Details
- **Slug:** `marketplac-exit-75`
- **Views:** 22

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

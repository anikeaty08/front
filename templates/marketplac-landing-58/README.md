# Marketplace Landing Page Template

A reusable marketplace template for launching a buyer-and-seller platform with storefronts, product listings, secure checkout, and seller dashboards.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

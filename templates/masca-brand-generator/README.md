# AI Brand Generator Web App Template

A dark, modern AI brand generator web app template for creating and previewing brand identity systems, ready to customize for your own projects.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

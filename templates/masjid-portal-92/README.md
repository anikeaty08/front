# Masjid Portal Funds Distribution Dashboard Template

A reusable admin dashboard template for managing masjid charity distributions, tracking Zakat, Sadaqah, and food aid records with filters and status controls.

## Project Details
- **Slug:** `masjid-portal-92`
- **Views:** 25
- **Tags:** Landing Page, Services, Religious, Clean, Minimal, Brand, Dashboard, Admin, Charity, Zakat
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

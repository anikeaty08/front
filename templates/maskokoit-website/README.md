# Digital Agency Landing Page Template

A modern digital agency landing page template featuring hero, services, projects, and contact sections for high-end web and app studios.

- **Slug:** `maskokoit-website`
- **Views:** 1185

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Wellness Massage Landing Page Template

A reusable landing page template for promoting at-home wellness massage services, helping solo practitioners present treatments, build trust, and drive bookings.

## Project Details
- **Slug:** `massage-services-40`
- **Views:** 40
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Elegant, Wellness, Massage
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

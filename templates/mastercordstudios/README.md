# Discord Developer Landing Page Template

A reusable landing page template for Discord server developers and community consultants to showcase services, pricing, and lead capture.

## Project Details
- **Slug:** `mastercordstudios`
- **Views:** 105
- **Tags:** Landing Page, Services, Technology, Dark, Clean, Minimal, Animated, portfolio, discord, freelancer
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# MatchOrg Sports Club Landing Page Template

Reusable landing page template for MatchOrg, a sports club match-organization platform, featuring hero, features, pricing, stats, and contact sections.

## Project Details
- **Slug:** `matchorgtrameeee`
- **Views:** 21
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Large Type, SaaS, sports club, match management
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

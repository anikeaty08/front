# Matt Renocation - Couvreur dans le Tarn

A reusable landing page template for roofing and home renovation businesses to showcase services, projects, testimonials, and capture quote requests.

## Project Details
- **Slug:** `matt-renovation-tarn`
- **Views:** 35
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Home services, Roofing, Renovation, Local business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mattijs Kuiper

Clean photography portfolio landing page template for showcasing work, presenting services and rates, and capturing client inquiries via a contact form.

## Project Details
- **Slug:** `mattijskuiper`
- **Views:** 15
- **Tags:** Landing Page, Portfolio, Art & Design, Minimal, Clean, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

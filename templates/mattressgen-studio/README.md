# MattressGen Studio Web App Template

MattressGen Studio is a reusable web app template for showcasing AI-powered mattress design ideation, photorealistic renders, and interactive concept generation.

## Project Details
- **Slug:** `mattressgen-studio`
- **Views:** 28
- **Tags:** Landing Page, Technology, Clean, Minimal, Gradient, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Video Generation Landing Page Template

A reusable landing page template for showcasing AI video generation tools, features, galleries, and CTAs with a cinematic futuristic design.

## Project Details
- **Slug:** `maze-ai-video`
- **Views:** 66

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

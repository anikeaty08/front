# MBBS Abroad Education Landing for AV Global Overseas

A reusable template for education consultants to showcase MBBS in Russia programs for Indian students, including fees, eligibility, universities, and admissions details.

## Project Details
- **Slug:** `mbbs-in-russia`
- **Views:** 29
- **Tags:** Landing Page, Education, Services, Brand, Clean, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

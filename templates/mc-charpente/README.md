# MC Charpente

A reusable landing page template for local carpenters and renovation businesses to showcase services, projects, testimonials, and capture quote requests.

## Project Details
- **Slug:** `mc-charpente`
- **Views:** 11
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Dark, home services, carpentry, renovation, local business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

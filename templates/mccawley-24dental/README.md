# Dental Quiz Landing Page Template

A reusable landing page template for dental clinics to promote a gum health quiz, build trust with testimonials, and drive new patient inquiries.

## Project Details
- **Slug:** `mccawley-24dental`
- **Views:** 20
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Brand, quiz funnel, dental, testimonials
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

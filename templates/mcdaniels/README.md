# Junk Removal Services Landing Page Template

A reusable landing page template for local junk removal and hauling businesses to showcase services, build trust, and capture quote requests.

## Project Details
- **Slug:** `mcdaniels`
- **Views:** 29
- **Tags:** Landing Page, Services, Business, Clean, Dark, Minimal, Local service, Home services, Lead generation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

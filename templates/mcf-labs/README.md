# MCF LABS

A dark, futuristic landing page template for institutional-grade quant trading terminals, showcasing AI simulations, order flow analytics, pricing, FAQs, and testimonials.

## Project Details
- **Slug:** `mcf-labs`
- **Views:** 16

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

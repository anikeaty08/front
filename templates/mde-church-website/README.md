# Religious Church Landing Page Template

A modern church website template for La Maison Des Élus–style ministries, perfect for promoting services, sermons, events, donations, and prayer requests.

## Project Details
- **Slug:** `mde-church-website`
- **Views:** 26
- **Tags:** Landing Page, Religious, Brand, Clean, Gradient, Large Type, Social, Services, Church, Prayer
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

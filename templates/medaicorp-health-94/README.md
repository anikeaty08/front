# MedAICorp Health Dashboard Web App Template

A modern MedAICorp-style dashboard template for managing employee medical checkups (MCU), AI health analysis, scheduling, and reports in a single web app.

## Project Details
- **Slug:** `medaicorp-health-94`
- **Views:** 26
- **Tags:** Health, Technology, Landing Page, Brand, Clean, Minimal, Dashboard, SaaS, Medical, Admin
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

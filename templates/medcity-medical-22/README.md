# Medcity Medical Healthcare Landing Page Template

A modern Medcity medical healthcare landing page template for clinics, hospitals, and dental practices to showcase services, doctors, and online appointment booking.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

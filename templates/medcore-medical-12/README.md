# MedCore Medical Admin Dashboard Template

A modern MedCore medical admin dashboard template for managing clinic operations, appointments, patients, doctors, and billing in a clean, dark UI.

## Project Details
- **Slug:** `medcore-medical-12`
- **Views:** 8

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

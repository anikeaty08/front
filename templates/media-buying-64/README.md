# Media Buying Dashboard Template

A reusable dashboard template for media buyers and agencies to track spend, reach, channel mix, and booking schedules across broadcast and print campaigns.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

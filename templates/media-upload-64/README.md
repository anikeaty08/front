# Video Upload Dashboard Template

Dark, modern template for uploading movie files, managing a processing queue, and configuring media metadata in a reusable web app interface.

## Project Details
- **Slug:** `media-upload-64`
- **Views:** 30
- **Tags:** Technology, Landing Page, Brand, Dark, Clean, Minimal, Dashboard, Video Upload, Media Manager, Web App UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Medical 404 Error Page

A reusable Medical Process–branded 404 error page template themed around water hygiene and filtration, ideal for healthcare and medical services websites.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

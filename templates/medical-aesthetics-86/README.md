# Aesthetic Medicine Landing Page Template

A reusable landing page template for consultant-led aesthetic clinics to showcase treatments, clinical technology, and drive consultation bookings.

## Project Details
- **Slug:** `medical-aesthetics-86`
- **Views:** 34
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Technology, Medical, Aesthetics

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

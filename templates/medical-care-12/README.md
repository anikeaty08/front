# Medical Clinic Landing Page Template

A modern MedCore Health-inspired landing page template for medical clinics and healthcare providers to showcase services, specialists, technology, and appointments.

## Project Details
- **Slug:** `medical-care-12`
- **Views:** 21
- **Tags:** Health, Landing Page, Services, Brand, Clean, Gradient, Minimal, Large Type, Medical, Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

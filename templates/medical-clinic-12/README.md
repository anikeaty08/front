# Medical Clinic Landing Page Template

A clean, modern medical clinic landing page template for doctors and healthcare practices, featuring services, hours, and an integrated appointment booking form.

## Project Details
- **Slug:** `medical-clinic-12`
- **Views:** 318
- **Tags:** Health, Landing Page, Services, Brand, Clean, Minimal, Large Type, Gradient, Medical, Doctor
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

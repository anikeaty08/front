# Medical Clinic Landing Page Template

Modern medical center landing page template for clinics to showcase services, specialists, and appointment booking with a smart health search experience.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

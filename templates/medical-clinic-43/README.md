# Medical Clinic Landing Page Template

A modern, patient-focused medical clinic landing page template featuring services, doctor profile, facilities, testimonials, booking form, contact details, and admin view.

## Project Details
- **Slug:** `medical-clinic-43`
- **Views:** 72
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Clinic, Medical, Appointment
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

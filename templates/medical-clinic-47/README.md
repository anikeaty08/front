# Medical Practice Landing Page Template

A modern Meridian Medical Group-style landing page template for clinics and healthcare practices to showcase services, physicians, telehealth, billing, and patient stories.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

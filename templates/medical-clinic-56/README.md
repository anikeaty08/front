# Medical Clinic Landing Page Template

A reusable medical clinic template for physicians and family practices to showcase services, build trust, and drive appointment bookings online.

## Project Details
- **Slug:** `medical-clinic-56`
- **Views:** 56
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Brand, doctor, clinic, appointment booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Medical College Contact Page Template

A customizable contact page template for medical colleges and hospitals, featuring enquiry forms, directories, maps, and visitor info for easy reuse.

## Project Details
- **Slug:** `medical-college-48`
- **Views:** 108
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Brand, Education, Hospital, Contact Page, Directory
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Medical College Contact Landing Page Template

A modern contact and directory landing page template for medical colleges and hospitals, ready to reuse for patient inquiries, admissions, and key info.

- **Views:** 23

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

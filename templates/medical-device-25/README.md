# Medical Device OEM Landing Page Template

A clean, technical landing page template for showcasing OEM medical imaging components like ionization chambers to equipment manufacturers and engineering teams.

## Project Details
- **Slug:** `medical-device-25`
- **Views:** 5
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Large Type, Gradient, Grid
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

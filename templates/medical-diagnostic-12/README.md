# Medical Diagnostic Dashboard UI Template

A reusable template for an interactive medical diagnostic dashboard with risk mapping, wayfinding engine, and D3 data visualizations.

## Project Details
- **Slug:** `medical-diagnostic-12`
- **Views:** 13
- **Tags:** Landing Page, Technology, Brand, Dark, Futuristic, Minimal, Dashboard, Data Visualization, Health
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Medical Doctor Landing Page Template

A clean, modern landing page template for individual doctors or medical clinics to showcase services, experience, patient stories, and appointment booking.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

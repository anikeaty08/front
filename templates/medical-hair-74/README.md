# Medical Hair Restoration Landing Page Template

A high-end, conversion-focused landing page template designed for hair restoration clinics and surgical specialists to book more patient consultations.

- **Slug:** `medical-hair-74`
- **Views:** 30

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

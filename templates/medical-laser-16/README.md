# Medical Device Product Landing Page Template

A dark, modern product detail template for showcasing certified pre-owned medical or aesthetic devices with rich specs, pricing, and e-commerce actions.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

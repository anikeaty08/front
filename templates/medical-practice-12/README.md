# Medical Practice Landing Page Template

A clean, patient-focused landing page template for local medical and general practices to showcase services, doctors, hours, and online appointment booking.

## Project Details
- **Slug:** `medical-practice-12`
- **Views:** 33
- **Tags:** Health, Landing Page, Services, Brand, Clean, Minimal, Large Type, Clinic, Medical Practice, Healthcare
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

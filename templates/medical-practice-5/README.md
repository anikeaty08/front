# Medical Practice Landing Page Template

A clean, modern medical practice landing page template for clinics and GP practices to showcase services, fees, and contact details with clear appointment CTAs.

## Project Details
- **Slug:** `medical-practice-5`
- **Views:** 42
- **Tags:** Health, Landing Page, Services, Brand, Clean, Minimal, Large Type, Clinic, Medical, GP Practice
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

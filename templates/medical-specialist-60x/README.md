# Medical Specialist Landing Page Template

A professional and clean healthcare landing page template designed for medical specialists, specifically urologists, to showcase services and book appointments.

## Project Details
- **Slug:** `medical-specialist-60x`
- **Views:** 16
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Medical Surgeon Landing Page Template

A reusable landing page template for surgeons, clinics, and medical specialists to showcase services, credentials, patient trust, and appointment booking.

## Project Details
- **Slug:** `medical-surgeon-77`
- **Views:** 36
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Animated, medical, surgeon, clinic

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

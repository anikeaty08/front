# AuraMed Medical Training Landing Page Template

AuraMed is a clean, modern landing page template for medical training and clinical nutrition services, ideal for promoting premium rehabilitation and diet programs.

## Project Details
- **Slug:** `medical-training-16`
- **Views:** 16
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Gradient, Large Type, Medical Training, Rehabilitation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

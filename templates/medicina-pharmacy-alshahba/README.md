# Pharmacy Branch Listing Landing Page Template

A clean, modern pharmacy branch listing landing page template for showcasing healthcare locations, contact details, hours, and maps across multiple branches.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

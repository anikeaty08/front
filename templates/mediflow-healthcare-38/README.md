# MediFlow Healthcare Landing Page Template

A premium MediFlow healthcare landing page template for clinics and hospitals, featuring online booking, doctor profiles, services, blog, and contact sections.

## Project Details
- **Slug:** `mediflow-healthcare-38`
- **Views:** 9
- **Tags:** Health, Landing Page, Services, Brand, Clean, Gradient, Large Type, Minimal, Medical, Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Medikal

Reusable Medikal Shop landing page template for online medical equipment and supplies stores, featuring hero promo, product grid, and trust-building features.

- **Slug:** `medikal-cfk-ssas`
- **Views:** 28

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

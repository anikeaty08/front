# Medspa Landing Page Template

A modern Medspa landing page template for clinics to showcase services, testimonials, and contact details, optimized for booking appointments and new patients.

## Project Details
- **Slug:** `medspa-clinic-10`
- **Views:** 8
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Gradient, Large Type, Medical Spa, Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Medical Inventory Dashboard Template

A reusable template for a MedStock-style medical college inventory dashboard with admin and department user views for tracking items and requisition requests.

## Project Details
- **Slug:** `medstock-medical-7`
- **Views:** 119
- **Tags:** Health, Services, Technology, Dashboard, Inventory, Clean, Minimal, Grid, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

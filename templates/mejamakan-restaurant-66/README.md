# Mejamakan Food Landing Page Template

A reusable Mejamakan-inspired restaurant landing page template for showcasing weekly Malay menus, authentic flavours, and driving online food delivery orders.

## Project Details
- **Slug:** `mejamakan-restaurant-66`
- **Views:** 13
- **Tags:** Food, Landing Page, Brand, Clean, Colorful, Minimal, Restaurant, Delivery, Weekly Menu, Cuisine

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Men's Fashion E-commerce Template

A reusable e-commerce template for men's fashion stores featuring product listings, cart checkout, WhatsApp ordering, and a lightweight admin dashboard.

## Project Details
- **Slug:** `men-s-fashion-29`
- **Views:** 29

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

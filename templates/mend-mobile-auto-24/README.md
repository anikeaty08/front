# Mobile Auto Repair Landing Page Template

This template provides a sleek, user-friendly design to connect car owners with mobile mechanics for easy booking, tracking, and payment via a mobile app.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

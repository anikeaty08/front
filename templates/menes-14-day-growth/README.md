# MENES WhatsApp Growth Landing Page Template

A dark, Arabic RTL landing page template for MENES-style 14-day WhatsApp sales growth systems, ready to adapt for service businesses and marketing offers.

## Project Details
- **Slug:** `menes-14-day-growth`
- **Views:** 9
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Gradient, Minimal, Large Type, Futuristic, 3D
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

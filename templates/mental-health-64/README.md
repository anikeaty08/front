# Mental Health Clinic Landing Page Template

A modern, clinic-ready landing page template for behavioral and integrative mental health practices to showcase services, build trust, and drive appointment bookings.

- **Slug:** `mental-health-64`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mental Load Dashboard UI Template

A modern dashboard UI template for tracking, managing, and visualizing household mental load across brain dumps, energy check-ins, and shared analytics.

## Project Details
- **Slug:** `mental-load-dashboard-30`
- **Views:** 14
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Dashboard, Mental load, Productivity, Household management, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

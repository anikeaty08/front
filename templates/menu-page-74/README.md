# Vietnamese Restaurant Landing Page Template

A reusable restaurant website template for Vietnamese food brands to showcase menus, reviews, hours, locations, and drive online orders.

## Project Details
- **Slug:** `menu-page-74`
- **Views:** 43
- **Tags:** Food, Landing Page, Brand, Clean, Colorful, Minimal, Restaurant, Menu, Reviews, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Restaurant POS Landing Page Template

A high-converting landing page template for Menumiz-style restaurant POS platforms, showcasing features, pricing, and testimonials to drive demo and app downloads.

## Project Details
- **Slug:** `menumizposfeature`
- **Views:** 702
- **Tags:** Landing Page, Services, Food, Technology, Gradient, Minimal, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

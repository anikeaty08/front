# Fintech Merchant Portal Template

A reusable merchant portal template for payment platforms and fintech brands to showcase secure access, digital payments, and streamlined account sign-in.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Treely - Merci

A clean, eco-focused thank you landing page template for impact-driven apps and services, perfect for post-form confirmations and lead capture flows.

## Project Details
- **Slug:** `merci`
- **Views:** 22
- **Tags:** Landing Page, Brand, Environmental, Clean, Minimal, Technology, Large Type, Gradient

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

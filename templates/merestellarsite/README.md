# Mere Stellar

A dark, visionary artist portfolio landing page template for showcasing music, creative leadership, and wellbeing services with a built-in contact form.

## Project Details
- **Slug:** `merestellarsite`
- **Views:** 3
- **Tags:** Landing Page, Portfolio, Art & Design, Artist, Services, Brand, Dark, Clean, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

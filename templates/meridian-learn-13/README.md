# Student Learning Dashboard UI Template

A reusable Meridian Learn-style student login and dashboard UI template for modern education platforms and e-learning products.

- **Slug:** `meridian-learn-13`
- **Views:** 16
- **Tags:** Education, Landing Page, Technology, Brand, Clean, Colorful, Minimal, Dashboard, E-learning, Student Portal

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mesa Digital Restaurant Landing Page Template

A professional and modern landing page template designed for restaurants and local businesses to showcase menus and drive reservations.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

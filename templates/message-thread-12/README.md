# Message Thread View UI Template

A reusable message thread view UI template for displaying conversational email or chat inquiries with metadata, perfect for modern web apps and CRMs.

## Project Details
- **Slug:** `message-thread-12`
- **Views:** 15
- **Tags:** Technology, Services, Clean, Minimal, Large Type, Gradient, messaging UI, CRM, email thread, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

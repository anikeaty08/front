# Messaging App Group Creation Template

A reusable mobile UI template for creating chat groups, selecting members, and naming conversations in messaging or social apps.

## Project Details
- **Slug:** `messaging-app-59`
- **Views:** 48
- **Tags:** Landing Page, Technology, Social, Clean, Minimal, Mobile UI, App, Messaging

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

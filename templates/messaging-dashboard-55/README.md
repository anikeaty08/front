# Private Messages UI Dashboard Template

A modern React messaging UI template with sidebar, chat stream, and input bar, ideal for building in‑app private message dashboards and support chats.

- **Slug:** `messaging-dashboard-55`
- **Views:** 80

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Metal Export Landing Page 

A reusable landing page template for metalware exporters and B2B kitchenware suppliers to showcase products, global reach, and generate quote inquiries.

## Project Details
- **Slug:** `metal-exporter-72`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

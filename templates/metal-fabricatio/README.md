# Metal Fabrication Services Landing Page Template

A reusable landing page template for metal fabrication and machining service businesses to showcase capabilities, industries served, and generate quote inquiries.

## Project Details
- **Slug:** `metal-fabricatio`
- **Views:** 120
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Brand, Technology, Gradient, Metal Fabrication, Welding
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

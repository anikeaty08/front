# Industrial Packaging Landing Page Template

A reusable landing page template for tin can manufacturers and metal packaging companies to showcase products, capabilities, and contact-driven sales outreach.

## Project Details
- **Slug:** `metal-packaging-99`
- **Views:** 35
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Manufacturing, Industrial, Packaging, B2B

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

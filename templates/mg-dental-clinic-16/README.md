# Dental Clinic Landing Page 

Reusable landing page template for modern dental clinics to showcase services, testimonials, and location details while driving WhatsApp reservations.

## Project Details
- **Slug:** `mg-dental-clinic-16`
- **Views:** 95
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, dental clinic, medical

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Learning Platform Landing Page Template

This reusable landing page template is designed for online learning platforms to showcase courses, career outcomes, and testimonials to attract learners.

## Project Details
- **Slug:** `mh-learning-platform-35`
- **Views:** 1905
- **Tags:** Landing Page, Hero, Courses, Testimonials, FAQ, Career Outcomes, Call to Action, Education, User Testimonials
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Micro-Journal Mobile App UI Template

A reusable mobile journaling app UI template with onboarding, mood tracking, community feed, insights, and premium upgrade flows for mental wellness products.

- **Slug:** `micro-journal-21`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Microfinance Nano Loan Landing Page Template

A reusable landing page template for promoting microfinance nano loan products with instant approval, key info cards, and mobile banking app downloads.

## Project Details
- **Slug:** `microfinan-nano-5`
- **Views:** 10
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Gradient, Minimal, Large Type, Financial, Microfinance
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mobile Game Organic Distribution Landing Page Template

A reusable landing page template for mobile game growth agencies and UA teams to showcase organic video distribution, case studies, and booking flows.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

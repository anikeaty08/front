# Microsoft 365 Training Landing Page Template

A high-converting landing page template for promoting structured Microsoft 365 (Excel, Word, PowerPoint, Outlook, Teams) training programs and lead-gen diagnostics.

## Project Details
- **Slug:** `microsoft-365-90`
- **Views:** 15
- **Tags:** Landing Page, Education, Services, Technology, Brand, Dark, Clean, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

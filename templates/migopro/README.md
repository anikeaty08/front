# Sports Luxe Lounge

A modern sports-lounge restaurant landing page template for showcasing menus, VIP memberships, and reservations for upscale food and hospitality brands.

## Project Details
- **Slug:** `migopro`
- **Views:** 11
- **Tags:** Landing Page, Food, Brand, Clean, Colorful, Gradient, Large Type, Services, Technology

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Orthodontic Clinic Landing Page Template

A modern orthodontic landing page template for Invisalign and braces practices, featuring services, locations, reviews, and an appointment request form.

## Project Details
- **Slug:** `milestoneorthodontics`
- **Views:** 6
- **Tags:** Health, Services, Landing Page, Brand, Clean, Colorful, Minimal, Large Type, Orthodontics, Invisalign
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

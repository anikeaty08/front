# Sales Consulting by Christine

A reusable landing page template for sales consultants, coaches, and fractional leaders to showcase services, process, credibility, and booking CTAs.

## Project Details
- **Slug:** `miller-consulting`
- **Views:** 280
- **Tags:** Landing Page, Services, Business, Technology, Dark, Clean, Minimal, sales consulting, coaching, fractional leadership

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

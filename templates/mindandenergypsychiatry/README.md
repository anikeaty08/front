# Psychiatry Practice Landing Page Template

A modern, dark-mode psychiatry practice landing page template for telehealth mental health services, ready to customize for your own clinic or provider brand.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

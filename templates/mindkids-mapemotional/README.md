# Children's Emotional Assessment App Template

A playful mobile-first template for child emotional mapping, guided reflection, and report sharing for schools, therapists, and family support.

## Project Details
- **Slug:** `mindkids-mapemotional`
- **Views:** 62

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

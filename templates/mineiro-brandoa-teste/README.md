# Restaurant Landing Page Template

A modern restaurant landing page template for buffet-style and local dining businesses, ready to customize for your own venue.

## Project Details
- **Slug:** `mineiro-brandoa-teste`
- **Views:** 38
- **Tags:** Food, Landing Page, Brand, Clean, Colorful, Minimal, Restaurant, Buffet, Local Business, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

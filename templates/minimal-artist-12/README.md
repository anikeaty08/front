# Minimalist Artist Portfolio Template

A clean, contemporary artist portfolio template for showcasing fine art collections, exhibitions, and collector inquiries with a gallery-focused layout.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

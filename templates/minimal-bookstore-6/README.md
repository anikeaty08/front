# Bookstore Landing Page Template

Minimal, editorial bookstore landing page template for showcasing featured titles and selling books online with a clean, modern shopping flow.

## Project Details
- **Slug:** `minimal-bookstore-6`
- **Views:** 24
- **Tags:** Landing Page, E-commerce, Brand, Clean, Minimal, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Minimal Read More Card UI Template

A reusable minimal card and modal UI template for displaying truncated text with a read-more interaction in dark, modern web interfaces.

## Project Details
- **Slug:** `minimal-card-66`
- **Views:** 128
- **Tags:** Landing Page, Technology, Brand, Minimal, Dark, Clean, UI component, Card layout, Modal, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Minimalist Chat App Landing Page Template

A clean, minimalist landing page template for promoting a modern chat app like Aura, designed to highlight core features, clarity, and early-access signup.

## Project Details
- **Slug:** `minimal-chat-11`
- **Views:** 22
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Large Type, Gradient, SaaS, App, Messaging
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Minimal Designer Portfolio Template

A clean, modern portfolio template for product designers and developers to showcase projects, services, and contact details with a fixed sidebar layout.

## Project Details
- **Slug:** `minimal-designer-35`
- **Views:** 21
- **Tags:** Portfolio, Landing Page, Art & Design, Clean, Minimal, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

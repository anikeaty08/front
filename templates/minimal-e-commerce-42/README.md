# Minimal E-commerce Storefront Template

A clean, minimal e-commerce storefront template for modern product brands, featuring hero, product grid, filters, cart, and product detail pages.

## Project Details
- **Slug:** `minimal-e-commerce-42`
- **Views:** 26
- **Tags:** E-commerce, Landing Page, Brand, Art & Design, Clean, Minimal, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

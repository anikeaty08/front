# Minimal E-commerce Landing Page Template

A clean, minimalist e-commerce landing page template for modern product brands, featuring hero promo, filters, cart slide-over, and responsive product grid.

## Project Details
- **Slug:** `minimal-e-commerce-5`
- **Views:** 115
- **Tags:** E-commerce, Landing Page, Brand, Clean, Minimal, Gradient, Large Type, Technology, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

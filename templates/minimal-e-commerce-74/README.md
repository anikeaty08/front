# Ensokken E-commerce Storefront Template

A modern e-commerce storefront template for minimalist fashion brands, ideal for showcasing products, collections, cart, and checkout flows.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

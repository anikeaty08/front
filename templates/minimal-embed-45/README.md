# Minimal Embed Test Landing Page Template

A reusable minimal landing page template for testing isolated embeds, scripts, and widget integrations without complex UI or extra dependencies.

## Project Details
- **Slug:** `minimal-embed-45`
- **Views:** 30
- **Tags:** Landing Page, Technology, Minimal, Clean, Brand, testing, embed, widget integration
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

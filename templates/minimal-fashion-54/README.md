# Monochrome Fashion E-commerce Landing Page Template

A sleek, minimal e-commerce landing page template for fashion and streetwear brands, featuring product grid, cart drawer, search, and newsletter flows.

## Project Details
- **Slug:** `minimal-fashion-54`
- **Views:** 51

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

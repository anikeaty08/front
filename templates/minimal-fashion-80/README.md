# Minimal Fashion E-commerce Landing Page Template

A clean, minimal fashion e-commerce landing page template for showcasing collections, product grids, and editorial features for modern apparel brands.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

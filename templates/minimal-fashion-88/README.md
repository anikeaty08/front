# Fashion E-commerce Storefront Template

Minimal black-and-white fashion e-commerce storefront template for showcasing curated collections, filters, and products with an editorial shopping experience.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

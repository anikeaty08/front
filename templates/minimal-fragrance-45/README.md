# Luxury Fragrance E-commerce Template

A refined e-commerce template for premium fragrance brands to showcase collections, product stories, discovery sets, and minimalist shopping flows.

## Project Details
- **Slug:** `minimal-fragrance-45`
- **Views:** 72

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

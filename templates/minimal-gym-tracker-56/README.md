# Minimal Gym Tracker App UI Template

A dark, minimal mobile gym tracker app UI template for logging weekly workouts, sets, and notes, ready to reuse in fitness or health products.

## Project Details
- **Slug:** `minimal-gym-tracker-56`
- **Views:** 23
- **Tags:** Health, Landing Page, Brand, Minimal, Dark, Mobile UI, Fitness, Workout Tracker, App Design, Clean
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Minimal Landing Page Template

A reusable landing page template for quickly launching simple brand, product, or startup websites with a clean and flexible structure.

## Project Details
- **Slug:** `minimal-landing-79`
- **Views:** 20
- **Tags:** Landing Page, Brand, Minimal, Clean, Technology, startup, marketing, one-page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

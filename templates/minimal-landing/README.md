# Architecture Studio Portfolio Landing Page Template

A dark, minimal portfolio landing page template for architecture and spatial design studios to showcase selected works, process, and philosophy.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

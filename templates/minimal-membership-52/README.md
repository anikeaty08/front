# Dark Minimal Membership Prompt Template

A dark, minimal landing page template for membership-based products that asks a bold value question with simple Yes/No CTAs and a clear login entry point.

## Project Details
- **Slug:** `minimal-membership-52`
- **Views:** 23
- **Tags:** Landing Page, Brand, Clean, Dark, Minimal, Large Type, Membership, Hero Section, CTA Focus
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

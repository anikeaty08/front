# Minimal Mono E-commerce Landing Page Template

A minimalist mono-style e-commerce landing page template for fashion brands featuring hero, collections, product grid, journal story, newsletter, and footer sections.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Minimalist Full-Stack Portfolio Template

A sophisticated, high-performance portfolio template designed for full-stack developers and freelancers using ConcreteCMS.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Minimal Gallery Portfolio Template

A calm, reusable gallery template for showcasing retreat spaces, interiors, and nature-inspired photography with an elegant minimalist layout.

## Project Details
- **Slug:** `minimal-retreat-12`
- **Views:** 30
- **Tags:** Portfolio, Landing Page, Art & Design, Minimal, Clean, Grid, Interior Design, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

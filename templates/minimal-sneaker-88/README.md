# Minimal Sneaker Store Landing Page Template

A modern, minimal e-commerce landing page template for sneaker and footwear brands, featuring hero promotion, product grid, filters, and email capture.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

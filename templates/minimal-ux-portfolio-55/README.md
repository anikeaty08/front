# Minimal UX Portfolio Website Template

A minimalist UX portfolio website template for product designers to showcase services, selected work, testimonials, and contact details with clean visual storytelling.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

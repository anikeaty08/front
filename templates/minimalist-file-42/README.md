# Minimalist File Manager UI Template

A minimalist file manager UI template for web apps, featuring toggleable list and grid views, upload states, and modern Tailwind-based components.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

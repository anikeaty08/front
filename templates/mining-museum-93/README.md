# Mining Museum Attraction Landing Page Template

A modern, museum-focused landing page template for mining or industrial heritage attractions to showcase tours, exhibits, stories, and ticket booking.

- **Slug:** `mining-museum-93`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

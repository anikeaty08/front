# Mivana Food E-commerce Template

A clean and minimal e-commerce template designed for premium food brands and wholesale exporters looking to showcase artisanal products.

## Project Details
- **Slug:** `mivana-artisanal-25`
- **Views:** 25
- **Tags:** E-commerce, Food, Clean, Minimal, Grid, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

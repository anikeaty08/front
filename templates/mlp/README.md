# MLP Consulting

Reusable Spanish-language landing page template for consulting firms offering technical and financial evaluation services for funded projects.

## Project Details
- **Slug:** `mlp`
- **Views:** 37
- **Tags:** Landing Page, Services, Business, Consulting, Clean, Dark, Minimal, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

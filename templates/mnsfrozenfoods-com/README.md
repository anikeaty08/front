# Frozen Foods Restaurant Landing Page Template

A modern, mobile-friendly landing page template for frozen foods and snack restaurants to showcase menus, reviews, and ordering details.

## Project Details
- **Slug:** `mnsfrozenfoods-com`
- **Views:** 23
- **Tags:** Landing Page, Food, Business, Brand, Clean, Colorful, Gradient, Large Type, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mobile AI App Landing Page Template

A reusable landing page template for promoting a mobile AI app with sleek hero sections, feature grids, and app download CTAs.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

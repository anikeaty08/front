# Mobile Analytics Dashboard UI Template

A reusable mobile analytics dashboard UI template that replicates a professional post insights screen for content, social, or media apps.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

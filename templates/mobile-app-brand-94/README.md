# Mobile App Brand Guidelines Template

A reusable mobile app brand guidelines template for habit-tracking products, showcasing logo, colors, typography, components, and key UI screens.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

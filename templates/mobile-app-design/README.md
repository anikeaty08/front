# Design & Prototyping Mobile App Template

A reusable mobile app design template showcasing event timelines, immersive sessions, and course details for UX and interaction design projects.

## Project Details
- **Slug:** `mobile-app-design`
- **Views:** 10103
- **Tags:** Mobile App, UX Research, Event Timeline, Prototyping, Interaction Design, Course Schedule, User Persona, Team Collaboration, UI Components
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

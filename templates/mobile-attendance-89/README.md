# Mobile Attendance Dashboard UI Template

A reusable mobile attendance dashboard UI template for tracking detailed leave, WFH, and field visits with clean cards and yearly balance stats.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

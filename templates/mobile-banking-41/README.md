# Mobile Banking Dashboard UI Template

A reusable mobile banking dashboard UI template for displaying accounts, balances, and transactions inside a sleek app-style viewport.

## Project Details
- **Slug:** `mobile-banking-41`
- **Views:** 5
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Banking, Finance, Mobile App UI, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

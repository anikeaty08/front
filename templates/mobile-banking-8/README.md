# Mobile Banking App UI Template

A reusable mobile banking template for showcasing account balances, transactions, and wallet alerts in a clean fintech app interface.

## Project Details
- **Slug:** `mobile-banking-8`
- **Views:** 34
- **Tags:** Technology, Landing Page, Clean, Minimal, Mobile Banking, Fintech, App UI, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

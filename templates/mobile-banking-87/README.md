# Mobile Banking App Template

A reusable mobile banking app template for showcasing account balances, transactions, transfers, and in-app alerts in a polished finance UI.

## Project Details
- **Slug:** `mobile-banking-87`
- **Views:** 26
- **Tags:** Technology, Landing Page, Clean, Minimal, Mobile App, Banking, Finance Dashboard, UI Kit
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

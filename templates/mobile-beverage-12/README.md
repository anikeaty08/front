# Mobile Beverage Catering Landing Page Template

A reusable landing page template for mobile beverage catering businesses to showcase packages, pricing, testimonials, and event booking.

## Project Details
- **Slug:** `mobile-beverage-12`
- **Views:** 28
- **Tags:** Landing Page, Food, Services, Colorful, Gradient, Clean, Event Catering, Mobile Beverage, Booking Form
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

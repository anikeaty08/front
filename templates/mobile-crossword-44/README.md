# Persian Crossword Game UI Template

A reusable Persian crossword mobile UI template for RTL puzzle games, featuring glassmorphism design, grid, hints, score and on-screen keyboard.

## Project Details
- **Slug:** `mobile-crossword-44`
- **Views:** 14
- **Tags:** Landing Page, Brand, Entertainment, Clean, Dark, Gradient, Large Type, Game UI, Mobile App, RTL
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

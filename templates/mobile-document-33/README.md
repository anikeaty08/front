# Mobile Scanner App UI Template

A dark, glassmorphism mobile scanner app UI template for document, ID, and QR scanning experiences, ready to customize for your own product.

## Project Details
- **Slug:** `mobile-document-33`
- **Views:** 15
- **Tags:** Technology, Landing Page, Brand, Clean, Dark, Futuristic, Minimal, Large Type, Mobile UI, Scanner
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mobile E-commerce Basket Template

A reusable mobile shopping basket template for e-commerce apps, designed to showcase cart management, pickup selection, pricing summaries, and checkout flows.

## Project Details
- **Slug:** `mobile-e-commerce-25`
- **Views:** 35
- **Tags:** E-commerce, Landing Page, Technology, Clean, Gradient, Minimal, Mobile UI, Cart, Checkout
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

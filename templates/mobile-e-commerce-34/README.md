# Mobile Shopping & Cargo App Template

A reusable mobile app template for social shopping, group cargo orders, and product discovery with wallet, tracking, and community-based shipping flows.

## Project Details
- **Slug:** `mobile-e-commerce-34`
- **Views:** 32

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

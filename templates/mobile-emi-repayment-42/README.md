# Mobile EMI Repayment Screen UI Template

A modern mobile EMI repayment screen UI template for finance apps, showcasing upcoming payments, rewards, and Pay All actions in a clean layout.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

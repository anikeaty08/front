# Mobile Health Dashboard App UI Template

A modern mobile health & wellness dashboard UI template for tracking activity, sleep, nutrition, mood and insights in your health or fitness app.

## Project Details
- **Slug:** `mobile-health-21`
- **Views:** 32
- **Tags:** Health, Technology, Landing Page, Clean, Minimal, Mobile App, Wellness, Fitness Tracker, Dashboard UI, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

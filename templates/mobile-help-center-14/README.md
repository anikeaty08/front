# Help Center Mobile App Template

A reusable mobile support template for help centers, featuring search, live chat, categorized assistance, FAQs, and urgent contact actions.

## Project Details
- **Slug:** `mobile-help-center-14`
- **Views:** 31
- **Tags:** Documentation, Services, Technology, Landing Page, Clean, Minimal, Mobile UI, Help Center, Customer Support
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

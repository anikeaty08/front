# Mobile Learning App Template

A reusable mobile app template for curated learning feeds that helps users save, revisit, and act on insights from books, podcasts, and research.

## Project Details
- **Slug:** `mobile-learning-1`
- **Views:** 34
- **Tags:** Education, Technology, Landing Page, Dark, Minimal, Mobile App, Learning, Feed, Knowledge Management
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mobile Learning App UI Template

A reusable mobile app template for language learning products, featuring lesson flows, gamified progress, onboarding, pricing, profile, and settings screens.

## Project Details
- **Slug:** `mobile-learning-60`
- **Views:** 40
- **Tags:** Education, Technology, Landing Page, Clean, Colorful, Mobile App, UI Kit, Gamified, SaaS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

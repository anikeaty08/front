# Nexus Professional Learning App UI Template

A mobile-first Nexus Professional Learning app UI template for online courses, progress tracking, and in-app payments, ready to customize for your platform.

## Project Details
- **Slug:** `mobile-lms-course-13`
- **Views:** 13
- **Tags:** Education, Landing Page, Brand, Clean, Minimal, Gradient, Technology, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

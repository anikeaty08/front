# Calor.ai Mobile App UI Template

A reusable mobile app UI template for AI-driven nutrition, calorie tracking, and weekly health stats, ready to customize for your health or fitness product.

## Project Details
- **Slug:** `mobile-nutrition-67`
- **Views:** 65
- **Tags:** Health, Technology, Landing Page, Minimal, Clean, Brand, Mobile App, Nutrition, Fitness, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

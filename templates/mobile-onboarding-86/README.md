# Fintech Onboarding Screens Template

A reusable mobile onboarding template for fintech and e-commerce apps to showcase EMI shopping, order tracking, rewards, and conversion-focused user flows.

## Project Details
- **Slug:** `mobile-onboarding-86`
- **Views:** 62
- **Tags:** Landing Page, E-commerce, Technology, Clean, Minimal, Gradient, Mobile UI, Fintech, Onboarding
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

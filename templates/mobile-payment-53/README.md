# Mobile Payment Flow Template

A reusable mobile payment interface template for showcasing send-money flows, transfer alerts, and account upgrade prompts in fintech demos.

## Project Details
- **Slug:** `mobile-payment-53`
- **Views:** 11

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

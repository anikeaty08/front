# Mobile Payment Checkout Template

A reusable mobile checkout template for selecting payment methods, confirming split payments, and validating wallet balance in e-commerce flows.

## Project Details
- **Slug:** `mobile-payment-90`
- **Views:** 33
- **Tags:** E-commerce, Landing Page, Technology, Clean, Gradient, Minimal, 3D, Mobile UI, Checkout, Payment
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

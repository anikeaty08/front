# Mobile Phone Repair Landing Page Template

A clean, conversion-focused landing page template for on-site mobile phone repair services with online booking, pricing, zones, testimonials, and FAQ.

## Project Details
- **Slug:** `mobile-phone-22`
- **Views:** 144
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Brand, Large Type, Gradient, Mobile repair, Booking

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

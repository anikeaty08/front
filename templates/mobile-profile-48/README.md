# Mobile Profile Settings UI Template

A sleek dark-mode mobile profile settings UI template for apps, featuring avatar editing, account controls, and a bottom navigation bar.

## Project Details
- **Slug:** `mobile-profile-48`
- **Views:** 26

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

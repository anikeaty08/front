# Mobile Sales

A modern mobile sales dashboard UI template for field sales teams to track routes, visits, and orders in a clean, ready-to-customize layout.

## Project Details
- **Slug:** `mobile-sales-21`
- **Views:** 3
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Gradient, Large Type, Sales dashboard, Mobile app UI, Field sales
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

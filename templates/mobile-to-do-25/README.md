# Productivity Mobile App UI Template

A clean, modern mobile app UI template for to-do, calendar, and focus timer experiences, ready for reuse in productivity and habit-tracking apps.

## Project Details
- **Slug:** `mobile-to-do-25`
- **Views:** 19
- **Tags:** Technology, App, Productivity, Clean, Minimal, Gradient, Large Type, Landing Page, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

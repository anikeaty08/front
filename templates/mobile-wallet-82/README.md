# Mobile Wallet Dashboard Template

A reusable mobile wallet template for payout management, escrow tracking, payment method selection, and transaction history in fintech apps.

## Project Details
- **Slug:** `mobile-wallet-82`
- **Views:** 36
- **Tags:** Technology, Landing Page, Clean, Minimal, Dark, mobile wallet, fintech, dashboard, payments
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

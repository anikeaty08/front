# Mobile Wedding Invitation Page Template

Elegant mobile wedding invitation page template for Chinese weddings, featuring event details, schedule, and RSVP form in a refined, ceremonial layout.

## Project Details
- **Slug:** `mobile-wedding-9`
- **Views:** 15
- **Tags:** Wedding, Landing Page, Brand, Minimal, Clean, Large Type, Art & Design, Services, Responsive, RSVP
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

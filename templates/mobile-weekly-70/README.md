# Weekly Planner App UI Template

A clean mobile weekly planner UI template for organizing daily tasks, routines, and scheduling, ready to customize for productivity or to-do list apps.

## Project Details
- **Slug:** `mobile-weekly-70`
- **Views:** 10
- **Tags:** Landing Page, Brand, Clean, Minimal, Technology, Gradient, Large Type, Productivity, Mobile UI, Planner

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

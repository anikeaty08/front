# Medical Mobility Landing Page Template

A modern landing page template for medical mobility services offering 100% funded wheelchairs, ideal for showcasing reimbursement, process steps, and lead capture.

## Project Details
- **Slug:** `mobilibre-medical-33`
- **Views:** 28

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Service Marketplace Website Template

A reusable website template for building a local services marketplace with searchable categories, featured providers, expert profiles, and city-based discovery.

## Project Details
- **Slug:** `mobilno`
- **Views:** 62
- **Tags:** Services, Technology, Landing Page, Clean, Minimal, Marketplace, Directory, Local Services, Search, Listings
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

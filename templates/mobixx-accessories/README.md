# Mobile Accessories E-commerce Landing Page Template

A dark, modern template for mobile accessories and repair service brands, ideal for showcasing parts, accessories, and same-day repair booking in one landing page layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

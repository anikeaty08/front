# Model Portfolio Landing Page Template

This reusable template showcases a professional model's portfolio, bio, experience, and featured work to attract clients and bookings.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Kyn Baby Registry App UI Template

A modern mobile baby registry app UI template for organizing products, crowdsourcing advice from friends, and creating shareable polls for expecting parents.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

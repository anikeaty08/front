# Modern Barber Shop Landing Page Template

A premium, dark-themed local business template designed for barber shops and salons to showcase services and drive appointment calls.

## Project Details
- **Slug:** `modern-barber-61`
- **Views:** 36
- **Tags:** Services, Landing Page, Dark, Minimal, Clean, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Fine Dining Restaurant Landing Page Template

A dark, modern restaurant landing page template for bistros and charcoal grill concepts, featuring menus, reservation form, and experience highlights.

## Project Details
- **Slug:** `modern-bistro-6`
- **Views:** 20
- **Tags:** Food, Landing Page, Brand, Dark, Clean, Minimal, Large Type, Restaurant, Fine Dining, Reservation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

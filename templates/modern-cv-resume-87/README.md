# Minimal Resume CV Page Template

A clean, modern resume/CV page template for showcasing digital professionals’ experience, skills, and projects in a structured one-page layout.

## Project Details
- **Slug:** `modern-cv-resume-87`
- **Views:** 42
- **Tags:** Landing Page, Portfolio, Resume, Clean, Minimal, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

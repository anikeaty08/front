# Modern Dashboard Sidebar UI Template

Reusable template for a modern dashboard layout with a sidebar navigation, analytics cards, and project overview content, ideal for web apps and admin panels.

## Project Details
- **Slug:** `modern-dashboard-78`
- **Views:** 11
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Dashboard, Admin, Analytics, Web App UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

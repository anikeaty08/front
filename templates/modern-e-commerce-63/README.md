# Modern E-commerce Navbar & Carousel Template

A reusable dark-mode e-commerce UI template with a modern navbar, hero slider, product carousel, and testimonial section for stylish online stores.

## Project Details
- **Slug:** `modern-e-commerce-63`
- **Views:** 12
- **Tags:** E-commerce, Landing Page, Brand, Clean, Dark, Minimal, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

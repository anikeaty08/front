# Modern Indian Restaurant Landing Page Template

A premium dark-theme restaurant landing page template for modern Indian cuisine brands, featuring menu highlights, experience sections, and reservations.

## Project Details
- **Slug:** `modern-indian-83`
- **Views:** 5
- **Tags:** Landing Page, Food, Brand, Clean, Dark, Minimal, Large Type, Restaurant, Fine Dining, Reservation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

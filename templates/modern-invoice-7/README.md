# Modern Invoice Layout Template

A clean, modern invoice layout template for billing dashboards and client invoices, ready to customize with your brand, line items, and payment details.

## Project Details
- **Slug:** `modern-invoice-7`
- **Views:** 34

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Marketplace UI Website Template

A modern marketplace website template for buying and selling products, featuring homepage, category, product, dashboard, chat, and auth flows.

## Project Details
- **Slug:** `modern-marketplac-77`
- **Views:** 42
- **Tags:** E-commerce, Landing Page, Services, Brand, Clean, Minimal, Grid, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

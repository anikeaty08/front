# School Landing Page Template

A modern school website landing page template for showcasing academics, facilities, admissions, and contact information for educational institutions.

## Project Details
- **Slug:** `modern-school-56`
- **Views:** 35
- **Tags:** Landing Page, Education, Services, Brand, Clean, Minimal, Large Type, School, Admissions, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

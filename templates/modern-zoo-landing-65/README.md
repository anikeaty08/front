# Zoo & Wildlife Landing Page Template

A bold, brutalist zoo and wildlife park landing page template for promoting exhibits, tickets, and visitor information with immersive visuals.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

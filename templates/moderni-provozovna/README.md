# Retail Interior Services Landing Page Template

A dark, modern landing page template for interior design and fit-out services, ideal for showcasing commercial retail and optics projects with strong case studies.

## Project Details
- **Slug:** `moderni-provozovna`
- **Views:** 21
- **Tags:** Landing Page, Services, Art & Design, Portfolio, Dark, Clean, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

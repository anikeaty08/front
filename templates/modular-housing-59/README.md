# Modular Housing Landing Page Template

A modern, bilingual landing page template for premium modular housing brands to showcase models, process, sustainability, testimonials, and capture project inquiries.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

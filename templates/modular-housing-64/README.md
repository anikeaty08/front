# Modular Housing Landing Page Template

A modern, bilingual landing page template for modular housing and prefab home builders to showcase models, process, portfolio, testimonials, and lead-gen contact form.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

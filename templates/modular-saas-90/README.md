# Modular SaaS Landing Page Template

A modular SaaS landing page template featuring multiple hero, social proof, pricing, and CTA layouts to quickly launch high-converting product sites.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

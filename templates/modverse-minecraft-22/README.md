# Minecraft Mod Repository Landing Page Template

A dark, modern Minecraft mod repository landing page template for showcasing, browsing, and filtering community-created mods with a clean grid layout.

## Project Details
- **Slug:** `modverse-minecraft-22`
- **Views:** 10
- **Tags:** Landing Page, Technology, Brand, Dark, Grid, Minimal, Large Type, Gaming, Marketplace
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

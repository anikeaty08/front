# Moje Kára Demo Web

A reusable dark-style landing page template for car detailing studios to showcase services, portfolio work, and drive quote requests.

## Project Details
- **Slug:** `mojekara`
- **Views:** 47
- **Tags:** Landing Page, Services, Dark, Clean, Minimal, Portfolio, Automotive, Car Detailing, Luxury
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

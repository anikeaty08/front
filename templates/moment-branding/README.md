# Fashion Brand Guidelines Page Template

A refined, minimal brand guidelines template for fashion or lifestyle brands to showcase logo, typography, color, photography, and voice with editorial polish.

## Project Details
- **Slug:** `moment-branding`
- **Views:** 41
- **Tags:** Brand Guidelines, Brand, Fashion, Art & Design, Landing Page, Minimal, Clean, Large Type, Grid, Portfolio

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

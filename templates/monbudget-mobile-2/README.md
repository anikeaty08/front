# Finance Budgeting App UI Template

Mobile-first finance app UI template for a personal budgeting and expense tracking experience, ready to reuse in your next fintech or money management project.

- **Slug:** `monbudget-mobile-2`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

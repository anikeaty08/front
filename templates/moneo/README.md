# Moneo Financial SaaS Landing Page Template

A dark, AI-driven finance SaaS landing page template for smart budget assistants, virtual cards, and pricing that you can reuse for your own fintech product.

## Project Details
- **Slug:** `moneo`
- **Views:** 64
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Gradient, Large Type, Fintech, AI, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

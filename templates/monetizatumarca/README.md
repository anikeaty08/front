# Monetiza y Escala tu Marca Personal

High-converting landing page template for Spanish-speaking content creators to present a VSL system, capture leads and sell a personal brand monetization offer.

## Project Details
- **Slug:** `monetizatumarca`
- **Views:** 16
- **Tags:** Landing Page, Brand, Services, Dark, Minimal, Large Type, Technology, Marketing, VSL, Personal Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Money Transfer Landing Page Template

A reusable landing page template for online money transfer services to Bangladesh, featuring a fee calculator, app promotion, FAQs, and trust-building sections.

## Project Details
- **Slug:** `money-transfer-42`
- **Views:** 80
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Brand, Gradient, Large Type, Money Transfer, Fintech
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

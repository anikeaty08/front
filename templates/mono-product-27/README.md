# Mono Product Landing Page Template

A minimalist Mono product landing page template for showcasing a single physical or hardware product with benefits, social proof, and a high-converting CTA.

## Project Details
- **Slug:** `mono-product-27`
- **Views:** 124
- **Tags:** Landing Page, Brand, Minimal, Clean, Technology, Large Type, Product, Single Product, Hardware

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

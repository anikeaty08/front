# AI Knowledge Chat Interface Template

A reusable AI knowledge chat interface template for modern web apps, featuring conversation history, code snippets, and a clean dark UI layout.

## Project Details
- **Slug:** `monoplic-base-ai`
- **Views:** 68
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Minimal, Large Type, AI chat, Web app UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

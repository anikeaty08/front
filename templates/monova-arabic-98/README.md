# Arabic Creative Agency Landing Page Template

Modern Arabic landing page template for digital creative agencies to showcase branding, UI/UX, marketing services, pricing packages, and contact CTAs.

## Project Details
- **Slug:** `monova-arabic-98`
- **Views:** 11
- **Tags:** Landing Page, Brand, Services, Technology, Colorful, Dark, Gradient, Minimal, Portfolio, Marketing
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# French Restaurant Landing Page Template

Elegant French bistrot landing page template for showcasing menus, wine cellar, gallery, and reservations for upscale restaurants and bars.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

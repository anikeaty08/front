# Moving Services Landing Page Template

A reusable moving company landing page template for local and long-distance relocation businesses to showcase services and capture quote requests.

## Project Details
- **Slug:** `mooremajor-moves`
- **Views:** 29
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Brand, local moving, relocation, quote form
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# B2B Sales Consulting by Morgan

A reusable landing page template for B2B sales consultants, outbound coaches, and social selling experts to showcase services and book strategy calls.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

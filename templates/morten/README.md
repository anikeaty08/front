# Automation Consultancy Landing Page Template

A dark, modern Automation Consultancy landing page template for boutique AI and workflow automation firms to showcase services, pricing, and book strategy calls.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mosque Digital Signage Screen Template

A reusable mosque digital signage template for displaying live prayer times, Ramadan sahri/iftar, countdowns, image slideshows, and bookstore promos on large screens.

## Project Details
- **Slug:** `mosque-digital-1`
- **Views:** 16
- **Tags:** Landing Page, Religious, Brand, Clean, Dark, Minimal, Technology, Mosque, Digital Signage
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mosque Digital Signage Screen Template

A reusable mosque digital signage template for displaying prayer times, Ramadan timings, announcements, and community info on TV screens.

## Project Details
- **Slug:** `mosque-digital-26`
- **Views:** 92
- **Tags:** Landing Page, Religious, Community, Clean, Minimal, Technology, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

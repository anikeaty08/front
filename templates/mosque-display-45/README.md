# Mosque Display Dashboard Template

A reusable TV-ready mosque display template for showcasing daily prayer times, next prayer countdowns, announcements, and Islamic messages on large screens.

## Project Details
- **Slug:** `mosque-display-45`
- **Views:** 120

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

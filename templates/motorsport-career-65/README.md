# Motorsport Driver Dashboard Web App Template

A dark, data-rich motorsport career OS UI template for building driver dashboards with budgeting, telemetry, and progression tracking features.

## Project Details
- **Slug:** `motorsport-career-65`
- **Views:** 40
- **Tags:** Landing Page, Technology, Brand, Dark, Futuristic, Dashboard, Motorsport, Clean, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

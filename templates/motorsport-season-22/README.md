# Motorsport Season Tracker App Template

A reusable mobile app template for racing teams and drivers to track season goals, event schedules, and budget performance in one dashboard.

## Project Details
- **Slug:** `motorsport-season-22`
- **Views:** 38
- **Tags:** Technology, Landing Page, Clean, Minimal, Services, mobile app, motorsport, dashboard, budgeting, event tracking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Moving Services Landing Page Template

Reusable landing page template for residential and commercial moving services, featuring zones served, quote form, and trust-building service details.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

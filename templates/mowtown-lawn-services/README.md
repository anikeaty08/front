# Lawn Care Services Landing Page Template

A reusable landing page template for local lawn care and landscaping services, optimized for showcasing offerings, reviews, and driving quote requests.

## Project Details
- **Slug:** `mowtown-lawn-services`
- **Views:** 53
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Décoration d'événement intimiste - MS Events

Elegant French event decor landing page template for showcasing services, portfolio, and client testimonials for independent decorators and planners.

## Project Details
- **Slug:** `ms-event`
- **Views:** 263
- **Tags:** Landing Page, Services, Brand, Portfolio, Clean, Minimal, Large Type, Wedding, Event decor, French
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

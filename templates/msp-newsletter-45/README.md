# MSP Newsletter Landing Page Template

A reusable landing page template for MSP-focused newsletters, featuring curated AI, VoIP, marketing content, article highlights, and email subscription CTAs.

## Project Details
- **Slug:** `msp-newsletter-45`
- **Views:** 30
- **Tags:** Landing Page, Technology, Blog, Dark, Clean, Minimal, Brand, newsletter, MSP, SaaS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Snack E-commerce Catalog Page Template

A clean, modern snack e-commerce catalog page template with filters, product cards, and cart-ready CTAs for food and DTC brands.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

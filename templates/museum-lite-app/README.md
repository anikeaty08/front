# MuseumLite CMS & Collections Management Template

A professional-grade dashboard template designed for museums and galleries to manage inventories, digital assets, and exhibition workflows.

## Project Details
- **Slug:** `museum-lite-app`
- **Views:** 31

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

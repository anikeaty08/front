# Sporeborne Game Lobby UI Template

A cinematic dark-mode game lobby UI template for competitive matchmaking dashboards, perfect for fantasy or sci-fi multiplayer titles and esports hubs.

## Project Details
- **Slug:** `mushroom-universe`
- **Views:** 40
- **Tags:** Landing Page, Brand, Entertainment, Dark, Futuristic, Gradient, Gaming UI, Dashboard, Esports, Multiplayer
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

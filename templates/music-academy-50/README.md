# Music Academy Landing Page Template

A reusable landing page template for music academies and instrument schools to showcase programs, build brand appeal, and drive student enrollment.

## Project Details
- **Slug:** `music-academy-50`
- **Views:** 27
- **Tags:** Landing Page, Education, Services, Dark, Gradient, Clean, Music, Academy, Enrollment

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Music Artist Admin Dashboard Template

A dark, minimal admin dashboard template for music artists to manage songs, videos, tours, merch, credits, and account settings in one place.

## Project Details
- **Slug:** `music-artist-50`
- **Views:** 29
- **Tags:** Landing Page, Technology, Entertainment, Dark, Minimal, Dashboard, Music, Admin, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Music Streaming Dashboard UI Template

A dark, modern music streaming dashboard UI template for web apps, featuring playlists, moods, charts, and a bottom player for rapid product design.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

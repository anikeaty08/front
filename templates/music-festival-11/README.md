# Music Festival Landing Page Template

A modern, immersive music festival landing page template for multi-day events, showcasing lineup, workshops, travel, and ticket booking in a vibrant, scroll-driven layout.

## Project Details
- **Slug:** `music-festival-11`
- **Views:** 107
- **Tags:** Landing Page, Entertainment, Event, Clean, Colorful, Gradient, Large Type, Animated, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

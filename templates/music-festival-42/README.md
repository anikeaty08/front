# Music Festival Landing Page Template

A reusable festival website template for promoting a multi-day music event with lineup, venue details, gallery, press, FAQ, and ticket sales.

## Project Details
- **Slug:** `music-festival-42`
- **Views:** 77
- **Tags:** Landing Page, Entertainment, Conference, Dark, Minimal, Large Type, Clean, Music Festival, Tickets, Event
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

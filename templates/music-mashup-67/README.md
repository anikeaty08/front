# iOS Music Mashup App UI Template

A sleek iOS-style music mashup app UI template for showcasing track selection, beat and vocal editing, and a primary mashup generation action.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

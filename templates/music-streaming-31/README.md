# Music Streaming Web App UI Template

A dark, minimal music streaming web app UI template for MVPs and prototypes, featuring playlists, trending tracks, and a responsive player layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

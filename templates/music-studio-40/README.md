# Music Studio Landing Page Template

A reusable landing page template designed for music studios to showcase services, spaces, events, and content, with booking and contact features.

## Project Details
- **Slug:** `music-studio-40`
- **Views:** 1031
- **Tags:** Landing Page, Hero, Services, Spaces, Events, Content Hub, Booking, Testimonials, Newsletter, Footer
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

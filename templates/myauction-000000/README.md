# Auction App UI Mobile Screen Template

A dark, glassmorphism mobile auction app UI template for showcasing bidding flows, live lots, and navigation in premium marketplace concepts.

## Project Details
- **Slug:** `myauction-000000`
- **Views:** 90
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Minimal, Gradient, Large Type, Auction, Mobile App UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

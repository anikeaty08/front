# Myde Afolabi Portifolio

A reusable portfolio template for product, brand, and no-code designers to showcase services, selected work, case studies, and contact details.

## Project Details
- **Slug:** `myde-afolabi-portifolio`
- **Views:** 80
- **Tags:** Portfolio, Services, Brand, Technology, Dark, Minimal, Clean, designer portfolio, case study, no-code
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

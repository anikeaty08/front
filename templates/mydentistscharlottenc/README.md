# Dental Clinic Landing Page Template

A modern My Dentists landing page template for dental clinics to showcase services, pricing, testimonials, and online appointment bookings.

## Project Details
- **Slug:** `mydentistscharlottenc`
- **Views:** 57
- **Tags:** Health, Landing Page, Services, Brand, Clean, Dark, Gradient, Large Type, Portfolio, Dental
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Practice Landing Page Template

A modern dental practice landing page template with appointment booking form, trust metrics, and partner logos to convert visitors into new patients.

## Project Details
- **Slug:** `myfavouriteportfolio`
- **Views:** 14
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, Large Type, Gradient, Dental, Appointment Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

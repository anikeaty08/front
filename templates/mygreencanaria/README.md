# Mountain Retreat Rental Landing Page Template

A serene, nature-focused landing page template for promoting eco-friendly mountain or cave house rentals like My Green Canaria.

## Project Details
- **Slug:** `mygreencanaria`
- **Views:** 30
- **Tags:** Landing Page, Travel, Services, Brand, Clean, Minimal, Large Type, Nature, Vacation Rental, Eco Lodge
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

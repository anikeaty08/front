# Home Services Landing Page Template

Conversion-focused landing page template for a modern home services membership brand, perfect for HVAC, plumbing, electrical, and appliance repair plans.

## Project Details

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

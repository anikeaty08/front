# FX Book

A reusable trading journal template for forex and crypto traders to log trades, review performance, and track psychology with dashboards and calendars.

## Project Details
- **Slug:** `mytradingfxbook`
- **Views:** 50
- **Tags:** Technology, Landing Page, Dark, Clean, Minimal, Dashboard, Trading Journal, Finance, Analytics
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

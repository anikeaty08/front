# African Beverage Brand Landing Page Template

A premium landing page template for African beverage and heritage brands, showcasing vision, sustainability, news, and contact in a modern, urban layout.

## Project Details
- **Slug:** `myurbanafrica1`
- **Views:** 43

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Naija Translators Directory Landing Page Template

A modern template for a Nigerian translators directory, letting you list verified language experts, browsing filters, and CTAs to add or search listings.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

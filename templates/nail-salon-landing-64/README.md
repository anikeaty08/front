# dear nail

A reusable nail salon landing page template for showcasing services, pricing, locations, and bookings for modern beauty or nail studios.

## Project Details
- **Slug:** `nail-salon-landing-64`
- **Views:** 39
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Beauty, Nail Salon, Pricing, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

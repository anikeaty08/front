# Nail Salon Landing Page Template

A refined landing page template for manicure and pedicure salons to showcase services, testimonials, contact details, and online booking.

## Project Details
- **Slug:** `nail-studio-landing-54`
- **Views:** 85
- **Tags:** Landing Page, Services, Fashion, Clean, Minimal, Brand, beauty salon, nail salon, booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

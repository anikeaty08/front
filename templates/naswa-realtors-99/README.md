# Real Estate Realtor Landing Page Template

A modern real estate landing page template for local property dealers and consultants to showcase listings, services, reviews, and capture enquiries.

## Project Details
- **Slug:** `naswa-realtors-99`
- **Views:** 43

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

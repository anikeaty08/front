# Natural Cosmetics E-commerce Landing Page Template

Elegant e-commerce landing page template for natural cosmetics brands to showcase products, rituals, and brand story with a clean, nature-inspired design.

- **Slug:** `natural-cosmetics-36`
- **Views:** 10

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

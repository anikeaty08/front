# Nature Travel Trip Catalog Dashboard Template

A clean Trip Catalog Dashboard template for nature tour operators to manage trip templates, group departures, and website sync in one streamlined interface.

## Project Details
- **Slug:** `nature-travel-8`
- **Views:** 15
- **Tags:** Travel, Services, Landing Page, Brand, Clean, Minimal, Dashboard, Admin, Trip Management, Tour Operator
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# NCAA Recruiting Timeline Landing Page Template

A dark, interactive NCAA women’s lacrosse recruiting timeline template that helps athletes visualize D1, D2, and D3 milestones, rules, and key actions.

## Project Details
- **Slug:** `ncaa-women-s-lacrosse-1`
- **Views:** 40
- **Tags:** Landing Page, Education, Sports Recruiting, Clean, Dark, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

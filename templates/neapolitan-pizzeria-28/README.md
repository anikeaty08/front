# Pizza Delivery and Restaurant Website Template

A warm and artisanal website template designed for local pizzerias featuring a full digital menu and integrated cart functionality.

## Project Details
- **Slug:** `neapolitan-pizzeria-28`
- **Views:** 425
- **Tags:** Landing Page, Food, Services, Clean, Minimal, Animated, Large Type, E-commerce
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

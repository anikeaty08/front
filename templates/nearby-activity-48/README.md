# Nearby Activity UI System Template

A reusable UI system template designed for building activity discovery and social connection apps with onboarding, profiles, chat, and interactive filters.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

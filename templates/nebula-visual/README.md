# Nebula Marketing Site Template

A reusable marketing site template designed for visual website builders to showcase features, pricing, and client testimonials with modern UI.

## Project Details
- **Slug:** `nebula-visual`
- **Views:** 2646
- **Tags:** Landing Page, Features, Pricing, Testimonials, Visual Builder, No Code, Collaboration, Web Design, SaaS, Call to Action
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

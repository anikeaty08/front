# Luxury Interior Design Landing Page Template

A reusable landing page template for interior design studios to showcase services, portfolio projects, testimonials, and consultation booking.

## Project Details
- **Slug:** `neer-interior-architects`
- **Views:** 32
- **Tags:** Landing Page, Services, Interior Design, Portfolio, Brand, Clean, Minimal, Elegant, Luxury
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

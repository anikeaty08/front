# Community Event Partnership Landing Page Template

A reusable landing page template for community apps or social platforms to present venue partnerships, growth models, event systems, and city launch plans.

## Project Details
- **Slug:** `neer-rooted1`
- **Views:** 70
- **Tags:** Landing Page, Social, Membership, Services, Brand, Clean, Minimal, Community, Event Marketing, Partnership
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

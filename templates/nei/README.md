# Health Clinic Landing Page Template

Modern health clinic landing page template for medical centers to showcase specialties, insurance plans, and appointment scheduling in a clean, patient-focused layout.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

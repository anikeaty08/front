# Neighbourhood Café Landing Page Template

A clean, modern neighbourhood café website template for showcasing your menu, story, community events, and visit details with order-ahead CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

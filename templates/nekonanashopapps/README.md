# Digital Subscription Store Landing Page Template

A mobile-first landing page template for selling discounted streaming and editing app subscriptions with guided category selection and order form checkout.

- **Slug:** `nekonanashopapps`
- **Views:** 84

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

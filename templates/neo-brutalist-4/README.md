# Modern Web Agency Landing Page Template

A sleek, dark-mode Modern Web Agency landing page template for showcasing services, portfolio, and contact inquiries for creative and tech agencies.

## Project Details
- **Slug:** `neo-brutalist-4`
- **Views:** 24
- **Tags:** Landing Page, Services, Brand, Technology, Portfolio, Clean, Dark, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

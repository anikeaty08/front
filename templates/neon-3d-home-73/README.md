# Neon 3D Engine Interface Template

A reusable Neon 3D engine interface template for web-based 3D scene editors with hierarchy, viewport, and inspector panels built on Three.js.

## Project Details
- **Slug:** `neon-3d-home-73`
- **Views:** 19
- **Tags:** Technology, Landing Page, Brand, Futuristic, Dark, 3D, Minimal, Large Type, Web App UI, Three.js
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

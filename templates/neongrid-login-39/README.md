# Arabic Online Courses Dashboard Template

A reusable NeonGrid-style Arabic dashboard template for online courses platforms, featuring dark UI, course cards, search, and student profile layout.

## Project Details
- **Slug:** `neongrid-login-39`
- **Views:** 26
- **Tags:** Landing Page, Education, Technology, Brand, Dark, Clean, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

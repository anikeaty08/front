# NeonGrid Sign In Template

This reusable sign-in template is designed for secure workspace access, featuring email login, password input, and social sign-in options.

## Project Details
- **Slug:** `neongrid-login`
- **Views:** 8777
- **Tags:** Sign In, Login Form, Workspace, Authentication, Social Login, Tailwind CSS, Dark UI, Responsive, Security, User Access
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

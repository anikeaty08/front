# Neon Soda E-commerce Template

A bold reusable e-commerce template for soda, beverage, and CPG brands featuring animated product showcases, subscriptions, testimonials, and high-conversion shopping CTAs.

## Project Details
- **Slug:** `neonpulp`
- **Views:** 50
- **Tags:** E-commerce, Food, Landing Page, Brand, Animated, Colorful, 3D, Gradient, beverage, subscription
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

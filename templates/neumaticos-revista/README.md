# Motor Sports Magazine Landing Page Template

A bold, dark-style landing page template for an online motorsports magazine to showcase news, editions, and subscriptions.

## Project Details
- **Slug:** `neumaticos-revista`
- **Views:** 501
- **Tags:** Landing Page, Brand, Entertainment, Magazine, Dark, Large Type, Minimal, Gradient, Automotive, Motorsport
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Neumorph UI Design System Landing Page Template

A reusable Neumorph UI design system landing page template showcasing soft neumorphic components, interactive depth, and WCAG-accessible Soft UI for modern products.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Neurowellness Clinic Landing Page Template

A premium landing page template for neurowellness clinics and performance-focused health brands to showcase services, methods, memberships, and booking CTAs.

- **Slug:** `neurowelln-clinic-50`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Integrative Medicine Landing Page Template

A reusable healthcare landing page template for integrative medicine clinics to promote consultations, build trust, and showcase patient success.

## Project Details
- **Slug:** `new-medicine-84`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

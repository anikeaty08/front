# Inspiration Book

A reusable dark UI template for building a random word combiner or name generator tool with dual input lists, keyboard shortcuts, and instant results.

## Project Details
- **Slug:** `new-word-generator`
- **Views:** 74
- **Tags:** Technology, Landing Page, Dark, Minimal, Clean, Tool, Generator, Productivity
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

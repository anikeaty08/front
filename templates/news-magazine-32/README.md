# News Magazine Homepage Template

Reusable news magazine homepage template inspired by Le Monde, ideal for editorial sites showcasing breaking stories, live coverage, and curated selections.

## Project Details
- **Slug:** `news-magazine-32`
- **Views:** 10
- **Tags:** Landing Page, Brand, Clean, Grid, Minimal, Large Type, News, Magazine, Editorial, French
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

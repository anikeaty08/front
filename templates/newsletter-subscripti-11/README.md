# Newsletter Subscription Thank You Page Template

A clean, modern thank you page template for confirming newsletter subscriptions and guiding new subscribers to community and content.

## Project Details
- **Slug:** `newsletter-subscripti-11`
- **Views:** 16
- **Tags:** Landing Page, Brand, Clean, Minimal, Gradient, Large Type, Newsletter, Subscription, Thank You Page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

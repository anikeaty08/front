# Curated Learning Landing Page Template

A modern, clean landing page template for curated learning platforms like NewUnic, showcasing segments, impact, process, testimonials, and a contact form.

## Project Details
- **Slug:** `newunic-curatedlearning`
- **Views:** 25
- **Tags:** Landing Page, Education, Technology, Brand, Clean, Gradient, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Nexava Startup OS Landing Page Template

A dark, futuristic landing page template for promoting an early-access SaaS “operating system” for modern startups, featuring roadmap, features, and waitlist CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

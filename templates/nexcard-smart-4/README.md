# Smart Card Platform Landing Page Template

A reusable landing page template for promoting a smart multi-purpose card platform with security, loyalty, and access control features.

## Project Details
- **Slug:** `nexcard-smart-4`
- **Views:** 19
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

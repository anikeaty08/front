# BTP Web Agency 

Conversion-focused landing page template for web agencies targeting artisans and BTP companies, optimized for showcasing done‑for‑you website services.

## Project Details
- **Slug:** `nexcraft-agency`
- **Views:** 35
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Gradient, Large Type, Dark

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

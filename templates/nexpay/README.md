# Fintech API Landing Page Template

A reusable landing page template for fintech, payments, and financial infrastructure platforms to showcase APIs, billing, compliance, and global scale.

## Project Details
- **Slug:** `nexpay`
- **Views:** 2012
- **Tags:** Landing Page, Technology, Documentation, Clean, Dark, Minimal, API, Fintech, Payments
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

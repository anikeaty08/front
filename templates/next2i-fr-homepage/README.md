# IT Services Landing Page Template

A modern NEXT2i-inspired landing page template for managed IT, cloud, and cybersecurity service providers to showcase offerings, expertise, and lead-generation CTAs.

## Project Details
- **Slug:** `next2i-fr-homepage`
- **Views:** 43
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Dark, Gradient, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

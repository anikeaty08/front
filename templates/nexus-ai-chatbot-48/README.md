# Restaurant Landing Page Template

A refined dark-theme restaurant landing page template for all-you-can-eat or world cuisine venues, ready to customize for your own brand.

## Project Details
- **Slug:** `nexus-ai-chatbot-48`
- **Views:** 26
- **Tags:** Landing Page, Food, Brand, Dark, Clean, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

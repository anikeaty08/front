# Nexus Design System Whole Site Template

A reusable landing page template for Nexus Design, a comprehensive UI component library to build scalable, high-performance digital products and design systems.

- **Views:** 1120

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

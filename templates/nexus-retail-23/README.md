# Nexus Retail POS Landing Page Template

Modern landing page template for showcasing a cloud-based retail POS system, ideal for SaaS and technology brands to present features and drive signups.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

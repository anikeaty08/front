# Modern SaaS Hero List Landing Page Template

A dark, modern SaaS hero section template with an event stream list UI, ideal for developer tools and monitoring platforms landing pages.

## Project Details
- **Slug:** `nexus-saas-hero-13`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

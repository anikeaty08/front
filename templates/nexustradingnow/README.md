# Trading Course Landing Page Template

A dark, premium landing page template for promoting a price action swing trading course and private community, ready to reuse for education-based trading programs.

## Project Details
- **Slug:** `nexustradingnow`
- **Views:** 98
- **Tags:** Landing Page, Education, Services, Dark, Minimal, Brand, Large Type, Technology, Gradient, Trading
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# IoT Network Dashboard Template

A reusable dark dashboard template for monitoring IoT devices, network health, geolocation, and resource usage in real time.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Fashion College Landing Page Template

A bold, responsive landing page template for fashion and design colleges to showcase programs, campus life, and industry-linked education.

- **Slug:** `niftteafashioncollege`
- **Views:** 29

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

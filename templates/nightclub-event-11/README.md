# Nightclub Landing Page Template

A dark, sophisticated nightclub landing page template for promoting Afrobeat and R&B events, showcasing social nights, venue details, and contact form.

## Project Details
- **Slug:** `nightclub-event-11`
- **Views:** 25
- **Tags:** Landing Page, Entertainment, Brand, Dark, Minimal, Large Type, Social, Music, Events
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Nightclub Event Landing Page Template

A dark, sophisticated nightclub landing page template for promoting Afrobeat and R&B events, showcasing social photos, venue details, and a partner contact form.

## Project Details
- **Slug:** `nightclub-event-51`
- **Views:** 32
- **Tags:** Landing Page, Entertainment, Nightclub, Brand, Dark, Minimal, Large Type, Grid, Social
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

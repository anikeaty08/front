# Nightclub Landing Page Template

A dark, luxury nightclub website template for Afrobeat and Amapiano venues to showcase events, gallery, location, and contact in a sleek, ready-to-edit layout.

## Project Details
- **Slug:** `nightclub-event-60`
- **Views:** 211
- **Tags:** Landing Page, Entertainment, Nightclub, Event, Brand, Dark, Clean, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

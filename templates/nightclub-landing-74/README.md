# Nightclub Event Landing Page Template

A dark, sophisticated nightclub landing page template for Afrobeat and R&B venues to showcase events, location, and capture booking or partnership inquiries.

## Project Details
- **Slug:** `nightclub-landing-74`
- **Views:** 193
- **Tags:** Landing Page, Brand, Entertainment, Nightclub, Dark, Clean, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

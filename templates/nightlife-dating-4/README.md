# Nightlife Social PWA App Template

A dark, mobile-first nightlife social PWA UI template for anonymous, location-based club matching, messaging, and ephemeral profiles.

- **Slug:** `nightlife-dating-4`
- **Views:** 16

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

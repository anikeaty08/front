# SaaS Invoice Dashboard Web App Template

A modern SaaS invoice management web app template for tracking clients, invoices, and payments with a clean, dashboard-style interface.

## Project Details
- **Slug:** `nilesh-invoicely`
- **Views:** 11
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Dashboard, Invoice, Admin, Web App, SaaS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

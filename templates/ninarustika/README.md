# Estrategia de emprendimiento basado en la artesania

Elegante presentación tipo landing page template para mostrar estrategias de negocio artesanal premium, proyecciones financieras y roadmap en formato slider.

## Project Details
- **Slug:** `ninarustika`
- **Views:** 18
- **Tags:** Landing Page, Brand, Services, Clean, Minimal, Large Type, Presentation, Strategy, Financials, Roadmap
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Classifieds Marketplace Landing Page Template

A clean, modern classifieds marketplace UI template for showcasing global listings, categories, and trusted buyer–seller interactions.

## Project Details
- **Slug:** `noah-marketplace`
- **Views:** 20
- **Tags:** Landing Page, Business, Services, Technology, Clean, Minimal, Grid, Large Type, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

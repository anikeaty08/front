# Luxury Fashion Landing Page Template

This reusable landing page template is designed for luxury fashion ateliers to showcase collections, philosophy, bespoke services, and facilitate customer engagement.

- **Slug:** `noir-haute-couture`
- **Views:** 2070

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Developer Portfolio Landing Page Template

A clean, responsive portfolio landing page template for developers and designers, with sections for work, skills, about, testimonials, and contact.

## Project Details
- **Slug:** `nomandeveloper-`
- **Views:** 34
- **Tags:** Landing Page, Portfolio, Art & Design, Clean, Minimal, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

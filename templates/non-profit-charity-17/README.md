# Associação Abrigo para a Vida

A modern, donation-focused landing page template for non-profit associations to showcase their mission, campaigns, impact, and ways to help.

## Project Details
- **Slug:** `non-profit-charity-17`
- **Views:** 8
- **Tags:** Landing Page, Non-profit, Social, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

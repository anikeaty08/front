# Non-profit Charity Landing Page Template

A reusable Arabic RTL landing page template for non-profit charity campaigns to showcase impact, drive donations, and recruit volunteers.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

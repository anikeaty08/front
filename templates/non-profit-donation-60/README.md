# Non-profit Donation Landing Page Template

A modern donation landing page template for non-profit associations to collect online donations, bank transfers, and 3.5% tax redirections.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

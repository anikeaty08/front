# Non-profit Foundation Landing Page Template

Reusable landing page template for humanitarian and non-profit foundations to showcase mission, projects, donations, partnerships, podcast, and shop.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

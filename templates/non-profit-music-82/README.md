# Non-profit Music Foundation About Page Template

A refined About page template for non-profit music foundations to present mission, history, core initiatives, and impact with a clean, heritage-inspired design.

## Project Details
- **Slug:** `non-profit-music-82`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

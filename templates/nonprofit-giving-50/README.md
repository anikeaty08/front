# Non-profit Giving Day Landing Page Template

A reusable nonprofit campaign template for promoting community giving days, showcasing impact stories, and driving donations, signups, and cause discovery.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

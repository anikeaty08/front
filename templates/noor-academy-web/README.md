# Early Education Landing Page Template

A premium early education landing page template for Montessori-style academies and preschools to showcase programs, campus, nutrition, and enrollments.

## Project Details
- **Slug:** `noor-academy-web`
- **Views:** 24
- **Tags:** Landing Page, Education, Services, Brand, Clean, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

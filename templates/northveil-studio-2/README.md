# Web Studio Landing Page Template

A dark, decisive web studio landing page template for agencies or solo founders to showcase services, process, and contact form in a high-conversion layout.

## Project Details
- **Slug:** `northveil-studio-2`
- **Views:** 2
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Minimal, Clean, Large Type, Portfolio, Web Studio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

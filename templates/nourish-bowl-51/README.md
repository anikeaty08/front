# Healthy Food Delivery Landing Page Template

A high-conversion brutalist landing page template designed for breakfast brands, healthy food snacks, and D2C food subscription services.

## Project Details
- **Slug:** `nourish-bowl-51`
- **Views:** 36
- **Tags:** Landing Page, Food, Health, Services, Brutal, Large Type, Clean, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

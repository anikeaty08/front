# AI Automation SaaS Landing Page Template

A dark, modern AI automation SaaS landing page template for enterprises, featuring services, benefits, testimonials, and pricing to showcase your AI solutions.

## Project Details
- **Slug:** `nova-ai-automation`
- **Views:** 3274

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

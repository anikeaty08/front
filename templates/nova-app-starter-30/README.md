# Nova App Starter Landing Page Template

A dark, clean app starter landing page template for showcasing interactive SaaS prototypes, dashboards, and product workspaces with live preview UI.

## Project Details
- **Slug:** `nova-app-starter-30`
- **Views:** 7
- **Tags:** Landing Page, Technology, Brand, Dark, Clean, Minimal, Gradient, Dashboard, SaaS, Prototype
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

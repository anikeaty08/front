# All-in-One BPM

A dark, futuristic landing page template for music artist incubators or creative coaching programs, ready to customize for your own artist accelerator.

## Project Details
- **Slug:** `nova-bpm`
- **Views:** 97
- **Tags:** Landing Page, Brand, Entertainment, Dark, Futuristic, Minimal, Large Type, Music, Creative Coaching
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

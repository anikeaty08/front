# NOVA Digital Agency Landing Page Template

A sleek, dark-mode NOVA digital marketing and blog landing page template for agencies to showcase services, process, insights, and drive contact leads.

- **Slug:** `nova-dijital-34`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Aeterna Legacy AI Landing Page Template

Aeterna is a dark, futuristic landing page template for privacy-first AI legacy archives, ideal for concept-stage products validating demand and trust.

## Project Details
- **Slug:** `nova-product-35`
- **Views:** 11
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Futuristic, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

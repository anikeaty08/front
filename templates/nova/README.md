# Creative VR Studio Landing Page Template

This reusable landing page template is designed for creative VR studios to showcase immersive virtual reality experiences, capabilities, projects, and client testimonials.

## Project Details
- **Slug:** `nova`
- **Views:** 1570
- **Tags:** Landing Page, Hero, Features, Portfolio, Testimonials, VR, Immersive, Creative Studio, Technology, Contact
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Nova AI Technologies

A reusable landing page template for AI studios and digital agencies to showcase services, custom platforms, automation systems, and conversion-focused CTAs.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

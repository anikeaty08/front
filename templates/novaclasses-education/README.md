# Digital Coaching Platform Landing Page Template

A dark, modern landing page template for digital coaching platforms to showcase lectures, manage content, and convert visitors into engaged students.

## Project Details
- **Slug:** `novaclasses-education`
- **Views:** 4
- **Tags:** Landing Page, Education, Technology, Brand, Dark, Clean, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# NovaPay Mobile Payments Landing Page Template

NovaPay is a reusable landing page template for modern mobile payment and smart security solutions targeting in-store retailers and proximity merchants.

## Project Details
- **Slug:** `novapay-mobile-3`
- **Views:** 20
- **Tags:** Landing Page, Technology, Services, Brand, Dark, Clean, Gradient, Large Type, Minimal, E-commerce
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

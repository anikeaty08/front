# E-commerce Product Buy Box Template

This reusable template provides a clean, user-friendly product buy box for e-commerce sites, featuring product details, pricing, color and size selection, and purchase CTAs.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

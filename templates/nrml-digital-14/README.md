# Digital Product Store Landing Page Template

A high-conversion landing page template designed for selling digital assets, UI kits, and software components with a premium dark-themed aesthetic.

## Project Details
- **Slug:** `nrml-digital-14`
- **Views:** 30
- **Tags:** E-commerce, Technology, Dark, Minimal, Clean, Graphic Design, Landing Page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Spa & Wellness Landing Page Template

A reusable template for massage spa and holistic wellness businesses, featuring hero, services, wellness, beauty, testimonials, and booking sections.

## Project Details
- **Slug:** `nubylove-massage-spa`
- **Views:** 72
- **Tags:** Landing Page, Services, Health, Brand, Clean, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

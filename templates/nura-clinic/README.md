# Health Technology Landing Page Template

A reusable landing page template for precision health, longevity medicine, and biotech brands to showcase services, protocols, memberships, and waitlist conversion.

## Project Details
- **Slug:** `nura-clinic`
- **Views:** 33
- **Tags:** Health, Technology, Landing Page, Brand, Dark, Minimal, Clean, Futuristic, Waitlist
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Health Technology Landing Page Template

A reusable landing page template for premium health-tech, longevity, or wellness brands to showcase diagnostics, protocols, pricing, and applications.

## Project Details
- **Slug:** `nura-health-clinical`
- **Views:** 50
- **Tags:** Health, Technology, Landing Page, Brand, Dark, Clean, Minimal, Animated, Futuristic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

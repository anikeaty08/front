# Nursery E-commerce Landing Page Template

A modern e-commerce landing page template for nurseries and seedling sellers to showcase catalogs, wholesale terms, and contact details in a clean layout.

## Project Details
- **Slug:** `nursery-e-commerce-11`
- **Views:** 20
- **Tags:** E-commerce, Landing Page, Services, Brand, Clean, Minimal, Gradient, Large Type, Technology, Garden
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Tree Nursery & Landscaping Template

A reusable website template for tree nurseries and landscaping businesses to showcase plants, services, testimonials, and contact-driven local marketing.

## Project Details
- **Slug:** `nursery-landscapin-82`
- **Views:** 36
- **Tags:** Landing Page, Services, Brand, Clean, Nature, Landscaping, Nursery, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

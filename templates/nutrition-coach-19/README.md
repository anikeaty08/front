# Health Coaching Landing Page Template

A clean, modern landing page template for nutritionists and health coaches to promote services, pricing, and app-based coaching programs.

## Project Details
- **Slug:** `nutrition-coach-19`
- **Views:** 35
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, Nutrition, Coaching

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

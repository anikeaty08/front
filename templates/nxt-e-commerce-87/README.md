# NovaMart E-commerce Landing Page Template

A modern NovaMart-themed e-commerce landing page template with hero, categories, featured products, cart sidebar, and promo banner for online shops.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

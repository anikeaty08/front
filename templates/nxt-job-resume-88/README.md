# Job Matching Web App Template

A modern job-matching web app template with signup, resume upload, skill extraction, and recommended roles flow, ready to customize for recruitment platforms.

## Project Details
- **Slug:** `nxt-job-resume-88`
- **Views:** 28
- **Tags:** Technology, Services, Landing Page, Clean, Minimal, Brand, Large Type, Gradient, job board, recruitment
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

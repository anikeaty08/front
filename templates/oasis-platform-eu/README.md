# Oasis Social Feed Web App Template

A modern Oasis-inspired social feed UI template for building unified, multi-context social or community web apps with dark mode and Tailwind CSS.

## Project Details
- **Slug:** `oasis-platform-eu`
- **Views:** 21
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Minimal, Large Type, Social, Dashboard UI, React
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

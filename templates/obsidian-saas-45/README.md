# Obsidian SaaS Dashboard UI Template

A dark-mode Obsidian workspace template featuring login and analytics dashboard layouts for modern SaaS, finance, and admin web apps.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Environmental Analytics Dashboard Template

An interactive template for an ocean plastic management dashboard with upload, AI prediction, simulation, and impact analytics sections ready to customize.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

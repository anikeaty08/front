# Offroad Driving School Landing Page Template

A modern dark-theme landing page template for 4x4 offroad driving schools and adventure training centers to showcase courses, expertise, and capture inquiries.

## Project Details
- **Slug:** `off-road-driving-6`
- **Views:** 40
- **Tags:** Landing Page, Services, Travel, Brand, Dark, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

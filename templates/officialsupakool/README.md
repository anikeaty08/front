# $UPA Entertainment Hub Dashboard Template

A dark, glassmorphism dashboard UI template for creating a password-gated entertainment hub with games, music, soundboard, cinema, themes, and global search.

## Project Details
- **Slug:** `officialsupakool`
- **Views:** 21
- **Tags:** Landing Page, Technology, Entertainment, Dark, Clean, Minimal, Dashboard, Glassmorphism, Gaming, Music
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

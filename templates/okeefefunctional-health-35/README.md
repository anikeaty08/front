# Functional Health Clinic Landing Page Template

A reusable landing page template for functional health clinics to showcase services, build trust, and drive free consultation bookings.

## Project Details
- **Slug:** `okeefefunctional-health-35`
- **Views:** 18
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Brand, testimonials, medical, wellness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Oktal AI Site Builder

A high-performance dark-mode landing page template for AI-powered SaaS and web builders featuring GPT-5 integration and Tailwind optimization.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

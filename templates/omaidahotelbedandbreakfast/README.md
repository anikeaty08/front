# Boutique Bed & Breakfast Landing Page Template

A modern dark-style Bed & Breakfast landing page template for showcasing rooms, dining, location, and offers with a built-in booking bar and newsletter.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

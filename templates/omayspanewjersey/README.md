# Spa & Wellness Landing Page Template

A reusable spa and wellness landing page template for showcasing scalp treatments, services, location, and online booking for local salons or studios.

## Project Details
- **Slug:** `omayspanewjersey`
- **Views:** 110
- **Tags:** Landing Page, Services, Health, Brand, Clean, Minimal, Large Type, Gradient, Spa, Wellness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

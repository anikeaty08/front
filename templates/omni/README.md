# Omni Team Collaboration Landing Page Template

This reusable landing page template is designed to showcase a team collaboration platform with features, pricing, and professional profiles for SaaS projects.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

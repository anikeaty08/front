# Oncore Health Clinic

A modern medical spa landing page template designed for clinics offering aesthetic treatments, acne care, and wellness services to attract new clients.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

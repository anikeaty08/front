# Educational Mobile App UI Template

A gamified mobile app template for learning platforms, featuring onboarding, streaks, rewards, shorts, and project-based progress screens.

## Project Details
- **Slug:** `one-app-onboarding`
- **Views:** 81
- **Tags:** Education, Technology, Landing Page, Clean, Colorful, Mobile App, Gamification, UI Kit, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

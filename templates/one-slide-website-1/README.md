# One Slide Website Landing Page Template

A reusable one-slide website landing page template for freelancers and small businesses to showcase services, pricing, and CTAs with a bold, modern design.

## Project Details
- **Slug:** `one-slide-website-1`
- **Views:** 530
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Gradient, Minimal, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

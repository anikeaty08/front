# Online Library Landing Page Template

Modern RTL online library landing page template for book and audiobook platforms, featuring subscriptions, search, user accounts, and responsive design.

## Project Details
- **Slug:** `online-book-library-25`
- **Views:** 12
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Dark, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Online Course Landing Page Template

A dark, modern landing page template for Ukrainian online courses and educational programs, ready to reuse for selling modular training with clear outcomes.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

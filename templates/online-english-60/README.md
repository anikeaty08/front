# Online English Course Landing Page Template

A modern LingOwl-branded landing page template for promoting online English courses, perfect for language schools and tutors to convert visitors into students.

## Project Details
- **Slug:** `online-english-60`
- **Views:** 8
- **Tags:** Landing Page, Education, Services, Brand, Clean, Minimal, Large Type, Technology

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

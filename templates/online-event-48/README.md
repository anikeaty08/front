# Evento Online Espiritual Landing Page Template

Landing page template para promocionar un evento online espiritual de 3 días, ideal para captar registros y presentar ponente, agenda y mensaje central.

## Project Details
- **Slug:** `online-event-48`
- **Views:** 11
- **Tags:** Landing Page, Education, Religious, Clean, Minimal, Brand, Event, Spiritual, Online Workshop, Registration
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

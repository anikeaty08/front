# Online Exam Interface Template

A modern SSC-style online exam interface template for timed mock tests, question navigation, and status tracking, ready to adapt for any test portal.

## Project Details
- **Slug:** `online-exam-portal-78`
- **Views:** 7
- **Tags:** Education, Landing Page, Services, Clean, Minimal, Technology, Mock Test, Exam Portal, Online Test
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

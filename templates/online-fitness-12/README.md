# Online Fitness Coach Landing Page Template

A reusable landing page template for online fitness coaches to showcase programs, testimonials, and consultations that convert busy adults into clients.

## Project Details
- **Slug:** `online-fitness-12`
- **Views:** 65
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Personal Trainer, Fitness Coach
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

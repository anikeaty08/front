# Latino Online Radio Landing Page Template

Vibrant online radio landing page template for Latin music stations to showcase live streaming, shows, hosts, news, and contact in a modern, mobile-first design.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

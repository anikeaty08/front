# Online Quran Academy Landing Page Template

A modern, conversion-focused landing page template for online Quran, Tajweed, Hifz, and Arabic academies to showcase courses and book free trial classes.

## Project Details
- **Slug:** `online-quran-18`
- **Views:** 304
- **Tags:** Landing Page, Education, Services, Brand, Dark, Clean, Minimal, Large Type, Religious, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

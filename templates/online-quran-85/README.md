# Online Quran Tajweed Classes Landing Page Template

A reusable landing page template for promoting online Tajweed and Quran recitation classes with pricing, syllabus, instructor bio, and registration form.

## Project Details
- **Slug:** `online-quran-85`
- **Views:** 35
- **Tags:** Landing Page, Education, Religious, Services, Brand, Clean, Minimal, Large Type, Gradient, Social
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

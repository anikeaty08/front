# Education Landing Page Template

A reusable education landing page template for online tutoring brands to showcase programs, pricing, and trial-class booking with a guided onboarding flow.

## Project Details
- **Slug:** `online-tutoring-etw`
- **Views:** 56
- **Tags:** Landing Page, Education, Services, Clean, Minimal, Technology, tutoring, pricing, onboarding, lead generation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

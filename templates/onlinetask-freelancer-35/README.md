# OnlineTasks Freelancer Landing Page Template

A modern OnlineTasks-style landing page template for digital freelancer and micro-task platforms, optimized to convert visitors into new earners.

## Project Details
- **Slug:** `onlinetask-freelancer-35`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

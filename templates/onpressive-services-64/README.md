# Creative Services List Section Template

A reusable dark-themed services list template for agencies and studios, featuring hover-triggered descriptions and imagery for service offerings.

## Project Details
- **Slug:** `onpressive-services-64`
- **Views:** 15
- **Tags:** Landing Page, Services, Brand, Art & Design, Portfolio, Dark, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Onyx Mobile Detailing Landing Page Template

Premium dark-style landing page template for mobile car detailing businesses to showcase services, benefits, and bookings with a modern, high-end aesthetic.

## Project Details
- **Slug:** `onyxdetails`
- **Views:** 10
- **Tags:** Landing Page, Services, Brand, Dark, Minimal, Large Type, Gradient, Automotive, Car Detailing, Mobile Service
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

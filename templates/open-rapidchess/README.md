# Chess Tournament Landing Page Template

A modern template for promoting open rapid chess tournaments with event details, prize structure, rules, and registration calls-to-action.

## Project Details
- **Slug:** `open-rapidchess`
- **Views:** 29
- **Tags:** Landing Page, Event, Technology, Brand, Dark, Gradient, Large Type, Minimal, Social, Sports
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

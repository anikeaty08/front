# Langfuse LLM Platform Landing Page Template

A reusable landing page template for an open-source LLM engineering platform, ideal for showcasing AI observability, evaluations, pricing, and documentation.

## Project Details
- **Slug:** `open-source-llm-10`
- **Views:** 630

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

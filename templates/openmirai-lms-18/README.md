# OpenMirai LMS Landing Page Template

Modern Thai-language LMS SaaS landing page template for promoting an online learning platform, showcasing features, pricing, and conversion-focused CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

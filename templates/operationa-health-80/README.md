# Operational Health Dashboard UI Template

A dark, real-time operational health dashboard UI template for firewall and network monitoring teams to visualize system status, interfaces, logs, and alerts.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Portuguese Restaurant Landing Page Template

A modern Portuguese restaurant landing page template for showcasing menus, locations, awards, and reviews for family-run eateries and casual dining brands.

## Project Details
- **Slug:** `operiperi`
- **Views:** 20
- **Tags:** Food, Landing Page, Brand, Clean, Dark, Gradient, Large Type, Restaurant, Portuguese, Menu
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

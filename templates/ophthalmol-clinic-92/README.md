# Ophthalmology Clinic Website Template

A premium healthcare website template for ophthalmology clinics to showcase treatments, doctors, locations, reviews, and appointment booking.

## Project Details
- **Slug:** `ophthalmol-clinic-92`
- **Views:** 65
- **Tags:** Health, Services, Full Website, Clean, Minimal, Brand, Landing Page, Medical, Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

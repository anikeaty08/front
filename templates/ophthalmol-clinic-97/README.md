# Ophthalmology Clinic Landing Page Template

A premium ophthalmology clinic template for eye care centers to showcase treatments, doctors, locations, FAQs, and drive appointment bookings.

## Project Details
- **Slug:** `ophthalmol-clinic-97`
- **Views:** 90
- **Tags:** Health, Landing Page, Services, Clean, Gradient, Minimal, Medical, Clinic, Ophthalmology, Doctors
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

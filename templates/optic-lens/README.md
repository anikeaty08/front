# Optic Community Landing Page Template

A dark, modern landing page template for Optic-style photography communities to showcase lens reviews, sample galleries, memberships, and a verified gear marketplace.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Optical Services Dashboard Template

A reusable dashboard-style template for optical clinics, eyewear brands, and optician networks to showcase specialists, locations, and service offerings.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

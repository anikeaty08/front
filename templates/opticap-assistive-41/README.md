# Assistive Tech Product Landing Page Template

A modern assistive technology landing page template for showcasing smart wearables like OptiCap, including problem, solution, features, and financials sections.

## Project Details
- **Slug:** `opticap-assistive-41`
- **Views:** 34
- **Tags:** Landing Page, Technology, Health, Brand, Clean, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Options Education Landing Page Template

A reusable landing page template for an options trading education brand, featuring visual lessons, broker walkthroughs, and a waitlist-focused funnel.

## Project Details
- **Slug:** `options-demystified`
- **Views:** 96
- **Tags:** Landing Page, Education, Technology, Brand, Dark, Gradient, Large Type, Clean, Minimal, Financial
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# OrbiSwap DeFi Landing Page Template

A modern OrbiSwap-inspired DeFi landing page template for Arbitrum token swap apps, showcasing non-custodial DEX features and a 3D swap UI.

## Project Details
- **Slug:** `orbiswap-defi-dex`
- **Views:** 18
- **Tags:** Landing Page, Technology, Brand, Clean, Gradient, Large Type, Futuristic, DeFi, Web3, Arbitrum
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

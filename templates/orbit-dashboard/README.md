# Dashboard Analytics Template

A sleek and modern dashboard analytics template designed for monitoring orders, registrations, revenue, and customer retention with interactive charts and KPI cards.

## Project Details
- **Slug:** `orbit-dashboard`
- **Views:** 2520
- **Tags:** Dashboard, Analytics, KPI, Charts, Metrics, Reports, User Profile, Navigation, Responsive, Dark Theme
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

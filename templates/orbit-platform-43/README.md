# Developer Platform Dashboard UI Template

A dark, modern developer platform dashboard UI template for monitoring deployments, system health, and team activity in one clean, ready-to-use layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

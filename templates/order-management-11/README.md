# E-commerce Order Management Dashboard Template

A reusable e-commerce admin template for managing order details, product purchasing status, customer messaging, logistics assignment, and billing summaries.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

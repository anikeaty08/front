# Pickup Tracking Mobile App Template

A reusable mobile app template for package pickup confirmation, QR verification, and order status tracking with a polished delivery experience.

## Project Details
- **Slug:** `order-pickup-23`
- **Views:** 20
- **Tags:** Technology, Landing Page, Clean, Minimal, 3D, Mobile UI, QR Code, Order Tracking, Delivery
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

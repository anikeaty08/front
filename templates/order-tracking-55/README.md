# Order Tracking Landing Page Template

A reusable order tracking template for confirming payments, showing group shipping progress, and driving follow-up actions after checkout.

- **Slug:** `order-tracking-55`
- **Views:** 71

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

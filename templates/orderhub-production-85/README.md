# OrderHub Production Dashboard UI Template

A dark, modern production orders dashboard template for managing print and plate jobs with statuses, tooltips, and table views for operations teams.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

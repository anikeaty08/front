# Organic Grocery E-commerce Landing Page Template

A modern template for farm-to-table and organic grocery brands to launch an e-commerce landing page with hero, product grid, and trust sections.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Philosophical Course Landing Page Template

A reusable landing page template for showcasing a self-guided philosophical program with audio lessons, guided paths, downloadable resources, and reflective content.

## Project Details
- **Slug:** `origin-membre`
- **Views:** 63

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

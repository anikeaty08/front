# Orthodontist Landing Page Template

A clean, modern orthodontist website template for dental specialists to showcase services, experience, and contact details with clear appointment CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

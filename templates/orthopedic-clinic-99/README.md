# Orthopedic Clinic Landing Page Template

A modern orthopedic clinic landing page template for private medical practices to showcase services, expertise, and drive online appointment requests.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Ortopedista y Traumatóloga Landing Page Template

Landing page template para médicos ortopedistas y traumatólogos que desean presentar especialidades, trayectoria, testimonios y agendar citas por WhatsApp.

## Project Details
- **Slug:** `ortopedist-y-80`
- **Views:** 41
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Medical, Doctor, WhatsApp Citas
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

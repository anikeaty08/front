# OS Simulator Desktop Environment Template

This template simulates a desktop OS environment with multiple draggable windows, a dock, and interactive system controls for UI prototyping and app demos.

## Project Details
- **Slug:** `os-simulator-desktop-4`
- **Views:** 274
- **Tags:** Landing Page, Desktop UI, Window Manager, Draggable Windows, Dock, System Controls, Login Screen, Spotlight Search, Control Center
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

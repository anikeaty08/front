# Cleaning Services & Training Landing Page Template

A modern French-language landing page template for cleaning services and professional training providers to showcase offers, build trust, and capture quote requests.

## Project Details
- **Slug:** `ospservices`
- **Views:** 37
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Gradient, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

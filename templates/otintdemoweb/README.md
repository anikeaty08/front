# otintdemoweb

A modern, brand-ready landing page template for local auto glass, ADAS calibration, tint, PPF, and wrap service businesses to showcase services and capture leads.

## Project Details
- **Slug:** `otintdemoweb`
- **Views:** 31
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Large Type, Automotive, Local Business, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# OTP Verification Mobile UI Template

A reusable mobile app template for secure OTP number verification, featuring polished code inputs, resend timing, and a clear account confirmation flow.

## Project Details
- **Slug:** `otp-verificati-18`
- **Views:** 81
- **Tags:** Landing Page, Technology, Clean, Gradient, Minimal, Mobile UI, OTP, Verification, Authentication
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

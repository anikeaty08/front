# Outdoor Fitness App Landing Page Template

A high-converting landing page template for mobile outdoor fitness and wellness apps, showcasing locations, schedules, pricing, and app downloads.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Outlaw Covenant Mobile App UI Template

A dark, cinematic mobile app UI template for motorcycle or private club membership dashboards, rides, tickets, and encrypted comms screens.

## Project Details
- **Slug:** `outlaw-covenant-75`
- **Views:** 29
- **Tags:** Landing Page, Brand, Entertainment, Dark, Clean, Minimal, Mobile UI, Membership, Motorcycle Club
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

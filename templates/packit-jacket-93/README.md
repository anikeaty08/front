# Packit Jacket Product Landing Page Template

A reusable landing page template designed to showcase a travel jacket with huge pockets that replaces carry-on luggage and helps users avoid airline baggage fees.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

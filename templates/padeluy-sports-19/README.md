# PadelUY Sports Community Landing Page Template

A reusable landing page template designed to promote a Uruguayan padel app that connects players, offers court booking, matchmaking, and rankings.

## Project Details
- **Slug:** `padeluy-sports-19`
- **Views:** 48
- **Tags:** Landing Page, Sports, App Promotion, Matchmaking, Rankings, Court Booking, Community, Mobile App, CTA, Testimonials
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

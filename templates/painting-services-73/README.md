# Painting Services Landing Page Template

A reusable landing page template for painting and decorating businesses to showcase services, portfolio, testimonials, and capture quote requests.

## Project Details
- **Slug:** `painting-services-73`
- **Views:** 133

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Video Platform UI Template

A reusable YouTube-style video platform UI template for building modern, dark-mode video streaming or content library web apps.

## Project Details
- **Slug:** `pakyoutubepromod`
- **Views:** 9
- **Tags:** Landing Page, Technology, Brand, Dark, Clean, Grid, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

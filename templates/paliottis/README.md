# Italian Family Restaurant Landing Page Template

A reusable landing page template designed for Italian family restaurants to showcase their legacy, menu, locations, and customer testimonials.

## Project Details
- **Slug:** `paliottis`
- **Views:** 992
- **Tags:** Landing Page, Hero, Features, Menu, Testimonials, Locations, Reservations, Blog, VIP Access, Family Restaurant
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Palm beach concierge medicine

A premium landing page template for concierge and direct primary care practices to showcase relationship-based medicine, benefits, and membership details.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

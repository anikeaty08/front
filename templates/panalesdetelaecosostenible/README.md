# Guía Pañales de Tela Landing Page Template

Landing page template en español para una guía educativa de pañales de tela, ideal para marcas que quieran explicar beneficios, uso y kits de inicio.

## Project Details
- **Slug:** `panalesdetelaecosostenible`
- **Views:** 15
- **Tags:** Landing Page, Education, Health, Brand, Clean, Minimal, Large Type, Spanish, Scroll Storytelling, baby care
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Paperplane File Sharing App UI Template

Mobile-first Paperplane file sharing app UI template for instant, no-login uploads, text snippets, secure downloads, and expiry states, ready for product demos or prototypes.

## Project Details
- **Slug:** `paperplanefilesharing`
- **Views:** 40
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Gradient, Large Type, File sharing, Mobile app UI, Product demo
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

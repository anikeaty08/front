# Paramus Dental Arts Modernized Website

A modern dental clinic landing page template for cosmetic, implant, and family dentistry practices to showcase services, locations, and online appointment requests.

## Project Details
- **Slug:** `paramusdentalarts`
- **Views:** 41
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

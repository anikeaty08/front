# Tattoo Studio Landing Page Template

A dark, high-impact tattoo studio landing page template for showcasing artists, services, reviews, and driving booking enquiries online.

## Project Details
- **Slug:** `parralax`
- **Views:** 25
- **Tags:** Landing Page, Services, Brand, Entertainment, Portfolio, Dark, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

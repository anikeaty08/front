# Partner Affiliate Dashboard UI Template

A reusable PartnerFlow-style affiliate portal dashboard template for managing referrals, leads, deals, earnings, payouts, and invoices in one clean interface.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Tiling Services Landing Page Template

A professional tiling services landing page template for showcasing wall, bathroom, kitchen, and tomb projects with portfolio, contact form, and call features.

## Project Details
- **Slug:** `pascaltiling-services-96`
- **Views:** 6
- **Tags:** Landing Page, Services, Business, Portfolio, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

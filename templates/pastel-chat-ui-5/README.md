# Pastel Chat UI Template

A cozy, pastel real-time chat UI template for messaging apps, showcasing conversations, reactions, and composer interactions ready for reuse.

## Project Details
- **Slug:** `pastel-chat-ui-5`
- **Views:** 20
- **Tags:** Technology, Brand, Clean, Colorful, Gradient, Minimal, Landing Page, chat ui, messaging template, tailwind
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

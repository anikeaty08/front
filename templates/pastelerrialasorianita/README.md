# Artisanal Bakery Landing Page Template

Elegant bakery website template for showcasing an artisanal catalog, brand story, and location details for local pastry shops and panaderías.

## Project Details
- **Slug:** `pastelerrialasorianita`
- **Views:** 538
- **Tags:** Landing Page, Food, Brand, Clean, Minimal, Large Type, Colorful, Art & Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

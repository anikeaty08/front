# Bakery Landing Page 

A stylish bakery website template for showcasing cakes, menus, custom orders, testimonials, and WhatsApp-based ordering for boutique bake shops.

- **Slug:** `pastrymaniadevanahalli`
- **Views:** 690
- **Tags:** Food, Landing Page, E-commerce, Brand, Clean, Minimal, Elegant, Bakery, WhatsApp Ordering

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

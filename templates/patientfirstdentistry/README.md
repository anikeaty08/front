# Patient-First Dentistry Website

A modern dental practice landing page template for showcasing services, doctor profiles, and appointment booking for local patient acquisition.

## Project Details
- **Slug:** `patientfirstdentistry`
- **Views:** 22
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Dental, Medical, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

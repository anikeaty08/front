# Plumbing Services Landing Page Template

A modern plumbing services landing page template for local residential and commercial contractors to showcase offerings, reviews, and capture quote requests.

## Project Details
- **Slug:** `patrick-s-plumbing`
- **Views:** 17
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mobile Money SaaS Landing Page Template

Conversion-focused landing page template for a Mobile Money invoicing SaaS, tailored to PME billing, payments, and pricing in Côte d'Ivoire.

## Project Details
- **Slug:** `payfact-invoicing-35`
- **Views:** 35
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Large Type, Gradient, Payment, Mobile Money
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Payment Confirmation Landing Page Template

A reusable payment confirmation template for wellness or service businesses that guides new customers to complete onboarding steps after purchase.

## Project Details
- **Slug:** `payment-confirmati-24`
- **Views:** 75
- **Tags:** Landing Page, Services, Health, Clean, Minimal, Dark, onboarding, payment confirmation, post-purchase
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

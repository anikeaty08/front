# Payment History Modal UI Template

A reusable template for a payment history and management modal interface with filters, status, and actions, ideal for finance or visa-tracking web apps.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

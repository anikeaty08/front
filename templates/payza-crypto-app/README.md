# Payza Crypto Wallet

A dark, futuristic crypto wallet landing page template for promoting a self-custodial Web3 app with features, security highlights, and app download CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

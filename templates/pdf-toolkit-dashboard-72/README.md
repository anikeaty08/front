# PDF Toolkit Dashboard Template

This is a reusable dashboard template designed for managing and processing PDF documents with tools like merge, split, extract, and encrypt.

## Project Details
- **Slug:** `pdf-toolkit-dashboard-72`
- **Views:** 18
- **Tags:** Landing Page, Dashboard, PDF Tools, File Management, Upload, OCR, Dark Mode, Responsive, Task Settings, Recent Activity
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

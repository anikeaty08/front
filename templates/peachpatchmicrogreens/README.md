# Peach Patch Microgreens

A reusable template for local microgreens farms and fresh produce brands to showcase products, subscriptions, nutrition benefits, and online ordering.

## Project Details
- **Slug:** `peachpatchmicrogreens`
- **Views:** 302
- **Tags:** E-commerce, Food, Landing Page, Clean, Gradient, Brand, local produce, subscription, farm shop
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

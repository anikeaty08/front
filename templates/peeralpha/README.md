# Crypto Trading AI Landing Page Template

A dark, futuristic landing page template for AI-powered crypto trading platforms to showcase strategies, results, pricing, and security in one high-conversion layout.

## Project Details
- **Slug:** `peeralpha`
- **Views:** 84
- **Tags:** Landing Page, Technology, Brand, Dark, Futuristic, Gradient, Large Type, 3D, Clean
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# American Diner Restaurant Landing Page Template

A dark, bold American diner restaurant landing page template with full menu, reviews, and location details, ready to customize for any burger joint.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Peptide Product Landing Page Template

A reusable e-commerce template for peptide and research compound product pages, designed to showcase lab-tested details, COAs, pricing, and purchase CTAs.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

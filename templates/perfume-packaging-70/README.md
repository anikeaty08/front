# Perfume Packaging Landing Page Template

A reusable landing page template for perfume packaging manufacturers and luxury bottle suppliers to showcase products, capabilities, and generate quote inquiries.

## Project Details
- **Slug:** `perfume-packaging-70`
- **Views:** 49

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Bookstore E-commerce Website Template

A modern RTL bookstore e-commerce template for selling academic and university books online, ready to customize as your own digital shop.

## Project Details
- **Slug:** `persian-bookstore-89`
- **Views:** 15
- **Tags:** E-commerce, Landing Page, Services, Brand, Clean, Colorful, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Persona Cafe & Restro Landing Page Template

A modern dark-theme cafe and lounge landing page template for showcasing ambiance, menu, reviews, and reservations for restaurants and hookah lounges.

## Project Details
- **Slug:** `personacafeandrestro`
- **Views:** 40
- **Tags:** Landing Page, Food, Brand, Clean, Dark, Gradient, Large Type, Restaurant, cafe, hookah lounge
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

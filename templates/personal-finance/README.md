# NovaCash Financial Dashboard Landing Page Template

A reusable landing page template designed for personal finance and budgeting apps to showcase spending lanes, cashflow insights, and growth tracking.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

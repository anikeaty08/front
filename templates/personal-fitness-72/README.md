# Personal Fitness Journal Template

A reusable fitness journal template for tracking workouts, calories, diary entries, progress photos, and body measurements in one clean dashboard.

## Project Details
- **Slug:** `personal-fitness-72`
- **Views:** 20
- **Tags:** Health, Landing Page, Clean, Minimal, Dashboard, Fitness, Journal, Wellness, Tracker
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

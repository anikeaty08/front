# Personal Portfolio Landing Page Template

A reusable portfolio landing page template designed for full stack engineers and interface designers to showcase skills, experience, projects, and education.

## Project Details
- **Slug:** `personal-portfolio-45`
- **Views:** 39
- **Tags:** Portfolio, Hero, Work Experience, Skills, Projects, Education, Resume, Contact, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

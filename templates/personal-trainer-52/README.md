# Personal Trainer Gym Landing Page Template

A modern personal trainer and gym landing page template for showcasing trainers, classes, and lead-capture forms for fitness studios and local gyms.

- **Slug:** `personal-trainer-52`
- **Views:** 11

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

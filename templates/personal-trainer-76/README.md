# Personal Trainer Landing Page Template

A reusable landing page template for personal trainers and fitness coaches to showcase services, credentials, apparel, and client conversion CTAs.

## Project Details
- **Slug:** `personal-trainer-76`
- **Views:** 37

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

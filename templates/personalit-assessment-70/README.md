# Personality Assessment Landing Page Template

A dark, modern landing page template for a Jungian-based personality assessment, featuring an interactive quiz, progress tracking, and detailed MBTI-style results.

## Project Details
- **Slug:** `personalit-assessment-70`
- **Views:** 18
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Gradient, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

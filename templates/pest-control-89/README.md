# Pest Control Landing Page Template

A reusable pest control landing page template for local service businesses to promote eco-friendly treatments, build trust, and drive quote requests.

## Project Details
- **Slug:** `pest-control-89`
- **Views:** 42
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Environmental, local services, pest control, home services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

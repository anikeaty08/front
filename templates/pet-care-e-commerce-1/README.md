# Pet Care E-commerce Landing Page Template

A reusable landing page template for pet health brands to promote welcome offers, vet-approved products, and online consult-driven e-commerce sales.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

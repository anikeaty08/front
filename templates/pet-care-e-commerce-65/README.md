# Pet Care E-commerce Landing Page Template

A reusable landing page template for vet-connected pet care brands to promote prescription products, consult pathways, and first-order offers.

## Project Details
- **Slug:** `pet-care-e-commerce-65`
- **Views:** 40
- **Tags:** Landing Page, E-commerce, Health, Services, Clean, Minimal, Brand, pet care, veterinary, offer
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

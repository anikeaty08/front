# Pet Care E-commerce Landing Page Template

A reusable landing page template for online pet care stores selling prescription foods, preventatives, and medicines with guided consult flows.

## Project Details
- **Slug:** `pet-care-e-commerce-80`
- **Views:** 46
- **Tags:** E-commerce, Landing Page, Health, Services, Clean, Minimal, Brand, pet care, prescription products, veterinary

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

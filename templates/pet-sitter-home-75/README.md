# Pet Sitter Dashboard UI Template

A reusable PetGuard-inspired sitter dashboard template for managing pet profiles, emergency info, and real-time visit logs in modern web apps.

## Project Details
- **Slug:** `pet-sitter-home-75`
- **Views:** 3
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Technology, Dashboard, Pet Care, Tailwind CSS, Web App UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

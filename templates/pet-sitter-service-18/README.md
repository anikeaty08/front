# Pet Sitter Services Landing Page Template

A clean and warm landing page template for professional pet sitting and home care services, designed to build trust with pet owners.

## Project Details
- **Slug:** `pet-sitter-service-18`
- **Views:** 118
- **Tags:** Services, Health, Clean, Minimal, Noto Serif JP, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

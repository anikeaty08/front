# Local Pet Store Website Template

A warm, full-website template for independent pet stores to showcase supplies, grooming, and live animals with guided shopping and local visit CTAs.

## Project Details
- **Slug:** `pet-store-grooming-10`
- **Views:** 26
- **Tags:** E-commerce, Services, Brand, Landing Page, Clean, Colorful, Minimal, Large Type, Pet Store, Grooming
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

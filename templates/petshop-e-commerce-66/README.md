# PetShop E-commerce Landing Page Template

PetShop E-commerce Landing Page Template para lojas de pets que querem vender rações, brinquedos e acessórios online com uma vitrine moderna e completa.

## Project Details
- **Slug:** `petshop-e-commerce-66`
- **Views:** 35
- **Tags:** E-commerce, Landing Page, Brand, Clean, Colorful, Large Type, Technology, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

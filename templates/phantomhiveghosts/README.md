# Social Gaming Dashboard UI Template

A dark, futuristic social gaming dashboard UI template for community forums, media, and player profiles, ready to customize for your gaming platform.

## Project Details
- **Slug:** `phantomhiveghosts`
- **Views:** 30
- **Tags:** Landing Page, Technology, Entertainment, Dark, Futuristic, Dashboard, Social, Community, Gaming UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

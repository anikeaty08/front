# Pharmaceutical Distribution Landing Page Template

A reusable landing page template for pharmaceutical distributors, medical suppliers, and healthcare logistics teams to showcase services, compliance, and reach.

## Project Details
- **Slug:** `pharmaceut-distributi-1`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

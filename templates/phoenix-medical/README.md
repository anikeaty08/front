# Medical Travel Landing Page Template

Premium landing page template for VIP medical travel and aesthetic surgery services, ideal for agencies offering all-inclusive treatments in Turkey.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

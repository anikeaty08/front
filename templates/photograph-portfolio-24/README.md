# Photography Portfolio Website Template

A dark, cinematic photography portfolio template showcasing landscape, portrait, and cinematic work with a built-in contact modal for commissions.

## Project Details
- **Slug:** `photograph-portfolio-24`
- **Views:** 37
- **Tags:** Portfolio, Art & Design, Photography, Minimal, Dark, Large Type, Landing Page, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Photography Portfolio Landing Page Template

A reusable landing page template designed for photographers to showcase portfolios, services, and contact options with a clean, minimal mobile-friendly design.

## Project Details
- **Slug:** `photograph-portfolio`
- **Views:** 1515
- **Tags:** Landing Page, Portfolio, Photography, Services, Mobile Preview, Hero, Contact, Pricing, Visual Storytelling, Minimal Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

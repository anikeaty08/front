# Wedding Photography Portfolio Template

A refined portfolio template for wedding and portrait photographers to showcase timeless imagery, services, and inquiries with an elegant editorial feel.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

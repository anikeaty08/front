# Photography Guide Landing Page Template

A dark, minimal photography education landing page template for sharing shoot tips, gear guides, and presets with modern creators.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

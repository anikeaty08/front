# Physiotherapy Clinic Landing Page Template

A reusable landing page template for physiotherapy clinics and wellness practices to showcase treatments, team expertise, pricing, and appointment inquiries.

## Project Details
- **Slug:** `physicalmedfisio`
- **Views:** 15
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Medical, Physiotherapy, Clinic, Wellness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

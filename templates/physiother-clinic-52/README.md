# Physiotherapy Clinic Landing Page Template

A modern physiotherapy clinic landing page template for showcasing services, location, and WhatsApp booking to convert visitors into booked appointments.

## Project Details
- **Slug:** `physiother-clinic-52`
- **Views:** 64
- **Tags:** Landing Page, Health, Services, Brand, Clean, Gradient, Minimal, Large Type, Physiotherapy, Medical Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

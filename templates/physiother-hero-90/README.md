# Physiotherapy Services Landing Page Template

This reusable landing page template is designed for physiotherapy clinics to showcase services, patient benefits, and enable appointment bookings.

## Project Details
- **Slug:** `physiother-hero-90`
- **Views:** 22
- **Tags:** Landing Page, Hero, Features, Services, Testimonials, FAQ, Contact, Appointment Booking, Physiotherapy, Healthcare

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

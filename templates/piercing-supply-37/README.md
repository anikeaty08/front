# Piercing Supply E-commerce Template

A bold e-commerce template for piercing supply brands to showcase sterile tools, jewelry, wholesale offers, and product drops with a high-impact retail aesthetic.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

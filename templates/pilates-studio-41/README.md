# Pilates Studio Landing Page Template

A reusable landing page template for boutique Pilates studios to showcase classes, memberships, booking, FAQs, and a calm wellness-focused brand.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

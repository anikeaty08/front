# Pilgrimage Transport Landing Page Template

A high-conversion landing page template for pilgrimage and regional bus routes, perfect for showcasing journeys, routes, and bookings for transport operators.

## Project Details
- **Slug:** `pilgrimage-transport-98`
- **Views:** 13
- **Tags:** Landing Page, Travel, Services, Brand, Gradient, Clean, Colorful, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Clinic Landing Page Template

A modern dental clinic landing page template for local practices to showcase services, team, reviews, and appointment requests with a clean, trust-driven design.

## Project Details
- **Slug:** `pinespalmdental`
- **Views:** 12
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

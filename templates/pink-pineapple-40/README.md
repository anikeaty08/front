# Pink Pineapple Boutique E-commerce Landing Page Template

A tropical-chic e-commerce landing page template for fashion boutiques, featuring hero promotion, product grid, Instagram social proof, and newsletter signup.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

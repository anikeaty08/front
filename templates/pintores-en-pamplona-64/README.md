# Pintores Locales Landing Page Template

Plantilla de landing page para pintores locales, ideal como base reutilizable para presentar servicios de pintura, trabajos realizados y solicitar presupuestos online.

## Project Details
- **Slug:** `pintores-en-pamplona-64`
- **Views:** 20
- **Tags:** Landing Page, Services, Business, Brand, Clean, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

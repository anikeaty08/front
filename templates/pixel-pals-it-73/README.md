# Pixel Pals IT Services Landing Page Template

A reusable landing page template for local IT and tech support services, inspired by Pixel Pals, to promote computer help, Wi-Fi fixes, and device setup.

- **Slug:** `pixel-pals-it-73`
- **Views:** 707

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

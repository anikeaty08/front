# Pixel Bryndza

Retro 8-bit street food landing page template for pixel-style restaurants or food trucks to showcase menus, locations, and email offers.

## Project Details
- **Slug:** `pixel-street-food-3`
- **Views:** 24
- **Tags:** Food, Landing Page, Brand, Colorful, Gradient, Grid, Large Type, Minimal, Street Food, Restaurant
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

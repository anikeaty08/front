# Pizza Restaurant Landing Page Template

A bold restaurant template for pizzerias and fast-casual food brands to showcase menu items, delivery benefits, and drive online orders.

## Project Details
- **Slug:** `pizza-restaurant-10`
- **Views:** 523

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Pizza Restaurant Landing Page Template

A reusable restaurant website template for pizza shops featuring a bold hero, detailed menu sections, location info, and online ordering CTAs.

## Project Details
- **Slug:** `pizza-restaurant-63`
- **Views:** 527

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

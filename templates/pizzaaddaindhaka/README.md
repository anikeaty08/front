# Pizza Restaurant Landing Page Template

A bold restaurant template for pizza shops and fast-casual food brands to showcase menus, chefs, offers, testimonials, and online ordering.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Pizzeria Restaurant Website Template

A reusable restaurant template for pizzerias and local eateries to showcase menus, location details, opening hours, and food ordering calls to action.

## Project Details
- **Slug:** `pizzeria-restaurant-22`
- **Views:** 37
- **Tags:** Food, Services, Landing Page, Clean, Minimal, Restaurant, Pizzeria, Menu, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

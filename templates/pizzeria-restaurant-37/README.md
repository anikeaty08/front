# Krunni Pizzeria Menu Landing Page Template

A modern dark-theme restaurant menu landing page template for pizzerias and kebab houses to showcase pizzas, prices, hours, and contact details online.

## Project Details
- **Slug:** `pizzeria-restaurant-37`
- **Views:** 154
- **Tags:** Food, Landing Page, Brand, Clean, Dark, Minimal, Restaurant, Pizzeria, Menu, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# PKXD Universe

A futuristic gaming landing page template for promoting an open-world mobile game with avatars, pets, minigames, and community features.

## Project Details
- **Slug:** `pkxd-universe-official`
- **Views:** 11
- **Tags:** Landing Page, Entertainment, Technology, Colorful, Gradient, Large Type, Dark, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Plant-Based Cafe Landing Page Template

A clean, modern landing page template for plant-based or specialty coffee cafes to showcase menu highlights, story, gallery, and location details.

## Project Details
- **Slug:** `plant-based-cafe`
- **Views:** 27
- **Tags:** Food, Landing Page, Brand, Clean, Minimal, Gradient, Cafe, Restaurant, Vegan
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

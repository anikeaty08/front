# Plant E-commerce Landing Page Template

A modern Botanica-inspired plant e-commerce template with catalog, product detail, cart, and checkout flows ready to customize for your online shop.

## Project Details
- **Slug:** `plant-e-commerce-19`
- **Views:** 23
- **Tags:** E-commerce, Landing Page, Brand, Clean, Minimal, Gradient, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

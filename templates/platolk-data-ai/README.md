# AI Business Data Chat Landing Page Template

A dark, glassmorphism SaaS landing page template for an AI agent that lets teams chat with their business data via WhatsApp, ready to customize for your product.

- **Slug:** `platolk-data-ai`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Playerpack Landing Page Template

Playerpack is a high-converting landing page template for selling strategic design template packs to designers who want to charge premium, high-ticket fees.

## Project Details
- **Slug:** `playerpack-conversion-56`
- **Views:** 28
- **Tags:** Landing Page, Services, Brand, Technology, Dark, Gradient, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Play Wonder Gaming Landing Page Template

A bold, App-Store-style landing page template for showcasing iPhone and mobile games, featured categories, and top studios in a visually rich layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

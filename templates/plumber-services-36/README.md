# Plumbing Services Landing Page Template

A clean, conversion-focused template for plumbers and home service businesses to showcase services, build trust, and capture quote requests.

## Project Details
- **Slug:** `plumber-services-36`
- **Views:** 18
- **Tags:** Landing Page, Services, Clean, Minimal, Brand, plumbing, home services, local business, quote form

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

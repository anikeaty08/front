# Plumbing Services Landing Page Template

A modern plumbing services landing page template with hero form, services grid, FAQ, and blog sections to help local plumbers capture more leads.

## Project Details
- **Slug:** `plumbfix-plumbing-52`
- **Views:** 41
- **Tags:** Landing Page, Services, Business, Clean, Dark, Gradient, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Plumbing Services Landing Page Template

A reusable landing page template for local plumbing and gas engineers to showcase services, reviews, and contact details and convert visitors into enquiries.

## Project Details
- **Slug:** `plumbing-gas-25`
- **Views:** 23
- **Tags:** Landing Page, Services, Business, Brand, Clean, Minimal, Gradient, Large Type, Plumbing, Local Service
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

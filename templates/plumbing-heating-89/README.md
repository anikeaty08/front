# Local Plumbing Services Landing Page Template

A clean, modern landing page template for local plumbing and heating businesses to showcase services, reviews, and 24/7 emergency call-outs.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

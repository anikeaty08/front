# Plumbing Services Landing Page Template

A reusable plumbing services landing page template for local trades and emergency repair businesses, featuring 24/7 CTA, services, testimonials, FAQ, and contact form.

## Project Details
- **Slug:** `plumbing-services-18`
- **Views:** 35
- **Tags:** Landing Page, Services, Business, Brand, Clean, Gradient, Large Type, Minimal, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

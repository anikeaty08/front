# Plumbing Services Landing Page Template

A reusable landing page template for local plumbing companies to showcase services, build trust, and capture service requests online.

## Project Details
- **Slug:** `plumbing-services-26`
- **Views:** 25
- **Tags:** Landing Page, Services, Business, Clean, Dark, Minimal, local services, plumbing, home repair
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

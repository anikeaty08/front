# Plumbing Services Landing Page Template

A modern plumbing services landing page template featuring hero call buttons, services, reviews, service areas, and a quote request form for local trades.

## Project Details
- **Slug:** `plumbing-services-8`
- **Views:** 27
- **Tags:** Landing Page, Services, Business, Local Service, Clean, Dark, Gradient, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

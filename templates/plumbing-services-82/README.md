# Plumbing Services Landing Page Template

A modern plumbing services landing page template featuring hero, services, reviews, about, and contact sections for local trade and home service businesses.

## Project Details
- **Slug:** `plumbing-services-82`
- **Views:** 43

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

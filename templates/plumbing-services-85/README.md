# Plumbing Services Landing Page Template

A reusable plumbing services landing page template for licensed contractors to showcase offerings, service areas, trust signals, and capture quote requests.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Plumbing Services Landing Page Template

A modern, dark-themed landing page template for local plumbing service businesses, featuring services, reviews, location, and always-visible call-now CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Financial Services Landing Page Template

A modern PlusFin-inspired landing page template for financial services firms to showcase offerings, process, and consultations with a built-in chat widget.

## Project Details
- **Slug:** `plusfin-financial-42`
- **Views:** 25
- **Tags:** Landing Page, Services, Business, Clean, Dark, Gradient, Large Type, Technology, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

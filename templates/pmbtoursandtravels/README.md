# Travel Agency Landing Page Template

A modern PMB Tours & Travels-inspired landing page template for travel agencies to showcase destinations, curated packages, and bookings with a clean, premium design.

## Project Details
- **Slug:** `pmbtoursandtravels`
- **Views:** 18
- **Tags:** Travel, Landing Page, Services, Brand, Clean, Minimal, Gradient, Large Type, 3D
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

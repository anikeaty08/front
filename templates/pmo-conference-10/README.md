# B2B Conference Landing Page Template

A premium event landing page template for promoting B2B conferences, capturing early-interest leads, and showcasing agenda, audience, and event value.

## Project Details
- **Slug:** `pmo-conference-10`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

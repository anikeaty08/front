# PMO Conference Landing Page Template

A high-converting template for promoting PMO conferences, executive summits, and industry events with speaker highlights, agenda sections, FAQs, and lead capture.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Podcast Landing Page Template – The Hunt for Success

A dark, cinematic podcast landing page template for interview-style shows, featuring hero, episode archive, guest roster, and application form sections.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

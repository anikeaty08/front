# Podcast Landing Page Template

A dark, editorial-style podcast website template for showcasing episodes, host stories, platform links, and companion blog content for builder-focused shows.

## Project Details
- **Slug:** `podcast-landing-33`
- **Views:** 376

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

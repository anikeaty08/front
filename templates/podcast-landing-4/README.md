# Podcast Landing Page Template

A premium podcast landing page template for showcasing episodes, hosts, and subscribe links across Spotify, Apple Podcasts, and YouTube.

## Project Details
- **Slug:** `podcast-landing-4`
- **Views:** 14
- **Tags:** Landing Page, Brand, Entertainment, Dark, Gradient, Large Type, Minimal, Podcast, Audio, Clean
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

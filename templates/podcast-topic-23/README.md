# Podcast Topic Picker Landing Page Template

A dark, colorful podcast topic picker landing page template for shows that crowdsource episode ideas, votes, and comments from their community.

## Project Details
- **Slug:** `podcast-topic-23`
- **Views:** 14
- **Tags:** Landing Page, Entertainment, Brand, Dark, Colorful, Gradient, Large Type, Minimal, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Enterprise Wellness App Dashboard Template

A reusable mobile app template for enterprise wellness programs, combining employee challenges, leaderboards, profiles, and admin analytics.

- **Slug:** `podiumcorporate`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# PodPress Podcast-to-Newsletter SaaS Landing Page Template

A dark, modern SaaS landing page template for PodPress, built to showcase an AI tool that turns podcast episodes into newsletters and written content in minutes.

## Project Details
- **Slug:** `podpress-podcast-40`
- **Views:** 30
- **Tags:** Landing Page, Technology, Brand, Dark, Clean, Gradient, Large Type, Minimal, SaaS, podcasting
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

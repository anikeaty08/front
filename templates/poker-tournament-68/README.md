# Poker Tournament Schedule Template

A reusable tournament schedule template for showcasing multi-date poker series events, buy-ins, formats, and highlighted championship entries in a clean layout.

## Project Details
- **Slug:** `poker-tournament-68`
- **Views:** 38
- **Tags:** Landing Page, Sports, Conference, Minimal, Clean, Dark, schedule, tournament, events
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Pollys Dock

A reusable restaurant template for waterfront seafood spots, showcasing menus, boat rentals, reviews, hours, and visit details in a vibrant coastal layout.

## Project Details
- **Slug:** `pollys-dock-lbi`
- **Views:** 63

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Ferry Booking App Landing Page Template

This reusable landing page template is designed for ferry or maritime booking apps to showcase routes, bookings, and promotions seamlessly.

## Project Details
- **Slug:** `polsca-moibile-app`
- **Views:** 37
- **Tags:** Landing Page, Booking Widget, Ferry Routes, Promotions, Navigation, Responsive, UI Template, Passenger Info, Mobile App
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

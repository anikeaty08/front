# Pool Service Landing Page Template

A modern pool service landing page template for showcasing maintenance plans, philosophy, and client login, ready to customize for local service businesses.

## Project Details
- **Slug:** `pool-service-40`
- **Views:** 14

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

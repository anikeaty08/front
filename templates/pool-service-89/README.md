# Pool Service Landing Page Template

Reusable landing page template for local pool cleaning and maintenance businesses to showcase services, locations, reviews, and capture new client quotes online.

## Project Details
- **Slug:** `pool-service-89`
- **Views:** 28
- **Tags:** Landing Page, Business, Services, Clean, Colorful, Brand, Local Service, Pool Cleaning, Home Services, Maintenance
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

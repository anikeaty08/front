# Home Services Landing Page Template for Pools & Shadeports

A reusable landing page template for Johannesburg-based pool, shadeport, and paving service businesses to showcase projects and capture WhatsApp quote requests.

## Project Details
- **Slug:** `pools-car-shdes-87`
- **Views:** 48
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Gradient, Home services, Construction
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

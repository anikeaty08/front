# Spatial Design Portfolio Template

A reusable portfolio template for architecture and spatial design studios to showcase projects, philosophy, capabilities, and attract new client commissions.

## Project Details
- **Slug:** `popo`
- **Views:** 21
- **Tags:** Portfolio, Art & Design, Services, Minimal, Clean, Dark, Animated, Architecture, Spatial Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

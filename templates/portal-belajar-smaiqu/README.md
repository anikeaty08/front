# Student Report Portal Landing Page Template

A clean mobile-style student report portal landing page template for schools to let parents and students check attendance and grades by student ID.

## Project Details
- **Slug:** `portal-belajar-smaiqu`
- **Views:** 30
- **Tags:** Landing Page, Education, Clean, Minimal, Technology, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Futuristic Streetwear E-commerce Landing Page Template

A bold, glitchy streetwear e-commerce landing page template for limited product drops, technical product specs, and NFC-enabled faith-based apparel brands.

## Project Details
- **Slug:** `portalseverywhere`
- **Views:** 14
- **Tags:** E-commerce, Landing Page, Fashion, Brand, Entertainment, Dark, Brutal, Large Type, Futuristic, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

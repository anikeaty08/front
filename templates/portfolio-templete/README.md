# Sarita Creative Portfolio Website Template

A modern, clean portfolio website template for showcasing graphic design, web design, and photography work with resume, testimonials, and contact sections.

## Project Details
- **Slug:** `portfolio-templete`
- **Views:** 47

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# X.Studio Portfolio Website Template

A dark, cinematic portfolio website template for studios and product designers to showcase selected work, services, and process with motion-rich case studies.

## Project Details
- **Slug:** `portfolio-website-`
- **Views:** 39

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

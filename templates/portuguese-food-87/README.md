# Portuguese Food Import Business Landing Page Template

A modern landing page template for Portuguese food import and distribution businesses to showcase products, B2B services, and retail store information.

## Project Details
- **Slug:** `portuguese-food-87`
- **Views:** 19
- **Tags:** Landing Page, Food, Business, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

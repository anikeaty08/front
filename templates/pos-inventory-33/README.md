# POS & Inventory Dashboard UI Template

A modern POS and inventory management UI template for building responsive in-store sales dashboards and checkout experiences with Tailwind CSS.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

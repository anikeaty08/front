# POSCLOUD Admin Dashboard Template

A reusable admin dashboard template for restaurant POS and management systems, featuring orders, tables, inventory, staff, and reports.

## Project Details
- **Slug:** `poscloud-admin-55`
- **Views:** 107
- **Tags:** Admin Dashboard, POS, Restaurant Management, Orders, Inventory, Staff, Reports, Authentication, Analytics, Settings
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# POSCLOUD Master Admin Dashboard Template

This reusable admin dashboard template is designed for managing multi-tenant POS systems with features like tenant management, support tools, notifications, and role-based access control.

## Project Details
- **Slug:** `poscloud-master-4`
- **Views:** 60
- **Tags:** Admin Panel, Dashboard, Multi-Tenant, Tenant Management, Support Tools, RBAC, Notifications, Printer Testing, Audit Logs, Approvals
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# POSCLOUD Restaurant POS Landing Page Template

This reusable landing page template is designed for restaurant POS systems to manage orders, tables, billing, and shift operations efficiently.

## Project Details
- **Slug:** `poscloud-restaurant-13`
- **Views:** 74
- **Tags:** Landing Page, POS, Restaurant, Orders, Tables, Billing, Shift Management, Dashboard, Reports, Authentication
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

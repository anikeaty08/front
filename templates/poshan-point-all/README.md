# Fitness Smoothie Bar Landing Page Template

A modern PoshanPoint-inspired landing page template for fitness-focused smoothie bars and healthy cafes to showcase menus, benefits, and capture orders.

## Project Details
- **Slug:** `poshan-point-all`
- **Views:** 18
- **Tags:** Landing Page, Food, Services, Brand, Clean, Colorful, Minimal, Large Type, Healthy Cafe, Restaurant
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

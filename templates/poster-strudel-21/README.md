# Poster Strudel E-Commerce Landing Page Template

This template provides a stylish, curated art bundle e-commerce landing page designed to showcase and sell art prints and collections effectively.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Postpartum Haircare E-commerce Landing Page Template

A reusable e-commerce landing page template for postpartum haircare brands to showcase products, stories, and blogs with a calming, organic aesthetic.

1. Open folder in VS Code / terminal.
2. Run `npm install`.

# Health Insurance SaaS Landing Page Template

A modern, dark SaaS template for health insurance and RCM platforms, ideal for showcasing claims automation products and booking demos as a reusable template.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

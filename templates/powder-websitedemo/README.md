# Health Insurance SaaS Landing Page Template

A dark, modern SaaS landing page template for health insurance and revenue cycle management platforms, ready to customize for your healthcare tech brand.

## Project Details
- **Slug:** `powder-websitedemo`
- **Views:** 24
- **Tags:** Landing Page, Health, Technology, Brand, Dark, Clean, Minimal, Large Type, Gradient

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

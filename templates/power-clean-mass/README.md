# Power Clean Mass

A modern pressure washing business landing page template for local home service providers to showcase services, reviews, and capture free quote requests.

## Project Details
- **Slug:** `power-clean-mass`
- **Views:** 42
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Gradient, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

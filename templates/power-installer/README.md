# Energy Installer Dashboard UI Template

A clean, tablet-style dashboard UI template for energy and battery backup installers to manage routes, grid uptime, and service maps with real-time clarity.

## Project Details
- **Slug:** `power-installer`
- **Views:** 42
- **Tags:** Technology, Services, Landing Page, Clean, Minimal, Brand, Dashboard, Energy, Installers, Power Grid
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Power Universe Character Ranking App Template

An interactive template for ranking and exporting Power Universe character hierarchies, featuring tiered slots, category voting, and roster search.

## Project Details
- **Slug:** `powerbook-selection-game`
- **Views:** 40
- **Tags:** Entertainment, Landing Page, Dark, Gradient, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

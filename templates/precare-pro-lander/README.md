# Patient-Driven Health SaaS Landing Page Template

A modern template for a patient-driven health context SaaS landing page, ideal for clinics and health startups to explain workflows and capture pilot signups.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

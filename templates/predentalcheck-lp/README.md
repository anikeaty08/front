# PreDentalCheck Template

A reusable landing page template for dental treatment review services that helps patients explain estimates, compare options, and drive case uploads.

## Project Details
- **Slug:** `predentalcheck-lp`
- **Views:** 33
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Medical, Dental, Pricing, FAQ
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

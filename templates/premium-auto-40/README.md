# Auto Detailing Landing Page Template

A dark, premium auto detailing landing page template for showcasing high-end car care services, pricing, and online booking for detailing studios.

## Project Details
- **Slug:** `premium-auto-40`
- **Views:** 37
- **Tags:** Landing Page, Services, Brand, Dark, Gradient, Clean, Minimal, Automotive, Car Detailing, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

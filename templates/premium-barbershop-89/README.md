# Barbershop Landing Page Template

A premium barbershop landing page template for grooming studios to showcase services, style galleries, testimonials, and online booking.

## Project Details
- **Slug:** `premium-barbershop-89`
- **Views:** 61

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

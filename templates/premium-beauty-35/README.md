# Premium Beauty & Wellness Landing Page Template

A sophisticated and clean landing page template designed for luxury salons and boutique beauty studios to showcase services and book appointments.

## Project Details
- **Slug:** `premium-beauty-35`
- **Views:** 43
- **Tags:** Health, Services, Clean, Minimal, Grid, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

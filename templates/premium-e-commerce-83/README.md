# Premium E-Commerce App Landing Page Template

This reusable template offers a sleek, mobile-optimized landing page designed for e-commerce apps showcasing product categories, featured products, and EMI options.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

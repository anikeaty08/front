# Premium iPhone E-commerce Landing Page Template

A dark, premium iPhone e-commerce landing page template for showcasing refurbished or new Apple devices with inventory, featured offer, and WhatsApp sales flow.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

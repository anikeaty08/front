# Premium Merchandising Landing Page Template

A sleek reusable template for premium merchandising, corporate gifts, and global sourcing businesses to showcase product lines, services, and catalog lead capture.

## Project Details
- **Slug:** `premium-merchandis-15`
- **Views:** 15
- **Tags:** Landing Page, Services, Brand, Technology, Dark, Clean, Minimal, corporate merchandising, promotional products
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

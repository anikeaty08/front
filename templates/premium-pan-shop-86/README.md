# Premium Pan Shop Landing Page Template

A dark, cinematic retail landing page template for premium pan, tobacco, beverages, and snacks shops to showcase collections, payments, and store location.

## Project Details
- **Slug:** `premium-pan-shop-86`
- **Views:** 30
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Minimal, Large Type, Gradient, Retail, Food
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Pet E-commerce Landing Page Template

A premium pet shop landing page template for showcasing curated food, accessories, and articles for dogs, cats, and birds in a modern online store layout.

- **Slug:** `premium-pet-e-8`
- **Views:** 66

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

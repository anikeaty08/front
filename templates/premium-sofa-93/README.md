# Furniture Store & Admin Dashboard Template

A premium furniture store and admin dashboard website template for showcasing sofas, managing leads, orders, catalog, and integrated chat in one modern UI.

## Project Details
- **Slug:** `premium-sofa-93`
- **Views:** 160
- **Tags:** E-commerce, Services, Brand, Clean, Minimal, Large Type, Furniture, Admin Dashboard, Interior, Responsive
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

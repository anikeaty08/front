# Premium Tech E-commerce Landing Page Template

A sleek, Apple-style e-commerce landing page template for premium tech resellers to showcase devices, offers, and service centers with a modern shopping experience.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

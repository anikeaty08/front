# Tech E-commerce Website Template

A reusable e-commerce template for premium tech stores selling laptops, desktops, accessories, and gaming gear with product grids, deals, and filtering.

## Project Details
- **Slug:** `premium-tech-30`
- **Views:** 32
- **Tags:** E-commerce, Technology, Landing Page, Dark, Clean, Minimal, Brand, premium tech, electronics store
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

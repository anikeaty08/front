# Prepaid Gift Card Landing Page Template

A polished template for Blazecard/Blazegift-style prepaid gift card landing pages, perfect for selling digital cards with instant delivery and global access.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

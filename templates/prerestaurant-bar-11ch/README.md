# Restaurant & Bar Landing Page Template

A modern dark-theme restaurant & bar landing page template for showcasing menus, events, and location details for dining venues.

## Project Details
- **Slug:** `prerestaurant-bar-11ch`
- **Views:** 241
- **Tags:** Landing Page, Food, Brand, Clean, Dark, Large Type, Minimal, Restaurant, Bar, Events

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Presentation Studio Landing Page Template

A modern presentation studio landing page template for showcasing pitch deck services, process, portfolio, pricing, and booking strategy calls.

- **Slug:** `presentations-main`
- **Views:** 368

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# E-commerce Admin Dashboard UI Template

A modern e-commerce admin dashboard template for managing products, orders, customers, payments, shipping, and product logic in one clean interface.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Arabic Agency Pricing Page Template

A sleek Arabic pricing page template for creative marketing agencies to showcase tiered service plans, add-ons, and CTAs with a dark, modern look.

## Project Details
- **Slug:** `price`
- **Views:** 21
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Minimal, Large Type, Gradient, Technology, Art & Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

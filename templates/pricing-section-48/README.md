# Website Pricing Section Template

A reusable pricing template for web design agencies and freelancers to showcase landing page, business website, and advanced website packages.

## Project Details
- **Slug:** `pricing-section-48`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

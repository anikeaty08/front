# Pridor

A reusable e-commerce template for premium concept stores selling fashion, fragrance, home decor, and gourmet goods with an elegant boutique feel.

## Project Details
- **Slug:** `pridor-webdemo-v1`
- **Views:** 417
- **Tags:** E-commerce, Landing Page, Fashion, Food, Brand, Clean, Minimal, Elegant, Luxury, Premium
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

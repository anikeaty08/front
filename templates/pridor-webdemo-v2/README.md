# Pridor

A reusable landing page template for an oriental-inspired family concept store, showcasing products, promotions, store info, and click-and-collect services.

## Project Details
- **Slug:** `pridor-webdemo-v2`
- **Views:** 567
- **Tags:** E-commerce, Landing Page, Fashion, Food, Brand, Clean, Minimal, Elegant, Retail
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

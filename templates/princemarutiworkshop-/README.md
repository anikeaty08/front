# PrinceMarutiWorkshop 

A dark, modern single-page template for local auto workshops and car repair centers, ready to customize and deploy as your service website.

## Project Details
- **Slug:** `princemarutiworkshop-`
- **Views:** 3
- **Tags:** Landing Page, Services, Brand, Dark, Clean, Minimal, Large Type, Automotive, Local Business, Workshop
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

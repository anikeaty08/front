# Automobile Workshop 

A modern automobile workshop landing page template for showcasing services, location, and contact details for local car repair and maintenance garages.

## Project Details
- **Slug:** `princemarutiworkshop`
- **Views:** 42

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

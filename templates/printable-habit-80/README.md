# Printable Habit Tracker Dashboard Template

A printable habit dashboard template for tracking 31 days of habits and daily work hours, ready to customize, print, and reuse each month.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

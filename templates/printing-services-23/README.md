# Printing Services Profile Card Template

A reusable dark profile card template for printing services businesses to showcase contact details, availability, services, and a direct call CTA.

## Project Details
- **Slug:** `printing-services-23`
- **Views:** 40
- **Tags:** Landing Page, Services, Brand, Dark, Minimal, Clean, business card, profile card, printing services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Digital Seva & Print Portal 

A modern Digital Seva and online services landing page template for portals offering government services, job forms, printing, and bill payments.

## Project Details
- **Slug:** `printportalindia`
- **Views:** 330
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Gradient, Clean, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Auto Detailing Landing Page Template

A modern auto detailing landing page template for showcasing premium car care services, pricing, and online booking for detailing businesses.

## Project Details
- **Slug:** `pristine-auto-25`
- **Views:** 14
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Gradient, Large Type, Automotive, Detailing, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Pristine Power Washing Inc

A reusable landing page template for local power washing and exterior cleaning businesses to showcase services, build trust, and drive free quote requests.

## Project Details
- **Slug:** `pristine-power-washing-inc`
- **Views:** 7
- **Tags:** Landing Page, Services, Business, Clean, Gradient, Large Type, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

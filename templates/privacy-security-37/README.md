# Privacy & Security Mobile App Settings Template

A reusable mobile app UI template for privacy, security, and account settings screens with toggles, actions, and clean profile controls.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

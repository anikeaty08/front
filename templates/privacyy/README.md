# Crypto Privacy Swap Interface Template

A dark, glassmorphism crypto privacy swap UI template for anonymous Solana-style wallet transfers, ready to customize for your Web3 landing page or dApp.

## Project Details
- **Slug:** `privacyy`
- **Views:** 29
- **Tags:** Landing Page, Technology, Dark, Minimal, Gradient, Crypto, dApp, Web3, Fintech, Swap Interface
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Christian School Landing Page Template

A reusable landing page template for private Christian schools to showcase academics, programs, parent trust, and drive campus tour inquiries.

- **Slug:** `private-christianp3-65`
- **Views:** 12

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

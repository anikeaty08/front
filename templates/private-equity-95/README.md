# Private Equity Fund Landing Page Template

A dark, fintech-inspired landing page template for private equity and investment funds to present their offer, selection process, and lead-capture form.

- **Slug:** `private-equity-95`
- **Views:** 9

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

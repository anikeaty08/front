# Product Catalogue Landing Page Template

A clean, modern product catalogue landing page template for B2B suppliers to showcase categories, highlight featured products, and capture quote requests.

## Project Details
- **Slug:** `product-catalogue-9`
- **Views:** 44
- **Tags:** Landing Page, Business, Services, Technology, Brand, Clean, Minimal, Grid, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

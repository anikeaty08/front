# Product Data Management Dashboard Template

A modern product data management dashboard template for organizing e-commerce product hierarchies, specs, FAQs, guides, and change history.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

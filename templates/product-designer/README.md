# Product Designer Portfolio Landing Page Template

This reusable template showcases a product designer's portfolio, highlighting services, tools, process, pricing, and client FAQs for B2B and SaaS audiences.

## Project Details
- **Slug:** `product-designer`
- **Views:** 1903
- **Tags:** Landing Page, Portfolio, Product Design, Pricing, FAQ, Testimonials, Services, Process, Tools, Contact
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

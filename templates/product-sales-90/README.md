# Luxury LED Product Landing Page Template

A high-converting RTL Arabic product landing page template for showcasing and selling luxury LED mirrors or beauty accessories with a modern checkout form.

- **Views:** 17

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

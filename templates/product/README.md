# Hospitality AI Platform Landing Page Template

A reusable landing page template for showcasing an agentic AI hospitality platform with hotel automation, guest experience modules, pricing, and demo CTAs.

## Project Details
- **Slug:** `product`
- **Views:** 95
- **Tags:** Landing Page, Technology, Services, Clean, Minimal, Futuristic, SaaS, AI, Hospitality, Hotel
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

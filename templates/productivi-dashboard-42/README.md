# Productivity Dashboard Web App Template

A dark, modern productivity dashboard template with tasks, timers, and analytics, ready to customize as your own productivity web app UI.

- **Slug:** `productivi-dashboard-42`
- **Views:** 10

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

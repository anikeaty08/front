# Athlete Portfolio Landing Page Template

A refined template for professional golfers and athletes to showcase biography, career stats, recent results, and personal brand presence.

## Project Details
- **Slug:** `profession-golfer-10`
- **Views:** 48

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Healthy Swappers

A modern café and healthy food landing page template for showcasing plant-forward menus, community-focused app concepts, and easy online reservations.

## Project Details
- **Slug:** `programabienestar`
- **Views:** 231
- **Tags:** Landing Page, Food, Brand, Clean, Minimal, Gradient, Portfolio, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

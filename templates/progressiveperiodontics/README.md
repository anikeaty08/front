# Periodontist Clinic Landing Page Template

A modern multi-location periodontics landing page template for dental implant and gum care practices to showcase services, team, and appointment requests.

## Project Details
- **Slug:** `progressiveperiodontics`
- **Views:** 13
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

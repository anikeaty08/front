# AeroSky Flight SaaS Landing Page Template

AeroSky is a modern flight booking SaaS landing page template with an integrated dashboard demo, ideal for travel and airline platforms to launch fast.

- **Slug:** `project-brief-51`
- **Views:** 4

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

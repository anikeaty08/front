# Financial Advisory Landing Page Template

A modern, trust-building landing page template for financial advisors and leadership development firms to showcase services and capture consultation leads.

- **Slug:** `promisedland`
- **Views:** 42

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

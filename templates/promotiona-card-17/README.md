# Promotional Card Landing Page Template

A reusable promotional card landing page template designed for showcasing offers, campaigns, or products with a clean, modern layout.

## Project Details
- **Slug:** `promotiona-card-17`
- **Views:** 21
- **Tags:** Landing Page, Brand, Clean, Minimal, Marketing, Promotional, Campaign, Product

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

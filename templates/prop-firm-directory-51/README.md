# Prop Firm Comparison Landing Page Template

A reusable landing page template for comparing proprietary trading firms, showcasing rankings, filters, reviews, and affiliate-style CTAs to help traders choose funding options.

## Project Details
- **Slug:** `prop-firm-directory-51`
- **Views:** 71
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Directory, Comparison, Finance, Trading
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

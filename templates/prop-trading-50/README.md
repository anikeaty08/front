# Prop Trading Landing Page Template

A reusable prop trading landing page template for funding firms and broker-style brands to showcase evaluations, platforms, payouts, and trader growth.

## Project Details
- **Slug:** `prop-trading-50`
- **Views:** 67
- **Tags:** Landing Page, Services, Technology, Dark, Futuristic, Gradient, Trading, Finance, Prop Firm
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

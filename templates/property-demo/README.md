# Real Estate Development Landing Page Template

A modern Worthing Estates-inspired landing page template for premium real estate development and property management brands to showcase projects and capture inquiries.

## Project Details
- **Slug:** `property-demo`
- **Views:** 118
- **Tags:** Real Estate, Landing Page, Brand, Clean, Dark, Gradient, Large Type, Portfolio, Services

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Property Finance Dashboard UI Template

Reusable template for a property finance dashboard with an Add Income flow, ideal for rental, Airbnb, and real estate revenue tracking apps.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Property Management Landing Page Template

A reusable landing page template for short-term rental management companies to attract property owners, showcase results, and drive free valuation leads.

## Project Details
- **Slug:** `property-management-32`
- **Views:** 40
- **Tags:** Landing Page, Real Estate, Services, Clean, Minimal, Dark, Portfolio, lead generation, property management

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

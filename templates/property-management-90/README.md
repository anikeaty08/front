# Property Management SaaS Landing Page Template

A reusable landing page template for short-term rental automation platforms, helping property managers showcase channel syncing, guest messaging, pricing, and smart locks.

## Project Details
- **Slug:** `property-management-90`
- **Views:** 90
- **Tags:** Landing Page, Technology, Services, Clean, Minimal, SaaS, Property Management, Vacation Rental, Automation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

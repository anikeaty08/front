# Real Estate Analytics Dashboard Template

A reusable real estate analytics template for showcasing property valuations, comparable sales, walkability, climate risks, and lifestyle fit.

## Project Details
- **Slug:** `propertyinsights`
- **Views:** 66
- **Tags:** Real Estate, Landing Page, Technology, Clean, Minimal, Dashboard, Analytics, Data Visualization
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

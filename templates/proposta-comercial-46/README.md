# Sales Proposal Landing Page Template

A dark, data-driven proposal page template to present commercial offers, services, scope, and pricing for sales and marketing agencies.

## Project Details
- **Slug:** `proposta-comercial-46`
- **Views:** 10
- **Tags:** Landing Page, Services, Business, Brand, Dark, Clean, Gradient, Large Type, Proposal, Sales
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

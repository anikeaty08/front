# Protective Streetwear Landing Page Template

A dark, high-impact landing page template for protective streetwear or moto apparel brands to showcase product tech, lifestyle visuals, and email waitlist signup.

## Project Details
- **Slug:** `protective-streetwear-2`
- **Views:** 24
- **Tags:** Landing Page, Brand, Fashion, Style, Dark, Minimal, Large Type, Gradient, Technology

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

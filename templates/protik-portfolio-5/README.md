# Dark Developer Portfolio Landing Page Template

A dark, futuristic developer portfolio landing page template for showcasing projects, tech stack, and contact details with an immersive 3D hero and starfield background.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

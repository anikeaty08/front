# Hyper Animated Wallet

A sleek dark-mode crypto wallet app UI template for showcasing smart wallet dashboards, actions, and activity inside product or marketing demos.

- **Slug:** `prowalletanimated`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

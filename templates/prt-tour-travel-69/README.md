# PRT Tour Travel Landing Page Template

A modern PRT Tour-themed landing page template for local and custom U.S. tour agencies to showcase destinations, tour packages, and inquiries in Korean.

- **Slug:** `prt-tour-travel-69`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

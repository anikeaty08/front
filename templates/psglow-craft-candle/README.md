# Candle E-commerce Landing Page Template

A minimal Aura Candles-inspired landing page template for showcasing a small-batch candle collection and driving WhatsApp orders for boutique e-commerce brands.

## Project Details
- **Slug:** `psglow-craft-candle`
- **Views:** 52
- **Tags:** E-commerce, Landing Page, Brand, Clean, Minimal, Large Type, Gradient, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

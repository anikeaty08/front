# Malvin Studio.

A dark, cinematic streaming UI template for showcasing, filtering, and downloading public domain movies, ready to customize for your own film platform.

## Project Details
- **Slug:** `public-domain-50`
- **Views:** 30
- **Tags:** Landing Page, Entertainment, Brand, Dark, Minimal, Large Type, Technology, Streaming, Movies, Cinema
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

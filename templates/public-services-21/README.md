# Government Services Landing Page Template

A modern, accessible landing page template for public sector or government service portals, easily adapted for online benefits, forms, and citizen support.

## Project Details
- **Slug:** `public-services-21`
- **Views:** 24
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Grid, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

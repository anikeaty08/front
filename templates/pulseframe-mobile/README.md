# Pulseframe Mobile App Landing Page Template

A sleek, mobile-focused landing page template designed to showcase app integrations, features, and CTAs for tech and product growth platforms.

- **Slug:** `pulseframe-mobile`
- **Views:** 1418

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

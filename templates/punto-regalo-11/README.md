# Punto Regalo Marketplace Landing Page Template

Landing page template for a Spanish-language loyalty points marketplace, ideal to showcase rewards, filters, and product grids for point-based redemptions.

## Project Details
- **Slug:** `punto-regalo-11`
- **Views:** 11
- **Tags:** Landing Page, E-commerce, Brand, Clean, Colorful, Minimal, Marketplace, Rewards, Loyalty, Spanish
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

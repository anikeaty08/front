# PupGuide AI Mobile App UI Template

A reusable mobile app UI template for a dog training and health assistant, featuring AI coaching, daily tracking, guides, and pet profile flows.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

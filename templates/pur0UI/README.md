# Event Creation Modal with Categories

Responsive modal UI for creating events with category selection, date/time inputs, attachments, and invitees, styled using Tailwind CSS.

## Project Details
- **Slug:** `pur0UI`
- **Views:** 212
- **Tags:** Event Modal, Segmented Control, Form, Tailwind CSS, Date Picker, File Upload, Invitees
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

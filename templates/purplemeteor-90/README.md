# Purple Meteor Features SaaS Landing Page Template

A dark, futuristic SaaS landing page template for showcasing productivity app or knowledge tool features, security, and collaboration at a glance.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

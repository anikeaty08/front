# QR Scanner Inventory App Template

A reusable mobile app template for QR-based cargo and warehouse scanning, helping logistics teams detect items, review details, and add inventory faster.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Clinic Landing Page Template

Modern dental clinic landing page template for dentists and odontologia practices to showcase treatments, testimonials, and contact details in a clean, conversion-focused layout.

## Project Details
- **Slug:** `qualidenteportoalegre`
- **Views:** 15
- **Tags:** Health, Landing Page, Services, Brand, Clean, Minimal, Gradient, Large Type, Technology, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

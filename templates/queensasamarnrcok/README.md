# Flight E-Itinerary Management Dashboard Template

A reusable template for a flight E-itinerary management dashboard to create, store, edit, and print professional booking receipts for travel agencies or operators.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Quiz Management Dashboard Template

A reusable dark-mode Quiz Management Dashboard Template for monitoring live Telegram webhook quizzes, tracking user responses, and exporting results.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

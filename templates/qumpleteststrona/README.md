# Gaming Guild Landing Page Template

A polished landing page template for online gaming guilds to showcase events, onboarding, rankings, and Discord recruitment in one organized hub.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Rabies Control PWA Interface Template

A mobile-first PWA interface template for rabies vaccination field operatives, featuring secure login, microchip search, and guided record creation flows.

## Project Details
- **Slug:** `rabies-control-91`
- **Views:** 3
- **Tags:** Health, Services, Technology, Clean, Minimal, Landing Page, PWA, Mobile UI, Medical, Admin Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

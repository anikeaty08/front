# Beauty Salon 

A reusable beauty salon landing page template for showcasing services, reviews, gallery and contact details, optimized for local appointment bookings.

- **Views:** 70

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

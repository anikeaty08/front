# Racing Budget Planner App Template

A reusable mobile app template for motorsport teams and drivers to estimate season budgets, compare event decisions, and plan development outcomes.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

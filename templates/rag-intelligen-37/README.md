# RAG Intelligence Dashboard UI Template

A modern RAG intelligence platform UI template for document-aware chat, letting you quickly prototype and ship retrieval-augmented generation dashboards.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Luxury Dental Clinic Landing Page Template

A dark, high-end dental clinic landing page template for aesthetic dentistry brands to showcase services, philosophy, and bookings with a cinematic, editorial feel.

1. Open folder in VS Code / terminal.
2. Run `npm install`.

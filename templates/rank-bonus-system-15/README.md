# Partner Dashboard Template

A reusable partner dashboard template designed for managing business insights, bonuses, client tracking, and team analytics efficiently.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

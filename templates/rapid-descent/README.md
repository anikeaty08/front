# rapid-descent

A reusable landing page template for precision bike workshops and MTB service businesses, featuring services, pricing, testimonials, and booking.

## Project Details
- **Slug:** `rapid-descent`
- **Views:** 74
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Technology, Bike Repair, Workshop
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

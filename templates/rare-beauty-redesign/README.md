# Beauty E-commerce Landing Page Template

A modern beauty brand e-commerce template for showcasing makeup collections, storytelling, and conversions—fully reusable for cosmetics shop landing pages.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

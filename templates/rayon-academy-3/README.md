# Youth Education Program Landing Page Template

A reusable landing page template for youth personal development and education programs like RAYON Academy, designed to promote a 6‑month skills-building course.

## Project Details
- **Slug:** `rayon-academy-3`
- **Views:** 29
- **Tags:** Landing Page, Education, Services, Brand, Clean, Minimal, Large Type, Technology, youth program, course

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

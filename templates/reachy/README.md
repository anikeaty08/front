# Richie Seeding Service Landing Page Template

A high-converting landing page template for Richie, a short-form content seeding and creator distribution service to request custom media plans and start campaigns.

## Project Details
- **Slug:** `reachy`
- **Views:** 400
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

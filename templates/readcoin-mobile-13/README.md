# ReadCoin Read-to-Earn Mobile App Template

This reusable ReadCoin template is designed for building a mobile read-to-earn app that motivates users to read articles and earn digital coins.

## Project Details
- **Slug:** `readcoin-mobile-13`
- **Views:** 32
- **Tags:** Landing Page, Mobile App, Read-to-Earn, Rewards, Wallet, Missions, Articles, User Engagement, Cryptocurrency, Finance
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

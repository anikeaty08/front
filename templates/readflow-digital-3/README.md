# Reading Habit SaaS Landing Page Template

A clean, book-focused landing page template for reading tracker or digital library apps, designed to showcase features, explain methodology, and capture waitlist signups.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Real Estate About Us Landing Page Template

A modern About Us landing page template for real estate agencies, showcasing expertise, testimonials, and calls-to-action to browse properties or contact your team.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

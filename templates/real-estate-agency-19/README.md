# Real Estate Agency Landing Page Template

A modern real estate agency landing page template for showcasing properties, services, team, reviews, and contact form for local agencies.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

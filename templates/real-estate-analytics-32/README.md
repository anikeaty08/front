# Real Estate Analytics Dashboard Template

A dark, modern real estate analytics dashboard template for tracking Croatian property portfolios, listings, and performance metrics in a reusable UI layout.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

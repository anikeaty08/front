# Real Estate Rental App UI Template

Mobile-first real estate rental app UI template for discovering verified to-let posters, managing uploads, and viewing properties in map and list views.

- **Views:** 1

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

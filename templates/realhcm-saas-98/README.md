# SaaS HR Software Landing Page Template

A clean, modern SaaS landing page template designed for HCM and workforce management platforms featuring automated payroll and team directory sections.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

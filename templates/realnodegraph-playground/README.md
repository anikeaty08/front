# Developer

A dark, developer-focused dashboard UI template for data querying, table views, JSON documents, schema inspection, and tenant settings.

## Project Details
- **Slug:** `realnodegraph-playground`
- **Views:** 35
- **Tags:** Technology, Landing Page, Brand, Dark, Clean, Minimal, Dashboard, Developer Tools, Data Studio

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Recovery Access Montana Non-profit Landing Page Template

A dark, data-driven non-profit landing page template for statewide recovery networks to showcase certification standards, coordinated services, and partner access.

## Project Details
- **Slug:** `recovery-access-montana`
- **Views:** 404
- **Tags:** Landing Page, Non-profit, Health, Services, Technology, Brand, Dark, Grid, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Recruiter Network Landing Page Template

A dark, minimal landing page template for promoting an entrepreneurial recruiter network and showcasing its business model, infrastructure, and benefits.

## Project Details
- **Slug:** `recruiter-network-6`
- **Views:** 14

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Recruitment Services Landing Page Template

A clean, Polish-language recruitment landing page template for independent recruiters helping candidates find legal jobs abroad in Germany and the Netherlands.

## Project Details
- **Slug:** `recruitmen-services-96`
- **Views:** 36
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Recruitment, Job Search, Consulting
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

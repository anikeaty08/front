# RED AURA - AI SaaS Features Landing Page Template

A dark, futuristic AI SaaS landing page template for showcasing advanced platform features, technical specs, and FAQs for developer-focused products.

## Project Details
- **Slug:** `red-aura`
- **Views:** 64

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

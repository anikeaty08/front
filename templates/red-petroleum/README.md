# EV Charging Service Landing Page Template

A dark, futuristic EV charging service landing page template for promoting fast-charging networks, mobile apps, pricing plans, and FAQs.

## Project Details
- **Slug:** `red-petroleum`
- **Views:** 20
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Gradient, Grid, Large Type, Minimal, Travel
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Content Marketing System Landing Page Template

A reusable landing page template for agencies and media teams showcasing content production systems, strategy, analytics, and growth-focused service offers.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

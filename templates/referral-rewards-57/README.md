# Referral Rewards Mobile App Template

A reusable mobile app template for referral and invite-earn flows, showcasing earnings, referral codes, friend status, and wallet withdrawals.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

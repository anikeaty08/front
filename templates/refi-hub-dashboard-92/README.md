# ReFi Hub Dashboard Template

This reusable dashboard template is designed for impact investors to track renewable energy investments, yields, and portfolio allocation efficiently.

## Project Details
- **Slug:** `refi-hub-dashboard-92`
- **Views:** 25
- **Tags:** Dashboard, Metrics, Chart, Investment, Portfolio, Yield, Activity Log, Claim Yield, Responsive, TailwindCSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

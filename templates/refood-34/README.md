# Food Tech Dessert Landing Page Template

A reusable landing page template for promoting and pre-selling healthy, low-sugar dessert products with brand storytelling, product highlights, and pricing.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

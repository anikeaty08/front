# Food Product Landing Page Template

A reusable landing page template for modern food brands to showcase healthy dessert products, ingredients, flavors, and pre-order offers with bold storytelling.

## Project Details
- **Slug:** `refood`
- **Views:** 81
- **Tags:** Landing Page, Food, E-commerce, Brand, Clean, Dark, Gradient, Animated, product launch, pre-order
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

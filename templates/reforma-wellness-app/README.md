# ReForma 

A clean and accessible mobile app template designed to help seniors manage daily routines and find social activities.

## Project Details
- **Slug:** `reforma-wellness-app`
- **Views:** 31
- **Tags:** Health, Services, Social, Clean, Minimal, Landing Page, Mobile UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

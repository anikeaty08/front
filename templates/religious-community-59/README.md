# Community Mosque Landing Page Template

A modern, faith-centered landing page template for mosques and community centres to showcase programs, events, and donation campaigns.

## Project Details
- **Slug:** `religious-community-59`
- **Views:** 20
- **Tags:** Landing Page, Religious, Non-profit, Clean, Minimal, Brand, Social, Community Centre, Mosque Website, Donation Campaign
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

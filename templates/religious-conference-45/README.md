# Religious Conference Landing Page Template

A reusable landing page template for promoting church camp meetings or faith-based conferences, with schedule, trailer, registration, contact, and app CTA sections.

## Project Details
- **Slug:** `religious-conference-45`
- **Views:** 276
- **Tags:** Landing Page, Religious, Conference, Services, Dark, Clean, Large Type, Event, Church
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Biblical Education Landing Page Template

A reusable landing page template for biblical education projects, helping theologians, teachers, and study programs present resources and grow a waitlist.

## Project Details
- **Slug:** `religious-education-58`
- **Views:** 65
- **Tags:** Landing Page, Education, Religious, Services, Clean, Minimal, Grid, Large Type, newsletter, waitlist
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Church Fundraising and Construction Landing Page Template

A sophisticated and clean landing page template designed for religious institutions to manage construction fundraising, project tracking, and material donations.

## Project Details
- **Slug:** `religious-institutio-61`
- **Views:** 29

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

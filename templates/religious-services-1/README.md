# Religious Services Landing Page Template

A refined landing page template for showcasing faith-based services like donations, omra by proxy, and charitable actions in holy cities, ready to customize for your brand.

## Project Details
- **Slug:** `religious-services-1`
- **Views:** 160
- **Tags:** Landing Page, Services, Religious, Brand, Clean, Minimal, Dark, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Remote Stream Landing Page

A dark, cinematic hero landing page template for video production or SaaS platforms featuring embedded video, gradient CTA, and modern glassmorphism.

- **Slug:** `remotestre-video-32`
- **Views:** 25

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

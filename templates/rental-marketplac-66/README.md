# Rental Finder App UI Template

A mobile-first rental finder app UI template for listing, exploring, and managing to-let properties with user and admin dashboards.

- **Slug:** `rental-marketplac-66`
- **Views:** 12

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

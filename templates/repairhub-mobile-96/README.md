# RepairHub Mobile App UI Template

A modern RepairHub mobile app UI template for repair marketplaces to showcase AI diagnosis, technician booking, payments, tracking, and sustainability impact screens.

- **Slug:** `repairhub-mobile-96`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Internal Reporting Portal Dashboard Template

A clean, interactive template for an internal reporting portal that helps teams search, filter, and manage business dashboards and reports in one place.

## Project Details
- **Slug:** `reporting-portal-29`
- **Views:** 30
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Dashboard, Internal Tools, Analytics, Data Portal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

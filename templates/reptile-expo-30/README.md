# Reptile Expo Tickets & Vendor Portal Template

A dark, modern template for reptile expos to sell tickets, showcase exhibitors, and manage vendor applications across multiple event locations.

## Project Details
- **Slug:** `reptile-expo-30`
- **Views:** 40
- **Tags:** Landing Page, Services, Brand, Dark, Gradient, Large Type, Event, Ticketing, Vendor Portal, Expo
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

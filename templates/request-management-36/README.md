# Request Management Landing Page Template

A reusable request management template for collecting item requests, tracking submissions, and giving admins a simple review dashboard.

## Project Details
- **Slug:** `request-management-36`
- **Views:** 29

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

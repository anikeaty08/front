# Senior Care Landing Page Template

A warm, Spanish-language landing page template for senior care residences to showcase services, location, and contact options for family decision-makers.

## Project Details
- **Slug:** `residencialasglicinas`
- **Views:** 15
- **Tags:** Landing Page, Services, Health, Brand, Clean, Minimal, Large Type, Social, Senior Care
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

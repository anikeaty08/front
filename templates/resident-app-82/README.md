# Resident App Dashboard Template

A reusable mobile app template for residential communities to manage notices, bills, visitors, service requests, and gate passes in one place.

## Project Details
- **Slug:** `resident-app-82`
- **Views:** 26
- **Tags:** Real Estate, Services, Landing Page, Clean, Minimal, Mobile App, Dashboard, Community, Resident Portal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

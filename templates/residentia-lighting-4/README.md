# Electrical Supply Landing Page Template

A clean, reusable template for electrical supply companies, lighting showrooms, and service businesses to showcase products, locations, and contact details.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Aura Digital Assets Landing Page Template

A modern Aura landing page template for selling premium digital assets, courses, and templates to creators, ready to customize and reuse for your brand.

## Project Details
- **Slug:** `resources-for-you`
- **Views:** 2
- **Tags:** Landing Page, Technology, Services, Brand, Clean, Minimal, Gradient, Large Type, Creator, Digital Products
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

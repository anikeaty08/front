# Cafe & Restaurant Landing Page Template

A modern cafe & restaurant landing page template featuring hero, menu highlights, services, gallery, location, and contact sections for hospitality brands.

## Project Details
- **Slug:** `restaurace-radost`
- **Views:** 63
- **Tags:** Landing Page, Food, Services, Brand, Clean, Colorful, Minimal, Large Type, Restaurant, Cafe
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

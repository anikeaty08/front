# Restaurace 2

A modern coffee shop and café landing page template for showcasing your menu, reviews, gallery, and location to attract local customers.

## Project Details
- **Slug:** `restaurace2`
- **Views:** 20
- **Tags:** Landing Page, Food, Services, Brand, Clean, Gradient, Colorful, Large Type, Café, Restaurant
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

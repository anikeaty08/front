# Campus Restaurant & Bar Landing Page Template

A dark, modern restaurant and bar landing page template for campus eateries, showcasing menus, events, catering, and bookings in a bold, student-focused design.

## Project Details
- **Slug:** `restaurant-bar-59`
- **Views:** 860
- **Tags:** Landing Page, Food, Brand, Entertainment, Clean, Dark, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

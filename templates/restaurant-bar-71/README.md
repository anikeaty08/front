# Restaurant & Bar Landing Page Template

A reusable restaurant and bar landing page template for showcasing menus, bookings, private events, vouchers, and venue details in a premium nightlife style.

## Project Details
- **Slug:** `restaurant-bar-71`
- **Views:** 41
- **Tags:** Food, Landing Page, Services, Dark, Clean, Minimal, Brand, restaurant, bar, hospitality
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

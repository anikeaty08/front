# French Restaurant Landing Page Template

Elegant French restaurant website template for showcasing house-made cuisine, menus, catering and venue booking for local dining establishments.

## Project Details
- **Slug:** `restaurant-catering-14`
- **Views:** 48

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

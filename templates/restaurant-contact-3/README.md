# Restaurant Contact Landing Page Template

A reusable restaurant and bar contact page template for reservations, private event enquiries, location details, and guest messages in a refined dark layout.

## Project Details
- **Slug:** `restaurant-contact-3`
- **Views:** 337
- **Tags:** Food, Landing Page, Services, Dark, Clean, Minimal, Restaurant, Bar, Contact Form, Events
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

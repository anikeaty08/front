# Restaurant Finance Dashboard Template

A reusable dashboard template for restaurant financial calendar management, helping gastronomy businesses track accounts payable and receivable by month.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

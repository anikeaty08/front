# Restaurant Landing Page Template

A modern restaurant landing page template for showcasing menus, location, hours, and reservations with a stylish, high-conversion layout.

## Project Details
- **Slug:** `restaurant-landing-2`
- **Views:** 610
- **Tags:** Landing Page, Food, Business, Brand, Clean, Dark, Gradient, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

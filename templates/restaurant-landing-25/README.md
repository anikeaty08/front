# Restaurant Landing Page Template

A modern restaurant landing page template for showcasing menus, ambiance, and reservations, perfect for multi-cuisine or family dining venues.

## Project Details
- **Slug:** `restaurant-landing-25`
- **Views:** 45

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Il Porcellino Restaurant Landing Page Template

A modern restaurant landing page template for pizzerias and dining spots, featuring full menu sections, reservations, and email capture to promote your venue.

## Project Details
- **Slug:** `restaurant-landing-26`
- **Views:** 21
- **Tags:** Landing Page, Food, Business, Brand, Clean, Colorful, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

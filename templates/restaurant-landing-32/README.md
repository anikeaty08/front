# Restaurant Landing Page Template

A reusable restaurant landing page template for grill houses, local eateries, and food venues to showcase menus, atmosphere, location, and reservations.

## Project Details
- **Slug:** `restaurant-landing-32`
- **Views:** 33
- **Tags:** Food, Landing Page, Services, Clean, Elegant, Restaurant, Grill, Menu, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

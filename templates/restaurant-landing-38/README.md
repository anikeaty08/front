# Big Berger Cafe Restaurant Landing Page Template

A modern dark-theme restaurant landing page template for gourmet burger cafes, featuring menu highlights, customization options, locations, and online ordering.

## Project Details
- **Slug:** `restaurant-landing-38`
- **Views:** 20
- **Tags:** Landing Page, Food, Brand, Clean, Dark, Gradient, Large Type, Minimal, Restaurant, Cafe
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

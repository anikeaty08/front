# Restaurant Landing Page Template

A reusable restaurant landing page template for showcasing a fusion dining brand, menu highlights, ambiance, and reservation-focused calls to action.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

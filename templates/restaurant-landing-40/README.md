# Stone Barn Restaurant Landing Page Template

Elegant restaurant landing page template for showcasing seasonal menus, story, and bookings with a built-in reservation form and warm Cotswolds-inspired design.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

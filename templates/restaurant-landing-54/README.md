# Restaurant Landing Page Template

A warm, homely restaurant landing page template for showcasing menu, gallery, reviews, and table reservations for family-friendly dining brands.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

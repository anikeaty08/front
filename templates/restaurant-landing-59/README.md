# Restaurant Landing Page Template

A modern dark-theme restaurant landing page template with hero, menu, amenities, reservations, and location sections for dining brands.

## Project Details
- **Slug:** `restaurant-landing-59`
- **Views:** 23
- **Tags:** Food, Landing Page, Brand, Clean, Dark, Minimal, Restaurant, Reservation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

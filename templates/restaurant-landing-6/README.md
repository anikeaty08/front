# Andhra Restaurant Landing Page Template

A reusable restaurant website template for showcasing Andhra cuisine, menus, reviews, gallery highlights, and online ordering in a polished landing page.

## Project Details
- **Slug:** `restaurant-landing-6`
- **Views:** 21
- **Tags:** Landing Page, Food, E-commerce, Brand, Clean, Minimal, Gallery, Restaurant, Menu, Ordering
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

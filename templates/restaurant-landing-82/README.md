# Restaurant Landing Page Template

A reusable restaurant landing page template for vegetarian eateries to showcase menus, reservations, location details, and customer reviews.

## Project Details
- **Slug:** `restaurant-landing-82`
- **Views:** 29
- **Tags:** Food, Landing Page, Services, Clean, Minimal, Brand, restaurant, vegetarian, menu, reservation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Poonch resturant 

A dark, modern restaurant landing page template for showcasing authentic Indian/Mughlai cuisine, curated menus, galleries, and contact details.

- **Slug:** `restaurant-landing-86`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Restaurant Landing Page Template

A reusable restaurant landing page template for showcasing signature dishes, late-night dining, outlet locations, and online ordering with a bold food-first design.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Fine Dining Restaurant Landing Page Template

A refined restaurant landing page template for showcasing menus, chefs, reservations, and online orders for upscale dining brands.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

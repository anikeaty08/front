# Restaurant Listing Landing Page Template

A reusable restaurant listing template for showcasing location, hours, services, pricing, reviews, and map details in a clean local discovery layout.

## Project Details
- **Slug:** `restaurant-listing-4`
- **Views:** 9
- **Tags:** Landing Page, Food, Services, Clean, Minimal, Grid, directory, restaurant, map, local business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

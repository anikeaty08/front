# Restaurant Lunch Landing Page Template

A reusable restaurant landing page template for showcasing lunch menus, click-and-collect ordering, specials, and location details for busy local diners.

## Project Details
- **Slug:** `restaurant-lunch-90`
- **Views:** 62
- **Tags:** Food, Landing Page, Dark, Clean, Minimal, Restaurant, Menu, Click & Collect, Local Dining
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

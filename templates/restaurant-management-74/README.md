# Restaurant Management Dashboard Template

A reusable restaurant management dashboard template for handling orders, tables, kitchen flow, inventory, staff, billing, and analytics in one UI.

## Project Details
- **Slug:** `restaurant-management-74`
- **Views:** 101
- **Tags:** Food, Services, Technology, Dashboard, Admin Template, Clean, Minimal, Landing Page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

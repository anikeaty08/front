# Restaurant SaaS Landing Page Template

A high-converting SaaS landing page template for restaurant management systems, featuring PDV, QR code menu, delivery, and analytics sections.

## Project Details
- **Slug:** `restaurant-management-95`
- **Views:** 18
- **Tags:** Landing Page, Technology, Business, Clean, Dark, Gradient, Large Type, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

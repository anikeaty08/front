# Restaurant Menu Landing Page Template

A reusable restaurant menu template for showcasing dishes, drinks, pricing, and table bookings with a premium dark dining experience.

## Project Details
- **Slug:** `restaurant-menu-35`
- **Views:** 47
- **Tags:** Food, Landing Page, Services, Dark, Clean, Minimal, restaurant menu, cocktails, booking

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

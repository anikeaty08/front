# Restaurant Menu Landing Page Template

A reusable restaurant menu template for showcasing pizzas, pasta, sandwiches, drinks, and online ordering with pickup or delivery options.

## Project Details
- **Slug:** `restaurant-menu-97`
- **Views:** 33
- **Tags:** Food, Landing Page, E-commerce, Dark, Clean, Minimal, restaurant menu, online ordering
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

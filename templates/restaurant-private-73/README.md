# Restaurant Private Events Landing Page Template

A reusable landing page template for restaurants, bars, and venues to promote private events, showcase spaces, and capture booking enquiries.

## Project Details
- **Slug:** `restaurant-private-73`
- **Views:** 52
- **Tags:** Landing Page, Food, Services, Dark, Clean, Minimal, Restaurant, Private Events, Hospitality
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

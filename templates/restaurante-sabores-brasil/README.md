# Sabores do Brasil Website

A refined Brazilian restaurant landing page template for showcasing regional menus, monthly highlights, and reservations with a warm, story-driven design.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

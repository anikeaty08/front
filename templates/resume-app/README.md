# Product Designer Portfolio Template

A reusable portfolio template designed for product designers to showcase experience, skills, and contact info with a sleek dark UI.

## Project Details
- **Slug:** `resume-app`
- **Views:** 1370
- **Tags:** Portfolio, Resume, Design System, Skills, Experience, Contact, Dark Mode, Sidebar Navigation, Typography

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

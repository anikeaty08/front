# Retro Health Habit Tracker Template

A retro-styled daily habit tracker template that lets users input lifestyle data and see playful, estimated life expectancy impact in an interactive interface.

## Project Details
- **Slug:** `retro-health-17`
- **Views:** 17
- **Tags:** Health, Landing Page, Brand, Clean, Minimal, Large Type, Interactive, Habit Tracker, Retro UI, Calculator
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

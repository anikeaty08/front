# Retro Virtual Pet Game Template

A reusable retro game template for building an interactive virtual pet experience with pixel-style UI, animated states, and simple browser-based gameplay.

## Project Details
- **Slug:** `retro-virtual-99`
- **Views:** 56
- **Tags:** Landing Page, Entertainment, Technology, Dark, Minimal, Retro, Game, Interactive, ASCII
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Vietnamese Restaurant Landing Page Template

A vibrant, food-focused landing page template designed for restaurants and catering businesses to showcase menus and accept online orders.

## Project Details
- **Slug:** `review-page-62`
- **Views:** 21

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Medical Practice Landing Page Template

A modern RevivalMD-style landing page template for primary care and aesthetics clinics, featuring locations, services, FAQs, and an integrated booking form.

## Project Details
- **Slug:** `revivalmdaestheticclinic`
- **Views:** 26
- **Tags:** Health, Services, Landing Page, Brand, Clean, Gradient, Minimal, Large Type, Medical Clinic, Aesthetics
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Vegetarian Restaurant Landing Page Template

A reusable restaurant website template for vegetarian eateries, featuring menu browsing, table booking, contact details, and a polished local dining presentation.

## Project Details
- **Slug:** `rewa-rasoi-com-`
- **Views:** 369
- **Tags:** Landing Page, Food, Services, Clean, Minimal, Animated, restaurant, vegetarian, menu, reservation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Rezi

A clean recruiter dashboard UI template for managing jobs, candidates, and plan usage, ready to reuse in hiring and HR web applications.

## Project Details
- **Slug:** `rezi`
- **Views:** 321
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Dashboard, Recruiter, HR, SaaS, Admin
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

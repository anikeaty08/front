# Influencer Marketing Landing Page Template

This reusable influencer marketing landing page template connects brands with talent through a talent-first approach, featuring case studies, services, and contact forms.

## Project Details
- **Slug:** `rhythmstyle`
- **Views:** 1899
- **Tags:** Landing Page, Influencer Marketing, Talent Network, Case Studies, Services, Contact Form, Brand Partnerships, Campaign Results, Social Media, Creator Management
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# RIConsultancy 

A reusable landing page template for precision engineering and manufacturing companies to showcase capabilities, industries served, quality standards, and quote inquiries.

## Project Details
- **Slug:** `riconsultancy-firm`
- **Views:** 424
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Minimal, Manufacturing, Industrial, Corporate
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

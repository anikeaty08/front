# Ride Tip Modal Template

A reusable mobile payment template for ride apps to collect driver ratings and tips with preset amounts, custom input, and a clear confirmation CTA.

## Project Details
- **Slug:** `ride-tip-checkout-20`
- **Views:** 10
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Mobile UI, Payment, Tip Flow
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

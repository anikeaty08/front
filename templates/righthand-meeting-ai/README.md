# AI Meeting Assistant Landing Page Template

A reusable landing page template for promoting an AI meeting twin product that attends calls, shares updates, and sends smart recaps for busy professionals.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Food Ordering Landing Page Template

A mobile-style Nasi Ayam Gepuk food ordering template with customization, checkout, order tracking, and kitchen dashboard flows ready to adapt for your brand.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

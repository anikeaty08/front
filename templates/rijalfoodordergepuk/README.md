# Food Ordering Landing Page Template

A modern Nasi Ayam Gepuk food ordering template with menu customization, delivery checkout, and admin order management, ready to reuse for restaurant sites.

## Project Details
- **Slug:** `rijalfoodordergepuk`
- **Views:** 12
- **Tags:** Food, E-commerce, Landing Page, Brand, Clean, Colorful, Minimal, Large Type, Restaurant, Ordering
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

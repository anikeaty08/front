# Snack E-commerce Landing Page Template

A modern Kraft Snack Co. landing page template for premium snacks brands to showcase products, filters, and shopping cart-ready collections.

## Project Details
- **Slug:** `rintu-store-900`
- **Views:** 14
- **Tags:** E-commerce, Food, Landing Page, Brand, Clean, Minimal, Grid, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

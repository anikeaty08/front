# Developer Portfolio Landing Page Template

Reusable portfolio landing page template designed for software developers to showcase projects, skills, and professional experience.

## Project Details
- **Slug:** `rithytep-portfolio`
- **Views:** 88
- **Tags:** Portfolio, Developer, Projects, Skills, Experience, Technical Stack, Contact, Testimonials, Gallery

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

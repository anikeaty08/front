# Dental Clinic Landing Page Template

A modern dental clinic landing page template for family and cosmetic practices, featuring services, doctors, reviews, membership plan, and online booking.

## Project Details
- **Slug:** `riveredgedental`
- **Views:** 17
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

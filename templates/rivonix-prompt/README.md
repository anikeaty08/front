# Rivonix Aura Prompt Library Landing Page Template

A reusable landing page template providing a comprehensive AI prompt library for designing UI/UX with Aura.build, supporting Thai and English languages.

- **Slug:** `rivonix-prompt`
- **Views:** 87

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

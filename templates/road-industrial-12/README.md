# Signalisation Services Landing Page Template

A reusable landing page template for road, industrial and visual identity signalisation companies to showcase services, projects and capture contact requests.

## Project Details
- **Slug:** `road-industrial-12`
- **Views:** 23
- **Tags:** Landing Page, Services, Technology, Brand, Portfolio, Dark, Clean, Large Type, Gradient, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Roam Stays Landing Page Template

A refined travel booking landing page template for showcasing curated stays, collections, and guest stories with an editorial, design-first experience.

## Project Details
- **Slug:** `roam-editorial`
- **Views:** 1512
- **Tags:** Landing Page, Travel, Services, Brand, Clean, Minimal, Large Type, Grid, Portfolio

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

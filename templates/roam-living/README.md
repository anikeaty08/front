# ROAMLiving

A modern, mountain-themed co-living landing page template for promoting affordable housing, community living, and investor opportunities in one polished site.

## Project Details
- **Slug:** `roam-living`
- **Views:** 38
- **Tags:** Landing Page, Real Estate, Services, Brand, Clean, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Premium Travel & Stays Website Template (HTML + Figma)

Elsewhere is a premium travel and stays website template designed for booking platforms, hospitality brands, and modern travel startups. Built with a clean editorial layout and large typography system, this template includes 6 fully designed pages delivered in production-ready HTML and an editable Figma file.

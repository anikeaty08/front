# Rocknroll Barbershop & Salon Template

A dark, edgy, and high-conversion landing page template designed specifically for barbershops, salons, and grooming services.

## Project Details
- **Slug:** `rocknroll-barbershop-73`
- **Views:** 24

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

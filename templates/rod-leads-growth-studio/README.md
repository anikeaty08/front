# Rod Leads Growth Studio

A high-converting landing page template for local service businesses to showcase pricing, SEO services, and contact CTAs for predictable lead generation.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

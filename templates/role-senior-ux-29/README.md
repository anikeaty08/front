# Therapy Services Landing Page Template

A reusable landing page template for therapists, psychologists, and training academies to showcase services, courses, content, and contact options.

## Project Details
- **Slug:** `role-senior-ux-29`
- **Views:** 40
- **Tags:** Landing Page, Services, Health, Education, Blog, Clean, Minimal, Grid, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

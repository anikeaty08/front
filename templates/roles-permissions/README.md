# User Management Dashboard UI Template

A clean, reusable user management UI template for configuring scopes and actions like view, edit, and contact within your web app dashboard.

## Project Details
- **Slug:** `roles-permissions`
- **Views:** 174
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Dashboard, SaaS, Admin Panel, User Management
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

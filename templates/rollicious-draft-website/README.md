# Rollicious Website Template

A reusable restaurant website template for showcasing menus, reviews, hours, and online ordering for local dining brands and food businesses.

## Project Details
- **Slug:** `rollicious-draft-website`
- **Views:** 909
- **Tags:** Food, Landing Page, Brand, Colorful, Clean, Large Type, restaurant, menu, reviews, booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

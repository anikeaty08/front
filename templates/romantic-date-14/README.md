# Валентинка

A minimal, romantic mobile landing page template for sending stylish date invitations with photos, steps, and a heartfelt closing message.

## Project Details
- **Slug:** `romantic-date-14`
- **Views:** 22
- **Tags:** Landing Page, Brand, Minimal, Clean, Large Type, Colorful, Mobile, Romantic, Invitation, Personal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Interactive Romantic Greeting Landing Page Template

A charming, animated greeting card template designed for personal messages, special announcements, and heartfelt invitations.

## Project Details
- **Slug:** `romantic-message-24`
- **Views:** 36
- **Tags:** Social, Wedding, Personal, Animated, Colorful, Clean, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

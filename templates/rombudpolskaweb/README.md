# Construction Services Landing Page Template

A reusable landing page template for construction companies offering building services, materials sales, and equipment rental with strong local lead generation.

## Project Details
- **Slug:** `rombudpolskaweb`
- **Views:** 50
- **Tags:** Landing Page, Services, Business, Technology, Dark, Clean, Large Type, construction, equipment rental, local business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

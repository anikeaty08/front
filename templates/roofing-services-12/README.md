# Roofing Services Landing Page Template

A reusable landing page template for roofing companies to showcase services, build trust, and drive quote requests with a polished local-services design.

## Project Details
- **Slug:** `roofing-services-12`
- **Views:** 40
- **Tags:** Landing Page, Services, Brand, Clean, Gradient, Dark, Minimal, roofing, home services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

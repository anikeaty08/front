# Roofing Services Landing Page Template

A reusable landing page template for roofing contractors and home service brands to showcase heritage, benefits, and recent projects with trust-building visuals.

## Project Details
- **Slug:** `roofing-services-18`
- **Views:** 41
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Dark, Home Services, Roofing, Construction
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

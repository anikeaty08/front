# Roofing Services Landing Page Template

Modern dark-style roofing services landing page template for local craftsmen to showcase expertise, projects, and contact options in a single-page layout.

## Project Details
- **Slug:** `roofing-services-49`
- **Views:** 21
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Minimal, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

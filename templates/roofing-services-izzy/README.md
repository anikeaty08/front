# Roofing Services Landing Page Template

A reusable roofing services landing page template for contractors to showcase repairs, installations, testimonials, and capture quote requests.

## Project Details
- **Slug:** `roofing-services-izzy`
- **Views:** 31
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Minimal, home services, roofing, contractor
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

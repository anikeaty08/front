# Rooftop Bar Landing Page Template

A dark, neon rooftop bar landing page template for nightlife spots to showcase drinks, gaming zones, events, and delivery options.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

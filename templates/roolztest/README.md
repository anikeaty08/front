# Food Ordering Landing Page Template

Modern landing page template for food kiosks and online ordering sites, perfect for showcasing a digital ordering solution and capturing demo requests.

## Project Details
- **Slug:** `roolztest`
- **Views:** 15
- **Tags:** Landing Page, Food, Technology, Brand, Clean, Gradient, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Local Plumbing Services Landing Page Template

A high-converting plumbing services landing page template for local home-service businesses to showcase offerings, social proof, and drive service bookings.

## Project Details
- **Slug:** `roto-rooter-plumbers`
- **Views:** 17
- **Tags:** Landing Page, Services, Business, Local Service, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

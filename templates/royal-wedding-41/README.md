# Royal Wedding Invitation Template

A cinematic wedding invitation template for couples to share their story, events, venue, countdown, gallery, and family contact details online.

## Project Details
- **Slug:** `royal-wedding-41`
- **Views:** 40
- **Tags:** Wedding, Landing Page, Event Invitation, Dark, Elegant, Animated, Gradient, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

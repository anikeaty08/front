# Restaurant Landing Page Template

A reusable restaurant landing page template for promoting local food businesses with story sections, menu highlights, gallery imagery, reviews, and contact CTAs.

## Project Details
- **Slug:** `royalfood-saharwan`
- **Views:** 83
- **Tags:** Food, Landing Page, Services, Clean, Minimal, Brand, restaurant, menu, local dining
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

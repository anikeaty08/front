# AI Agency Landing Page Template

A dark, futuristic landing page template for AI and automation agencies to showcase services, generated work, and book high-intent sales calls.

## Project Details
- **Slug:** `royscompany-com`
- **Views:** 1509
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Futuristic, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

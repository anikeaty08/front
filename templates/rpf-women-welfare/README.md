# Women Welfare Grievance Portal UI Template

A modern dashboard-style template for a women welfare grievance and welfare request portal, ready to customize for secure role-based complaint management.

## Project Details
- **Slug:** `rpf-women-welfare`
- **Views:** 56
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Dashboard, Admin Panel, Grievance Portal, Role-based Access, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

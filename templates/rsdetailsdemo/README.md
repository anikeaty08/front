# Untitled Design

A reusable landing page template for car wrapping and detailing studios to showcase services, portfolio work, pricing inquiries, and lead generation.

## Project Details
- **Slug:** `rsdetailsdemo`
- **Views:** 33
- **Tags:** Landing Page, Services, Portfolio, Automotive, Dark, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Ruby Photography Portfolio Template

A cinematic, dark-themed photography portfolio template designed for professional photographers focusing on documentary, wedding, and editorial work.

## Project Details
- **Slug:** `ruby-photograph-86`
- **Views:** 23
- **Tags:** Portfolio, Dark, Minimal, Artist, Clean, Services, Animated, Creative
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

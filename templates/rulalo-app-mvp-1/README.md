# P2P Rental Marketplace Website Template

Reusable template for a peer‑to‑peer rental marketplace website, ideal for launching a platform like Rúlalo with home, search, item detail, dashboard, and publish flows.

- **Views:** 9

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

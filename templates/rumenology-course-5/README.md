# Education Landing Page Template

A refined landing page template for selling advanced online courses, experts, and premium academic programs with curriculum, pricing, testimonials, and FAQ.

## Project Details
- **Slug:** `rumenology-course-5`
- **Views:** 300
- **Tags:** Education, Landing Page, Services, Clean, Minimal, Dark, Brand, course, online education, academic

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

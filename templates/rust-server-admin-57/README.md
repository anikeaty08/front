# Rust Server Admin Dashboard Template

A dark, developer-focused Rust server admin dashboard template with live RCON console, connection settings, and terminal-style logs for game server control.

## Project Details
- **Slug:** `rust-server-admin-57`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

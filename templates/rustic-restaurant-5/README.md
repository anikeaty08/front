# Rustic Restaurant Landing Page Template

A reusable landing page template for rustic restaurants to showcase atmosphere, menu highlights, gallery, and reservations in a warm, welcoming layout.

## Project Details
- **Slug:** `rustic-restaurant-5`
- **Views:** 707
- **Tags:** Landing Page, Food, Business, Brand, Clean, Minimal, Large Type, Restaurant, Reservation, Gallery
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

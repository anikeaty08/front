# Logistics API Landing Page Template

A reusable landing page template for logistics APIs and delivery platforms to showcase unified infrastructure, routing, tracking, and merchant tools.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

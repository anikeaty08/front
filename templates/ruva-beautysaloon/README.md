# Luxury Salon Landing Page Template

A reusable luxury salon landing page template for showcasing hair, bridal, skincare, spa services and driving bookings via WhatsApp, phone, and forms.

## Project Details
- **Slug:** `ruva-beautysaloon`
- **Views:** 41
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Gradient, Large Type, Beauty, Salon, Spa
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Golf Tournament Live Scoring Landing Page Template

A modern, reusable template for live golf tournament scoring pages with match cards, momentum tracking, and a hero scoreboard layout.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

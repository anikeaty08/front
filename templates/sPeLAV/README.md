# Digital Wallet Interface

Responsive wallet UI displaying balance, cards carousel, quick actions, and filtered recent transactions using Tailwind CSS and Font Awesome icons.

## Project Details
- **Slug:** `sPeLAV`
- **Views:** 97
- **Tags:** Wallet, Cards Carousel, Transactions, Quick Actions, Tailwind CSS, Font Awesome, Responsive UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

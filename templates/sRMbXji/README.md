# Weather Information Card UI

Responsive weather card displaying current conditions, stats, and 5-day forecast with icons using Tailwind CSS and SVG.

## Project Details
- **Slug:** `sRMbXji`
- **Views:** 1020
- **Tags:** HTML, Tailwind CSS, Responsive, Weather UI, SVG Icons, Grid Layout
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

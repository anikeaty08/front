# DentalStudio Clinic Landing Page Template

A modern, dark-mode DentalStudio landing page template for premium cosmetic and restorative dental clinics to showcase services, pricing, and book appointments.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# SaaS Dashboard Template

A reusable SaaS dashboard template for analytics, projects, customers, tasks, and settings with a clean admin UI and modern workspace flows.

## Project Details
- **Slug:** `saas-dashboard-21`
- **Views:** 98

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

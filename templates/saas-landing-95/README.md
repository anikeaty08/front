# SaaS Landing Page Template

A reusable SaaS landing page template for modern product teams to showcase features, pricing, FAQs, and conversion-focused CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# SaaS Platform Landing Page Template

A reusable landing page template for showcasing a production-ready SaaS platform with auth, billing, admin tools, and product adoption messaging.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# SaaS Settings Dashboard UI Template

A modern, dark SaaS settings dashboard UI template for managing profiles, notifications, and API keys, ready to customize for your web app.

- **Slug:** `saas-settings-22`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Safari Departure Management Dashboard Template

A reusable template for a safari departure management dashboard, showcasing logistics, capacity, and financials for tour and travel operators.

## Project Details
- **Slug:** `safari-departure-86`
- **Views:** 24
- **Tags:** Travel, Services, Brand, Clean, Minimal, Dashboard, Tour Operator, Safari
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

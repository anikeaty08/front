# Safari Travel Landing Page Template

A reusable safari travel website template for tour operators and eco-luxury agencies to showcase destinations, itineraries, conservation impact, and bookings.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

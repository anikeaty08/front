# Sichere und Kostenlose Datenübertragung

A reusable SecureDrop-style landing page template for secure, anonymous file upload and sharing with password protection, download limits, and progress UI.

## Project Details
- **Slug:** `safe-securedrop`
- **Views:** 14
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Gradient, File sharing, Security
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Restaurant Landing Page Template

A modern dark-themed restaurant landing page template for showcasing menus, amenities, hours, and reservations for local dining venues.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

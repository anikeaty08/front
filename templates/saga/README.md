# Sleep Tales Mobile App Landing Page Template

A dark, futuristic mobile app landing page template for an interactive sleep and history story generator, featuring mood radar, settings, and playback UI.

## Project Details
- **Slug:** `saga`
- **Views:** 25
- **Tags:** Landing Page, Technology, Brand, Dark, Futuristic, Minimal, Mobile app, Interactive UI, Storytelling, Audio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

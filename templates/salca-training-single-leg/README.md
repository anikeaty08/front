# Fitness Training Landing Page Template

A reusable landing page template for balance training products, rehab programs, and guided fitness video hubs with clear modules, benefits, and conversion CTAs.

## Project Details
- **Slug:** `salca-training-single-leg`
- **Views:** 360
- **Tags:** Landing Page, Health, Services, Clean, Minimal, E-commerce, Fitness, Rehabilitation, Video Training
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Sales Analytics Dashboard UI Template

A reusable Sales Analytics Dashboard UI template for visualizing revenue, quotes, closed deals, and team performance in a modern dark-mode layout.

## Project Details
- **Slug:** `sales-analytics-94`
- **Views:** 7
- **Tags:** Landing Page, Technology, Brand, Dark, Clean, Minimal, Dashboard, Analytics, Sales
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

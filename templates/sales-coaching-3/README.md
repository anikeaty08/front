# Sales Coaching Landing Page Template

A reusable landing page template for sales coaches, closers, and consultants to promote strategy calls, showcase proof, and convert more qualified leads.

## Project Details
- **Slug:** `sales-coaching-3`
- **Views:** 79

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

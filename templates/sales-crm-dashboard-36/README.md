# Sales Dashboard Template

A reusable CRM dashboard template for managing leads, timelines, messaging, approvals, and webhook-based sales workflows in one polished interface.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

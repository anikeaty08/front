# Sales Dashboard UI Template

Modern dark-mode sales dashboard template to manage transactions, buyers, and performance metrics, ready to reuse in web apps and admin panels.

## Project Details
- **Slug:** `sales-dashboard-65`
- **Views:** 40
- **Tags:** Technology, Landing Page, Brand, Dark, Clean, Minimal, Dashboard, Admin, Sales, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

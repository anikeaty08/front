# Sales Recruitment Funnel Landing Page Template

Modern dark-mode landing page template for sales team recruitment, combining a VSL hero with a multi-step application form and thank-you confirmation flow.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Sales Samur.ai

A dark-mode agency template for coaches, consultants, and sales-focused service brands to showcase offers, proof, process, and book audit calls.

## Project Details
- **Slug:** `salessamurai`
- **Views:** 105
- **Tags:** Landing Page, Services, Technology, Dark, Clean, Gradient, Large Type, agency, sales, consulting

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# B2B Sales Strategy by Salman

A reusable landing page template for B2B sales consultants, coaches, and revenue advisors to showcase services, process, and strategy call CTAs.

## Project Details
- **Slug:** `salman-sales`
- **Views:** 94
- **Tags:** Landing Page, Services, Technology, Dark, Gradient, Minimal, Animated, B2B sales, consulting

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

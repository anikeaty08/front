# Salon Management Dashboard UI Template

A modern salon management dashboard UI template for bookings, POS, staff, inventory, and reports, ready to customize for beauty and spa businesses.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

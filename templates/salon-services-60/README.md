# Unisex Salon Landing Page Template

A clean, modern template for barbershops and unisex salons to showcase services, location, and contact details for walk-ins and bookings.

## Project Details
- **Slug:** `salon-services-60`
- **Views:** 41
- **Tags:** Landing Page, Services, Fashion, Clean, Minimal, Brand, salon, barbershop, grooming
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

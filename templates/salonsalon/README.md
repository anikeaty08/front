# Hair Salon Landing Page Template

A modern dark-style hair salon landing page template for showcasing services, pricing, gallery, and contact details for local beauty businesses.

## Project Details
- **Slug:** `salonsalon`
- **Views:** 8
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Minimal, Beauty, Hair Salon, Local Business, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

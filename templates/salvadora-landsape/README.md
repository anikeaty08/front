# Landscape Design Portfolio Template

A reusable portfolio template for landscape architects and design studios to showcase projects, philosophy, and client inquiries with an editorial feel.

## Project Details
- **Slug:** `salvadora-landsape`
- **Views:** 90
- **Tags:** Portfolio, Services, Landing Page, Art & Design, Minimal, Dark, Clean, Luxury, Landscape Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Untitled Design

A modern restaurant landing page template for showcasing Ghanaian dishes, menus, testimonials, and WhatsApp ordering for food delivery businesses.

## Project Details

- **Views:** 18

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

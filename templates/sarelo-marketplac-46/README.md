# Marketplace Web App UI Template

A modern marketplace web app UI template for multi-vendor food, grocery, and electronics delivery platforms, ready to customize for your product.

- **Slug:** `sarelo-marketplac-46`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

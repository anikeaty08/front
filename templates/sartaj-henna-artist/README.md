# Henna Artist Landing Page Template

A modern henna artist landing page template for showcasing bridal mehndi services, portfolio, pricing, and bookings with a clean, minimal aesthetic.

## Project Details
- **Slug:** `sartaj-henna-artist`
- **Views:** 32
- **Tags:** Landing Page, Services, Art & Design, Portfolio, Clean, Minimal, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

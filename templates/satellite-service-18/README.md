# Satellite Services Landing Page Template

A reusable landing page template for local dish antenna and satellite service businesses to showcase services, trust signals, reviews, FAQs, and contact CTAs.

## Project Details
- **Slug:** `satellite-service-18`
- **Views:** 39
- **Tags:** Landing Page, Services, Technology, Dark, Clean, Minimal, Local Business, Home Services, Satellite, Repair
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

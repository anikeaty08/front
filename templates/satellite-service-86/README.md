# Satellite Services Landing Page Template

A reusable landing page template for local dish antenna and satellite TV installation, repair, and signal-fixing service businesses.

## Project Details
- **Slug:** `satellite-service-86`
- **Views:** 32
- **Tags:** Landing Page, Services, Technology, Clean, Dark, Minimal, local service, satellite repair, home services

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Scale Up Agency Website Landing Page Template

A dark, high-converting agency landing page template for service businesses, showcasing process, pricing, and lead-capture contact form ready to customize.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Fine Dining Restaurant Landing Page Template

A dark, modern restaurant landing page template for upscale dining brands, featuring hero storytelling, signature menu highlights, and reservation booking.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

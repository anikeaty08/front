# School Bento Grid Landing Page Template

A clean, modern school landing page template featuring a bento grid layout with calendar, video, photo gallery, and contact sections for educational websites.

## Project Details
- **Slug:** `school-bento-18`
- **Views:** 49
- **Tags:** Landing Page, Education, Clean, Grid, Large Type, Brand, Technology, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

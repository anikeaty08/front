# School Profile Landing Page Template

A modern school profile landing page template for showcasing key data, facilities, contact info, and nearby institutions for educational organizations.

## Project Details
- **Slug:** `school-profile-22`
- **Views:** 21
- **Tags:** Landing Page, Education, Clean, Minimal, Brand, Large Type, Technology, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# School Profile Landing Page Template

A reusable landing page template for detailed school profiles, showcasing stats, facilities, staff, and nearby institutions in a clean, data-focused layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

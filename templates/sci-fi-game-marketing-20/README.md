# Sci-Fi Game Landing Page Template

A reusable dark sci-fi landing page template for promoting a tactical extraction game, showcasing features, lore updates, dev logs, and pre-launch CTAs.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

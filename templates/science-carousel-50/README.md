# Science Carousel Slide Deck Template

A reusable template for creating educational, science-focused social media slide decks with downloadable, dark-mode slides and clean typography.

## Project Details
- **Slug:** `science-carousel-50`
- **Views:** 21
- **Tags:** Landing Page, Education, Brand, Clean, Dark, Minimal, Gradient, Large Type, Presentation, Slides
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

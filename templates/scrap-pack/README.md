# Junk Removal Scrap Pack

A reusable landing page template for local junk removal and hauling businesses to showcase services, build trust, and drive estimate requests.

## Project Details
- **Slug:** `scrap-pack`
- **Views:** 56
- **Tags:** Landing Page, Services, Business, Dark, Gradient, Clean, Local Service, Home Services, Junk Removal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

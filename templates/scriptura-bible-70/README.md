# Modern Bible Reader App UI Template

A clean, modern Bible reader app UI template for scripture reading, audio playback, and study tools across desktop and mobile layouts.

## Project Details
- **Slug:** `scriptura-bible-70`
- **Views:** 14
- **Tags:** Landing Page, Technology, Clean, Minimal, Dark, Religious, Bible app, Audio player, Study tools, Mobile-first
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

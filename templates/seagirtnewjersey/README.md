# Dental Clinic Landing Page Template

A clean, modern dental clinic landing page template for promoting family, cosmetic, and pediatric dentistry services with online appointment requests.

## Project Details
- **Slug:** `seagirtnewjersey`
- **Views:** 21
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, Large Type, Technology, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Search Console Analytics Dashboard Template

A dark-mode analytics dashboard template for visualizing Search Console clicks, impressions, CTR, and positions over time, ready to adapt to your own SEO data.

## Project Details
- **Slug:** `search-console-95`
- **Views:** 37
- **Tags:** Technology, Landing Page, Brand, Dark, Minimal, Dashboard, SEO, Analytics, Data Visualization

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

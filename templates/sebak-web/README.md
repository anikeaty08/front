# Utility and Municipal Services Landing Page Template

A robust, professional landing page template for industrial utility services like sewer cleaning, trenchless repairs, and equipment rental.

## Project Details
- **Slug:** `sebak-web`
- **Views:** 69
- **Tags:** Services, Technology, Business, Brand, Clean, Minimal, Grid

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

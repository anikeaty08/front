# Medical Clinic Service Landing Page Template

A conversion-focused landing page template for medical clinics selling an "Agente de Atendimento" service system with scripts, qualification flows, and WhatsApp follow-up.

## Project Details
- **Slug:** `secretaria-ia-atendimento`
- **Views:** 49
- **Tags:** Landing Page, Services, Health, Brand, Clean, Minimal, Large Type, Gradient, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

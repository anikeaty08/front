# Secret Santa Campaign Report Landing Page Template

A festive case-study style landing page template for showcasing a Secret Santa or gift card campaign report, ready to adapt for your own brand.

## Project Details
- **Slug:** `secretsantagiftcards`
- **Views:** 25
- **Tags:** Landing Page, Brand, Clean, Colorful, Gradient, Marketing, Case Study, Campaign, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

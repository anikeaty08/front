# Secure Checkout Order Form Template

A modern secure checkout page template for collecting contact, shipping, and custom project requirements via email without backend code.

## Project Details
- **Slug:** `secure-checkout-2`
- **Views:** 16
- **Tags:** E-commerce, Services, Technology, Brand, Clean, Minimal, Large Type, Checkout, Order Form, Secure Payment
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Clearance Verification Portal UI Template

A modern NMEX-style clearance verification portal UI template for identity, vehicle, and biometric verification flows, ready to reuse in secure apps.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

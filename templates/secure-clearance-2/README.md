# Identity Verification Portal UI Template

A modern identity verification portal UI template for clearance workflows, featuring multi-step forms, PIN checks, biometrics, and release confirmation screens.

## Project Details
- **Slug:** `secure-clearance-2`
- **Views:** 20
- **Tags:** Technology, Services, Brand, Clean, Minimal, Large Type, Landing Page, Gradient, Verification, Portal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

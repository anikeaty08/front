# Secure Invite Message Landing Page Template

A dark, animated secure message landing page template for passcode-locked invites and encrypted announcements with an interactive envelope reveal.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

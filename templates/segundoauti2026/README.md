# Education Dashboard Template

A reusable education dashboard template for universities and instructors to present course syllabi, schedules, workshops, evaluation rubrics, and bibliography in one polished interface.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

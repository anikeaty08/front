# Seniorenbetreuung Landing Page Template

Ein liebevoll gestaltetes Landing Page Template für lokale Seniorenbetreuung und Alltagsbegleitung, ideal für Betreuungsdienste und Lebensbegleiter-Angebote.

## Project Details
- **Slug:** `seniorenbe-landing-90`
- **Views:** 14
- **Tags:** Landing Page, Services, Health, Brand, Clean, Minimal, Large Type, Senior Care, Local Service, Compassionate
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# SEO Blog Template

A reusable blog template for SEO consultants, marketers, and personal brands to publish articles, guides, and grow an email audience.

## Project Details
- **Slug:** `seo-blog-template-22`
- **Views:** 24
- **Tags:** Blog, Brand, Technology, Clean, Minimal, Personal Brand, SEO, Digital Marketing, Content Strategy
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

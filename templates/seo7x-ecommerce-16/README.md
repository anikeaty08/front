# SEO7X eCommerce SEO Agency Landing Page Template

A high-converting dark-mode landing page template for revenue-focused eCommerce SEO agencies to showcase results, methodology, case studies, and applications.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

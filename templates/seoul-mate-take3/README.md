# Food Landing Page Template

A reusable food landing page template for customizable oatmeal or meal brands, featuring an interactive bowl builder, rankings, plans, and conversion-focused sections.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Food Subscription Landing Page Template

A reusable landing page template for personalized oatmeal and nutrition subscription brands, featuring a product builder, benefits, pricing, reviews, and FAQ.

## Project Details
- **Slug:** `seoulmate-daesang`
- **Views:** 50
- **Tags:** Landing Page, Food, Health, Brand, Clean, Minimal, Dark, subscription, nutrition, wellness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

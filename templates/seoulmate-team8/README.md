# Food E-commerce Landing Page Template

A stylish reusable template for customizable oatmeal or meal brands, featuring a recipe builder, rankings, subscription plans, and bilingual CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

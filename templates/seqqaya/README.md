# Seqqaya Restaurant Landing Page Template

A modern restaurant landing page template for showcasing menus, reviews, and location details for cafes, bistros, and pizzerias.

## Project Details
- **Slug:** `seqqaya`
- **Views:** 352
- **Tags:** Landing Page, Food, Business, Brand, Clean, Colorful, Large Type, Gradient, Restaurant, Menu
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Serene Meditation App Template

This reusable template provides a sleek iOS-style meditation app interface with guided sessions, stats, and mindfulness features for wellness projects.

## Project Details
- **Slug:** `serene-meditation`
- **Views:** 940
- **Tags:** Landing Page, Mobile UI, Meditation, Mindfulness, Guided Sessions, Stats, Onboarding, Features, Dark Mode, Interactive
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

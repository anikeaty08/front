# Physiotherapy Clinic Landing Page Template

A clean healthcare template for physiotherapy clinics to showcase treatments, build trust, and drive online appointment bookings.

- **Slug:** `serfit-campeche`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dark Chat Interface UI Template

A reusable dark-mode chat interface UI template for messaging, collaboration, and server-style channel layouts in modern web apps.

## Project Details
- **Slug:** `server-settings-14`
- **Views:** 10
- **Tags:** Technology, Landing Page, Brand, Clean, Dark, Minimal, Large Type, chat ui, collaboration

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Service Verification Portal Landing Page Template

This reusable template provides a secure service verification portal for customers to check repair status using mobile numbers with privacy protection.

## Project Details
- **Slug:** `service-verificati-20`
- **Views:** 26
- **Tags:** Landing Page, Service Verification, Search, Results, Modal Details, Secure Portal, Privacy, Status Tracking, Responsive, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Services Management Dashboard UI Template

A clean services management dashboard UI template for listing, pricing, and editing billable services across hourly, fixed, and subscription types.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

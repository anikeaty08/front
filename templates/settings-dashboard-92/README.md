# Account Settings Dashboard Template

A reusable settings dashboard template for web apps to manage profile details, preferences, notifications, and account controls with a clean UI.

## Project Details
- **Slug:** `settings-dashboard-92`
- **Views:** 34
- **Tags:** Technology, Landing Page, Clean, Minimal, Dashboard, Settings, Admin, SaaS

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Share & Care Community Landing Page Template

A reusable Share & Care landing page template for Vietnamese circular-economy communities to share, gift, and recycle pre-loved items with a clean modern UI.

## Project Details
- **Slug:** `share-care-community-34`
- **Views:** 12
- **Tags:** Landing Page, Community, Environmental, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

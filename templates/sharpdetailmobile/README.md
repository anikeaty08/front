# Mobile Car Detailing Landing Page Template

A high-converting mobile car detailing landing page template for local service businesses to showcase packages, reviews, and online booking.

## Project Details
- **Slug:** `sharpdetailmobile`
- **Views:** 66
- **Tags:** Landing Page, Services, Business, Brand, Clean, Dark, Gradient, Large Type, Automotive, Local Service
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Shashwat

A modern AuraSteps-inspired footwear e-commerce template for showcasing premium sneakers, product details, and reviews with built-in shop and newsletter sections.

## Project Details
- **Slug:** `shashwa-ki-company`
- **Views:** 20

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

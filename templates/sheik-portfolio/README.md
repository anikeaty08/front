# Developer Portfolio Landing Page Template

A modern dark-themed developer portfolio landing page template for showcasing skills, projects, experience, and contact details for software professionals.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

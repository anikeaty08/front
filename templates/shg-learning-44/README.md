# Voice Assistant Dashboard UI Template

A reusable dashboard UI template for a Hindi-first voice assistant that helps SHG members manage loans, schemes, ONDC business and learning content.

## Project Details
- **Slug:** `shg-learning-44`
- **Views:** 11
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Dashboard, Voice Assistant, Hindi, SHG
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

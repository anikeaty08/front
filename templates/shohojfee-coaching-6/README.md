# ShohojFee Coaching Management Landing Page Template

A reusable landing page template for ShohojFee, a Bengali coaching fee collection and SMS management SaaS, designed to convert coaching centers into free trial signups.

## Project Details
- **Slug:** `shohojfee-coaching-6`
- **Views:** 19
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Education, Coaching, SaaS, Bengali, SMS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

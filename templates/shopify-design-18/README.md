# Complete Digital & E-Commerce Agency

A modern, dark-themed landing page template for freelance Shopify design specialists to showcase curated themes, services, and WhatsApp-based inquiries.

## Project Details
- **Slug:** `shopify-design-18`
- **Views:** 16
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Minimal, Large Type, Portfolio

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Shopify eCommerce Services Landing Page Template

A reusable landing page template for Shopify developers, agencies, and eCommerce service brands to showcase offers, portfolio, pricing, and capture leads.

## Project Details
- **Slug:** `shopify-ecommerce-66`
- **Views:** 34
- **Tags:** Landing Page, E-commerce, Services, Technology, Clean, Minimal, Portfolio, Shopify, Agency

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

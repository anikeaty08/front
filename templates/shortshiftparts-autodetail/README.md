# Auto Detailing Landing Page Template

A reusable landing page template for auto detailing and car care businesses to showcase services, build trust, and drive consultation or quote requests.

## Project Details
- **Slug:** `shortshiftparts-autodetail`
- **Views:** 80
- **Tags:** Landing Page, Services, Brand, Dark, Clean, Large Type, Automotive, Auto Detailing, Car Care
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

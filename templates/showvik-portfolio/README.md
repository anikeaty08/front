# Portfolio of Showvik Das

A dark, reusable portfolio template for OSP design engineers to showcase fiber network expertise, experience, education, and contact details.

## Project Details
- **Slug:** `showvik-portfolio`
- **Views:** 200
- **Tags:** Portfolio, Technology, Services, Dark, Minimal, Clean, Resume, Personal Brand, Engineering
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

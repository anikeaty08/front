# Adventure Social App Template

A reusable mobile app template for visual discovery, local activity feeds, and community condition updates for outdoor sports and travel experiences.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Restaurant Landing Page Template

A premium, brand-forward landing page template for restaurants and dining establishments featuring interactive menu previews and booking integrations.

## Project Details
- **Slug:** `shreyas-cafe-11`
- **Views:** 5
- **Tags:** Food, Services, Landing Page, Clean, Dark, Animated, Minimal

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

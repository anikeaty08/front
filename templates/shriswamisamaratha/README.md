# Temple Landing Page Template for Swami Mandir

A modern, responsive temple landing page template for showcasing Swami Samarth mandir history, daily aarti timings, pilgrim services, and donation details.

## Project Details
- **Slug:** `shriswamisamaratha`
- **Views:** 18
- **Tags:** Landing Page, Religious, Brand, Clean, Minimal, Large Type, Travel, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

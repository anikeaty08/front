# Digital Signage CMS Dashboard Template

A reusable admin dashboard template for managing digital signage viewers, schedules, assets, templates, and users across multiple locations.

## Project Details
- **Slug:** `signagecast-cms`
- **Views:** 91
- **Tags:** Technology, Services, Dashboard, Landing Page, Clean, Minimal, Dark, CMS, Admin, Digital Signage
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Web3 PR Agency Landing Page Template

A dark, futuristic landing page template for Web3 PR and AI search optimization agencies to showcase services, process, results, and book client calls.

## Project Details
- **Slug:** `signalpr2`
- **Views:** 57
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Minimal, Gradient, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Aesthetic Clinic Landing Page Template

Elegant landing page template for aesthetic and medical beauty clinics to showcase treatments, team, testimonials, and drive booking inquiries.

## Project Details
- **Slug:** `siluette`
- **Views:** 216

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

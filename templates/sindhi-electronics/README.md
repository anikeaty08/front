# Solar & Electronics Business Landing Page Template

A modern dark-theme landing page template for solar energy and electronics businesses, featuring product showcases, services, stats, and consultation lead capture.

## Project Details
- **Slug:** `sindhi-electronics`
- **Views:** 32
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Gradient, Large Type, E-commerce, Energy

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

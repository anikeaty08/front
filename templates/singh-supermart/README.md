# Grocery Store Landing Page Template

A modern grocery store landing page template for local supermarkets to showcase products, location, and hours with a clean, trust-building design.

## Project Details
- **Slug:** `singh-supermart`
- **Views:** 33
- **Tags:** Landing Page, Business, Services, Brand, Clean, Gradient, Large Type, Minimal, Grocery, Supermarket
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

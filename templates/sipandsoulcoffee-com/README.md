# Coffee House Landing Page Template

A reusable coffee house landing page template with menu, story, reviews, and contact details to showcase your café or specialty coffee shop online.

## Project Details
- **Slug:** `sipandsoulcoffee-com`
- **Views:** 61
- **Tags:** Landing Page, Food, Brand, Clean, Minimal, Large Type, Coffee Shop, Cafe, Restaurant
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Commercial Construction Landing Page Template

A reusable landing page template for commercial construction and concrete service companies to showcase expertise, services, and consultation requests.

## Project Details
- **Slug:** `site-23`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Developer Portfolio Website Template

A reusable dark portfolio template for aspiring software developers to showcase skills, featured projects, and contact details with a polished personal brand.

## Project Details
- **Slug:** `site-prototype-gagster`
- **Views:** 37
- **Tags:** Portfolio, Landing Page, Technology, Dark, Minimal, Gradient, Personal Brand, Developer, Student
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

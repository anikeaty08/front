# Construction Services Landing Page Template

A reusable landing page template for construction and renovation companies to showcase services, projects, testimonials, and capture quote requests.

## Project Details
- **Slug:** `site-ttbat`
- **Views:** 65
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Dark, Renovation, Construction, Home Improvement
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Bia Estetica e Beleza

A reusable landing page template for beauty clinics and esthetic professionals to showcase treatments, care plans, credentials, and booking CTAs.

## Project Details
- **Slug:** `sitebiaesteticaebeleza`
- **Views:** 404
- **Tags:** Landing Page, Services, Health, Brand, Dark, Minimal, Clean, Beauty, Wellness, Spa
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

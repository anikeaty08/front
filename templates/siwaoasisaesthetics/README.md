# Medical Aesthetics Clinic Landing Page Template

A premium medical spa landing page template for aesthetics clinics to showcase services, locations, reviews, and appointment requests with an elegant, modern design.

## Project Details
- **Slug:** `siwaoasisaesthetics`
- **Views:** 9
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Gradient, Large Type, Medical Spa, Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Ski Instructor Landing Page Template

A reusable landing page template for independent ski & snowboard instructors or ski schools to showcase offers, instructors, and capture bookings.

## Project Details
- **Slug:** `ski-instructor-89`
- **Views:** 40
- **Tags:** Landing Page, Services, Travel, Brand, Clean, Minimal, Large Type, Ski instructor, Sports coaching
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dermatology & Aesthetic Clinic Landing Page Template

A high-end, clinical landing page template designed for dermatologists and aesthetic specialists to showcase skin treatments and patient results.

## Project Details
- **Slug:** `skin-page-dr-namrata-`
- **Views:** 20
- **Tags:** Health, Services, Clean, Minimal, Portfolio, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

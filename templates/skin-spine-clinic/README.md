# Skin and Spine Clinic 

A reusable landing page template for dermatology and cosmetic clinics to showcase services, specialist profiles, testimonials, and appointment booking.

## Project Details
- **Slug:** `skin-spine-clinic`
- **Views:** 65
- **Tags:** Health, Landing Page, Services, Clean, Minimal, Gradient, Medical, Dermatology, Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Skiper-UI Navbar Component Template

A reusable Skiper-UI navbar template for modern apps and landing pages, featuring a dark gradient brand bar, responsive links, and a bold Sign In CTA.

- **Slug:** `skiper-ui-navbar-31`
- **Views:** 18

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

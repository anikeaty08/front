# Fintech SaaS Landing Page Template

A reusable fintech landing page template for payment infrastructure, billing, and embedded finance platforms targeting startups, SaaS teams, and enterprises.

- **Slug:** `skriitofficialsite`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

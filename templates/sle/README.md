# Sober Living Services Landing Page Template

A modern, brand-forward landing page template for sober living and transitional housing programs to showcase services, structure, and impact.

## Project Details
- **Slug:** `sle`
- **Views:** 58
- **Tags:** Landing Page, Services, Health, Brand, Clean, Dark, Gradient, Large Type, Minimal

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

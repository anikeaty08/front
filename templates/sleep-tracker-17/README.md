# Sleep Tracker App Template

A reusable mobile app template for CBT-I sleep tracking, habit logging, sleep metrics, and guided content for digital health and wellness products.

- **Slug:** `sleep-tracker-17`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

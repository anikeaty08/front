# sleepal-homepage

A reusable, dark-mode e-commerce footer template for product brands featuring newsletter signup, payment badges, support links, and legal navigation.

## Project Details
- **Slug:** `sleepal-homepage`
- **Views:** 125
- **Tags:** E-commerce, Landing Page, Technology, Brand, Dark, Clean, Minimal, Large Type, Footer, Newsletter
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

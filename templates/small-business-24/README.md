# Small Business Web Design Landing Page Template

Clean, conversion-focused landing page template for small business web design services, showcasing a 5-day, fixed-price website offer for agencies or studios.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

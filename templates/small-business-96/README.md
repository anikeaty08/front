# Small Business Hub Landing Page Template

A modern small business hub landing page template for showcasing resources, software deals, directories, and tutorials to support local Main Street businesses.

## Project Details
- **Slug:** `small-business-96`
- **Views:** 65
- **Tags:** Landing Page, Business, Services, Technology, Brand, Clean, Minimal, Gradient, Directory, Small Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

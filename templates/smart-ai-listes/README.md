# AI Tool Directory Landing Page Template

A modern AI tool directory landing page template for showcasing, filtering, and reviewing AI tools with blog resources and ad placements.

## Project Details
- **Slug:** `smart-ai-listes`
- **Views:** 66

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

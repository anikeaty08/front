# Smart Campus Student Utility Dashboard Template

A modern Smart Campus web app template for student utilities including login, lost & found, resource exchange, and infrastructure complaint tracking.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Smart Home App Landing Page Template

A reusable landing page template designed for showcasing smart home control apps, featuring device management, thermostat, lighting, and user interface elements.

## Project Details
- **Slug:** `smart-home`
- **Views:** 1294
- **Tags:** Landing Page, Smart Home, Thermostat, Lights, Devices, UI, Controls, Dashboard, Responsive, TailwindCSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

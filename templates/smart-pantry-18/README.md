# Smart Pantry Mobile App UI Template

A clean mobile app UI template for smart pantry management, grocery lists, and recipe planning, ready to customize for your own food organization product.

## Project Details
- **Slug:** `smart-pantry-18`
- **Views:** 17
- **Tags:** Landing Page, Food, Technology, Clean, Minimal, Brand, Mobile app, Pantry management, Grocery list, Recipes

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

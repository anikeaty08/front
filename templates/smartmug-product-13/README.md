# SmartMug Product Landing Page Template

A sleek, dark-mode SmartMug product landing page template designed to showcase a smart heated mug, highlight benefits, and drive “Order Now” purchases.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

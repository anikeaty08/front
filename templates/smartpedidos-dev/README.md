# Smart Pedidos SaaS Landing Page Template

Conversion-focused SaaS landing page template for Smart Pedidos, a B2B sales force and AI assistant platform, ready to reuse for similar software products.

## Project Details
- **Slug:** `smartpedidos-dev`
- **Views:** 30
- **Tags:** Landing Page, Technology, Business, Brand, Clean, Gradient, Minimal, Large Type, SaaS, AI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Online Tuition Classes in English & Malayalam

A modern SmartSteps-inspired online tuition landing page template for promoting personalized classes and booking WhatsApp demos for students in grades 5–12.

## Project Details
- **Slug:** `smartstepsonline`
- **Views:** 31
- **Tags:** Landing Page, Education, Services, Brand, Clean, Minimal, Large Type, Gradient, Technology, Tutoring
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

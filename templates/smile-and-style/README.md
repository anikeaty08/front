# Smile And Style

A modern dark-style dental clinic landing page template for showcasing services, building trust, and driving consultation bookings.

## Project Details
- **Slug:** `smile-and-style`
- **Views:** 18
- **Tags:** Landing Page, Health, Services, Brand, Clean, Dark, Gradient, Large Type, Dental Clinic, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Smiles By Bergen Dental Website

A modern dental practice landing page template for family and cosmetic dentists to showcase services, locations, and appointment bookings with a clean, patient-focused design.

## Project Details
- **Slug:** `smilesbybergendental`
- **Views:** 95
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Family dentistry, dental clinic template
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

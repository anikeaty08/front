# Holistic Dental Clinic Landing Page Template

Customizable landing page template for holistic and pediatric dental clinics to showcase services, memberships, and online appointment requests.

## Project Details
- **Slug:** `smilewellnessdental`
- **Views:** 17
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Gradient, Large Type, Dentist, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

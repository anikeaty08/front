# Auto Detailing Services Landing Page Template

A premium landing page template for car detailing studios to showcase services, pricing, portfolio work, and drive customer inquiries.

## Project Details
- **Slug:** `smkdetailing`
- **Views:** 61
- **Tags:** Landing Page, Services, Brand, Dark, Clean, Minimal, Luxury, Automotive, Detailing

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

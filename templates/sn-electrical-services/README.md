# Electrical Services Landing Page Template

A modern dark-theme electrical services landing page template for showcasing residential, commercial, and emergency offerings with a built-in quote request form.

## Project Details
- **Slug:** `sn-electrical-services`
- **Views:** 14
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

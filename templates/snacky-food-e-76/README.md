# Snacky Food E-commerce Landing Page Template

A modern Snacky-themed food e-commerce landing page template for selling chips, biscuits, and snacks online with product cards, contact form, and CTAs.

## Project Details
- **Slug:** `snacky-food-e-76`
- **Views:** 21
- **Tags:** Food, E-commerce, Landing Page, Brand, Colorful, Clean, Minimal, Large Type, Gradient, Flat
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

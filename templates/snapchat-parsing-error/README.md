# Mobile Warning Overlay UI Template

A reusable UI template for a mobile-style restricted-page overlay with a glassmorphism coach mark prompting users to open the page in their browser.

## Project Details
- **Slug:** `snapchat-parsing-error`
- **Views:** 33
- **Tags:** Landing Page, Technology, Brand, Minimal, Clean, Gradient, Large Type, Mobile overlay, Glassmorphism, Coach mark
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

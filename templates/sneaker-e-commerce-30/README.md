# Footwear E-commerce Template

A reusable e-commerce template for modern shoe stores, featuring a polished product catalog, filters, product detail views, and conversion-focused shopping CTAs.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

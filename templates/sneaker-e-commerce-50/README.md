# E-commerce Shoe Catalog Landing Page Template

A modern e-commerce shoe catalog landing page template for showcasing footwear collections with filters, product grid, and membership promotion.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

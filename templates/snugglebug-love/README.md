# SnuggleBug

A soft, modern landing page template for gentle parenting apps or baby care products, featuring feature highlights, waitlist signup, and calming, family-first design.

## Project Details
- **Slug:** `snugglebug-love`
- **Views:** 60
- **Tags:** Landing Page, Health, Technology, Brand, Clean, Colorful, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

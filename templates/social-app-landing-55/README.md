# Social App Landing Page Template

A high-impact, dark-mode landing page template for social and community apps like VYBZ, optimized for showcasing real-time nearby vibes and driving app downloads.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Social Events Landing Page Template

A reusable landing page template for curated social clubs and event communities to showcase experiences, upcoming gatherings, and drive reservations.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

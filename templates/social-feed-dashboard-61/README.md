# Social Feed Dashboard Template

A reusable social platform dashboard template for prototyping feeds, promoted posts, engagement flows, and user-segment analytics in a modern UI.

## Project Details
- **Slug:** `social-feed-dashboard-61`
- **Views:** 56
- **Tags:** Technology, Dashboard, Social, Landing Page, Clean, Minimal, Dark, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

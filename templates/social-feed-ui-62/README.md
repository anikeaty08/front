# Social Feed UI Template

A reusable social media feed UI template that recreates an X-style timeline layout with sidebars, composer, and responsive navigation for modern web apps.

## Project Details
- **Slug:** `social-feed-ui-62`
- **Views:** 40
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Large Type, Social feed, Social media UI, Tailwind CSS, Responsive layout
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

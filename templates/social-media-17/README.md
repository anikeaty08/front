# Non-profit Impact Landing Page Template

A modern non-profit landing page template for showcasing global impact programs, from healthcare and education to clean water and shelter initiatives.

## Project Details
- **Slug:** `social-media-17`
- **Views:** 13
- **Tags:** Landing Page, Non-profit, Services, Brand, Dark, Clean, Large Type, Grid, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

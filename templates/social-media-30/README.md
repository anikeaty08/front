# Social Media Web App UI Template

A dark, modern CreatorHub social media web app UI template featuring login, feed, trends, and profile layouts for community platforms.

## Project Details
- **Slug:** `social-media-30`
- **Views:** 181
- **Tags:** Landing Page, Technology, Brand, Dark, Clean, Minimal, Social media, Community platform, Web app UI, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Social Media Downloader Landing Page Template

A reusable dark-mode landing page template for social media reel and video downloader tools, featuring URL input, platform detection, and download results UI.

## Project Details
- **Slug:** `social-media-35`
- **Views:** 86
- **Tags:** Landing Page, Technology, Dark, Gradient, Clean, Animated, downloader, social media, video tool
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

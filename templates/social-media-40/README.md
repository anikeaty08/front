# Social Media Management SaaS Landing Page Template

A dark, modern SaaS landing page template for social media management platforms, featuring AI captions, analytics, pricing, and multi-channel publishing.

- **Slug:** `social-media-40`
- **Views:** 30

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

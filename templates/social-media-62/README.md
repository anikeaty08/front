# Social Media App UI Template

A reusable mobile app template for showcasing a social feed, stories, reactions, and creator-focused navigation in a polished social platform UI.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Social Media Marketing Agency Landing Page Template

A reusable dark, high-converting landing page template for social media marketing agencies to showcase services, client results, and book strategy calls.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

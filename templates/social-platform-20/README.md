# ZoneUp

A reusable social platform template for kids, adults, and businesses with role-based feeds, marketplace views, AI creation tools, and admin dashboards.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Cafe Restaurant Landing Page Template

A stylish cafe and restaurant template for showcasing menus, catering, reservations, delivery, testimonials, and local brand experience online.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Softloftix Software Agency Landing Page Template

A dark, modern landing page template for software agencies to showcase services, case studies, pricing, and contact forms in a conversion-focused layout.

## Project Details
- **Slug:** `softloftix-software-51`
- **Views:** 34
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Gradient, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

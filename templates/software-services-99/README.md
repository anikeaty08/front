# Software Services Landing Page Template

A reusable landing page template for software consultancies offering custom web applications, portals, and ERP integration services.

## Project Details
- **Slug:** `software-services-99`
- **Views:** 15
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Large Type, Software agency, Web development, Consulting

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

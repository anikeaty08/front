# Software Utility Landing Page Template

A reusable dark landing page template for promoting and distributing a desktop system utility with feature highlights, setup steps, and download CTA.

## Project Details
- **Slug:** `software-utility-87`
- **Views:** 30
- **Tags:** Landing Page, Technology, Dark, Minimal, Clean, Gradient, software, utility, download
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

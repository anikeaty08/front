# Solana Wallet Chat Landing Page Template

A dark, futuristic landing page template for a Solana wallet-to-wallet encrypted chat app, showcasing features, pricing, FAQ, and in-app chat preview.

## Project Details
- **Slug:** `solana-private-15`
- **Views:** 41
- **Tags:** Landing Page, Technology, Brand, Dark, Futuristic, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

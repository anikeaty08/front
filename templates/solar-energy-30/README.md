# Solar Energy Supplier Landing Page Template

A modern dark-theme landing page template for solar energy equipment suppliers in Kuwait, ideal for showcasing products, solutions, and contact inquiries.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

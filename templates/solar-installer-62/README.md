# Solar Installer Landing Page Template

A reusable template for local solar and home battery installers to showcase services, projects, FAQs, and capture leads via quote request forms.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

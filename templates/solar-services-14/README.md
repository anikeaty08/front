# Solar Services Landing Page Template

A reusable landing page template for solar, net metering, and technical services companies to showcase offerings, equipment, portfolio, and lead-generation contact forms.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

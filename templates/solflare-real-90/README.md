# Solflare Real Estate Landing Page Template

A modern dark-mode real estate landing page template for agencies to showcase properties, testimonials, FAQs, and contact forms in a premium brand style.

- **Slug:** `solflare-real-90`
- **Views:** 505

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

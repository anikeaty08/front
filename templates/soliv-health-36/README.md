# Health App Landing Page Template

A modern Soliv-inspired landing page template for promoting a flexible wellness and nutrition app, ready to reuse and adapt for your own health product.

## Project Details
- **Slug:** `soliv-health-36`
- **Views:** 28
- **Tags:** Landing Page, Health, Technology, Brand, Clean, Gradient, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

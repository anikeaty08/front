# Financial Dashboard Template

A reusable financial dashboard template for trust account and project monitoring, with KPI cards, activity summaries, approvals, and AI-assisted insights.

## Project Details
- **Slug:** `sollapay-finance-5`
- **Views:** 12
- **Tags:** Technology, Services, Dashboard, Clean, Minimal, Gradient, Landing Page, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

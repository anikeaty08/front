# Mental Health Services Landing Page Template

A clean, modern template for mental health clinics, therapists, and wellness practices to showcase services, team, resources, and contact options.

- **Slug:** `solus-mental-23`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

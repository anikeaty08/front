# Somed Pharmacy

A modern pharmacy website template for local drugstores and health stores, featuring services, testimonials, contact details, delivery requests, and map integration.

## Project Details
- **Slug:** `somed-pharmacy-ng`
- **Views:** 19
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Gradient, Pharmacy, Local Business, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

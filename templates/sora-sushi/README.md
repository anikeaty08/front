# Sora Sushi Restaurant Landing Page Template

A reusable landing page template designed for modern sushi restaurants offering omakase dining, menu showcase, reservations, and ambiance presentation.

## Project Details
- **Slug:** `sora-sushi`
- **Views:** 2315
- **Tags:** Landing Page, Sushi, Omakase, Menu, Reservation, Restaurant, Cocktail Bar, Gallery, Hours, Location
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Secure Marketplace UI Template

A dual-interface template for a Saudi secure marketplace, featuring an Arabic RTL consumer app and English admin dashboard for escrow-based buy & sell platforms.

## Project Details
- **Slug:** `souqsafeuiux-design`
- **Views:** 9
- **Tags:** E-commerce, Technology, Landing Page, Brand, Clean, Minimal, Large Type, Gradient, Marketplace, Admin Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

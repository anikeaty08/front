# Sourcing Platform Dashboard Template

A reusable dashboard template for sourcing platforms to manage buyer requests, admin approvals, supplier workflows, and messaging in one clean interface.

## Project Details
- **Slug:** `sourcing-platform-28`
- **Views:** 15
- **Tags:** Technology, Services, Landing Page, Clean, Minimal, Dashboard, Admin, Messaging, SaaS, Procurement
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

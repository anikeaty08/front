# Sourcing Login Page Template

A clean enterprise login template for sourcing and supply chain platforms, built to help B2B teams sign in securely and access their dashboard fast.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

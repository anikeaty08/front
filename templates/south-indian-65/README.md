# House Of Benne

A warm, reusable restaurant landing page template for showcasing menu highlights, ambiance, reviews, and location details for cafes or local food brands.

## Project Details
- **Slug:** `south-indian-65`
- **Views:** 110
- **Tags:** Landing Page, Food, Brand, Clean, Minimal, Gallery, Restaurant, Cafe, Menu
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# SPA Animal Adoption Landing Page Template

Modern SPA-style animal adoption landing page template for shelters and non-profits to showcase pets, drive donations, and recruit volunteers online.

## Project Details
- **Slug:** `spa-animal-adoption-57`
- **Views:** 10
- **Tags:** Landing Page, Non-profit, Services, Clean, Minimal, Brand, Large Type, Animal Adoption, Donation, Volunteer
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

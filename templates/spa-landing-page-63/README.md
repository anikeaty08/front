# Korean Head Spa Landing Page Template

A refined spa landing page template for Korean head spa, massage, and reflexology studios to showcase services, pricing, testimonials, and online booking.

## Project Details
- **Slug:** `spa-landing-page-63`
- **Views:** 56
- **Tags:** Landing Page, Services, Health, Brand, Clean, Minimal, Large Type, Wellness, Massage, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

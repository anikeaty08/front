# Spark Conference Landing Page Template

A reusable landing page template designed for conferences and events to showcase speakers, features, and encourage sign-ups.

## Project Details
- **Slug:** `spark-conference`
- **Views:** 1018
- **Tags:** Landing Page, Conference, Speakers, Features, Registration, Events, Networking, Innovation, Community
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Sparks Dashboard Landing Page Template

A reusable dashboard landing page template designed for visualizing sales pipelines, revenue forecasts, team health, and priority tasks with interactive charts.

## Project Details
- **Slug:** `sparks-dashboard`
- **Views:** 2174
- **Tags:** Landing Page, Dashboard, Pipeline, Revenue, Charts, Team Health, Tasks, D3.js, Analytics, Marketing
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Spatial Banking Dashboard UI Template

A modern banking dashboard UI template for financial apps, featuring glassmorphism cards, charts, and transaction views ready to customize for your product.

- **Slug:** `spatial-banking-31`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

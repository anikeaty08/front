# Specialist Onboarding Dashboard UI Template

A reusable dark-mode specialist onboarding dashboard UI template for platforms to guide new experts through profile setup, status, and activation steps.

- **Slug:** `specialist-onboarding-10`
- **Views:** 12

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

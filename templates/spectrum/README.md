# Spectrum Audio SaaS Landing Page Template

A modern Spectrum-themed landing page template for audio SaaS products, showcasing features, integrations, and analytics for music creators and sound teams.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

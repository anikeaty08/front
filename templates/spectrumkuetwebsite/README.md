# Spectrum Website Template

A dark, animated multi-section website template for leadership and events clubs to showcase about, events, and alumni in a modern, brand-forward layout.

## Project Details
- **Slug:** `spectrumkuetwebsite`
- **Views:** 41
- **Tags:** Landing Page, Education, Conference, Brand, Dark, Animated, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

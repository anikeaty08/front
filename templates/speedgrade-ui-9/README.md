# SpeedGrader UI Redesign Template

A clean, minimal interface template for redesigning SpeedGrader-style grading and feedback workflows in education platforms.

- **Slug:** `speedgrade-ui-9`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

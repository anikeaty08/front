# SPEXOGRAPH Portfolio Website Template

A dark, futuristic website template for showcasing student, freelancer, and corporate portfolios with tiered pricing and modern, animated sections.

## Project Details
- **Slug:** `spexograph-portfolio-39`
- **Views:** 36
- **Tags:** Landing Page, Portfolio, Services, Technology, Brand, Clean, Dark, Futuristic, Animated, Gradient

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

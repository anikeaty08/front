# Dental Clinic Landing Page Template

Modern dental clinic landing page template for practices offering family, cosmetic, and implant dentistry, optimized for local patients to book online.

## Project Details
- **Slug:** `spfdentalcarenewjersery`
- **Views:** 15
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Dental, Medical, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

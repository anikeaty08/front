# Crypto Crash Game UI Template

A reusable dark-mode crypto crash game interface template featuring live bets, animated multiplier graph, and betting controls for gaming platforms.

## Project Details
- **Slug:** `spineazyautopilot`
- **Views:** 8
- **Tags:** Landing Page, Technology, Brand, Dark, Gradient, Large Type, Minimal, Gaming, Crypto, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

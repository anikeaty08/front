# Sports Academy Manager App UI Template

A modern mobile app UI template for sports academies to manage athletes, attendance, staff, billing, and communication from a sleek, glassmorphism dashboard.

## Project Details
- **Slug:** `sports-academy-74`
- **Views:** 23
- **Tags:** Landing Page, Brand, Technology, Clean, Gradient, Minimal, Large Type, Sports, Mobile App, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

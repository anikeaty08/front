# Sports Betting Platform Template

A reusable sports betting platform template for building sleek sportsbook, betslip, dashboard, and admin experiences across desktop and mobile.

## Project Details
- **Slug:** `sports-betting-64`
- **Views:** 108
- **Tags:** Technology, Landing Page, Dark, Clean, Dashboard, Sports Betting, Mobile UI, Admin Panel
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

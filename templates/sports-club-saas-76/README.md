# Sports Club Management Landing Page Template

A reusable landing page template for tennis clubs and racket sport managers to promote ladder competitions, automate scheduling, and grow player engagement.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# CourtMaster Sports Booking Landing Page Template

CourtMaster is a reusable landing page template for Vietnamese sports court management and online booking platforms, optimized to showcase features and boost signups.

## Project Details
- **Slug:** `sports-court-48`
- **Views:** 16
- **Tags:** Landing Page, Technology, Business, Brand, Dark, Clean, Gradient, Large Type, Minimal, SaaS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Sports Court Booking Web App Template

A modern TurfBook UAE-inspired template for building a reusable sports court booking web app with player and venue-owner dashboards.

## Project Details
- **Slug:** `sports-court-uae`
- **Views:** 39
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Gradient, Large Type, Booking, Dashboard
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

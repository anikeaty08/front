# Rugby Jersey E-commerce Landing Page Template

Dark, premium e-commerce template for showcasing and selling a flagship sports jersey collection, fully reusable for apparel and fan gear brands.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Sports Management Dashboard Template

A reusable dark-mode template for building a sports booking or roster management dashboard with drafting, scheduling, team assignment, and in-app messaging.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

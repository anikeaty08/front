# Sports Training Landing Page Template

A bold, reusable landing page template for sports performance academies, coaches, and athlete training programs with programs, locations, pricing, and blog sections.

## Project Details
- **Slug:** `sports-training-60`
- **Views:** 59
- **Tags:** Landing Page, Services, Health, Blog, Dark, Clean, Large Type, Sports, Fitness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Sports Turf Booking App UI Template

A modern mobile-style sports turf booking app UI template for venues like Velocity Turf to showcase facilities, manage slots, and handle admin dashboards.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

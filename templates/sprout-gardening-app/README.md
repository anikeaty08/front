# Gardening App Signup Page Template

A modern, conversion-focused signup page template for gardening or productivity apps, featuring social login, testimonials, and a split-screen layout.

## Project Details
- **Slug:** `sprout-gardening-app`
- **Views:** 33
- **Tags:** Landing Page, Brand, Technology, Clean, Gradient, Large Type, Minimal, Services, Signup, SaaS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Spudhaus.

A modern restaurant landing page template for showcasing your late-night menu, hours, and location with mouthwatering imagery and clear calls to visit.

## Project Details
- **Slug:** `spudhaus-restaurant-27`
- **Views:** 22
- **Tags:** Landing Page, Food, Clean, Minimal, Brand, Large Type, Restaurant, Menu, Location

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

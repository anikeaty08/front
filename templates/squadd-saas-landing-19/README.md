# Squadd SaaS Landing Page Template

Moderno template di landing page per software gestionale SaaS come Squadd, ideale per presentare funzionalità, prezzi e prove gratuite alle PMI.

- **Slug:** `squadd-saas-landing-19`
- **Views:** 10

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Cleaning Services Landing Page Template

A modern cleaning services landing page template for agencies to showcase services, social proof, and capture quote requests in one high-converting layout.

## Project Details
- **Slug:** `squeakycleaning`
- **Views:** 35
- **Tags:** Services, Landing Page, Brand, Clean, Minimal, Large Type, Gradient, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

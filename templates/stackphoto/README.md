# Stack Studio - Photography Studio Landing Page Template

A modern one-page landing page for photography and visual asset platforms, featuring a clean light UI, smooth animations, responsive image grids, and efficient Tailwind CSS-based structure.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

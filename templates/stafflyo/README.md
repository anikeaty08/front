# Stafflyo Brand Guidelines Template

A clean, minimal brand guidelines template for SaaS and workforce apps, outlining logo, colors, typography, UI, and tone of voice for consistent branding.

## Project Details
- **Slug:** `stafflyo`
- **Views:** 134
- **Tags:** Brand, Brand Guidelines, Landing Page, Technology, Clean, Minimal, Grid, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Operations Management SaaS Landing Page Template

A reusable landing page template for workforce operations software that showcases shift coverage, escalation workflows, multi-location control, pricing, and CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Stalen Onderstel E-commerce Landing Page Template

Een conversiegerichte e-commerce landing page template voor stalen tafelpoten en maatwerk frames, perfect voor webshops in meubel- en interieurbranche.

1. Open folder in VS Code / terminal.
2. Run `npm install`.

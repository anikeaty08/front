# Medical Supplies Landing Page Template

A modern, conversion-focused template for New Zealand medical supplies companies to showcase products, catalogue downloads, reviews, and contact options.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

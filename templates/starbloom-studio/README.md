# F&B Brand Identity Studio Landing Page Template

A refined landing page template for food, beverage, and hospitality brand identity studios to showcase services, process, work, and capture project inquiries.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Staff Sales Dashboard UI Template

A reusable staff sales dashboard UI template for tailoring or retail teams, featuring orders, performance metrics, leaderboards, and internal tools.

## Project Details
- **Slug:** `starstaffmanage`
- **Views:** 13
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Dashboard, Sales, Tailoring, Internal Tools

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

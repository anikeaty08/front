# Direct-to-Consumer Food Landing Page Template

A clean, conversion-focused landing page template designed for food and wellness products looking to showcase simple ingredients and direct-to-consumer sales.

## Project Details
- **Slug:** `startwithapbpacket`
- **Views:** 86
- **Tags:** Food, Health, Landing Page, Clean, Minimal, E-commerce
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

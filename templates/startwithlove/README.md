# #StartWithLove Conversation Landing Page Template

A conversational landing page template for movements or summits, using chat-style storytelling to explain your mission, event, and membership journey.

## Project Details
- **Slug:** `startwithlove`
- **Views:** 21
- **Tags:** Landing Page, Brand, Clean, Minimal, Large Type, Conference, Education, Social, Technology

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

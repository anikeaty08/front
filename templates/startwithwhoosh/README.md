# Beauty Booking SaaS Landing Page Template

A dark, modern SaaS landing page template for AI-powered salon and spa booking platforms, showcasing features, admin dashboard, and conversion-focused CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

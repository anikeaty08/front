# Flutter Developer Portfolio Website Template

A modern dark-mode Flutter developer portfolio website template showcasing skills, tech stack, projects, and contact form for mobile engineers.

## Project Details
- **Slug:** `staywithabdullah`
- **Views:** 25
- **Tags:** Landing Page, Portfolio, Technology, Clean, Dark, Gradient, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

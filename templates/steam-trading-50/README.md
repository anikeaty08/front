# Steam Trading API Landing Page Template

A dark, developer-focused landing page template for marketing a Steam inventory and market API, ideal for gaming SaaS and trading tools.

## Project Details
- **Slug:** `steam-trading-50`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

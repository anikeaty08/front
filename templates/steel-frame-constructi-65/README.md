# Steel Frame Construction Landing Page Template

A reusable landing page template for construction companies specializing in Steel Frame technology to showcase projects, benefits, process, and capture leads with a professional design.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Primary School Landing Page Template

A modern Curio-inspired primary school website template for showcasing your school, team, news, and parent information with clear calls to visit and enroll.

## Project Details
- **Slug:** `steenspil-curiozakaria`
- **Views:** 15
- **Tags:** Landing Page, Education, Brand, Clean, Minimal, Large Type, Gradient, Social
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Business Funding Landing Page Template

A reusable landing page template for business funding, credit repair, and capital consulting services that converts entrepreneurs into booked consultation calls.

## Project Details
- **Slug:** `steve-park-landing-page`
- **Views:** 60
- **Tags:** Landing Page, Services, Business, Dark, Clean, Large Type, Technology, funding, credit repair, consulting
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

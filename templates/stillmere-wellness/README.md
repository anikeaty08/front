# Stillmere Wellness & Private Sanctuary Template

A sophisticated and serene landing page template designed for private wellness houses, sensory therapy clinics, and restorative health practices.

## Project Details
- **Slug:** `stillmere-wellness`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

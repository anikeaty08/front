# Stokes Learning Path Landing Page Template

A dark, education-focused landing page template for teaching Stokes’ Theorem from zero with visual lessons, practice mode, and an interactive flux playground.

## Project Details
- **Slug:** `stokes-theorem-86`
- **Views:** 8
- **Tags:** Landing Page, Education, Brand, Technology, Dark, Gradient, Minimal, Large Type, Clean
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

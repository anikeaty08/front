# Medical and Pain Relief Landing Page Template

A high-converting landing page template designed for medical clinics, chiropractors, and physical therapy practices to drive patient consultations.

## Project Details

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

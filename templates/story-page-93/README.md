# Vietnamese Restaurant Landing Page Template

A reusable restaurant website template for Vietnamese cafés, food trucks, and casual dining brands to showcase story, menu highlights, reviews, hours, and online ordering.

## Project Details
- **Slug:** `story-page-93`
- **Views:** 297
- **Tags:** Food, Landing Page, Brand, Clean, Minimal, Colorful, restaurant, Vietnamese, catering, testimonials
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Snäxx App Splash Screen Template

A sleek, dark-mode splash screen template for apps or SaaS products, showcasing a shimmer logo, animated loader, and secure connection status.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

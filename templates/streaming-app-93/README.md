# Anime Streaming App Landing Page Template

A dark, cinematic landing page template for promoting an anime and movie streaming app with feature highlights, developer profiles, and community links.

- **Slug:** `streaming-app-93`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Streaming Admin Dashboard Template

A dark, modern StreamLab-style streaming admin dashboard template for managing movies, sessions, and server health in media server apps.

## Project Details
- **Slug:** `streamlab-dashboard-11`
- **Views:** 12
- **Tags:** Technology, Entertainment, Landing Page, Dark, Minimal, Dashboard, Streaming, Admin Panel, Media Server
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

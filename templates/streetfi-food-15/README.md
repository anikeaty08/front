# Streetfi Food Delivery Landing Page Template

A modern Streetfi food delivery landing page template inspired by Zomato-style UI, perfect for showcasing restaurant listings, offers, and online ordering experiences.

## Project Details
- **Slug:** `streetfi-food-15`
- **Views:** 14
- **Tags:** Landing Page, Food, Brand, Clean, Colorful, Minimal, Technology, Large Type, Grid
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Student Charity Association Landing Page Template

Reusable landing page template for a student charity association, featuring events calendar, volunteer signup, and donation sections for campus non-profits.

- **Slug:** `student-charity-67`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

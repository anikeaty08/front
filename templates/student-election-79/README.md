# Student Election Campaign Landing Page Template

A modern student election campaign landing page template for candidates to showcase their manifesto, collect issues, and share voting information.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# KazPlat

A modern student portal dashboard UI template for managing tasks, grades, course materials, and academic calendar in a clean, responsive layout.

## Project Details
- **Slug:** `student-portal-96`
- **Views:** 2
- **Tags:** Education, Landing Page, Technology, Clean, Minimal, Dashboard, Student Portal, Academic, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Hair Studio Mona Landing Page Template

Elegant hair salon website template for showcasing services, pricing, and contact details—perfect reusable template for modern beauty studios and hair stylists.

## Project Details
- **Slug:** `studio-mona`
- **Views:** 42
- **Tags:** Landing Page, Brand, Clean, Minimal, Services, Beauty, Hair Salon, Local Business, Single Page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

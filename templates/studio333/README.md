# Hair Salon Landing Page Template

A modern hair salon website template for multi-location studios, perfect for showcasing services, stylists, and contact details in a clean, conversion-ready layout.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

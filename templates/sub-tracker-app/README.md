# SubTracker - cykliczne płatności w jednym miejscu

A modern dark-mode SubTracker SaaS landing page template for subscription and personal finance apps, ready to customize for your own product launch.

## Project Details
- **Slug:** `sub-tracker-app`
- **Views:** 2

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

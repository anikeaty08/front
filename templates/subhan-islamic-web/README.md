# Islamic Learning Landing Page Template

A faith-centered template for building an Islamic website with Quran reading, Hadith collections, prayer times, audio recitation, and daily reminders.

## Project Details
- **Slug:** `subhan-islamic-web`
- **Views:** 83
- **Tags:** Landing Page, Religious, Education, Technology, Clean, Gradient, Services, Quran, Hadith, Prayer Times
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

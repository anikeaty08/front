# Personal Portfolio Landing Page Template

A reusable personal portfolio landing page template for showcasing UI/UX skills, projects, education, and contact details with a bold modern brand feel.

## Project Details
- **Slug:** `subhan-personal-2`
- **Views:** 58
- **Tags:** Landing Page, Portfolio, Personal Branding, Technology, Education, Dark, Gradient, Clean, Minimal

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

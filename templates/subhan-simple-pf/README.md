# Developer Portfolio Website Template

A clean developer portfolio website template built with HTML and Tailwind, perfect for showcasing skills, education, projects, and a contact form.

## Project Details
- **Slug:** `subhan-simple-pf`
- **Views:** 41
- **Tags:** Landing Page, Portfolio, Art & Design, Clean, Minimal, Technology, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

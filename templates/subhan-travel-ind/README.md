# Travel Landing Page Template

A reusable travel landing page template for showcasing destinations, holidays, flights, and offers with immersive visuals and interactive discovery features.

## Project Details
- **Slug:** `subhan-travel-ind`
- **Views:** 51
- **Tags:** Landing Page, Travel, Services, Dark, Clean, Large Type, Animated, destination slider, tourism

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

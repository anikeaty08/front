# Wiki Encyclopedia Website Template

A reusable Wikipedia-style website template for building modern knowledge bases, encyclopedias, and community-driven content platforms with search and article views.

## Project Details
- **Slug:** `subhan-wikipeadia`
- **Views:** 65
- **Tags:** Documentation, Education, Technology, Landing Page, Clean, Dark, Minimal, Animated, Knowledge Base, Wiki
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

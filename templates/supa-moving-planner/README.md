# Moving Planner Template

A reusable template for organizing and tracking moving-related purchases by categories and status, with interactive drag-and-drop and budgeting features.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# SaaS AI Assistant Widget Template

A reusable SaaS AI assistant widget template for embedding chat, documentation search, and activity timelines into modern dashboards and web apps.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

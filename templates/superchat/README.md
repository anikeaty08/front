# FlowChat SaaS Landing Page Template

A dark, developer-focused FlowChat landing page template for AI-powered team chat platforms, featuring product overviews, API docs highlights, and conversion CTAs.

## Project Details
- **Slug:** `superchat`
- **Views:** 37
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Gradient, Large Type, Minimal, SaaS, Developer Tools
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

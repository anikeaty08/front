# Automotive Detailing Landing Page Template

A modern automotive services landing page template for window tint, paint protection, vinyl wraps, and mobile detailing businesses.

## Project Details
- **Slug:** `superior-customs`
- **Views:** 21
- **Tags:** Landing Page, Services, Brand, Minimal, Dark, Large Type, Clean, Automotive, Detailing, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

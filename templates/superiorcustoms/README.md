# Auto Detailing Service Landing Page Template

A sleek, dark automotive service landing page template for showcasing window tint, PPF, vinyl wraps, and mobile detailing with pricing, reviews, and contact.

## Project Details
- **Slug:** `superiorcustoms`
- **Views:** 42
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Large Type, Automotive, Detailing, Local Business, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Supermarket E-commerce Template

A reusable supermarket e-commerce template for online grocery delivery brands, featuring product browsing, flash sales, promos, reviews, and app downloads.

## Project Details
- **Slug:** `supermarket-mirziyo-ai`
- **Views:** 78
- **Tags:** E-commerce, Food, Landing Page, Clean, Minimal, Services, grocery delivery, supermarket, mobile app
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

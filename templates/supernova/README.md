# AI Knowledge Platform Landing Page Template

A dark, futuristic Nova-themed landing page template for AI-powered knowledge platforms to showcase features, infrastructure, and workflow benefits.

## Project Details
- **Slug:** `supernova`
- **Views:** 34
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Futuristic, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Golf Competition Landing Page Template

A reusable landing page template for promoting a golf putting game, venue partnerships, competitions, and corporate event bookings.

## Project Details
- **Slug:** `superputtaustralia`
- **Views:** 22
- **Tags:** Landing Page, Sports, Services, Brand, Clean, Minimal, Corporate events, Golf, Competition
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

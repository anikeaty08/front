# Super Putt Landing Page Template

A reusable landing page template for promoting a golf putting game, scorecard download, and practice format system that builds confidence under pressure.

## Project Details
- **Slug:** `superputtcanberra`
- **Views:** 56
- **Tags:** Landing Page, Sports, Services, Clean, Minimal, Dark, Brand, Golf
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

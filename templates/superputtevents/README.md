# Golf Landing Page Template

A reusable landing page template for promoting a golf putting game, club activation, or venue-ready sports concept with clear rules, benefits, and demo CTAs.

## Project Details
- **Slug:** `superputtevents`
- **Views:** 57
- **Tags:** Landing Page, Sports, Services, Brand, Clean, Minimal, Golf, Events, Venue Marketing
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

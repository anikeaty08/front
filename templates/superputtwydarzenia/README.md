# Golf Marketing Landing Page Template

A reusable landing page template for promoting golf formats, club activations, and putting experiences with clear rules, venue benefits, and demo booking CTA.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

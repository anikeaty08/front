# 3D Liquidity Reservoir Visualizer Template

A reusable 3D visualization template for showcasing a cylindrical containment or liquidity reservoir system with interactive camera, density, and playback controls.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# suryagentsparlour

A modern dark-theme barbershop landing page template for gents salons, featuring services showcase, location details, and an integrated appointment booking form.

## Project Details
- **Slug:** `suryagentsparlour`
- **Views:** 20
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Minimal, Large Type, Barbershop, Salon, Grooming
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

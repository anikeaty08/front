# Sushi Restaurant Ordering Landing Page Template

A modern sushi restaurant landing page template with online ordering, sticky menu, and cart for delivery or takeaway locations like SushiDeli Lelystad.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

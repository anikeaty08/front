# Sustainable Fashion E-commerce Landing Page Template

A reusable e-commerce template for sustainable fashion brands to showcase products, supply chain transparency, repair programs, and bold brand storytelling.

## Project Details
- **Slug:** `sustainabl-fashion-56`
- **Views:** 365
- **Tags:** E-commerce, Landing Page, Fashion, Brand, Environmental, Dark, Editorial, Sustainable, Minimal

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

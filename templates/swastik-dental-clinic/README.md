# Dental Clinic Landing Page Template

A reusable landing page template for dental clinics to showcase services, build trust with reviews, and drive appointment bookings via call or WhatsApp.

## Project Details
- **Slug:** `swastik-dental-clinic`
- **Views:** 32
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Brand, dental clinic, medical, appointments, reviews
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Sweepin

Reusable landing page template for premium, vetted home cleaning services, perfect for promoting managed cleaning networks and converting visitors to bookings.

## Project Details
- **Slug:** `sweepincleaningcompany`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Retail Dashboard Template

A reusable retail operations dashboard template for supermarkets and hypermarkets to track sales, inventory, staff, documents, and live activity.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

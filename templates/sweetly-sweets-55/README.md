# Sweetly Sweets Shop E-commerce Landing Page Template

A modern Sweetly sweets shop UI template with hero, product grid, cart, login, and checkout flows for boutique confectionery and bakery stores.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

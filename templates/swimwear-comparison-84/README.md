# Swimwear Comparison Landing Page Template

A clean comparison landing page template for showcasing and contrasting high-performance swimwear or sports gear models to help athletes choose the right product.

- **Slug:** `swimwear-comparison-84`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

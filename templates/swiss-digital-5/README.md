# Swiss Digital Studio Landing Page Template

A clean, Swiss-inspired digital studio landing page template for agencies to showcase services, case studies, and capture project enquiries.

## Project Details
- **Slug:** `swiss-digital-5`
- **Views:** 19
- **Tags:** Landing Page, Services, Technology, Brand, Minimal, Clean, Grid, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

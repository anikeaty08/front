# University Syllabus Portal Template

A reusable academic template for presenting university course syllabi with instructor profiles, schedules, competencies, evaluation tabs, and bibliography.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

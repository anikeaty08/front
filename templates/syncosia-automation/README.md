# Automation Consulting Landing Page Template

A reusable landing page template for automation consulting agencies to showcase services, process benefits, FAQs, and capture leads through a contact form.

## Project Details
- **Slug:** `syncosia-automation`
- **Views:** 33
- **Tags:** Landing Page, Services, Technology, Dark, Clean, Minimal, Animated, automation, consulting
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Synex Liquidity Market Landing Page Template

This template provides a sleek, dark-themed landing page for a liquidity engine platform, showcasing market stats, assets, and user actions, ideal for DeFi or crypto projects.

- **Slug:** `synex-lending-app`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

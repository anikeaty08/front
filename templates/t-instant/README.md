# Industrial Product E-commerce Template

A reusable e-commerce template for showcasing and selling industrial plumbing products with technical specs, trust badges, and product detail sections.

## Project Details
- **Slug:** `t-instant`
- **Views:** 32
- **Tags:** E-commerce, Technology, Landing Page, Clean, Minimal, Industrial, Product Showcase, Swiss Made, Catalog
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

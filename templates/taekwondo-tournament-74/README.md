# Taekwondo Tournament Landing Page Template

A modern Taekwondo tournament landing page template with hero, schedule, judges, and newsletter sections, ready to customize for martial arts events.

## Project Details
- **Slug:** `taekwondo-tournament-74`
- **Views:** 30
- **Tags:** Landing Page, Event, Sports, Clean, Minimal, Large Type, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

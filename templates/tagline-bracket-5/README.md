# Tagline Voting Bracket Template

A reusable web app template for collaborative tagline selection, letting two players create brackets, vote blindly, and choose the strongest option together.

## Project Details
- **Slug:** `tagline-bracket-5`
- **Views:** 52
- **Tags:** Landing Page, Technology, Clean, Minimal, Interactive, Voting, Collaboration, Bracket, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Tai Chi Studio Landing Page Template

A refined landing page template for Tai Chi, Qigong, and wellness studios to showcase classes, instructors, shop items, FAQs, and drive trial class signups.

## Project Details
- **Slug:** `tai-chi-studio-51`
- **Views:** 276
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

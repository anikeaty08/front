# Technical IT Services Landing Page Template

A modern dark-mode landing page template for technical service providers offering software development, AI solutions, and free IT assistance.

## Project Details
- **Slug:** `tailotechnicals`
- **Views:** 20
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Gradient, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Meditation App Template

A reusable mobile app template for sleep, meditation, and relaxation experiences, featuring immersive story cards, ambient categories, and a polished dark UI.

## Project Details
- **Slug:** `talha`
- **Views:** 61
- **Tags:** Health, Technology, Landing Page, Dark, Gradient, Clean, Minimal, Mobile App, Meditation, Wellness
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

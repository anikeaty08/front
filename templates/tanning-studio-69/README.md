# Tanning Studio SaaS Landing Page Template

A reusable landing page template for tanning studio management apps, designed to showcase scheduling, CRM, payments, and WhatsApp automation.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

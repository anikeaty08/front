# Academic Routine System Dashboard Template

A clean, drag-and-drop academic routine system template for managing class schedules, merged slots, and timetable swaps in a responsive dashboard layout.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

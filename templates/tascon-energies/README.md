# Solar panel installation 

A reusable landing page template for solar installation companies to showcase services, pricing packages, testimonials, FAQs, and quote requests.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

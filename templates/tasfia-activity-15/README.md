# Telehealth Video Call UI Template

A reusable telehealth video call interface template designed for rehab and medical apps, featuring secure Zoom-style controls and mobile-first layout.

## Project Details
- **Slug:** `tasfia-activity-15`
- **Views:** 12
- **Tags:** Health, Technology, Services, Dark, Minimal, Clean, Landing Page, Telehealth, Video Call, Mobile UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Task Management Dashboard UI Template

A modern TaskFlow-inspired task management dashboard UI template for product teams to visualize, track, and manage work in a Kanban-style web app.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Task Manager Web App Template

A reusable task manager template for creating a sleek, React-based to-do web app with filtering, editing, and local storage productivity features.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

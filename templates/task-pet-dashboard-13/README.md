# Task & Pet Dashboard UI Template

A reusable dark-mode mobile dashboard UI template for task management and pet routine tracking, featuring progress cards, stats, and switchable views.

## Project Details
- **Slug:** `task-pet-dashboard-13`
- **Views:** 20
- **Tags:** Landing Page, Technology, Brand, Dark, Clean, Colorful, Minimal, Dashboard, Mobile UI, Task Management
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

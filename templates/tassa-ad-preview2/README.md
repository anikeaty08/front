# Coffee Directory Landing Page Template

A modern template for a coffee shop directory and price index site like tassa.ad, featuring maps, charts, featured cafés, and owner CTAs.

## Project Details
- **Slug:** `tassa-ad-preview2`
- **Views:** 23
- **Tags:** Landing Page, Services, Travel, Brand, Clean, Colorful, Minimal, Large Type, Coffee Directory, Map
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Industrial Laundry Services Landing Page Template

A reusable landing page template for industrial laundry businesses serving hotels, rentals, restaurants, and spas with fast pickup and delivery.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

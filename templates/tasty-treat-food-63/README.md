# Food Delivery Mobile UI Template

A modern food delivery app UI template featuring onboarding, ordering, cart, checkout, and tracking flows for restaurant and delivery products.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

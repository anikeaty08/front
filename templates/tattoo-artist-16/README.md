# Tattoo Artist Landing Page Template

A sleek, dark-themed landing page template for fine line and ornamental tattoo studios to showcase portfolios, process, care guides, and drive bookings.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

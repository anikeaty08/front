# Taubner Auto Detailing

A reusable auto detailing landing page template for showcasing car care services, portfolio work, and generating service inquiries online.

## Project Details
- **Slug:** `taubnerautodetailing`
- **Views:** 20
- **Tags:** Landing Page, Services, Dark, Minimal, Clean, Portfolio, automotive, car detailing, local business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Taur Brothers

A clean, modern landing page template for artisanal lassi, juice, and beverage brands to showcase menus, story, and locations.

## Project Details
- **Slug:** `taurbrothers555`
- **Views:** 26
- **Tags:** Food, Landing Page, Brand, Clean, Minimal, Large Type, Menu, Beverage, Cafe
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

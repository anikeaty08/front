# Dental Clinic Landing Page Template

A modern, family-focused dental clinic landing page template for showcasing services, special offers, and appointment bookings for local practices.

## Project Details
- **Slug:** `tawadentistcode`
- **Views:** 41

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

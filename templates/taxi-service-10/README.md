# Taxi Service Landing Page Template

A modern taxi service landing page template for 24/7 local transport, airport transfers, and courier bookings, ready to customize for any taxi brand.

## Project Details
- **Slug:** `taxi-service-10`
- **Views:** 9
- **Tags:** Landing Page, Services, Travel, Brand, Dark, Clean, Minimal, Large Type, Taxi, Transportation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Taxi Booking Landing Page Template

Premium taxi booking landing page template for urban transport apps and services, designed to showcase fleets, mobile app features, and on-demand ride booking.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

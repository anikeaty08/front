# Taxi Service Landing Page Template

A modern, minimalist taxi service landing page template for independent drivers to showcase services, build trust, and capture ride booking requests.

## Project Details
- **Slug:** `taxi-service-86`
- **Views:** 73
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Taxi, Transportation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

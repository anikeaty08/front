# Taxi Service Landing Page Template

Modern one-page taxi service landing page template for local cab companies to showcase 24/7 service, app downloads, and easy phone or online booking.

## Project Details
- **Slug:** `taxi-services-42`
- **Views:** 13
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Gradient, Large Type, Taxi, Transportation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

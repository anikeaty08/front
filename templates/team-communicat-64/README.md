# Team Communication Mobile UI Template

A clean mobile app UI template for fast, group-based team communication and sports clubs that you can reuse and customize for your own project.

## Project Details
- **Slug:** `team-communicat-64`
- **Views:** 13
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Gradient, Mobile UI, Team Chat, Sports Groups, Product Design
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

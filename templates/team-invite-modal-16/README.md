# Team Member Invite Modal UI Template

A clean, reusable UI template for inviting team members, assigning roles, and generating shareable invite links inside modern web apps.

- **Views:** 16

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

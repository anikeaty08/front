# SKILLDOTE

A modern, colorful kids education landing page template for academies and training institutes to showcase courses, faculty, and drive admissions.

## Project Details
- **Slug:** `teamskilldotein`
- **Views:** 25
- **Tags:** Landing Page, Education, Brand, Clean, Colorful, Large Type, Gradient, Services, Technology

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

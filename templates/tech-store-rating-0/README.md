# StoreRank BD Tech Store Finder Template

Mobile-first StoreRank BD template for ranking and comparing trusted tech and electronics stores in Bangladesh, ready to reuse for similar review platforms.

## Project Details
- **Slug:** `tech-store-rating-0`
- **Views:** 26

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

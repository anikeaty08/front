# Technician Mobile App Template

A reusable mobile app template for service technician teams to manage login, job requests, navigation, invoicing, payments, earnings, and profiles.

## Project Details
- **Slug:** `technician-mobile-24`
- **Views:** 56
- **Tags:** Technology, Services, Landing Page, Clean, Minimal, Mobile App, Dashboard, Field Service, UI Kit
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

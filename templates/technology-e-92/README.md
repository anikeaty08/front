# Technology E-commerce Landing Page Template

A reusable dark e-commerce template for showcasing premium laptops, desktops, and accessories with product highlights, category sections, and strong CTAs.

## Project Details
- **Slug:** `technology-e-92`
- **Views:** 11
- **Tags:** E-commerce, Technology, Landing Page, Dark, Minimal, Animated, Futuristic, Clean
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Technology Services Business Landing Page Template

Modern dark-theme landing page template for technology, security, and automation service providers to showcase offerings, contracts, and WhatsApp contact in one place.

## Project Details
- **Slug:** `technology-services-36`
- **Views:** 29
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Technology Services Website Template

A reusable website template for software agencies and enterprise tech consultancies to showcase services, projects, stack, and capture leads.

## Project Details
- **Slug:** `technology-services-77`
- **Views:** 80
- **Tags:** Technology, Services, Landing Page, Clean, Gradient, Minimal, SaaS, Agency, Enterprise
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

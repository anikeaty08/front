# Children’s Loft Party Landing Page Template

A dark, modern landing page template for promoting kids’ party loft rentals with packages, services, reviews, FAQ, and lead forms ready to customize.

## Project Details
- **Slug:** `teddyboom-kids-20`
- **Views:** 17
- **Tags:** Landing Page, Services, Brand, Entertainment, Clean, Dark, Gradient, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

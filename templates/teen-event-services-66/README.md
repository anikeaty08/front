# Teen Party Events Landing Page Template

A reusable landing page template for teen event and party services, built to promote bookings with bold visuals, feature highlights, and strong CTAs.

## Project Details
- **Slug:** `teen-event-services-66`
- **Views:** 56
- **Tags:** Landing Page, Services, Entertainment, Dark, Gradient, Clean, Brand, Events, Party
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

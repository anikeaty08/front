# Telecom Internet & Telefonia Landing Page Template

Landing page template para empresas de telecom venderem planos de internet fibra e telefonia com foco em cobertura, planos, depoimentos e contato rápido.

## Project Details
- **Slug:** `telecom-internet-81`
- **Views:** 64
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Gradient, Clean, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

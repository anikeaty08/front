# Tennis Tournament Landing Page Template

A reusable landing page template for promoting and managing tennis tournaments with event details, categories, schedules, venue info, testimonials, and registration.

## Project Details
- **Slug:** `tennis-tournament-97`
- **Views:** 110
- **Tags:** Landing Page, Sports, Services, Dark, Clean, Minimal, Technology, Event Registration, Tennis
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

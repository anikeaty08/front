# Terminal Course Landing Page Template

A dark, terminal-first landing page template for promoting a developer-focused course or curriculum, ready to reuse for your own tech education offering.

## Project Details
- **Slug:** `terminal-course-95`
- **Views:** 47
- **Tags:** Landing Page, Education, Technology, Brand, Dark, Futuristic, Minimal, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

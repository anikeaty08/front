# Healthcare Practice Management Landing Page Template

A reusable landing page template for healthcare and acupuncture practice management software, built to showcase scheduling, charting, patient portal, and demo-driven conversion.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

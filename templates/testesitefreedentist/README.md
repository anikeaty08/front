# Luxury Dental Clinic Landing Page Template

A premium landing page template for boutique orthodontists and cosmetic dental studios to showcase luxury services, patient stories, and location details with a modern dark aesthetic.

## Project Details
- **Slug:** `testesitefreedentist`
- **Views:** 420
- **Tags:** Health, Services, Landing Page, Brand, Clean, Dark, Gradient, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

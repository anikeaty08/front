# Editorial Portfolio Website Template

A refined editorial-style portfolio template for photographers and art directors to showcase selected works, services, and contact details with minimalist elegance.

## Project Details

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

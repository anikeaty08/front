# Developer Portfolio Landing Page Template

A dark, mobile-style developer portfolio landing page template for systems engineers and backend developers to showcase projects, tech stack, and client testimonials.

## Project Details
- **Slug:** `testingsitepanda`
- **Views:** 8
- **Tags:** Landing Page, Portfolio, Technology, Brand, Dark, Gradient, Minimal, Large Type, Developer, Personal Website
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

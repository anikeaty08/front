# Wedding Invitation Landing Page Template

A romantic wedding invitation template for couples to share their date, story, venue, dress code, countdown, and guest notes in an elegant one-page design.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

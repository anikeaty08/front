# Sewing Factory Landing Page Template

A modern landing page template for sewing factories and apparel manufacturers to showcase services, production process, portfolio, and lead-generation contact forms.

## Project Details
- **Slug:** `textile-factory-27`
- **Views:** 18
- **Tags:** Landing Page, Business, Services, Brand, Fashion, Portfolio, Dark, Clean, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

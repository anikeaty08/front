# Textile Greige ERP Dashboard Template

A modern web dashboard template for managing textile greige purchasing, stock, batching, and job orders, ready to customize and connect to your own backend.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Thai Restaurant Menu Landing Page Template

A reusable restaurant menu template for Thai and Isan eateries, featuring categorized dishes, pricing, sticky filters, and a polished dark dining aesthetic.

## Project Details
- **Slug:** `thai-restaurant-28`
- **Views:** 93
- **Tags:** Food, Landing Page, Dark, Clean, Minimal, Restaurant, Menu, Thai cuisine, Pricing
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Thai Restaurant Menu Template

A clean, reusable template for Thai restaurant menus, designed to showcase categories, pricing, and signature dishes in a polished single-page layout.

## Project Details
- **Slug:** `thai-restaurant-95`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Thank You Page Collection Template

A versatile thank you page template collection for various scenarios including e-commerce, SaaS onboarding, event RSVPs, and support, designed for quick integration.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Cafe & Brunch Landing Page Template

A reusable landing page template for cafés and brunch spots to showcase menus, ambiance, location details, and event inquiries.

## Project Details
- **Slug:** `the-coffee-house`
- **Views:** 13
- **Tags:** Food, Landing Page, Services, Clean, Minimal, Brand, cafe, brunch, restaurant, hospitality
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

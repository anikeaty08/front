# Fitness Studio Landing Page Template

A conversion-focused template for fitness studios and personal trainers, featuring programs, trainers, testimonials, blog, and contact form sections.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# HVAC Services Landing Page Template

A reusable HVAC services landing page template for local, veteran-owned heating and air companies to promote services, guides, and maintenance plans.

## Project Details
- **Slug:** `the-general-havc`
- **Views:** 8
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Gradient, Large Type, Technology, Real Estate, Environmental
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Killerpod E-commerce Template

A reusable e-commerce template for performance apparel brands featuring bold product showcases, category splits, limited drops, and email capture.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

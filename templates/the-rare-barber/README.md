# Barbershop Landing Page Template

A premium barbershop website template for showcasing grooming services, gallery, testimonials, and easy appointment booking for modern barber brands.

## Project Details
- **Slug:** `the-rare-barber`
- **Views:** 1002

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

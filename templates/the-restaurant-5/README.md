# Food Bench - Fine Dining Restaurant Landing Page Template

A high-end, futuristic restaurant landing page template featuring 3D layered card compositions and a sophisticated dark UI for immersive culinary brands.

## Project Details
- **Slug:** `the-restaurant-5`
- **Views:** 39
- **Tags:** Food, Services, Landing Page, Dark, 3D, Minimal, Animated, Clean

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Event Management Landing Page Template

A cinematic, dark-themed landing page template for premium event management and production agencies to showcase services, portfolio, and capture project inquiries.

## Project Details
- **Slug:** `the-show-company`
- **Views:** 240
- **Tags:** Landing Page, Services, Brand, Entertainment, Portfolio, Dark, Large Type, Minimal, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

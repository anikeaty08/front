# Automation Community Landing Page Template

A reusable landing page template for no-code automation communities, courses, or memberships promoting systems, curriculum, results, and Discord-based onboarding.

## Project Details
- **Slug:** `the-system-dojo`
- **Views:** 41
- **Tags:** Landing Page, Technology, Education, Membership, Community, Dark, Minimal, Animated, Futuristic, Clean
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

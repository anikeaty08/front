# Barbershop Landing Page Template

A refined barbershop landing page template for promoting grooming services, showcasing pricing and atmosphere, and driving online appointment bookings.

## Project Details
- **Slug:** `the-zen-braber`
- **Views:** 51
- **Tags:** Landing Page, Services, Brand, Dark, Minimal, Clean, Barbershop, Grooming, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

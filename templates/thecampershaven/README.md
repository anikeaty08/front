# Outdoor E-commerce Storefront Template

A modern Camper’s Haven-inspired e-commerce template for outdoor and camping gear brands to showcase products and drive conversions.

## Project Details
- **Slug:** `thecampershaven`
- **Views:** 35
- **Tags:** E-commerce, Landing Page, Brand, Clean, Minimal, Large Type, Gradient, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

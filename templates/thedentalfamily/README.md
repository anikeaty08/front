# Dental Clinic Landing Page Template

Modern dental clinic landing page template for family, pediatric, and orthodontic practices to showcase services, locations, team, and online appointment booking.

## Project Details
- **Slug:** `thedentalfamily`
- **Views:** 25
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Gradient, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# IV Therapy Clinic Landing Page Template

A modern IV therapy clinic landing page template for wellness studios to showcase drips, health support, memberships, and bookings with a spa-like brand feel.

## Project Details
- **Slug:** `thedripbarcranford`
- **Views:** 60
- **Tags:** Health, Services, Landing Page, Brand, Clean, Gradient, Minimal, Large Type, Wellness, IV Therapy
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

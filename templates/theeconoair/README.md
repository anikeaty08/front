# Econo Air

A reusable HVAC services landing page template for heating and cooling companies to showcase services, build trust, and capture quote requests.

## Project Details
- **Slug:** `theeconoair`
- **Views:** 30
- **Tags:** Landing Page, Services, Business, Clean, Professional, Local Services, HVAC, Home Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

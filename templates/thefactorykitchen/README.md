# Italian Restaurant Landing Page Template

A dark, upscale restaurant landing page template for showcasing menus, atmosphere, and online reservations for modern Italian or bistro-style dining.

## Project Details
- **Slug:** `thefactorykitchen`
- **Views:** 198
- **Tags:** Landing Page, Food, Brand, Dark, Clean, Minimal, Large Type, Restaurant, Reservations, Menu
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

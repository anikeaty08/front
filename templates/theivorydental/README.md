# The Ivory Dental

A clean, modern dental practice landing page template for clinics to showcase services, testimonials, and contact details while driving appointment bookings.

## Project Details
- **Slug:** `theivorydental`
- **Views:** 13
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Gradient, Dental, Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Dental Practice Landing Page Template

A modern dental practice landing page template for showcasing services, team, reviews, and appointment requests for local family and cosmetic dentists.

## Project Details
- **Slug:** `themontclairdentist`
- **Views:** 34
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, dentist template, dental clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mental Health Training Landing Page Template

A reusable landing page template for mental health training academies, therapists, and education programs promoting courses, events, supervision, and contact.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

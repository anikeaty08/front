# Healthy Café Landing Page Template

A modern, brandable landing page template for healthy cafés or restaurants to showcase menus, ambiance, reviews, and location in a clean, welcoming layout.

## Project Details
- **Slug:** `thetastefall-resturant`
- **Views:** 81
- **Tags:** Food, Landing Page, Brand, Clean, Colorful, Gradient, Large Type, Minimal, Café, Restaurant
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

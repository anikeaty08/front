# Dental Clinic Landing Page Template

A refined dental clinic landing page template for private practices, featuring hero enquiry form, services, reviews, FAQs, contact details, and chatbot.

## Project Details
- **Slug:** `theterracedental`
- **Views:** 27
- **Tags:** Landing Page, Services, Health, Brand, Clean, Minimal, Large Type, Technology, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

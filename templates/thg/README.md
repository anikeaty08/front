# Project Settings UI Card Template

A reusable project settings UI card template for web apps, featuring workspace details, environment select, and toggles for fast, modern dashboards.

## Project Details
- **Slug:** `thg`
- **Views:** 23
- **Tags:** Landing Page, Technology, Brand, Clean, Minimal, Dashboard, Settings, UI, Tailwind CSS, Web App
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# TicherChat Service Landing Page Template

Landing page template for TicherChat, a practical English chat assistant service for hospitality staff, ready to customize and reuse for similar products.

## Project Details
- **Slug:** `ticherchat-service-9`
- **Views:** 11
- **Tags:** Landing Page, Services, Education, Brand, Clean, Dark, Gradient, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

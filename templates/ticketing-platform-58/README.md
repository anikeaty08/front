# Ticketing Platform Landing Page Template

A reusable landing page template for modern ticketing platforms, showcasing event sales, developer APIs, payments, analytics, and organizer-focused conversion flows.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# TikBoost Social Services Landing Page Template

Modern dark-mode landing page template for TikTok growth and coin-selling services, featuring pricing grids, secure checkout, and WhatsApp order flow.

- **Slug:** `tikboostsocial-pk`
- **Views:** 74

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

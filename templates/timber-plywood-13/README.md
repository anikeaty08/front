# Timber & Surfaces Business Landing Page Template

A modern dark-theme landing page template for timber, plywood, and surfaces suppliers to showcase products, heritage, and logistics with bold, premium styling.

## Project Details
- **Slug:** `timber-plywood-13`
- **Views:** 12
- **Tags:** Landing Page, Business, Services, Brand, Dark, Clean, Gradient, Large Type, Grid, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

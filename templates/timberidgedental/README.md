# timber ridge dental

A modern dental clinic landing page template designed for local practices to showcase services, team, and contact details, optimized for patient appointments.

## Project Details
- **Slug:** `timberidgedental`
- **Views:** 20
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, Dental, Medical
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

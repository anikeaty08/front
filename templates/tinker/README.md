# AI Chatbot SaaS Landing Page Template

A modern, dark-mode template for promoting an AI assistant/chatbot SaaS like Tinker.AI, ready to customize as your own intelligent bot platform landing page.

- **Views:** 43

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Sports Injury Clinic Landing Page Template

A modern, conversion-focused landing page template for sports injury, physiotherapy, and performance clinics to showcase services and drive bookings.

## Project Details
- **Slug:** `tmaclife-free-design`
- **Views:** 21
- **Tags:** Health, Services, Landing Page, Brand, Clean, Gradient, Large Type, Minimal, Clinic, Physiotherapy
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

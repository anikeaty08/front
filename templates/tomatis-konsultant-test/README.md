# Health Therapy Landing Page Template

A reusable landing page template for hearing therapy, wellness, and specialist consultation services targeting children, adults, and families.

## Project Details
- **Slug:** `tomatis-konsultant-test`
- **Views:** 60
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Brand, wellness, therapy, consultant
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

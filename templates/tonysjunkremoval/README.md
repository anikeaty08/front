# Landscaping Services Landing Page Template

A clean, modern landscaping services landing page template for local lawn care and outdoor service businesses to showcase offerings and capture quote requests.

## Project Details
- **Slug:** `tonysjunkremoval`
- **Views:** 9
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Brand, Large Type, Technology

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

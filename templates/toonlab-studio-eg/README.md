# Animation Studio Landing Page Template

A modern ToonLab-inspired landing page template for professional animation studios to showcase services, portfolio, and capture WhatsApp leads.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

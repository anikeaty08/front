# Dental Clinic Landing Page Template

A modern Dental Clinic landing page template for dentists and practices to showcase services, build trust, and drive appointment calls and bookings.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

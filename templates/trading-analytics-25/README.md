# Trading Analytics Dashboard Landing Page Template

A dark, data-rich trading journal and analytics dashboard landing page template designed for trading platforms to showcase AI insights and performance tracking.

## Project Details
- **Slug:** `trading-analytics-25`
- **Views:** 45
- **Tags:** Landing Page, Technology, Brand, Dark, Gradient, Dashboard, Trading, SaaS

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

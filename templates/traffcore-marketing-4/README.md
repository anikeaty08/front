# TRAFFCORE Marketing Landing Page Template

This reusable template is designed for marketing teams and agencies to showcase an arbitration team with features, founders, and partner highlights.

## Project Details
- **Slug:** `traffcore-marketing-4`
- **Views:** 30
- **Tags:** Landing Page, Hero, Features, Stats, Founders, Partners, CTA, Dark Theme, Animation

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

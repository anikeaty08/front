# Trail Issue Report Form Template

A clean, minimalist trail issue report form template for parks, trails, and outdoor organizations to collect detailed maintenance and safety reports.

## Project Details
- **Slug:** `trail-issue-report`
- **Views:** 22

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

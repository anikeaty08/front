# Travel Adventure Landing Page Template

A reusable travel adventure template for trekking, expedition, and tour operators to showcase destinations, guides, testimonials, blog content, and booking CTAs.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

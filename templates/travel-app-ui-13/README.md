# Travel App UI Template

A reusable mobile travel app template for showcasing destinations, planning trips, managing wishlists, and handling bookings in a clean interface.

## Project Details
- **Slug:** `travel-app-ui-13`
- **Views:** 70
- **Tags:** Travel, Landing Page, Clean, Minimal, Mobile App, UI Kit, Booking, Itinerary, Wishlist
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

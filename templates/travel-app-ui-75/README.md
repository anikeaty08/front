# Travel App UI Template

A reusable mobile app template for showcasing city tours, landmarks, and bookable travel experiences with polished listing and detail screens.

## Project Details
- **Slug:** `travel-app-ui-75`
- **Views:** 45
- **Tags:** Travel, Landing Page, Clean, Minimal, Mobile App, UI Kit, Tourism, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

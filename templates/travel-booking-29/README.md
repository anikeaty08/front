# Travel Booking Landing Page Template

A reusable travel booking landing page template for hotels, resorts, and stay platforms to promote destinations, drive bookings, and capture leads.

## Project Details
- **Slug:** `travel-booking-29`
- **Views:** 427
- **Tags:** Landing Page, Travel, Services, Dark, Minimal, Clean, video background, booking, hospitality

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

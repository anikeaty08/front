# Travel Booking Dashboard UI Template

Modern travel booking dashboard UI template for flights, stays, and cars with search, upcoming trips, wallet, and trending destinations layouts.

- **Slug:** `travel-booking-49`
- **Views:** 31

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

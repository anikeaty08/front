# Travel Fleet Pricing Landing Page Template

A reusable travel booking template for tours and car rental businesses to showcase fleet options, per-kilometer pricing, and booking calls to action.

## Project Details
- **Slug:** `travel-booking-64`
- **Views:** 16
- **Tags:** Travel, Services, Landing Page, Clean, Minimal, Grid, pricing, car rental, fleet
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

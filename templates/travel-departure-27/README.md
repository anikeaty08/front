# Nature Travel Departure Calendar Dashboard Template

A reusable dashboard template for nature and adventure travel operators to schedule, visualize, and manage group departures across 18–24 months.

## Project Details
- **Slug:** `travel-departure-27`
- **Views:** 43
- **Tags:** Travel, Services, Brand, Clean, Minimal, Grid, Large Type, Dashboard, Calendar, Tour Operator
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

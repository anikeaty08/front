# Travel Discovery Landing Page Template

A reusable travel landing page template for showcasing hidden stays, farms, and local experiences with interactive maps, virtual tours, and direct booking inquiries.

## Project Details
- **Slug:** `travel-discovery-64`
- **Views:** 48
- **Tags:** Landing Page, Travel, Services, Clean, Minimal, 3D, Interactive Map, Virtual Tours, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

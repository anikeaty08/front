# Travel eSIM Landing Page Template

A modern TravelSim-style landing page template for selling global eSIM data plans, showcasing destinations, tariffs, and instant setup for international travelers.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Excursiones Travel Landing Page & Admin Dashboard Template

Template de landing page y dashboard admin para agencias de excursiones programadas que necesitan mostrar salidas, gestionar reservas y promocionar membresías.

## Project Details
- **Slug:** `travel-excursions-39`
- **Views:** 20
- **Tags:** Travel, Landing Page, Services, Clean, Gradient, Large Type, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

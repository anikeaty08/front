# Travel Assets UI Landing Page Template

A dark, modern Travel Assets UI landing page template showcasing premium discounts, packages, and policies for travel agencies and frequent travelers.

## Project Details
- **Slug:** `travel-intelligen-7`
- **Views:** 4
- **Tags:** Travel, Landing Page, Brand, Dark, Gradient, Minimal, Technology

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

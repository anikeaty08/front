# Travel Landing Page Template

A reusable travel landing page template for promoting limited-time Cancún vacation packages with urgent phone-first booking CTAs.

## Project Details
- **Slug:** `travel-landing-18`
- **Views:** 22
- **Tags:** Landing Page, Travel, Services, Clean, Gradient, Colorful, Mobile, Lead Generation, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

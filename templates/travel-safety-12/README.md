# Travel Safety SaaS Landing Page Template

Modern landing page template for a travel safety SaaS that ranks neighborhoods by safety and comfort so travelers can choose secure areas before booking.

## Project Details
- **Slug:** `travel-safety-12`
- **Views:** 17
- **Tags:** Landing Page, Travel, Technology, Brand, Clean, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

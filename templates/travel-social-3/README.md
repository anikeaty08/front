# Travel Social Feed Landing Page Template

A dark, modern travel discovery social feed template for showcasing hidden gems, trending locations, and explorer profiles—ready to customize for your product.

## Project Details
- **Slug:** `travel-social-3`
- **Views:** 20
- **Tags:** Landing Page, Travel, Brand, Clean, Dark, Gradient, Minimal, Large Type, Social feed, Community

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

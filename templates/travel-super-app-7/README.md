# ProximaGo Demo

A reusable mobile app template for building a travel booking platform with destination discovery, hotel listings, transport booking, guide profiles, payments, and chat.

## Project Details
- **Slug:** `travel-super-app-7`
- **Views:** 46
- **Tags:** Travel, Technology, Landing Page, Clean, Minimal, mobile app, booking, tourism, UI kit
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

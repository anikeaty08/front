# Travel Tips Finder Website Template

A modern Vantage-inspired travel guide template for building editorial travel sites with destination guides, gear reviews, and newsletter-driven flight deal content.

## Project Details
- **Slug:** `travel-tips-finder`
- **Views:** 14
- **Tags:** Travel, Landing Page, Blog, Brand, Clean, Minimal, Large Type, Gradient, Editorial, Affiliate

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

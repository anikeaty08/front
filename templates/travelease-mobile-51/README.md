# Travel Planning App UI Template

A modern mobile app UI template for TravelEase-style trip planning, covering search, itineraries, place details, and share flows for travel apps.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

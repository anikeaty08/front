# Finance Analytics Dashboard Template

A reusable admin dashboard template for tracking treasury, revenue, expenses, and profit margins across orders and operations.

## Project Details
- **Slug:** `treasury-dashboard-60`
- **Views:** 59
- **Tags:** Technology, Services, Dashboard, Clean, Minimal, Analytics, Admin, Finance, Data Visualization
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

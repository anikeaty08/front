# Tree Removal Service Landing Page Template

A clean, professional landing page template for local tree removal and stump grinding services, optimized for quotes, calls, and emergency service leads.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Tree Service Landing Page Template

A reusable landing page template for local tree services and landscaping businesses, optimized for high-converting quotes and emergency service calls.

## Project Details
- **Slug:** `tree-service-89`
- **Views:** 65
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Gradient, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

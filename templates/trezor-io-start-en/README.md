# Crypto Security Article Landing Page Template

A clean, modern article-style landing page template for crypto hardware wallet brands to educate users on self-custody and promote secure products.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

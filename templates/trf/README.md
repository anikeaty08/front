# Church Location Landing Page Template

A modern church location landing page template for local fellowships to showcase services, pastors, directions, and contact details with a warm, welcoming design.

## Project Details
- **Slug:** `trf`
- **Views:** 30
- **Tags:** Landing Page, Religious, Clean, Minimal, Brand, Large Type, Church, Location, Fellowship, Contact Form
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

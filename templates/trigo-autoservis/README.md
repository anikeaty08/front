# Auto Service Landing Page Template

Modern one-page autoservis website template for local car repair shops, showcasing services, financing, and contact details to quickly launch your garage online.

## Project Details
- **Slug:** `trigo-autoservis`
- **Views:** 15
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Automotive, Car Repair, Local Business, Czech
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

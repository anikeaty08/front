# Dental Clinic Landing Page Template

A clean, modern dental clinic landing page template for showcasing treatments, facilities, hours, and contact details for local practices and non‑profit clinics.

## Project Details
- **Slug:** `trinitydentalclinic`
- **Views:** 35
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Technology, Medical, Clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

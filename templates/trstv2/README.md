# Trust Infrastructure Landing Page Template

A reusable landing page template for showcasing a digital trust platform, domain acquisition opportunity, or partnership offer for security and identity brands.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AI Consultancy Landing Page Template

A reusable landing page template for AI consulting and professional services firms to showcase offerings, process, and capture consultation leads.

## Project Details
- **Slug:** `trustlight-ai-consulting`
- **Views:** 99
- **Tags:** Landing Page, Services, Technology, Business, Minimal, Clean, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

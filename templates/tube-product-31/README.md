# Cosmetic Product Card UI Template

A reusable cosmetic product card UI template featuring 3D tube illustrations, pricing, quantity controls, and Add to Cart buttons for modern e-commerce layouts.

## Project Details
- **Slug:** `tube-product-31`
- **Views:** 8
- **Tags:** E-commerce, Landing Page, Brand, 3D, Colorful, Minimal, Grid, Large Type, Product Cards, UI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

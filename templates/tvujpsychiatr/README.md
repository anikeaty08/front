# Psychiatry Clinic Landing Page Template

A clean healthcare template for psychiatry clinics and mental health practices to present services, hours, FAQs, articles, reviews, and contact details.

## Project Details
- **Slug:** `tvujpsychiatr`
- **Views:** 24
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Blog, medical, psychiatry, mental health
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

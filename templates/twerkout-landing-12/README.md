# TwerkOut Dance Studio Landing Page Template

A reusable landing page template for dance studios offering twerk classes, designed to showcase programs, schedules, and sign-up forms.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

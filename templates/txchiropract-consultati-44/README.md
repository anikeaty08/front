# Chiropractic Consultation Landing Page Template

A reusable landing page template for chiropractic and functional health clinics to promote pain relief services, build trust, and drive free consultation bookings.

## Project Details
- **Slug:** `txchiropract-consultati-44`
- **Views:** 25
- **Tags:** Health, Landing Page, Services, Clean, Dark, Minimal, Testimonials, Video, Medical

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

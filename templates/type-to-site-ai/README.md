# AI Website Builder Landing Page Template

A reusable landing page template for promoting an AI website builder that generates, edits, and publishes sites from simple text prompts.

## Project Details
- **Slug:** `type-to-site-ai`
- **Views:** 85
- **Tags:** Technology, Landing Page, SaaS, AI, Dark, Minimal, Clean, Gradient, Startup
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

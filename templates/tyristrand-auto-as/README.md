# Tyristrand

A modern landing page template for local car workshops and mechanics to showcase services, certifications, contact details, and online booking in a clean layout.

## Project Details
- **Slug:** `tyristrand-auto-as`
- **Views:** 168
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Technology, Auto Workshop, Local Business, Mechanics
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

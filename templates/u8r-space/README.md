# Multi-Chain Crypto Wallet App Template

A dark, clean multi-chain crypto wallet UI template for Ethereum and Solana, with connect, send, receive, and activity views ready to customize.

## Project Details
- **Slug:** `u8r-space`
- **Views:** 20
- **Tags:** Landing Page, Technology, Brand, Dark, Clean, Minimal, Gradient, Wallet, Crypto, Web3
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

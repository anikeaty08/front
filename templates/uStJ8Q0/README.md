# Interactive 3D Drum Kit UI

Renders a 3D drum kit with clickable drums that play sounds and animate using Three.js and Tailwind CSS.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

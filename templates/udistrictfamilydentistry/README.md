# Dental Clinic Landing Page Template

A modern dental practice landing page template for family and cosmetic dentists to showcase services, team, hours, and online appointment requests.

## Project Details
- **Slug:** `udistrictfamilydentistry`
- **Views:** 29
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Technology, dentist, dental clinic
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

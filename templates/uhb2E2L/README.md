# Mobile Music Player Interface

Responsive mobile music player UI with playback controls, progress and volume bars, album art, and audio settings using Tailwind CSS.

## Project Details
- **Slug:** `uhb2E2L`
- **Views:** 131
- **Tags:** Music Player, Tailwind CSS, Audio Controls, Responsive Design, UI Components, Progress Bar, Equalizer
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

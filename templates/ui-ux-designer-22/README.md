# UI/UX Designer Portfolio Template

A modern dark UI/UX designer portfolio template to showcase case studies, services, and contact details for freelancers and creative professionals.

## Project Details
- **Slug:** `ui-ux-designer-22`
- **Views:** 17
- **Tags:** Landing Page, Portfolio, Art & Design, Clean, Dark, Gradient, Large Type, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# UI/UX Designer Portfolio Website Template

A modern glassmorphism UI/UX designer portfolio website template showcasing work, services, skills, testimonials, and contact for creative professionals.

## Project Details
- **Slug:** `ui-ux-designer-93`
- **Views:** 28
- **Tags:** Landing Page, Portfolio, Art & Design, Clean, Minimal, Gradient, Large Type, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

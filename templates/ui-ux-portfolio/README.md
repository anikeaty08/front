# UI/UX Designer Portfolio Template

A reusable UI/UX designer portfolio template showcasing skills, work, and contact options for freelance and professional projects.

## Project Details
- **Slug:** `ui-ux-portfolio`
- **Views:** 1230
- **Tags:** Landing Page, Portfolio, UI/UX Design, Skills, Work Showcase, Contact, Testimonials, Core Values, Call to Action
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

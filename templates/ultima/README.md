# ULTIMA

A dark, high-impact landing page template for promoting Muay Thai or fitness immersion retreats, ready to adapt for your own training experience.

## Project Details

- **Views:** 166

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Umzugsnetzwerk Partner Landing Page Template

Moderne Landing Page Template für Umzugsnetzwerke, um neue Partnerunternehmen zu gewinnen und deren Registrierung mit klaren Benefits und Formular zu optimieren.

## Project Details
- **Slug:** `umzugspart-landing-23`
- **Views:** 12
- **Tags:** Landing Page, Services, Business, Clean, Minimal, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

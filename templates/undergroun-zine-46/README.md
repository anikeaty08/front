# Underground Zine Event Landing Page Template

A brutal, underground-culture landing page template for zine bars, music venues, and indie event spaces to showcase gigs, merch, and location.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

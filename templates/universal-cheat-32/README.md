# Author & Book E-commerce Landing Page Template

A clean, high-conversion landing page template designed for authors to showcase and sell books with wholesale and pre-order capabilities.

## Project Details
- **Slug:** `universal-cheat-32`
- **Views:** 71
- **Tags:** Landing Page, Education, Clean, Minimal, Dark, Services, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

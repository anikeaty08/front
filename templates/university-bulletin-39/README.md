# University Bulletin Landing Page Template

A reusable bulletin-style landing page template for universities and campuses to share weekly events, announcements, updates, and community information.

## Project Details
- **Slug:** `university-bulletin-39`
- **Views:** 45
- **Tags:** Education, Landing Page, Clean, Minimal, Gradient, Newsletter, Events, Campus, Bulletin
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

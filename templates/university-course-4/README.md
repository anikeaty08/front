# University Course Detail Dashboard Template

A reusable university course detail dashboard template for showcasing class info, grade distributions, prerequisites, and sessions in a modern dark UI.

## Project Details
- **Slug:** `university-course-4`
- **Views:** 60
- **Tags:** Education, Landing Page, Technology, Clean, Dark, Minimal, Dashboard, University, Course Catalog, Student Portal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

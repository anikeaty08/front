# University International Cooperation Division Website Template

A reusable website template for university international cooperation divisions to showcase news, programs, and services for global partnerships and mobility.

## Project Details
- **Slug:** `university-internatio-92`
- **Views:** 24
- **Tags:** Education, Landing Page, Clean, Minimal, Brand, Large Type, Grid, University, International Cooperation, Study Abroad

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

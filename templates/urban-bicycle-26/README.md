# Bike Catalog Landing Page Template

A sleek e-commerce template for showcasing and selling urban bicycles with product cards, pricing, and WhatsApp order CTAs.

## Project Details
- **Slug:** `urban-bicycle-26`
- **Views:** 11
- **Tags:** E-commerce, Landing Page, Technology, Dark, Minimal, Clean, Catalog, Bikes, WhatsApp
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

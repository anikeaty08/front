# Urban Nail & Beauty Landing Page Template

A reusable landing page template designed for nail salons and beauty studios to showcase services, team, testimonials, and online booking.

## Project Details
- **Slug:** `urban-nail-beauty`
- **Views:** 1652
- **Tags:** Landing Page, Nail Salon, Beauty, Services, Team, Testimonials, Pricing, FAQ, Contact, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

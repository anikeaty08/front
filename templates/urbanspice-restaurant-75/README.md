# UrbanSpice Restaurant Landing Page Template

A refined restaurant landing page template for modern Indian dining brands, showcasing story, menu, gallery, and reservations in an elegant dark layout.

## Project Details
- **Slug:** `urbanspice-restaurant-75`
- **Views:** 14
- **Tags:** Landing Page, Food, Business, Brand, Dark, Clean, Minimal, Large Type, Restaurant, Indian Cuisine
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

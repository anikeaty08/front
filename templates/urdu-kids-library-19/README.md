# Urdu Kids Stories Landing Page Template

A colorful Urdu kids stories landing page template for libraries and educators to showcase children’s tales, audio stories, and weekly story updates.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Used Car Dealership Landing Page Template

A reusable landing page template for premium used car dealerships to showcase inventory, financing options, reviews, and showroom contact details.

## Project Details
- **Slug:** `used-car-dealership-80`
- **Views:** 151
- **Tags:** Landing Page, Automotive, Services, Dark, 3D, Gradient, Clean, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

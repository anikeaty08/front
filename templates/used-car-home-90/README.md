# Used Car Dealership Landing Page Template

A reusable landing page template for used car dealers to showcase inventory, build trust, and drive car buying, selling, and valuation inquiries.

## Project Details
- **Slug:** `used-car-home-90`
- **Views:** 20
- **Tags:** Landing Page, Services, Clean, Minimal, Brand, Automotive, Used Cars, Dealership, Inventory
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

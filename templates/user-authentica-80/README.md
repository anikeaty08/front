# Authentication Dashboard Template

A reusable admin dashboard template for managing user authentication, sessions, API keys, logs, and signups with a clean SaaS-style interface.

## Project Details
- **Slug:** `user-authentica-80`
- **Views:** 23
- **Tags:** Technology, Services, Dashboard, Admin, Clean, Minimal, Landing Page, SaaS, Authentication
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

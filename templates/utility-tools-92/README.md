# Developer Utility Tools Web App Template

A clean, privacy-first web app template showcasing IP lookup and JPG-to-PNG conversion tools, ready to adapt into your own developer utilities suite.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

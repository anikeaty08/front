# UV Index Card UI Template

A reusable UV Index card UI template for weather, health, or climate apps, featuring bold typography and a colorful gradient safety indicator.

## Project Details
- **Slug:** `uv-index-card-36`
- **Views:** 12
- **Tags:** Health, Technology, Landing Page, Brand, Colorful, Dark, Gradient, Minimal, Large Type, Weather
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Wind Information Dashboard

Displays current, hourly, and 7-day wind data with direction, speed, gusts, and feels like temperature using Tailwind CSS and icons.

## Project Details
- **Slug:** `uv5nzS`
- **Views:** 25
- **Tags:** Wind, Weather UI, Tailwind CSS, SVG Compass, Responsive Design, Data Visualization
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

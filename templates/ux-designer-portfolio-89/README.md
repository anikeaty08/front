# Designer Portfolio Landing Page Template

A clean, modern portfolio landing page template for UI/UX and web designers to showcase services, case studies, and client testimonials.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

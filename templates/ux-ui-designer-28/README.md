# UX/UI Designer Portfolio Template

A modern UX/UI designer portfolio template showcasing skills, CV, case studies and contact details, ready to customize for creative professionals.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Interactive Valentine Proposal Page Template

A romantic, interactive Valentine proposal page template featuring playful YES/NO buttons, heart confetti, and a photo memory section you can personalize.

## Project Details
- **Slug:** `valentine-proposal-55`
- **Views:** 6
- **Tags:** Wedding, Social, Entertainment, Colorful, Gradient, Large Type, Minimal, Landing Page, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

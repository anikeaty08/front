# Valentine Proposal Landing Page Template

A playful Valentine proposal landing page template for creating interactive, romantic invites with animations, secret notes, and a fun yes/no interaction.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

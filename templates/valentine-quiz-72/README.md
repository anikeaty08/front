# Valentine Quiz Landing Page Template

A romantic Valentine quiz landing page template to let users create, take, and share playful “How Well Do You Know Me?” relationship quizzes.

## Project Details
- **Slug:** `valentine-quiz-72`
- **Views:** 9
- **Tags:** Landing Page, Entertainment, Social, Brand, Colorful, Gradient, Large Type, Minimal, Valentine, Quiz
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

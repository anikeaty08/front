# Hair Salon Landing Page Template

A clean, modern landing page template for local hair salons to showcase stylists, contact details, and location information.

## Project Details
- **Slug:** `valticka-kadernictvi`
- **Views:** 14
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Local Business, Hair Salon, Beauty
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

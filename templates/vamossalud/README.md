# Healthcare Financing Landing Page Template

A conversion-focused landing page template for healthcare financing programs helping Mexican nurses secure education funding and jobs in the U.S.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mobile Pet Grooming Landing Page Template

A premium, modern landing page template for mobile dog grooming services featuring a booking flow, service packages, and comprehensive business sections.

## Project Details
- **Slug:** `vanity-mobile-28`
- **Views:** 18
- **Tags:** Services, Health, Clean, Colorful, Animated, Landing Page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

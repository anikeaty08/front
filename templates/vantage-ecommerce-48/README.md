# Vantage Ecommerce Collections Landing Page Template

A modern ecommerce landing page template for Shopify-powered stores, featuring animated hero, product grids, collections, blog, and testimonials.

## Project Details
- **Slug:** `vantage-ecommerce-48`
- **Views:** 21
- **Tags:** E-commerce, Landing Page, Brand, Clean, Gradient, Minimal, Large Type, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

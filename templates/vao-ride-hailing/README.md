# Ride-Hailing App Landing Page Template

A polished ride-hailing app landing page template for promoting urban mobility apps with safety, features, and download CTAs ready to customize.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Interactive Desktop Environment UI

Creates a desktop-style interface with draggable app windows for calculator, notes, and photos using Tailwind CSS and Font Awesome icons.

## Project Details
- **Slug:** `vcC1XqvI`
- **Views:** 112
- **Tags:** HTML, CSS, Tailwind, JavaScript, UI, Desktop UI, Web Apps
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

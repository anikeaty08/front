# TEST - V-Day -Page Template

A romantic Valentine’s Day landing page template for sharing your love story, timeline, photos, playlist, and interactive love calculator as a personalized web experience.

## Project Details
- **Slug:** `vday`
- **Views:** 15
- **Tags:** Landing Page, Wedding, Social, Entertainment, Colorful, Gradient, Animated, Love Story, Valentines, Playlist
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

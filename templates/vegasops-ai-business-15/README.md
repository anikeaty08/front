# Restaurant AI Voice Landing Page Template

A dark, high-converting landing page template for restaurant-focused AI voice assistants, showcasing features, pricing, FAQs, and demos to sell your solution.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# VeggainzIndia Coming Soon Landing Page Template

A dark, plant-powered coming soon landing page template for high-protein vegetarian meal brands to capture pre-orders and launch interest.

## Project Details
- **Slug:** `veggainzindia-meals`
- **Views:** 13
- **Tags:** Landing Page, Food, Brand, Dark, Gradient, Clean, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

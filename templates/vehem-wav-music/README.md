# VEHEM Band Mobile Landing Page Template

A dark, music-focused landing page template for bands or artists, optimized for mobile with hero slider, member profiles, and booking contact form.

## Project Details
- **Slug:** `vehem-wav-music`
- **Views:** 26
- **Tags:** Landing Page, Entertainment, Art & Design, Dark, Large Type, Brand, Portfolio, Music, Band, Mobile
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

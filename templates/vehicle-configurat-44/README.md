# Vehicle Configurator UI Template

A dark, futuristic vehicle configurator UI template for showcasing and customizing cars, bikes, trucks, and aircraft with 3D-style previews and detailed options.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

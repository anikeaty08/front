# Vein Clinic Landing Page Template

A reusable medical landing page template for vein clinics and vascular practices to showcase treatments, build trust, and drive consultation bookings.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

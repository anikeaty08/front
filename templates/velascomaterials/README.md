# Velasco Materials

A reusable landing page template for landscape material supply and logistics brands, featuring services, testimonials, and quote-focused CTAs.

## Project Details
- **Slug:** `velascomaterials`
- **Views:** 37

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

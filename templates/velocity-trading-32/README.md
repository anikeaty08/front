# Service Partner Landing Page Template

A dark, modern landing page template for service and repair partners to showcase SRsolutions-style offerings and capture repair inquiries.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

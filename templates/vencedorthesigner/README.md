# Product Designer Portfolio Website Template

A cinematic, animated portfolio website template for product designers to showcase work, process, and services with a bold dark aesthetic.

## Project Details
- **Slug:** `vencedorthesigner`
- **Views:** 20
- **Tags:** Portfolio, Art & Design, Graphic Design, Brand, Dark, Animated, Minimal, Large Type, Technology, Landing Page
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

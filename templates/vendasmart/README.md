# Venda Smart

A modern AI sales landing page template for service businesses to showcase WhatsApp-based appointment automation and book client meetings.

## Project Details
- **Slug:** `vendasmart`
- **Views:** 58
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Large Type, AI Sales, WhatsApp Automation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

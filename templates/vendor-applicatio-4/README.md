# Vendor Application Dashboard UI Template

A modern vendor application dashboard UI template for managing market stall applications, documents, dates, and bookings in one streamlined workspace.

## Project Details
- **Slug:** `vendor-applicatio-4`
- **Views:** 3
- **Tags:** Landing Page, Services, Technology, Minimal, Clean, Dashboard, Admin, Market, Vendor Management, Application Review
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Vendor Dashboard Template

A reusable vendor operations dashboard template for tracking purchase orders, production stages, and item progress in a clean admin interface.

## Project Details
- **Slug:** `vendor-dashboard-0`
- **Views:** 43
- **Tags:** Technology, Services, Landing Page, Clean, Minimal, Dashboard, Admin, Supply Chain, Order Management

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

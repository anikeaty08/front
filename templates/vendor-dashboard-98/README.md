# Vendor Dashboard Template

A reusable vendor dashboard template for procurement teams to track bidding stages, vendor performance, and expiring compliance documents in one place.

## Project Details
- **Slug:** `vendor-dashboard-98`
- **Views:** 40
- **Tags:** Technology, Services, Dashboard, Clean, Minimal, Documentation, Procurement, Vendor Management, Analytics
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

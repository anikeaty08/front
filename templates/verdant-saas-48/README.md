# Verdant SaaS Landing Page Template

A high-conversion landing page template for SaaS and AI data platforms featuring a dark aesthetic with glassmorphism and nature-inspired neon accents.

## Project Details
- **Slug:** `verdant-saas-48`
- **Views:** 26

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

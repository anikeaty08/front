# Hair Salon Landing Page Template

Elegant, minimalist landing page template for independent hair salons and stylists to showcase services, pricing, and contact details in a refined layout.

## Project Details
- **Slug:** `veronika-tuma`
- **Views:** 20
- **Tags:** Landing Page, Services, Brand, Minimal, Clean, Large Type, Portfolio, Beauty, Hair Salon, Local Business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

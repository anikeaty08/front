# Vertical OTT Mobile UI Template

A sleek vertical OTT mobile app UI template with episodes sheet and paywall flows, ready for streaming and micro-drama product prototypes.

- **Slug:** `vertical-ott-mobile-4`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

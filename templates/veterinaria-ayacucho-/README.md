# Veterinary Clinic Landing Page Template

A modern, Spanish-language veterinary clinic landing page template for showcasing services, team, testimonials, and contact details to attract pet owners.

## Project Details
- **Slug:** `veterinaria-ayacucho-`
- **Views:** 20
- **Tags:** Landing Page, Services, Health, Brand, Clean, Minimal, Large Type, Pet care, veterinary
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

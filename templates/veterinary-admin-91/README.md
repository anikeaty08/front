# Veterinary Admin Dashboard Template

A reusable admin dashboard template for veterinary clinics to manage appointments, patients, admissions, billing, and daily operations in one clean interface.

## Project Details
- **Slug:** `veterinary-admin-91`
- **Views:** 109
- **Tags:** Technology, Health, Services, Dashboard, Admin, Clean, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

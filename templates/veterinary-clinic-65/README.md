# Tierarzt Praxis Landing Page Template

A modern veterinary practice landing page template for small animal clinics to showcase services, opening hours, and online appointment booking.

## Project Details
- **Slug:** `veterinary-clinic-65`
- **Views:** 10
- **Tags:** Landing Page, Health, Services, Brand, Clean, Gradient, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

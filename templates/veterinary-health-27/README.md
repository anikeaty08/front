# Veterinary Health Dashboard UI Template

A clean veterinary health dashboard UI template for comparing pet bloodwork panels across dates and visualizing trends in lab parameters.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

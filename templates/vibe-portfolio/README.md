# Vibe Designer Portfolio Template

This template provides a sleek, modern portfolio layout for designers to showcase art direction, brand moods, and experiential identities for creative projects.

## Project Details
- **Slug:** `vibe-portfolio`
- **Views:** 1900
- **Tags:** Portfolio, Designer, Art Direction, Brand Identity, Moodboards, Creative Suite, Packages, Contact Form, Responsive, Tailwind CSS
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

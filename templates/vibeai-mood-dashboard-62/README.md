# VibeAI Mood Dashboard UI Template

A dark, glassmorphism VibeAI dashboard template for mood-based music, quotes, and tips, ready to reuse as a modern web app interface.

- **Slug:** `vibeai-mood-dashboard-62`
- **Views:** 14

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

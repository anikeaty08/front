# VibeCLI Developer Landing Page Template

A reusable landing page template for showcasing a modern, lightning-fast CLI framework designed to help developers build beautiful, type-safe command-line tools quickly.

- **Slug:** `vibecli-developer`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

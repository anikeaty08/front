# AI Developer Dashboard UI Template

A dark-mode AI code assistant dashboard UI template for building developer-focused e-commerce analytics and chat-driven creation experiences.

## Project Details
- **Slug:** `videcodingtemplate`
- **Views:** 3
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Dashboard, Developer, AI, E-commerce, Clean

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

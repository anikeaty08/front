# Live Video Chat App UI Template

A polished live video chat app UI template for random global connections, ready to reuse for chat, dating, or social calling products.

- **Slug:** `video-chat-app-84`
- **Views:** 6

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

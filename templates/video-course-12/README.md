# Copyright Course Lesson Page Template

A reusable lesson page template for online copyright and legal education courses, featuring video player, transcript, curriculum sidebar, and resource downloads.

## Project Details
- **Slug:** `video-course-12`
- **Views:** 25
- **Tags:** Education, Landing Page, Brand, Clean, Dark, Minimal, Technology, Course, Video Learning, Legal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

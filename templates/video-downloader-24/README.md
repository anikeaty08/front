# Video Downloader Landing Page Template

A clean landing page template for promoting a browser-based TikTok video downloader with fast, watermark-free downloads and simple user flows.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

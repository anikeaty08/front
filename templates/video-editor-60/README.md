# Video Editor Portfolio Template

A reusable portfolio template for cinematic video editors and post-production creatives to showcase work, services, showreels, and attract new projects.

## Project Details
- **Slug:** `video-editor-60`
- **Views:** 64
- **Tags:** Portfolio, Landing Page, Services, Dark, Minimal, Clean, Brand, Video Editor, Creative Studio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

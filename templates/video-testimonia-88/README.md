# Video Testimonial Agency Landing Page Template

A reusable landing page template for video testimonial agencies and service brands that want to boost trust, conversions, and sales with social proof.

- **Slug:** `video-testimonia-88`
- **Views:** 50

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

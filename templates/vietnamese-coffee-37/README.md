# Specialty Coffee Shop Landing Page Template

A modern Kakou Coffee-inspired landing page template for specialty cafés and roasteries to showcase their story, menu, and online orders.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

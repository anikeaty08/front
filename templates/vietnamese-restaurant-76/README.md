# Vietnamese Restaurant Landing Page Template

A modern dark-style restaurant landing page template for showcasing Vietnamese and sushi fusion menus, ambiance, and reservations for dine-in venues.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Vietnamese Coffee E-commerce Landing Page Template

A refined e-commerce landing page template for specialty Vietnamese coffee brands to showcase origins, rituals, products, pricing, and subscriptions.

## Project Details
- **Slug:** `vietnamese-specialty-19`
- **Views:** 191
- **Tags:** E-commerce, Food, Landing Page, Brand, Clean, Minimal, Large Type, Gradient, Coffee, Subscription

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Wine Bar Restaurant Landing Page Template

Elegant dark-mode wine bar website template for showcasing menus, private cellar events, and reservations for restaurants, bistros, and vinárna-style venues.

## Project Details
- **Slug:** `vinarna-krizik`
- **Views:** 19
- **Tags:** Landing Page, Food, Services, Brand, Dark, Clean, Minimal, Large Type, Restaurant, Wine Bar
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

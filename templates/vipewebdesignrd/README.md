# Digital Agency Landing Page Template

Modern dark-mode digital agency landing page template for web, software, and marketing services, ready to customize for your own studio or agency brand.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

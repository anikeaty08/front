# Instagram Trends & Reels Landing Page Template

A modern, free landing page template for showcasing Instagram Reels, CapCut templates, and trending audio to help creators find and use viral content fast.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

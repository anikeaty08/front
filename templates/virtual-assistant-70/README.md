# My Portfolio 

A clean, elegant virtual assistant portfolio landing page template to showcase services, experience, testimonials, and capture leads for remote business support.

- **Slug:** `virtual-assistant-70`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

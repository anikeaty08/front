# Virtual Fit E-commerce Interface Template

A clean virtual try-on interface template for fashion and e-commerce brands to showcase garment fitting, sizing, and catalog browsing experiences.

## Project Details
- **Slug:** `virtual-fit-fashion-90`
- **Views:** 14
- **Tags:** E-commerce, Fashion, Technology, Clean, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

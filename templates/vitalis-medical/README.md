# Healthcare Clinic Landing Page Template

A modern VITALIS-inspired healthcare landing page template for clinics and medical groups to showcase services, specialists, outcomes, and patient-first care online.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

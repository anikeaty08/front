# Health & Wellness Mobile App Template

A clean, modern mobile health tracking dashboard template designed for tracking calories, steps, heart rate, and daily nutrition.

## Project Details
- **Slug:** `vitals-health-7`
- **Views:** 34
- **Tags:** Health, Landing Page, Technology, Clean, Animated, Minimal, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

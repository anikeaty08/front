# Chemical Manufacturer Landing Page Template

A modern landing page template for chemical and dye manufacturers to showcase basic dye portfolios, technical specs, and industrial applications.

## Project Details
- **Slug:** `vivekcolourindsutries`
- **Views:** 67
- **Tags:** Landing Page, Brand, Technology, Clean, Dark, Gradient, Large Type, Portfolio, Services
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

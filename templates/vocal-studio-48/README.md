# Vocal Studio Mobile Dashboard Template

A modern mobile-first template for vocal studios to manage classes, bookings, media practice, and student profiles in one sleek dashboard interface.

## Project Details
- **Slug:** `vocal-studio-48`
- **Views:** 4
- **Tags:** Landing Page, Services, Brand, Clean, Dark, Minimal, Large Type, Technology, Music, Mobile App
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

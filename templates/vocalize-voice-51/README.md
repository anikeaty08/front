# Vocalize Fitness App Template

A modern mobile-first calorie tracking template featuring voice-input logging and daily nutrition summaries for health-conscious users.

## Project Details
- **Slug:** `vocalize-voice-51`
- **Views:** 10

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

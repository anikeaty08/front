# VOCALOPS

Moderne SaaS landing page template pour présenter une solution IA vocale de génération de rapports d’intervention et convertir les visiteurs avec une offre d’essai.

## Project Details
- **Slug:** `vocalops-webapp`
- **Views:** 16
- **Tags:** Landing Page, Technology, Business, Brand, Clean, Gradient, Minimal, Large Type, SaaS, Voice AI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

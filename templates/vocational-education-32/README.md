# Vocational Institute Landing Page Template

A clean, modern landing page template for vocational institutes and training centers to showcase programs, stories, FAQs, and capture enrollment inquiries.

## Project Details
- **Slug:** `vocational-education-32`
- **Views:** 41
- **Tags:** Landing Page, Education, Services, Clean, Minimal, Large Type, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

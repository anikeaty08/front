# Voice AI SHG Mobile Landing Page Template

A reusable mobile-first landing page template for showcasing a Hindi voice AI assistant that supports self-help groups (SHGs) with meetings, schemes, and learning content.

## Project Details
- **Slug:** `voice-ai-shg-72`
- **Views:** 31
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Mobile UI, Voice Assistant, SHG, Hindi
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

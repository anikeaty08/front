# Voice Recognition Landing Page Template

A reusable landing page template for playful voice-interaction experiences, featuring speech recognition, success states, retry flows, and a sleek minimal UI.

## Project Details
- **Slug:** `voice-interactio-18`
- **Views:** 56
- **Tags:** Landing Page, Technology, Dark, Minimal, Clean, Animated, voice recognition, interactive, web speech
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

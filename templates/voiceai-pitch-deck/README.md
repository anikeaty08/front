# AI Pitch Deck Website Template

A sleek, investor-ready pitch deck website template for AI and SaaS startups to showcase problem, solution, unit economics, and growth roadmap.

## Project Details
- **Slug:** `voiceai-pitch-deck`
- **Views:** 28
- **Tags:** Landing Page, Brand, Technology, Dark, Gradient, Minimal, Large Type, Pitch Deck, Startup, AI
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

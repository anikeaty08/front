# VoiceID Dashboard Template

A reusable dashboard template for biometric voice authentication platforms, showcasing real-time metrics, live monitoring, and API usage.

- **Slug:** `voiceid-biometric-36`
- **Views:** 535
- **Tags:** Dashboard, Biometric Authentication, Voice Verification, Live Monitor, API Usage, Metrics, User Activity, Security, Tailwind CSS

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

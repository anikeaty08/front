# Digital Experience Studio Landing Page Template

A reusable landing page template for creative studios and agencies to showcase immersive services, portfolio work, process, and project CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

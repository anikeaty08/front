# Void Architecture Studio Portfolio Template

VOID is a minimal, immersive architecture website inspired by the concept of space and silence. The design focuses on negative space, strong typography, and a dark cinematic palette to highlight the work without distractions.

Built with a clean and intentional approach, the interface removes clutter and lets visuals take center stage. Smooth scrolling, subtle interactions, and layered compositions create a fluid, gallery-like experience almost like walking through a physical space.

VOID is designed to feel calm, refined, and effortless where every interaction is soft, minimal, and purposeful.

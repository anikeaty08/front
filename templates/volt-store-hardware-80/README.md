# Hardware Shop Mobile App UI Template

A dark, modern hardware and electronics shop mobile app UI template for showcasing tools, components, and deals with trending products and smooth navigation.

## Project Details
- **Slug:** `volt-store-hardware-80`
- **Views:** 12
- **Tags:** E-commerce, Technology, Brand, Dark, Clean, Minimal, Gradient, Large Type, Mobile App, Hardware Store
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

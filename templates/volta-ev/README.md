# EV Dashboard Landing Page Template

A reusable landing page template designed for electric vehicle dashboards to showcase real-time monitoring, features, pricing, and app downloads.

## Project Details
- **Slug:** `volta-ev`
- **Views:** 1252
- **Tags:** Landing Page, EV Dashboard, Features, Pricing, Real-time Monitoring, App Download, Battery Management, Climate Control, Security, Analytics
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

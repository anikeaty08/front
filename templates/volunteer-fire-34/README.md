# Bombeiros Voluntários Landing Page Template

Multipage bombeiros voluntários website template para corporações de bombeiros e associações humanitárias que precisam comunicar serviços, história e recrutamento.

## Project Details
- **Slug:** `volunteer-fire-34`
- **Views:** 35
- **Tags:** Landing Page, Services, Health, Brand, Clean, Colorful, Large Type, Non-profit, Education, Social
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Von Bahr Agency Multi-Page Website Template

A modern, bilingual agency website template for service-based businesses to showcase services, portfolio, pricing, and legal pages with a polished, trustworthy feel.

- **Slug:** `von-bahr-agency-`
- **Views:** 267

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

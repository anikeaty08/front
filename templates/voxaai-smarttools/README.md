# AI Writing Tools Web App Template

A clean, minimal web app template for AI-powered professional writing tools, ready to connect with your OpenAI API key and launch as your own product.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

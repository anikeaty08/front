# VRCinema – Watch YouTube Videos in VR Instantly

A reusable landing page template for launching immersive VR video players with YouTube input, fullscreen playback, and mobile headset viewing.

## Project Details
- **Slug:** `vrcinema-screen`
- **Views:** 30
- **Tags:** Landing Page, Technology, Dark, Minimal, Futuristic, Animated, Video, VR, YouTube
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

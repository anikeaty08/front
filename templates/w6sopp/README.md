# Mobile Statistics Dashboard UI

Responsive mobile stats dashboard with monthly overview, donut chart, and categorized spending breakdown using Tailwind CSS.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

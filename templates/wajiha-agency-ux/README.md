# Wajiha UX & Interface Design Landing Page Template

This reusable landing page template showcases a UX and interface design agency with services, portfolio, and contact options, ideal for creative design firms.

## Project Details
- **Slug:** `wajiha-agency-ux`
- **Views:** 22

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Civic Walkability Reporting Landing Page Template

A reusable landing page template for a civic walkability reporting platform where citizens submit sidewalk reports and view real-time urban walkability data.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

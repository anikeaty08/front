# Backend Developer Portfolio Template

A dark, clean portfolio template for backend developers to showcase expertise, projects, and architecture thinking with a hiring-focused layout.

## Project Details
- **Slug:** `walker-portfolio`
- **Views:** 19
- **Tags:** Portfolio, Landing Page, Technology, Brand, Dark, Minimal, Large Type, Developer, Personal Site, Resume

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

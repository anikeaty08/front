# Wallet Dashboard UI Template

A modern wallet dashboard UI template for finance and investment apps, showcasing multi-currency balances, conversions, services, and transaction history.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

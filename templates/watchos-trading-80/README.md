# WatchOS Trading App UI Template

A comprehensive 32-screen smartwatch UI template for stock trading and financial portfolio management on WatchOS.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

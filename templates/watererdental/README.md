# Waterer Dental

A modern private dental clinic landing page template for showcasing services, promotions, reviews, and online booking for local practices.

## Project Details
- **Slug:** `watererdental`
- **Views:** 20
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type, Gradient, Technology, dental clinic template
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

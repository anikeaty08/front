# Waterfront Pizza Restaurant Landing Page Template

A modern restaurant landing page template for Mediterranean and pizza spots, featuring menus, reviews, hookah, catering, and location details ready to customize.

1. Open folder in VS Code / terminal.
2. Run `npm install`.

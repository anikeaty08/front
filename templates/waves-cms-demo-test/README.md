# AI CMS SaaS Landing Page Template

A dark, futuristic SaaS landing page template for AI-powered CMS and developer platforms, ideal for showcasing infrastructure, features, pricing, and technical workflow.

## Project Details
- **Slug:** `waves-cms-demo-test`
- **Views:** 444
- **Tags:** Landing Page, Technology, Brand, Dark, Futuristic, Minimal, Large Type, Gradient

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

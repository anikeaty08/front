# Web Design Agency Landing Page Template

A reusable landing page template for web design studios and digital agencies to showcase services, projects, process, and pricing with a premium modern look.

## Project Details
- **Slug:** `wavesitepl-test`
- **Views:** 24
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Minimal, Grid, Agency, Web Design

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

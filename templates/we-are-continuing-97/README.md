# Accounting Firm Articles Template

A reusable blog-style template for accounting firms and advisory practices to showcase articles, client stories, expertise, and lead-generating contact CTAs.

## Project Details
- **Slug:** `we-are-continuing-97`
- **Views:** 19
- **Tags:** Blog, Services, Business, Brand, Clean, Minimal, Editorial, Accounting, Professional
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

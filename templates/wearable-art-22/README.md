# Handcrafted Wearable Art E-commerce Landing Page Template

A clean, minimal e-commerce landing page template for showcasing handcrafted wearable art collections and custom commissions with an integrated enquiry form.

## Project Details
- **Slug:** `wearable-art-22`
- **Views:** 20
- **Tags:** E-commerce, Fashion, Art & Design, Clean, Minimal, Brand, Landing Page, Portfolio

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AFC Richmond Sports Landing Page Template

A premium sports club landing page template featuring modern Bento grids, match scheduling, and a heritage-focused design for football and athletic organizations.

## Project Details
- **Slug:** `wearerichmond-co-uk`
- **Views:** 33

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

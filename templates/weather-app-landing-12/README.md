# Weather App Landing Page Template

A sleek landing page template for weather apps and forecasting platforms, designed to showcase real-time forecasts, radar, alerts, and premium features.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

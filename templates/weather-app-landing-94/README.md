# Weather App Landing Page Template

A reusable landing page template for hyper-local weather apps, forecasting platforms, and climate tech products featuring radar, alerts, widgets, and API sections.

## Project Details
- **Slug:** `weather-app-landing-94`
- **Views:** 30
- **Tags:** Landing Page, Technology, Dark, Futuristic, Gradient, Animated, Clean, Weather, API
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Web Agency Landing Page Template

A reusable landing page template for freelance web designers and small agencies to showcase services, portfolio, pricing, testimonials, and capture leads.

## Project Details
- **Slug:** `web-agency-landing-29`
- **Views:** 43
- **Tags:** Landing Page, Services, Portfolio, Technology, Clean, Gradient, Minimal, Animated
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

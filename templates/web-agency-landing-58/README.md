# Web Agency Landing Page Template

A dark, gradient-rich web agency landing page template for showcasing custom WordPress, WooCommerce, and SEO services with transparent, tiered pricing.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

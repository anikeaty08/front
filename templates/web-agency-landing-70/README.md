# Web Agency Landing Page Template

A reusable landing page template for fast-turnaround web design services, showcasing offers, testimonials, and WhatsApp-first lead generation.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

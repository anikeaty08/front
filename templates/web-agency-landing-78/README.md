# AI Automation Agency Landing Page Template

A reusable landing page template for AI and WhatsApp automation agencies to showcase services, social proof, offers, testimonials, and lead capture.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Local Web Design Landing Page Template

A modern, dark-style landing page template for local web design and small business services, ideal as a reusable one-page or multi-section website layout.

## Project Details
- **Slug:** `web-design-services-32`
- **Views:** 20

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Web Development Studio Landing Page Template

A reusable landing page template for web development studios and digital agencies to showcase services, tech stack, and capture project inquiries.

## Project Details
- **Slug:** `web-developmen-36`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

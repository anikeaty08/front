# Web Development Agency Template

A reusable website template for web development agencies to showcase services, portfolio, team, testimonials, blog content, and project inquiries.

## Project Details
- **Slug:** `web-developmen-47`
- **Views:** 95
- **Tags:** Landing Page, Services, Technology, Portfolio, Blog, Dark, Gradient, Animated, Clean, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Web Project

A dark, conversion-focused landing page template for Shopify-partnered e-commerce agencies to showcase process, portfolio, pricing and capture new client projects.

## Project Details
- **Slug:** `web-project`
- **Views:** 186
- **Tags:** Landing Page, E-commerce, Services, Technology, Brand, Dark, Clean, Gradient, Large Type, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

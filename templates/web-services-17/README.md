# Web Services Pricing Template

A reusable pricing template for web design and business website services, built to showcase packages, features, and conversion-focused offers.

## Project Details
- **Slug:** `web-services-17`
- **Views:** 60
- **Tags:** Services, Technology, Landing Page, Clean, Minimal, Pricing, Web Design, Business Website

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

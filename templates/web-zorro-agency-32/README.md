# Local Services Website Landing Page Template

A high-converting landing page template for managed local service business websites, ideal for agencies selling done-for-you sites with clear pricing and ongoing care.

## Project Details
- **Slug:** `web-zorro-agency-32`
- **Views:** 16
- **Tags:** Landing Page, Services, Technology, Business, Brand, Clean, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Web3 Dapp Directory Landing Page Template

A dark, futuristic Web3Explorer UI template for a multi-chain dapp directory with landing, explorer, and project detail views ready for Web3 platforms.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

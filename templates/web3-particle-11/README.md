# Web3 Particle Engine Experience Template

Immersive Web3 particle engine template using Three.js and MediaPipe for gesture-controlled 3D visuals, ideal for interactive landing pages and experiments.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

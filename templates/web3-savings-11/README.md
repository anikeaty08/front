# DeFi Rotating Savings Dashboard Template

A sleek web dApp UI template for on-chain rotating savings circles (ROSCA), featuring login, groups dashboard, payment flow, and group creation screens.

- **Slug:** `web3-savings-11`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

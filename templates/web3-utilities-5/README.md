# Web3 Tools Directory Landing Page Template

A dark, developer-focused landing page template for showcasing a curated directory of Web3 utilities, tools, and calculators with search and filtering.

## Project Details
- **Slug:** `web3-utilities-5`
- **Views:** 20
- **Tags:** Landing Page, Technology, Brand, Dark, Minimal, Grid, Large Type, Web3, Developer Tools, Directory
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

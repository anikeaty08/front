# WebBuggs Agency Landing Page Template

A dark, futuristic WebBuggs agency landing page template for digital studios to showcase services, process, testimonials, and capture project inquiries.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Interactive Agency Website Template

A dark, futuristic interactive agency website template for showcasing web development services, portfolio, pricing, FAQs, and contact, ready to customize for your brand.

## Project Details
- **Slug:** `webdevai-agiagency`
- **Views:** 25
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Gradient, Large Type, Portfolio, Agency, Web Development
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

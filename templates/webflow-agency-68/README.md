# Webflow Agency Landing Page Template

A reusable landing page template for Webflow agencies and creative studios to showcase services, process, and portfolio with a polished dark UI.

## Project Details
- **Slug:** `webflow-agency-68`
- **Views:** 45
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Gradient, Animated, Minimal, Portfolio, Webflow
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Webflow Developer Portfolio Template

A dark, minimal Webflow developer portfolio template to showcase projects, stack, and contact details for freelance web developers.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

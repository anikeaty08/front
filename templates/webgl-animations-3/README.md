# Email Marketing Landing Page Template

A futuristic landing page template for agencies and consultants promoting email and SMS marketing services, audits, automation, and customer retention.

- **Views:** 48

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

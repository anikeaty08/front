# Web na míru Agency Landing Page Template

Conversion-focused agency landing page template for custom, high-speed websites with pricing, FAQs, and lead-gen CTAs, ready to reuse for web studios.

## Project Details
- **Slug:** `webnamiru`
- **Views:** 50
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Dark, Minimal, Large Type, Gradient
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

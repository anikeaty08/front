# Website Design Studio Template

A reusable website design studio template for agencies and service businesses to showcase services, target industries, and drive consultation bookings.

## Project Details
- **Slug:** `website-design-35`
- **Views:** 20
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Portfolio, SEO, Agency
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

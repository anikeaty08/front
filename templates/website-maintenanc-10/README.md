# Website Maintenance Landing Page Template

A reusable landing page template for website maintenance and security services, designed to showcase plans, support, uptime monitoring, and trust-building CTAs.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

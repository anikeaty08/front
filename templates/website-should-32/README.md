# Qusar Marathon Event Landing Page Template

A high-energy Qusar Marathon landing page template for promoting race events, showcasing routes, partners, sustainability, and driving registrations.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Digital Marketing Agency Landing Page Template

A modern digital marketing agency landing page template for promoting TikTok, Facebook, YouTube ads and web development services to local business clients.

## Project Details
- **Slug:** `website-social10`
- **Views:** 28
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Gradient, Large Type, Minimal, Marketing, Agency
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

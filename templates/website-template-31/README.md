# Амарант «Северная Олива» Landing Page Template

Готовый landing page template для бренда здорового питания и семян амаранта, с героем, продуктами, наукой, новостями и контактами.

## Project Details
- **Slug:** `website-template-31`
- **Views:** 58
- **Tags:** Landing Page, Food, Health, Brand, Clean, Minimal, Large Type, Gradient, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

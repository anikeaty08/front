# Mobile Car Detailing Landing Page Template

A modern mobile car detailing landing page template with booking flow, pricing tiers, and gallery—ready to customize for local auto detail businesses.

## Project Details
- **Slug:** `website-with-16`
- **Views:** 16
- **Tags:** Landing Page, Services, Brand, Clean, Minimal, Large Type, Technology, Automotive, Local Business, Booking
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Web Design Studio Landing Page Template

A dark, modern studio landing page template for showcasing web design and engineering services, selected work, and a project inquiry contact form.

## Project Details
- **Slug:** `websmiths-studio-in`
- **Views:** 14
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Clean, Grid, Portfolio, Large Type, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

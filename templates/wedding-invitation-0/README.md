# Wedding Invitation Landing Page Template

A romantic wedding invitation template for couples to share event details, travel info, schedule, accommodation tips, and RSVP online.

## Project Details
- **Slug:** `wedding-invitation-0`
- **Views:** 25
- **Tags:** Landing Page, Wedding, Clean, Minimal, Animated, Elegant, RSVP, Event, Romance
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mobile Wedding Invitation Landing Page Template

A refined mobile wedding invitation landing page template with story, gallery, and RSVP form, perfect for modern couples sharing their special day online.

## Project Details
- **Slug:** `wedding-invitation-32`
- **Views:** 1
- **Tags:** Wedding, Landing Page, Brand, Clean, Minimal, Large Type, Mobile, RSVP, Event
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

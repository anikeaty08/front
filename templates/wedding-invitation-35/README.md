# Wedding Invitation Landing Page Template

A reusable wedding invitation template for showcasing the couple, event details, gallery, RSVP, and gift registry in an elegant digital format.

## Project Details
- **Slug:** `wedding-invitation-35`
- **Views:** 45
- **Tags:** Wedding, Landing Page, Brand, Elegant, Clean, Dark, Gradient, Animated, Minimal
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

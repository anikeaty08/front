# Wedding Invitation Landing Page Template

A romantic wedding invitation template with an animated envelope intro, event schedule, venue details, gallery, and RSVP form for elegant celebrations.

## Project Details
- **Slug:** `wedding-invitation-76`
- **Views:** 35
- **Tags:** Wedding, Landing Page, Animated, Elegant, Clean, Minimal, Services, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

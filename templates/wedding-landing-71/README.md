# Romantic Wedding

A romantic, interactive wedding website template for couples to share their story, schedule, FAQs and RSVP details with guests in a single elegant page.

## Project Details
- **Slug:** `wedding-landing-71`
- **Views:** 17
- **Tags:** Wedding, Landing Page, Brand, Clean, Colorful, Gradient, Large Type, Animated, Portfolio
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

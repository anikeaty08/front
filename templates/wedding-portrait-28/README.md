# Photography Portfolio Landing Page Template

A clean photography portfolio landing page template for wedding and portrait photographers to showcase work, services, and capture client inquiries.

## Project Details
- **Slug:** `wedding-portrait-28`
- **Views:** 7
- **Tags:** Landing Page, Portfolio, Art & Design, Minimal, Brand, Photography, wedding photographer, clean layout
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

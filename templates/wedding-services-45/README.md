# Wedding Services Landing Page Template

Elegant wedding services landing page template for showcasing decoration, catering, MUA, testimonials, and contact details for professional planners.

## Project Details
- **Slug:** `wedding-services-45`
- **Views:** 26
- **Tags:** Landing Page, Services, Wedding, Brand, Clean, Minimal, Large Type, Portfolio, Marketing
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

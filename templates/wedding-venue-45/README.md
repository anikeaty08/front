# Wedding Venue Landing Page Template

Elegant wedding and events venue website template for showcasing spaces, services, gallery and inquiries for quintas or countryside locations.

- **Slug:** `wedding-venue-45`
- **Views:** 304

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

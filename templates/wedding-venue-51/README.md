# Wedding Venue Landing Page Template

A reusable wedding venue landing page template for showcasing premium event lawns, facilities, gallery, reviews, and booking enquiries.

## Project Details
- **Slug:** `wedding-venue-51`
- **Views:** 500
- **Tags:** Landing Page, Wedding, Services, Brand, Clean, Minimal, Large Type, Travel, Event Venue, Hospitality
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

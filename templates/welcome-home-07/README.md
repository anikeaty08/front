# Welcome Home Travel Greeting Page Template

A playful, pastel travel welcome page template for celebrating someone’s return home with maps, animations, and personal touches you can easily customize.

## Project Details
- **Slug:** `welcome-home-07`
- **Views:** 25
- **Tags:** Travel, Landing Page, Brand, Colorful, Illustrative, Animated, Minimal, Large Type, Personal, Celebration
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

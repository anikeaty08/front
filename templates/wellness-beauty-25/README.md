# Beauty & Wellness Booking Landing Page Template

A modern just-book style landing page template for beauty, physio and barber booking platforms, ready to customize for your own appointment service.

## Project Details
- **Slug:** `wellness-beauty-25`
- **Views:** 46

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

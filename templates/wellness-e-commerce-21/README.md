# Wellness E-commerce Landing Page Template

A modern wellness e-commerce landing page template for promoting supplement collections, essential cures, reviews, FAQs, and a journal in a clean, premium layout.

- **Slug:** `wellness-e-commerce-21`
- **Views:** 41

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

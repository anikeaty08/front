# Wellness Landing Page Template

A reusable wellness landing page template for yoga, meditation, and fitness brands to showcase classes, guided programs, community proof, and conversions.

## Project Details
- **Slug:** `wellness-landing-96`
- **Views:** 20
- **Tags:** Landing Page, Health, Services, Clean, Minimal, Dark, Wellness, Yoga, Meditation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

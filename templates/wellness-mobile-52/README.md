# Wellness App Dashboard UI Template

A mobile wellness app dashboard UI template for tracking sleep, steps, calories, and habits, ready to customize for modern health and fitness products.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

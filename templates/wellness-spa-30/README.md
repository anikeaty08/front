# Wellness and Massage Center Template

A clean and calming landing page template designed for massage therapists and wellness studios to showcase services and take bookings via WhatsApp.

## Project Details
- **Slug:** `wellness-spa-30`
- **Views:** 38
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Animated, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

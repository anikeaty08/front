# ChangeUp Global

A modern consulting landing page template for boutique and innovation-focused consultancies to showcase services, thinking, and contact in a clean, conversion-ready layout.

## Project Details
- **Slug:** `weprototypechange1`
- **Views:** 12

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

#  Smart city Educational Consultancy 

A modern template for educational consultancies to promote study abroad programs, capture student bookings, and manage inquiries with a built-in admin dashboard.

## Project Details
- **Slug:** `westernsmartcity-consult`
- **Views:** 21
- **Tags:** Landing Page, Education, Services, Brand, Clean, Minimal, Gradient, Technology, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Weybey - Bank

A modern glassmorphism banking dashboard UI template for card management, activity, referrals, and settings screens in fintech web or app projects.

- **Views:** 37

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

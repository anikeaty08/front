# WhatsApp AI Automation Landing Page Template

A high-converting dark-mode landing page template for WhatsApp AI automation services, designed to help agencies showcase lead capture and follow-up solutions.

## Project Details
- **Slug:** `whatsapp-automation`
- **Views:** 27
- **Tags:** Landing Page, Services, Technology, Dark, Gradient, Futuristic, Large Type, Brand

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

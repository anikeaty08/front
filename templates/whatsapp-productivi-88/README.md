# WhatsApp Productivity Assistant Landing Page Template

A modern WhatsApp productivity assistant landing page template designed to showcase AI scheduling, reminders, and email-to-task workflows for freelancers.

## Project Details
- **Slug:** `whatsapp-productivi-88`
- **Views:** 90
- **Tags:** Landing Page, Technology, Business, Brand, Clean, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

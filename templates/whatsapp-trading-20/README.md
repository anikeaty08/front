# WhatsApp Trading Signals Landing Page Template

A high-converting landing page template for WhatsApp-based trading signal services, optimized to capture leads for Forex, Gold, and indices recommendations.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

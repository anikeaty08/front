# Whiskey Distillery Landing Page Template

A premium whiskey distillery website template for showcasing collections, craft process, and membership clubs with an elegant dark, brand-forward design.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

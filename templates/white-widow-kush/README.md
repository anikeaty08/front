# Cannabis Product Landing Page Template

A dark, premium cannabis strain landing page template for showcasing products, pricing, and Cash App purchases with a modern, glassmorphism design.

## Project Details
- **Slug:** `white-widow-kush`
- **Views:** 23
- **Tags:** Landing Page, Brand, Clean, Dark, Gradient, Large Type, Minimal, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

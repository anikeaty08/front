# B2B Wholesale Dealer Portal Template

A reusable wholesale dealer portal template for automotive parts distributors to manage catalogs, fitment search, bulk orders, pricing tiers, and support.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

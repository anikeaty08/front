# Wholesale Importer E-commerce Template

A reusable e-commerce template for wholesale importers and promotional product suppliers to showcase catalogs, categories, stock, and corporate merchandise offers.

## Project Details
- **Slug:** `wholesale-importer-84`
- **Views:** 30
- **Tags:** E-commerce, Services, Brand, Clean, Minimal, Animated, Technology, wholesale, promotional products, catalog
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

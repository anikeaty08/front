# Executive Portfolio Landing Page Template

A polished executive portfolio landing page template for CMOs, founders, and leaders to showcase responsibilities, metrics, and strategic value to investors.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

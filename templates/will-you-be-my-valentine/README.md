# Valentine Proposal Landing Page Template

A playful Valentine proposal landing page template with interactive yes/no buttons, secret notes, and a romantic success modal for personalized invitations.

## Project Details
- **Slug:** `will-you-be-my-valentine`
- **Views:** 53
- **Tags:** Landing Page, Brand, Romantic, Valentine, Interactive, Minimal, Clean, Animated, Colorful
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

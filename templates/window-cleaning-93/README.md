# Window Cleaning Services Landing Page Template

A reusable landing page template for local window cleaning and exterior home services, designed to generate quotes, bookings, and customer trust.

## Project Details
- **Slug:** `window-cleaning-93`
- **Views:** 504
- **Tags:** Landing Page, Services, Clean, Minimal, Brand, local services, home maintenance, quote form
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

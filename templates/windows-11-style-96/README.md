# Windows 11 Style Settings Template

A reusable Windows 11 inspired template for building modern desktop-style settings and system control interfaces with a sleek UI.

## Project Details
- **Slug:** `windows-11-style-96`
- **Views:** 36
- **Tags:** Settings, Desktop UI, Windows 11, System Controls, Sidebar, Taskbar, Icons, Responsive, Tailwind CSS, Template

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

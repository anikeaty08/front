# Wine & Spirits E-commerce Template

A refined e-commerce template for showcasing and selling curated wines, spirits, and craft beers with elegant product browsing and brand-led merchandising.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

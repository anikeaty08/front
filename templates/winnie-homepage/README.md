# Winnie Homepage

A reusable landing page template for vending, coffee service, and workplace refreshment brands to showcase solutions, testimonials, gallery highlights, and lead capture.

## Project Details
- **Slug:** `winnie-homepage`
- **Views:** 36
- **Tags:** Landing Page, Services, Food, Brand, Dark, Clean, Minimal, coffee, vending, lead generation
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

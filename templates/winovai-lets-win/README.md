# Voice AI SaaS Landing Page Template

A reusable dark, modern landing page template for voice AI SaaS platforms selling automated call agents, lead qualification, and demo bookings.

## Project Details
- **Slug:** `winovai-lets-win`
- **Views:** 35
- **Tags:** Landing Page, Technology, Business, Brand, Dark, Gradient, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

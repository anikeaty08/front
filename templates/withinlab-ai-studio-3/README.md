# AI Studio Landing Page Template

A reusable landing page template for an AI strategy and prototyping studio, ideal for showcasing services, method, founders, and a strong "Parla con noi" CTA.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

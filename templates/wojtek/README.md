# Medical Research Network Landing Page Template

A dark, modern landing page template for international clinical and medical research collaboration networks to showcase focus areas, coordinators, and contact details.

## Project Details
- **Slug:** `wojtek`
- **Views:** 36
- **Tags:** Landing Page, Health, Technology, Brand, Dark, Clean, Minimal, Large Type, Medical, Research
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

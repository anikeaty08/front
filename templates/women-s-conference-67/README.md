# Women’s Conference Landing Page Template

Elegant, faith-centered landing page template for promoting a women’s conference or church event, featuring speakers, agenda, testimonials, FAQ, and ticket registration.

## Project Details
- **Slug:** `women-s-conference-67`
- **Views:** 502
- **Tags:** Landing Page, Religious, Conference, Brand, Clean, Minimal, Large Type, Gradient, Event
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

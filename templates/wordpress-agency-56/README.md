# WordPress Agency Landing Page Template

A reusable landing page template for web design and WordPress agencies to showcase services, results, pricing, and drive audit or call bookings.

## Project Details
- **Slug:** `wordpress-agency-56`
- **Views:** 67
- **Tags:** Landing Page, Services, Technology, Dark, Minimal, Grid, Brand, WordPress, Agency, Conversion
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

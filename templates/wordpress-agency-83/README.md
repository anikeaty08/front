# WordPress Agency Landing Page Template

A reusable landing page template for WordPress web design agencies to showcase services, pricing, process, testimonials, and book strategy calls.

## Project Details
- **Slug:** `wordpress-agency-83`
- **Views:** 43
- **Tags:** Landing Page, Services, Technology, Brand, Dark, Futuristic, Gradient, Clean, WordPress, Agency
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

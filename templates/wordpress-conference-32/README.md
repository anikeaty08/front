# WordPress Conference Landing Page Template

A modern WordCamp-style landing page template for WordPress and tech conferences, ready to reuse for event promotion, tickets, news, and sponsors.

## Project Details
- **Slug:** `wordpress-conference-32`
- **Views:** 87
- **Tags:** Landing Page, Conference, Technology, Brand, Clean, Colorful, Large Type, Gradient, Event, WordPress
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

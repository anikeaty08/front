# WordPress Support Landing Page Template

A clean, conversion-focused WordPress support landing page template for agencies and service providers to showcase maintenance, security, and care plans.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# WordPress Web Design Landing Page Template

A reusable landing page template for WordPress web design agencies to showcase packages, build trust, and capture quote requests from business clients.

## Project Details
- **Slug:** `wordpress-web-43`
- **Views:** 86
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Brand, pricing, lead generation, WordPress, agency
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

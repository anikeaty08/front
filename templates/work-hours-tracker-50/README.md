# Work Hours Tracker Dashboard UI Template

A modern Work Hours Tracker dashboard UI template for time tracking apps, helping you monitor shifts, breaks, and required hours with a clean layout.

## Project Details
- **Slug:** `work-hours-tracker-50`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Workflow Automation Landing Page Template

A reusable landing page template for workflow automation SaaS products, featuring hero, feature highlights, testimonials, pricing, and conversion-focused CTAs.

- **Slug:** `workflow-automation-83`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

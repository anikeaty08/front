# WorkFlow Project Dashboard UI Template

A reusable WorkFlow dashboard UI template for task, sprint, and project management with stats, filters, and productivity widgets ready for modern web apps.

## Project Details
- **Slug:** `workflow-dashboard`
- **Views:** 29
- **Tags:** Technology, Landing Page, Brand, Clean, Dark, Dashboard, SaaS, Project Management, Productivity, UI Kit
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

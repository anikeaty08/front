# Workout Builder Web App Template

A simple, reusable workout builder template for coaches and trainers to create multi-day exercise plans and export structured workout PDFs.

## Project Details
- **Slug:** `workout-planner-17`
- **Views:** 15
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Technology, Fitness, Coaching, PDF Export
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Workshop Booking Landing Page Template

A modern template for craft studios to showcase workshops and let visitors browse a calendar, select dates, and reserve spots—all ready to customize.

## Project Details
- **Slug:** `workshop-booking-92`
- **Views:** 750
- **Tags:** Landing Page, Services, Art & Design, Clean, Minimal, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

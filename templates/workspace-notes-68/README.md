# Notebook Workspace App Template

A reusable template for building a clean, Notion-style workspace and document editor UI with sidebar navigation, rich text controls, and collaborative actions.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# WorkSync SaaS Landing Page Template

A reusable WorkSync-inspired SaaS landing page template for team chat and task management platforms, featuring product hero, feature grid, stats, and CTA sections.

## Project Details
- **Slug:** `worksync`
- **Views:** 26
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Gradient, Large Type, SaaS, Productivity, Team Collaboration

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# WriteRush Feedback Modal UI Template

A reusable WriteRush-inspired feedback modal UI template for capturing user ratings, quick-select chips, and comments inside web apps and plugins.

- **Slug:** `writerush-feedback-11`
- **Views:** 50

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

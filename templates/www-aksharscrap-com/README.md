# Industrial Scrap Trading Landing Page Template

A clean, modern landing page template for industrial scrap trading businesses to showcase materials, process, and contact details for quote and pickup inquiries.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# AtoZ E-commerce Landing Page Template

A modern AtoZ-style e-commerce landing page template for online marketplaces, featuring hero promos, product grids, and brand-focused offer sections.

## Project Details
- **Slug:** `www-atoz-market-`
- **Views:** 13
- **Tags:** E-commerce, Landing Page, Services, Brand, Clean, Colorful, Grid, Large Type, Minimal, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

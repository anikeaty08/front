# Beautiful Aura

A reusable wellness template for beauty and self-care brands that combines product discovery, community discussion, and newsletter growth in one polished site.

## Project Details
- **Slug:** `www-beautifulaura-com`
- **Views:** 15
- **Tags:** E-commerce, Health, Social, Brand, Landing Page, Clean, Gradient, Minimal, wellness, community
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

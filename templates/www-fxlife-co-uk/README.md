# FX Life Market Intelligence Dashboard Template

A dark, institutional-style FX intelligence dashboard template for traders to track macro context, liquidity maps, and daily trade bias in one interface.

## Project Details
- **Slug:** `www-fxlife-co-uk`
- **Views:** 101
- **Tags:** Landing Page, Technology, Brand, Dark, Clean, Grid, Large Type, Minimal, Trading, Forex
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

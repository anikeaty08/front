# Logopedie Zedelgem

A clean, professional logopedie (speech therapy) landing page template for independent practitioners to present services, expertise, and contact options with ease.

## Project Details
- **Slug:** `www-logopediezedelgem-be`
- **Views:** 26
- **Tags:** Health, Services, Landing Page, Brand, Clean, Minimal, Large Type, Portfolio, Speech Therapy, Medical Practice
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Modern E-commerce Storefront Template

A modern Lumina-branded e-commerce storefront template featuring product grid, filters, cart preview, and secure checkout for online retail brands.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

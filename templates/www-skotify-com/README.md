# Music Streaming Dashboard UI Template

A dark, modern music streaming dashboard UI template for audio apps and web players, ready to customize for playlists, libraries, and full playback controls.

## Project Details
- **Slug:** `www-skotify-com`
- **Views:** 11

- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

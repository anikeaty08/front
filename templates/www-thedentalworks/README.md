# Dental Clinic Landing Page Template

A reusable landing page template for dental clinics and facial aesthetics practices to showcase services, team, financing, and drive online bookings.

## Project Details
- **Slug:** `www-thedentalworks`
- **Views:** 49
- **Tags:** Health, Services, Landing Page, Clean, Minimal, Brand, dental clinic, facial aesthetics, booking form
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

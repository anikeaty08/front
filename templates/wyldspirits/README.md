# Wild Spirits Yoga

A reusable landing page template for independent yoga instructors and mobile wellness brands to showcase services, locations, events, and bookings.

## Project Details
- **Slug:** `wyldspirits`
- **Views:** 35
- **Tags:** Yoga Red Oak, Texas and Surrounding Areas
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

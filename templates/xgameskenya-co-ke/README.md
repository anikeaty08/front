# PC Computer Shop E-commerce Landing Page Template

A dark, modern e-commerce landing page template for PC computer shops to showcase pre-built rigs, components, and an interactive custom PC builder.

## Project Details
- **Slug:** `xgameskenya-co-ke`
- **Views:** 49
- **Tags:** E-commerce, Landing Page, Technology, Brand, Dark, Minimal, Gradient, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

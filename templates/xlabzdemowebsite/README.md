# Aether Creative Studio Landing Page Template

Aether is a dark, cinematic landing page template for design studios and creative agencies to showcase showreels, stats, and brand-forward digital experiences.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

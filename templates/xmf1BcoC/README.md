# Location Search Interface

UI for searching locations with recent searches, popular cities, and current location option using Tailwind CSS and icons.

## Project Details
- **Slug:** `xmf1BcoC`
- **Views:** 80
- **Tags:** Location Search, Recent Searches, Popular Cities, Tailwind CSS, Responsive UI, Iconography
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

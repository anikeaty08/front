# Crypto DeFi Mobile Landing Page Template

A modern DeFi-focused mobile landing page template for promoting Sui-based trading apps, highlighting features, metrics, and a waitlist signup flow.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

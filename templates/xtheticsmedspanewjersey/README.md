# Med Spa Landing Page Template

Elegant med spa landing page template for aesthetic clinics to showcase services, locations, and bookings with a branded, appointment-focused design.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

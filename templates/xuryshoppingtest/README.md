# Minimalist E-commerce Product Page Template

A clean, minimalist e-commerce product page template for showcasing a premium backpack or similar physical product with features, use cases, and checkout.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Cashflow Dashboard Interface

Responsive UI displaying cashflow data with income, expenses, charts, category breakdown, and recent transactions using Tailwind and Chart.js.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

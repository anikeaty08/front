# Special Education Center Landing Page Template

A clean, pastel landing page template for special education and rehabilitation centers to present services, share their story, and drive contact inquiries.

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Photography Portfolio Landing Page Template

A reusable photography landing page template for portrait, family, maternity, and wedding photographers to showcase work and turn visitors into bookings.

## Project Details
- **Slug:** `yarytejedaphotography`
- **Views:** 405
- **Tags:** Landing Page, Portfolio, Services, Wedding, Dark, Minimal, Clean, Large Type, Photography, Personal Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

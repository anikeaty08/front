# yashuuportifolio

An immersive portfolio template for developers to showcase experience, projects, skills, services, and contact info in a navigable 3D world.

## Project Details
- **Slug:** `yashuuportifolio`
- **Views:** 26
- **Tags:** Portfolio, Technology, Dark, 3D, Animated, Futuristic, Personal branding, Developer portfolio, Interactive

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

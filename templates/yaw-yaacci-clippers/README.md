# Yaw Yaacci Clippers

A modern barbershop landing page template for unisex hair design studios to showcase services, inclusivity, and drive phone bookings and walk-ins.

- **Slug:** `yaw-yaacci-clippers`
- **Views:** 16

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Interactive Rolodex Card Stack UI

Displays a vertical stack of interactive profile cards with smooth transitions and floating icons using Tailwind CSS and custom animations.

## Project Details
- **Slug:** `ycm0AI`
- **Views:** 922
- **Tags:** HTML, CSS, Tailwind CSS, Animation, UI, Interactive Cards
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

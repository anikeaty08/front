# Car Service App UI Template

Mobile-first car service app UI template for browsing vehicle types, booking popular services, and promoting membership plans in a clean, modern layout.

## Project Details
- **Slug:** `yes-this-layout-8`
- **Views:** 18
- **Tags:** Landing Page, Services, Technology, Clean, Minimal, Large Type, Automotive, Mobile App, Membership, Car Service
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# YesChess Education Landing Page Template

A clean and modern education landing page template designed for schools, academies, and chess clubs featuring course sections and enrollment CTAs.

## Project Details
- **Slug:** `yeschess-school-14`
- **Views:** 45
- **Tags:** Education, Services, Clean, Minimal, Colorful, Landing Page, Social

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# OneMedAll Patient Reimbursement Landing Page Template

A clean, healthcare-focused landing page template for OneMedAll-style patient reimbursement hubs, guiding surgical dental patients to upload plans and book intake calls.

## Project Details
- **Slug:** `yesonus-patient`
- **Views:** 28
- **Tags:** Landing Page, Health, Services, Brand, Clean, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

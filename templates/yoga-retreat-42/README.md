# Retreat Services Landing Page Template

A reusable landing page template for yoga retreat organizers, facilitators, and wellness collaborators to present services, partnership support, and contact details.

## Project Details
- **Slug:** `yoga-retreat-42`
- **Views:** 39
- **Tags:** Landing Page, Services, Health, Minimal, Clean, Large Type, Wellness, Retreat, Yoga

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

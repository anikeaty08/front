# Dental Clinic Landing Page Template

A reusable dental clinic landing page template for promoting treatments, building trust, and driving appointment bookings with a modern healthcare-focused design.

1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# YCF(YourCyclingFriend)

A premium adventure travel template designed for cycling tour operators, featuring route showcases, local guide profiles, and custom trip planning forms.

## Project Details
- **Slug:** `yourcyclingfriend`
- **Views:** 15
- **Tags:** Travel, Services, Clean, Minimal, Outdoor, Adventure, Fitness, Modern
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

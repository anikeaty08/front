# Muslim Youth Association Landing Page Template

A cinematic, dark-themed landing page template for Muslim youth and family associations to showcase mission, activities, facilities, and contact details.

## Project Details
- **Slug:** `youth-community-7`
- **Views:** 32
- **Tags:** Landing Page, Brand, Education, Social, Dark, Clean, Minimal, Large Type, Non-profit, Services

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Youth Sports Club Landing Page Template

A reusable landing page template for youth sports clubs and community organizations to promote activities, events, galleries, and membership signups.

## Project Details
- **Slug:** `youth-sports-75`
- **Views:** 20
- **Tags:** Landing Page, Sports, Community, Social, Services, Clean, Dark, Gradient, Minimal, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Youtube

A reusable mobile UI template for video streaming apps, designed to showcase content feeds, category filters, and bottom navigation in a clean interface.

## Project Details
- **Slug:** `youtube`
- **Views:** 23
- **Tags:** Technology, Landing Page, Minimal, Clean, Entertainment, Mobile App, Video Streaming, UI Kit
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

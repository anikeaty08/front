# Yucca Packaging Landing Page Template

A modern landing page template for packaging and supply companies to showcase food service, processing, and agriculture solutions with a premium brand feel.

## Project Details
- **Slug:** `yucca-packaging-6`
- **Views:** 30
- **Tags:** Landing Page, Business, Brand, Clean, Minimal, Large Type, E-commerce, Services, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

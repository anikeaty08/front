# Yume Pan-Asian Restaurant Landing Page Template

A refined Pan-Asian restaurant landing page template featuring menu sections, gallery, reviews, and reservations for modern dining brands.

## Project Details
- **Slug:** `yume`
- **Views:** 19
- **Tags:** Landing Page, Food, Brand, Clean, Minimal, Large Type, Restaurant, Asian Fusion, Modern Dining, Reservations
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Mochi Desktop Companion Product Landing Page Template

A sleek product landing page template for showcasing a next-gen desktop companion or robotics gadget with specs, accessories, reviews, and ecommerce CTAs.

## Project Details
- **Slug:** `yuzumigolabs-in`
- **Views:** 144
- **Tags:** Landing Page, E-commerce, Technology, Brand, Dark, Minimal, Gradient, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

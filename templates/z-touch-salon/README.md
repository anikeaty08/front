# Luxury Hair Salon Landing Page Template

A premium salon website template for showcasing hair services, stylists, gallery highlights, reviews, and appointment booking in a polished luxury format.

## Project Details
- **Slug:** `z-touch-salon`
- **Views:** 116
- **Tags:** Landing Page, Services, Fashion, Dark, Clean, Minimal, Luxury salon, Beauty, Hair salon
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

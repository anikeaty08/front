# Course Progress Visualization UI

Displays animated course progress with bar and line charts, performance stats, and a gradient action button using Tailwind CSS.

- **Views:** 77

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

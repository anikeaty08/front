# Dhaba Restaurant Landing Page Template

A modern dhaba-style restaurant landing page template for showcasing veg & non-veg menus, gallery, reviews, and contact details for local eateries.

- **Slug:** `zaika-dhaba-zaika-15`
- **Views:** 435

- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

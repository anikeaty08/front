# Automotive Service Landing Page Template

Premium automotive workshop landing page template for showcasing car renovation, tuning, import and mechanic services with bold, dark, high-end styling.

## Project Details
- **Slug:** `zapacars`
- **Views:** 375
- **Tags:** Landing Page, Services, Brand, Automotive, Car Workshop, Dark, Clean, Minimal, Large Type, Gradient

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

# Streetwear E-commerce Landing Page Template

A minimalist streetwear e-commerce landing page template for showcasing collections, lookbooks, and newsletter signups for modern apparel brands.

## Project Details
- **Slug:** `zen-z-indianstore`
- **Views:** 35
- **Tags:** E-commerce, Fashion, Landing Page, Brand, Clean, Minimal, Dark, Large Type, Grid, Technology
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

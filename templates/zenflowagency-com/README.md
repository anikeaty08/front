# AI Agency Landing Page Template

A reusable AI agency landing page template for service-based businesses, featuring pricing, feature highlights, and strong demo-focused calls-to-action.

## Project Details
- **Slug:** `zenflowagency-com`
- **Views:** 30
- **Tags:** Landing Page, Services, Technology, Brand, Clean, Minimal, Gradient, Large Type, AI agency, Local business
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

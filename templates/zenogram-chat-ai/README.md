# AI Chatbot SaaS Landing Page Template

A reusable landing page template for promoting AI-powered website chatbots like Zenogram Chat, designed to convert visitors into users and leads.

## Project Details
- **Slug:** `zenogram-chat-ai`
- **Views:** 41
- **Tags:** Landing Page, Technology, Brand, Dark, Gradient, Clean, Minimal, Large Type
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

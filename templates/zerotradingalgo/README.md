# Algo Trading Landing Page Template

A high-converting landing page template designed to promote an algo trading system with performance stats, pricing, guarantees, and risk disclaimers.

## Project Details
- **Slug:** `zerotradingalgo`
- **Views:** 40

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

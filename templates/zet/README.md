# Zet Work Management Landing Page Template

A modern dark-mode Zet-themed landing page template for work management SaaS products, featuring hero, app UI preview, features, testimonials, and FAQ sections.

## Project Details
- **Slug:** `zet`
- **Views:** 14
- **Tags:** Landing Page, Technology, Brand, Clean, Dark, Gradient, Large Type, Animated
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

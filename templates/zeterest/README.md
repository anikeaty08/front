# Zero Interest Capital Fund Landing Page Template

A modern landing page template for zero-interest housing capital funds and impact ventures to showcase their mission, model, roadmap, and partners.

## Project Details
- **Slug:** `zeterest`
- **Views:** 30
- **Tags:** Landing Page, Services, Non-profit, Clean, Minimal, Large Type, Brand
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

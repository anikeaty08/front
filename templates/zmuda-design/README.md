# Web Designer Portfolio Landing Page Template

A dark, futuristic personal portfolio landing page template for web designers and developers to showcase work, skills, and invite new project inquiries.

## Project Details
- **Slug:** `zmuda-design`
- **Views:** 40
- **Tags:** Landing Page, Portfolio, Art & Design, Technology, Brand, Dark, Futuristic, Animated, Minimal, Large Type

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

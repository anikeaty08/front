# Zoho IT Services Landing Page Template

A modern, multi-section Zoho implementation and IT services landing page template for consultancies and agencies to showcase services, experience, and contact options.

## Project Details
- **Slug:** `zoho-it-services-49`

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

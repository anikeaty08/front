# Maximalist City Zoo Landing Page Template

A bold, maximalist zoo landing page template for showcasing attractions, animals and online ticket sales for urban zoos or theme parks.

## Project Details
- **Slug:** `zoo-ticket-landing-45`
- **Views:** 35
- **Tags:** Landing Page, Entertainment, Brand, Colorful, Large Type, Gradient, Animated, Services, Travel
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.

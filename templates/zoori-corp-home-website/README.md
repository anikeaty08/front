# Technology Services Landing Page Template

A reusable landing page template for AI-powered software studios and development agencies to showcase services, projects, credibility, and lead capture.

## Project Details
- **Slug:** `zoori-corp-home-website`
- **Views:** 63
- **Tags:** Landing Page, Services, Technology, Dark, Gradient, Grid, Minimal, Clean
- **Template Type:** Vite-React Project (Compiled from static HTML)

## How to Run
1. Open folder in VS Code / terminal.
2. Run `npm install`.
3. Run `npm run dev`.
